# FBI長官の翼・事件簿 その五（事件081〜100）

- **中身は全部が秘密。翼より先に言わない。** 欄の読み方と規則は資料「fbi-knowledge.md」の§4と§9。闇の全体と12人の大統領は§7。
- 1つの事件は、端緒 → 十転（翼が崩すたびに1つ開く）→ 処理の選択肢 → 索引カード。**証拠は、翼が動いた分だけ、書いてある順に、それを扱う人の報告として出す。かっこ内の手続きと時間を守る。**
- 章の頭に、その章の大統領と、逮捕の三点・壁・道・場面がある。**逮捕は資料§4-9の4つ（三点、道、時期、翼の決心）がそろった時だけ起きる。手錠をかけるのは、いつも翼。**
- 行頭に書いてよいのは、資料の名簿（§5）と、その事件の「関係者」欄の名前と役だけ。翼の名前の行は書かない。

## 第九章　票の闇（081〜090。2028年5月〜6月。オハイオ、サウスカロライナ、イリノイ、アラバマ、ペンシルヴェニア、アリゾナ、オクラホマ、コロラド、メイン、ヴァージニア）

- **この章の闇**：票。有権者名簿、選挙区割り、候補者の署名、郵便投票、献金者の名前が出ない金、毎週の自動献金、「投票した罪」、大統領図書館、合わない署名。2028年は大統領選挙の年で、春から夏は予備選挙。
- **番頭**：ディーコン・プライス（ダニエル・プライス、55歳。選挙の「数字」を請け負う会社の社長。教会の執事なので皆が「ディーコン」と呼ぶ。どちらの党の仕事も受ける）。
- **章を通して出る人**：プライス／ホロウィッツ／ライアソン／ファインバーグ／ハーン／エリス／ガードナー／ヘイズ。
- **章の終わりに分かること**：母は生きている。別の名前でメインの海辺の町に19年。1度も選挙を休まずに。そして翼が20歳で長官になった理由の半分。名前を出したのは棚。世界中の新聞が書く史上最年少の長官は、隠れている母親をおびき出す餌。
- **章転**：票は盗まれていない。数えられる人が先に選ばれている。名簿から消す。区割りの線を引く。署名を弾く。脅す。開票の夜には、もう終わっている。そして、それを請け負う者はどちらの党の仕事も受ける。
- **通報**：081。女性の声が消された名前の一覧の並べ方を言い、最後に「長官に、有権者名簿に自分の名前がちゃんとあるか確かめるように伝えてください」と足す。
- **この章の大統領**：⑪ブラッドフォード前大統領（ハル・ブラッドフォード、74歳。アメリカの前大統領。2021年から2025年。敗北を潔く認めた男として全国で好かれている。今年、再び出馬している）。退任後、自分の名前の大統領図書館を、棚の外国向けの受付にした。①から⑧の元首たちはみな図書館の財団に寄付し、寄付の翌月に請求票が1枚出ている。出したのは彼。高齢者の「毎週の献金」（086）も財団へ流れた。
- **逮捕の三点**：086の献金の流れ（選挙陣営から図書館の財団へ）／088の財団の帳簿（8人の元首の名前と日付）と、レプリカの執務室に置かれた本物の贈答品／090でプライスが渡す鍵と、レプリカの机の引き出しの請求票の控え。
- **逮捕の壁**：前大統領。生涯シークレット・サービスが警護する。大統領の公務として行った事は罪に問えない（2024年の連邦最高裁判決）。選挙の年で、彼は候補者。逮捕すれば「FBIが選挙に介入した」。得をするのは現職のコールドウェル。翼を長官にした男。
- **逮捕の道**：問えないのは公務だけ。図書館の財団の金は退任後の私的な事で、候補者としての行為も私的な事。司法長官アバナシーが特別検察官を任命する（ハーン。28 C.F.R. Part 600）。罪名は外国代理人登録法違反（22 U.S.C. §611）、外国の元首からの金を受けて司法省に働きかけた共謀（18 U.S.C. §371）、献金の流用（52 U.S.C. §30114）、公有財産の窃取（§641。国に帰属する贈答品）。コロラド地区の大陪審が封印起訴。シークレット・サービスのガードナーと事前に調整する。警護官は法の執行を妨げない。夏の党大会より前に動く。選挙が近づくほど動けなくなる（投票日前60日は動かない司法省の慣行）。

### 081　消えた名前
- **発生**：予備選挙で投票を断られた人たち。オハイオ州の郡。2028年5月。
- **管轄と法令**：連邦の選挙の前90日間に、有権者名簿の組織的な削除をしてはならない（全米有権者登録法、52 U.S.C. §20507(c)(2)(A)）。有権者を脅したり投票を妨げたりすれば18 U.S.C. §241。
- **関係者**：アボット（ルース・アボット、91歳。1958年から休まず投票してきた。名簿上は「死亡」）／郡の選挙管理委員長／名簿照合を請け負う会社の技術者／4万人に異議を出した男（引退した歯科医）／クリーヴランド支局長／パテル／ピケット／通報ホットラインの受付担当
- **端緒**：予備選挙の朝、91歳の女性が投票所で言われた。「名簿では亡くなっています」。彼女はFBIの支局まで歩いてきた。「死んだ人間が歩いて文句を言いに来ました」。その郡で同じ朝、2000人が投票を断られている。
- **真相**：州は名簿の「整理」を会社に請け負わせた。会社は他州の名簿や死亡記録と照合して「同一人物」を消す。照合するのは名前と生年月日だけ。同じ名前、同じ生年月日の別人は全国に何万組もいる。消された人は特定の名字に偏る。同じ名字が多い人々。そして会社とは別に、1人の男が会社の配るツールを使って4万人に「この人はもう住んでいない」と異議を出した。法律は1人が何人に異議を出してもいいと言っている。連邦法は選挙前90日間の組織的な削除を禁じている。消したのは85日前。
- **十転**：①名簿の手違い。1人の。②同じ朝に2000人。③削除の記録。「死亡」「転居」「重複」。④消したのは請負の会社。照合したのは名前と生年月日。⑤同じ名前、同じ日に生まれた別人。91歳の彼女と同じ名前の女性がアリゾナで去年死んでいる。⑥消された名字の偏り。ある人々に多い名字が4倍消されている。会社は「システムは名字の意味を見ていない」と言う。見ていない。だがそうなる。⑦4万人への異議。1人の男。引退した歯科医。ツールは会社が無料で配っている。⑧削除の日。選挙の85日前。連邦法の90日の内側。⑨会社への支払い。「削除した名前1件につき」。⑩通報ホットラインに女性の声。「消された名前の一覧を、消した日の順ではなく、依頼した者の順に並べてください。依頼したのは州ではありません。州に一覧を渡した団体があります。……それから長官に、有権者名簿に自分の名前がちゃんとあるか確かめるように伝えてください」。
- **証拠**：1 彼女の70年の投票記録（郡。即日）／2 断られた2000人の一覧（郡。当日）／3 削除の記録（同）／4 照合の規則（名前と生年月日。会社に召喚状。1週間）／5 名字の偏り（ホロウィッツの分析。数日）／6 4万人への異議の書類（郡。即日）／7 削除の日付（同）／8 会社への支払い契約（州。数日）／9 通報の録音（FBIの通報センター。即日）
- **参考知識**：有権者名簿は死亡や転居した人を消して保つ。だが連邦法は、連邦の選挙の前90日間に組織的に消す事を禁じている。名前と生年月日だけで照合すると別人が消える。
- **誤った見立て**：1人の手違い／選挙管理委員長の落ち度／異議を出した男の悪意
- **障壁**：名簿は州の物。消すのは「整理」のため。異議は法律が許している。予備選挙はもう終わった。
- **部下のミス**：ピケットが異議を出した歯科医の家へ行き、「あなたのした事は選挙妨害です」と言う。男は本気で驚く。「私は名簿を正しくしたかっただけだ。ツールがそう言った」。彼は4万人の1人も訪ねていない。ピケットも、彼の話を聞く前に決めていた。
- **索引カード**：第20番（2011年）「オハイオ　有権者名簿の照合の請負の件」。棚。依頼した鍵＝議会。
- **処理の選択肢**：2000人を11月までに名簿に戻す。会社。一覧を渡した団体。90日。ルース・アボットの次の投票。

### 082　線を引く男
- **発生**：死んだ選挙コンサルタントのパソコン。サウスカロライナ州。2028年5月。
- **管轄と法令**：党派的な区割りは連邦裁判所が止めない（2019年の連邦最高裁判決）が、人種による区割りは禁止。法廷での偽証は18 U.S.C. §1621、§1623。証拠を奪うための侵入と証人への妨害は§1512。2019年に、死んだ区割りの専門家の娘が見つけたハードディスクが裁判で問題になった件が実際にある。
- **関係者**：クレイ（エルドン・クレイ、75歳。選挙区割りのコンサルタント。故人。病死）／その娘（40歳。父と10年口をきいていなかった）／州議会の区割り委員長／娘の家に侵入した男たち／コロンビア駐在事務所長／パテル／オドネル／ファインバーグ
- **端緒**：区割りのコンサルタントが病気で死んだ。娘が父の部屋を片付けて、ハードディスクを4台見つけた。中に7万の地図。娘はそれを区割り訴訟の原告側の弁護士に渡そうとした。その夜、娘の家に侵入者が入った。ハードディスクはもう銀行の貸金庫の中だった。
- **真相**：選挙区の線は10年に1度、州議会が引き直す。誰をどの区に入れるか。コンサルタントは30年、14の州で線を引いてきた。法廷で州議会は宣誓して言った。「人種は見ていない。党派だけを見た」。ハードディスクの地図には、通り1本ごとに人種の割合が入っている。そしてもう1つ。彼は片方の党のためだけに引いていない。ある州ではこちらの党、ある州ではあちらの党。どの州でも「いま座っている者が負けない線」。2つの党の現職同士の手打ち。
- **十転**：①死んだ父のハードディスクと泥棒。②7万の地図。③区割り訴訟。州は宣誓して言った。「人種は見ていない」。④地図のレイヤー。通り1本ごとの人種の割合。⑤見ていた。委員長は法廷で嘘を言った事になる。⑥侵入者が狙ったのはハードディスクだけ。宝石はそのまま。⑦侵入者を雇ったのはどちらの党の人間か。⑧ハードディスクの中の顧客一覧。14の州。片方の党だけではない。両方。⑨彼のメモ。「区割りの目的は勝つ事ではない。負けない事。相手の現職も負けさせない。そうすれば相手も訴えない」。⑩侵入者を雇った金は、両方の党の州組織から同じ法律事務所へ出ている。ハードディスクを表に出したくないのは両方。
- **証拠**：1 ハードディスクの地図（娘の同意。コピーの解析に1〜2週間）／2 法廷の宣誓証言の記録（裁判所。即日）／3 地図のレイヤー（同上の解析）／4 侵入の痕跡（市警とFBIの証拠対応班。当日）／5 顧客一覧（同上の解析）／6 彼のメモ（同）／7 侵入者への支払い（法律事務所の口座。召喚状。2〜3週間）
- **参考知識**：選挙区の線は10年に1度引き直す。線を引く人は「誰が誰を選ぶか」ではなく「誰が選ぶ人を選ぶか」を決める。党派のための区割りを連邦裁判所は止めない。人種による区割りは禁止。法廷で宣誓して嘘を言えば犯罪。
- **誤った見立て**：ただの空き巣／片方の党の不正／娘の父への報復
- **障壁**：区割りは州議会の仕事。党派のための線は合法。ハードディスクの中身は父と顧客の秘密かもしれない。両方の党が敵。
- **部下のミス**：オドネルが娘に「お父さん、ひどい事をしていたんですね」と言う。娘は言う。「10年口をきかなかったのは私です。あなたに言われたくない」。彼女は翌日、貸金庫の鍵をFBIではなく記者のエリスに渡そうとする。
- **索引カード**：第19番（2010年）「サウスカロライナ　区割りコンサルタントの記録の件」。棚。依頼した鍵＝議会。
- **処理の選択肢**：侵入した男たち。委員長（宣誓下の嘘）。ハードディスクを誰に渡すか。娘。

### 083　下手な偽物
- **発生**：候補者名簿から外された5人の候補。イリノイ州。2028年5月。
- **管轄と法令**：候補者名簿の署名の偽造は州の選挙犯罪。連邦の根拠は、候補者から金をだまし取った電信詐欺（18 U.S.C. §1343）と、選挙の妨害の共謀（§241）。2022年にミシガン州で、偽造署名のために知事選の候補5人が名簿から外された件が実際にある。
- **関係者**：オーウェンズ（マーガレット・オーウェンズ、52歳。郡の看護部長から知事選に出ようとした。外された1人）／署名集めの会社の社長／署名を書いた若者たち（時給で雇われた）／得をした候補／州の選挙管理委員会の職員／ヤブロンスキ／ホロウィッツ／サンチェス／クオン
- **端緒**：州知事の予備選挙。候補になるには1万5000人の署名が要る。10人のうち5人が名簿から外された。提出した署名の束に、同じ筆跡の偽の署名が何千と混じっていたから。5人は言う。「だまされた。金を払って集めてもらっただけだ」。
- **真相**：署名集めは会社に1つ何ドルで頼む。締め切りが近づくと1つ20ドルまで上がる。集める人たちはもう街頭に立たない。部屋で古い名簿を見ながら順番に書く。5人は同じ会社に頼んでいた。だまされたのは本当。だが会社はわざと「ばれるように」書かせている。同じ筆跡、同じペン、名簿の順番のまま。外された5人はみな同じ系統の候補。残った同じ系統の候補は1人だけで、票は彼に集まる。反対側の4人は割れたまま。
- **十転**：①偽の署名を出した5人の候補。②5人は同じ会社に頼んでいる。だまされた側。③会社は金を取って偽物を渡した。ただの詐欺。④偽の署名の出来。あまりに下手。同じ筆跡。名簿の順番。見れば分かる。⑤会社は10年この仕事をしている。ばれない偽物を作れる人たち。⑥わざとばれるように。⑦書いた若者たちの話。「今回は丁寧にやるなと言われました」。⑧会社の口座。5人からの支払いのほかに、もう1つ大きな支払い。名目は「コンサルタント料」。⑨払ったのは残った5人の誰でもない。州外の、選挙の「数字」を請け負う会社。⑩外された5人と残った5人の色分け。外された5人はみな同じ系統。残った同じ系統の1人は言う。「私は何も知らない」。本当に知らない。頼んだのは彼に金を出す人たち。
- **証拠**：1 外された署名の束（州の選挙管理委員会。即日）／2 5人の契約（各陣営。当日）／3 偽の署名の出来（FBIラボの筆跡鑑定。1週間）／4 若者たちの話（聴取。数日）／5 会社の口座の「コンサルタント料」（召喚状。2週間）／6 払った会社（同）／7 外された5人と残った5人（公開情報。即日）
- **参考知識**：候補になるには決まった数の署名が要る。署名集めは1つ何ドルで会社に頼める。偽の署名を出せば犯罪で、出した候補は知らなくても名簿から外される。
- **誤った見立て**：5人の候補の不正／会社のただの手抜き／得をした候補の仕業
- **障壁**：外された5人はもう戻れない（期限は過ぎた）。得をした候補は本当に知らない。頼んだ者は「コンサルタント料を払っただけ」。
- **部下のミス**：クオンが得をした候補を早とちりで「黒幕」と報告書に書く。翼が提出前に読む。候補は知らない。知らない者が一番得をするように作られている。クオンの早とちりは3回目（042、049）。
- **索引カード**：第18番（2010年）「イリノイ　署名集めの会社の件」。棚。依頼した鍵＝司法。
- **処理の選択肢**：会社の社長。「コンサルタント料」を払った者。外された5人。予備選挙はやり直せるか。

### 084　親切な娘さん
- **発生**：郵便投票を「預かる」人たち。アラバマ州の農村の郡。2028年5月〜6月。
- **管轄と法令**：連邦の選挙で、不正な投票の取得・投票・集計によって住民をだませば連邦犯罪（52 U.S.C. §20511）。封をしていない票への書き足し、票の廃棄も同じ。2018年にノースカロライナ州で、不在者投票の回収の不正で連邦議会選挙がやり直しになった件が実際にある。
- **関係者**：エステル（エステル・グローヴァー、84歳。目がよく見えない）／リサ（33歳。票を集める係。時給で雇われた）／リロイ（61歳。郡の古い「票まとめ役」。元締め）／郡の選挙管理委員会の職員／勝った候補／バーミングハム支局長／ブライト／デュプレ
- **端緒**：連邦下院の予備選挙で900票差。負けた側が言う。「郵便投票がおかしい」。84歳の女性が支局で話した。「親切な娘さんが来てくれたんです。票を預かって出しておいてあげますと。封はしていませんでした。私は目が見えないもので」。

### 099　承認しない
- **発生**：国連総会の週。ニューヨーク。2028年9月下旬。
- **管轄と法令**：どの者をその国の元首と承認するかは大統領だけが決める（2015年の連邦最高裁判決）。承認していない者に元首の免責はない（1990年のパナマの将軍の先例）。国連総会に来た者は、国連との本部協定で、公務の間と往復は逮捕できない。
- **関係者**：ヴォロノフ／ルイス大統領／ペンハロウ／ペンハロウの執事／エリス（モスクワの拘置所）／国務長官／マローン／ヴォス／ヘイズ／ノーラ
