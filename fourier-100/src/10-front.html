はじめに ― この本の使い方

この本は、フーリエ解析をまったく習っていない人が、フーリエ解析の大定理を自分の手で証明していくためだけに作られています。100 の大問はすべて証明問題で、すべてが名前のついた定理です。計算問題は一問もありません。

1. 予備知識はいりません。ただし第 0 章は飛ばせません

「位相って何」「ルベーグ積分って何だっけ」― まったく問題ありません。第 0 章（約 10 ページ）に、本書で使う記号・定義・前提となる定理をすべて書きました。集合の記号から始まり、上限・下限、距離空間、コンパクト性、可測集合、ルベーグ積分、収束定理、$L^{p}$ 空間、Hilbert 空間まで、必要なものは全部あります。

第 0 章の定義には $\mathbf{(D\text{-}12)}$ のような番号が振ってあり、各大問の中で「$\mathbf{(D\text{-}12)}$ により」のように参照します。分からない記号が出てきたら、番号をたどって戻ってください。第 0 章は読み物ではなく、辞書として何十回も引くものです。

なお第 0 章の定理（単調収束定理・Fubini の定理など、測度論の基本定理）は証明なしに使ってよいことにします。それらまで証明すると本書が測度論の本になってしまうからです。第 0 章に書いていない事実を使うときは、その都度自分で証明してください。

2. 100 大問は一本の階段です

大問は独立していません。1 番から順に解くことで、フーリエ解析の理論全体が下から組み上がるように並べてあります。各大問の冒頭には

依存　大問 14, 21 ／ $\mathbf{(D\text{-}31)}$, $\mathbf{(T\text{-}5)}$

のように、使ってよい既出の結果を明示しました。ここに挙がっていないものは（第 0 章を除き）使わずに証明してください。逆に、挙がっているものは証明抜きで自由に使えます。

各大問は「主張」と「誘導」からなります。誘導は証明の骨格を 3〜6 段に割ったものです。誘導を読まずに主張だけで挑むのが最も力がつきますが、30 分考えて糸口が見えなければ誘導 (1) だけ読む、という使い方を勧めます。

4. 到達点

最後まで登ると、次のものが「自分で証明した定理」になります。

  • Fejér の定理、Parseval の等式、Riemann–Lebesgue の補題、Carleson 型の各点収束（弱い版）
  • Plancherel の定理、Poisson の和公式、標本化定理、Paley–Wiener の定理
  • Hardy–Littlewood の極大不等式、Lebesgue の微分定理、Calderón–Zygmund 分解、Hilbert 変換の $L^{p}$ 有界性
  • Riesz–Thorin と Marcinkiewicz の補間定理、Hausdorff–Young の不等式
  • Sobolev の埋め込み定理、熱・波動・Schrödinger 方程式の基本評価
  • Bochner の定理、Wiener のタウバー型定理、素数定理
  • 不確定性原理（Heisenberg・Hardy・Benedicks）、等周不等式
  • そして最後に Roth の定理（3 項等差数列の存在）
