付録 A　分野横断の地図

1000 題は分野別に並んでいるが、実際には四つの分野は互いを支え合っている。ここでは部をまたぐ主要な依存の筋を挙げる。番号は大問番号である。前半は各部の古典的な幹（第 1–12 章）の間の筋、後半は現代の枝（第 13–20 章）が他の部から何を借りているかの筋である。

古典的な幹の間の筋

複素 → 関数解析{{R:193}}（スペクトルが空でない：レゾルベントの解析性＋Liouville）→ {{R:194}}（Gelfand の半径公式：Hadamard の公式 {{R:16}}）→ {{R:213}}（Gelfand–Mazur）→ {{R:215}}（正則関数カルキュラス：Cauchy の積分公式 {{R:14}}）。作用素論の出発点はすべて複素解析である。
複素 → 調和解析{{R:56}}, {{R:57}}（Hadamard の三円・三直線）→ {{R:339}}（Riesz–Thorin）→ {{R:341}}–{{R:344}}（Marcinkiewicz・Hausdorff–Young・HLS）。補間定理は最大値原理の変装である。
複素 → 確率{{R:98}}（Hadamard の因数分解）→ {{R:486}}（Cramér の分解定理）、{{R:487}}（Marcinkiewicz の定理）。特性関数を整関数として扱う場面。
複素 → 数論{{R:37}}（Jensen）→ {{R:97}}, {{R:98}}（零点の収束指数・因数分解）→ {{R:137}}（$\xi$ の積表示）→ {{R:135}}, {{R:136}}（零点計数・明示公式）→ {{R:131}}（素数定理）。
関数解析 → 調和解析{{R:163}}, {{R:164}}（Baire・一様有界性）→ {{R:306}}（du Bois-Reymond）、{{R:308}}（Stein の最大原理）。／ {{R:176}}, {{R:181}}（Alaoglu・Krein–Milman）→ {{R:332}}, {{R:416}}（Bochner）。
関数解析 → 確率{{R:489}}（条件付き期待値＝Radon–Nikodym または $L^{2}$ 射影 {{R:188}}）／ {{R:473}}（Prohorov）は {{R:176}}（Alaoglu）の測度版／ {{R:575}}（エルゴード分解）は {{R:183}}（Choquet）そのもの。
調和解析 → 関数解析{{R:367}}（M. Riesz）→ {{R:386}}（ベクトル値特異積分）、{{R:299}}（Toeplitz の指数）は {{R:205}}, {{R:207}}（Fredholm・Atkinson）の具体例。
調和解析 → 確率{{R:332}}（Bochner）→ {{R:476}}–{{R:478}}（特性関数と Lévy の連続性定理）→ {{R:479}}–{{R:484}}（CLT・安定分布）。中心極限定理は Fourier 変換の定理である。
調和解析 → PDE{{R:352}}–{{R:353}}（極大関数・微分定理）→ {{R:356}}, {{R:357}}（近似単位元の a.e. 収束）→ {{R:363}}–{{R:368}}（CZ 理論）→ {{R:401}}–{{R:412}}（Sobolev）。
確率 → 解析{{R:512}}（Brown 運動と Dirichlet 問題）→ {{R:78}}, {{R:82}}（Poisson 積分・Perron）の確率的再証明／ {{R:523}}（Feynman–Kac）→ {{R:242}}（スペクトル定理）→ {{R:600}}。
確率 → 数論・組合せ論{{R:461}}（Khinchin）→ {{R:349}}（Khinchin の不等式）→ {{R:377}}（Littlewood–Paley）／ {{R:438}}–{{R:450}}（加法的組合せ論）では {{R:462}}（Paley–Zygmund）と第二モーメント法が随所に現れる。
前半の合流点大問 {{R:600}}：Feynman–Kac（{{R:523}}）＋ 大偏差原理（{{R:562}}）＋ 非有界自己共役作用素のスペクトル定理（{{R:242}}）＋ Laplace 法。第 IV 部前半の到達点。

現代の枝が借りているもの

関数解析 → 複素{{R:188}}（射影定理）と Riesz 表現 → {{R:horL2}}（Hörmander の $L^{2}$ 評価）→ {{R:bergman}}（Bergman 核）。多変数関数論の現代的な核心は Hilbert 空間論である。{{R:mrmt}}（可測 Riemann 写像定理）は Beurling 変換の $L^{p}$ 有界性（CZ 理論 {{R:363}}–{{R:368}}）と Neumann 級数で解ける。
複素 → 複素（深層）{{R:72}}（Löwner の方法）→ {{R:loewner}}（放射型 Löwner 方程式）→ {{R:debranges}}（de Branges）。／ {{R:37}}（Jensen）→ {{R:nev2}}（Nevanlinna の第二主要定理）は Picard の定理の定量化。
調和解析 → 数論{{R:440}}（Weyl 和）→ {{R:dec}}（decoupling と Vinogradov の平均値定理）／ 大篩 → {{R:bv}}（Bombieri–Vinogradov）→ 有界素数間隔／ {{R:449}}（Szemerédi）→ {{R:gt}}（Green–Tao）。
表現論 → 保型形式{{R:418}}（Peter–Weyl）, {{R:415}}（Plancherel）→ $\mathrm{SL}(2,\mathbb{R})$ の Plancherel 定理 → {{R:trace}}（Selberg の跡公式）→ Weyl 則 {{R:212}} の双曲版。
関数解析 → 作用素環{{R:226}}–{{R:238}}（$C^{*}$-環とスペクトル定理）→ {{R:stine}}（Stinespring）→ {{R:tt}}（冨田–竹崎）。{{R:ks}}（Kadison–Singer）は Weaver の予想と interlacing 多項式を経て解かれた ― 確率論（ランダム行列 {{R:584}}）との交点。
関数解析 → 幾何{{R:205}}–{{R:207}}（Fredholm 指数の安定性）→ {{R:299}}（Toeplitz 指数）→ {{R:as}}（Atiyah–Singer）。熱核の短時間漸近（{{R:251}} の半群論）が McKean–Singer 経由で指数を局所化する。
確率 → 関数解析{{R:521}}（Girsanov）→ {{R:cm}}（Cameron–Martin）／ {{R:533}}（Ornstein–Uhlenbeck）→ {{R:nelson}}（Nelson の超縮小性）⇔ {{R:579}}（対数 Sobolev）。／ ランダム作用素 → {{R:anderson}}（Anderson 局在）。
調和解析 → 調和解析（深層）{{R:308}}（Carleson–Hunt）→ {{R:lt}}（Lacey–Thiele の時間周波数解析）／ {{R:361}}（Kakeya）→ {{R:st}}（Stein–Tomas）→ 制限予想／ Strichartz 評価 → {{R:nls}}（エネルギー臨界 NLS）。／ {{R:363}}（CZ 分解）→ sparse 支配 → {{R:a2}}（$A_{2}$ 定理）。
調和解析 → 確率{{R:frost}}（Frostman）とエネルギー積分 → {{R:511}}（Brown 運動の零点集合）の次元計算／ Gaussian 過程の最大値 → {{R:tal}}（majorizing measure）は {{R:503}}（Kolmogorov–Chentsov）の最終形。
解析 → 確率（幾何）{{R:579}}（対数 Sobolev）→ {{R:be}}（Bakry–Émery）／ Kantorovich 双対 → {{R:brenier}}（Brenier）→ Wasserstein 勾配流／ {{R:479}}（CLT）→ {{R:steinm}}（Stein の方法）, {{R:entclt}}（エントロピー的 CLT）。
複素 → 確率（共形不変性）{{R:65}}（Riemann の写像定理）＋ {{R:loewner}}（Löwner 方程式）＋ {{R:518}}（Lévy の特徴づけ）→ {{R:sle}}（SLE）。／ {{R:gff}}（Gauss 自由場）, {{R:wilson}}（一様全域木）, {{R:rsw}}（RSW）が離散から連続への橋となる。
四分野の最終合流点大問 {{R:smirnov}}（Smirnov の定理）：離散正則関数（複素）＋ RSW とパーコレーション（確率）＋ Riemann の写像定理 {{R:65}} と境界対応（複素）＋ 正規族 {{R:102}}（関数論）＋ SLE$_{6}$ との同定（確率解析）。本書の最後の一題。

分野内の主要な幹

複素{{R:1}}, {{R:13}}（Goursat・Cauchy）→ {{R:26}}–{{R:28}}（Laurent・留数）→ {{R:37}}（Jensen）→ {{R:89}}–{{R:101}}（無限積・Hadamard）→ {{R:127}}–{{R:138}}（ζ）→ 解析数論の深層。別筋：{{R:51}}–{{R:55}}（Schwarz–Pick・双曲計量）→ {{R:65}}, {{R:74}}（写像定理・一意化）→ {{R:102}}–{{R:113}}（力学系）→ 擬等角写像 → 単葉関数と調和測度。
関数解析{{R:151}}–{{R:153}}（Hahn–Banach）→ {{R:175}}–{{R:187}}（弱位相）→ 凸解析と最適化／ {{R:163}}（Baire）→ {{R:164}}–{{R:167}}（三大定理）／ {{R:188}}–{{R:199}}（Hilbert）→ {{R:200}}–{{R:212}}（コンパクト）→ {{R:226}}–{{R:238}}（$C^{*}$ とスペクトル定理）→ {{R:239}}–{{R:250}}（非有界）→ スペクトル理論の深層・作用素環の深層。
調和解析{{R:301}}–{{R:313}}（収束論）→ 各点収束の深層／ {{R:351}}–{{R:353}}（極大関数）→ {{R:363}}–{{R:368}}（CZ）→ {{R:376}}–{{R:387}}（Littlewood–Paley）→ {{R:388}}–{{R:400}}（$H^{p}$・BMO）→ 重み理論と sparse 支配。補間 {{R:339}}–{{R:350}} はすべてに横断的に効く。
確率{{R:451}}–{{R:462}}（独立性）→ {{R:463}}–{{R:475}}（極限定理）→ {{R:476}}–{{R:488}}（CLT）→ 極値理論・数理統計／ {{R:489}}–{{R:501}}（マルチンゲール）→ {{R:502}}–{{R:513}}（Brown 運動）→ {{R:514}}–{{R:526}}（伊藤）→ {{R:527}}–{{R:550}}（SDE・Markov）→ 確率偏微分方程式・幾何と最適輸送／ {{R:551}}–{{R:562}}（大偏差）と {{R:563}}–{{R:575}}（エルゴード）は情報とエントロピーへ合流する。
