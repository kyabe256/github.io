# 数学 1000 大問 ― 複素関数論・関数解析・調和解析・確率論

**定理の主張だけ**を 1000 個並べた問題集。誘導なし、解答なし、準備章なし。全問が名前のついた定理で、難易度は ★★★★☆（272 題）と ★★★★★（728 題）の二段階のみ。A4 で 119 ページ。

`../math-600/` の 600 題をすべて含み、各部に現代的な定理を 100 題ずつ加えた完全版。

| ファイル | 内容 |
| --- | --- |
| `math-1000-problems.pdf` | 本体（PDF） |
| `index.html` | Web 版（KaTeX / Noto Serif JP を CDN から読み込む） |
| `src/*.html` | 素材。数式は `$…$` / `$$…$$` で記述 |
| `assets/style.css` | スタイル |
| `build.js` | 採番・参照解決・目次・索引の生成 → KaTeX でサーバサイド描画 → PDF 化 |

## 構成（通し番号 1–1000、各部 250 題・20 章）

各部の第 1–12 章（150 題）は古典的な幹（`math-600` と同内容）、第 13–20 章（100 題）が現代の枝。

| 部 | 番号 | 第 13–20 章（新規） |
| --- | --- | --- |
| I　複素関数論 | 1–250 | 多変数関数論／$\bar\partial$ 方程式と再生核／擬等角写像／Nevanlinna 理論／解析数論の深層／保型形式の深層／単葉関数と調和測度の深層／超越性と特殊関数 |
| II　関数解析 | 251–500 | 非線形関数解析／凸解析と最適化／作用素環の深層／作用素論の深層／スペクトル理論の深層／Banach 空間論の深層／無限次元の測度と解析／指数理論への入口 |
| III　調和解析 | 501–750 | 振動積分と制限問題／各点収束の深層／解析的整数論の調和解析／非可換調和解析／幾何的測度論と Fourier 次元／非線形分散方程式／重み理論と sparse 支配／離散幾何と多項式法 |

付録 A（分野横断の依存地図）、付録 B（章ごとの参考書対応表）、付録 C（1000 題の定理名索引・2 段組）。

## 使用許可のルール

> 番号 *n* の問題を解くとき、1…*n*−1 のすべての結果、各分野の学部標準の基礎事実、そして問題文中で大問番号を明示して引用された結果（番号の前後を問わない）は自由に使ってよい。

三つめは、各部の後半が他の部の古典的な結果を必要とするための例外。引用に循環はない。

## 素材の書き方（採番は自動）

番号は手で書かない。`build.js` が次のトークンを処理する。

| トークン | 意味 |
| --- | --- |
| `{{H:label}}` | 大問の見出し。出現順に 1, 2, … と採番。`label` は参照用の名前（`math-600` 由来の問題は旧番号、新規の問題は `+`＝無名、または `smirnov` などの名前） |
| `{{R:label}}` | 見出し `label` の大問番号に置換（未定義ならビルド失敗） |
| `{{RANGE}}` | 章見出し内。その章の番号範囲 |
| `<!--TOC-->`, `<!--INDEX-->` | 目次・定理名索引を生成 |
| `{{STAT:TOTAL|S4|S5|LATIN|OTHER}}` | 総数・★ごとの題数・索引の欧文/和文の題数 |

問題を足しても削っても、番号・相互参照・章範囲・目次・索引・統計はすべて追従する。

```sh
mkdir -p build/vendor/files
cp node_modules/@fontsource/noto-serif-jp/japanese-{400,700}.css build/vendor/
cp node_modules/@fontsource/noto-serif-jp/files/noto-serif-jp-japanese-{400,700}-normal.woff2 build/vendor/files/
cp -r node_modules/katex/dist/katex.min.css node_modules/katex/dist/fonts build/vendor/

MODULES=$PWD/node_modules OUT_DIR=$PWD/build CHROME=/path/to/chrome node build.js
```
