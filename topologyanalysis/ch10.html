第I部　位相空間の基礎

第10章商空間と等化写像

← 第9章　部分空間と相対位相 第11章　積空間——なぜ箱位相ではないのか →

この章の問い

  • 「貼り合わせる」という操作に、どう位相を入れるのか。
  • 商空間からの写像の連続性は、どうやって確かめるのか。
  • 良い空間を割ったのに、悪い空間が出てくるのはなぜか。

貼り合わせを位相で表す

紙テープの両端をつなぐと輪になる。これを数学の言葉にしたい。区間 [0,1] の 0 と 1 を同一視すれば円になる——集合としてはそのとおりである。では位相はどうか。

第2章で、同値関係による商集合 X/{\sim} を作った。いま X が位相空間なら、商集合にも位相を入れたい。方針は第8章の終位相である。商写像 q \colon X \to X/{\sim} が連続になるような、最大の位相を選ぶ。

商位相

X を位相空間、\sim を X 上の同値関係、q \colon X \to Y = X/{\sim} を自然な全射とする。

\mathcal{T}_Y = \{\, V \subseteq Y \mid q^{-1}(V) \text{ が } X \text{ で開} \,\}

は Y 上の位相であり、商位相という。このとき q を商写像という。

逆像が合併と交叉を保つ（第2章）から、（T1）（T2）（T3）はただちに従う。終位相の構成が、位相の公理を逆像経由でそのまま引き継いでいる。

最大性を示す。q が連続な位相 \mathcal{T}' があれば、V \in \mathcal{T}' について q^{-1}(V) は開だから V \in \mathcal{T}_Y。よって \mathcal{T}' \subseteq \mathcal{T}_Y。

部分空間が「最小」で商空間が「最大」なのは、矢印の向きが逆だからである。包含写像は部分から全体へ、商写像は全体から商へ向かう。連続性はつねに「逆像が開」なので、写像の向きが逆になれば最適化の向きも逆になる。

商位相のもっとも重要な性質は、そこからの写像の連続性判定である。

商空間の普遍性

q \colon X \to Y を商写像とする。写像 g \colon Y \to Z について、

g \text{ が連続} \iff g \circ q \text{ が連続}

が成り立つ。とくに、f \colon X \to Z が連続で、x \sim x' ならば f(x) = f(x') を満たすならば、f = g \circ q となる連続な g がただ一つ存在する。

g が連続なら合成も連続。逆に g \circ q が連続とする。W \subseteq Z を開とすると (g \circ q)^{-1}(W) = q^{-1}(g^{-1}(W)) が X で開である。商位相の定義がまさに「逆像が開なら開」だから、g^{-1}(W) は Y で開である。

後半を示す。条件より f は同値類の上で一定だから、g([x]) = f(x) は矛盾なく定まる。g \circ q = f が連続だから、前半より g は連続である。一意性は q が全射であることによる。

この定理が、商空間を実際に使うときのほぼすべてである。商空間からの写像を作るには、もとの空間からの写像を作って「同値な点を同じ所へ送る」ことを確かめればよい。商空間の開集合を直接調べる必要はない。

具体的な貼り合わせ

円・トーラス・メビウスの帯

円。[0,1] で 0 \sim 1 とすると、商空間は S^1 と同相である。実際 f(t) = (\cos 2\pi t, \sin 2\pi t) は連続で f(0) = f(1) だから、 より連続な g \colon [0,1]/{\sim} \to S^1 が誘導される。g は全単射であり、定義域がコンパクトで値域がハウスドルフだから同相である（第20章）。

トーラス。正方形 [0,1]^2 で (t,0) \sim (t,1) かつ (0,s) \sim (1,s) とすると、商空間は S^1 \times S^1 と同相になる。向かい合う辺を同じ向きに貼る。

メビウスの帯。同じ正方形で (0,s) \sim (1, 1-s) だけを課すと、メビウス Möbius の帯が得られる。貼る向きを反転させるだけで、まったく違う空間になる。貼り合わせの指定が位相を決めていることが、この対比でよく分かる。

商はハウスドルフ性を保たない

X = \mathbb{R} で、x \sim y \iff x - y \in \mathbb{Q} と定める。商空間 \mathbb{R}/\mathbb{Q} はどうなるか。

各同値類は \mathbb{R} のなかで稠密である。したがって、q^{-1}(V) が開で空でなければ、それは稠密な集合を含む開集合であり、その補集合に開集合が入る余地がほとんどない。実際、空でない開集合 V, W \subseteq \mathbb{R}/\mathbb{Q} を取ると、q^{-1}(V) と q^{-1}(W) はともに \mathbb{Q}-不変な空でない開集合であり、必ず交わる。

よって \mathbb{R}/\mathbb{Q} は密着位相をもつ。\mathbb{R} は距離空間で、ハウスドルフどころか正規で完全正規である。それを割った結果、二点すら分離できない空間になった。

壊れ方の軽い例もある。\mathbb{R} で x \sim y を「x = y、または x と y がともに (0,1) に属する」と定める。同値類 (0,1) は \mathbb{R} で閉でないから、その像は商空間で閉でない。すなわち商空間は T_1 ですらない（第13章）。同値類が閉であることは、商がハウスドルフになるための必要条件である。

飽和集合と、開商写像

商位相の定義には q^{-1}(V) が現れる。この形の集合を直接扱うと便利である。

A \subseteq X が飽和であるとは、A = q^{-1}(q(A)) となることをいう。すなわち、A が A と交わる同値類をすべて丸ごと含むことをいう。

商位相は「飽和な開集合の像が開」と言い換えられる。商写像は、飽和でない開集合の像については何も保証しない。これが商写像が一般に開写像でない理由である。

商写像 q が開写像であるための必要十分条件は、どの開集合 U についても q^{-1}(q(U)) が開であることである。

q(U) が開 \iff q^{-1}(q(U)) が開、というのが商位相の定義そのものである。言い換えただけだが、後者は X のなかの条件なので確かめやすい。

群作用による商では、この条件が自動的に満たされる。G が X に同相写像として作用しているとき、q^{-1}(q(U)) = \bigcup_{g \in G} gU は開集合の合併だから開である。群による商写像は必ず開写像である。

商がハウスドルフになる条件

商がハウスドルフ性を壊すことは反例で見た。では、いつ壊れないのか。条件を見つけておくと、実際の構成で役に立つ。

必要条件。Y = X/{\sim} がハウスドルフなら、一点集合は閉である。q は連続だから q^{-1}(\{[x]\}) = [x] は X で閉である。したがって、すべての同値類が閉でなければならない。 の第二の例が壊れたのは、この段階である。

十分条件。q が開写像であるとき、次が成り立つ。

Y \text{ がハウスドルフ} \iff R = \{\, (x,y) \mid x \sim y \,\} \text{ が } X \times X \text{ の閉集合}

証明の骨子はこうである。R が閉なら、[x] \ne [y] のとき (x,y) \notin R なので、U \times V が R と交わらないような近傍が取れる。q が開写像だから q(U), q(V) は開であり、これが [x], [y] を分離する。逆向きは、R = (q \times q)^{-1}(\Delta_Y) と、ハウスドルフ性が対角線の閉性と同値であること（第13章）による。

使いどころ。群 G が X に作用しているとき、商 X/G がハウスドルフになる条件は「作用が固有である」ことで与えられる。先に見たとおり群作用の商写像は開写像なので、上の判定が使える。\mathbb{R}/\mathbb{Z} が円になるのは \mathbb{Z} の作用が固有だからであり、\mathbb{R}/\mathbb{Q} が潰れるのは \mathbb{Q} の作用が固有でないからである。

閉写像の場合。q が閉写像であるときにも、似た判定がある。コンパクトハウスドルフ空間の商がハウスドルフになる条件は、同値関係が閉集合であることと同値である。この場合、商は再びコンパクトハウスドルフになり、したがって正規である（第20章）。CW複体の構成が破綻なく進むのは、この事実に支えられている。

まとめると。商を取るときに確かめるべきは、次の三点である。同値類が閉であるか。商写像が開写像か閉写像か。同値関係が積空間の閉集合か。三つとも満たされれば、良い空間の商は良い空間である。

商は積と可換でない

位相空間の構成には、部分・積・商・和の四つがある。これらは互いに可換だろうか。答えは「たいてい可換だが、商と積は違う」である。

問題の所在。q \colon X \to Y を商写像、Z を任意の空間とする。

q \times \mathrm{id}_Z \colon X \times Z \to Y \times Z

は商写像か。一般には違う。連続な全射ではあり、商位相より弱い位相を与えるが、一致するとは限らない。

反例の構造。ドウディ Dowker による古典的な例がある。X = \mathbb{Q} から、整数全体を一点に潰した商を Y とし、Z = \mathbb{Q} とすると、q \times \mathrm{id} は商写像にならない。原因は、積を取ったときに「対角線方向の近づき方」が新たに生じることにある。一点に潰された像のまわりで、二つの座標が連動して近づく道筋を、商位相が捉えきれない。

いつ可換になるか。ホワイトヘッド Whitehead の定理が答えを与える。Z が局所コンパクトハウスドルフならば、q \times \mathrm{id}_Z は商写像である。

証明の鍵は、局所コンパクト性が「点のまわりにコンパクトな近傍が取れる」ことを保証する点にある。コンパクト性のおかげで、対角線方向の近づき方を有限個の場合に還元できる。第22章で局所コンパクト性を扱うとき、この定理に戻る。

なぜこれが困るのか。第8章の★★★で述べた \mathbf{Top} のデカルト閉性の不足と、これは同じ現象である。実際、

\text{積が商を保つ} \iff \text{関数空間の随伴が働く}

という関係がある。どちらの不便も、局所コンパクト性を仮定すると消える。そしてどちらも、コンパクト生成空間の圏に移れば一般に解決する。

代数的位相幾何学での帰結。ホモトピー論では、商と積を自由に交換したい場面が絶えず出てくる。商空間の族を積で貼り合わせ、さらに商を取るといった構成が日常的だからである。コンパクト生成空間の圏が標準になったのは、この交換可能性を保証するためである。

本書は解析学へ向かうので、この方向には進まない。だが「良い構成をしたつもりが、細部で破綻する」という経験は、位相空間という枠組みの限界を知るうえで有用である。第11章で積位相を扱うとき、同種の慎重さが別の形で必要になる。

演習

基本
  1. [0,1] で 0 \sim 1 とした商空間が S^1 と同相であることを、 を使って示せ。
  2. 商写像が必ずしも開写像でない例を挙げよ。
  3. 飽和集合の合併・交叉・補集合が再び飽和であることを示せ。
  4. \mathbb{R}/\mathbb{Z} が円と同相であることを示せ。
証明
  1. 群 G が同相写像として作用するとき、商写像が開写像であることを示せ。（10点）
  2. において \mathbb{R}/\mathbb{Q} が密着位相をもつことを、飽和な開集合の性質から示せ。（20点）
  3. 商写像 q が開写像のとき、商がハウスドルフであることと、同値関係が X \times X で閉であることが同値であることを示せ。（25点）

  1. メビウスの帯が向きづけ不可能であることを、位相的な言葉で述べ、トーラスとの違いを説明せよ。（25点）
  2. コンパクトハウスドルフ空間の商がハウスドルフになる条件を述べ、そのとき商が正規になることを示せ。（30点）
