第VII部　測度と積分

第52章外測度とCarathéodoryの構成

← 第51章　Riemann積分の限界 第53章　Lebesgue測度と非可測集合 →

この章の問い

  • 「大きさ」に何を要求すればよいのか。
  • 外測度から測度へ、どうやって渡るのか。
  • カラテオドリの条件は、なぜあの形なのか。

測度に何を要求するか

区間でない集合に「長さ」を与えたい。どんな性質を要求すべきか。

四つの要求

非負性　\mu(A) \ge 0、\mu(\varnothing)=0。

単調性　A \subseteq B \implies \mu(A) \le \mu(B)。

可算加法性　互いに交わらない A_1,A_2,\ldots について \mu\big(\bigsqcup_n A_n\big) = \sum_n \mu(A_n)。

区間との整合　\mu([a,b]) = b-a。

この四つを、\mathbb{R} のすべての部分集合について同時に満たすことはできない。第53章で見る（バナッハ–タルスキの状況と同じ）。だから「測れる集合」を選ぶ必要がある。

なぜ可算加法性なのか

有限加法性だけなら、\mathbb{R} のすべての部分集合に長さを与えることができる（バナッハ）。それでは足りない。

可算加法性がないと、極限と積分の交換ができない。第55章の収束定理は、可算加法性の言い換えとして出てくる。

逆に、非可算加法性は要求できない。[0,1] = \bigsqcup_{x \in [0,1]}\{x\} で右辺の測度の和は 0 になってしまう。

外測度

外測度

集合 X 上の関数 \mu^* \colon \mathcal{P}(X) \to [0,\infty] が外測度であるとは、

（1）\mu^*(\varnothing)=0。
（2）A \subseteq B \implies \mu^*(A) \le \mu^*(B)（単調性）。
（3）\mu^*\big(\bigcup_n A_n\big) \le \sum_n \mu^*(A_n)（劣加法性）。

外測度はすべての部分集合に定まる。代わりに、加法性が不等式にゆるめられている。

方針はこうである。まず全部の集合に外測度を与え、そのうち加法性が等式で成り立つものだけを選び出す。

ルベーグ外測度

\mathbb{R} 上で

\lambda^*(A) = \inf\Big\{\, \sum_k |I_k| \ \Big|\ A \subseteq \bigcup_k I_k,\ I_k \text{ は開区間} \,\Big\}

と定める。これが外測度であることは、（1）（2）は明らか、（3）は各 A_n の被覆を \varepsilon 2^{-n} の余裕で取って合わせればよい。

の測度零は \lambda^*(N)=0 にあたる。

\lambda^*([a,b]) = b-a。

\le。(a-\varepsilon, b+\varepsilon) で覆えば b-a+2\varepsilon。

\ge。[a,b] \subseteq \bigcup_k I_k とする。コンパクト性（第20章）より有限個で覆える。有限個の開区間で [a,b] を覆うとき、長さの和が b-a 以上であることは、区間の端点を並べる帰納法で示せる。

ここでコンパクト性が本質的に効く。可算個のままでは、直接の帰納法が回らない。

カラテオドリの条件

可測性

\mu^* を外測度とする。E \subseteq X が \mu^*-可測であるとは、すべての A \subseteq X について

\mu^*(A) = \mu^*(A \cap E) + \mu^*(A \setminus E)

が成り立つことをいう。可測集合の全体を \mathcal{M}_{\mu^*} と書く。

なぜこの形なのか

直観はこうである。E が「よい形」なら、どんな集合 A を E で切っても、二つの断片の大きさの和がもとに戻る。

劣加法性から \le はつねに成り立つ。だから条件は実質 \ge だけである。

「すべての A について」という強い要求が、あとで σ-加法族になることを保証する。A を任意に取れることが、可算合併を扱うときの余地になる。

カラテオドリの拡張定理

\mu^* を X 上の外測度とする。

（1）\mathcal{M}_{\mu^*} は σ-加法族である（全体・補集合・可算合併で閉じている）。
（2）\mu = \mu^*|_{\mathcal{M}_{\mu^*}} は \mathcal{M}_{\mu^*} 上で可算加法的である。
（3）\mu^*(N)=0 なら N \in \mathcal{M}_{\mu^*}（完備性）。

（3）。\mu^*(N)=0 とする。\mu^*(A\cap N) \le \mu^*(N) = 0 と \mu^*(A\setminus N)\le \mu^*(A) より和は \mu^*(A) 以下。劣加法性で逆も出る。

（1）補集合。条件が E と X\setminus E について対称なので明らか。\varnothing と X も明らか。

（1）有限合併。E, F \in \mathcal{M} とする。任意の A について

\mu^*(A) = \mu^*(A\cap E) + \mu^*(A\setminus E)

であり、第二項を F で切ると \mu^*(A\setminus E) = \mu^*((A\setminus E)\cap F) + \mu^*(A \setminus (E\cup F))。

一方 A \cap (E\cup F) = (A\cap E) \sqcup ((A\setminus E)\cap F) なので、劣加法性より

\mu^*(A\cap(E\cup F)) \le \mu^*(A\cap E) + \mu^*((A\setminus E)\cap F)

これらを合わせると \mu^*(A) \ge \mu^*(A\cap(E\cup F)) + \mu^*(A\setminus(E\cup F))。逆向きは劣加法性。

（1）可算合併と（2）。E_1,E_2,\ldots \in \mathcal{M} を互いに交わらないとし（一般の場合は差を取って交わらなくできる）、E = \bigsqcup_n E_n とおく。有限合併の場合を繰り返すと、任意の A と各 N について

\mu^*(A) = \sum_{n=1}^{N}\mu^*(A\cap E_n) + \mu^*\Big(A \setminus \bigsqcup_{n\le N}E_n\Big) \ \ge\ \sum_{n=1}^{N}\mu^*(A\cap E_n) + \mu^*(A\setminus E)

（最後は単調性）。N \to \infty として

\mu^*(A) \ge \sum_{n=1}^{\infty}\mu^*(A\cap E_n) + \mu^*(A\setminus E) \ge \mu^*(A\cap E) + \mu^*(A\setminus E)

（最後は劣加法性）。逆向きは劣加法性なので、E \in \mathcal{M} で、かつ上の不等式がすべて等号になる。

A = E と取れば \mu(E) = \sum_n \mu(E_n)、すなわち（2）。可測性が自動的に可算加法性を与える——これがこの定理の要点である。

証明を見ると、「任意の A について」という要求が、最後の一行で A=E と取るために使われている。可測性を強く要求したことが、加法性という利得になって返ってきた。

測度空間

測度空間

集合 X、X 上の σ-加法族 \mathcal{A}、\mathcal{A} 上の可算加法的な非負関数 \mu（\mu(\varnothing)=0）の三つ組 (X,\mathcal{A},\mu) を測度空間という。

\mu(X) < \infty のとき有限、\mu(X)=1 のとき確率空間、X が可測な有限測度集合の可算合併のとき \sigma-有限という。

測度の連続性

(X,\mathcal{A},\mu) を測度空間とする。

（1）A_1 \subseteq A_2 \subseteq \cdots なら \mu\big(\bigcup_n A_n\big) = \lim_n \mu(A_n)。
（2）A_1 \supseteq A_2 \supseteq \cdots かつ \mu(A_1)<\infty なら \mu\big(\bigcap_n A_n\big) = \lim_n \mu(A_n)。

（1）B_1 = A_1、B_n = A_n \setminus A_{n-1} とおくと互いに交わらず \bigcup_n A_n = \bigsqcup_n B_n、A_N = \bigsqcup_{n \le N}B_n。可算加法性から従う。

（2）A_1 \setminus A_n が増加列なので（1）を使う。\mu(A_1)<\infty は引き算をするために要る。

有限性を外すと（2）が壊れる

A_n = [n,\infty) とすると \bigcap_n A_n = \varnothing で測度 0 だが、各 \lambda(A_n)=\infty。

減少列については、有限性の仮定が外せない。第55章のファトゥの補題と優収束定理で、同じ形の注意が繰り返される。

前測度からの拡張と、一意性

は外測度から始めた。実際には、もっと少ない情報から出発できる。

前測度。X 上の集合の族 \mathcal{E}（有限加法族でよい）と、その上の有限加法的で可算加法的な \mu_0 を前測度という。\mathbb{R} では \mathcal{E} を「有限個の区間の合併」、\mu_0 を長さの和に取る。

誘導される外測度。

\mu^*(A) = \inf\Big\{\, \sum_n \mu_0(E_n)\ \Big|\ A \subseteq \bigcup_n E_n,\ E_n \in \mathcal{E} \,\Big\}

これは外測度であり、\mathcal{E} の元はすべて可測で、\mu^*|_{\mathcal{E}} = \mu_0。証明は と同じ形で、有限加法性から出る。

結果として \mathcal{E} の生成する σ-加法族の上に、\mu_0 を延ばした測度が得られる。

一意性。\mu_0 が σ-有限なら、この拡張は \sigma(\mathcal{E}) 上で一意である。

証明にはディンキンの補題（π-λ 定理）を使う。二つの拡張が一致する集合の全体が λ 系をなし、\mathcal{E} を含むので \sigma(\mathcal{E}) 全体になる。

σ-有限性が要る。外すと一意性が崩れる。\mathcal{E} を \mathbb{R} 上の可算集合と補集合が可算な集合の族に取り、\mu_0 = 0 と \mu_0 = \infty（空でない集合に）で拡張が二通りできる。

完備化。（3）より、カラテオドリの構成で得られる測度はつねに完備である。一方、\sigma(\mathcal{E}) に制限すると完備でないことがある。

\mathbb{R} では、ボレル集合族 \mathcal{B} 上のルベーグ測度は完備でなく、カラテオドリの構成で得られる \mathcal{M} がその完備化である。|\mathcal{B}| = 2^{\aleph_0} だが |\mathcal{M}| = 2^{2^{\aleph_0}}——カントール集合の部分集合がすべて可測だからである（第53章）。

使い分け。ボレル集合族は、位相から決まるので写像による扱いがよい（連続写像の逆像がボレル）。ルベーグ可測集合族は、完備なので「ほとんどいたるところ」の議論に強い。第54章で両方を使う。

測度の存在と、位相との関係

ハール測度。局所コンパクト群 G には、左移動で不変な測度（ハール測度）が定数倍を除いて一意に存在する。\mathbb{R} のルベーグ測度は、その加法群としての場合である。

存在証明は第20章のコンパクト性と、第21章のチコノフの定理を使う。位相群の構造から測度が生まれる。

ラドン測度。局所コンパクトハウスドルフ空間 X 上で、コンパクト集合で有限、内部正則かつ外部正則な測度をラドン測度という。第59章のリースの表現定理が、C_c(X) 上の正線型汎関数とラドン測度を一対一に対応させる。

どの位相空間に測度が乗るか。ボレル集合族はどの位相空間にも定まるが、そこに「よい」測度が乗るかは空間の性質に依る。

ポーランド空間（可分完備距離空間、第33章）では事情がとてもよい。ボレル確率測度の全体が、それ自身ポーランド空間になる（弱位相について）。これが確率論の標準的な舞台である。

測度の非存在。逆に、測度が存在しないこともある。

可測基数の問題。「\kappa 上のすべての部分集合に定まり、一点の測度が 0 で、\kappa-加法的な確率測度が存在するか」——そのような \kappa を可測基数という。

可測基数の存在は、集合論の公理系から証明できない（強到達不可能基数より強い）。第4章・第36章で見た独立性の構図が、測度論にも現れる。

実数値可測基数。2^{\aleph_0} が実数値可測であること（すなわち \mathbb{R} のすべての部分集合に可算加法的な拡張測度が存在すること）は、可測基数の存在と同等の強さをもつ。

したがって「ルベーグ測度をすべての集合に延ばせるか」という素朴な問いの答えは、選択公理のもとでは否（第53章）、選択公理を落としても巨大基数の存在と結びつくという形になる。

ソロヴェイのモデル。一九七〇年、ソロヴェイは「到達不可能基数が存在すれば、選択公理を従属選択公理に弱めた体系で、すべての集合がルベーグ可測なモデルが作れる」ことを示した。

そこでは解析の大半が成り立つ。非可測集合は、選択公理が作り出すものである。第53章で、その作り方を見る。
