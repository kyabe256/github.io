第XI部　フーリエ解析

第87章Schwartz空間と超関数

← 第86章　畳み込みと近似単位元 第88章　超関数のFourier変換とSobolev空間 →

この章の問い

  • 微分できない関数を、どうやって微分するのか。
  • デルタ関数は、何なのか。
  • なぜ「なめらかで急減少な関数」の空間が要るのか。

微分を双対に移す

第84章と第85章で、フーリエ変換が定義できない対象が残った——定数関数、多項式、平面波、ディラック測度。共通しているのは「積分が収束しない」ことである。

解決の着想は、関数を「値の割り当て」ではなく「積分による汎関数」と見ることである。f のかわりに

\varphi \ \longmapsto \ \int f\varphi\,dx

という汎関数を考える。この見方では、f 自身が可積分でなくても、\varphi が十分よい関数なら積分が収束しうる。そして微分は部分積分で \varphi の側に移せる——

\int f'\varphi = -\int f\varphi'

右辺は f の微分可能性を要求しない。ここに、微分できない対象を微分する道が開ける。

シュワルツ空間

\varphi\in C^\infty(\mathbb{R}^d) が、任意の多重指数 \alpha,\beta について

\|\varphi\|_{\alpha,\beta} = \sup_{x\in\mathbb{R}^d}\big|x^\alpha\partial^\beta\varphi(x)\big| < \infty

をみたすとき急減少関数といい、その全体を \mathcal{S}(\mathbb{R}^d)（シュワルツ空間）と書く。可算個の半ノルム \|\cdot\|_{\alpha,\beta} が定める位相を入れると、\mathcal{S} はフレシェ空間（完備な距離化可能局所凸空間）になる。

例：e^{-|x|^2}、C_c^\infty の元。例でないもの：e^{-|x|}（原点で滑らかでない）、(1+|x|^2)^{-N}（多項式減衰では足りない）。

シュワルツ空間はフーリエ変換で不変

\mathcal{F}:\mathcal{S}(\mathbb{R}^d)\to\mathcal{S}(\mathbb{R}^d) は連続な線形同型であり、逆写像は反転公式で与えられる。さらに

\widehat{\partial^\beta\varphi}(\xi) = (i\xi)^\beta\hat\varphi(\xi), \qquad \widehat{x^\alpha\varphi}(\xi) = (i\partial_\xi)^\alpha\hat\varphi(\xi)

\varphi\in\mathcal{S} なら \varphi\in L^1（急減少だから）で、（6）の二つの式が任意の階数で使える。二式を組み合わせると

\xi^\alpha\partial_\xi^\beta\hat\varphi(\xi) = c\,\widehat{\partial^\alpha(x^\beta\varphi)}(\xi)

の形になり、右辺は \partial^\alpha(x^\beta\varphi)\in\mathcal{S}\subset L^1 の変換だから有界（（1））。すなわち \hat\varphi のすべての半ノルムが有限で、\hat\varphi\in\mathcal{S}。連続性も同じ評価から出る。

\hat\varphi\in L^1 なので反転公式（（1））が使えて \mathcal{F}^{-1}\mathcal{F}=\mathrm{id}。逆変換も同じ議論で \mathcal{S} を \mathcal{S} に写すから、\mathcal{F} は同型である。

「微分と多項式倍を入れ替える」という性質そのものが、この空間を不変にする。シュワルツ空間は、そのために作られた空間である。

超関数

緩増加超関数

\mathcal{S}(\mathbb{R}^d) 上の連続線形汎関数の全体を \mathcal{S}'(\mathbb{R}^d) と書き、その元を緩増加超関数という。u\in\mathcal{S}' と \varphi\in\mathcal{S} の対を \langle u,\varphi\rangle と書く。

連続性は、ある有限個の半ノルムで |\langle u,\varphi\rangle|\le C\sum\|\varphi\|_{\alpha_j,\beta_j} と押さえられることと同値である。

同様に、C_c^\infty(\Omega) 上の連続線形汎関数の全体を \mathcal{D}'(\Omega)（超関数）と書く。\mathcal{S}'\subset\mathcal{D}' である。

超関数の演算

u\in\mathcal{S}' について、次を定義とする（いずれも「よい場合に成り立つ等式」をそのまま定義に採用している）。

（1）微分：\langle\partial^\alpha u,\varphi\rangle = (-1)^{|\alpha|}\langle u,\partial^\alpha\varphi\rangle。
（2）フーリエ変換：\langle\hat u,\varphi\rangle = \langle u,\hat\varphi\rangle。
（3）滑らかな関数との積：a が多項式増大の C^\infty 関数なら \langle au,\varphi\rangle=\langle u,a\varphi\rangle。
（4）急減少関数との畳み込み：\langle u*\psi,\varphi\rangle=\langle u,\tilde\psi*\varphi\rangle（\tilde\psi(x)=\psi(-x)）。
（5）平行移動・拡大縮小：同様に双対で定める。

（1）（2）により、すべての緩増加超関数は無限回微分可能で、フーリエ変換をもつ。定義できないことが原理的に起こらない枠組みになっている。

超関数の見本

（1）局所可積分関数。f が多項式増大の L^1_{\mathrm{loc}} 関数なら \langle f,\varphi\rangle=\int f\varphi で \mathcal{S}' の元。この対応は単射である（二つの L^1_{\mathrm{loc}} 関数が同じ超関数を定めれば、ほとんどいたるところ一致する）。L^p（すべての p）、有限測度、多項式はすべて \mathcal{S}' に入る。

（2）ディラックのデルタ。\langle\delta,\varphi\rangle=\varphi(0)。これは関数ではない——\int f\varphi=\varphi(0) をみたす L^1_{\mathrm{loc}} 関数 f は存在しない。フーリエ変換は

\langle\hat\delta,\varphi\rangle = \langle\delta,\hat\varphi\rangle = \hat\varphi(0) = \int\varphi(x)\,dx = \langle 1,\varphi\rangle

すなわち \hat\delta=1。逆に \hat1=(2\pi)^d\delta。第85章で「定義できない」とした変換が、ここでは一行の計算になる。

（3）ヘヴィサイド関数の微分。H=\chi_{[0,\infty)} について \langle H',\varphi\rangle=-\int_0^\infty\varphi'=\varphi(0)、すなわち H'=\delta。跳びの微分がデルタである。

（4）主値。1/x は L^1_{\mathrm{loc}} でないが、

\Big\langle \mathrm{p.v.}\frac1x,\varphi\Big\rangle = \lim_{\varepsilon\downarrow0}\int_{|x|>\varepsilon}\frac{\varphi(x)}{x}\,dx = \int_0^\infty\frac{\varphi(x)-\varphi(-x)}{x}\,dx

右辺は \varphi の滑らかさから収束する。フーリエ変換は -i\pi\,\mathrm{sgn}(\xi) で、これがヒルベルト変換の乗子である（第81章★★）。

（5）層と曲面上の測度。球面上の面積測度 \sigma は \mathcal{S}' の元で、\hat\sigma(\xi)=c_d|\xi|^{-(d-2)/2}J_{(d-2)/2}(|\xi|)（ベッセル関数）。これが波動方程式の基本解と、第85章★★★の制限定理の出発点である。

（6）基本解。-\Delta E=\delta をみたす E は、d\ge3 で E(x)=c_d|x|^{2-d}、d=2 で -\frac{1}{2\pi}\log|x|。ニュートンポテンシャル・クーロンポテンシャルが、超関数の方程式の解として特徴づけられる。

何ができて、何ができないか

できること。任意回の微分、フーリエ変換、滑らかな関数との積、急減少関数との畳み込み、平行移動・拡大縮小、極限（弱位相での収束）。

できないこと。超関数どうしの積である。\delta^2 に意味を与えることはできない。シュヴァルツの不可能性定理：微分と両立し、連続関数の上で通常の積に一致する結合的な積は、超関数の空間には存在しない。

この制約が、非線形偏微分方程式の理論が難しい根本的な理由である。方程式 \partial_tu+u\partial_xu=0 の u\partial_xu が、u が超関数のときには意味をもたない。回避策は（i）解の滑らかさを確保してから積を定義する（ソボレフ空間と積の評価、第88章）、（ii）弱解の定義を方程式ごとに工夫する（エントロピー解、粘性解）、（iii）確率論的な繰り込み（ホグの正則性構造、2014年フィールズ賞）。

構造と局所性

超関数の構造定理

（1）台がコンパクトなら有限階の微分。u\in\mathcal{D}' で \mathrm{supp}\,u がコンパクトなら、有限個の連続関数 f_\alpha があって u=\sum_{|\alpha|\le N}\partial^\alpha f_\alpha。
（2）一点に台をもつもの。\mathrm{supp}\,u=\{0\} なら u=\sum_{|\alpha|\le N}c_\alpha\partial^\alpha\delta（有限和）。
（3）正の超関数は測度。\varphi\ge0\Rightarrow\langle u,\varphi\rangle\ge0 なら u は正のラドン測度である（）。
（4）平滑化で近づける。C_c^\infty は \mathcal{S}' で（弱位相について）稠密。すなわちどの超関数も滑らかな関数の極限である。

（2）を示す。\varphi\in C_c^\infty が原点で N 階まですべての導関数が零なら \langle u,\varphi\rangle=0 であることを見ればよい（N は u の連続性から決まる階数）。テイラーの定理から |\partial^\beta\varphi(x)|\le C|x|^{N+1-|\beta|}（|x| 小）。原点のまわりの切り落とし \chi(x/\varepsilon) を掛けて評価すると、u の階数 N の連続性から |\langle u,\chi(\cdot/\varepsilon)\varphi\rangle|\le C\varepsilon\to0。

よって \langle u,\varphi\rangle は \varphi の原点での N 階までの導関数のみに依存する線形汎関数で、有限次元空間上の線形汎関数だから係数の組で書ける——それが \sum c_\alpha\partial^\alpha\delta である。

（4）u*\varphi_\varepsilon（\varphi_\varepsilon は軟化子）は C^\infty で、\varepsilon\downarrow0 のとき u に弱収束する。さらに切り落とせばコンパクト台にできる。「超関数とは、滑らかな関数列の極限である」という素朴な理解が、これで正当化される。

超関数の限界

（1）点での値がない。u\in\mathcal{S}' に u(x_0) という量はない。ただし「u が開集合 U 上で滑らかな関数と一致する」ことは言える（局所性）。台と特異台（u が滑らかでない点の集合）が、この方向の道具である。

（2）積が定義できない。上述。ただし波面集合（位置と方向の両方で特異性を追う）が交わらなければ積を定義できる（ヘルマンダーの理論）。これが線形偏微分方程式の特異性の伝播の理論を生んだ。

（3）合成が定義できない。\delta(f(x)) は f の零点が非退化なら定義できるが、一般には不可能。

（4）緩増加でないと変換できない。e^{x^2} は \mathcal{D}'(\mathbb{R}) の元だが \mathcal{S}' に属さず、フーリエ変換をもたない。\mathcal{S}' という制限は、変換のために必要である。

（5）すべての超関数が「関数の極限」だが、逆は言えない。収束しない列もある。\sin(nx) は \mathcal{S}' で 0 に弱収束するが、\sin^2(nx) は 1/2 に収束する。弱収束は積と両立しない——これが（2）の不可能性の、もう一つの現れである。

★★ 学部後半——台・波面集合・基本解

台と特異台。u\in\mathcal{D}'(\Omega) の台 \mathrm{supp}\,u は、u が近傍で零にならない点の集合。特異台 \mathrm{sing\,supp}\,u は、u が近傍で C^\infty 関数と一致しない点の集合。\delta の台と特異台はどちらも \{0\}。

波面集合。特異性を「どの点で」だけでなく「どの方向で」も記述する。u の波面集合 WF(u)\subset\Omega\times(\mathbb{R}^d\setminus0) は、局所的にフーリエ変換が方向 \xi に沿って急減少しない点 (x,\xi) の集合。波面集合が交わらない二つの超関数は、積が定義できる。ヘルマンダーの定理：線形偏微分作用素 P について、WF(u)\subset WF(Pu)\cup\mathrm{Char}(P)。これが「特異性は特性曲線に沿って伝播する」という物理的な直観の厳密な形である。

基本解と楕円性。定数係数の作用素 P(\partial) について P(\partial)E=\delta をみたす E（基本解）は、マルグランジュ–エーレンプライスの定理により常に存在する。フーリエ変換すれば P(i\xi)\hat E=1 だが、P(i\xi) の零点で割れない。零点を避けて積分路をずらすのが証明の要点で、複素解析（第90章）が本質的に使われる。

作用素が楕円型（P の最高次部分 P_m(\xi) が \xi\ne0 で零にならない）なら、正則性定理：Pu\in C^\infty\Rightarrow u\in C^\infty。ラプラシアンの解が自動的に滑らかであるという事実（第94章）は、この一般論の特別な場合である。双曲型（波動方程式）では特異性が伝播し、放物型（熱方程式）では即座に消える——方程式の型が、特異性の運命を決めている。

仮定を外すと。試験関数を \mathcal{S} より小さい C_c^\infty にすると双対が大きくなり（\mathcal{D}'\supset\mathcal{S}'）、局所的な議論には便利だがフーリエ変換ができない。逆に試験関数を大きくすると（解析的関数など）、双対が小さくなって使いにくい。ジェヴレイ類や佐藤の超局所解析は、この中間の選択を系統的に扱う。

★★★ 大学院——ガウス測度、確率超関数、正則性構造

無限次元のガウス測度。\mathcal{S}'(\mathbb{R}^d) の上には、特性汎関数

\int_{\mathcal{S}'} e^{i\langle u,\varphi\rangle}\,d\mu(u) = e^{-\frac12\|\varphi\|_{H}^2}

をみたす確率測度がただ一つ存在する（ボホナー–ミンロスの定理、ボホナーの定理（第84章★★）の無限次元版）。H=L^2 のとき \mu は白色雑音で、その実現はほとんど確実に関数ではなく超関数である。「確率的な対象が超関数でしかありえない」という事実が、確率偏微分方程式の枠組みを決めている。

ガウス自由場。H=H^1 にとるとガウス自由場が得られ、d=2 ではその等高線が共形場理論と結びつく（シェラム–レフナー発展、シュラムのSLE）。二次元臨界現象の普遍性が、この超関数の共形不変性から説明される。

積の問題の回避。確率偏微分方程式 \partial_tu=\Delta u+u^2+\xi（\xi は時空白色雑音）では、解が超関数なので u^2 に意味がない。ホグの正則性構造の理論（2014年フィールズ賞）は、超関数を「局所的なテイラー展開の一般化」として記述し直し、繰り込みによって積を定義する。同時期にグビネッリ–インベリ–ペリーヌのパラ制御解の理論が別の道から同じ問題を解いた。シュヴァルツの不可能性定理は「単一の普遍的な積は存在しない」と言っているだけで、方程式ごとに意味を与える道は閉ざされていなかった。

佐藤の超局所解析。波面集合の考えを層の言葉に翻訳し、超関数の特異性を余接束の上の層（マイクロ関数の層）として扱う。佐藤–河合–柏原の理論は、線形偏微分方程式の解の構造を代数解析（D 加群）の言葉で記述する。方程式系を加群と見て、その特性多様体の幾何を調べる——解析の問いが、代数幾何の問いに完全に翻訳される。リーマン–ヒルベルト対応（柏原、メビリー）はその頂点の一つで、正則特異な D 加群の圏と構成可能層の圏の同値を述べる。

未解決に近い問い。3 次元ナヴィエ–ストークス方程式の解の一意性・滑らかさは、まさに「弱解の積をどう扱うか」という問題である。弱解の存在はルレイ（1934年）が示したが、一意性は未解決——ブッコマステル–ヴィコルは、より弱い意味の解に対して非一意性を示した（2019年）。積が定義できないという超関数の一つの限界が、九十年間ミレニアム問題として残っている。
