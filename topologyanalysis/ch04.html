序論　数学の文章をどう読むか

第4章順序数と基数

← 第3章　選択公理とその同値物 第5章　なぜ開集合から始めるのか →

この章の問い

  • 「無限番目」という言い方に、意味を与えられるか。
  • 数える順序（順序数）と、大きさ（基数）は、なぜ別の概念なのか。
  • 自然数の次の無限は、実数の個数なのか。

順序数——整列集合を数とみなす

前章で、どの集合も整列できることを見た。整列集合は「一番目、二番目、……」と並べられる集合であり、有限で止まるとは限らない。自然数を全部並べ終えたあとに、もう一つ元を置くことができる。その元は「無限番目」と呼ぶしかない位置にある。

このような位置を数として扱うために、順序数を導入する。順序数とは、整列集合の「並び方の型」を代表する集合である。代表のとり方には一つの巧妙な工夫がある。

集合 \alpha が順序数であるとは、次の二つを満たすことをいう。

（1）\alpha は推移的である。すなわち x \in \alpha ならば x \subseteq \alpha。
（2）関係 \in は \alpha を整列する。

この定義のもとでは、それぞれの順序数は、自分より小さい順序数の全体に等しい。

0 = \varnothing, \quad 1 = \{0\}, \quad 2 = \{0, 1\}, \quad 3 = \{0, 1, 2\}, \ \ldots

自然数をすべて集めたものも、この条件を満たす。これを \omega と書く。

\omega = \{0, 1, 2, 3, \ldots\}

そして \omega のあとが続く。\alpha の次の順序数は \alpha \cup \{\alpha\} であり、これを \alpha + 1 と書く。

\omega + 1, \quad \omega + 2, \quad \ldots, \quad \omega + \omega = \omega \cdot 2, \quad \ldots, \quad \omega^2, \quad \ldots, \quad \omega^\omega, \ \ldots

順序数には二種類ある。\alpha = \beta + 1 と書けるものを後続順序数、0 でも後続でもないものを極限順序数という。\omega と \omega \cdot 2 は極限順序数である。極限順序数には直前の元がない。帰納法の議論で場合分けが必要になるのは、この区別のためである。

順序数の全体は、\in によって整列されている。だが順序数の全体は集合ではない。もし集合なら、それ自身が順序数になり、自分自身の元になってしまう。これをブラリ＝フォルティ Burali-Forti の逆説という。第2章のラッセルの逆説と同じ構造であり、同じ理由で禁じられる。

超限帰納法——帰納法を無限番目まで伸ばす

自然数についての帰納法は「0 で成り立ち、n で成り立てば n+1 でも成り立つ」という形をとる。順序数ではこれに一段加える。

超限帰納法

順序数についての性質 P が次を満たすとする。

（1）P(0) が成り立つ。
（2）P(\alpha) ならば P(\alpha + 1)。
（3）\lambda が極限順序数で、すべての \beta < \lambda について P(\beta) が成り立つならば、P(\lambda)。

このとき、すべての順序数 \alpha について P(\alpha) が成り立つ。

P(\alpha) が成り立たない順序数があったとし、そのようなもの全体を考える。順序数は \in で整列されているから、この族には最小のもの \alpha_0 がある。\alpha_0 = 0 なら（1）に反する。\alpha_0 = \beta + 1 なら、\beta < \alpha_0 より P(\beta) が成り立ち、（2）から P(\alpha_0) が従って矛盾する。\alpha_0 が極限順序数なら、すべての \beta < \alpha_0 で P(\beta) が成り立つので（3）から P(\alpha_0) が従い、やはり矛盾する。三つの場合をすべて尽くしたので、そのような \alpha_0 は存在しない。

超限帰納法の本質は「整列していること」であって、順序数であることではない。整列集合の上でなら、同じ議論がそのまま通る。前章で整列定理を得たのは、まさにこの道具を任意の集合の上で使えるようにするためだった。第3章のツォルンの補題の証明も、ここに戻ってくる。

対応する構成の原理が超限再帰である。「すでに定めた値から次の値を定める規則」を与えると、すべての順序数について値が定まる。帰納法が証明の道具であるのに対し、再帰は定義の道具である。本書では第52章の外測度の構成や、第23章のコンパクト化の構成で使う。

基数——大きさだけを見る

順序数は並び方を区別する。だが大きさだけを見たいときには、区別しすぎる。

並びが違っても大きさは同じ

\omega と \omega + 1 は順序数として異なる。前者には最大元がなく、後者にはある。したがって順序同型ではない。しかし全単射は存在する。\omega + 1 = \{0, 1, 2, \ldots\} \cup \{\omega\} の元を

\omega \mapsto 0, \quad n \mapsto n + 1 \ (n \in \omega)

と対応させれば、\omega との全単射が得られる。並べ替えると型が変わるが、個数は変わらない。

そこで、大きさだけを取り出す。

順序数 \kappa が基数であるとは、\kappa と全単射をもつ順序数のうち最小のものであることをいう。集合 X の濃度 |X| とは、X と全単射をもつ基数のことである。

濃度が定義できるのは整列定理のおかげである。選択公理がなければ、どの集合にも濃度があるとは限らない。有限の順序数はすべて基数であり、\omega も基数である。基数としての \omega を \aleph_0 と書く。\omega + 1 は基数でない。

無限基数は、小さい順に並べることができる。\aleph_0 の次の基数を \aleph_1、その次を \aleph_2 と書き、極限では和をとる。\aleph_1 は「\aleph_0 より大きい最小の基数」であって、何か具体的な集合の濃度として与えられるのではない。この点が次節の問題につながる。

連続体仮説

第2章のカントールの定理により、|\mathbb{R}| = 2^{\aleph_0} > \aleph_0 である。一方 \aleph_1 は \aleph_0 より大きい最小の基数である。したがって \aleph_1 \le 2^{\aleph_0} は確実に成り立つ。では等号が成り立つか。

連続体仮説

2^{\aleph_0} = \aleph_1 であるか。言い換えれば、実数の部分集合であって、可算でも実数全体と同じ濃度でもないものが存在するか。

カントールはこれを肯定と予想し、証明を試みて果たせなかった。結末は一九六三年に出た。連続体仮説は、選択公理を含む集合論の公理系から、証明も反証もできない。ゲーデルが「仮定しても矛盾しない」ことを示し、コーエンが「否定しても矛盾しない」ことを示した。

これは「まだ分かっていない」という意味ではない。公理系が答えを決めていない、という意味である。第1章の★★★で述べた「どの公理系の上で問うているか次第だ」という事態が、ここに実例として現れている。本書では第36章のスーリン Souslin 問題で、この独立性が位相空間の性質としてそのまま姿を現す場面を扱う。

順序数の算術と、基数の算術は別物である

順序数にも基数にも和と積が定義される。記号は似ているが、振る舞いはまったく違う。混同すると議論が崩れるので、ここで整理しておく。

順序数の和。\alpha + \beta は、\alpha の後ろに \beta を並べた整列集合の型と定める。この定義から直ちに次が出る。

1 + \omega = \omega, \qquad \omega + 1 \ne \omega

1 + \omega は「一つ置いてから自然数を並べる」ことであり、全体として自然数の並びと同型である。\omega + 1 は「自然数を並べてから一つ置く」ことで、最大元ができてしまう。順序数の和は可換でない。

順序数の積。\alpha \cdot \beta は、\beta の各点を \alpha で置き換えたものと定める。こちらも可換でない。

2 \cdot \omega = \omega, \qquad \omega \cdot 2 = \omega + \omega \ne \omega

書き順によって意味が変わるので、教科書ごとに約束が違うことがある。本書は上の約束を使う。

基数の算術。基数 \kappa, \lambda に対して、\kappa + \lambda は交わらない集合の合併の濃度、\kappa \cdot \lambda は直積の濃度と定める。こちらは可換であり、しかも無限では劇的に単純になる。

\kappa + \lambda = \kappa \cdot \lambda = \max(\kappa, \lambda) \quad (\kappa, \lambda \text{ のいずれかが無限})

この等式は選択公理を使う。無限基数の和と積は情報を失う——だから濃度の議論で本当に効くのは冪だけである。

冪だけが難しい。\kappa^\lambda は \lambda から \kappa への写像全体の濃度と定める。カントールの定理は 2^\kappa > \kappa を述べている。ではどれだけ大きいのか。ここが公理から決まらない部分である。

共終数。基数 \kappa の共終数 \mathrm{cf}(\kappa) とは、\kappa に共終な部分集合の最小の濃度をいう。\mathrm{cf}(\aleph_0) = \aleph_0、\mathrm{cf}(\aleph_1) = \aleph_1 だが、\mathrm{cf}(\aleph_\omega) = \aleph_0 である。ケーニヒ König の定理により

\mathrm{cf}(2^{\aleph_0}) > \aleph_0

が成り立つので、2^{\aleph_0} = \aleph_\omega であることはありえない。公理から決まらないとはいえ、何でもよいわけではない。共終数の制約が、決まらない範囲に枠をはめている。この概念は第35章の基数不変量で再登場する。

決まらないことが、位相空間の性質として現れる

連続体仮説の独立性は、集合論の内輪の話に見えるかもしれない。だが本書の後半で、それが空間の性質として表に出る場面がある。

スーリン問題。実数直線は、次の性質で特徴づけられる。稠密で、端点がなく、連結で、そして可分（可算な稠密部分集合をもつ）である。ここで可分を可算鎖条件——互いに交わらない空でない開集合の族は必ず可算——に置き換えたら、同じ特徴づけになるか。

可分ならば可算鎖条件が従うので、問いは「逆が言えるか」である。この問いの答えは、集合論の公理系から決まらない。反例となる空間をスーリン直線という。マーティン Martin の公理と連続体仮説の否定を仮定すればスーリン直線は存在せず、構成可能性公理を仮定すれば存在する。第36章で詳しく扱う。

基数不変量の比較。第35章で導入する weight、density、cellularity、character といった基数不変量のあいだの大小関係にも、独立な命題が多数現れる。「この不変量はあの不変量より必ず小さいか」という素朴な問いが、公理系に依存する。実数直線の部分集合をめぐる一連の基数（いわゆる小さい基数）の相互関係は、それ自体が一つの研究分野をなしている。

次元論との関わり。第38章から第42章で扱う三つの次元 \mathrm{ind}、\mathrm{Ind}、\mathrm{dim} は、可分距離空間では一致する。一般の空間では一致せず、一致しない例の構成に集合論的な仮定が必要になることがある。次元が「空間の素朴な性質」ではなく、どの公理系で見ているかに依存しうるという事実は、第42章の主題の一つである。

解析学ではどうか。解析学の主要な定理は、連続体仮説に依存しない。可測性、完備性、コンパクト性といった概念が、可算的な操作で閉じているからである。ただし境界に触れる例はある。第53章で扱う非可測集合の存在は選択公理に依存し、ルベーグ測度の拡張可能性——すべての部分集合に定義された可算加法的測度があるか——は可測基数という大きい基数の存在と結びつく。

本書の扱い方。独立な命題に出会ったとき、本書は「未解決」とは書かない。未解決と独立は別である。未解決とは答えがまだ見つかっていないこと、独立とは公理系が答えを持たないことである。前者は努力で解決しうるが、後者は公理を足さないかぎり解決しない。どちらであるかを明記することが、この本が守る方針の一つである。
