第VIII部　関数空間

第62章稠密性と近似

← 第61章　完備性——Riesz–Fischerの定理 第63章　Banach空間 →

この章の問い

  • なぜ「稠密な部分集合で示せば十分」なのか。
  • Lᵖ のなかで、どんな関数が稠密なのか。
  • 近似の道具は、どこから来るのか。

稠密性という論法

三/ε の論法

D が L^p で稠密、T が有界線型作用素とする。「D の上で成り立つ評価は、L^p 全体に延びる」。

実際、f\in L^p、\varepsilon>0 に対し \|f-g\|_p<\varepsilon なる g\in D を取れば

\|Tf\| \le \|T(f-g)\| + \|Tg\| \le \|T\|\varepsilon + \|Tg\|

第47章の「三分割の議論」と同じ形である。有界性が「誤差を誤差のまま運ぶ」ことを保証している。

したがって定理を証明するときは、扱いやすい関数の族で示せばよい。これが第VIII部以降の標準的な戦略になる。

何が稠密か

単関数の稠密性

1\le p<\infty のとき、\mu-可測な集合の有限一次結合（単関数）で、台の測度が有限なものの全体は L^p(\mu) で稠密である。

f\ge0 としてよい。 より単関数の増加列 s_n\uparrow f が取れる。

|f-s_n|^p \le f^p \in L^1 が優関数なので、優収束定理より \|f-s_n\|_p\to0。

s_n\le f と f\in L^p から、s_n の台のうち値が正の部分は有限測度である（チェビシェフの不等式）。

連続関数の稠密性

X を局所コンパクトハウスドルフ空間、\mu をラドン測度とする。1\le p<\infty のとき C_c(X) は L^p(\mu) で稠密である。

より \mathbf{1}_E（\mu(E)<\infty）を近似すれば十分。

正則性を使う。\mu がラドン測度なので、K\subseteq E\subseteq U（K コンパクト、U 開）で \mu(U\setminus K)<\varepsilon なるものが取れる。

ウリゾーンの補題を使う。局所コンパクトハウスドルフ空間では、K\prec h\prec U（h\in C_c、0\le h\le1、h=1 on K、\mathrm{supp}\,h\subseteq U）なる h が存在する（第15章・第22章）。

|\mathbf{1}_E-h|\le\mathbf{1}_{U\setminus K} なので \|\mathbf{1}_E-h\|_p \le \mu(U\setminus K)^{1/p}<\varepsilon^{1/p}。

測度の正則性と、位相の分離公理（ウリゾーン）が、ここで噛み合う。

第II部で分離公理を扱い、第VII部で正則性を測度の条件として立てたのは、この一点のためだったといってよい。

p=\infty では成り立たない。C_c の L^\infty での閉包は C_0(X) であって、L^\infty 全体ではない。\mathbf{1}_{[0,1]} は、どの連続関数からも L^\infty 距離 1/2 以上離れている。

滑らかな関数の稠密性

1\le p<\infty のとき、C_c^\infty(\mathbb{R}^n)（台がコンパクトな無限回微分可能関数）は L^p(\mathbb{R}^n) で稠密である。

より C_c を近似すれば十分。軟化子を使う。

軟化子

軟化子

\varphi\in C_c^\infty(\mathbb{R}^n)、\varphi\ge0、\int\varphi=1、\mathrm{supp}\,\varphi\subseteq B(0,1) を取る。たとえば

\varphi(x) = c\,\exp\Big(\frac{-1}{1-|x|^2}\Big)\ \ (|x|<1), \qquad \varphi(x)=0 \ \ (|x|\ge1)

\varphi_\epsilon(x)=\epsilon^{-n}\varphi(x/\epsilon) とおく。この族を軟化子という。

軟化子の性質

f\in L^p(\mathbb{R}^n)（1\le p<\infty）とする。

（1）f*\varphi_\epsilon \in C^\infty。
（2）\|f*\varphi_\epsilon\|_p \le \|f\|_p。
（3）\|f*\varphi_\epsilon - f\|_p \to 0（\epsilon\to0）。
（4）f の台がコンパクトなら f*\varphi_\epsilon の台もコンパクト。

（1）微分を積分の中に入れる。\partial^\alpha(f*\varphi_\epsilon) = f*(\partial^\alpha\varphi_\epsilon)。優収束定理で微分と積分の交換を正当化する。

（2）ミンコフスキーの積分形（第60章★★）、あるいは \int\varphi_\epsilon=1 とヤングの不等式から。

（3）\int\varphi_\epsilon=1 を使って

(f*\varphi_\epsilon)(x)-f(x) = \int \big(f(x-y)-f(x)\big)\varphi_\epsilon(y)\,dy

ミンコフスキーの積分形より \|f*\varphi_\epsilon-f\|_p \le \sup_{|y|\le\epsilon}\|\tau_y f - f\|_p。

ここで \tau_y f(x)=f(x-y)。「平行移動が L^p で連続である」ことに帰着した。

平行移動の連続性。g\in C_c なら一様連続なので明らか。一般の f は で近似し、三分割の議論を使う。

近似単位元

(\varphi_\epsilon) は近似単位元と呼ばれる。畳み込みの単位元 \delta が L^1 に存在しないので、その代用である。

質量 1 を 0 のまわりに集中させていく族なら、何でもよい。第86章でフェイエール核・ポアソン核を、同じ枠組みで扱う。

第87章では、\varphi_\epsilon \to \delta が超関数の意味で厳密な等式になる。

近似の速さと、そこから出るもの

稠密性は「近づける」としか言わない。どのくらい速く近づくかを問うと、別の理論が始まる。

連続度。\omega_p(f,t)=\sup_{|y|\le t}\|\tau_y f - f\|_p とおく。（3）の証明は

\|f*\varphi_\epsilon - f\|_p \le \omega_p(f,\epsilon)

を示していた。\omega_p(f,t)\to0 が稠密性の内容である。

速さで空間を分ける。\omega_p(f,t) \le Ct^\alpha（0<\alpha\le1）なる f の全体をベゾフ空間あるいはリプシッツ空間という。

「近似の速さ」が関数の滑らかさを測る尺度になる。第88章のソボレフ空間も、この見方で統一的に扱える。

単調性。\omega_p(f,t) は t について単調増加で劣加法的。\omega_p(f,t)=o(t) なら f は定数である（p<\infty、連結な台の上で）。

したがって非自明な関数の近似の速さには上限がある。t^1 より速くは近づけない。

軟化子の選び方。 の \varphi を変えると、近似の性質が変わる。

モーメント条件。\int x^\alpha\varphi(x)dx=0（1\le|\alpha|\le m）なら、f が C^{m+1} のとき \|f*\varphi_\epsilon-f\|_\infty = O(\epsilon^{m+1})。

ただしそのような \varphi は非負にできない。「速く近似したいなら、正値性を諦める」——数値解析の高次スキームと同じ構図である。

ヤングの不等式（畳み込み版）。\frac1r=\frac1p+\frac1q-1 について

\|f*g\|_r \le \|f\|_p\|g\|_q

（2）は q=1、r=p の場合である。証明はヘルダーの不等式とフビニの定理を組み合わせる。第86章で詳しく扱う。

ワイエルシュトラスの近似定理から、ストーン–ワイエルシュトラスへ

L^p の稠密性とは別に、一様ノルムでの稠密性がある。

ワイエルシュトラスの近似定理。[a,b] 上の連続関数は、多項式で一様近似できる。

軟化子による証明。f を [0,1] の外へ 0 で延長し、ランダウ核 c_n(1-x^2)^n と畳み込む。この核は多項式なので、畳み込みも（区間上で）多項式になる。

バーンスタイン多項式による証明。

B_n f(x) = \sum_{k=0}^{n}f\Big(\frac{k}{n}\Big)\binom{n}{k}x^k(1-x)^{n-k}

が f に一様収束する。確率論的に読むと、二項分布の期待値である——大数の法則が一様収束を与える。

ストーン–ワイエルシュトラスの定理（第96章）。コンパクトハウスドルフ空間 X 上で、C(X) の部分代数 A が定数を含み、点を分離するなら、A は C(X) で稠密である。

多項式が稠密なのは「x が点を分離するから」という一点に尽きる。第96章で証明を与える。

三角多項式。円周 \mathbb{T} 上では、\{e^{inx}\} の有限一次結合が C(\mathbb{T}) で稠密である（ストーン–ワイエルシュトラスの複素版、自己共役性が要る）。

これが第80章のフーリエ級数の出発点になる。そして C(\mathbb{T}) が L^p(\mathbb{T}) で稠密だから、三角多項式は L^p(\mathbb{T}) でも稠密になる——第65章の「完全正規直交系」の意味がこれである。

稠密性が壊れる場合。\{x^{n_k}\} が C[0,1] で稠密（定数を加えて）であるための条件は、ミュンツの定理により

\sum_k \frac{1}{n_k} = \infty

\{x, x^4, x^9, \ldots\} では稠密にならない——\sum 1/k^2<\infty だから。

「点を分離する」だけでは足りず、密度の条件が要る場合がある。ストーン–ワイエルシュトラスが「代数」を要求するのは、この困難を避けるためである。
