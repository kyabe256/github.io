第II部　分離公理

第15章正規空間とUrysohnの補題

← 第14章　正則空間と完全正則空間 第16章　Tietzeの拡張定理 →

この章の問い

  • 開集合しか与えられていないところから、どうやって連続関数を作るのか。
  • 二進有理数で添字をつけるのは、なぜうまくいくのか。
  • 正規性という条件は、どこまで必要なのか。

正規空間

正規空間

X が正規であるとは、交わらない二つの閉集合 A, B に対し、交わらない開集合 U \supseteq A、V \supseteq B が存在することをいう。T_1 かつ正規な空間を T4 空間という。

第14章の正則性は点と閉集合を分離した。正規性は閉集合と閉集合を分離する。T_1 のもとでは一点集合が閉なので、正規ならば正則である。

X が正規であることと、閉集合 A とその近傍 U \supseteq A に対し、A \subseteq W \subseteq \overline{W} \subseteq U なる開集合 W が存在することは同値である。

正則性の場合（）と同じ議論である。B = X \setminus U と置き、A と B を分離する開集合 W, V を取ると \overline{W} \subseteq X \setminus V \subseteq U。逆も同様。

正則性との違いは、縮める対象が点ではなく閉集合であることだけである。だがこの違いが、次節で決定的に効く。

ウリゾーンの補題

これが第II部の中心にある定理である。開集合の情報だけから、連続関数を作り出す。

ウリゾーンの補題

X が正規で、A, B が交わらない閉集合とする。このとき連続関数 f \colon X \to [0,1] で

f|_A \equiv 0, \qquad f|_B \equiv 1

となるものが存在する。

証明は三段からなる。第一に開集合の族を作り、第二に関数を定義し、第三に連続性を示す。

第一段。D = \{\, k/2^n \mid n \ge 0,\ 0 \le k \le 2^n \,\} を [0,1] の二進有理数全体とする。D で添字づけられた開集合の族 \{U_q\}_{q \in D} を、次を満たすように作る。

A \subseteq U_0, \qquad U_1 = X \setminus B, \qquad p < q \implies \overline{U_p} \subseteq U_q

n についての帰納法で構成する。n = 0 のとき、A \subseteq X \setminus B で X \setminus B は開だから、 より A \subseteq U_0 \subseteq \overline{U_0} \subseteq X \setminus B = U_1 なる U_0 が取れる。

n まで作れたとする。新しく必要なのは q = (2k+1)/2^{n+1} の形の添字であり、その両隣 p = k/2^n、r = (k+1)/2^n はすでに作られていて \overline{U_p} \subseteq U_r。閉集合 \overline{U_p} とその近傍 U_r に を適用して

\overline{U_p} \subseteq U_q \subseteq \overline{U_q} \subseteq U_r

なる U_q を取る。ここで縮める対象が閉集合 \overline{U_p} であることに注意してほしい。正則性ではこの一歩が踏めない。

第二段。関数を

f(x) = \inf \{\, q \in D \mid x \in U_q \,\}

と定める（x がどの U_q にも入らないときは f(x) = 1）。x \in A なら x \in U_0 だから f(x) = 0。x \in B なら x \notin U_1 \supseteq U_q（すべての q）だから f(x) = 1。

第三段。連続性を示す。[0,1] の位相は [0,a) と (a,1] の形の集合で生成されるから（第8章（3））、この二つの逆像が開であることを見ればよい。

f(x) < a であることは、q < a なる q \in D で x \in U_q となるものがあることと同値である。よって

f^{-1}\big([0,a)\big) = \bigcup_{q < a} U_q

は開である。次に f(x) > a を考える。これは q > a なる q で x \notin \overline{U_q} となるものがあることと同値である——実際、f(x) > a なら a < p < q < f(x) なる p, q \in D が取れ、x \notin U_q \supseteq \overline{U_p}。逆に x \notin \overline{U_q}、q > a なら f(x) \ge q > a。したがって

f^{-1}\big((a,1]\big) = \bigcup_{q > a} \big(X \setminus \overline{U_q}\big)

も開である。閉包の包含 \overline{U_p} \subseteq U_q が、この二つ目の等式でちょうど必要になる。

なぜ二進有理数なのか。必要なのは [0,1] のなかで稠密な可算全順序集合であり、しかも「二つの元のあいだに必ず元がある」ことである。帰納法の各段で「両隣のあいだに新しい添字を挿す」操作ができればよい。有理数全体でも構成できるが、二進有理数のほうが段数が数えやすい。

この補題は f|_A \equiv 0、f|_B \equiv 1 を主張するが、f^{-1}(0) = A とは言っていない。f^{-1}(0) = A かつ f^{-1}(1) = B が取れるのは、A と B が G_\delta 集合であるときに限る——これが第18章の完全正規性の内容である。

ただちに従うこと

T_4 空間はチコノフ空間である。すなわち T_4 \Rightarrow T_{3\frac12} \Rightarrow T_3 \Rightarrow T_2。

T_1 より一点集合 \{x\} は閉である。x \notin F、F 閉なら \{x\} と F は交わらない閉集合だから、 より分離する関数が存在する。よって完全正則である。残りは第14章で示した。

正規な空間の例

距離空間は正規である。A, B を交わらない閉集合とし、

f(x) = \frac{d(x,A)}{d(x,A) + d(x,B)}

と置く。分母は A, B が閉で交わらないので消えない。f は連続で f|_A \equiv 0、f|_B \equiv 1。距離空間ではウリゾーンの補題を経由せず、関数を一行で書ける。

コンパクトハウスドルフ空間は正規である。第20章で証明する。

順序位相をもつ全順序集合は正規である。とくに順序数の空間 [0, \omega_1] は正規である。

正規性の言い換えと、1の分割への道

正規性は、いくつもの同値な形をもつ。どの形で使うかが、証明の見通しを決める。

関数による特徴づけ。 の逆は易しい。分離する関数が常に存在すれば、f^{-1}([0,1/2)) と f^{-1}((1/2,1]) が開集合の分離を与える。したがって正規性は「交わらない閉集合を関数で分離できる」と同値である。

これは完全正則性との対比で覚えるとよい。完全正則は点と閉集合を関数で分離し、正規は閉集合と閉集合を関数で分離する。

被覆による特徴づけ。もう一つの形がある。X が正規であることは、二つの開集合による被覆 X = U_1 \cup U_2 に対し、\overline{V_i} \subseteq U_i なる開被覆 X = V_1 \cup V_2 が取れることと同値である。

証明は、A = X \setminus U_2、B = X \setminus U_1 と置けば交わらない閉集合になることから従う。この形が「被覆を縮める」という言い方に通じ、第24章のパラコンパクト性と1の分割へつながる。

1の分割。有限開被覆 \{U_1, \ldots, U_n\} に対し、連続関数 \varphi_i \colon X \to [0,1] で

\mathrm{supp}\,\varphi_i \subseteq U_i, \qquad \sum_{i=1}^n \varphi_i \equiv 1

となるものが取れる。これを1の分割という。正規性から作れる。各 i について縮めた被覆 V_i を取り、ウリゾーンの補題で \psi_i（\overline{V_i} で 1、X \setminus U_i で 0）を作り、

\varphi_i = \frac{\psi_i}{\sum_j \psi_j}

と規格化すればよい。分母は \{V_i\} が被覆だから消えない。

なぜ1の分割が重要か。局所的に定義されたものを大域的に貼り合わせる道具になる。各 U_i の上で作った対象に \varphi_i を掛けて足せば、大域的な対象が得られる。

この手法は第24章で無限被覆に拡張され、多様体論・微分幾何学・偏微分方程式論の基本的な道具になる。第88章でソボレフ空間を扱うとき、局所的な推定を大域化するのに使う。

正規性の悪い性質——階層が崩れはじめる

ここまでの分離公理は、部分空間に遺伝し、積に保たれた。正規性は、どちらも満たさない。

遺伝しない。第9章の★★★で見たチコノフ板がそれである。T = [0,\omega_1] \times [0,\omega] はコンパクトハウスドルフだから正規だが、角の一点を除いた開部分空間は正規でない。

簡単な言い方をすると、上辺 [0,\omega_1) \times \{\omega\} と右辺 \{\omega_1\} \times [0,\omega) が分離できない。右辺を覆う開集合は、各 n < \omega について「ある \alpha_n < \omega_1 より右」を含む。\alpha = \sup_n \alpha_n < \omega_1 なので（\mathrm{cf}(\omega_1) > \omega）、その \alpha より右の部分で、上辺を覆う開集合と必ず交わる。

積で保たれない。もっと劇的な例がある。ゾルゲンフライ直線 \mathbb{R}_\ell は正規だが、\mathbb{R}_\ell \times \mathbb{R}_\ell（ゾルゲンフライ平面）は正規でない。

反対角線 L = \{\, (x, -x) \,\} を考える。L はゾルゲンフライ平面の閉集合であり、しかも相対位相が離散位相になる——基本開集合 [x, x+\varepsilon) \times [-x, -x+\varepsilon) が L と一点でしか交わらない。

L は濃度 2^{\aleph_0} の離散閉集合である。一方ゾルゲンフライ平面は可分である（\mathbb{Q}^2 が稠密）。可分な正規空間の離散閉部分集合の濃度は 2^{\aleph_0} より小さくなければならないという定理（ヨーンズの補題）があり、これに矛盾する。

ヨーンズの補題。正規空間 X が稠密部分集合 D と離散閉部分集合 S をもつとき、2^{|S|} \le 2^{|D|}。証明は、S の各部分集合 T に対し T と S \setminus T を分離する開集合を取り、D との交わりで区別することによる。正規性が、二つの濃度のあいだに不等式を強いる。

これは何を意味するか。正規性は「大域的な」条件である。局所的な条件（第一可算、正則）は操作に強いが、大域的な条件（正規、コンパクト、連結）は壊れやすい。

そこで二つの応答がある。第一に、遺伝的に正規な空間を別の階層として立てる——これが第18章の完全正規性である。第二に、より強く、より安定な条件を探す——これが第24章のパラコンパクト性であり、第32章の距離化定理の主役になる。

第17章で階層と反例を一覧にするとき、正規性がどこで階層を乱しているかを確かめる。
