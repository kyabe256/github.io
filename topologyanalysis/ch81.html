第81章各点収束の問題——DirichletとFejér

この章の問い

  • 部分和は、どんな積分として書けるのか。
  • なぜ部分和は収束せず、平均は収束するのか。
  • 各点収束を保証する条件は何か。

部分和は核との畳み込みである

フーリエ部分和を定義に戻して書き直すと、畳み込みの形になる。

S_Nf(\theta) = \sum_{|n|\le N}\hat f(n)e^{in\theta} = \frac{1}{2\pi}\int_{-\pi}^{\pi} f(t)\sum_{|n|\le N}e^{in(\theta-t)}\,dt = (f*D_N)(\theta)

ここで D_N(\theta)=\sum_{|n|\le N}e^{in\theta}。収束の問題は「この核の族がどう振る舞うか」という問題に完全に翻訳される。関数 f の側の性質は、あとから核の性質と組み合わせるだけになる。

ディリクレ核とフェイェール核

ディリクレ核を D_N(\theta)=\sum_{|n|\le N}e^{in\theta}、フェイェール核を K_N=\frac{1}{N+1}\sum_{k=0}^N D_k とする。閉じた表示は

D_N(\theta) = \frac{\sin\big((N+\tfrac12)\theta\big)}{\sin(\theta/2)}, \qquad K_N(\theta) = \frac{1}{N+1}\left(\frac{\sin\big(\tfrac{(N+1)\theta}{2}\big)}{\sin(\theta/2)}\right)^2

これらを使って S_Nf=f*D_N、\sigma_Nf=f*K_N（フェイェール平均）と書ける。ただし畳み込みは (f*g)(\theta)=\frac{1}{2\pi}\int f(t)g(\theta-t)dt と正規化する。

ディリクレ核の表示は等比級数の和である。z=e^{i\theta} として

D_N = \sum_{n=-N}^{N}z^n = \frac{z^{-N}-z^{N+1}}{1-z} = \frac{z^{-(N+1/2)}-z^{N+1/2}}{z^{-1/2}-z^{1/2}} = \frac{\sin((N+\tfrac12)\theta)}{\sin(\theta/2)}

フェイェール核は \sum_{k=0}^N\sin((k+\tfrac12)\theta)=\frac{\sin^2((N+1)\theta/2)}{\sin(\theta/2)}（同じく等比級数の実部をとる）を使えば出る。フェイェール核が完全平方の形をしているのが、次節のすべてを決める。

二つの核の違い

両方の核について次が成り立つ。

\frac{1}{2\pi}\int_{-\pi}^{\pi} D_N = \frac{1}{2\pi}\int_{-\pi}^{\pi} K_N = 1

しかし振る舞いは大きく異なる。

（1）K_N\ge0。一方 D_N は符号を変える。
（2）\|K_N\|_1=1。一方

\|D_N\|_1 = \frac{1}{2\pi}\int_{-\pi}^{\pi}|D_N| \sim \frac{4}{\pi^2}\log N \to \infty

（\|D_N\|_1 をルベーグ定数という）。
（3）任意の \delta>0 について \sup_{|\theta|\ge\delta}|K_N(\theta)|\to0、さらに \int_{|\theta|\ge\delta}K_N\to0。

積分が 1 なのは、\frac{1}{2\pi}\int e^{in\theta}=\delta_{n0} から定数項だけが残るため。（1）はフェイェール核の完全平方表示から明らか。

（2）|\sin(\theta/2)|\le|\theta|/2 と |\sin((N+\frac12)\theta)| の平均が 2/\pi 程度であることから

\frac{1}{2\pi}\int_{-\pi}^{\pi}\frac{|\sin((N+\frac12)\theta)|}{|\sin(\theta/2)|}\,d\theta \ \ge\ \frac{1}{2\pi}\int_{1/N}^{\pi}\frac{|\sin((N+\frac12)\theta)|}{\theta/2}\,d\theta \ \gtrsim\ \log N

核の絶対値の積分が発散する——これが各点収束が破れる理由のすべてである。

（3）|\theta|\ge\delta では \sin^2(\theta/2)\ge\sin^2(\delta/2) なので K_N(\theta)\le\frac{1}{(N+1)\sin^2(\delta/2)}\to0。

なぜ絶対値の積分が決定的か

作用素 f\mapsto f*D_N を C(\mathbb{T})\to\mathbb{C}（\theta=0 での値）と見ると、そのノルムはちょうど \|D_N\|_1 である。したがってルベーグ定数が発散することは、この汎関数の族が一様有界でないことを意味する。

一様有界性の原理（）の対偶により、ある連続関数について \sup_N|S_Nf(0)|=\infty が従う——で示したのがこれである。発散の反例が「存在する」だけでなく、なぜ存在するかが核の形から読めている。

逆に、核が正で積分が 1 なら、対応する作用素のノルムは 1 で一様に有界になる。フェイェール核が良い振る舞いをする理由は、この一点に尽きる。

近似単位元としてのフェイェール核

近似単位元

\mathbb{T} 上の可積分関数の族 (\Phi_N) が次をみたすとき近似単位元（または良い核）という。

（1）\frac{1}{2\pi}\int\Phi_N=1。
（2）\sup_N\|\Phi_N\|_1 < \infty。
（3）任意の \delta>0 について \int_{\delta\le|\theta|\le\pi}|\Phi_N|\to0。

さらに \Phi_N\ge0 のとき正の近似単位元という（このとき（1）から（2）が従う）。

近似単位元による収束

(\Phi_N) を近似単位元とする。

（1）f\in C(\mathbb{T}) なら f*\Phi_N\to f 一様に。
（2）f\in L^p(\mathbb{T})（1\le p < \infty）なら \|f*\Phi_N-f\|_p\to0。
（3）f が点 \theta_0 で連続なら f*\Phi_N(\theta_0)\to f(\theta_0)。f が \theta_0 で左右の極限をもつなら、\Phi_N が偶関数のとき

f*\Phi_N(\theta_0) \to \frac{f(\theta_0^+)+f(\theta_0^-)}{2}

（1）（3）を示す。\frac{1}{2\pi}\int\Phi_N=1 より

f*\Phi_N(\theta)-f(\theta) = \frac{1}{2\pi}\int_{-\pi}^{\pi}\big(f(\theta-t)-f(\theta)\big)\Phi_N(t)\,dt

\varepsilon>0 をとる。f の一様連続性から \delta>0 を |t| < \delta\Rightarrow|f(\theta-t)-f(\theta)| < \varepsilon（すべての \theta で）となるように選ぶ。積分を |t| < \delta と |t|\ge\delta に分けると

|f*\Phi_N(\theta)-f(\theta)| \le \varepsilon\cdot\frac{\|\Phi_N\|_1}{1} + 2\|f\|_\infty\cdot\frac{1}{2\pi}\int_{|t|\ge\delta}|\Phi_N|

第一項は（2）より C\varepsilon で押さえられ、第二項は（3）より N\to\infty で零。\theta に依らない評価なので一様収束である。

点 \theta_0 での連続性しか仮定しない場合も同じ議論が通る（\delta が \theta_0 にのみ依存する）。左右極限の場合は、\Phi_N が偶であることから |t| < \delta の積分を t>0 と t < 0 に分け、それぞれ f(\theta_0^-)・f(\theta_0^+) に半分の重みで近づくことを見る。

（2）は C(\mathbb{T}) の稠密性（）と、\|f*\Phi_N\|_p\le\|\Phi_N\|_1\|f\|_p（ミンコフスキーの積分不等式）から（1）を移す。「稠密な部分集合で収束＋一様有界」という型の議論が、また使われている。

フェイェールの定理

f\in C(\mathbb{T}) なら \sigma_Nf\to f 一様に。f\in L^p(\mathbb{T})（1\le p < \infty）なら \|\sigma_Nf-f\|_p\to0。f が \theta_0 で左右極限をもつなら \sigma_Nf(\theta_0)\to\frac12(f(\theta_0^+)+f(\theta_0^-))。

とくに三角多項式は C(\mathbb{T}) で一様稠密であり、フーリエ係数がすべて零なら f=0。

より (K_N) は正の近似単位元だから、を適用するだけである。\sigma_Nf は三角多項式なので稠密性が従い、\hat f\equiv0 なら \sigma_Nf\equiv0 で f=0。

この証明はフーリエ級数の一意性を使っていない——核の三つの性質だけから出ている。したがって第80章で先取りして使ったに循環はない。

良い核・悪い核

（1）フェイェール核。正の近似単位元。チェザロ平均（部分和の算術平均）に対応する。

（2）ポアソン核 P_r(\theta)=\frac{1-r^2}{1-2r\cos\theta+r^2}（r\uparrow1）。正で、積分が 1、原点以外で零に収束する。アーベル平均 \sum r^{|n|}\hat f(n)e^{in\theta} に対応し、第94章の調和関数の境界値の理論の中核にある。

（3）熱核 H_t(\theta)=\sum_n e^{-n^2t}e^{in\theta}（t\downarrow0）。正の近似単位元。フーリエがそもそも解こうとしていた熱方程式の解が、核との畳み込みとして現れる——第80章の出発点に戻ってきた。

（4）ディリクレ核。近似単位元ではない（\|D_N\|_1\to\infty）。部分和という最も自然な近似が、実は最も扱いにくい。

（5）ド・ラ・ヴァレ–プーサン核 V_N=2K_{2N+1}-K_N。符号を変えるが \|V_N\|_1\le3 で一様有界なので近似単位元である。正でない近似単位元の例で、しかも |n|\le N でフーリエ係数を保つ——「なめらかな切り落とし」の原型である。

各点収束の十分条件

ディニの判定法

f\in L^1(\mathbb{T})、\theta_0\in\mathbb{T} とし、ある \delta>0 について

\int_{|t| < \delta} \frac{|f(\theta_0-t)-f(\theta_0)|}{|t|}\,dt < \infty

が成り立つなら S_Nf(\theta_0)\to f(\theta_0)。

S_Nf(\theta_0)-f(\theta_0)=\frac{1}{2\pi}\int(f(\theta_0-t)-f(\theta_0))D_N(t)\,dt と書ける。g(t)=f(\theta_0-t)-f(\theta_0) と置き、

D_N(t) = \frac{\sin((N+\tfrac12)t)}{\sin(t/2)}

を代入する。h(t)=g(t)/\sin(t/2) と置けば、仮定と |\sin(t/2)|\asymp|t|（|t| < \delta）から h\in L^1(|t| < \delta)。|t|\ge\delta では 1/\sin(t/2) が有界なので、そこでも h\in L^1。したがって h\in L^1(\mathbb{T}) で

S_Nf(\theta_0)-f(\theta_0) = \frac{1}{2\pi}\int h(t)\sin\big((N+\tfrac12)t\big)\,dt \to 0

最後の収束はリーマン–ルベーグの補題（（5））である（\sin((N+\frac12)t) を e^{iNt} の組み合わせに展開する）。

ディリクレ核の悪さを、関数 f の側の滑らかさで打ち消している。核だけを見ていては何も言えないが、両者を合わせれば収束が出る。

ディニの判定法から出る系

（1）f が \theta_0 で微分可能なら、あるいはヘルダー連続（|f(\theta_0-t)-f(\theta_0)|\le C|t|^\alpha、\alpha>0）なら収束する。連続だけでは足りないが、ほんのわずかな余分の滑らかさで十分である。

（2）ジョルダンの判定法。f が \theta_0 の近くで有界変動（）なら S_Nf(\theta_0)\to\frac12(f(\theta_0^+)+f(\theta_0^-))。跳びのある関数でも、跳びの中点に収束する。方形波で実際にそうなっている。証明はジョルダン分解（）で単調関数に帰着し、第二平均値定理を使う。

（3）局所性。ディニの条件は \theta_0 の近傍のみに関する。つまり各点収束は局所的な性質である——遠くで f がどれほど荒れていても、この点の近くでなめらかなら収束する。一方でフーリエ係数は大域的な量である。この食い違いが、フーリエ解析の技術的な難しさの源泉である（リーマンの局所化原理）。

連続でも部分和は暴れる

で示したように、部分和が一点で発散する連続関数がある。フェイェール平均をとれば、同じ関数について一様収束する（）。

「級数が発散する」ことと「係数が情報を失っている」ことは、まったく別である。係数は f を完全に決めている（一意性）。ただ、部分和という足し方が悪いのである。

これは級数論で古くから知られた区別である：ある総和法で発散する級数が、別の総和法（チェザロ、アーベル）で収束する。フーリエ級数の場合、チェザロ平均とアーベル平均はどちらも常にうまくいく。にもかかわらず部分和を調べる価値があるのは、L^p ノルムでの収束（第82章）や、ほとんどいたるところの収束（第83章）が部分和について成り立つかが、独立に深い問題だからである。

★★ 学部後半——総和法、ギブズ現象、そして共役関数

総和法の階層。級数 \sum a_n に対し、部分和 s_N、チェザロ平均 \frac{1}{N+1}\sum_{k\le N}s_k、アーベル平均 \lim_{r\uparrow1}\sum a_nr^n を考える。「部分和が収束すればチェザロも収束し、チェザロが収束すればアーベルも収束する」——逆は成り立たない。この階層が、フェイェール核とポアソン核の「良さ」の順序に対応している。

タウバー型定理は、逆向きを回復する条件を与える：\sum a_n がアーベル総和可能で na_n\to0 なら収束する（タウバー）。ハーディ–リトルウッドは条件を na_n の有界性に弱めた。フーリエ級数に適用すると、n\hat f(n)\to0 と f の連続性から一様収束が出る（ハーディの定理）。

ギブズ現象の計算。方形波 f の部分和を跳びの近くで見る。\theta_N=\pi/(N+1) あたりで S_Nf は最大値をとり、

S_Nf(\theta_N) \to \frac{2}{\pi}\int_0^\pi\frac{\sin t}{t}\,dt = \frac{2}{\pi}\,\mathrm{Si}(\pi) \approx 1.1789

跳びの高さの約 9\% だけ超過する。原因はディリクレ核の振動で、平均をとると振動が打ち消されるためフェイェール平均では超過が起こらない。画像処理や信号処理で「リンギング」として現れるのは、この現象である。

共役関数とヒルベルト変換。フーリエ級数の各項に -i\,\mathrm{sgn}(n) をかけたものを f の共役関数 \tilde f という。核は

\tilde D_N(\theta) = -i\sum_{0 < |n|\le N}\mathrm{sgn}(n)e^{in\theta}

で、極限は \cot(\theta/2) という可積分でない核になる。したがって \tilde f は素朴な積分では定義できず、主値をとる必要がある。リースの定理：1 < p < \infty のとき f\mapsto\tilde f は L^p で有界。p=1 と p=\infty では成り立たない。

この作用素が、L^p でのフーリエ級数の収束（第82章）と、特異積分の理論全体の原型である。正則関数の実部と虚部の関係（第94章）、ポアソン核と共役ポアソン核の対、リース変換——すべてこの一つの作用素から広がる。

仮定を外すと。近似単位元の条件（3）を落とすと、質量が原点から離れた場所に残り、極限は f の平行移動や平均になる。条件（2）を落とすとディリクレ核と同じ破綻が起こる。条件（1）を落とせば極限が定数倍ずれる。三つとも外せない。

★★★ 大学院——最大作用素と重みつき理論

最大作用素。各点収束を論じる正しい枠組みは、最大作用素の有界性である。S^*f=\sup_N|S_Nf|、M f=\sup_{r>0}\frac{1}{2r}\int_{|t| < r}|f(\theta-t)|dt（ハーディ–リトルウッドの最大作用素）と置く。マルチンキェヴィチの原理：最大作用素が L^p で有界なら、稠密な部分集合での収束からほとんどいたるところの収束が従う。

M が L^p（p>1）で有界かつ L^1 から弱 L^1 へ有界であること（ハーディ–リトルウッドの最大不等式）は、ヴィタリの被覆補題（）から出る。第53章の被覆補題が、ここで解析的な不等式に変わる。これがルベーグの微分定理（）の証明の骨格でもあった。

S^* の有界性がカールソンの定理。\|S^*f\|_{L^2}\le C\|f\|_{L^2} が第83章で扱うカールソンの定理の実質である。証明は「時間–周波数」平面の分解（タイル分解）を要し、ハーディ–リトルウッドの最大不等式のような単純な被覆論では届かない。フェファーマンの別証明とレイシー–タイルの位相空間的な証明が、現代の調和解析の技術の源になった。

重みつき理論。重み w\ge0 について L^p(w) でヒルベルト変換や最大作用素が有界になる条件は、A_p 条件

\sup_I \left(\frac{1}{|I|}\int_I w\right)\left(\frac{1}{|I|}\int_I w^{-1/(p-1)}\right)^{p-1} < \infty

である（マッケンホープト）。A_p 重みの理論は、特異積分・偏微分方程式の正則性・確率論のマルチンゲール理論を横断する。ヒュトネンが解決した A_2 予想（作用素ノルムが A_2 定数に線形に依存する）は、鋭い定量的評価がどこまで可能かという問いに答えた（2012年）。

未解決。円板の乗子問題は解かれた（フェファーマン、1971年：\mathbb{R}^n（n\ge2）で球の特性関数による切り落としは L^p（p\ne2）で有界でない）。一方、制限予想・カクヤ予想・束縛予想の連鎖は、多次元フーリエ解析の中心的な未解決問題として残っている。カクヤ集合のハウスドルフ次元が空間の次元に等しいかという問いは、第42章で扱った次元論が、フーリエ解析の最前線で決定的な役割を果たしていることの実例である（三次元の場合はワン–ザールが2025年に解決）。
