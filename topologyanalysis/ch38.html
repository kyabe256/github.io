第V部　基数不変量と次元論

第38章小さい帰納的次元 ind

← 第37章　積空間の基数不変量 第39章　大きい帰納的次元 Ind →

この章の問い

  • 「次元」を、開集合だけでどう定義するのか。
  • なぜ境界の次元を使う再帰的な定義になるのか。
  • この定義は、直線を1次元、平面を2次元と判定するか。

次元を位相で定義する

直線は1次元、平面は2次元、空間は3次元である。これを座標を使わずに言いたい。

手がかりは境界にある。直線上の点のまわりには、境界が二点（0次元）の近傍が取れる。平面上の点のまわりには、境界が円（1次元）の近傍が取れる。

したがって、次元を「境界の次元より1大きい」と再帰的に定義すればよい。出発点は空集合で、その次元を -1 と約束する。

小さい帰納的次元

正則空間 X について、小さい帰納的次元 \mathrm{ind}\,X を次のように定める。

（1）\mathrm{ind}\,X = -1 \iff X = \varnothing。
（2）\mathrm{ind}\,X \le n とは、各点 x と各近傍 U \ni x に対し、開集合 V で

x \in V \subseteq U, \qquad \mathrm{ind}\,(\partial V) \le n-1

となるものが存在することをいう。
（3）\mathrm{ind}\,X = n とは、\mathrm{ind}\,X \le n かつ \mathrm{ind}\,X \le n-1 でないことをいう。どの n でも \le n でないとき \mathrm{ind}\,X = \infty。

この定義は局所的である。各点のまわりで、境界の小さい近傍が取れるかを問う。正則性を仮定するのは、近傍を縮める操作（）が要るからである。

\mathrm{ind}\,X = 0 であることと、開かつ閉な集合が基底をなすこと（零次元、第28章★★★）は同値である。

\mathrm{ind}\,X \le 0 とは、各点の各近傍のなかに \partial V = \varnothing なる開集合 V が取れることである。\partial V = \overline{V} \setminus V^\circ = \varnothing は V が開かつ閉であることと同値。

基本的な値

いくつかの空間の ind

\mathrm{ind} = 0。\mathbb{Q}、無理数全体、カントール集合、離散空間、\{0,1\}^{I}、\beta\mathbb{N}。どれも全不連結である。

\mathrm{ind}\,\mathbb{R} = 1。各点 x と近傍 (a,b) \ni x に対し、V = (c,d)（a）を取れば \partial V = \{c,d\} で、これは離散空間だから \mathrm{ind} = 0。よって \mathrm{ind}\,\mathbb{R} \le 1。

\mathrm{ind}\,\mathbb{R} \ne 0 は、\mathbb{R} が連結だから（開かつ閉な集合が自明なものしかない）。

\mathrm{ind}\,\mathbb{R}^n = n。\le n は開球を取れば従う（境界は S^{n-1}）。\ge n のほうが難しく、第41章で扱う。

\mathrm{ind}\,\mathbb{R}^n \ge n を示すのは、この分野の中心的な難所である。ブラウワーの領域不変性定理（\mathbb{R}^n と \mathbb{R}^m は n \ne m なら同相でない）と同値な内容をもつ。位相の言葉だけでは出ず、代数的な道具か、綿密な組合せ論が必要になる。

基本的な性質

（1）\mathrm{ind} は位相的性質である（同相で保たれる）。
（2）\mathrm{ind} は遺伝的である。すなわち A \subseteq X なら \mathrm{ind}\,A \le \mathrm{ind}\,X。
（3）\mathrm{ind}(X \times Y) \le \mathrm{ind}\,X + \mathrm{ind}\,Y（可分距離空間で）。
（4）可分距離空間 X について、\mathrm{ind}\,X \le n ならば X は n+1 個の零次元集合の合併である（分解定理）。

（1）定義が開集合と境界だけを使うので明らか。

（2）n についての帰納法。x \in A、U を A での近傍とすると U = U' \cap A（U' は X で開）。X で x \in V \subseteq U'、\mathrm{ind}\,\partial V \le n-1 なる V を取る。\partial_A(V \cap A) \subseteq (\partial V) \cap A であり、帰納法の仮定より右辺の \mathrm{ind} は n-1 以下。境界が制限で小さくなることが、遺伝性の鍵である。

（3）と（4）は第41章で扱う。

零次元空間

空でない可分距離空間 X について、次は同値である。

（1）\mathrm{ind}\,X = 0。
（2）X は開かつ閉な可算基底をもつ。
（3）X はカントール集合 \{0,1\}^{\mathbb{N}} の部分空間と同相。

さらに、これらが成り立つとき X は全不連結である。ただしその逆は成り立たない。

（1）と（2）。 により \mathrm{ind}\,X = 0 は開かつ閉な基底の存在と同値である。可分距離空間は第二可算（第34章）なので、その基底から可算部分族を選んで、なお基底であるようにできる。

（2）から（3）。開かつ閉な可算基底 \{B_n\}_{n \in \mathbb{N}} を取り、e(x) = (\chi_{B_n}(x))_n \in \{0,1\}^{\mathbb{N}} と定める。各 B_n が開かつ閉だから \chi_{B_n} は連続であり、e は連続。x \ne y なら一方だけを含む B_n があるので単射。像の上での逆写像の連続性も、e(B_n) が像のなかで開であることから従う。

（3）から（1）。カントール集合は開かつ閉な基底をもち、この性質は部分空間に遺伝する（（1））。

全不連結性。開かつ閉な集合が基底なら、異なる二点を開かつ閉な集合で分離でき、連結成分は一点になる。

全不連結でも零次元でない——エルデシュ空間

第28章★★★で見たエルデシュ Erdős 空間

E = \{\, x \in \ell^2 \mid \text{すべての座標 } x_n \text{ が有理数} \,\}

は可分距離空間であり、全不連結だが \mathrm{ind}\,E = 1 である。つまり の最後の含意は、逆向きには可分距離空間でも成り立たない。

「連結成分が一点」と「開かつ閉な基底がある」は、別の条件である。両者が一致するのはコンパクトハウスドルフ空間の場合であり（第28章の演習）、そこでは全分離性も加わって三つが同値になる。

零次元空間の分類（可分距離）

カントール集合。コンパクトで完全（孤立点がない）な零次元空間は、すべてカントール集合と同相である（ブラウワーの定理）。

\mathbb{Q}。可算で孤立点をもたない零次元距離空間は、すべて \mathbb{Q} と同相である（シェルピンスキの定理）。

無理数全体。完備距離化可能・零次元・孤立点なし・どのコンパクト部分集合も内部が空、という空間は \mathbb{N}^{\mathbb{N}} と同相である（アレクサンドロフ–ウリゾーンの定理）。

零次元の世界は、驚くほど整理されている。1次元以上ではこの種の完全な分類はない。

ind が加法的でない

次元には「和の公式」があってほしい。だが \mathrm{ind} は素直に振る舞わない。

部分集合への分解。（4）の分解定理は、\mathrm{ind}\,X \le n なら X = Z_0 \cup \cdots \cup Z_n（各 Z_k は零次元）と書けることを述べる。逆も成り立つ——n+1 個の零次元集合の合併なら \mathrm{ind} \le n。

したがって \mathrm{ind}\,X は「零次元集合で何枚に分けられるか」を測っている。

和の公式。この分解から、X = A \cup B について

\mathrm{ind}(A \cup B) \le \mathrm{ind}\,A + \mathrm{ind}\,B + 1

が従う（可分距離空間で）。右辺の +1 は外せない。\mathbb{R} = \mathbb{Q} \cup (\mathbb{R}\setminus\mathbb{Q}) がその例で、左辺が 1、右辺が 0+0+1=1 である。

積の公式。（3）の不等式

\mathrm{ind}(X \times Y) \le \mathrm{ind}\,X + \mathrm{ind}\,Y

も等号とは限らない。ポントリャーギン Pontryagin が一九三〇年に、\mathrm{ind}\,X = \mathrm{ind}\,Y = 2 なのに \mathrm{ind}(X \times Y) = 3 という例を作った。

第42章でこの例を扱う。次元が「足し算で決まらない」のは、次元論のもっとも驚くべき事実の一つである。

なぜ素直でないのか。\mathrm{ind} は局所的な定義である。各点のまわりの境界しか見ていない。

積を取ると、点のまわりの構造が座標ごとの情報の組合せになるが、境界の取り方に自由度が残り、最良の取り方が座標ごとに独立とは限らない。

この不便さが、第39章で \mathrm{Ind}（大域的な定義）を導入する動機の一つである。

次元を測る三つの流儀

本書では三つの次元を扱う。それぞれ何を測っているのかを先に述べておく。

ind（小さい帰納的次元）——本章。点と閉集合を、低次元の境界で分ける。局所的。ウリゾーンとメンガー Menger による（一九二二–二三）。

Ind（大きい帰納的次元）——第39章。閉集合と閉集合を、低次元の境界で分ける。大域的。チェック Čech による（一九三二）。

dim（被覆次元）——第40章。開被覆を、重なりが n+1 以下の細分に置き換えられるか。被覆的。ルベーグ Lebesgue の着想をチェックが定式化した。

三つの関係。一般に

\mathrm{ind}\,X \le \mathrm{Ind}\,X, \qquad \dim X \le \mathrm{Ind}\,X

が成り立つ（正規空間で）。可分距離空間では三つすべてが一致する——これが第41章の一致定理である。

一般の空間では一致しない。第42章で反例を扱う。

第II部・第III部との対応。三つの流儀は、分離公理と被覆性質の区別に対応している。

ind は「点と閉集合」を分ける——正則性（第14章）の水準である。

Ind は「閉集合と閉集合」を分ける——正規性（第15章）の水準である。

dim は被覆を扱う——パラコンパクト性（第24章）の水準である。

第II部と第III部で丁寧に区別した階層が、次元の三つの定義としてそのまま再現されている。

なぜ三つとも必要か。それぞれ得意な場面が違う。

\mathrm{ind} は定義が直観的で、零次元の理論が美しい。\mathrm{Ind} は和の公式が素直に成り立つ。\dim は被覆の言葉なので、パラコンパクト性と相性がよく、写像による評価がしやすい。

そして三つが一致する場面（可分距離空間）では、どれを使ってもよい。第41章でその範囲を確定させる。

ハウスドルフ次元との違い。フラクタルで使われるハウスドルフ次元は、位相的でない——距離に依存する。カントール集合の位相次元は 0 だが、ハウスドルフ次元は \log 2/\log 3 \approx 0.63 である。

第34章の三層で言えば、位相次元は位相の層、ハウスドルフ次元は距離の層に属する。本書は位相次元だけを扱う。
