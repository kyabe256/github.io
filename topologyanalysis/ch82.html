第82章L2理論とParsevalの等式

この章の問い

  • なぜ二乗可積分な関数だけが、きれいに扱えるのか。
  • パーセヴァルの等式は、何を言っているのか。
  • L^p（p\ne2）では何が成り立ち、何が崩れるのか。

二乗可積分という特別な場所

第81章で見たように、フーリエ部分和は各点では暴れる。ところが二乗平均で測ると、何の条件もなしに収束する。この落差の理由は、L^2 が内積空間であり、フーリエ係数が直交射影の係数だという一点にある。

リース–フィッシャーの定理とパーセヴァルの等式

（1）f\in L^2(\mathbb{T}) について \|S_Nf-f\|_2\to0、かつ

\|f\|_2^2 = \frac{1}{2\pi}\int_{-\pi}^{\pi}|f|^2\,d\theta = \sum_{n\in\mathbb{Z}}|\hat f(n)|^2

（2）逆に (c_n)_{n\in\mathbb{Z}} が \sum|c_n|^2 < \infty をみたすなら、\hat f(n)=c_n となる f\in L^2(\mathbb{T}) がただ一つ存在する。
（3）一般に f,g\in L^2(\mathbb{T}) について

\frac{1}{2\pi}\int_{-\pi}^{\pi} f\bar g\,d\theta = \sum_{n\in\mathbb{Z}}\hat f(n)\overline{\hat g(n)}

すなわち f\mapsto\hat f は L^2(\mathbb{T}) から \ell^2(\mathbb{Z}) へのユニタリ同型である。

\{e^{in\theta}\}_{n\in\mathbb{Z}} は L^2(\mathbb{T}) の正規直交系であり（の直前の計算）、フェイェールの定理（）から張る空間が稠密である。したがってこれは正規直交基底であり、あとは第65章の一般論を引くだけである：（1）は、（2）は、（3）は偏極恒等式から（1）に帰着する。

証明の実質は、この一つの正規直交系が基底であること——つまり三角多項式の稠密性——に尽きている。収束の議論は抽象論が全部やってくれる。

パーセヴァルの等式が言っていること

左辺はエネルギー（時間領域での二乗積分）、右辺は各周波数成分の強さの総和である。「エネルギーは周波数ごとに分解でき、総量は保たれる」——これが物理的な読み方である。

数学的には等距離性である。L^2(\mathbb{T})\cong\ell^2(\mathbb{Z}) というユニタリ同型は、連続的な対象（周期関数）と離散的な対象（数列）を完全に同一視する。第65章のヒルベルト空間の分類定理（）の、もっとも具体的な実例である。

この同型のもとで、平行移動は各成分の位相回転に、微分は in 倍に、畳み込みは各成分の積に移る。作用素が対角化されている——第77章の言葉では、平行移動作用素のスペクトル分解を与えているのである。

等式から出てくるもの

パーセヴァルの等式の使い方

（1）級数の値。f(\theta)=\theta（-\pi < \theta < \pi）のフーリエ係数は \hat f(n)=i(-1)^n/n（n\ne0）。パーセヴァルより

\frac{1}{2\pi}\int_{-\pi}^{\pi}\theta^2\,d\theta = \frac{\pi^2}{3} = \sum_{n\ne0}\frac{1}{n^2} = 2\sum_{n\ge1}\frac{1}{n^2}

バーゼル問題 \sum1/n^2=\pi^2/6 が、積分の計算だけから出る。同様に \theta^2 を使えば \sum1/n^4=\pi^4/90 が得られる。

（2）ヴィルティンガーの不等式。f が \mathbb{T} 上絶対連続で \int f=0 なら

\|f\|_2 \le \|f'\|_2

証明はパーセヴァル二回：\|f\|_2^2=\sum_{n\ne0}|\hat f(n)|^2\le\sum_{n\ne0}n^2|\hat f(n)|^2=\|f'\|_2^2。等号は n=\pm1 の成分だけのとき、つまり f が単一の正弦波のときである。これは第76章の最小最大原理の、フーリエによる別証明にあたる——-d^2/d\theta^2 の最小固有値が 1 だと言っている。

（3）等周不等式。長さ L の閉曲線が囲む面積 A について 4\pi A\le L^2。曲線を \mathbb{T} 上の複素数値関数として弧長でパラメータ表示し、面積をグリーンの公式でフーリエ係数の双線形式に書き換え、（2）と同じ比較をする。等号は円のときのみ。純粋に幾何的な最適性が、係数の比較という代数的な操作に還元される。

（4）熱方程式の解。u(\theta,t)=\sum\hat f(n)e^{-n^2t}e^{in\theta} は t>0 で無限回微分可能で、\|u(\cdot,t)\|_2\le\|f\|_2。高周波成分が指数的に潰されるので、初期値がどれほど荒くても解は瞬時になめらかになる。フーリエの出発点（第80章）に、これで答えが出た。

ハウスドルフ–ヤングの不等式

1\le p\le2、1/p+1/q=1 とすると、f\in L^p(\mathbb{T}) について

\|\hat f\|_{\ell^q} \le \|f\|_{L^p}

逆向きに 2\le p < \infty のときは \|f\|_{L^p}\le\|\hat f\|_{\ell^q}（q\le2）。

p=1 のとき q=\infty で \|\hat f\|_\infty\le\|f\|_1（（1））。p=2 のとき q=2 でパーセヴァルの等号。あいだは補間で埋める。

リース–ソリンの補間定理。T が L^{p_0}\to L^{q_0} でノルム M_0、L^{p_1}\to L^{q_1} でノルム M_1 の有界作用素なら、1/p_\theta=(1-\theta)/p_0+\theta/p_1、1/q_\theta も同様として

\|T\|_{L^{p_\theta}\to L^{q_\theta}} \le M_0^{1-\theta}M_1^{\theta}

証明は複素解析を使う：両端で評価がある正則関数に最大値原理（第90章）を適用する（三線定理）。「二点で評価があれば、あいだでも評価がある」という主張が、正則関数の剛性から出る。

p\ne2 では何が崩れるか

（1）係数の特徴づけが失われる。L^2 では「\sum|c_n|^2 < \infty」がフーリエ係数であることの必要十分条件だった。L^1 では、リーマン–ルベーグの条件 c_n\to0 は必要だが十分でない。「どんな数列がフーリエ係数か」という問いに、p\ne2 では答えがない。

（2）ハウスドルフ–ヤングは等式でない。p < 2 のとき不等式は真に厳しく、逆向きの不等式は成り立たない。等距離性は p=2 の特権である。

（3）L^1 では部分和が収束しない。f\in L^1(\mathbb{T}) で \|S_Nf-f\|_1\to0 が破れる例がある。理由はルベーグ定数の発散（）である——一様有界でない作用素族が、稠密でない部分で破綻する。L^\infty でも同様。

（4）1 < p < \infty なら部分和は収束する。これはリースの定理で、共役関数（ヒルベルト変換）の L^p 有界性から出る（第81章★★）。したがって L^p ノルムでの収束は p=1,\infty だけが例外である。

（5）三角関数系は L^p（p\ne2）の「基底」ではない。シャウダー基底としては 1 < p < \infty で正しいが、無条件基底ではない：項の順序を変えると収束が壊れる。直交性を失うと、絶対収束と条件収束の区別が復活する。

同型としての読み方——三つの空間

パーセヴァルの等式は、次の三つを同一視する。

（1）L^2(\mathbb{T})——周期関数。
（2）\ell^2(\mathbb{Z})——二乗総和可能な両側数列。
（3）H^2(\mathbb{D})（ハーディ空間）——単位円板上の正則関数 F(z)=\sum_{n\ge0}c_nz^n で \sum|c_n|^2 < \infty なるもの。これは（2）の片側部分 \ell^2(\mathbb{N}) に対応する。

（3）への対応が、作用素論と複素解析を結ぶ。H^2 上の掛け算作用素 M_z（F\mapsto zF）は、係数の側では片側シフトである（）。片側シフトの不変部分空間を分類する問題は、ベーリングの定理として「内部関数による表現」という完全な答えをもつ——第75章★★★で触れた不変部分空間問題が、この特別な作用素については解けているのである。

ハーディ空間の境界値の理論は、第94章の調和関数の境界値の理論と同じものである。フーリエ級数・作用素論・複素解析の三つが、この一つの同型のところで出会っている。

★★ 学部後半——補間、ラクナリ級数、絶対収束の境目

マルチンキェヴィチの補間。リース–ソリンは強有界性の補間だが、実際に使いたいのは弱型の評価である。T が L^{p_0} から弱 L^{p_0} へ、L^{p_1} から弱 L^{p_1} へ有界なら、あいだの p で強有界。ハーディ–リトルウッドの最大作用素は L^1 から弱 L^1 へしか有界でないので、この形の補間が必須になる。証明は実解析的で、複素解析を使わない。

ラクナリ級数。指数が急速に増える n_1 < n_2 < \cdots（n_{k+1}/n_k\ge\lambda>1）に沿った級数 \sum c_ke^{in_k\theta} は、独立な確率変数の和のように振る舞う。シドンの定理：このような級数について、L^p ノルムはすべての p < \infty で同値で、\ell^2 ノルムに比例する。

これからヴァイエルシュトラス型の反例が作れる。\sum 2^{-k\alpha}e^{i2^k\theta} はヘルダー指数 \alpha で連続だが、\alpha\le1/2 では絶対収束しない。したがって第80章★★のベルンシュタインの定理の境目 \alpha=1/2 は最適である。ラクナリ級数は、フーリエ解析の「最悪の場合」を作る標準的な道具である。

ランダムな符号。\sum\pm c_ne^{in\theta} の符号を独立に選ぶと、ほとんど確実に次が成り立つ：\sum|c_n|^2 < \infty なら級数は L^p（すべての p < \infty）に属し、\sum|c_n|^2\log(1/|c_n|) 型の条件で連続になる（サレム–ジグムント）。「典型的な」フーリエ級数の挙動は、決定的な場合よりずっと良い。カーンの本はこの主題の古典である。

仮定を外すと。周期性・直交性・二乗可積分性のうち、二乗可積分性を外すと等距離が消え（ハウスドルフ–ヤングの不等式だけが残る）、直交性を外すと係数の一意性と無条件収束が消え、周期性を外すと \mathbb{Z} が \mathbb{R} に置き換わる（第85章）。三つのうち二つを保てば、理論の骨格はほぼ残る。

★★★ 大学院——一様分布からフェファーマンの反例まで

ソボレフ埋め込みの原型。\|f\|_\infty\le C\|f\|_{H^s}（s>1/2）は、パーセヴァルとコーシー–シュワルツだけで出る：

|f(\theta)| \le \sum|\hat f(n)| \le \Big(\sum(1+n^2)^{-s}\Big)^{1/2}\Big(\sum(1+n^2)^{s}|\hat f(n)|^2\Big)^{1/2}

第一の和が収束するのが s>1/2 のとき。ソボレフ埋め込みの臨界指数が、単に級数 \sum n^{-2s} の収束条件だったことが分かる。第88章で \mathbb{R}^n 上の一般形を扱うが、仕組みはこれと同じである。

球面上の調和解析。S^{n-1} 上では指数関数のかわりに球面調和関数が正規直交基底をなす。パーセヴァルはそのまま成り立つが、部分和（低次の球面調和関数への射影）の各点収束は n\ge3 で著しく難しくなる。ボヘナー–リース乗子の有界性の範囲を決める問題は、多次元フーリエ解析の中心的な未解決問題の一つである。

フェファーマンの球乗子の反例。\mathbb{R}^n（n\ge2）で、フーリエ変換を単位球の外で切り落とす作用素は L^p（p\ne2）で有界でない（1971年）。証明はカクヤ型の集合を使う：細長い長方形を巧妙に重ねると、面積がほとんど増えないまま方向が全部揃う。「境界が曲がっていると切り落とせない」——曲率の存在が、p=2 以外での破綻を生む。一次元では区間の特性関数による切り落としが有界（ヒルベルト変換の有界性）なので、これは純粋に多次元の現象である。

離散版と加法的組合せ論。有限アーベル群 \mathbb{Z}/N 上のフーリエ解析では、パーセヴァルが有限和の等式になる。ロスの定理（正の密度をもつ整数集合は長さ 3 の等差数列を含む）の証明は、この等式と「大きなフーリエ係数がなければランダムに振る舞う」という原理だけからなる。長さ 4 以上ではフーリエ解析が足りず、ゴワーズの高次一様性が必要になる——「フーリエ係数が小さい」が「構造がない」を意味しなくなる境目が、ちょうどここにある。

演習

基本
  1. f(\theta)=\theta のフーリエ係数を計算せよ。
  2. パーセヴァルの等式からバーゼル問題の値を導け。
  3. \sum1/n^4=\pi^4/90 を、適当な関数にパーセヴァルを使って導け。
  4. 熱方程式の解が t>0 で無限回微分可能であることを、係数の減衰から確かめよ。
証明
  1. （3）を偏極恒等式から示せ。（25点）
  2. ヴィルティンガーの不等式を示し、等号の場合を決定せよ。（35点）
  3. p=1 と p=2 の場合からハウスドルフ–ヤングの不等式が補間で出ることを説明せよ。（30点）
  4. ソボレフ埋め込み \|f\|_\infty\le C\|f\|_{H^s}（s>1/2）を示せ。（35点）
  5. L^1(\mathbb{T}) で部分和がノルム収束しないことを、ルベーグ定数から示せ。（40点）

  1. 等周不等式をフーリエ係数の比較で示せ。（50点）

  3. ラクナリ級数について、ヘルダー連続だが絶対収束しない例を構成せよ。（50点）
