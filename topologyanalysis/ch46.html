第VI部　実数と極限

第46章連続関数——中間値と最大値

← 第45章　極限——ε-δ はなぜこの形か 第47章　一様連続と一様収束 →

この章の問い

  • 中間値の定理は、連結性の何を使っているのか。
  • 最大値の定理は、コンパクト性の何を使っているのか。
  • 「有界閉区間」という仮定を外すと、どこから壊れるのか。

二つの定理、二つの位相的性質

連続関数についての基本定理は二つある。中間値の定理と、最大値の定理。

どちらも高校で習う。だが二つは、まったく別の性質から来ている。中間値は連結性（第28章）、最大値はコンパクト性（第20章）である。

中間値の定理

f \colon [a,b] \to \mathbb{R} を連続とし、f(a) < c < f(b) とする。このとき f(\xi) = c なる \xi \in (a,b) が存在する。

S = \{\, x \in [a,b] \mid f(x) < c \,\} とおく。a \in S で S は上に有界なので、\xi = \sup S が存在する。

f(\xi) < c と仮定する。連続性より \xi の近くで f < c なので、\xi + \delta \in S となり上限に反する（\xi < b は f(b) > c から）。

f(\xi) > c と仮定する。連続性より \xi の近くで f > c なので、\xi - \delta が S の上界になり、最小性に反する。

よって f(\xi) = c。

位相で書き直す

この証明は上限性質を使っている。位相の言葉ではこう言える——[a,b] は連結（第28章）、連続像は連結（第19章）、\mathbb{R} の連結部分集合は区間。

よって f([a,b]) は区間であり、f(a) と f(b) を含むから c も含む。三行で終わる。

上限を使った証明は、\mathbb{R} の完備性を直接使う。位相を使った証明は、それが「連結性」という形で結晶したものを使う。同じ内容の、抽象度の違う二つの証明である。

最大値の定理

最大値の定理

f \colon [a,b] \to \mathbb{R} を連続とすると、f は有界であり、最大値と最小値を取る。

有界性。有界でないとすると、各 n について |f(x_n)| > n なる x_n \in [a,b] がある。ボルツァーノ–ワイエルシュトラスの定理（下）より収束部分列 x_{n_k} \to \xi \in [a,b] が取れる。連続性より f(x_{n_k}) \to f(\xi) だが、|f(x_{n_k})| > n_k \to \infty で矛盾。

最大値。M = \sup_{x} f(x) とおく（有界性から有限）。各 n について f(y_n) > M - 1/n なる y_n を取り、収束部分列 y_{n_k} \to \eta を取る。連続性より f(\eta) = \lim f(y_{n_k}) = M。

ボルツァーノ–ワイエルシュトラスの定理

[a,b] の任意の点列は、収束部分列をもつ。

二分法。[a,b] を半分に分け、無限個の項を含むほうを選ぶ。これを繰り返して区間の減少列 I_1 \supseteq I_2 \supseteq \cdots（長さ (b-a)2^{-k}）を作る。

各 I_k から項を一つずつ、番号が増えるように選んで部分列とする。区間縮小原理（第43章★★）より \bigcap_k I_k は一点 \xi からなり、部分列は \xi に収束する。

位相の言葉では、 は「[a,b] が点列コンパクト」（第25章）である。距離空間では、コンパクト・点列コンパクト・可算コンパクトが一致した（第29章）。

は「コンパクト空間の連続像はコンパクト、\mathbb{R} のコンパクト集合は有界閉、空でない有界閉集合は最大元をもつ」で片づく。これも三行である。

仮定を外すとどこが壊れるか

閉区間という仮定を外す

開区間にすると。f(x) = 1/x は (0,1] で連続だが有界でない。(0,1] はコンパクトでない。

有界でない閉集合にすると。f(x) = x は [0,\infty) で連続だが最大値をもたない。

有界で最大値をもたない例。f(x) = x は (0,1) で有界だが、最大値も最小値も取らない。

連結でない定義域にすると。f = \mathbf{1}_{[2,3]} は [0,1] \cup [2,3] で連続だが、値 1/2 を取らない。中間値の定理は連結性、最大値の定理はコンパクト性——どちらを外したかで、壊れ方が違う。

中間値の定理の使い道

不動点。f \colon [0,1] \to [0,1] が連続なら f(\xi) = \xi なる \xi がある。g(x) = f(x)-x に中間値の定理を使う（g(0) \ge 0 \ge g(1)）。

奇数次方程式。実係数の奇数次多項式は実根をもつ。x \to \pm\infty で符号が変わる。

平方根の存在。f(x) = x^2 に [0,2] で中間値の定理を使えば \sqrt{2} が出る。第43章で完備性から作ったものが、ここでは定理の帰結として出る。

単調関数と、中間値の逆

中間値の定理の逆は成り立つか。「すべての中間値を取る関数は連続か」という問いである。

反例。f(0)=0、x \ne 0 で f(x) = \sin(1/x) とすると、f はどの区間でも [-1,1] のすべての値を取るが、x=0 で連続でない。中間値性は連続性より真に弱い。

この性質をもつ関数をダルブー関数Darbouxという。第48章で見るとおり、導関数はつねにダルブー関数である——連続でなくても。

単調なら逆が成り立つ。f が単調で中間値性をもつなら連続である。単調関数の不連続点は跳びだけで、跳びがあれば値を飛ばすからである。

単調関数の不連続点。f が [a,b] で単調増加なら、各点で片側極限 f(x^-) \le f(x) \le f(x^+) が存在し、不連続点は f(x^-) < f(x^+) となる点である。

各不連続点に開区間 (f(x^-), f(x^+)) を対応させると、これらは互いに交わらない。\mathbb{R} の互いに交わらない開区間の族は可算である（各区間から有理数を一つ取れば単射になる）。

よって単調関数の不連続点は高々可算個。第35章のセル数の言葉でいえば、\mathbb{R} が可算鎖条件を満たすことの帰結である。

逆関数定理。f \colon [a,b] \to \mathbb{R} が連続かつ狭義単調なら、f は像への同相写像である。[a,b] がコンパクト、\mathbb{R} がハウスドルフなので、連続全単射は同相（第20章）。

これが第III部の「コンパクトからハウスドルフへの連続全単射は同相」の、もっとも身近な応用である。\sqrt{\ } や \log の連続性は、ここから出る。

中間値の定理の構成的な側面と、より強い形

構成的でない。 の証明は \xi = \sup S を取る。この上限を計算する手続きはない。

実際、構成的数学では中間値の定理はそのままの形では証明できない。f が区間 [\xi-\varepsilon,\xi+\varepsilon] で c に張りついていると、根の位置を決められないからである。

構成的に証明できるのは、近似版である——どの \varepsilon > 0 についても |f(x)-c| < \varepsilon なる x が計算できる。二分法がそのまま手続きになる。

より強い形——ブラウワーの不動点定理。[0,1] での不動点定理（）は、中間値の定理から出た。高次元ではどうか。

\bar{B}^n \to \bar{B}^n の連続写像は不動点をもつ（ブラウワー）。これは第40章のスペルナーの補題と同値であり、ルベーグの被覆定理とも同値である。

つまり「中間値の定理の n 次元版」が、次元論の中心定理と同じ内容をもつ。一次元では自明に近いことが、二次元以上では組合せ論を要する。

さらに強い形——ボルスーク–ウラムの定理。f \colon S^n \to \mathbb{R}^n が連続なら、f(x) = f(-x) なる x がある。n=1 の場合が「地球上に、気温と気圧が対蹠点と一致する点がある」という有名な主張である。

n=1 の証明は中間値の定理で書ける。g(x) = f(x)-f(-x) は g(-x) = -g(x) だから、符号が変わる。高次元では代数的位相幾何が要る。

まとめ。中間値の定理は「連結性 + 一次元」である。次元を上げると、連結性だけでは足りず、次元論か代数的位相幾何が必要になる。第40章で見た構図が、ここでも現れている。

演習

基本
  1. x^5 - x - 1 = 0 が実根をもつことを示せ。
  2. f \colon [0,1] \to [0,1] 連続が不動点をもつことを示せ。
  3. (0,1) 上の連続関数で有界だが最大値をもたないものを挙げよ。
  4. [a,b] の連続関数の像が閉区間であることを示せ。
証明
  1. を、区間縮小ではなく上極限を使って示せ。（20点）
  2. を、コンパクト性（有限部分被覆）から直接示せ。（25点）
  3. 単調関数の不連続点が高々可算であることを示せ。（25点）
  4. 連続かつ狭義単調な f の逆関数が連続であることを、コンパクト性を使って示せ。（25点）
発展
  1. ダルブー関数だが連続でない例を作り、中間値性が連続性より弱いことを確かめよ。（30点）
  2. ボルスーク–ウラムの定理の n=1 の場合を示せ。（30点）
  3. f \colon \mathbb{R} \to \mathbb{R} が連続かつ全単射なら狭義単調であることを示せ。（35点）
