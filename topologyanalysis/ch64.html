この章の問い

  • 内積は、ノルムに何を付け加えるのか。
  • なぜ「最も近い点」が存在するのか。
  • 直交分解は、なぜヒルベルト空間だけの特権なのか。

内積とノルム

内積空間・ヒルベルト空間

複素ベクトル空間 H 上の \langle\cdot,\cdot\rangle \colon H\times H\to\mathbb{C} が内積であるとは、

\langle x,x\rangle \ge 0\ (=0 \iff x=0), \qquad \langle y,x\rangle=\overline{\langle x,y\rangle}, \qquad \langle \lambda x + z, y\rangle = \lambda\langle x,y\rangle + \langle z,y\rangle

を満たすことをいう。\|x\|=\sqrt{\langle x,x\rangle} が定めるノルムについて完備なとき、H をヒルベルト空間という。

コーシー–シュワルツの不等式

|\langle x,y\rangle| \le \|x\|\,\|y\|。等号は x,y が一次従属のときに限る。

y=0 なら明らか。y\ne0 とし、\lambda = \langle x,y\rangle/\|y\|^2 とおく。

0 \le \|x-\lambda y\|^2 = \|x\|^2 - \frac{|\langle x,y\rangle|^2}{\|y\|^2}

等号は x=\lambda y のときに限る。「直交する成分を引いて、残りの長さが非負」——これがこの不等式の内容である。

中線定理

内積から来るノルムは

\|x+y\|^2 + \|x-y\|^2 = 2\|x\|^2 + 2\|y\|^2

を満たす。逆に、この等式を満たすノルムは内積から来る（ヨルダン–フォン・ノイマン）。

前半は展開するだけ。後半は

\langle x,y\rangle = \tfrac14\big(\|x+y\|^2-\|x-y\|^2 + i\|x+iy\|^2 - i\|x-iy\|^2\big)

と定めて、これが内積になることを確かめる（加法性の証明が長い）。

ヒルベルト空間はどれか

L^p(\mu) が中線定理を満たすのは p=2 のときに限る。f,g を台が交わらない関数に取ると、左辺が 2\|f\|_p^p{}^{2/p}\cdots となって等式が崩れる。

C[0,1]（一様ノルム）も満たさない。f=1、g=x で確かめられる。

ヒルベルト空間は、バナッハ空間のなかで例外的に恵まれた一族である。

最も近い点

凸集合への射影

H をヒルベルト空間、C\subseteq H を空でない閉凸集合とする。どの x\in H についても

\|x-p\| = \mathrm{dist}(x,C) = \inf_{y\in C}\|x-y\|

なる p\in C がただ一つ存在する。

d=\mathrm{dist}(x,C) とし、\|x-y_n\|\to d なる y_n\in C を取る。

コーシー列であること。中線定理を x-y_n と x-y_m に使う。

\|y_n-y_m\|^2 = 2\|x-y_n\|^2 + 2\|x-y_m\|^2 - 4\Big\|x-\frac{y_n+y_m}{2}\Big\|^2

凸性より \frac{y_n+y_m}{2}\in C なので、最後の項は 4d^2 以上。よって

\|y_n-y_m\|^2 \le 2\|x-y_n\|^2 + 2\|x-y_m\|^2 - 4d^2 \ \longrightarrow\ 0

極限。完備性より y_n\to p、C が閉なので p\in C、連続性より \|x-p\|=d。

一意性。p,p' がどちらも最小を与えるなら、上の式で \|p-p'\|^2 \le 2d^2+2d^2-4d^2=0。

三つの仮定が全部効いている

凸性は中点が C に入るために、完備性は極限が存在するために、内積は中線定理のために要る。

どれを外しても定理は壊れる。第63章で「無限次元では最大値の定理が使えない」と述べたが、ヒルベルト空間の凸集合に限れば、最良近似が存在する。

一般のバナッハ空間では、閉凸集合への最近点が存在しないこともあるし、存在しても一意とは限らない。\ell^\infty や L^1 で反例が作れる。

直交分解

直交補空間

M\subseteq H に対し M^\perp = \{\, x\in H \mid \langle x,y\rangle=0 \ (\forall y\in M) \,\} と定める。M^\perp はつねに閉部分空間である（内積の連続性から）。

直交分解定理

M\subseteq H を閉部分空間とすると

H = M \oplus M^\perp

すなわち、どの x\in H も x=p+q（p\in M、q\in M^\perp）と一意に書ける。さらに (M^\perp)^\perp = M。

で C=M として p を取り、q=x-p とおく。

q\in M^\perp であること。y\in M、t\in\mathbb{R} について p+ty\in M なので

\|q\|^2 \le \|x-(p+ty)\|^2 = \|q\|^2 - 2t\,\mathrm{Re}\langle q,y\rangle + t^2\|y\|^2

すべての t でこれが成り立つには \mathrm{Re}\langle q,y\rangle=0。y を iy に替えて虚部も 0。

一意性。p+q=p'+q' なら p-p'=q'-q \in M\cap M^\perp = \{0\}。

(M^\perp)^\perp=M。M\subseteq(M^\perp)^\perp は明らか。逆に x\in(M^\perp)^\perp を x=p+q と分けると q\in M^\perp かつ q = x-p \in (M^\perp)^\perp なので \langle q,q\rangle=0。

第63章★★で述べた「補空間をもたない閉部分空間」の問題が、ヒルベルト空間では起こらない。

そしてリンデンシュトラウス–ツァフリーリの定理により、それはヒルベルト空間だけの性質である。

射影 P_M \colon x\mapsto p は有界（\|P_M\|\le1）で、P_M^2=P_M、\langle P_Mx,y\rangle=\langle x,P_My\rangle。第75章で、この性質をもつ作用素を「直交射影」として扱う。

リースの表現定理（ヒルベルト空間版）

\varphi を H 上の有界線型汎関数とすると、y\in H がただ一つ存在して

\varphi(x) = \langle x,y\rangle \qquad (\forall x\in H)

と書ける。さらに \|\varphi\|=\|y\|。

\varphi=0 なら y=0。そうでないとき、M=\ker\varphi は閉部分空間（\varphi が連続だから）で M\ne H。

より M^\perp\ne\{0\}。z\in M^\perp、\varphi(z)=1 と取る（正規化）。

どの x も x = (x-\varphi(x)z) + \varphi(x)z と分け、第一項は M に入る。よって

\langle x,z\rangle = \varphi(x)\langle z,z\rangle, \qquad \varphi(x) = \Big\langle x, \frac{z}{\|z\|^2}\Big\rangle

y=z/\|z\|^2 とすればよい。一意性と \|\varphi\|=\|y\| はコーシー–シュワルツから。

双対の反線型性と、随伴作用素

は H^* \cong H を与える。ただし対応 y\mapsto\langle\cdot,y\rangle は反線型である——\lambda y \mapsto \bar\lambda\langle\cdot,y\rangle。

実ヒルベルト空間なら線型同型、複素なら共役線型同型。この違いが、以降の符号の扱いに効いてくる。

随伴作用素。T\in B(H) に対し、y を固定した汎関数 x\mapsto\langle Tx,y\rangle にリースの表現定理を使うと、T^*y\in H が定まる。

\langle Tx,y\rangle = \langle x,T^*y\rangle \qquad (\forall x,y)

性質。(T^*)^*=T、(ST)^*=T^*S^*、(\lambda T)^*=\bar\lambda T^*、そして

\|T^*\|=\|T\|, \qquad \|T^*T\| = \|T\|^2

最後の等式（C^* 等式）が、第79章のゲルファント理論の出発点になる。

証明。\|Tx\|^2 = \langle T^*Tx,x\rangle \le \|T^*T\|\|x\|^2 より \|T\|^2\le\|T^*T\|。逆は \|T^*T\|\le\|T^*\|\|T\|=\|T\|^2。

核と像の関係。

\ker T^* = (\mathrm{ran}\,T)^\perp, \qquad \overline{\mathrm{ran}\,T} = (\ker T^*)^\perp

「解が存在する条件」が「随伴の核に直交すること」で書ける——これがフレドホルムの択一定理（第73章）の原型である。

有限次元との対応。行列でいえば T^* は共役転置。上の関係式は、線型代数の「階数・退化次数定理」の無限次元版にあたる。

ただし無限次元では \mathrm{ran}\,T が閉とは限らない。閉包を取る必要があるところが、有限次元との実質的な差である。第69章の開写像定理が、閉になる条件を与える。

ヒルベルト空間の特徴づけと、そこから外れる世界

何がヒルベルト空間を決めるか。これまでに三つの特徴づけが出た。

ノルムが中線定理を満たす（ヨルダン–フォン・ノイマン）。どの閉部分空間も補空間をもつ（リンデンシュトラウス–ツァフリーリ）。そして単位球の等長変換群が推移的（マズール–ウラムの周辺）。

さらに幾何的な特徴づけがある。カデツ–スネジキンの定理——どの二次元部分空間も等距離に同型なバナッハ空間は、ヒルベルト空間である（実 3 次元以上）。

「すべての方向が同じに見える」ことが、内積の存在と同値になる。

分類。ヒルベルト空間は、正規直交基底の濃度（ヒルベルト次元）だけで同型を除いて決まる（第65章）。

可分な無限次元ヒルベルト空間は、すべて \ell^2 と同型。バナッハ空間の分類が絶望的に難しいのと、際立った対照をなす。

ヒルベルト空間でない世界。バナッハ空間の同型分類は、記述集合論の意味で「完全に複雑」であることが知られている（フェルドマン–ムーア型の結果）。

たとえばツィルセルソンの空間は、\ell^p も c_0 も部分空間として含まない。「どんなバナッハ空間も \ell^p か c_0 のコピーを含む」という長年の予想が、これで否定された。

ゴワーズの二分法。どの無限次元バナッハ空間も、無条件基底列をもつか、あるいは遺伝的に既約な部分空間をもつ。この定理でゴワーズはフィールズ賞を受けた。

証明にはラムゼー型の組合せ論が使われる。第V部で見た「集合論が解析に入り込む」構図が、ここでも現れている。

同次空間問題。「すべての閉部分空間が自分自身と同型なバナッハ空間は、ヒルベルト空間に限るか」——ゴワーズの二分法から、答えははいである（一九九六年）。

ヒルベルト空間は、いくつもの方向から「唯一の完全に対称なバナッハ空間」として立ち現れる。第X部でスペクトル理論が美しく展開できるのも、この対称性による。
