第III部　コンパクト性と被覆性質

第25章Lindelöf・可算コンパクト・点列コンパクト

← 第24章　パラコンパクト性と1の分割 第26章　被覆性質の相互関係と反例 →

この章の問い

  • 「有限」を「可算」に置き換えると、何が変わるのか。
  • 点列コンパクトとコンパクトは、なぜ一致しないのか。
  • 距離空間では、これらがすべて一致するのはなぜか。

三つの弱いコンパクト性

位相空間 X について、

リンデレーフ　どの開被覆も可算部分被覆をもつ。
可算コンパクト　どの可算開被覆も有限部分被覆をもつ。
点列コンパクト　どの点列も収束する部分列をもつ。
擬コンパクト　どの連続実数値関数も有界。

コンパクト性の定義には二つの「有限」が現れていた。「どの開被覆も」の部分と「有限部分被覆」の部分である。前者を可算に制限したのが可算コンパクト性、後者を可算に緩めたのがリンデレーフ性である。

X がコンパクトであることと、リンデレーフかつ可算コンパクトであることは同値である。

コンパクトなら両方は明らか。逆に、開被覆 \mathcal{U} を取る。リンデレーフ性より可算部分被覆 \{U_n\} があり、可算コンパクト性よりその有限部分被覆がある。二つの条件が、ちょうど補い合って完全なコンパクト性を作る。

含意の関係

（1）コンパクト \Rightarrow 可算コンパクト \Rightarrow 擬コンパクト。
（2）点列コンパクト \Rightarrow 可算コンパクト。
（3）第一可算かつ可算コンパクト \Rightarrow 点列コンパクト。
（4）第二可算 \Rightarrow リンデレーフ。
（5）正則かつリンデレーフ \Rightarrow パラコンパクト、したがって正規。

（1）の後半。f が非有界なら U_n = f^{-1}((-n,n)) は可算開被覆で有限部分被覆をもたない。

（2）可算開被覆 \{U_n\} が有限部分被覆をもたないとする。各 n について x_n \notin U_1 \cup \cdots \cup U_n を選ぶ。点列コンパクト性より収束部分列 x_{n_k} \to x がある。x \in U_m なる m を取ると、n_k \ge m なる k について x_{n_k} \notin U_m となり、収束に反する。

（3）点列 (x_n) を取る。A_n = \{\, x_k \mid k \ge n \,\} とすると、\{\overline{A_n}\} は有限交叉性をもつ閉集合の族である。可算コンパクト性より x \in \bigcap_n \overline{A_n} がある。第一可算性より x の可算減少近傍基 \{V_m\} を取り、各 V_m から A_m の点を選べば部分列になる。

（4）可算基底 \mathcal{B} を取る。開被覆 \mathcal{U} に対し、B \subseteq U なる U \in \mathcal{U} が存在する B \in \mathcal{B} を集める。それらは可算で、各 B に一つずつ U を選べば可算部分被覆になる。

（5）は証明を省く。第24章のマイケルの定理の系である。

逆が成り立たない例

可算コンパクトだがコンパクトでない。[0,\omega_1)。可算個の [0,\alpha_n) の合併は [0, \sup \alpha_n) で、\sup \alpha_n < \omega_1 だから被覆にならない——すなわち可算開被覆は必ず有限で足りる。一方 \{[0,\alpha)\}_{\alpha<\omega_1} は有限部分被覆をもたない。リンデレーフでない。

コンパクトだが点列コンパクトでない。\{0,1\}^{I}（I の濃度 2^{\aleph_0} より大）。第12章の議論による。また \beta\mathbb{N} もそうである（第23章）。

点列コンパクトだがコンパクトでない。[0,\omega_1)。可算な部分集合は有界なので、どの点列も収束部分列をもつ。

擬コンパクトだが可算コンパクトでない。構成は込み入るが存在する。完全正則な空間では擬コンパクトと可算コンパクトが一致するので、そうでない空間を作る必要がある。

リンデレーフだが第二可算でない。ゾルゲンフライ直線。第7章で第二可算でないことを見た。リンデレーフであることは、被覆から可算個を選ぶ議論で示せる。

距離空間ではすべて一致する

距離空間 X について、次は同値である。（1）コンパクト。（2）可算コンパクト。（3）点列コンパクト。（4）全有界かつ完備。

詳細は第29章で扱う。骨子だけ述べる。距離空間は第一可算だから、（2）（3）により（2）と（3）は同値である。

（3）から（1）を示すのが要点である。点列コンパクトな距離空間は全有界である——そうでなければ、互いに \varepsilon 以上離れた点列が作れ、収束部分列をもたない。全有界性から可分性が従い、可分な距離空間は第二可算（第7章）、したがってリンデレーフ（（4））。リンデレーフかつ可算コンパクトならコンパクトである（）。

証明の鍵は「点列コンパクト \Rightarrow 可分 \Rightarrow 第二可算 \Rightarrow リンデレーフ」という経路である。距離があることで、局所的な可算性が大域的な可算性に持ち上がる（第7章）。この持ち上げが、可算と有限の差を消している。

擬コンパクト性——関数の側から見る

擬コンパクト性は、開被覆ではなく連続関数で定義された。この違いが何を意味するかを見ておく。

完全正則なら可算コンパクトと一致する。完全正則空間 X が擬コンパクトなら可算コンパクトである。

証明。可算開被覆 \{U_n\}（増加としてよい）が有限部分被覆をもたないとする。各 n について x_n \notin U_n を選ぶ。完全正則性より、x_n で n をとり X \setminus U_{n+1} の外で急速に消える関数 f_n が作れる。和 f = \sum_n f_n が局所有限和になるよう調整すると、連続で非有界な関数が得られる。擬コンパクト性に反する。

完全正則でなければ一致しない。関数が足りない空間では、擬コンパクト性は何も言わない。極端な例として、第14章★★★のヘヴィットの空間——連続関数が定数しかない正則空間——は自動的に擬コンパクトである。可算コンパクトである必要はない。

解析学での意味。擬コンパクト性は「有界性が自動的に成り立つ」条件である。第20章で見たとおり、コンパクト空間上の連続関数は最大値を取った。擬コンパクト性は、最大値までは保証しないが有界性は保証する。

第VIII部で関数空間を扱うとき、C(X) が有界関数の空間になる条件として、この概念が背後にある。C(X) = C^b(X) であることが、まさに擬コンパクト性である。

第23章との接続。第23章で C^b(X) \cong C(\beta X) を見た。X が擬コンパクトなら C(X) = C^b(X) \cong C(\beta X) である。

したがって擬コンパクトな空間は、関数の側から見ると \beta X と区別がつかない。「有界でない関数が作れない」ということは、「コンパクト化しても関数が増えない」ということである。

まとめ。四つの弱いコンパクト性のうち、リンデレーフ性だけが被覆の側を緩め、他の三つは有限性の側を緩めている。この非対称が、 の分解に現れている。

[0, ω₁) という空間を読む

で三度登場した [0,\omega_1) を、正面から調べる。この空間は、位相空間論のあらゆる反例に顔を出す。

基本的な性質。順序位相を入れる。基本開集合は (\alpha, \beta) の形である。[0,\omega_1) は

局所コンパクト——各 \alpha の近傍 [0,\alpha] はコンパクト。

可算コンパクト——可算個の順序数の上限は \omega_1 未満（\mathrm{cf}(\omega_1) > \omega）。

点列コンパクト——同じ理由。可算な点列は有界。

正規——順序位相をもつ全順序集合は正規（第15章）。

第一可算——後続順序数は孤立点、極限順序数 \lambda には \mathrm{cf}(\lambda) = \omega より可算な近傍基がある。

しかし。コンパクトでなく、リンデレーフでなく、パラコンパクトでなく、可分でなく、第二可算でない。

閉非有界集合。この空間を理解する鍵は、閉非有界集合（クラブ集合）という概念である。C \subseteq \omega_1 がクラブとは、閉であって非有界であることをいう。

二つのクラブの交叉はクラブである。さらに、可算個のクラブの交叉もクラブである。この性質が、[0,\omega_1) の連続関数の振る舞いを決める。

連続関数は最終的に定数。驚くべき事実がある。連続関数 f \colon [0,\omega_1) \to \mathbb{R} は、ある \alpha < \omega_1 より先で定数になる。

証明の筋。各 n について、|f(\beta) - f(\gamma)| < 1/n がすべての \beta, \gamma \ge \alpha_n で成り立つような \alpha_n が取れることを示す。そうでなければ、1/n 以上離れた値をとる増加列が作れ、その上限で連続性が壊れる。\alpha = \sup_n \alpha_n < \omega_1 と置けばよい。

したがって [0,\omega_1) は擬コンパクトであり、\beta([0,\omega_1)) = [0,\omega_1] である——一点コンパクト化とストーン–チェックのコンパクト化が一致する珍しい例である。

プレッシング・ダウン補題。より強い道具がある。f が退行的（f(\alpha) < \alpha）なら、f はある定常集合の上で定数である。フォドア Fodor の補題という。

これは第36章のスーリン問題や、第V部の基数不変量の議論で使われる。\omega_1 の組合せ論が、位相空間の性質を決めている。

なぜこの空間が重要か。[0,\omega_1) は、「可算では届かないが、それより上はない」という最小の非可算性を体現している。第4章で共終数を導入した目的が、ここに集約される。

本書の後半では、この空間は表に出てこない。解析学は可算な操作で閉じているからである。だが第36章と第42章では、非可算性が本質的に効く場面が現れる。そこでこの空間に戻る。
