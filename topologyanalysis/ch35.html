第V部　基数不変量と次元論

第35章基数不変量——重み・稠密度・指標

← 第34章　距離空間は何が特別なのか 第36章　セル数とスーリン問題 →

この章の問い

  • 「はい／いいえ」の条件を、量に変えると何が見えるのか。
  • 基数不変量のあいだには、どんな不等式が成り立つのか。
  • 空間の濃度は、局所的な量で押さえられるのか。

条件を量に変える

第7章で可算公理を三つ導入した。「可算な基底があるか」「可算な近傍基があるか」「可算な稠密集合があるか」。どれも「はい／いいえ」の問いだった。

「可算」という語を「濃度 \kappa 以下」に置き換えると、条件が量になる。

四つの基数不変量

位相空間 X（無限とする）について、

重みweight w(X)　基底の濃度の最小値。
稠密度density d(X)　稠密部分集合の濃度の最小値。
指標character \chi(X)　各点の近傍基の濃度の最小値の上限。
セル数cellularity c(X)　互いに交わらない空でない開集合の族の濃度の上限。

いずれも慣例として \aleph_0 を下限とする（有限空間で 0 にならないように）。

第7章の条件は、これらの値が \aleph_0 であることにあたる。w(X)=\aleph_0 が第二可算、\chi(X)=\aleph_0 が第一可算、d(X)=\aleph_0 が可分。三つの「はい／いいえ」が、三つの基数の値になった。

もう三つ

Lindelöf 数 L(X)　どの開被覆も濃度 L(X) 以下の部分被覆をもつような最小の基数。
散布度spread s(X)　離散部分空間の濃度の上限。
拡がりextent e(X)　離散閉部分空間の濃度の上限。

基本的な不等式

任意の位相空間 X について、

d(X) \le w(X), \qquad \chi(X) \le w(X), \qquad c(X) \le d(X), \qquad e(X) \le s(X), \qquad L(X) \le w(X)

が成り立つ。ハウスドルフ空間ではさらに |X| \le 2^{w(X)}。

d(X) \le w(X)。基底 \mathcal{B}（濃度 w(X)）の各元から点を一つ選べば稠密集合になる（第7章 の議論）。

\chi(X) \le w(X)。x を含む基底元の全体が近傍基になる。

c(X) \le d(X)。D を稠密集合、\{U_i\} を互いに交わらない空でない開集合の族とすると、各 U_i が D の点を含み、交わらないので異なる点である。よって族の濃度は |D| 以下。

L(X) \le w(X)。基底から被覆を選び直す議論（第25章 （4））の一般化。

|X| \le 2^{w(X)}。T_0 ならば、各点 x に「x を含む基底元の集合」を対応させる写像が単射である。値域は \mathcal{P}(\mathcal{B}) なので濃度 2^{w(X)}。

具体的な値

\mathbb{R}。w = d = \chi = c = L = \aleph_0。すべて可算である。

ゾルゲンフライ直線 \mathbb{R}_\ell。d = \chi = c = L = \aleph_0 だが w = 2^{\aleph_0}。第7章で第二可算でないことを見たのが、この不等式が真であることの内容である。

\{0,1\}^{I}（|I| = \kappa \ge \aleph_0）。w = \kappa、\chi = \kappa、c = \aleph_0（後述）、d = \log \kappa（第37章）。セル数が可算にとどまるのが積空間の際立った性質である。

非可算離散空間 D（濃度 \kappa）。w = d = c = s = e = \kappa、\chi = \aleph_0、L = \kappa。

距離空間では潰れる

距離空間 X について w(X) = d(X) = L(X) = c(X) であり、\chi(X) = \aleph_0 である。

\chi = \aleph_0 は第一可算性（\{B(x,1/n)\}）。

d \le w は一般の不等式。w \le d を示す。D を稠密集合（濃度 d(X)）とすると、\{B(x, q) \mid x \in D,\ q \in \mathbb{Q}^{+}\} が基底になる——第7章の議論の一般化である。濃度は d(X) \cdot \aleph_0 = d(X)。有理半径という可算な目盛りが、ここでも効いている。

c \le d は一般。d \le c は、c(X) 個以下の交わらない球で覆えることから従う（極大な族を取る）。L についても同様。

この命題が第34章の主題を数量的に述べたものである。距離空間では四つの量が一つに潰れる。一般の空間で四つを区別する意味は、距離化できない空間を扱うときに初めて生じる。

空間の濃度を押さえる定理

の最後は |X| \le 2^{w(X)} だった。重みは大域的な量なので、この評価は粗い。局所的な量で押さえられないか。

アルハンゲリスキーの定理。ハウスドルフ空間 X について

|X| \le 2^{L(X) \cdot \chi(X)}

とくに、リンデレーフかつ第一可算なハウスドルフ空間の濃度は 2^{\aleph_0} 以下である。

なぜ意外か。第一可算性は各点のまわりの条件、リンデレーフ性は被覆の条件である。どちらも空間の大きさを直接には制限しない。それなのに、二つを合わせると濃度の上限が出る。

一九六九年にアルハンゲリスキー Arhangelskii が示すまで、この問題は二十年以上未解決だった。ハウスドルフ空間の濃度を第一可算性から押さえる問題は、アレクサンドロフとウリゾーンが一九二三年に提起している。

証明の道具。証明は閉包構成法と呼ばれる手法による。長さ \omega_1 の増加列 \{F_\alpha\} を作り、各段で

（1）F_\alpha の各点の近傍基から被覆を選び、（2）その補集合に点を足し、（3）閉包を取る。

各段の濃度が 2^{\aleph_0} を超えないように制御する。\mathrm{cf}(\omega_1) > \omega により、極限段で閉包が閉じる。

第4章で導入した共終数が、ここでも決定的に働いている。第17章のチコノフ板、第25章の [0,\omega_1) と同じ構造である。

系。コンパクトハウスドルフかつ第一可算な空間の濃度は 2^{\aleph_0} 以下である（コンパクトならリンデレーフ）。したがって、そのような空間は連続体の濃度を超えられない。

関連する不等式。同じ方向の結果が多数ある。

|X| \le 2^{c(X) \cdot \chi(X)} \quad(\text{正規ハウスドルフ}), \qquad |X| \le d(X)^{\chi(X)} \quad(\text{ハウスドルフ})

後者はポスピシル Pospíšil の不等式である。どれも「局所的な量と大域的な量から、空間全体の大きさが決まる」という形をしている。

第37章で積空間について同じ問いを扱う。そこで独立性が現れる。

基数不変量の全体像と、独立な不等式

基数不変量は十数個が標準的に使われる。それらのあいだの関係を尽くすのが、この分野の仕事である。

主要な不変量。本章で導入した七つに加えて、

緊密度tightness t(X)——x \in \overline{A} なら濃度 t(X) 以下の B \subseteq A で x \in \overline{B}。第12章の点列の議論を量化したものである。

π重みπ-weight \pi w(X)——どの空でない開集合もある元を含むような開集合の族の、最小濃度。

網重みnetwork weight nw(X)——開とは限らない集合の族で「基底の役割」を果たすものの最小濃度。

擬指標pseudocharacter \psi(X)——一点が \psi(X) 個の開集合の交叉になる。

不等式の網。これらのあいだには数十の不等式が知られている。例を挙げる。

nw(X) \le w(X), \qquad t(X) \le \chi(X), \qquad c(X) \le \pi w(X) \le w(X) w(X) \le 2^{d(X)} \ (\text{ハウスドルフ}), \qquad \psi(X) \le \chi(X)

一部は証明でき、一部は公理系から独立である。

独立な例。「c(X) = \aleph_0 ならば |X| \le 2^{\aleph_0} か」——ハウスドルフ空間では偽だが、正規なら？ この種の問いに独立なものが多い。

もっとも有名なのが第36章のスーリン問題である。「c(X) = \aleph_0 と d(X) = \aleph_0 は、順序位相をもつ連結な空間で一致するか」という形に書ける。

積での振る舞い。不変量が積でどうなるかも独立性の宝庫である。c(X \times Y) = \max(c(X), c(Y)) は成り立つか。

成り立つかどうかは公理に依存する。第37章で扱う。

なぜ独立性が多いのか。基数不変量は「どれだけの個数で足りるか」を問う。そして個数の比較は、可算と非可算の境界で集合論に触れる。

第4章で共終数と連続体仮説を導入し、第17章と第26章で反例に使い、第32章で距離化問題の限界として見た。第V部は、その構造を正面から測る部である。

次元論との関係。第38章以降で扱う次元も、一種の不変量である。ただし値が自然数に限られる。

「大きさ」を測るのが基数不変量、「太さ」を測るのが次元——どちらも位相だけで定義され、距離を使わない。そして第41章の一致定理は、距離があると三つの次元が潰れることを述べる。本章の と同じ構図である。

演習

基本
  1. \mathbb{R} の四つの基数不変量を求めよ。
  2. 濃度 \kappa の離散空間について、七つの不変量を求めよ。
  3. c(X) \le d(X) を示せ。
  4. ゾルゲンフライ直線で w \ne d であることを述べよ。
証明
  1. の |X| \le 2^{w(X)} を、T_0 をどこで使うか明示して示せ。（20点）
  2. の w \le d を示せ。（20点）
  3. L(X) \le w(X) を示せ。（15点）
発展
  1. アルハンゲリスキーの不等式 |X| \le 2^{L(X)\chi(X)} の主張を述べ、コンパクト第一可算ハウスドルフ空間について何が言えるかを説明せよ。（30点）
  2. ハウスドルフ空間について w(X) \le 2^{d(X)} を示せ。（35点）
