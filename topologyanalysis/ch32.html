第32章Nagata–SmirnovとBingの距離化定理

この章の問い

  • 第二可算性を、どこまで弱められるのか。
  • 「局所有限な基底」という条件は、何を保証しているのか。
  • 距離化の必要十分条件は、結局どう述べられるのか。

基底の細かさを測り直す

第二可算性は「基底が可算」という条件だった。これを緩めたい。だが単に「基底の濃度を大きくしてよい」では駄目である——ゾルゲンフライ直線が反例になる（第31章）。

濃度ではなく、基底の重なり方を制限する。第24章の局所有限性が使える。

部分集合の族 \mathcal{A} が \sigma-局所有限であるとは、\mathcal{A} = \bigcup_{n \in \mathbb{N}} \mathcal{A}_n と書けて各 \mathcal{A}_n が局所有限であることをいう。\sigma-離散とは、各 \mathcal{A}_n が離散（各点が高々一つの元と交わる近傍をもつ）であることをいう。

距離空間の基底

距離空間 (X,d) は \sigma-局所有限な基底をもつ。実は \sigma-離散な基底ももつ。

構成の骨子。各 n について、半径 2^{-n} の球による被覆を取り、第24章のパラコンパクト性（距離空間はパラコンパクト）から局所有限な細分 \mathcal{A}_n を作る。\bigcup_n \mathcal{A}_n が基底になる——各点の各近傍について、半径を小さく取れば収まるからである。

可算でないことに注意。各 \mathcal{A}_n は無限個でよい。可算個の局所有限な族の合併という形が、可算性を局所性に置き換えている。

ナガタ–スミルノフの距離化定理

ナガタ–スミルノフの距離化定理

位相空間 X が距離化可能であるための必要十分条件は、X が正則ハウスドルフであって \sigma-局所有限な基底をもつことである。

必要性は 。十分性を示す。三段で進む。

第一段——正規性。\mathcal{B} = \bigcup_n \mathcal{B}_n を \sigma-局所有限な基底とする。X が正規であることを示す。

A, B を交わらない閉集合とする。各 x \in A について、正則性より \overline{B} \cap B = \varnothing なる基底元 B \ni x が取れる。それらを n ごとに集めて \mathcal{C}_n、U_n = \bigcup \mathcal{C}_n と置く。

\mathcal{C}_n は局所有限だから、第24章の より \overline{U_n} = \bigcup_{C \in \mathcal{C}_n} \overline{C} であり、これは B と交わらない。局所有限な族の閉包が閉になることが、ここで決定的に効く。

B についても同様に V_n を作り、第16章★★★と同じ対角線的な構成

U = \bigcup_n \Big(U_n \setminus \bigcup_{k \le n} \overline{V_k}\Big), \qquad V = \bigcup_n \Big(V_n \setminus \bigcup_{k \le n} \overline{U_k}\Big)

で分離する。可算個の段しかないことが、この削り方を可能にする。

第二段——擬距離の族を作る。各 n と各 B \in \mathcal{B}_n について、正規性とウリゾーンの補題より f_{n,B} \colon X \to [0, 2^{-n}] を、X \setminus B で 0、ある小さい基底元の上で 2^{-n} となるように取る。

そのうえで擬距離を

\rho_n(x,y) = \sum_{B \in \mathcal{B}_n} |f_{n,B}(x) - f_{n,B}(y)|

と定める。和は局所有限性より各点で有限項しかない。ここが可算性の代わりを務める箇所である。

第三段——距離にまとめる。

d(x,y) = \sum_{n=1}^{\infty} \min\big(\rho_n(x,y),\ 2^{-n}\big)

と置く。可算和なので収束する。これが距離であり、もとの位相を与える。位相の一致は第31章★★と同じ二方向の議論による。

証明の構造は第31章とほぼ同じである。違いは「関数が可算個」の代わりに「擬距離が可算個、各擬距離は局所有限な関数族の和」になっていることだけである。局所有限性が、無限個の関数を各点で有限個に落としている。これが第24章の の御利益である。

ビングの距離化定理

X が距離化可能であるための必要十分条件は、X が正則ハウスドルフであって \sigma-離散な基底をもつことである。

離散な族は局所有限だから、 より十分性が従う。必要性は の構成を、離散になるように精密化する。

具体的には、各 n について半径 2^{-n} の球の被覆から、互いに 2^{-n} 以上離れた中心をもつ極大な族を選ぶ（ツォルンの補題）。この族は離散である。n を動かして合併すれば \sigma-離散な基底になる。

パラコンパクト性との関係

距離化可能な空間はパラコンパクトである（スミルノフ–ストーンの定理）。逆に、局所距離化可能なパラコンパクト空間は距離化可能である。

前半が第24章で引用した事実である。証明は の \sigma-離散基底を使って被覆を細分する。距離化定理とパラコンパクト性は、互いに支え合っている。

後半が実用的である。多様体が距離化可能なのは、局所的に \mathbb{R}^n であり、かつパラコンパクト（通常は定義に含める）だからである。

σ-局所有限とσ-離散はなぜ同値になるのか

と は、条件が違うのに同じ結論を与える。離散は局所有限より真に強いのに、なぜか。

族としては違う。離散な族は局所有限だが、逆は成り立たない。\mathbb{R} で \{(n-1,n+1)\}_{n \in \mathbb{Z}} は局所有限だが離散でない（隣り合う区間が重なる）。

基底の存在としては同じ。\sigma-局所有限な基底があれば、\sigma-離散な基底も作れる。したがって二つの定理の条件は同値である。

証明の方針。\sigma-局所有限な基底があれば、 より距離化できる。距離化できれば の必要性の証明で \sigma-離散基底が作れる。距離を経由して往復する。

直接示すには。距離を経由しない証明もある。局所有限な族 \mathcal{A} の各元を「重なりの個数」で分類し、k 個と重なる部分を集めると離散な族になる。局所有限性より、この分類は可算個の段に収まる。

より正確には、\mathcal{A} の有限部分族 \mathcal{F} ごとに

A_{\mathcal{F}} = \bigcap_{A \in \mathcal{F}} A \setminus \bigcup_{A \notin \mathcal{F}} \overline{A}

を考える。同じ大きさの \mathcal{F} についての族は離散になる。ただし \mathcal{A} が非可算のとき、この分類が可算段で済むことには議論が要る。

実用上どちらを使うか。距離を作るには局所有限で足りる（和が各点で有限になればよい）。被覆を細分するには離散のほうが扱いやすい。

第40章で被覆次元 \dim を定義するとき、被覆の重なりの個数を数える。そこでは離散性と局所有限性の区別が本質的になる。次元とは、まさに「いくつまで重なるか」を測る量だからである。

距離化定理の外側——ムーア空間と独立性

ナガタ–スミルノフは必要十分条件を与えた。それで距離化問題は終わったのか。そうではない。

条件が確かめにくい。\sigma-局所有限な基底の存在は、実際の空間について確かめるのが難しい。もっと素朴な条件で距離化を保証したい。この動機から、別種の条件が探された。

ムーア空間。X が発展的であるとは、開被覆の列 \{\mathcal{G}_n\} が存在して、各点 x と各近傍 U について、ある n で \mathcal{G}_n の x を含む元がすべて U に収まることをいう。発展的な正則空間をムーア空間という。

距離空間はムーア空間である（\mathcal{G}_n を半径 2^{-n} の球の族とする）。逆は成り立たない。

正規ムーア空間予想。「正規なムーア空間は距離化可能か」。この問いの答えは集合論の公理系から決まらない。

連続体仮説を仮定すると反例が構成できる（ビング、後にフリードマン Fleissner が精密化）。一方、可測基数の存在を仮定すると予想が成り立つモデルが作れる（ニッケリ Nyikos）。

注目すべきは、予想を証明するには大きい基数が必要だということである。純粋に位相的な問いが、集合論のもっとも強い仮定に結びついている。

集合論的位相空間論。この種の問いを扱う分野を集合論的位相空間論という。第36章のスーリン問題、第37章の積の基数不変量も同じ分野に属する。

問いの形は素朴なのに、答えが公理に依存する——これが第4章★★★で述べた事態の、もっとも豊富な現れ方である。

なぜここで止まるのか。距離化問題が集合論に突き当たったのは、偶然ではない。

距離化とは「空間の構造を可算個の実数で書けるか」という問いである。そして「可算個で足りるか」という問いは、非可算性の構造に直接触れる。

第4章で共終数を導入し、第17章と第26章で反例に使い、ここで距離化問題の限界として現れた。可算と非可算の境界が、位相空間論の主要な問題のほとんどが行き着く場所である。

本書の進み方。第33章で完備距離化を扱い、第34章で総括したあと、第V部で基数不変量と次元論に進む。そこでは非可算性を正面から測る。

そして第VI部からは解析学に移り、可算な操作だけで閉じた世界に入る。第43章で実数を構成し、第52章でボレル集合を作り、第55章で収束定理を証明する——どれも可算性のなかで完結する。第97章でこの対比を地図に載せる。
