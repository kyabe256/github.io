第3章選択公理とその同値物

← 第2章　集合・写像・同値関係 第4章　順序数と基数 →

この章の問い

  • 「各箱から一つずつ選ぶ」という当たり前に見える操作が、なぜ公理を要するのか。
  • ツォルンの補題は、選択公理とどこが同じなのか。
  • 選択公理を認めると、なぜ直観に反する帰結が出てくるのか。
  • 認めない数学は、どこまで進めるのか。

無限個の選択は、有限個の選択と違う

空でない集合が有限個あるとき、それぞれから元を一つずつ取り出せる。これは公理ではなく、定理である。集合が空でないとは「元が存在する」という主張なのだから、一つ取り、二つ取り、と有限回繰り返せばよい。繰り返しの回数が有限であることが効いている。帰納法で書けば、証明は三行で終わる。

では、空でない集合が無限個あるときはどうか。「一つずつ取る」という操作を無限回続けることは、有限回の推論を並べても正当化できない。必要なのは、選び方を一挙に与える写像の存在である。それを要求するのが選択公理である。

選択公理

空でない集合の族 \{A_i\}_{i \in I} が与えられたとき、写像

c \colon I \to \bigcup_{i \in I} A_i \quad\text{で}\quad c(i) \in A_i \ (\forall i \in I)

を満たすものが存在する。この c を選択関数という。

選択公理は「選べる」と主張するだけで、どう選ぶかは教えない。存在は保証されるが、具体物は手に入らない——第1章の図で見た、背理法と構成のあいだの溝が、ここでも開いている。選択公理を使った証明から、具体的な対象を取り出すことは一般にできない。この性質が、後に述べる直観に反する帰結の源になる。

ラッセル Russell が挙げた例が事情を明瞭にする。靴が無限足あるとき、各足から一つずつ選ぶのに公理はいらない——「左足を取る」という規則を書けばよい。だが靴下が無限足あるときは、左右の区別がないので規則が書けない。選択公理は、この「規則が書けない」場合を埋めるためにある。

族が有限のときは不要であり、また各 A_i が自然数の空でない部分集合であるようなときも不要である（最小元を取ればよい）。選択公理が本当に効くのは、選ぶべきものに自然な順序も自然な代表もないときだけである。

順序集合の言葉

同値物を述べるために、順序の言葉を用意する。

集合 P 上の関係 \le が半順序であるとは、反射律（x \le x）、反対称律（x \le y かつ y \le x ならば x = y）、推移律を満たすことをいう。P の任意の二元が比較可能なとき全順序という。

P の部分集合 C が、\le の制限について全順序になるとき C を鎖という。u \in P が C の上界であるとは、すべての x \in C について x \le u となることをいう。m \in P が極大元であるとは、m \le x なる x が m 自身に限ることをいう。

極大元と最大元を混同しないこと。最大元はすべての元より大きいが、極大元は「それより大きいものがない」だけである。比較できない元があってもよい。半順序集合には極大元が複数あってよく、最大元は高々一つしかない。

もう一つ、整列の概念が要る。全順序集合 (W, \le) が整列集合であるとは、W の空でない部分集合がすべて最小元をもつことをいう。自然数全体は整列集合であり、整数全体や実数の区間は整列集合でない。整列集合の上では超限帰納法が使える——それが整列の御利益である（第4章）。

三つの主張が同じものであること

選択公理の同値物

次の三つは、選択公理を除いた集合論の公理系のもとで互いに同値である。

（1）選択公理　空でない集合の族には選択関数が存在する。
（2）ツォルンの補題　半順序集合 P が空でなく、すべての鎖が上界をもつならば、P は極大元をもつ。
（3）整列定理　任意の集合には、それを整列集合にする順序が存在する。

三つが同値であることは、循環に証明するのが手際がよい。（1）から（2）、（2）から（3）、（3）から（1）を示せば、三通りの往復をすべて示したことになる——第1章で述べた環状の手である。ここでは（3）から（1）と、（2）から（3）を示し、もっとも重い（1）から（2）は骨組みだけを述べる。完全な証明は★★に置く。

（3）から（1）。\{A_i\}_{i \in I} を空でない集合の族とする。整列定理により、\bigcup_i A_i に整列順序を一つ入れる。各 A_i は空でない部分集合だから最小元をもつ。c(i) をその最小元と定めれば、これが選択関数である。整列順序が「選ぶ規則」そのものを与えている。

（2）から（3）。集合 X を与える。X の部分集合 A と、A 上の整列順序 \le_A の対 (A, \le_A) 全体を P とする。(A, \le_A) \preceq (B, \le_B) を「A \subseteq B であり、\le_B の A への制限が \le_A に等しく、さらに A が B の始切片である」と定めると、\preceq は半順序になる。(\varnothing, \varnothing) があるので P は空でない。

P の鎖 \mathcal{C} に対しては、台集合の合併と順序の合併をとれば上界が得られる。始切片であるという条件が、合併した順序が再び整列になることを保証している。実際、合併の空でない部分集合 S を取れば、S と交わる鎖の元を一つ選んで、そこでの最小元が S 全体の最小元になる。

よってツォルンの補題より極大元 (M, \le_M) が存在する。もし M \ne X なら、x \in X \setminus M を取り、M \cup \{x\} に x を最大元として付け足した順序を考えると、これは P の元であって (M, \le_M) より真に大きい。極大性に反する。よって M = X であり、X は整列される。

値段——何を受け入れることになるのか

選択公理は、解析学と位相空間論の広い範囲を支えている。ベクトル空間には必ず基底があり、チコノフ Tychonoff の定理が成り立ち、ハーン–バナッハ Hahn–Banach の定理が使える。これらを手放すと、本書の後半はほとんど成立しない。

その一方で、次のようなものも同時に生じる。

ヴィタリ集合

区間 [0, 1] 上で、x \sim y を「x - y が有理数」と定めると同値関係になる。各同値類から代表を一つずつ選んで集めた集合 V を考える。この「選ぶ」に選択公理を使っている。

V は長さをもてない。有理数 q \in [-1, 1] による平行移動 V + q は互いに交わらず、その合併は [-1, 2] に含まれ [0, 1] を含む。もし V に長さ \lambda があれば、可算個の交わらない集合の長さの和として

1 \le \sum_{q} \lambda \le 3

が成り立たねばならない。しかし左辺は \lambda = 0 なら 0、\lambda > 0 なら無限大で、どちらも不等式を満たさない。よって V は測れない。第53章でこの議論を精密に述べる。

より劇的なのがバナッハ–タルスキ Banach–Tarski の逆説である。三次元の球を有限個に分割し、回転と平行移動だけで組み直すと、もとと同じ大きさの球が二つできる。分割の各片は、ヴィタリ集合と同じ理由で測れない。

この逆説は物理的な主張ではない。述べているのは「体積という概念を、すべての部分集合に矛盾なく与えることはできない」ということである。逆説を避ける道は、選択公理を捨てることではなく、測れる集合だけを相手にすることだった。測度論が可測集合の族を限定して出発するのは、この事情による（第52章）。

そして決定的な事実がある。選択公理は、他の公理から証明も反証もできない。ゲーデル Gödel は一九三八年に選択公理が矛盾を生まないことを示し、コーエン Cohen は一九六三年に、選択公理の否定もまた矛盾を生まないことを示した。採用するかどうかは、証明の問題ではなく選択の問題である。本書は採用する。ただし使うたびに断る。

ツォルンの補題の証明と、その使い方

選択公理からツォルンの補題を導く部分は、三つの同値のうちもっとも技術的である。骨組みを述べておく。

方針。P を仮定を満たす半順序集合とし、極大元がないと仮定して矛盾を導く。極大元がなければ、どの元 x にも x < y なる y がある。選択公理により、各元に対してそのような y を一つ選ぶ写像 s が取れる。同様に、各鎖に対してその上界を一つ選ぶ写像も取れる。これで「常に一歩先へ進む規則」が手に入った。

超限的に延ばす。この規則を \varnothing から始めて繰り返し適用し、極限段階では上界を取る。すると、P のなかに順序数で添字づけられた真に増加する列ができる。ところが順序数の全体は集合でないほど大きい。一方この列は P のなかにあるから、単射 \mathrm{Ord} \to P が得られることになり、置換公理に反する。よって極大元が存在する。

この論法は次章の順序数を使うので、厳密な形は第4章の後に読み返すのがよい。順序数を避けて、ブルバキ–ヴィット Bourbaki–Witt の不動点定理を経由する証明もある。そちらは超限帰納法を表に出さずに済むが、代わりに閉包性の議論が込み入る。

実際の使い方。ツォルンの補題を適用するときの手順は、いつも同じ三段である。

第一に、求めたいものの「部分的な答え」全体を半順序集合 P として定める。基底が欲しければ一次独立な部分集合の全体、イデアルが欲しければ真イデアルの全体を取る。

第二に、鎖に上界があることを確かめる。ほとんどの場合、鎖の合併がそのまま上界になる。ここで確かめるべきは「合併が P の元であること」であり、定義に現れる条件が有限的かどうかが分かれ目になる。一次独立性は有限個の元だけに関わる条件なので、合併でも保たれる。

第三に、極大元が求めるものであることを示す。そうでなければ真に大きい元を作れてしまう、という形の背理法になる。

この三段は、第67章のハーン–バナッハの定理でも、線型空間の基底の存在でも、極大イデアルの存在でも、そのまま繰り返される。証明の型として覚えておくと、以降の見通しがよくなる。

弱い選択公理と、位相空間論への跳ね返り

選択公理は一つの主張ではなく、強さの異なる主張の階層をなしている。どれを仮定するかで、成り立つ定理が変わる。

可算選択公理。族の添字集合が可算であるときに限った選択公理である。解析学の基本的な事実の多くは、これだけで足りる。「点列コンパクトならば可算コンパクト」「実数の可算部分集合の上限が列の極限として実現される」などがそうである。前章で触れた「可算個の可算集合の合併は可算」も、これと同値ではないが、これから従う。

従属選択公理。関係 R について、どの x にも xRy なる y があるならば、x_0 R x_1 R x_2 \cdots という列が取れる、という主張である。可算選択公理より真に強い。ベール Baire のカテゴリー定理（第27章）は、従属選択公理と同値である。完備距離空間で可算個の稠密開集合の交叉が稠密であるという、解析学の至るところで使われる定理が、集合論の公理と正確に釣り合っている。

超フィルター補題。「どのフィルターも極大フィルターに拡張できる」という主張で、選択公理より真に弱い。第12章で導入するフィルターの言葉で述べられるこの補題は、チコノフの定理のハウスドルフ空間版と同値である。一方、一般の空間についてのチコノフの定理は完全な選択公理と同値である。分離公理を一段落とすだけで、必要な集合論の強さが変わる——これが第II部と第III部の関係を見るときの、一つの視点になる。

選択公理を否定する世界。ソロヴェイ Solovay は一九七〇年に、従属選択公理は成り立つが実数のすべての部分集合が可測であるようなモデルを構成した（到達不能基数の存在を仮定する）。この世界では、ヴィタリ集合もバナッハ–タルスキの逆説も存在しない。そして解析学の大部分は、ほとんどそのまま通用する。

ただし失われるものもある。この世界では実数の集合に整列順序が入らず、ハーン–バナッハの定理も一般の形では成り立たない。関数解析は、双対空間が十分に大きいことを前提に組み立てられている。第66章から第73章までの議論は、選択公理なしでは骨格を保てない。

本書の立場。以上を踏まえて、本書は選択公理を採用する。ただし、ある定理がどの強さの選択を要するかは、分かる範囲で明記する。それは衒学ではない。どの仮定が本質的かを知ることは、定理の意味を知ることの一部だからである——第1章で述べた「仮定を外すと何が壊れるか」の、もっとも深い層にあたる。

基本
