第VI部　実数と極限

第49章級数と収束判定

← 第48章　微分と平均値の定理 第50章　関数列——何が保存され、何が壊れるか →

この章の問い

  • 無限個を足すとは、どういう約束なのか。
  • 足す順序を変えると和が変わるのは、なぜ起きるのか。
  • 収束判定法はたくさんあるが、根はいくつあるのか。

無限和の約束

級数の収束

数列 (a_n) に対し、部分和 S_N = \sum_{n=1}^{N} a_n を作る。(S_N) が収束するとき、級数 \sum_n a_n は収束するといい、その極限を和とする。

無限和は「足す」という操作ではなく、「部分和の極限」という約束である。だから足し算の法則がそのまま成り立つとは限らない。結合法則は生き残るが、交換法則は条件つきでしか成り立たない（後述）。

\sum_n a_n が収束するなら a_n \to 0。逆は成り立たない。

a_n = S_n - S_{n-1} \to S - S = 0。逆の反例は調和級数 \sum 1/n。

調和級数の発散。\sum_{n=2^k+1}^{2^{k+1}} \frac1n \ge 2^k \cdot \frac{1}{2^{k+1}} = \frac12 なので、部分和はいくらでも大きくなる。

正項級数——単調収束定理だけで足りる

a_n \ge 0 なら部分和は単調増加である。よって第44章の単調収束定理から、収束と有界性が同値になる。

正項級数の判定法

a_n, b_n \ge 0 とする。

（1）比較　a_n \le b_n で \sum b_n 収束なら \sum a_n 収束。
（2）比判定（ダランベール）　\limsup_n \frac{a_{n+1}}{a_n} < 1 なら収束、\liminf_n \frac{a_{n+1}}{a_n} > 1 なら発散。
（3）根判定（コーシー）　\limsup_n a_n^{1/n} < 1 なら収束、>1 なら発散。
（4）積分判定　f が [1,\infty) で正・単調減少なら、\sum_n f(n) と \int_1^\infty f は同時に収束する。

（1）部分和が単調増加で上に有界。。

（2）\limsup \frac{a_{n+1}}{a_n} = r < 1 なら、r < \rho < 1 を取れば、ある N から先 a_{n+1} \le \rho a_n。よって a_n \le a_N \rho^{n-N} で、等比級数と比較。

（3）\limsup a_n^{1/n} = r < 1 なら r<\rho<1 を取って a_n \le \rho^n（ある N から先）。同じく等比級数と比較。

（4）\int_{n}^{n+1} f \le f(n) \le \int_{n-1}^{n} f を足し上げる。

根判定は比判定より強い

第44章の演習で見たとおり \limsup a_n^{1/n} \le \limsup \frac{a_{n+1}}{a_n}。だから比判定で収束が出れば、根判定でも出る。

逆は成り立たない。a_n = 2^{-n+(-1)^n} とすると、比 a_{n+1}/a_n は 1/8 と 2 のあいだを振動するが、a_n^{1/n} \to 1/2。根判定は収束するが、比判定は何も言えない。

それでも比判定がよく使われるのは、階乗や二項係数が現れる級数で比のほうが計算しやすいからである。

絶対収束と条件収束

絶対収束

\sum_n |a_n| が収束するとき、\sum_n a_n は絶対収束するという。収束するが絶対収束しないとき条件収束するという。

絶対収束すれば収束する。

コーシー条件。\left|\sum_{n=m}^{k} a_n\right| \le \sum_{n=m}^{k}|a_n| で、右辺がコーシー条件を満たす。\mathbb{R} の完備性を使っている。

リーマンの再配列定理

\sum_n a_n が条件収束するとき、どの S \in [-\infty,+\infty] についても、適当な置換 \sigma を取れば \sum_n a_{\sigma(n)} = S とできる。

絶対収束するときは、どの置換についても和は変わらない。

a_n^+ = \max(a_n,0)、a_n^- = \max(-a_n,0) とおく。条件収束なら \sum a_n^+ = \sum a_n^- = +\infty である。片方が有限なら、もう片方も有限になり絶対収束してしまうから。

目標 S を取る。正項を S を超えるまで足し、次に負項を S を下回るまで足し、これを繰り返す。どちらも無限に足せるので、いつでも越えられる。

a_n \to 0 だから、越えたときの超過幅は 0 に近づく。よって部分和は S に収束する。

絶対収束の場合。\varepsilon > 0 に対し \sum_{n>N}|a_n|<\varepsilon なる N を取る。置換後に 1,\ldots,N がすべて現れる番号 M を取れば、k \ge M の部分和と \sum a_n の差は \varepsilon 以下。

条件収束する級数の「和」は、足す順序に依存する。つまり集合としての \{a_n\} には、和という量が定まっていない。

第VII部で測度を扱うとき、可算加法性を要求する。その値が順序によらないためには、絶対収束が要る。ルベーグ積分が「絶対可積分」を基本にするのは、この理由による。

冪級数

コーシー–アダマールの公式

冪級数 \sum_n a_n (x-c)^n について

\frac{1}{R} = \limsup_{n} |a_n|^{1/n}

とおくと、|x-c| で絶対収束、|x-c|>R で発散する。さらに 0 なら |x-c|\le r で一様収束する。

根判定（（3））を |a_n(x-c)^n| に適用する。\limsup |a_n(x-c)^n|^{1/n} = |x-c|/R。

一様収束。|x-c|\le r なら |a_n(x-c)^n| \le |a_n| r^n で、右辺の級数は収束する。定数列で押さえるこの手法をワイエルシュトラスの M 判定法という。

ここで第44章の上極限が効いている。|a_n|^{1/n} は収束しなくてよい。極限が存在しなくても収束半径は定まる——これが上極限を用意した理由である。

収束円周 |x-c|=R での挙動は、公式からは何も出ない。\sum x^n、\sum x^n/n、\sum x^n/n^2 はどれも R=1 だが、境界での様子が違う。

条件収束する級数を扱う道具

絶対収束しない級数には、比較判定が使えない。別の道具が要る。

交代級数判定法（ライプニッツ）。b_n \ge 0 が単調減少で b_n \to 0 なら \sum (-1)^n b_n は収束し、部分和の誤差は次の項で押さえられる。

証明。偶数番の部分和は単調減少、奇数番は単調増加で、互いに挟み合う。区間縮小原理（第43章★★）そのものである。

アーベルの総和法。A_N = \sum_{n\le N} a_n とおくと

\sum_{n=m}^{k} a_n b_n = A_k b_k - A_{m-1}b_m - \sum_{n=m}^{k-1} A_n (b_{n+1}-b_n)

これは部分積分の離散版である。和の一方を「積分」し、他方を「微分」している。

ディリクレの判定法。(A_N) が有界で b_n \downarrow 0 なら \sum a_n b_n は収束する。上の式で A_n を有界性で押さえ、\sum|b_{n+1}-b_n| = b_m（単調だから）を使う。

応用。\sum \frac{\sin n\theta}{n}（\theta \ne 2k\pi）は収束する。\sum_{n\le N}\sin n\theta が有界だから。これは第80章のフーリエ級数で本質的に効く。

アーベルの定理。\sum a_n が収束するなら \lim_{x\to 1^-}\sum a_n x^n = \sum a_n。境界での値が、内部からの極限として取れる。

逆は成り立たない（\sum(-1)^n は x\to1^- で 1/2 に近づくが発散する）。タウバーの定理は、逆が成り立つ追加条件（na_n \to 0 など）を与える。

まとめ。条件収束の道具はすべて「部分和を有界に保ちながら、係数を単調に減らす」という形をしている。絶対値で評価しないところが、正項級数と根本的に違う。

無条件収束・総和可能性・そして発散級数

無条件収束。どの置換についても収束して同じ和になることを無条件収束という。 は、\mathbb{R} では無条件収束と絶対収束が同値であることを述べている。

高次元では変わる。レヴィ–シュタイニッツの定理——\mathbb{R}^d の級数が収束するとき、再配列で得られる和の全体はアフィン部分空間をなす。一次元では「一点か直線全体」で、これがリーマンの定理にあたる。

無限次元ではさらに変わる。ドヴォレツキー–ロジャースの定理——無限次元バナッハ空間には、無条件収束するが絶対収束しない級数がつねに存在する。

逆に、無条件収束と絶対収束が一致するのは有限次元の場合に限る。これは第63章で扱う「バナッハ空間の有限次元性の特徴づけ」の一つである。

総和法。発散する級数にも「和」を与えたい場面がある。

チェザロ総和——部分和の平均 \frac{1}{N}\sum_{k\le N} S_k の極限。\sum(-1)^n に 1/2 を与える。

アーベル総和——\lim_{x\to1^-}\sum a_n x^n。チェザロ総和より強い（チェザロ総和可能ならアーベル総和可能で値も同じ）。

これらは正則である——収束する級数には、もとの和を与える。第81章のフェイエールの定理は、フーリエ級数のチェザロ平均が一様収束することを示す。発散しうる級数を、平均で救う技法である。

バナッハ極限との関係。第44章★★★で触れたバナッハ極限 \Lambda は、あらゆる有界数列に「極限」を与える。部分和の列に適用すれば、どんな有界な部分和をもつ級数にも和が定まる。

ただし線型性しか保証されず、積とは噛み合わない。そしてハーン–バナッハの定理（第67章）すなわち選択公理に依存する。「すべての級数に和を与える」ことは、具体的な構成を諦める代償で買える。

オイラーの流儀。1+2+4+8+\cdots = -1 のような等式は、\frac{1}{1-x} の x=2 での「値」として意味づけられる。解析接続（第91章）が、形式的な計算に正当な意味を与える。

演習

基本
  1. \sum 1/n^2 が収束することを積分判定で示せ。
  2. \sum n!/n^n の収束を比判定で調べよ。
  3. \sum x^n/n! の収束半径を求めよ。
  4. \sum (-1)^n/n が条件収束することを示せ。
証明
  1. （4）の積分判定を、細部まで示せ。（20点）
  2. の条件収束の場合を、S=+\infty についても示せ。（30点）
  3. ディリクレの判定法を、アーベルの総和法から導け。（30点）
  4. 冪級数が収束円の内部で項別微分できることを、第48章★★を使って示せ。（30点）
