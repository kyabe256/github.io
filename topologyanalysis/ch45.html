第VI部　実数と極限

第45章極限——ε-δ はなぜこの形か

← 第44章　上限・下限と単調列 第46章　連続関数——中間値と最大値 →

この章の問い

  • なぜ極限の定義は、あのわかりにくい形をしているのか。
  • 量化子の順序を入れ替えると、何が変わるのか。
  • 位相の言葉（第8章）と、どこで同じでどこで違うのか。

「近づく」を有限の言葉で書く

x が a に近づくとき f(x) が L に近づく——この文には「近づく」という動きの言葉が二回出てくる。動きを避けて、静止した言葉で書き直したい。

どうするか。「どんなに厳しい精度を要求されても、それに応じた近さを用意できる」と言い換える。精度を \varepsilon、近さを \delta と書けば、定義ができあがる。

関数の極限

f を a のある除外近傍で定義された関数とする。\lim_{x \to a} f(x) = L とは、

\forall \varepsilon > 0\ \exists \delta > 0\ \forall x\ \big(0 < |x-a| < \delta \implies |f(x)-L| < \varepsilon\big)

が成り立つことをいう。

三つの量化子の順序が本質である。\varepsilon が先、\delta が後。\delta は \varepsilon に依存してよいが、x には依存できない。この依存関係が、次章以降の「一様」という語の正体になる。

0 < |x-a| と書くのは、x = a での値を問わないためである。極限は、その点を除いた周りだけで決まる。

数列の極限

\lim_n x_n = L とは、

\forall \varepsilon > 0\ \exists N \in \mathbb{N}\ \forall n \ge N\ \big(|x_n - L| < \varepsilon\big)

が成り立つことをいう。

量化子を入れ替えると何が起きるか

順序を変えた四つの文

（甲）\forall \varepsilon\ \exists \delta\ \forall x。これが極限の定義である。

（乙）\exists \delta\ \forall \varepsilon\ \forall x。一つの \delta がすべての \varepsilon に効く——これは f が a の近くで定数 L であることを意味する。

（丙）\forall \varepsilon\ \forall x\ \exists \delta。\delta が x に依存してよい——これは何も言っていない（各 x ごとに \delta を |x-a| より小さく取れば、含意の前提が偽になる）。

（丁）\exists \varepsilon\ \forall \delta\ \exists x。これは「（甲）の否定」の形である。

量化子の順序は、定義の内容そのものである。

否定の作り方

\lim_{x\to a} f(x) = L でないとは、

\exists \varepsilon > 0\ \forall \delta > 0\ \exists x\ \big(0 < |x-a| < \delta \ \text{かつ}\ |f(x)-L| \ge \varepsilon\big)

である。\forall と \exists が入れ替わり、含意が「前提かつ結論の否定」になる。第1章で述べた「否定は機械的に作れる」が、ここで実際に効く。

位相の言葉との対応

f \colon \mathbb{R} \to \mathbb{R} について、次は同値である。

（1）どの a でも \lim_{x \to a} f(x) = f(a)（\varepsilon-\delta の意味で連続）。
（2）どの開集合 V についても f^{-1}(V) が開（第8章の意味で連続）。
（3）どの点 a と a に収束する数列 (x_n) についても f(x_n) \to f(a)。

（1）から（2）。V を開、a \in f^{-1}(V) とする。B(f(a),\varepsilon) \subseteq V なる \varepsilon を取り、対応する \delta を取れば B(a,\delta) \subseteq f^{-1}(V)。

（2）から（3）。x_n \to a、V を f(a) の近傍とすると f^{-1}(V) は a の近傍なので、ある N から先 x_n \in f^{-1}(V)。

（3）から（1）。対偶を示す。（1）が破れるなら、ある \varepsilon についてどの \delta = 1/n でも |x_n - a| < 1/n かつ |f(x_n)-f(a)| \ge \varepsilon なる x_n がある。この (x_n) が（3）の反例になる。

（3）から（1）の議論で、各 n について x_n を「選んで」いる。可算選択公理を使っている。第3章で述べたとおり、この程度の選択は解析のいたるところに現れる。

そして（2）と（3）が同値なのは \mathbb{R} が第一可算だからである。一般の位相空間では、点列では足りない（第12章）。

極限の演算

\lim_{x\to a} f(x) = L、\lim_{x\to a} g(x) = M とすると、

\lim_{x \to a}(f+g) = L+M, \qquad \lim_{x\to a}(fg) = LM, \qquad \lim_{x\to a} \frac{f}{g} = \frac{L}{M}\ (M \ne 0)

和。\varepsilon > 0 に対し、|f-L| < \varepsilon/2 となる \delta_1 と |g-M| < \varepsilon/2 となる \delta_2 を取り、\delta = \min(\delta_1,\delta_2)。

積。|fg - LM| \le |f||g-M| + |M||f-L| と分ける。|f| を押さえるために、まず |f - L| < 1 となる \delta_0 を取って |f| < |L|+1 としておく。「先に粗く押さえてから、細かく詰める」——積の評価はつねにこの形になる。

商。|1/g - 1/M| = |g-M|/(|g||M|) で、|g| > |M|/2 を先に確保する。

片側極限・無限大・そして定義の統一

極限には変種が多い。だが形はすべて同じである。「精度」と「近さ」を何で測るかだけが違う。

片側極限。\lim_{x \to a^+} f(x) = L は 0 < x - a < \delta と書き換えるだけ。\lim_{x\to a} が存在することと、両側の片側極限が存在して一致することは同値である。

無限大への極限。\lim_{x \to \infty} f(x) = L は、\delta の代わりに M を使う。

\forall \varepsilon > 0\ \exists M\ \forall x > M\ \big(|f(x)-L| < \varepsilon\big)

無限大に発散。\lim_{x\to a} f(x) = +\infty は、\varepsilon の代わりに K を使う。

\forall K\ \exists \delta > 0\ \forall x\ \big(0<|x-a|<\delta \implies f(x) > K\big)

統一。すべて「a の近傍系」と「L の近傍系」で書ける。\infty を一点として付け加え、\{\, x \mid x > M \,\} をその近傍とすればよい。

これが第23章のコンパクト化である。\mathbb{R} に二点 \pm\infty を足した [-\infty,+\infty] は、[0,1] と同相なコンパクト空間になる。そこでは、六種類の極限がすべて一つの定義に統一される。

ネットで書くと。第12章のネットを使えば、x \to a も n \to \infty も同じ記号で書ける。方向づけられた集合を「a の除外近傍を逆包含で順序づけたもの」と取ればよい。

解析の「極限」は、位相の「ネットの収束」の特別な場合である。ただし実数では第一可算性のおかげで、数列だけで足りる。

合成の極限。注意が要る。\lim_{x\to a} g(x) = b かつ \lim_{y \to b} f(y) = L でも、\lim_{x\to a} f(g(x)) = L とは限らない。g が a の近くで値 b を取ってしまうと、f の b での値が効いてくるからである。f が b で連続なら問題ない。

無限小と、ε-δ が勝った理由

\varepsilon-\delta は、一九世紀にコーシーとワイエルシュトラスによって整えられた。それ以前は無限小で議論していた。なぜ置き換わったのか。

無限小の困難。ライプニッツの dx は「0 ではないが、どの正の数より小さい」量だった。アルキメデス性（）と矛盾する。\mathbb{R} のなかには、そんな数はない。

計算は正しい答えを出したが、「なぜ正しいか」を説明できなかった。バークリーの批判（「消え去った量の亡霊」）はこの点を突いている。

ロビンソンの解決。一九六〇年、ロビンソンは超実数体 {}^{*}\mathbb{R}（第43章★★★）を使って無限小を正当化した。{}^{*}\mathbb{R} はアルキメデス的でない順序体で、\mathbb{R} を真に含む。

そこでは f が a で連続であることが、x \approx a \implies f(x) \approx f(a)（\approx は差が無限小）と書ける。量化子が三つから一つに減る。

それでも標準的にならなかった理由。三つある。

第一に、構成に超フィルターが要る（第12章・第3章）。選択公理が本質的で、具体的な構成がない。

第二に、移行原理の適用範囲を見極めるのに、論理の訓練が要る。「一階で書ける性質」という制限を扱い損ねると誤りが出る。

第三に、位相空間への一般化が自然でない。\varepsilon-\delta は第8章の開集合の言葉にそのまま乗る。距離のない空間でも使えるのは、こちらだけである。

構成的解析。もう一つの方向がある。\varepsilon に対する \delta を具体的に構成する関数として要求する立場である。\delta(\varepsilon) を計算できることを求めるので、排中律の使用が制限される。

この立場では \lim の存在証明が、そのまま数値計算の手続きになる。計算機による証明支援と相性がよく、近年また注目されている。

同じ「極限」に、三つの定式化がある。どれを採るかは、何を説明したいかで決まる。本書は \varepsilon-\delta を採る——位相へつながるからである。

演習

基本
  1. \lim_{x\to 2}(3x-1) = 5 を定義に従って示せ（\delta を具体的に書くこと）。
  2. \lim_{x\to 0} \sin(1/x) が存在しないことを示せ。
  3. \lim_n x_n = L の否定を書き下せ。
  4. \lim_{x\to a} f(x) = L かつ \lim_{x\to a} f(x) = L' なら L = L' を示せ。
証明
  1. の積の場合を、細部まで書け。（20点）
  2. （3）から（1）を、可算選択公理をどこで使うか明示して示せ。（25点）
  3. f(x) = x^2 が各点で連続であることを示し、\delta が a に依存することを確かめよ。（20点）
  4. 合成の極限が成り立たない例を作り、f が b で連続なら成り立つことを示せ。（30点）
発展
  1. [-\infty,+\infty] に位相を入れ、六種類の極限が一つの定義に統一されることを示せ。（40点）
  2. ディリクレ関数（有理数で 1、無理数で 0）がどの点でも連続でないことを、定義に従って示せ。（25点）
  3. f(x) = x \cdot \mathbf{1}_{\mathbb{Q}}(x) が x=0 でのみ連続であることを示せ。（30点）
