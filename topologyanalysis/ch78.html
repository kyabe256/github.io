第X部　スペクトル理論

第78章非有界作用素と自己共役拡大

← 第77章　一般のスペクトル定理と作用素値測度 第79章　Banach環とGelfand理論 →

この章の問い

  • 微分作用素は有界でない。それでもスペクトル理論は使えるのか。
  • 「対称」と「自己共役」は、なぜ非有界では別のことになるのか。
  • 自己共役な延長は、いくつあるのか。

定義域を捨てられない

本書でここまで扱ってきた作用素は、すべて H 全体で定義された有界作用素だった。ところが解析学で実際に現れる作用素の多くは有界でない。微分作用素 d/dx は L^2 上で有界でない：f_n(x)=e^{inx} を考えれば \|f_n\| は一定なのに \|f_n'\|=n\|f_n\| である。

有界でないなら H 全体では定義できない。したがって非有界作用素の理論では、作用素は「写像」ではなく「定義域と写像の組」である。同じ式で与えられていても定義域が違えば別の作用素であり、この区別が理論の中心になる。

ヘリンガー–テプリッツの定理

T:H\to H が H 全体で定義され、すべての x,y\in H について (Tx,y)=(x,Ty) をみたすなら、T は有界である。

各 y\in H について \varphi_y(x)=(Tx,y)=(x,Ty) は有界線形汎関数で \|\varphi_y\|=\|Ty\|。\|x\|\le1 なる x の族 \{\varphi_y\mapsto\varphi_y(x)\} を H 上の汎関数の族と見ると、各 y について

\sup_{\|x\|\le1}|(x,Ty)| = \|Ty\| < \infty

すなわち各点で有界。一様有界性の原理（）より族は一様有界、つまり \sup_{\|x\|\le1}\|Tx\| < \infty。

この定理は、非有界作用素の理論が「定義域を真部分空間にとる」以外の道をもたないことを示している。定義域を全体にした瞬間に、対称性は有界性を強制してしまう。閉グラフ定理（）を使った別証明もある。

非有界作用素・閉作用素・随伴

D(T)\subset H を稠密な部分空間、T:D(T)\to H を線形写像とする（稠密に定義された作用素）。

（1）グラフ \Gamma(T)=\{(x,Tx):x\in D(T)\} が H\times H で閉のとき T は閉作用素。
（2）\Gamma(T) の閉包がまたある作用素のグラフになるとき、その作用素を閉包 \bar T という。
（3）随伴 T^* を次で定める：

D(T^*) = \{\, y\in H \mid \exists z,\ (Tx,y)=(x,z)\ (\forall x\in D(T)) \,\}, \qquad T^*y=z

D(T) が稠密だから z は一意である。
（4）T\subset T^*（すなわち D(T)\subset D(T^*) かつ T^*|_{D(T)}=T）のとき T は対称。
（5）T=T^*（定義域も含めて一致）のとき T は自己共役。
（6）対称で、閉包が自己共役になるとき本質的自己共役。

対称と自己共役の隔たり

対称性は (Tx,y)=(x,Ty) を D(T) の中だけで要求する。随伴の定義域は D(T) より広くなりうる——対称作用素では常に D(T)\subset D(T^*) であり、この包含が真になることが普通に起こる。

自己共役性は「定義域が広すぎも狭すぎもしない」という、絶妙な釣り合いの要求である。そしてスペクトル定理が成り立つのは自己共役のときだけで、対称では足りない。この一点が本章のすべての動機である。

T が対称なら T\subset\bar T\subset T^* の三段階があり、本質的自己共役とは中央が右端に一致することである。

同じ式、違う作用素

運動量作用素の三つの顔

H=L^2[0,1]、Tf=-if' を三通りの定義域で考える。部分積分から

(Tf,g)-(f,Tg) = -i\big[f\bar g\big]_0^1 = -i\big(f(1)\overline{g(1)}-f(0)\overline{g(0)}\big)

対称性は、この境界項が消えるかどうかで決まる。

（1）D(T_0)=\{f\in H^1 : f(0)=f(1)=0\}。境界項は消えるので T_0 は対称。しかし随伴の定義域は H^1 全体（g に条件が要らない）で、D(T_0)\subsetneq D(T_0^*)。対称だが自己共役でない。

（2）D(T_\theta)=\{f\in H^1 : f(1)=e^{i\theta}f(0)\}（\theta\in[0,2\pi)）。境界項は |e^{i\theta}|=1 より消え、随伴の定義域も同じ条件になる。各 \theta について自己共役で、固有値は 2\pi n+\theta（n\in\mathbb{Z}）、固有関数は e^{i(2\pi n+\theta)x}。

（3）D(T_1)=H^1[0,1]（条件なし）。境界項は消えないので対称でさえない。実際 T_1=T_0^* で、T_1^*=T_0。

同じ微分作用素が、境界条件によって「対称だが自己共役でない」「自己共役」「対称でない」に分かれる。そして（2）の自己共役な延長は \theta の分だけ連続無限にあり、スペクトルは \theta ごとに違う。物理的には \theta が「環の周りの磁束」に対応する。

自己共役な非有界作用素の見本

（1）掛け算作用素。\varphi を実数値可測関数（有界でなくてよい）、D(M_\varphi)=\{f : \varphi f\in L^2\}。これは自己共役で、スペクトルは \varphi の本質的値域（非有界なら非有界な閉集合）。第77章の掛け算作用素モデルは、この形で非有界の場合にも成り立つ。

（2）全直線上の運動量。H=L^2(\mathbb{R})、Pf=-if'、D(P)=H^1(\mathbb{R})。フーリエ変換（第85章）により \xi の掛け算に同値で、自己共役。スペクトルは \mathbb{R} 全体、純絶対連続で固有値をもたない。境界がないので境界条件の自由度も消えている。

（3）ラプラシアン。-\Delta は C_c^\infty(\mathbb{R}^n) 上で対称、その閉包は H^2(\mathbb{R}^n) を定義域として自己共役（本質的自己共役）。有界領域では境界条件（ディリクレ・ノイマン・混合）ごとに別の自己共役作用素になり、スペクトルも異なる。

（4）調和振動子。H=-\tfrac{d^2}{dx^2}+x^2 は L^2(\mathbb{R}) 上で本質的自己共役、固有値は 2n+1、固有関数はエルミート関数。固有関数が正規直交基底をなす（純点スペクトル）非有界作用素の例である。

欠損指数と自己共役拡大

欠損指数

T を閉対称作用素とする。

K_\pm = \ker(T^*\mp iI) = \big(\mathrm{ran}(T\pm iI)\big)^\perp

の次元 n_\pm=\dim K_\pm を欠損指数という。

フォン・ノイマンの拡大定理

T を閉対称作用素とする。

（1）n_+=n_-=0 ならば T は自己共役（拡大は自分自身のみ）。
（2）n_+=n_-=n < \infty（または一般に n_+=n_-）ならば、自己共役拡大は K_+ から K_- へのユニタリ写像と一対一に対応する。n < \infty のときその族は n^2 次元のパラメータをもつ。
（3）n_+\ne n_- ならば自己共役拡大は一つも存在しない。
（4）T の定義域は D(T^*)=D(T)\oplus K_+\oplus K_-（直和、内積 (x,y)+(T^*x,T^*y) について直交）をみたす。

ケーリー変換に移す。T が対称なら x\in D(T) について \|(T\pm i)x\|^2=\|Tx\|^2+\|x\|^2（交叉項は (Tx,x) が実なので消える）。よって T\pm i は単射で、T が閉なら値域も閉である。そこで

V = (T-i)(T+i)^{-1} : \mathrm{ran}(T+i) \longrightarrow \mathrm{ran}(T-i)

は等距離（上の等式から両辺のノルムが等しい）。V を T のケーリー変換という。逆に V が与えられれば T=i(I+V)(I-V)^{-1} で復元できる。

拡大の対応。T の対称な拡大は、V の等距離な拡大に対応する。T が自己共役であることは、V がユニタリ（すなわち \mathrm{ran}(T+i)=\mathrm{ran}(T-i)=H）であることと同値。したがって V を \mathrm{ran}(T+i)^\perp=K_+ から \mathrm{ran}(T-i)^\perp=K_- へのユニタリで継ぎ足すしかなく、それができるのは n_+=n_- のときに限る。継ぎ足し方の自由度がそのまま拡大の自由度である。

n < \infty のとき K_+ から K_- へのユニタリ写像全体は n 次ユニタリ群と同一視でき、その実次元は n^2 である。

欠損指数を数える

（1）L^2[0,1] 上の T_0f=-if'（f(0)=f(1)=0）。T_0^*g=\pm ig すなわち -ig'=\pm ig の解は g(x)=e^{\mp x}。どちらも H^1[0,1] に属するので n_+=n_-=1。自己共役拡大は 1 次ユニタリ群、つまり e^{i\theta} の 1 パラメータ族——（2）の T_\theta がそれである。

（2）L^2[0,\infty) 上の Tf=-if'（f(0)=0）。-ig'=ig の解 e^{-x} は L^2 に属するが、-ig'=-ig の解 e^{x} は属さない。n_+=1、n_-=0。自己共役拡大は存在しない——半直線上に「運動量」は定義できない。

（3）L^2(\mathbb{R}) 上の Pf=-if'（C_c^\infty 上）。e^{\pm x} はどちらも L^2(\mathbb{R}) に属さないので n_+=n_-=0。本質的自己共役で、延長の選択肢がない。

（4）-\Delta を \mathbb{R}^3\setminus\{0\} 上の C_c^\infty で考えると、n_\pm=0（三次元では一点は「見えない」）。ところが -\Delta-c/|x|^2 は c が大きいと n_\pm=1 になり、拡大の選択が物理的な意味をもつ——境界条件が点での相互作用を記述する。

非有界作用素の落とし穴

（1）対称なのにスペクトルが複素平面全体。（1）の T_0 について、任意の \lambda\in\mathbb{C} は T_0 の意味で「スペクトル」に属する（T_0-\lambda は全射でない）。対称性は、スペクトルを実軸に押し込めない。押し込めるのは自己共役性だけである。

（2）和の定義域が空になりうる。非有界作用素 A,B について D(A)\cap D(B)=\{0\} となる例がある。このとき A+B は稠密に定義された作用素ですらない。したがって「非有界作用素の代数」は素朴には構成できない。

（3）可換性の定義が微妙。AB=BA を定義域まで含めて要求すると強すぎる。正しい定義は「スペクトル測度が可換」であり、ネルソンは AB=BA が稠密な芯の上で成り立つのにスペクトル測度が可換でない例を与えた。量子力学の不確定性関係が「交換子」で語られるとき、この微妙さが背後にある。

スペクトル定理は非有界でも成り立つ

T が（非有界でも）自己共役なら、\mathbb{R} 上の作用素値測度 E がただ一つあって

T = \int_{\mathbb{R}} \lambda\,dE(\lambda), \qquad D(T) = \Big\{ x : \int \lambda^2\,dE_{x,x}(\lambda) < \infty \Big\}

定義域が積分の収束条件として自然に出てくるのが、非有界の場合の特徴である。証明はケーリー変換で有界ユニタリに移し、第77章の定理を適用して戻す。

スペクトルが実であること、剰余スペクトルがないこと、掛け算作用素モデルが成り立つこと——第75章と第77章の結論はすべて非有界でも成り立つ。ただし「自己共役」を正しい意味で要求したときに限る。

★★ 学部後半——ストーンの定理と二次形式による構成

ストーンの定理（非有界版）。強連続なユニタリ一径数群 U(t) に対し、

D(A) = \Big\{ x : \lim_{t\to0}\frac{U(t)x-x}{t} \text{ が存在} \Big\}, \qquad Ax = \frac{1}{i}\lim_{t\to0}\frac{U(t)x-x}{t}

と定めると A は自己共役で U(t)=e^{itA}。逆も成り立つ。したがって「時間発展」と「自己共役作用素」は同じものである。量子力学でハミルトニアンに自己共役性を要求する理由は、ユニタリな時間発展（確率の保存）がそれと同値だという、この定理にある。

D(A) が稠密であることの証明が面白い。x\in H と f\in C_c^\infty(\mathbb{R}) について x_f=\int f(t)U(t)x\,dt と置くと x_f\in D(A) で、f を \delta に近づければ x_f\to x。平滑化（第62章 ）と同じ手口が、作用素の定義域に対して使われている。

フリードリクスの拡大。T が対称で下に有界（(Tx,x)\ge c\|x\|^2）なら、自己共役拡大が必ず存在し、しかも下からの評価を保つもののうち最大のものが一意に定まる。構成は二次形式を使う：a(x,y)=(Tx,y)+(1-c)(x,y) を内積として D(T) を完備化し、その完備化を新しい定義域にとる。ラプラシアンのディリクレ境界条件は、この構成そのものである——H_0^1 が完備化として現れ、第88章のソボレフ空間論と直結する。

加藤–レリッヒの定理。A を自己共役、B を対称で D(B)\supset D(A)、かつ

\|Bx\| \le a\|Ax\| + b\|x\|, \qquad a < 1

なら A+B は D(A) 上で自己共役。「小さい摂動は自己共役性を壊さない」という定理である。これにより -\Delta+V が自己共役であることが、V について広いクラスで保証される——水素原子の V=-1/|x| がその範囲に入ることが、量子力学の数学的基礎づけの出発点になった（加藤、1951年）。

仮定を外すと。下に有界でない対称作用素には、自己共役拡大が一つもない場合がある（（2））。また、本質的自己共役でない作用素では「どの拡大を選ぶか」が物理の問題になり、数学だけでは決まらない。これは病理ではなく、境界での物理を指定せよという要求である。

★★★ 大学院——芯・半群・作用素の和

本質的自己共役性の判定。ネルソンの解析ベクトル定理：T が対称で、D(T) の中に T の解析ベクトル（\sum\|T^nx\|t^n/n! がある t>0 で収束する x）の全体が稠密なら、T は本質的自己共役。判定を「べき級数の収束」に落とすのが要点である。多項式的に増大するポテンシャルへの応用が広い。

半群とヒレ–吉田。自己共役性を捨て、e^{-tA}（t\ge0）という半群だけを考えると、ヒレ–吉田の定理が生成子を特徴づける：A が縮小半群を生成することは、A が閉で稠密に定義され、(0,\infty)\subset\rho(-A) かつ \|(\lambda+A)^{-1}\|\le1/\lambda と同値。熱方程式（A=-\Delta）のように時間の向きが一方向な現象は、群ではなく半群で記述される。ルーマー–フィリップスの定理は、これを散逸性という条件に言い換える。

トロッター積公式。A,B が自己共役で A+B も自己共役なら

e^{it(A+B)} = \lim_{n\to\infty}\big(e^{itA/n}e^{itB/n}\big)^n

（強収束）。これがファインマンの経路積分の数学的な出発点である——運動エネルギーとポテンシャルを交互に短時間作用させ、その極限をとる。ウィック回転して虚時間にすると、e^{-t(-\Delta+V)} についてファインマン–カッツの公式

\big(e^{-t(-\Delta+V)}f\big)(x) = \mathbb{E}_x\Big[ e^{-\int_0^tV(B_s)\,ds}f(B_t) \Big]

が成り立ち、ブラウン運動の期待値としてスペクトルの情報が読める。作用素論と確率論が同じ対象の二つの顔になる。

未解決に近い問い。非可換な自己共役作用素の和 A+B のスペクトルを、\sigma(A) と \sigma(B) から決める問題は、有限次元でもホーンの予想（2000年頃に解決、シューベルト算法と表現論を経由する）という深い問題だった。無限次元での対応物は、自由確率論における自由畳み込みとして部分的に理解されている。一方で、多体シュレーディンガー作用素の本質的スペクトルの下端（基底状態エネルギー）の漸近挙動は、物質の安定性という物理的な問いとして、いまも研究の対象である。
