第83章発散する例と、Carlesonの定理

この章の問い

  • 連続関数のフーリエ級数が発散する例は、どう作るのか。
  • 可積分関数では、どこまで悪くなりうるのか。
  • 二乗可積分なら救われる——それはなぜ、そして何が難しいのか。

発散する例を作る

第81章で、ディリクレ核のルベーグ定数が対数的に発散することを見た。ここからは、二通りの道で反例に到達できる。一つは一様有界性の原理による存在証明（非構成的）、もう一つは実際に関数を組み立てる構成である。両方を見ることで、「発散が起こる仕組み」が具体的に分かる。

デュ・ボワ–レーモンの定理

f\in C(\mathbb{T}) で、\sup_N|S_Nf(0)|=\infty となるものが存在する。さらに、そのような f の全体は C(\mathbb{T}) の余第一類集合である（つまり、発散する関数のほうが「ほとんど」である）。

より強く、任意の第一類集合 E\subset\mathbb{T} に対し、E のすべての点で部分和が発散する連続関数が存在する。

非構成的な証明。\Lambda_N(f)=S_Nf(0)=\frac{1}{2\pi}\int f(-t)D_N(t)dt は C(\mathbb{T}) 上の有界線形汎関数で、そのノルムは \|D_N\|_1（正確には D_N の符号に合わせた関数で近似的に達成される）。より \|\Lambda_N\|\to\infty。一様有界性の原理（）により、\sup_N|\Lambda_N(f)|=\infty となる f が存在する。

さらに、そのような f の全体は \bigcap_M\bigcup_N\{f:|\Lambda_Nf|>M\} という稠密 G_\delta 集合を含む。ベールのカテゴリー定理（第27章）により、これは余第一類である——発散は例外でなく典型なのである。

構成的な証明。共役ディリクレ核を使って、N 次の三角多項式 p_N で \|p_N\|_\infty\le1、|S_{M}p_N(0)|\ge c\log N（ある M\le N）となるものを作る。具体的には

\tilde D_N(\theta) = \sum_{k=1}^{N}\frac{\sin(k\theta)}{k}

の部分和を組み合わせる（この級数の部分和は一様有界だが、原点近くでのずれが \log N の程度に育つ）。次に指数を急速に増やして

f(\theta) = \sum_{j=1}^{\infty} \frac{1}{j^2}\, p_{N_j}(\theta)\,e^{i m_j\theta}, \qquad N_j = 2^{2^j},\ m_j \gg N_{j-1}

と置く。各塊の周波数帯が重ならないように m_j をとるのが要点である。\sum1/j^2 < \infty なので f は一様収束して連続だが、j 番目の塊を見たときの部分和は \frac{1}{j^2}\cdot c\log N_j\approx\frac{c\,2^j}{j^2}\to\infty。

仕掛けは「大きさは小さいが部分和が大きい塊」を、周波数を離しながら重ねることである。この「周波数帯を分離して重ねる」手口は、フーリエ解析の反例構成のほぼすべてに現れる。

コルモゴロフの例

f\in L^1(\mathbb{T}) で、すべての点で \sup_N|S_Nf(\theta)|=\infty となるものが存在する（コルモゴロフ、1926年。1923年にはほとんどいたるところ発散する例）。

構成の核は、正の測度を一点に集めすぎない核を作ることである。n_1 < \cdots < n_k を適当に選び、

g_k = \frac{1}{k}\sum_{j=1}^{k} \varphi_{\varepsilon}(\theta-a_j), \qquad \varphi_\varepsilon = \frac{1}{2\varepsilon}\chi_{[-\varepsilon,\varepsilon]}

という「質量を k 個の点 a_1,\dots,a_k にばらまいた L^1 関数」を作ると、\|g_k\|_1=1 のまま、どの点から見てもどれかの山が「近すぎる」状態になり、部分和が \log k の程度に膨らむ。これを重ねる。

結論：L^1 では各点収束は完全に破綻する。にもかかわらずフェイェール平均はほとんどいたるところ f に収束する（ルベーグの微分定理から）。ここでも、悪いのは部分和という足し方である。

カールソンの定理

カールソン–ハントの定理

（1）f\in L^2(\mathbb{T}) ならば S_Nf(\theta)\to f(\theta) がほとんどすべての \theta で成り立つ（カールソン、1966年）。
（2）より一般に f\in L^p(\mathbb{T})（1 < p\le\infty）でも同様（ハント、1968年）。
（3）実質的な内容は最大作用素の有界性である：

S^*f(\theta) = \sup_N |S_Nf(\theta)| \qquad \text{について} \qquad \|S^*f\|_{L^p} \le C_p\|f\|_{L^p} \quad (1 < p < \infty)

なぜ最大作用素なのか

ほとんどいたるところの収束を示す標準的な手順は、次の三段である。

（1）稠密な部分集合で収束を示す。三角多項式では S_Nf=f（N が十分大きいとき）なので自明。
（2）最大作用素の弱型評価を示す。|\{S^*f>\lambda\}|\le C\|f\|_p^p/\lambda^p。
（3）両者を合わせる。f=g+h（g は三角多項式、\|h\|_p 小）と分け、

\limsup_N|S_Nf-f| \le \limsup_N|S_Nh| + |h| \le S^*h + |h|

右辺は（2）により、大きな値をとる集合の測度が小さい。\varepsilon\to0 として結論を得る。

この手順は、ルベーグの微分定理（）の証明とまったく同じ骨格である——そこでは最大作用素がハーディ–リトルウッドのもので、ヴィタリの被覆補題（）から弱型評価が出た。カールソンの定理が難しいのは、S^* の弱型評価が被覆論では出ないからである。

何が難しいのか

ハーディ–リトルウッドの最大作用素との違いを並べる。

（1）核が正でない。M f は正の核の平均だから、被覆論が効く。S^* はディリクレ核（符号が振れ、絶対値の積分が発散）の上限である。

（2）変調に不変である。S_N(e^{ik\theta}f)=e^{ik\theta}S_{N-k}f の形の関係があるため、S^* は平行移動・拡大縮小だけでなく周波数の平行移動にも不変。この三重の対称性が、被覆論的な手法を無効にする。不変性が多いほど、評価は難しくなる。

（3）時間と周波数を同時に分解する必要がある。カールソンの証明は、位相平面（位置と周波数の平面）をタイル——面積 1 の長方形——に分け、各タイルへの射影を制御する。ハイゼンベルクの不確定性から、面積 1 より細かくは分けられない。この極限の細かさで議論するのが技術的な核心である。

（4）例外集合が本当に必要である。結論は「ほとんどいたるところ」であって「いたるところ」ではない。実際、どんな測度零の集合 E に対しても、E 上で発散する連続関数が存在する（カハネ–カツネルソン、1966年）。カールソンの定理とカハネ–カツネルソンの定理が合わさって、発散集合の特徴づけが完成する：発散しうる集合はちょうど測度零の集合である。

カハネ–カツネルソンの定理

任意の測度零の集合 E\subset\mathbb{T} に対し、f\in C(\mathbb{T}) で E のすべての点でフーリエ級数が発散するものが存在する。

したがって、f\in L^2 のフーリエ級数の発散集合として現れうる集合は、ちょうど測度零の集合である（カールソンの定理と合わせて）。

百五十年の問いに、どう決着がついたか

年表で見ると、この問題の歩みが分かる。

1807年　フーリエが「任意の関数は三角級数で表せる」と主張。
1829年　ディリクレが、区分的に単調な関数について収束を証明（（2）の原型）。
1873年　デュ・ボワ–レーモンが、連続関数で発散する例を構成。フーリエの主張は素朴な形では偽だと判明。
1900年　フェイェールが、平均をとれば常に収束することを証明（十九歳）。
1913年　ルジンが「L^2 ならほとんどいたるところ収束する」と予想。
1926年　コルモゴロフが、L^1 でいたるところ発散する例を構成。予想の L^2 という仮定が本質的だと分かる。
1966年　カールソンがルジンの予想を証明。同年、カハネ–カツネルソンが逆向きの最適性を示す。
1968年　ハントが L^p（p>1）へ拡張。

五十三年かかった予想が、その証明のために新しい手法（時間–周波数解析）を要求し、それが現代の調和解析を作った。問いの難しさが、道具の水準を引き上げた典型である。

★★ 学部後半——時間–周波数平面とタイル

不確定性が分解の限界を決める。関数 f を「位置 x のあたり、周波数 \xi のあたり」に局在した部品に分けたい。ところが位置の広がり \Delta x と周波数の広がり \Delta\xi には

\Delta x \cdot \Delta\xi \ \ge\ \frac{1}{4\pi}

という下限がある（ハイゼンベルクの不等式、第86章で証明する）。したがって位相平面を分けるときの最小単位は、面積 1 程度の長方形——タイル——である。

カールソンの証明の骨格。各点 \theta について、上限をとる N=N(\theta) を可測関数として固定する（線形化）。すると評価すべきは

\Big\| \sum_{|n|\le N(\theta)}\hat f(n)e^{in\theta} \Big\|_{L^2}

である。位相平面を \{(\theta,\xi):\xi\le N(\theta)\} という領域で切り、これをタイルに分解して、各タイルの寄与を数える。タイルは「選ばれた」ものと「選ばれない」ものに分かれ、選ばれたタイルが作る木構造（ツリー）ごとに評価する。ツリー内では議論が単純になり、ツリーの個数の評価が全体を決める。

フェファーマンの証明（1973年）。カールソンの証明を組合せ論的に整理し直したもので、現代の標準的な説明になっている。レイシー–タイルは同じ手法を双線形ヒルベルト変換

H(f,g)(x) = \mathrm{p.v.}\int f(x-t)g(x+t)\frac{dt}{t}

に適用し、カルデロンの三十年来の問題を解決した（1997年）。カールソンの技術が、別の問題を解く道具として再利用された。

仮定を外すと。p=1 ではコルモゴロフの反例があるので、p>1 は外せない。ただし L\log L\log\log L という L^1 と L^p のあいだのクラスでは収束する（シェーグレン、アントノフ）。逆に L^1 に少しでも近づけると反例が出る。境目は L\log L の近傍にあり、正確な位置はまだ完全には分かっていない。

★★★ 大学院——発散集合の構造と多次元

ハウスドルフ次元。カールソンの定理は発散集合が測度零だと言うが、その大きさはもっと細かく測れる。f\in L^2 の発散集合のハウスドルフ次元は 0 になりうるか、それとも 1 に近づけるか。カハネ–カツネルソンの構成は次元 1 の測度零集合（たとえば適当なカントール集合）でも動くので、発散集合の次元は 1 に達しうる。第42章の次元論の道具が、ここで発散の「濃さ」を測る尺度になる。

多次元の球形部分和。\mathbb{T}^d（d\ge2）では、部分和の取り方が一意でない。正方形部分和（各座標で切る）ならフビニでカールソンに帰着できるが、球形部分和 \sum_{|n|\le R} は本質的に難しい。フェファーマンの反例（第82章★★★）により、球形部分和は L^p（p\ne2）でノルム収束しない。L^2 での球形部分和のほとんどいたるところ収束は、d\ge2 で未解決である。

ボヘナー–リース平均。切り落としを滑らかにした \sum(1-|n|^2/R^2)_+^\delta\hat f(n)e^{in\theta} は、\delta>(d-1)/2 なら扱いやすい。臨界指数 \delta=(d-1)(1/p-1/2)-1/2 でのノルム有界性がボヘナー–リース予想で、d=2 ではカルレソン–ショーグレンとフェファーマンによって解決済み、d\ge3 では未解決。この予想は制限予想・カクヤ予想と論理的に連鎖しており、ボヘナー–リースが解ければ制限が、制限が解ければカクヤが従う。

エルゴード理論との対応。バーコフの個別エルゴード定理（時間平均がほとんど確実に空間平均に収束する）も、最大作用素の弱型評価から同じ三段の手順で出る。ブルガンのポリノミアル・エルゴード定理——\frac1N\sum_{n\le N}f(T^{n^2}x) がほとんど確実に収束する——は、その証明に円周法（整数論の技法）と時間–周波数解析を同時に使う。「ほとんどいたるところ収束する」という一つの型の問いが、解析・確率・整数論を横断して同じ難しさで現れる。

演習

基本
  1. ルベーグ定数が発散することから、汎関数の族が一様有界でないことを確かめよ。
  2. 三角多項式については S_Nf=f が大きい N で成り立つことを確かめよ。
  3. フェイェール平均がほとんどいたるところ収束することを、ルベーグの微分定理から説明せよ。
  4. 発散集合が測度零であることと、測度零な集合すべてが発散集合になりうることの、二つの主張の関係を述べよ。
証明
  1. を一様有界性の原理から示せ。（30点）
  2. 発散する連続関数の全体が余第一類であることを示せ。（35点）
  3. 「稠密集合での収束＋最大作用素の弱型評価」からほとんどいたるところの収束が出ることを示せ。（40点）
  4. S^* が周波数の平行移動に不変であることを確かめ、なぜそれが評価を難しくするか説明せよ。（35点）
  5. ルベーグの微分定理を、同じ三段の手順で証明し直せ。（40点）
発展
  1. 周波数帯を分離して重ねる手口で、連続だが部分和が一点で発散する関数を構成せよ。（50点）
  2. 不確定性から、位相平面の分解の最小単位が面積 1 であることを説明せよ。（45点）
  3. 正方形部分和については多次元でもカールソンの定理が成り立つことを、フビニの定理を使って示せ。（45点）
  4. バーコフの個別エルゴード定理を、最大エルゴード不等式から導け。（50点）
