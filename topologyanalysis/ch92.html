第XII部　複素解析

第92章留数定理とその応用

← 第91章　べき級数展開と解析接続 第93章　等角写像とRiemannの写像定理 →

この章の問い

  • なぜ「係数がひとつ」で積分が決まるのか。
  • 実数の定積分が、複素の積分路で解けるのはなぜか。
  • 留数は、数え上げの道具にもなるのか。

生き残るのは一つの係数だけ

第90章の基本計算を思い出す：円周に沿った (z-a)^n の積分は、n=-1 のときだけ 2\pi i で、他はすべて零だった。したがってローラン展開を項別に積分すると、c_{-1} の項しか残らない。

留数

a を f の孤立特異点とし、ローラン展開を f(z)=\sum_nc_n(z-a)^n とする。

\mathrm{Res}_{z=a}f = c_{-1} = \frac{1}{2\pi i}\oint_{|z-a|=\rho}f(z)\,dz

を f の a における留数という。

留数定理

\Omega を開集合、f を \Omega から孤立特異点の集合 S を除いた部分で正則、\gamma を \Omega のなかで零ホモローグなサイクルで S と交わらないものとする。このとき

\frac{1}{2\pi i}\oint_\gamma f(z)\,dz = \sum_{a\in S} n(\gamma,a)\,\mathrm{Res}_{z=a}f

（右辺は有限和：n(\gamma,a)\ne0 なる a は有限個）。

n(\gamma,a)\ne0 なる特異点を a_1,\dots,a_k とし、各 a_j でのローラン展開の主要部を P_j(z) と置く。P_j は \mathbb{C}\setminus\{a_j\} 上正則である。

g=f-\sum_jP_j と置くと、g は各 a_j で除去可能特異点をもつので、\Omega 上（修正して）正則になる。コーシーの定理のホモロジー版（（3））より \oint_\gamma g=0。したがって

\oint_\gamma f = \sum_j \oint_\gamma P_j

P_j(z)=\sum_{n\ge1}c^{(j)}_{-n}(z-a_j)^{-n} を項別に積分する（主要部は \gamma 上で一様収束）。n\ge2 の項は (z-a_j)^{-n} が原始関数 \frac{(z-a_j)^{1-n}}{1-n} をもつので閉曲線に沿った積分が零。n=1 の項だけが残り、

\oint_\gamma \frac{c^{(j)}_{-1}}{z-a_j}\,dz = 2\pi i\, n(\gamma,a_j)\,c^{(j)}_{-1}

留数定理は、コーシーの定理と「-1 乗だけが原始関数をもたない」という一点の組み合わせにすぎない。

留数の計算法

（1）位数 1 の極：\mathrm{Res}_{z=a}f=\lim_{z\to a}(z-a)f(z)。
（2）f=g/h、h(a)=0、h'(a)\ne0、g(a)\ne0：\mathrm{Res}_{z=a}\dfrac gh=\dfrac{g(a)}{h'(a)}。
（3）位数 m の極：

\mathrm{Res}_{z=a}f = \frac{1}{(m-1)!}\lim_{z\to a}\frac{d^{m-1}}{dz^{m-1}}\Big[(z-a)^mf(z)\Big]

（4）真性特異点：展開して c_{-1} を読むしかない。
（5）無限遠での留数：\mathrm{Res}_{z=\infty}f=-\mathrm{Res}_{w=0}\big[w^{-2}f(1/w)\big]。すべての留数（無限遠を含む）の和は零。

実積分を解く

型ごとの処方

（1）有理関数の全直線積分。\displaystyle\int_{-\infty}^{\infty}\frac{dx}{1+x^4}。

上半平面の半円（半径 R）を積分路にとる。円弧上では |f|\le\frac{1}{R^4-1}、長さ \pi R なので寄与は O(R^{-3})\to0。上半平面の極は e^{i\pi/4}、e^{3i\pi/4} で、（2）より留数は \frac{1}{4z^3}=\frac{z}{4z^4}=-\frac z4。和をとって

\int_{-\infty}^{\infty}\frac{dx}{1+x^4} = 2\pi i\cdot\Big(-\frac{e^{i\pi/4}+e^{3i\pi/4}}{4}\Big) = \frac{\pi}{\sqrt2}

一般に、分母の次数が分子より 2 以上大きければこの方法が使える。

（2）振動する積分。\displaystyle\int_{-\infty}^{\infty}\frac{\cos x}{1+x^2}dx。

\cos x ではなく e^{iz} を使う。上半平面で |e^{iz}|=e^{-\mathrm{Im}\,z}\le1 だから、円弧の寄与が制御できる（ジョルダンの補題：|f|\to0 なら \int_{\text{半円}}f(z)e^{iaz}dz\to0、a>0）。極は i、留数は \frac{e^{i\cdot i}}{2i}=\frac{e^{-1}}{2i}。実部をとって \pi/e。

（3）三角関数の周期積分。\displaystyle\int_0^{2\pi}\frac{d\theta}{a+\cos\theta}（a>1）。

z=e^{i\theta} と置くと \cos\theta=\frac{z+z^{-1}}{2}、d\theta=\frac{dz}{iz} で、単位円周上の積分になる。これは第80章のフーリエ係数の計算と同じ変数変換である。結果は 2\pi/\sqrt{a^2-1}。

（4）分岐点をもつ積分。\displaystyle\int_0^\infty\frac{x^{a-1}}{1+x}dx（0 < a < 1）。

正の実軸に沿って切断を入れ、鍵穴型の積分路をとる。切断の上下で z^{a-1} の値が e^{2\pi i(a-1)} 倍だけずれる——この差が答えを生む。極は z=-1 で留数 e^{i\pi(a-1)}。整理すると

\int_0^\infty\frac{x^{a-1}}{1+x}\,dx = \frac{\pi}{\sin\pi a}

これはガンマ関数の相反公式 \Gamma(a)\Gamma(1-a)=\pi/\sin\pi a にほかならない。

（5）主値積分。\displaystyle\mathrm{p.v.}\int_{-\infty}^{\infty}\frac{\sin x}{x}dx=\pi。

原点を小さな半円で迂回する。位数 1 の極を角 \alpha の円弧で迂回すると、寄与は i\alpha\times 留数になる（半円なら i\pi\times 留数）。第87章の主値超関数 \mathrm{p.v.}\frac1x の変換が -i\pi\,\mathrm{sgn}\,\xi だったのは、この迂回の i\pi である。

（6）級数の和。\pi\cot\pi z はすべての整数に位数 1 の極をもち留数 1。したがって f が適当に減衰すれば

\sum_{n\in\mathbb{Z}} f(n) = -\sum_{\text{$f$ の極 }a}\mathrm{Res}_{z=a}\big[\pi\cot(\pi z)f(z)\big]

f(z)=1/z^2 とすれば \sum1/n^2=\pi^2/6。留数が「和を積分に変える」道具になる——ポアソンの和公式（第84章）と同じ主題の、別の実現である。

なぜ複素に出ると実積分が解けるのか

実軸上の積分だけを見ていると、計算すべき量は積分そのものである。ところが積分路を閉じると、コーシーの定理により値は「囲んだ特異点の情報」だけで決まってしまう。

大域的な量（積分）が、局所的な量（各特異点での一つの係数）の有限和に落ちる。これが第90章★★★で述べた「局所と大域の往復」の、最も実用的な形である。

成功の条件は二つ：（i）積分路を閉じたときの追加部分（円弧など）の寄与が消えること、（ii）囲まれた特異点が有限個で、留数が計算できること。どちらかが破れると、この方法は使えない。

数え上げの道具として

偏角の原理とルーシェの定理

（1）f が \gamma の内部で有理型、\gamma 上に零点も極もないとき

\frac{1}{2\pi i}\oint_\gamma\frac{f'(z)}{f(z)}\,dz = Z - P

（Z、P は重複度込みの零点・極の個数）。
（2）ルーシェ：\gamma 上で |g| < |f| なら、f と f+g は内部で同じ個数の零点をもつ。
（3）フルヴィッツ：零点をもたない正則関数の列が広義一様収束すれば、極限も零点をもたないか恒等的に零。

（1）f(z)=(z-a)^m u(z)（u(a)\ne0）なら \dfrac{f'}{f}=\dfrac{m}{z-a}+\dfrac{u'}{u}。第二項は a で正則だから、f'/f は a で位数 1 の極をもち留数 m。極 a（位数 p）なら同様に留数 -p。を適用すればよい。

（2）h_t=f+tg（t\in[0,1]）は \gamma 上で零にならない（|f+tg|\ge|f|-|g|>0）。零点の個数 Z(t)=\frac{1}{2\pi i}\oint\frac{h_t'}{h_t} は t の連続関数で整数値だから一定。

（3）f\not\equiv0 で f(a)=0 とすると、小さな円周 \gamma 上で |f|\ge\delta>0（零点は孤立）。n が大きければ |f_n-f| < \delta\le|f| なので、ルーシェより f_n も内部に零点をもつ——矛盾。

ルーシェの使いどころ

（1）代数学の基本定理。P(z)=z^n+a_{n-1}z^{n-1}+\cdots+a_0。R を十分大きくとれば |z|=R 上で |a_{n-1}z^{n-1}+\cdots+a_0| < |z^n|。よって P と z^n は同じ個数（n 個）の零点をもつ。

（2）零点の位置。z^5+3z+1 の零点は |z| < 2 にいくつあるか。|z|=2 で |3z+1|\le7 < 32=|z^5| なので、z^5 と同じ 5 個。|z|=1 では |z^5+1|\le2 < 3=|3z| なので、3z と同じ 1 個。したがって 1\le|z| < 2 に 4 個。

（3）開写像定理の証明。f(a)=w_0 とし、|f(z)-w_0|\ge\delta（小円周上）とする。|w-w_0| < \delta なら、ルーシェより f(z)-w と f(z)-w_0 は同じ個数の零点をもつ。後者は少なくとも 1 個（z=a）だから、前者も解をもつ。像が w_0 のまわりの円板を含む——これが開写像性である。

（4）逆関数定理。f'(a)\ne0 なら、（3）の議論で零点がちょうど 1 個になり、f は a の近傍で単射。逆関数は

f^{-1}(w) = \frac{1}{2\pi i}\oint_\gamma \frac{z\,f'(z)}{f(z)-w}\,dz

という積分で書け、したがって w について正則である。

（5）逆関数の係数（ラグランジュの反転公式）。同じ積分から f^{-1} のテイラー係数が

[w^n]\,f^{-1}(w) = \frac1n[z^{n-1}]\Big(\frac{z}{f(z)}\Big)^n

と書ける。組合せ論の数え上げ（木の個数、カタラン数）が、この公式で一行で出る。

うまくいかない場合

（1）円弧の寄与が消えない。\int_{-\infty}^\infty\frac{x\,dx}{1+x^2} は主値としてしか存在せず、半円の寄与は零に行かない。分母と分子の次数差が 1 しかないと、円弧上で |f|\cdot\pi R\not\to0。

（2）特異点が無限個。1/\sin z を大きな円で囲むと、極の個数が R とともに増える。それでも和が制御できれば使える（（6）の級数和の方法がまさにそれ）が、無条件ではない。

（3）真性特異点。留数は定義されるが、計算には展開が要る。\oint_{|z|=1}e^{1/z}dz=2\pi i（c_{-1}=1）。

（4）分岐点は孤立特異点でない。\sqrt z の原点は、穴あき円板で一価に定まらないので留数が定義できない。切断を入れて扱うしかない。

（5）実積分が発散していれば当然だめ。\int_0^\infty\frac{dx}{x} のような場合、留数計算は形式的な答えを出すことがあるが意味をもたない。計算の前に収束を確かめること。

★★ 学部後半——鞍点法と、漸近評価

ラプラスの方法と鞍点法。I(\lambda)=\int_\gamma g(z)e^{\lambda h(z)}dz（\lambda\to\infty）を評価したい。積分路を変形して、\mathrm{Re}\,h が最大になる点を一点だけ通るようにする。正則性により、そのような点は h'(z_0)=0 をみたす鞍点である（最大値原理により、|e^h| は内点で極大値をもてない——極値は鞍点にしかならない）。

I(\lambda) \sim g(z_0)\,e^{\lambda h(z_0)}\sqrt{\frac{2\pi}{-\lambda h''(z_0)}}

最大値原理が「峠を通る道しかない」ことを保証し、それが漸近展開の主要項を決める。

例：スターリングの公式。\Gamma(n+1)=\int_0^\infty t^ne^{-t}dt で t=nz と置けば n^{n+1}\int z^ne^{-nz}dz=n^{n+1}\int e^{n(\log z-z)}dz。鞍点は z=1、h''=-1 で

n! \sim \sqrt{2\pi n}\,\Big(\frac ne\Big)^n

特異点解析。母関数 F(z)=\sum a_nz^n の係数の漸近挙動は、F の収束円上の特異点の種類で決まる。コーシーの係数公式 a_n=\frac{1}{2\pi i}\oint\frac{F(z)}{z^{n+1}}dz を、特異点のまわりに積分路を変形して評価する。

（i）位数 m の極 \rho なら a_n\sim c\,n^{m-1}\rho^{-n}。
（ii）代数的特異点 (1-z/\rho)^{-\alpha} なら a_n\sim\frac{n^{\alpha-1}}{\Gamma(\alpha)}\rho^{-n}。カタラン数の 4^n n^{-3/2} はこの型（\alpha=-1/2）。

フラジョレ–セジウィックの解析的組合せ論は、この対応を体系化した——「数え上げの漸近は、母関数の最も近い特異点を見よ」。

逆ラプラス変換。F(s)=\int_0^\infty f(t)e^{-st}dt の反転は

f(t) = \frac{1}{2\pi i}\int_{c-i\infty}^{c+i\infty}F(s)e^{st}\,ds

（ブロムウィッチ積分）。積分路を左に倒して留数を拾えば、F の極が f の指数的な成分を与える。制御理論で「極が左半平面にあれば安定」というのは、この留数計算の帰結である。第77章★★のストーンの公式も、同じ形をしている。

仮定を外すと。鞍点法は h''(z_0)\ne0 を要求する。退化した鞍点（h''=0）ではエアリー関数型の漸近が現れ、この分類がカタストロフィー理論になる。光学の焦線（コースティクス）が物理的な現れである。

★★★ 大学院——留数の一般化

多変数の留数。\mathbb{C}^n では特異点が孤立するとは限らず、留数は n 次元の積分路（|f_1|=\varepsilon_1,\dots,|f_n|=\varepsilon_n というトーラス）に沿った積分として定義される（グロタンディークの留数）。局所的なデータ（多項式の係数）から大域的な不変量（交点数）を読む道具で、代数幾何の交点理論の基礎にある。

層コホモロジーとしての留数。留数写像 H^n(\mathbb{C}^n\setminus V,\Omega^n)\to\mathbb{C} は、ド・ラム・コホモロジーの双対性の一部である。ポアンカレ双対性のもとで、留数をとることと「サイクルと交わる」ことが同じになる。第90章★★★で並べた「局所と大域の往復」が、ここでは完全に代数的な形をとる。

グロタンディーク–リーマン–ロッホ。留数定理の「すべての留数の和は零」（（5））は、リーマン球面上の有理型 1 形式についての主張である。一般の閉リーマン面では、これが留数定理の大域版になり、さらに層の特性類の言葉に持ち上げるとリーマン–ロッホの定理

\dim H^0(X,L) - \dim H^1(X,L) = \deg L + 1 - g

が得られる。アティヤ–シンガーの指数定理は、これを任意の楕円型作用素へ一般化したものである。「留数の総和が零」という素朴な等式が、指数定理の系譜の出発点にある。

正則モチーフと周期。代数多様体の周期（代数的サイクル上の正則形式の積分）は、留数の高次元版として現れる。グロタンディークの周期予想——周期の代数的関係はすべて幾何的な理由から来る——は未解決である。コンツェヴィッチ–ザギエの周期の理論は、\pi、\log2、\zeta(3)、多重ゼータ値などを統一的に扱う枠組みを与えるが、\zeta(3) が無理数であること（アペリー、1979年）を超えて、\zeta(5) の無理数性すら未解決である。

物理での留数。ファインマン積分の値は、しばしば周期であり、その計算は留数と \bar\partial の理論に帰着する。散乱振幅の「単位性」（ユニタリティ）は、複素平面での切断と留数の関係（分散関係）として定式化される。第75章の作用素論的なユニタリ性と、複素解析的な単位性は、同じ物理を二つの言葉で述べたものである。
