第VI部　実数と極限

第43章実数の構成と完備性

← 第42章　次元論の反例と、一致しない空間 第44章　上限・下限と単調列 →

この章の問い

  • 有理数では、いったい何が足りないのか。
  • 実数を「作る」とは、どういう作業なのか。
  • 作り方が二通りあるのに、同じものができるのはなぜか。

有理数に空いている穴

第42章まで位相の言葉で議論してきた。ここから解析に移る。最初にやるべきは、議論の舞台である実数を確定させることである。

有理数体 \mathbb{Q} は、四則が自由にでき、順序があり、稠密でもある。それでも解析には足りない。

有理数で壊れる三つのこと

方程式が解けない。x^2 = 2 を満たす x \in \mathbb{Q} は存在しない。

上限がない。A = \{\, q \in \mathbb{Q} \mid q > 0,\ q^2 < 2 \,\} は上に有界だが、\mathbb{Q} のなかに上限をもたない。

コーシー列が収束しない。x_{n+1} = \tfrac{1}{2}(x_n + 2/x_n)、x_1 = 2 はコーシー列だが、極限は \mathbb{Q} にない。

三つは同じ穴を別の角度から見ている。「連続体である」という性質が欠けているのである。

第29章の言葉でいえば、\mathbb{Q} は通常の距離について完備でない。実数の構成とは、この完備でない空間を完備にする作業である。ただし、順序と四則をこわさずに行う必要がある。

切断による構成

デデキント切断

\mathbb{Q} の部分集合 \alpha が切断Dedekind cutであるとは、

（1）\varnothing \ne \alpha \ne \mathbb{Q}。
（2）q \in \alpha、p < q ならば p \in \alpha（下に閉じている）。
（3）\alpha は最大元をもたない。

切断の全体を \mathbb{R} と定め、包含関係 \alpha \subseteq \beta を順序 \alpha \le \beta とする。

直観は単純である。切断 \alpha は「その実数より小さい有理数の全体」を表す。数そのものを、それが切り分ける有理数の集合で代用する。

この順序について、\mathbb{R} の空でない上に有界な部分集合はつねに上限をもつ。

S \subseteq \mathbb{R} を空でない上に有界な集合とし、\gamma = \bigcup_{\alpha \in S} \alpha とおく。

\gamma が切断であることを確かめる。空でないことは S \ne \varnothing から。\mathbb{Q} と異なることは、S の上界 \beta について \gamma \subseteq \beta \ne \mathbb{Q} だから。下に閉じていること、最大元をもたないことは、各 \alpha がそうだから合併でも成り立つ。

\gamma がすべての \alpha \in S を含むので上界であり、どの上界 \beta についても \gamma \subseteq \beta なので最小の上界である。上限の存在が、合併というただ一つの操作で出てしまう。これが切断による構成の長所である。

加法は \alpha + \beta = \{\, p + q \mid p \in \alpha,\ q \in \beta \,\} で定義でき、これも切断になる。乗法は符号の場合分けが要り、証明が長くなる。切断は順序に強く、演算に弱い。次の構成はちょうど逆である。

コーシー列による構成

コーシー列による構成

\mathbb{Q} のコーシー列の全体を \mathcal{C} とする。(x_n) \sim (y_n) を \lim_n |x_n - y_n| = 0 で定めると同値関係になる。商集合 \mathcal{C}/{\sim} を \mathbb{R} と定める。

演算は項ごとに定める。[(x_n)] + [(y_n)] = [(x_n + y_n)]、[(x_n)] \cdot [(y_n)] = [(x_n y_n)]。

こちらは演算が自然である。項ごとに足し、項ごとにかければよい。代わりに、順序と上限の存在を示すのに手間がかかる。

この構成は、第29章の完備化をそのまま \mathbb{Q} に適用したものである。位相の言葉で作った完備化が、代数と順序も引き継ぐことを確かめている。

どちらでも同じものができる

完備順序体

順序体 F が完備であるとは、空でない上に有界な部分集合がつねに上限をもつことをいう。

実数体の一意性

完備順序体は、同型を除いてただ一つである。すなわち二つの完備順序体のあいだには、順序と演算を保つ全単射がただ一つ存在する。

F, G を完備順序体とする。どちらも \mathbb{Q} と同型な部分体を含む（1 を足していけば \mathbb{N}、差と商で \mathbb{Q} が出る）。この部分体を同一視する。

x \in F に対し \varphi(x) = \sup\{\, q \in \mathbb{Q} \mid q < x \,\}（G での上限）と定める。右辺の集合は空でなく上に有界なので、G の完備性から上限が存在する。

\varphi が順序と演算を保つことは、\mathbb{Q} が F でも G でも稠密であること（下のアルキメデス性）から従う。逆向きも同様に作れて、合成が恒等写像になる。

一意性。同型は \mathbb{Q} 上で恒等でなければならず、\mathbb{Q} が稠密だから全体で決まる。

アルキメデス性

完備順序体 F では、どの x \in F についても n > x なる自然数 n が存在する。したがって \mathbb{Q} は F で稠密である。

そうでないとすると \mathbb{N} が上に有界になり、完備性から上限 s をもつ。s-1 は上界でないので n > s-1 なる n があるが、すると n+1 > s で矛盾。

稠密性。x < y とし、n > 1/(y-x) を取る。m を m/n > x なる最小の整数とすれば x < m/n < y になる。アルキメデス性は完備性から出る——独立な公理ではない。

四つの言い換えが同値であること

完備性の言い換えを四つ挙げた。これらが同値であることを確かめておく。解析の議論では、場面に応じて使い分ける。

上限性質から単調収束へ。(x_n) を上に有界な単調増加列とし、s = \sup_n x_n とおく。どの \varepsilon > 0 についても s - \varepsilon は上界でないので、x_N > s-\varepsilon なる N がある。単調性より n \ge N で s - \varepsilon < x_n \le s。よって x_n \to s。

単調収束から区間縮小へ。[a_n, b_n] を減少する閉区間の列とすると、(a_n) は上に有界な単調増加列、(b_n) は下に有界な単調減少列。両方の極限が存在し、\lim a_n \le \lim b_n なので交わりは空でない。

区間縮小からコーシー完備へ。(x_n) をコーシー列とする。各 k について |x_m - x_n| < 2^{-k}（m,n \ge N_k）なる N_k を取り、I_k = [x_{N_k} - 2^{-k}, x_{N_k} + 2^{-k}] とおく。必要なら小さくして減少列にできる。交わりの点が極限になる。

コーシー完備から上限性質へ。ここでアルキメデス性が要る。S を空でない上に有界な集合とし、二分法で区間を縮める。[a_0,b_0] を a_0 が上界でなく b_0 が上界であるように取り、中点で分けて同じ性質を保つ半分を選ぶ。区間の長さが 2^{-n}(b_0-a_0) \to 0 となるのに、アルキメデス性が必要である。

なぜ最後だけ余分な仮定が要るのか。コーシー完備だがアルキメデス的でない順序体が存在するからである。たとえば有理関数体に「x はどの有理数より大きい」という順序を入れたものは、アルキメデス的でない。上限性質はアルキメデス性を含むが、コーシー完備性は含まない。

使い分け。上限性質は存在証明に、単調収束は数列の議論に、区間縮小は二分法に、コーシー完備性は極限の値がわからないときに使う。第45章以降で、どれも繰り返し現れる。

実数でない順序体と、実数の特徴づけ

完備順序体が一意だという事実は、逆に「完備性を落とすと何が出るか」を問わせる。

非アルキメデス順序体。形式的ローラン級数体 \mathbb{R}((t)) に、t > 0 かつ t がどの正の実数より小さい、という順序を入れる。これは順序体だがアルキメデス的でない。t は「無限小」である。

超実数体。\mathbb{R}^{\mathbb{N}} を超フィルター（第12章）で割ると、{}^{*}\mathbb{R} が得られる。\mathbb{R} を真に含む順序体で、一階の言語で書ける性質をすべて共有する（移行原理）。無限小と無限大をもち、微分や積分を無限小で直接扱える——これが超準解析である。

移行原理の証明には、超フィルターの存在すなわち選択公理（第3章）が要る。無限小の存在は、選択公理の帰結として現れる。

実閉体。順序体 F が実閉であるとは、正の元がすべて平方根をもち、奇数次多項式がつねに根をもつことをいう。\mathbb{R} は実閉だが、実閉体は他にもたくさんある（実代数的数の全体など）。

タルスキの定理により、実閉体の一階の理論は決定可能である。「実数についての一階の主張」は機械的に判定できる。ところが「すべての部分集合について」と量化した瞬間に、二階の主張になって決定不能になる。

完備性は二階の性質である。上限性質は「部分集合」を量化する。一階の言語では書けない。だからこそ \mathbb{R} と {}^{*}\mathbb{R} が一階では区別できず、二階では区別できる。

連続体としての ℝ。第36章のカントールの特徴づけは、順序の言葉だけで \mathbb{R} を決めていた。代数を使わずに、稠密・端点なし・連結・可分の四条件で足りる。そして第36章で見たとおり、最後の「可分」を「可算鎖条件」に弱めてよいかは、公理系から決まらない。

|\mathbb{R}| = 2^{\aleph_0} の値そのものも独立である（第4章）。実数は、構成は一意なのに、大きさが決まらない。
