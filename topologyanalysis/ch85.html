第XI部　フーリエ解析

第85章L2への拡張とPlancherelの定理

← 第84章　Fourier変換——L1の理論 第86章　畳み込みと近似単位元 →

この章の問い

  • 二乗可積分だが可積分でない関数の、フーリエ変換はどう定義するのか。
  • なぜ L^2 でだけ等距離になるのか。
  • フーリエ変換を作用素と見ると、そのスペクトルは何か。

定義できない場所へ、延長する

f\in L^2(\mathbb{R}) でも f\notin L^1(\mathbb{R}) ということが起こる。典型は f(x)=1/(1+|x|) で、二乗は可積分だが一乗は可積分でない。この場合、\int f(x)e^{-ix\xi}dx という積分は絶対収束しない。

それでもフーリエ変換を定義したい。方法は第63章以来おなじみの「稠密な部分空間で定義し、等距離性を使って延長する」である（）。鍵になるのは、L^1\cap L^2 の上で \mathcal{F} が（定数倍を除いて）等距離だという事実である。

プランシュレルの定理

（1）f\in L^1(\mathbb{R}^d)\cap L^2(\mathbb{R}^d) ならば \hat f\in L^2(\mathbb{R}^d) で

\|\hat f\|_2^2 = (2\pi)^d\|f\|_2^2

（2）L^1\cap L^2 は L^2 で稠密なので、\mathcal{F} は L^2(\mathbb{R}^d) 上の有界作用素にただ一通りに延長され、(2\pi)^{-d/2}\mathcal{F} はユニタリになる。
（3）パーセヴァルの等式：f,g\in L^2 について

\int_{\mathbb{R}^d} f\bar g\,dx = \frac{1}{(2\pi)^d}\int_{\mathbb{R}^d}\hat f\,\overline{\hat g}\,d\xi

（4）延長は具体的に \hat f=\lim_{R\to\infty}\int_{|x|\le R}f(x)e^{-ix\cdot\xi}dx（L^2 ノルムでの極限）で与えられる。

（1）の証明。g(x)=\overline{f(-x)} と置き、h=f*g とする。h は有界連続で（L^2 の元どうしの畳み込みはコーシー–シュワルツから有界連続）、h\in L^1（f,g\in L^1）、そして

h(0) = \int f(x)\overline{f(x)}\,dx = \|f\|_2^2, \qquad \hat h = \hat f\,\hat g = \hat f\,\overline{\hat f} = |\hat f|^2 \ \ge 0

反転公式のガウス総和法（（2））を h の連続点 x=0 で使うと

\|f\|_2^2 = h(0) = \lim_{\varepsilon\downarrow0}\frac{1}{(2\pi)^d}\int|\hat f(\xi)|^2e^{-\varepsilon|\xi|^2}\,d\xi

被積分関数は非負で \varepsilon\downarrow0 のとき単調に増えるから、単調収束定理（）により右辺は (2\pi)^{-d}\|\hat f\|_2^2（有限）に等しい。非負性が単調収束を許すところが、証明の急所である。

（2）。C_c(\mathbb{R}^d)\subset L^1\cap L^2 は L^2 で稠密（）。等距離写像の稠密な部分空間からの延長はによる。全射性は、逆変換 \mathcal{F}^{-1} も同様に延長され、L^1\cap L^2 上で \mathcal{F}^{-1}\mathcal{F}=\mathrm{id} が反転公式から成り立つことによる。

（3）は（1）と偏極恒等式、（4）は f\chi_{|x|\le R}\to f が L^2 で成り立つことと、\mathcal{F} の L^2 連続性による。

どの意味で「変換」なのか

f\in L^2\setminus L^1 のとき、\hat f(\xi) は各点での値としては定義されていない。定義されているのは L^2 の元としての同値類だけである。したがって「\hat f を \xi_0 で評価する」という操作に意味はない。

これは不便ではなく、正確さの代償である。実際、（4）の切り落とし積分は各点では収束しないことがある——カールソンの定理（第83章）の連続版が、ほとんどいたるところの収束を保証するが、それは深い定理である。

次章以降で、L^2 でも足りない場面が出てくる（たとえば定数関数 1 のフーリエ変換）。そこで超関数（第87章）へ進む。

ユニタリ作用素としてのフーリエ変換

フーリエ変換のスペクトル

\mathcal{U}=(2\pi)^{-d/2}\mathcal{F} を L^2(\mathbb{R}^d) 上のユニタリ作用素とする。

（1）\mathcal{U}^2f(x)=f(-x)、したがって \mathcal{U}^4=I。
（2）\sigma(\mathcal{U})=\{1,i,-1,-i\} で、すべて固有値である。
（3）d=1 のとき、固有関数はエルミート関数

h_n(x) = \big(2^nn!\sqrt\pi\big)^{-1/2}\,(-1)^n e^{x^2/2}\frac{d^n}{dx^n}e^{-x^2} , \qquad \mathcal{U}h_n = (-i)^n h_n

で与えられ、\{h_n\}_{n\ge0} は L^2(\mathbb{R}) の正規直交基底をなす。したがって L^2(\mathbb{R}) は四つの固有空間の直和に分かれ、各固有空間は無限次元である。

（1）反転公式から \mathcal{F}^{-1}g(x)=(2\pi)^{-d}\mathcal{F}g(-x)、よって \mathcal{F}^2f(x)=(2\pi)^df(-x)。正規化すれば \mathcal{U}^2f(x)=f(-x) で、これを二回で恒等写像。

（2）\mathcal{U}^4=I より、多項式 z^4-1 が \mathcal{U} を零化する。スペクトル写像定理（）から \sigma(\mathcal{U})^4=\{1\}、すなわち \sigma(\mathcal{U})\subset\{1,i,-1,-i\}。各値が実際に固有値であることは（3）から従う。

（3）A=-\frac{d^2}{dx^2}+x^2（調和振動子、（4））と置くと、（6）の二つの式から \mathcal{U}A=A\mathcal{U} が分かる（微分と掛け算が入れ替わるので、その和は不変）。A の固有値 2n+1 は単純なので、固有関数 h_n は \mathcal{U} の固有ベクトルでもある。固有値が (-i)^n であることは、生成関数（母関数）を使うか、h_0=e^{-x^2/2} が \mathcal{U} の固有値 1 の固有関数であること（（3））と、昇降作用素 a^\pm=\mp\frac{d}{dx}+x が \mathcal{U} とどう交換するかから出る。

フーリエ変換と調和振動子が可換だという一行が、エルミート関数の役割をすべて説明する。

等距離性の使い方

（1）乗子作用素のノルム。T_mf=(m\hat f)^\vee について、L^2 では

\|T_m\|_{L^2\to L^2} = \|m\|_{L^\infty}

プランシュレルで両辺を周波数側に移せば、掛け算作用素のノルムを計算するだけ（（1））。第77章のスペクトル定理の言葉で言えば、フーリエ変換は微分作用素の族を同時に対角化するユニタリ変換である。

（2）ソボレフ空間の定義。s\in\mathbb{R} について

H^s(\mathbb{R}^d) = \Big\{ f : \|f\|_{H^s}^2 = \frac{1}{(2\pi)^d}\int(1+|\xi|^2)^s|\hat f(\xi)|^2\,d\xi < \infty \Big\}

プランシュレルがあるので、s が非負整数のときこれは通常の「s 階までの導関数が二乗可積分」と一致する。s が実数でもよいというのが、フーリエによる定義の強みである——「半階の微分」に意味が与えられる。第88章で使う。

（3）不確定性の証明。ハイゼンベルクの不等式は、[\partial_x, x]=I という交換関係と、\|\partial_xf\|_2=\|\xi\hat f\|_2/\sqrt{2\pi}（プランシュレル）から出る。第86章で詳しく見る。

（4）シュレーディンガー方程式。i\partial_tu=-\Delta u の解は \hat u(\xi,t)=e^{-it|\xi|^2}\hat f(\xi)。各周波数の絶対値が変わらないので、\|u(\cdot,t)\|_2=\|f\|_2（確率の保存）。これは第77章★★のストーンの定理そのもので、生成子が -\Delta である。ただし位相が周波数ごとに違う速さで回るため、波束は分散する。

L^2 でも足りない場面

（1）定数関数。f\equiv1 は L^1 にも L^2 にも属さない。ところが \hat1=(2\pi)^d\delta であるべきで、この式は超関数の意味でのみ正しい。

（2）多項式・指数関数。同様に L^p のどれにも属さない。物理で扱う平面波 e^{ik\cdot x} がまさにこれである。

（3）測度。ディラック測度のフーリエ変換は定数関数で、L^2 に属さない。「関数」の枠のなかでは、変換が空間の外に出てしまう対象がある。

（4）L^p（p>2）では定義できない。ハウスドルフ–ヤングの不等式は p\le2 でしか成り立たず、p>2 ではフーリエ変換は関数として定義されない（超関数としてなら定義される）。

これらをすべて含む枠組みが、シュワルツ空間の双対としての緩増加超関数である（第87章）。そこでは \mathcal{F} が空間全体の自己同型になり、例外がなくなる。

★★ 学部後半——分数階フーリエ変換と、テストの取り方

分数階フーリエ変換。\mathcal{U}=\sum_n(-i)^nP_n（P_n は h_n への射影）とスペクトル分解できるので、実数 \alpha について

\mathcal{U}^\alpha = \sum_n e^{-i\pi n\alpha/2}P_n

と定められる（第77章のボレル関数計算）。\mathcal{U}^\alpha は位相平面を角度 \pi\alpha/2 だけ回転させる作用素で、\alpha=1 が通常のフーリエ変換、\alpha=0 が恒等写像である。「時間」と「周波数」は、位相平面のたまたま直交する二つの座標軸にすぎない。光学（レンズ系）と信号処理で実際に使われる。

メタプレクティック表現。より一般に、位相平面の面積を保つ線形変換（シンプレクティック群 Sp(2d,\mathbb{R})）は L^2(\mathbb{R}^d) 上のユニタリ作用素として（二重被覆を経て）表現される。フーリエ変換は 90 度回転に対応する元である。この表現が、量子力学の正準変換と古典力学のシンプレクティック幾何を結ぶ。

テスト関数の取り方の自由度。プランシュレルの証明では L^1\cap L^2 を出発点にしたが、他にも道はある。

（i）エルミート関数から出発する：\{h_n\} が正規直交基底で、各 h_n が固有関数だと示せば、等距離性は直ちに従う。この道は「変換を計算せずに、対角化だけで結論する」という点で美しい。

（ii）シュワルツ空間から出発する：\mathcal{S} 上でフーリエ変換が全単射であることを示し、そこから延長する。第87章の道である。

（iii）ガウス総和法から出発する：本章で採った道で、反転公式の証明を再利用できる。

どの道でも同じ定理に着くが、一般化の方向が違う。（i）は他の直交多項式系へ、（ii）は超関数へ、（iii）は局所コンパクト群へ伸びる。

仮定を外すと。ユニタリ性は p=2 の特権で、p\ne2 ではハウスドルフ–ヤングの不等式しか残らない（第82章）。また、\mathbb{R}^d を非可換群に替えると、プランシュレルの定理は「既約表現の空間の上の測度（プランシュレル測度）」に関する等式になる——表現論の中心的な定理の一つである。

★★★ 大学院——制限定理とカクヤ予想

制限問題。\hat f は一般に L^2 の元にすぎないから、曲面（たとえば球面 S^{d-1}）に制限しても意味がない——測度零の集合の上では値が定まらない。ところが曲率があると、話が変わる。

スタイン–トマスの定理：f\in L^p(\mathbb{R}^d)、1\le p\le\frac{2(d+1)}{d+3} なら

\|\hat f\|_{L^2(S^{d-1})} \le C\|f\|_{L^p(\mathbb{R}^d)}

曲率が、フーリエ変換に余分の滑らかさを与えるのである。平面（曲率零）では同じことが成り立たない。制限予想は、この不等式の L^q(S^{d-1}) 版で p < \frac{2d}{d+1} という最良の範囲を主張するもので、d=2 ではフェファーマン–ジグムントが解決、d\ge3 では未解決である。

カクヤ予想との連鎖。制限予想はカクヤ予想——すべての方向に単位線分を含む集合（カクヤ集合）のハウスドルフ次元は d に等しい——を含意する。連鎖は

\text{ボヘナー–リース} \Longrightarrow \text{制限} \Longrightarrow \text{カクヤ}

という向きで、左ほど強い。カクヤ集合はルベーグ測度零でありうる（ベシコヴィッチ、1919年）のに、次元は最大だと予想されている。第42章で扱った「測度と次元のずれ」が、ここでフーリエ解析の未解決問題の中心に座っている。d=3 のカクヤ予想はワンとザールによって解決された（2025年）が、d\ge4 は依然として開いている。

分散型評価。シュレーディンガー方程式の解の時空評価

\|e^{it\Delta}f\|_{L^q_{t,x}} \le C\|f\|_{L^2}

（ストリッカーツ評価）は、制限定理の双対として出る：放物面への制限が、時間発展の評価になる。これが非線形シュレーディンガー方程式の適切性理論の基礎で、ボルグ・タオ・ケンチヒらの仕事につながる。純粋に幾何的な問い（カクヤ集合の次元）と、偏微分方程式の可解性が、フーリエ変換を介して同じ一つの難しさを共有している。

演習

基本
  1. 1/(1+|x|) が二乗可積分だが可積分でないことを確かめよ。
  2. \mathcal{U}^2f(x)=f(-x) を反転公式から確かめよ。
  3. ガウス関数が固有値 1 の固有関数であることを確かめよ。
  4. シュレーディンガー方程式の解のノルムが保たれることを確かめよ。
証明
  1. f,g\in L^2 のとき f*g が有界連続であることを示せ。（25点）
  2. （1）を、単調収束定理を使う箇所に注意して書き下せ。（40点）
  3. 延長の一意性を、等距離性から示せ。（30点）
  4. \sigma(\mathcal{U})\subset\{1,i,-1,-i\} を、スペクトル写像定理から示せ。（30点）
  5. 乗子作用素の L^2 ノルムが \|m\|_\infty であることを示せ。（35点）
発展
  1. フーリエ変換と調和振動子が可換であることを示せ。（45点）
  2. エルミート関数が L^2(\mathbb{R}) の正規直交基底をなすことを示せ。（50点）
  3. 分数階フーリエ変換を定義し、二つの合成が指数の和になることを示せ。（45点）
  4. ソボレフ空間の二つの定義（導関数による定義とフーリエによる定義）が非負整数 s で一致することを示せ。（45点）
