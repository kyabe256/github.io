第93章等角写像とRiemannの写像定理

この章の問い

  • どんな領域も、円板と同じだと言えるのか。
  • 存在証明は、何を使って行うのか。
  • 境界はどこまで対応するのか。

等角同値という分類

等角同値

領域 \Omega_1,\Omega_2\subset\mathbb{C} のあいだに、正則な全単射 f:\Omega_1\to\Omega_2 が存在するとき、\Omega_1 と \Omega_2 は等角同値であるという。このとき逆写像も自動的に正則である（（4））。

等角同値は同値関係であり、「複素解析的に同じ」ということの正確な意味を与える。

具体的な等角写像

（1）メビウス変換。T(z)=\dfrac{az+b}{cz+d}（ad-bc\ne0）。リーマン球面の自己同型はこれに限る。円と直線の族を保ち、三点の像を自由に指定できる。

（2）上半平面と単位円板。\displaystyle z\mapsto\frac{z-i}{z+i} が \mathbb{H}=\{\mathrm{Im}\,z>0\} から D への等角同型。逆は w\mapsto i\frac{1+w}{1-w}。

（3）円板の自己同型。\mathrm{Aut}(D)=\Big\{\,e^{i\theta}\dfrac{z-a}{1-\bar az}\ \Big|\ |a| < 1,\ \theta\in\mathbb{R}\,\Big\}。証明はシュヴァルツの補題（（1））：0 を 0 に写す自己同型は回転に限る。この群が円板上の双曲幾何（ポアンカレ計量）の等長群である。

（4）帯・扇形・半平面。e^z は帯 0 < \mathrm{Im}\,z < \pi を上半平面へ、z^\alpha は扇形 0 < \arg z < \pi/\alpha を上半平面へ写す。\frac12(z+1/z)（ジューコフスキー写像）は円板の外部を切れ目の入った平面へ写し、翼型の設計に使われた。

（5）多角形。シュヴァルツ–クリストッフェルの公式

f(z) = C\int_0^z \prod_{k=1}^{n}(w-x_k)^{\alpha_k-1}\,dw + C'

が上半平面を多角形（内角 \pi\alpha_k）へ写す。被積分関数の各因子が、対応する頂点で角を \pi\alpha_k に折り曲げる。

リーマンの写像定理

\Omega\subsetneq\mathbb{C} を単連結な領域（\mathbb{C} 全体でない）とする。任意の z_0\in\Omega に対し、等角同型

f:\Omega \longrightarrow D = \{|w| < 1\}

で f(z_0)=0、f'(z_0)>0 をみたすものがただ一つ存在する。

したがって、\mathbb{C} 自身を除けば、単連結領域はすべて等角同値である。境界がどれほど複雑でも——フラクタルでも——関係ない。

一意性。f_1,f_2 が条件をみたすなら g=f_2\circ f_1^{-1} は D の自己同型で g(0)=0、g'(0)>0。シュヴァルツの補題より g(w)=cw（|c|=1）、g'(0)=c>0 から c=1。

存在。三段で進む。

第一段（単射正則写像の族が空でない）。a\notin\Omega をとる。\Omega は単連結だから z-a の平方根 h(z)=\sqrt{z-a} が一価に定まる（モノドロミー定理、）。h は単射で、h(\Omega) と -h(\Omega) は交わらない（交われば h(z_1)=-h(z_2) から z_1=z_2、よって h(z_1)=0、すなわち z_1=a\notin\Omega）。-h(\Omega) はある円板 D(w_0,r) を含むので、h(\Omega) はその円板を避ける。したがって \dfrac{r}{h(z)-w_0} は \Omega から D への単射正則写像である。

第二段（最大化問題を立てる）。

\mathcal{F} = \{\, g:\Omega\to D \ \text{単射正則},\ g(z_0)=0 \,\}, \qquad M = \sup_{g\in\mathcal{F}}|g'(z_0)|

第一段より \mathcal{F}\ne\emptyset。コーシーの評価より M < \infty。\mathcal{F} は一様有界（値が D に入る）なので、モンテルの定理（）により正規族である。最大化列 g_n をとり、広義一様収束する部分列を抜けば、極限 f は正則で |f'(z_0)|=M>0。フルヴィッツの定理（（3））を g_n(z)-g_n(z') に適用すれば、f も単射である。

第三段（最大値をとるものは全射）。f が全射でないとし、\alpha\in D\setminus f(\Omega) をとる。\varphi_\alpha(w)=\dfrac{w-\alpha}{1-\bar\alpha w}（円板の自己同型）を合成すると \varphi_\alpha\circ f は 0 を避けるので、単連結性から平方根 F=\sqrt{\varphi_\alpha\circ f} が一価に定まる。さらに 0 に戻す自己同型を合成した G=\varphi_{F(z_0)}\circ F について、計算すると

|G'(z_0)| = \frac{1+|\alpha|}{2\sqrt{|\alpha|}}\,|f'(z_0)| > |f'(z_0)|

（相加相乗平均より \frac{1+t^2}{2t}>1、t=\sqrt{|\alpha|}\ne1）。M の最大性に反する。

証明の骨格は「コンパクト性で最大化元を取り出し、最大でないと仮定して改良する」——変分法そのものである。コンパクト性を与えるのがモンテルの定理で、これは第95章のアスコリ–アルツェラの定理の複素版である。

モンテルの定理

\mathcal{F} を領域 \Omega 上の正則関数の族とする。\mathcal{F} が広義一様有界（各コンパクト集合上で一様有界）ならば、\mathcal{F} は正規族である：任意の列が広義一様収束する部分列をもつ。

コーシーの積分公式より、K\subset\Omega コンパクト、K の \delta 近傍が \Omega に入るとすると、z,z'\in K、|z-z'| 小について

|f(z)-f(z')| \le \frac{2M}{\delta}\,|z-z'| \qquad (\forall f\in\mathcal{F})

すなわち族は同程度連続である。一様有界性から同程度連続性が自動的に出る——これは正則関数に固有の現象で、連続関数の族では成り立たない。あとはアスコリ–アルツェラの定理（第95章）を可算個のコンパクト集合に適用し、対角線論法で結論を得る。

境界の対応

カラテオドリの境界対応定理

\Omega を単連結領域で、その境界 \partial\Omega がジョルダン曲線（単純閉曲線）であるとする。このときリーマン写像 f:\Omega\to D は \overline\Omega から \overline D への同相写像に延長される。

より一般に、f が境界まで連続に延びることと、\partial\Omega が局所連結であることが同値である。

境界がどこまで見えるか

（1）多角形・滑らかな曲線。境界は同相に対応する。境界が C^\infty なら f も境界まで C^\infty（ケロッグ–ワルシャフスキの定理）。

（2）スリット領域。\Omega=D\setminus[0,1)。境界の一点（切れ目の上側と下側）が、円周上の二点に対応する。境界は同相には対応しない——「一点が二点に割れる」。

（3）櫛形領域。境界が局所連結でない例（無限に細かい歯をもつ領域）では、リーマン写像は境界まで連続に延びない。

（4）フラクタル境界。コッホ雪片の内部は単連結だから円板と等角同値で、境界はジョルダン曲線だから同相に対応する。しかし対応は極端に悪い：円周上のルベーグ測度と境界上の長さ測度（無限大）が、まったく釣り合わない。この釣り合いの悪さを測るのが調和測度の次元の理論である。

（5）マクミランの定理・マカロフの定理。単連結領域の調和測度は、ハウスドルフ次元がちょうど 1 の集合に台をもつ（マカロフ、1985年）。境界がどれほどフラクタルでも（次元が 1 より大きくても）、調和測度が見ているのは次元 1 の部分だけである。第42章の次元論が、ここで「境界のどこが見えるか」を答えている。

仮定を外すと

（1）\Omega=\mathbb{C} は除外される。リウヴィルの定理（（3））により、\mathbb{C}\to D の正則写像は定数しかない。\mathbb{C} と D は等角同値でない。同相ではあるので、等角同値は同相よりずっと細かい分類である。

（2）単連結性は外せない。円環 A_r=\{r < |z| < 1\} と A_{r'} が等角同値であることと r=r' は同値である。つまり円環には連続無限個の等角同値類がある（モジュラス \log(1/r) が不変量）。穴が一つ増えるだけで、分類が離散から連続に変わる。

（3）多変数では成り立たない。\mathbb{C}^2 の球 \{|z_1|^2+|z_2|^2 < 1\} と双円板 D\times D は、どちらも単連結・有界・凸だが等角同値でない（ポアンカレ、1907年）。証明は自己同型群の次元を比べる。一変数の写像定理は、一変数に固有の奇跡である。

（4）構成的でない。証明は最大化元の存在を示すだけで、写像を明示しない。実際、一般の領域についてリーマン写像を明示的に書く方法はない（多角形ならシュヴァルツ–クリストッフェル、それ以外は数値計算）。

★★ 学部後半——双曲計量とシュヴァルツ–ピックの定理

ポアンカレ計量。単位円板に

ds = \frac{2|dz|}{1-|z|^2}

という計量を入れる。円板の自己同型はこの計量の等長変換であり、逆に等長変換は自己同型（または共役）に限る。曲率は一定 -1 で、これが双曲幾何のモデルである。ユークリッドの平行線公準を満たさない幾何が、複素解析の内部から自然に現れる。

シュヴァルツ–ピックの定理。f:D\to D 正則なら

\frac{|f'(z)|}{1-|f(z)|^2} \le \frac{1}{1-|z|^2}

すなわち正則写像は双曲距離を縮める。等号は自己同型のときのみ。シュヴァルツの補題は「原点を固定する」という特別な場合にすぎず、本質は距離を縮めるという幾何的な主張である。

この視点は一般化される。任意の複素多様体に小林距離（円板からの正則写像で測る最大の距離）が定義され、正則写像は必ずそれを縮める。小林距離が非退化な多様体を双曲的という。ブロディの定理：コンパクト多様体が双曲的であることと、\mathbb{C} からの非定数正則写像（整曲線）が存在しないことは同値。

ピカールの小定理を幾何で見る。\mathbb{C}\setminus\{0,1\} の普遍被覆は円板である（単一化定理、第91章★★）。整関数 f:\mathbb{C}\to\mathbb{C}\setminus\{0,1\} があれば、単連結性から \mathbb{C}\to D へ持ち上がり、リウヴィルにより定数。したがって整関数は二つ以上の値を除外できない——これがピカールの小定理である。解析的な定理が、被覆空間と双曲幾何の言葉で一行になる。

モンテルの大定理。二つの値 a,b を取らない正則関数の族は正規族である。同じ被覆の議論による。これがモンテルの定理（一様有界性の仮定）を大幅に強めたもので、複素力学系でジュリア集合とファトゥ集合を定義する道具になる：反復 f^{\circ n} が正規族になる点の集合がファトゥ集合、その補集合がジュリア集合である。

仮定を外すと。モンテルの定理で一様有界性を「各点有界」に弱めると成り立たない。ただし「広義一様有界でないなら、ある部分列が広義一様に \infty に発散する」という形（球面距離での正規性）に言い換えれば、より広い枠組みになる。

★★★ 大学院——一様化、タイヒミュラー空間、共形場

単一化定理の全体像。任意のリーマン面 X の普遍被覆は \hat{\mathbb{C}}、\mathbb{C}、D のいずれか。したがって X は次のどれかである：

（i）球面型：\hat{\mathbb{C}} のみ。
（ii）ユークリッド型：\mathbb{C}、\mathbb{C}^*、トーラス \mathbb{C}/\Lambda。
（iii）双曲型：それ以外すべて。圧倒的多数が双曲型である。

トーラス \mathbb{C}/\Lambda の等角同値類は格子の相似類で決まり、上半平面のモジュラー群による商 \mathbb{H}/SL(2,\mathbb{Z}) がそのモジュライ空間になる。モジュラー形式の理論は、ここから始まる。

タイヒミュラー空間。種数 g\ge2 の閉曲面の複素構造のモジュライ空間は、次元 3g-3 の複素多様体である。その普遍被覆であるタイヒミュラー空間は \mathbb{C}^{3g-3} の有界領域と同相で、タイヒミュラー計量（擬等角写像の歪みで測る距離）をもつ。第89章★★のベルトラミ方程式が、この空間の座標を与える。ミルザハニによるワイル–ピーターソン体積の再帰公式（2007年、2014年フィールズ賞）は、この空間の幾何を明示的に計算した。

等角写像の数値計算と確率。離散的な近似として円充填（サーストン）がある：三角形分割を円の接触パターンで実現すると、細分の極限がリーマン写像に収束する（ローディン–サリヴァン、1987年）。離散的な組合せ論的データから、解析的な写像が復元される。

確率論との接点がシュラム–レフナー発展（SLE）である。ランダムな曲線を、リーマン写像の族がみたす微分方程式

\partial_t g_t(z) = \frac{2}{g_t(z)-\sqrt\kappa B_t}

で記述する。二次元臨界現象（パーコレーション、イジング模型、一様全域木）のスケール極限が、パラメータ \kappa の値ごとにこの曲線として現れる。共形不変性という仮定だけから、臨界指数が厳密に計算できる——スミルノフ、ヴェルナー、ドゥミニル–コパンのフィールズ賞の主題である。第94章のディリクレ問題と調和測度が、その計算の道具として使われる。

未解決に近い問い。ブレナン予想——単連結領域のリーマン写像の導関数について \int|f'|^p dA < \infty が 4/3 < p < 4 で成り立つか——は、積分手段スペクトルの理論の中心にあり未解決である。また、二次多項式の族におけるマンデルブロー集合の局所連結性（MLC予想）も、ヤッコブソン–ヨッコスの部分的な結果を超えて未解決のままである。
