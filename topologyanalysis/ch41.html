第V部　基数不変量と次元論

第41章次元の一致定理

← 第40章　被覆次元 dim 第42章　次元論の反例と、一致しない空間 →

この章の問い

  • 三つの次元は、どこまで一致するのか。
  • 可分性は、なぜ一致の条件になるのか。
  • 一致定理があると、何が言えるようになるのか。

一致定理

一致定理

可分距離空間 X について

\mathrm{ind}\,X = \mathrm{Ind}\,X = \dim X

が成り立つ。

これが第V部の中心にある定理である。三つのまったく違う定義——点と近傍、閉集合と開集合、被覆の重なり——が、同じ値を与える。

証明は三つの不等式の環である。\dim \le \mathrm{ind} \le \mathrm{Ind} \le \dim を示す。

\mathrm{ind} \le \mathrm{Ind}は一般の T_1 正規空間で成り立つ（）。

\mathrm{Ind} \le \dimを示す。n についての帰納法。\dim X \le n とし、交わらない閉集合 A, B を取る。

\{X \setminus A,\ X \setminus B\} は開被覆だから、（5）より位数 n 以下の縮小被覆 \{V_1, V_2\} がある。S = X \setminus (V_1 \cup V_2) と置くと S は A と B を分離する。

\dim S \le n-1 が示せれば、帰納法の仮定より \mathrm{Ind}\,S \le n-1、 より \mathrm{Ind}\,X \le n となる。

\dim S \le n-1 は、S の被覆を X の被覆に延ばして位数を数えることで出る。細部には \dim の閉遺伝性と、位数の計算が要る。

\dim \le \mathrm{ind}が可分性を使う部分である。\mathrm{ind}\,X \le n とする。

第二可算性より可算基底 \{B_k\} が取れ、\mathrm{ind}\,\partial B_k \le n-1 となるように選べる（各点の各近傍のなかに境界の小さい基底元が取れるから）。

S = \bigcup_k \partial B_k と置く。帰納法の仮定（\dim \le \mathrm{ind} が n-1 で成立）と可算和定理（（3））より \dim S \le n-1。

X \setminus S は零次元である（開かつ閉な集合 B_k \setminus S が基底をなす）。よって X は \dim \le n-1 の部分と \dim = 0 の部分に分かれ、和の公式より \dim X \le n。

可分性が二か所で効いている。可算基底が取れることと、可算和定理が使えることである。非可算な基底しかない空間では、境界の合併が「可算個の閉集合の合併」にならず、この議論が通らない。

ただちに従うこと

可分距離空間について、次が成り立つ。

（1）\dim \mathbb{R}^n = \mathrm{ind}\,\mathbb{R}^n = \mathrm{Ind}\,\mathbb{R}^n = n。
（2）n \ne m なら \mathbb{R}^n と \mathbb{R}^m は同相でない（領域不変性）。
（3）分解定理——\dim X \le n であることと、X が n+1 個の零次元集合の合併であることは同値。
（4）和の公式 \dim(A \cup B) \le \dim A + \dim B + 1。
（5）可算和定理 \dim \bigcup_n F_n = \sup_n \dim F_n（F_n 閉）。
（6）積の不等式 \dim(X \times Y) \le \dim X + \dim Y。

（1）\le n は \mathrm{ind} で（第38章）、\ge n は \dim で（ルベーグの被覆定理、第40章）示した。一致定理が二つをつなぐ。

（2）同相なら次元が等しいが、（1）より異なる。「次元が位相的に定まる」という事実が、領域不変性を与える。

（3）から（6）は、\dim と \mathrm{Ind} の性質（第39章・第40章）を一致定理で移す。

一致の範囲

どこまで一致するか

（1）可分距離空間　\mathrm{ind} = \mathrm{Ind} = \dim。
（2）一般の距離空間　\mathrm{Ind} = \dim（カトゥートフ–モリタ）。\mathrm{ind} は一致しないことがある。
（3）コンパクトハウスドルフ空間　\dim \le \mathrm{Ind} のみ。三つとも異なりうる。
（4）一般の正規空間　\dim \le \mathrm{Ind}、\mathrm{ind} \le \mathrm{Ind} のみ。

可分性を外すと、まず \mathrm{ind} が落ちる。ロクトノフの例（第42章）は、完備距離空間で \mathrm{ind}=0、\mathrm{Ind}=\dim=1。

距離化可能性を外すと、\mathrm{Ind} と \dim も分かれる。コンパクトハウスドルフ空間で \dim = 1、\mathrm{Ind} = 2 という例がある（フィリポフ）。

分解定理を読む

（3）の分解定理は、次元の意味をもっとも直接に述べている。丁寧に見ておく。

主張。可分距離空間 X について、\dim X \le n \iff X = Z_0 \cup \cdots \cup Z_n（各 Z_k は零次元）。

例で確かめる。\mathbb{R} は \mathbb{Q} \cup (\mathbb{R}\setminus\mathbb{Q}) と書ける。どちらも零次元（第38章）。二枚なので \dim \mathbb{R} \le 1。

\mathbb{R}^2 はどうか。座標が両方有理数、片方だけ有理数、両方無理数——という分け方では三枚必要に見える。実際には

\mathbb{R}^2 = \{(x,y) : x \in \mathbb{Q}\} \cup \{(x,y) : x \notin \mathbb{Q},\ y \in \mathbb{Q}\} \cup \{(x,y) : x,y \notin \mathbb{Q}\}

で、各々が零次元であることを確かめれば \dim \mathbb{R}^2 \le 2 になる。ただし「三枚で済む」ことは、各片が本当に零次元であることを要する——単に定義から出るわけではない。

証明の方向。\Leftarrow は和の公式の繰り返しで従う。\Rightarrow が実質である。

\dim X \le n とする。可算基底 \{B_k\} を、境界の次元が n-1 以下になるように取る。S = \bigcup_k \partial B_k は \dim \le n-1 で、X \setminus S は零次元。

帰納法の仮定より S = Z_0 \cup \cdots \cup Z_{n-1} と分解でき、Z_n = X \setminus S を足せば n+1 枚になる。

何を意味するか。「n 次元」とは「零次元のものを n+1 枚重ねてできている」ということである。

零次元空間はカントール集合の部分空間だった（）。したがって n 次元の可分距離空間は、カントール集合的なものを n+1 枚重ねた構造をもつ。

埋め込み定理との関係。分解定理から、次の定理が出る。

\dim X \le n の可分距離空間は、\mathbb{R}^{2n+1} に埋め込める。

メンガー–ネーベリング Menger–Nöbeling の定理という。2n+1 という数は最良である——\mathbb{R}^{2n} には埋め込めない n 次元空間がある。

第9章★★で述べた「どこに入るかを問う」方法が、次元論でも中心的である。普遍空間としてメンガーの普遍曲線（n=1 の場合）が知られている。

可分性を外すとどうなるか

（2）のカトゥートフ–モリタの定理を述べる。可分でない距離空間でも、二つは一致する。

主張。距離空間 X について \mathrm{Ind}\,X = \dim X。

証明の道具。第32章の \sigma-離散な基底（ビングの定理）が使われる。可算基底の代わりに、可算個の離散族からなる基底を使う。

各離散族について、境界の合併を取る。離散族の境界の合併は、可算和定理が使える形になる。可分な場合の証明が、ほぼそのまま通る。

なぜ \mathrm{ind} だけが落ちるのか。\mathrm{ind} の議論では、点のまわりの境界を集めて可算和定理を使う必要があった。

可分でなければ、境界を可算個に集められない。\sigma-離散な基底があっても、\mathrm{ind} の定義が点ごとなので、離散族の構造を活かせない。

ロクトノフの例。一九六二年、ロクトノフ Roy は完備距離空間 \Delta で

\mathrm{ind}\,\Delta = 0, \qquad \mathrm{Ind}\,\Delta = \dim\Delta = 1

となるものを構成した。零次元（開かつ閉な基底をもつ）なのに、閉集合の分離では次元が落ちない。

構成は複雑である。\{0,1\}^{\omega_1} の部分空間として作られ、非可算性が本質的に使われる。

コンパクトでの破れ。フィリポフ Filippov は一九七〇年に、コンパクトハウスドルフ空間で \dim = 1、\mathrm{Ind} = 2 という例を作った。連続体仮説を仮定する。

ここでも集合論が入り込む。第36章のスーリン問題、第32章の正規ムーア空間予想に続いて、次元論でも独立性が現れる。

まとめ。一致定理の成立範囲は、可算性がどこまで効くかで決まる。

可分距離空間では、可算基底が三つの定義をつなぐ。距離空間では \sigma-離散基底が二つをつなぐ。それ以上の一般性では、つなぐ道具がない。

第32章の距離化定理と同じ構図である。可算性が局所と大域を橋渡しする——第7章から繰り返し現れてきた主題が、次元論でも中心にある。

演習

基本
  1. \dim \mathbb{R} = 1 を、一致定理を使って述べよ。
  2. \mathbb{R} = \mathbb{Q} \cup (\mathbb{R}\setminus\mathbb{Q}) が分解定理の例になっていることを確かめよ。
  3. 領域不変性が一致定理から従う理由を述べよ。
  4. \dim S^n を求めよ。
証明
  1. の \mathrm{Ind} \le \dim を、分離集合を作る部分を明示して示せ。（30点）
  2. の \dim \le \mathrm{ind} で、可分性がどこで効いているかを二か所とも述べよ。（25点）
  3. 分解定理の \Leftarrow を、和の公式から示せ。（20点）
発展
  1. \mathbb{R}^2 を三枚の零次元集合に分解し、各片が零次元であることを示せ。（35点）
  2. メンガー–ネーベリングの埋め込み定理を述べ、2n+1 が最良である理由を説明せよ。（35点）
