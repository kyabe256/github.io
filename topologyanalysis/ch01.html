序論　数学の文章をどう読むか

第1章定義・定理・証明——数学の文章の読み方

第2章　集合・写像・同値関係 →

この章の問い

  • 定義・定理・証明という形式は、何のためにあるのか。
  • 「明らか」と書いてよいのは、どんなときか。
  • 定理の仮定が本当に必要かどうかを、どうやって確かめるのか。

数学の文章は、三つの役割に分かれている

数学の本を読みにくくしているのは、記号の多さではない。文が三つの異なる役割を担っており、それぞれ読み方が違うのに、見た目が似ていることである。まずその区別をつけておきたい。

定義——言葉の意味を定める文。これは主張ではないので、正しいか誤っているかを問えない。問えるのは「便利か」「後の議論が通るか」だけである。定義を読んで「なぜそう決めるのか」と思ったら、その疑問は正しい。本書は定義の前に、必ずその問いに答える。

定理——主張する文。仮定と結論からなり、真偽を問える。仮定のどれを外しても成り立たなくなるように書かれているのが、よい定理である。

証明——定理が真であることを、既に認めた事柄から導く文。証明は「なぜ正しいか」を説明するのであって、「どうやって思いついたか」を説明するのではない。この二つが違うことが、数学の文章を難しくしている最大の原因である。

この本は、思いついた順序のほうも書く。定義の前に動機を置き、証明の前に方針を述べるのは、そのためである。

定理の形——仮定と結論

定理はほぼすべて「P ならば Q」の形に書ける。ここで P を仮定、Q を結論という。

この形について、初学者がつまずく点が三つある。

第一に、P が偽のとき「P ならば Q」は真である。「空集合のすべての元は赤い」は真の主張である。これは言葉遊びではない。この約束があるおかげで、場合分けのたびに例外を書かずに済む。

第二に、逆・裏・対偶を混同しないこと。「P ならば Q」に対して、逆は「Q ならば P」、裏は「P でないならば Q でない」、そして対偶は「Q でないならば P でない」である。

もとの命題と対偶は同値であり、逆と裏は同値である。だがもとの命題と逆は同値でない。証明に行き詰まったら対偶を証明してみる——これは本書で何度も使う手である。

第三に、「必要」と「十分」の向き。「P ならば Q」が成り立つとき、P は Q の十分条件であり、Q は P の必要条件である。向きを取り違えると、定理の意味が逆になる。

二つの主張 P と Q について、「P ならば Q」と「Q ならば P」がともに成り立つとき、P と Q は同値であるといい、P \iff Q と書く。

同値であることを示すには、両方向を示さなければならない。片方だけ示して終わる誤りは、驚くほど頻繁に起きる。三つ以上の条件が同値であることを示すときは、(1) \Rightarrow (2) \Rightarrow (3) \Rightarrow (1) のように環状に回すと手間が減る。本書ではこの手を第20章で本格的に使う。

証明の型

証明の書き方には、繰り返し現れる型がある。型を知っていれば、証明を読むときに「いま何をしているのか」が見える。

直接証明——仮定から出発し、既知の事柄を使って結論に至る。

対偶による証明——結論の否定から出発し、仮定の否定に至る。結論が「〜でない」という形のときに有効である。

背理法——仮定と結論の否定をともに認めて、矛盾を導く。強力だが、得られるのは「そうでないことはありえない」という情報だけで、具体物は手に入らない。この違いは第3章（選択公理）と第4章で重要になる。

数学的帰納法——自然数で添字づけられた主張の列に使う。後に第4章で、超限帰納法へ拡張する。

構成による証明——「存在する」という主張を、実際に作って示す。背理法による存在証明と対比される。

「明らか」と書いてよいとき

数学の文章には「明らかに」「容易に分かる」「同様にして」という語が頻繁に現れる。これらは読者を最も苛立たせる語でもある。

本書の方針を先に述べておく。「明らか」と書くのは、直前に示した議論をそのまま繰り返せば済む場合に限る。そしてその場合でも、何を繰り返すのかを述べる。

読者の側の作法も述べておきたい。「明らか」と書かれていて明らかでなかったら、それは読者の落ち度ではない。著者が省略の判断を誤ったか、読者がまだ必要な準備を終えていないかのどちらかである。後者であれば、どの準備が足りないのかを特定することが、次の一歩になる。

命題「P ならば Q」と、その対偶「Q でないならば P でない」は同値である。

「P ならば Q」が真であるとし、Q でないと仮定する。もし P であれば、仮定より Q が従い、Q でないことに反する。よって P でない。逆向きも同様に示される——「Q でないならば P でない」が真であるとし、P であると仮定すると、Q でないとすれば P でないことになって矛盾する。よって Q である。

いま「逆向きも同様に示される」と書いたが、実際には書き下した。「同様」で済ませてよいのは、読者が自分で再現できることが確かな場合だけである。ここでは、対偶という概念を導入したばかりなので、省略しなかった。

集合の言葉で書き直す——なぜ記号を使うのか

前節の議論は日本語だけで書けた。では、なぜ数学は記号を使うのか。答えは「短くするため」ではない。日本語では区別しにくい二つの主張を、区別するためである。

量化子の順序。次の二つの文を比べてほしい。

（甲）どんな \varepsilon > 0 に対しても、ある N が存在して、n \ge N ならば |a_n - a| < \varepsilon。

（乙）ある N が存在して、どんな \varepsilon > 0 に対しても、n \ge N ならば |a_n - a| < \varepsilon。

記号で書けば違いは一目で分かる。

\forall \varepsilon > 0\ \exists N\ \forall n \ge N:\ |a_n - a| < \varepsilon \exists N\ \forall \varepsilon > 0\ \forall n \ge N:\ |a_n - a| < \varepsilon

（甲）は数列 (a_n) が a に収束することを言う。（乙）は、ある番号から先で a_n が a に完全に一致することを言う——なぜなら \varepsilon をいくらでも小さくできるからである。語順を入れ替えただけで、意味がまったく違う主張になった。

N は何に依存するか。（甲）では N は \varepsilon の後に来るので、\varepsilon に依存してよい。これを明示したいときは N(\varepsilon) と書く。この依存が許されるかどうかが、一様収束と各点収束を分ける（第47章）。本書でもっとも重要な区別の一つである。

否定の作り方。量化子を含む文の否定は、機械的に作れる。\forall と \exists を入れ替え、最後の主張を否定する。

\lnot\big(\forall \varepsilon > 0\ \exists N\ \forall n \ge N:\ |a_n - a| < \varepsilon\big) \iff \exists \varepsilon > 0\ \forall N\ \exists n \ge N:\ |a_n - a| \ge \varepsilon

つまり「収束しない」とは、ある \varepsilon が存在して、どんなに先へ行っても a から \varepsilon 以上離れる番号があるということである。否定を機械的に作れることが、背理法と対偶を使える条件になっている。

記号は、思考の節約のためではなく、あいまいさの排除のためにある。日本語で書いたときに二通りに読める文が、記号では一通りにしか読めない——それが記号を使う理由である。

証明とは何か——形式化できるのか

本章では証明を「既に認めた事柄から導く文」と述べた。では「導く」とは何か。この問いは二〇世紀の数学基礎論の出発点であり、いまも完全には決着していない。

形式的証明という理想。二〇世紀初頭、証明を完全に機械的な手続きに還元する計画が立てられた。公理を並べ、推論規則を定め、証明とは記号列の有限列であって、各行が公理か、前の行から規則によって得られるものと定義する。この定義のもとでは、ある記号列が証明であるかどうかは機械的に確かめられる。

そして限界が示された。ゲーデル Gödel の不完全性定理は、この計画に本質的な制約があることを示した。算術を含むだけの強さを持ち、かつ無矛盾な公理系は、その体系内で証明も反証もできない主張を必ず含む。しかも、その体系自身の無矛盾性は、その体系内では証明できない。

これは数学を否定するのか。しない。不完全性定理が述べているのは「真だが証明できない主張がある」ことであって、「証明できたことが怪しい」ことではない。証明できたものは依然として証明できている。ただし、公理系を選ぶという行為が、数学の外にあることが明らかになった。

本書に関わる具体例。この抽象的な話は、本書の内容に直接関わる。

第3章で扱う選択公理は、他の公理から証明も反証もできない。採用するかどうかは選択である。採用すればチコノフ Tychonoff の定理（第21章）が得られ、同時にバナッハ–タルスキ Banach–Tarski の逆説のような直観に反する帰結も生じる。第4章で扱う連続体仮説も同様に独立であり、第36章のスーリン Souslin 問題は、その独立性が位相空間の性質として現れる例である。

「この定理は成り立つか」という問いに、「どの公理系の上で問うているか次第だ」という答えが返ってくる場面が、本書には実際に現れる。

実務としての証明。他方で、数学者が日々書いている証明は、形式的証明ではない。読者が形式的証明に翻訳できると納得するに足る説明である。どこまで書けば納得に足るかは、時代と読者によって変わる。一九世紀には認められた議論が、いまは不十分とされることがある（第43章で実数の構成を扱うときに、この例を見る）。

近年は、証明を計算機で検証する試みが進んでいる。四色定理のように、計算機の助けなしには検証しきれない証明も現れた。「証明とは何か」という問いは、技術の変化によって形を変えながら続いている。

演習

基本
  1. 命題「x > 2 ならば x^2 > 4」の逆・裏・対偶をそれぞれ述べ、真偽を判定せよ。
  2. 「空集合のすべての元は赤い」が真である理由を説明せよ。
  3. 三つの条件が同値であることを示すとき、環状に示すと手間が減るのはなぜか。
  4. 背理法による存在証明と構成による存在証明で、得られる情報がどう違うか述べよ。
証明
  1. 命題 の証明において、「逆向きも同様」で済ませずに書き下した理由を説明せよ。（10点）
  2. 数列 (a_n) が a に収束しないことの定義を、量化子を用いて書き下せ。さらに、その否定を作ってもとの定義に戻ることを確かめよ。（10点）
発展
  1. 「どんな \varepsilon > 0 に対してもある N が存在して」という語順と、「ある N が存在してどんな \varepsilon > 0 に対しても」という語順で、主張がまったく異なることを示した。この違いが、一様収束と各点収束の区別（第47章）にどう対応するかを予想して述べよ。（20点）
