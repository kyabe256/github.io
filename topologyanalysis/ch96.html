第XIII部　位相と解析の交差

第96章Stone–Weierstrassの定理

← 第95章　関数空間の位相とAscoli–Arzelàの定理 第97章　何が何を支えているか——本書の地図 →

この章の問い

  • なぜ多項式で連続関数を近似できるのか。
  • 近似の理由は、多項式のどんな性質にあるのか。
  • 複素の場合に条件が一つ増えるのは、なぜか。

近似の理由を突き止める

本書では稠密性を何度も使ってきた。三角多項式が C(\mathbb{T}) で稠密（第81章）、多項式が C(\sigma(T)) で稠密（第77章の関数計算）、連続関数が L^p で稠密（第62章）。

本章は、これらの多くが一つの定理の系であることを示す。鍵は「多項式である」ことではなく、「代数をなし、点を分離する」という二つの性質だけである。

ワイエルシュトラスの近似定理

f\in C([a,b],\mathbb{R}) と \varepsilon>0 に対し、多項式 p があって \sup_{[a,b]}|f-p| < \varepsilon。

ベルンシュタインによる構成的な証明（[a,b]=[0,1] としてよい）。

B_nf(x) = \sum_{k=0}^{n}f\Big(\frac kn\Big)\binom nk x^k(1-x)^{n-k}

と置く（ベルンシュタイン多項式）。確率論的に読むと、B_nf(x) は「成功確率 x の n 回の試行で成功率 S_n/n を観測したときの f(S_n/n) の期待値」である。

大数の法則により S_n/n\to x（確率収束）。定量的には、チェビシェフの不等式（）から

\mathbb{P}\Big(\Big|\frac{S_n}{n}-x\Big|\ge\delta\Big) \le \frac{x(1-x)}{n\delta^2} \le \frac{1}{4n\delta^2}

f の一様連続性から \delta を「|s-x| < \delta\Rightarrow|f(s)-f(x)| < \varepsilon/2」ととると

|B_nf(x)-f(x)| \le \mathbb{E}\big|f(S_n/n)-f(x)\big| \le \frac\varepsilon2 + 2\|f\|_\infty\cdot\frac{1}{4n\delta^2}

右辺は x に依らず、n を大きくすれば \varepsilon 未満になる。

大数の法則という確率論の定理が、近似定理の証明になっている。「確率変数を平均すると集中する」ことと「近似の精度が上がる」ことが、同じ現象である。

ストーン–ワイエルシュトラスの定理

ストーン–ワイエルシュトラスの定理

X をコンパクトハウスドルフ空間とする。

（実の場合）\mathcal{A}\subset C(X,\mathbb{R}) が

（1）部分代数である（和・積・スカラー倍で閉じる）、
（2）定数関数を含む（あるいは「どの点でも消えない」）、
（3）点を分離する：x\ne y なら f(x)\ne f(y) なる f\in\mathcal{A} がある

をみたすなら、\mathcal{A} は C(X,\mathbb{R}) で一様稠密である。

（複素の場合）\mathcal{A}\subset C(X,\mathbb{C}) については、（1）（2）（3）に加えて

（4）複素共役で閉じる：f\in\mathcal{A}\Rightarrow\bar f\in\mathcal{A}

が必要である。

第一段：閉包は絶対値で閉じる。\overline{\mathcal{A}}（一様閉包）も代数である。f\in\overline{\mathcal{A}}、\|f\|_\infty\le M とする。|t| を [-M,M] 上で多項式で一様近似し（；定数項は（2）で吸収できる）、t=f(x) を代入すれば |f|\in\overline{\mathcal{A}}。

第二段：束になる。\max(f,g)=\frac{f+g+|f-g|}{2}、\min(f,g)=\frac{f+g-|f-g|}{2} なので、\overline{\mathcal{A}} は有限個の最大・最小で閉じる。

第三段：二点で値を合わせる。x\ne y と \alpha,\beta\in\mathbb{R} に対し、h(x)=\alpha、h(y)=\beta なる h\in\mathcal{A} がある。分離する g をとり、h=\alpha+(\beta-\alpha)\dfrac{g-g(x)}{g(y)-g(x)} と置けばよい（定数関数が使えるので \mathcal{A} に入る）。

第四段：貼り合わせ。f\in C(X)、\varepsilon>0 とする。各対 (x,y) について h_{xy}(x)=f(x)、h_{xy}(y)=f(y) なる h_{xy} をとる。

x を固定する。各 y について U_y=\{z : h_{xy}(z) < f(z)+\varepsilon\} は y を含む開集合。X のコンパクト性より有限個 U_{y_1},\dots,U_{y_k} で覆え、g_x=\min_j h_{xy_j} と置くと

g_x < f+\varepsilon \ \ (X \text{ 全体で}), \qquad g_x(x)=f(x)

次に V_x=\{z : g_x(z)>f(z)-\varepsilon\} も x を含む開集合。再びコンパクト性で有限個で覆い、g=\max_i g_{x_i} と置くと

f-\varepsilon < g < f+\varepsilon

g\in\overline{\mathcal{A}} なので結論を得る。

複素の場合。（4）があれば \mathrm{Re}\,f=\frac{f+\bar f}{2}、\mathrm{Im}\,f=\frac{f-\bar f}{2i} が \mathcal{A} に入り、実部の全体 \mathcal{A}_{\mathbb{R}} が実の場合の仮定をみたす。実部と虚部を別々に近似すればよい。

証明の実質は「絶対値が近似できる」という一点である。それさえ言えれば、あとは束の構造とコンパクト性による貼り合わせで機械的に進む。

複素の場合に共役が要る理由

X=\overline D（閉単位円板）、\mathcal{A}=\{多項式\} とする。これは代数であり、定数を含み、点を分離する。しかし一様閉包はディスク環（円板で正則、閉円板で連続な関数の全体）であって、C(\overline D) 全体ではない。

\bar z は多項式で一様近似できない——できるとすればその極限は正則になり（ワイエルシュトラスの収束定理、（7））、\bar z が正則でないことに反する（（1））。

第89章の剛性が、ここで近似の障害として現れている。複素の場合の条件（4）は、この障害を取り除くためにある。共役を許せば |z|^2=z\bar z が使え、実部・虚部が分離できるようになる。

系として出てくるもの

（1）多項式の稠密性。X=[a,b]、\mathcal{A}=\{多項式\}。座標関数 x が点を分離する。

（2）三角多項式の稠密性。X=\mathbb{T}、\mathcal{A}=\{\sum_{|n|\le N}c_ne^{in\theta}\}。積・和で閉じ、共役で閉じ（\overline{e^{in\theta}}=e^{-in\theta}）、e^{i\theta} が点を分離する。第81章ではフェイェール核で示したが、こちらは核を使わない純位相的な証明である。

（3）多変数の多項式。X\subset\mathbb{R}^n コンパクト、\mathcal{A}=\mathbb{R}[x_1,\dots,x_n]。座標関数の組が点を分離する。

（4）積空間の関数。C(X\times Y) において、\sum_i f_i(x)g_i(y) の形の関数（有限階テンソル）が稠密。これが第56章のフビニの定理を関数解析的に使うときの基礎になる。

（5）関数計算。X=\sigma(T)\subset\mathbb{R}、\mathcal{A}=\{多項式\}。第77章の連続関数計算の延長が、これで正当化される。

（6）ゲルファント–ナイマルク。X=\Delta(A)、\mathcal{A}=\Gamma(A)。点を分離するのは指標の定義から、共役で閉じるのはシースター環の対合から。第79章の構造定理の全射性は、この定理そのものだった。

（7）リースの表現定理の一意性。測度が連続関数上の積分を決めることから、稠密な部分環での一致で十分になる。

条件を外すと

（1）点を分離しない。X=[-1,1]、\mathcal{A}=\{偶多項式\}。x と -x を分離できず、閉包は偶関数全体。f(x)=x は近似できない。

（2）どこかで消える。\mathcal{A}=\{p : p(0)=0\}（X=[0,1]）。閉包は \{f : f(0)=0\}。条件（2）が必要な理由である。

（3）代数でない。X=[0,1]、\mathcal{A}=\{一次関数\}。点を分離し定数を含むが、積で閉じない。閉包は自分自身。

（4）複素で共役なし。上述のディスク環。

（5）X がコンパクトでない。X=\mathbb{R}、C_b(\mathbb{R}) で多項式の閉包を考えても、有界でない関数は入らない。正しい定式化は C_0(X)（無限遠で消える連続関数）についての形で、そこでは条件（2）を「どの点でも消えない」に替える。

（6）一様収束でなければ別の話。L^2 での稠密性は、一様稠密性から従う（X が有限測度なら）が、逆は言えない。どの位相で稠密かを混同しないこと。

二つの証明の対比

三角多項式の稠密性には、本書で二つの証明が与えられた。

第81章（フェイェール核）。具体的な核を構成し、近似単位元の性質を確かめる。構成的で、収束の速さも読める。フーリエ級数に固有の議論である。

本章（ストーン–ワイエルシュトラス）。代数的・位相的な性質だけを使う。構成的でないが、適用範囲がはるかに広い。

「なぜ近似できるのか」への答えが違う。前者は「核が質量を集中させるから」、後者は「代数が点を分離するから」。後者の答えのほうが一般的だが、前者のほうが定量的である——数学の定理には、しばしばこの二種類の理解が並立する。

★★ 学部後半——定量化と、近似の速さ

ジャクソンの定理。ストーン–ワイエルシュトラスは速さを何も言わない。定量版：f が [-1,1] 上で連続度 \omega をもつとき、n 次多項式による最良近似 E_n(f) は

E_n(f) \le C\,\omega\Big(\frac1n\Big)

f\in C^k なら E_n(f)\le Cn^{-k}\omega(f^{(k)};1/n)。逆向きのベルンシュタインの定理：E_n(f)=O(n^{-\alpha})（0 < \alpha < 1）なら f はヘルダー指数 \alpha。近似の速さと滑らかさが、正確に対応する——第80章の「フーリエ係数の減衰＝滑らかさ」と同じ主題である。

ベルンシュタイン多項式の速さは遅い。B_nf の誤差は一般に O(n^{-1}) より速くならない（f が C^\infty でも）。構成的だが最適ではない。最良近似を与える多項式はチェビシェフの等振動定理で特徴づけられ、実際の計算にはチェビシェフ補間が使われる。

ミュンツ–サースの定理。\{1,x^{\lambda_1},x^{\lambda_2},\dots\}（\lambda_k>0 増加）が C[0,1] で稠密であることと

\sum_k \frac{1}{\lambda_k} = \infty

は同値。したがって \{1,x^2,x^4,\dots\} は稠密だが、\{1,x,x^4,x^9,\dots\}（平方数）は稠密でない。代数でない部分空間の稠密性は、こうした定量的な条件で決まる。ストーン–ワイエルシュトラスが「代数である」ことを要求するのは、この難しさを回避するためである。

格子版（ストーンの束定理）。代数のかわりに束（最大・最小で閉じる）であれば、（2）（3）の条件のもとで同じ結論が成り立つ。本章の証明は実は束であることしか使っておらず、代数であることは「絶対値が作れる」ためだけに要る。

仮定を外すと。X のハウスドルフ性を外すと、C(X) が点を分離できない（同一視される点がある）。コンパクト性を外すと C_0 の形になる。値域を \mathbb{R} や \mathbb{C} でなく一般のバナッハ環にすると、ベクトル値の場合は成り立たないことがある——テンソル積の理論（近似性質、エンフロの反例、第63章）が関わってくる。

★★★ 大学院——双対としての定式化と、量子化

ゲルファント双対性としての読み替え。ストーン–ワイエルシュトラスは、可換シースター環の圏とコンパクトハウスドルフ空間の圏の反変同値

X \ \longmapsto\ C(X), \qquad A \ \longmapsto\ \Delta(A)

の一部である（第79章）。「点を分離する部分環は全体」という主張は、圏論的には「単射の双対が全射」ということにあたる。第23章のストーン–チェックのコンパクト化、第27章のベールの定理、本章の近似定理は、同じ双対性の三つの側面である。

非可換化。非可換シースター環では「点」がないので、この定理の直接の類似はない。かわりに、部分環がいつ全体になるかを問うストーン–ワイエルシュトラス予想がある：非可換シースター環 A の部分環 B が A の純粋状態を分離すれば B=A か。一般には未解決で、いくつかのクラス（型 \mathrm{I}、核型）でのみ知られている。

量子力学への応用。ワイル量子化では、古典的な可観測量（位相空間上の関数）を作用素に対応させる。対応が「代数準同型」にならない——これが量子化の本質的な困難（グローネヴォルト–ファン・ホーヴの定理）である。近似の言葉では、古典極限 \hbar\to0 で交換子が \hbar 倍のポアソン括弧に収束する——「漸近的にだけ代数準同型」になる。変形量子化の理論（コンツェヴィッチの形式性定理、1997年）は、この漸近的な対応を形式的冪級数の水準で完全に構成した。

多項式の正値性。ストーン–ワイエルシュトラスは符号を制御しない。正の関数を正の多項式（平方和）で近似できるか——これが実代数幾何の主題である。ヒルベルトの第17問題（正定値多項式は有理関数の平方和か）はアルティンが肯定的に解決した（1927年）が、多項式の平方和では足りない（モツキンの反例 x^4y^2+x^2y^4-3x^2y^2z^2+z^6）。プッチナルやシュミュートゲンの定理は、コンパクトな半代数集合上で正の多項式が「明示的な平方和の組み合わせ」で書けることを保証し、これが多項式最適化（半正定値計画法への緩和）の理論的な基礎になっている。

未解決に近い問い。ラサール階層の収束の速さ、および有限収束が起こる条件の完全な特徴づけは、実代数幾何と最適化の境界で現在も研究されている。また、無限次元でのストーン–ワイエルシュトラス型の結果——たとえばバナッハ空間上の多項式による稠密性——は、空間の幾何（近似性質）に強く依存し、統一的な理論はまだない。
