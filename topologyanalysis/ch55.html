第VII部　測度と積分

第55章Lebesgue積分と収束定理

← 第54章　可測関数 第56章　積測度とFubini–Tonelli →

この章の問い

  • ルベーグ積分は、どう定義されるのか。
  • 極限と積分は、どんな条件で交換できるのか。
  • 三つの収束定理は、どういう関係にあるのか。

積分を三段階で定義する

第一段——単関数

s = \sum_{k=1}^{n}c_k\mathbf{1}_{E_k}（c_k \ge 0、E_k は互いに交わらない可測集合）に対し

\int_X s \,d\mu = \sum_{k=1}^{n} c_k\,\mu(E_k)

と定める（0\cdot\infty = 0 と約束する）。この値は s の表し方によらない。

第二段——非負可測関数

f \ge 0 可測に対し

\int_X f\,d\mu = \sup\Big\{\, \int_X s\,d\mu \ \Big|\ s \text{ は単関数},\ 0\le s\le f \,\Big\}

と定める。

第三段——一般の可測関数

f^+ = \max(f,0)、f^- = \max(-f,0) とおく。\int f^+ と \int f^- の少なくとも一方が有限なら

\int_X f\,d\mu = \int_X f^+\,d\mu - \int_X f^-\,d\mu

と定める。両方が有限のとき f は可積分であるという。f が可積分であることと \int|f|<\infty は同値。

第二段の上限は、 の単関数列 s_n \uparrow f について \lim_n \int s_n に等しい。それが単調収束定理の内容である。

ルベーグ積分が絶対可積分を基本にするのは、第49章で見た「可算加法性には絶対収束が要る」という事情による。

三つの収束定理

単調収束定理

非負可測関数の列 0\le f_1\le f_2\le\cdots が f に各点収束するなら

\int_X f_n\,d\mu \ \longrightarrow\ \int_X f\,d\mu

\le。f_n \le f より \int f_n \le \int f、極限も \le \int f。

\ge。単関数 0\le s\le f と 0 を取り、E_n = \{\, x \mid f_n(x) \ge c\,s(x) \,\} とおく。E_n は増加列で \bigcup_n E_n = X（f_n \uparrow f \ge s > cs が s>0 の点で成り立つから）。

\int_X f_n \ \ge\ \int_{E_n} f_n \ \ge\ c\int_{E_n}s = c\sum_k c_k\,\mu(E_k\cap E_n)

測度の連続性（（1））より \mu(E_k\cap E_n)\to\mu(E_k)。よって \lim_n\int f_n \ge c\int s。

c\to1、s について上限を取れば \lim_n \int f_n \ge \int f。

証明の心臓は測度の連続性、すなわち可算加法性である。単調収束定理は、可算加法性を積分の言葉に翻訳したものにほかならない。

第52章で「可算加法性がないと極限と積分が交換できない」と述べたのは、この定理のことである。

ファトゥの補題

非負可測関数の列 (f_n) について

\int_X \liminf_n f_n \,d\mu \ \le\ \liminf_n \int_X f_n\,d\mu

g_N = \inf_{n\ge N}f_n とおくと、g_N は非負可測で増加し、g_N \uparrow \liminf_n f_n。

より \int g_N \to \int\liminf f_n。一方 g_N \le f_n（n\ge N）より \int g_N \le \inf_{n\ge N}\int f_n。両辺で N\to\infty。

等号にならない

f_n = n\mathbf{1}_{(0,1/n)} とすると \liminf_n f_n = 0 で左辺は 0、\int f_n = 1 で右辺は 1。

f_n = \mathbf{1}_{[n,n+1]} でも同じく 0<1。第50章の「背が伸びる」「横へ逃げる」が、そのままファトゥの補題の不等号を説明している。

質量が消えることはあるが、湧くことはない——それがこの不等式の向きである。

優収束定理

可測関数の列 (f_n) がほとんどいたるところ f に収束し、可積分な g があって |f_n|\le g がほとんどいたるところ成り立つとする。このとき f は可積分で

\int_X |f_n - f|\,d\mu \to 0, \qquad \text{したがって}\quad \int_X f_n\,d\mu \to \int_X f\,d\mu

|f|\le g より f は可積分。|f_n-f|\le 2g なので 2g - |f_n-f| \ge 0。

を 2g-|f_n-f| に適用すると

\int 2g \ \le\ \liminf_n \int\big(2g - |f_n-f|\big) = \int 2g - \limsup_n \int|f_n-f|

\int 2g<\infty なので引けて、\limsup_n\int|f_n-f|\le0。よって \int|f_n-f|\to0。

優収束定理はファトゥの補題の系である。そしてファトゥの補題は単調収束定理の系である。

三つは同じ一つの事実——可算加法性——の三通りの姿である。使い分けは、手元に何があるかで決まる。

単調性があるなら単調収束定理。不等式だけでよいならファトゥ。押さえる関数があるなら優収束定理。

優関数がないと壊れる

の f_n = n\mathbf{1}_{(0,1/n)} を押さえるには g(x)\ge 1/x が要るが、\int_0^1 1/x\,dx = \infty で可積分でない。

f_n = \frac1n\mathbf{1}_{[0,n]}（第50章の「平らに広がる」）では g \ge \frac1n が [0,n] で要るので g \ge \sup_n \frac1n\mathbf{1}_{[0,n]}、これも可積分でない。

第50章で挙げた三つの型は、すべて「優関数が取れない」型だった。

積分の基本性質

（1）線型性。\int(af+bg)=a\int f+b\int g（可積分な f,g について）。
（2）単調性。f\le g なら \int f\le\int g。
（3）\left|\int f\right| \le \int|f|。
（4）\int|f|=0 であることと f=0 がほとんどいたるところ成り立つことは同値。
（5）項別積分。f_n\ge0 可測なら \int\sum_n f_n = \sum_n \int f_n。

（1）の加法性が意外に手間である。単関数では明らか。非負可測 f,g については で s_n\uparrow f、t_n\uparrow g を取れば s_n+t_n\uparrow f+g なので から従う。一般の場合は正部分と負部分に分けて組み直す。

（4）\Leftarrow は明らか。\Rightarrow：E_n=\{|f|>1/n\} とすると \mu(E_n)/n \le \int|f| = 0 より \mu(E_n)=0、\{f\ne0\}=\bigcup_n E_n。

（5）\sum_{n\le N}f_n \uparrow \sum_n f_n に 。項別積分が無条件に成り立つのが、非負の場合の強みである。

チェビシェフの不等式

f\ge0 可測、a>0 について \mu(\{f\ge a\}) \le \frac1a\int_X f\,d\mu。

a\,\mathbf{1}_{\{f\ge a\}} \le f を積分する。

積分と極限の交換——より弱い十分条件

優収束定理の「可積分な優関数」は、実用上ほとんどの場面で足りる。だが、もう少し弱い条件でも交換できる。

一様可積分性。可測関数の族 \mathcal{F} が一様可積分であるとは、

\lim_{M\to\infty}\ \sup_{f\in\mathcal{F}}\int_{\{|f|>M\}}|f|\,d\mu = 0

となることをいう。可積分な優関数があれば一様可積分（優収束定理を g\mathbf{1}_{\{g>M\}} に使う）。

ヴィタリの収束定理。\mu(X)<\infty とする。f_n\to f が測度収束し、(f_n) が一様可積分なら \int|f_n-f|\to0。

逆も成り立つ。L^1 収束することと、測度収束かつ一様可積分であることは同値である。

これが最善の条件である——優収束定理より真に弱く、かつ必要十分。

例。f_n = n\mathbf{1}_{(0,1/n)} は測度収束するが一様可積分でない（\int_{\{f_n>M\}}f_n = 1 が n>M で成り立つ）。やはり交換できない。

シェッフェの補題。f_n\ge0、f_n\to f ほとんどいたるところ、\int f_n\to\int f<\infty なら \int|f_n-f|\to0。

証明。(f-f_n)^+ \le f なので優収束定理より \int(f-f_n)^+\to0。一方 \int(f-f_n) = \int f-\int f_n \to 0 なので、\int(f-f_n)^- = \int(f-f_n)^+-\int(f-f_n)\to0。合わせて \int|f-f_n|\to0。

「各点収束して、積分の値も収束する」だけで L^1 収束が出る。確率論で分布の収束を扱うときの基本道具である。

まとめ。交換の条件には三つの水準がある。優関数（十分・使いやすい）、一様可積分性（必要十分）、シェッフェ（非負の場合の実用的な形）。どれも第VIII部以降で繰り返し使う。

積分の抽象化——バナッハ空間値、ボホナー積分、ダニエル積分

ベクトル値積分。f \colon X \to B（B はバナッハ空間、第63章）の積分をどう定義するか。

ボホナー積分。f が強可測（単関数の各点極限として書ける）で \int\|f\|\,d\mu<\infty のとき、単関数の積分の極限として \int f\,d\mu \in B を定める。

スカラー値の構成がそのまま動く。優収束定理も成り立つ。第87章の超関数、確率過程の理論で使う。

ペティス積分。弱い意味の積分。\int f\,d\mu を「どの \varphi\in B^* についても \varphi\big(\int f\big)=\int \varphi\circ f」で定める。

ボホナー可積分ならペティス可積分だが、逆は成り立たない。ペティス積分の存在には、B の性質（ラドン–ニコディム性）が絡む。

ダニエル積分。測度から積分を作るのではなく、積分から測度を作る道がある。

L を関数の線型空間（束をなす）とし、I \colon L\to\mathbb{R} を正線型汎関数で「f_n\downarrow0 なら I(f_n)\to0」を満たすものとする。このとき I を拡張して、ある測度についての積分として表せる。

第59章のリースの表現定理は、この構成の具体化である。「積分できること」を出発点にして「測れること」を導く。

どちらが自然か。関数解析の立場では、ダニエルの道のほうが自然である。測度は「積分という線型汎関数」の別の姿にすぎない。

一方、確率論では測度が先である。事象の確率が対象であって、期待値はその積分だからである。

積分の特徴づけ。ルベーグ積分は、次の性質で特徴づけられる。平行移動不変で、線型で、単調収束定理を満たし、\int\mathbf{1}_{[0,1]}=1 を満たす汎関数は一意である。

第52章のハール測度の一意性が、その一般的な形である。積分は「対称性 ＋ 連続性」で決まる。
