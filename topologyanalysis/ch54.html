第VII部　測度と積分

第54章可測関数

← 第53章　Lebesgue測度と非可測集合 第55章　Lebesgue積分と収束定理 →

この章の問い

  • どんな関数なら「横に切って」測れるのか。
  • 可測関数は、極限でどこまで閉じているのか。
  • 可測関数は、連続関数とどのくらい近いのか。

可測関数の定義

可測関数

(X,\mathcal{A}) を可測空間とする。f \colon X \to [-\infty,\infty] が可測であるとは、すべての a \in \mathbb{R} について

\{\, x \in X \mid f(x) > a \,\} \in \mathcal{A}

が成り立つことをいう。

なぜ > a だけでよいのか

\{f \ge a\} = \bigcap_n \{f > a-1/n\}、\{f < a\} = \{f\ge a\}^c、\{f \le a\}=\{f>a\}^c。σ-加法族は可算交叉と補集合で閉じているので、四つの形はすべて同値である。

第51章で「値域を横に切る」と述べた。その層 \{a \le f < b\} が可測であることが、可測関数の内容である。

f \colon X \to \mathbb{R} について、次は同値である。

（1）f は可測。
（2）どの開集合 U \subseteq \mathbb{R} についても f^{-1}(U) \in \mathcal{A}。
（3）どのボレル集合 B についても f^{-1}(B) \in \mathcal{A}。

（1）から（2）。開集合は可算個の開区間の合併で、f^{-1}((a,b)) = \{f>a\}\cap\{f。

（2）から（3）。\{\, B \mid f^{-1}(B)\in\mathcal{A} \,\} は σ-加法族であり（逆像が集合演算と可換だから）、開集合を含む。よってボレル集合族を含む。

（3）から（1）は (a,\infty) がボレルだから。

連続写像との対応

（2）は第8章の連続性の定義「開集合の逆像が開」とそっくりである。「開集合の族」を「σ-加法族」に取り替えただけ。

だから可測関数は「可測空間の圏における射」である——位相空間と連続写像の関係が、そのまま平行移動している。

ただし一点違う。合成 g \circ f は、f 可測・g ボレル可測なら可測だが、g がルベーグ可測なだけでは可測とは限らない。ルベーグ可測性は完備化で作ったので、逆像の議論と噛み合わない。

演算と極限で閉じている

f, g を可測、c \in \mathbb{R} とする。

（1）cf、f+g、fg、\max(f,g)、\min(f,g)、|f| は可測。
（2）可測関数の列 (f_n) について、\sup_n f_n、\inf_n f_n、\limsup_n f_n、\liminf_n f_n は可測。
（3）(f_n) が各点収束するなら、極限 f は可測。

（1）f+g。\{f+g>a\} = \bigcup_{q\in\mathbb{Q}}\big(\{f>q\}\cap\{g>a-q\}\big)。有理数で刻めるところが効いている。

fg は fg = \frac14\big((f+g)^2-(f-g)^2\big) と \{f^2>a\} の可測性から。

（2）\{\sup_n f_n > a\} = \bigcup_n \{f_n > a\}。可算合併で閉じているから可測。

\limsup_n f_n = \inf_N \sup_{n\ge N} f_n なので、上の二つを組み合わせればよい。

（3）収束するなら f = \limsup_n f_n。

（2）が、リーマン積分にはない性質である。 で見たとおり、リーマン可積分関数の各点極限は可積分とは限らなかった。

可測性は各点極限で完全に閉じている。これは可算加法性の直接の帰結で、\{\sup f_n > a\} が可算合併になるところに現れている。

単関数による近似

単関数

有限個の値しか取らない可測関数を単関数という。すなわち

s = \sum_{k=1}^{n} c_k \mathbf{1}_{E_k} \qquad (c_k \in \mathbb{R},\ E_k \in \mathcal{A})

の形に書ける関数である。

単関数近似定理

f \ge 0 を可測とすると、単関数の増加列 0 \le s_1 \le s_2 \le \cdots で s_n \to f 各点収束するものが存在する。f が有界なら収束は一様である。

一般の可測 f については、f = f^+ - f^-（f^\pm \ge 0 可測）と分けて適用する。

n ごとに、値域 [0,n) を幅 2^{-n} の区間に刻む。

s_n = \sum_{k=0}^{n2^n-1} \frac{k}{2^n}\,\mathbf{1}_{\{k2^{-n} \le f < (k+1)2^{-n}\}} \ +\ n\,\mathbf{1}_{\{f \ge n\}}

各 \{k2^{-n}\le f<(k+1)2^{-n}\} は可測なので s_n は単関数。

増加性。n から n+1 へ行くと各区間が半分に割れ、下端が上がるか同じになる。

収束。f(x)<\infty なら n>f(x) で 0 \le f(x)-s_n(x) < 2^{-n}。f が M で有界なら n>M 以降 \sup_x|f-s_n|\le2^{-n} で一様収束。

この定理が、第55章で積分を定義する道具である。単関数の積分は「値 \times 集合の測度」の和で明らかに定義でき、あとは極限を取ればよい。

第51章の図で「値域を横に切る」と描いたのが、この s_n である。

ほとんどいたるところ

ほとんどいたるところ

測度空間 (X,\mathcal{A},\mu) で、性質 P がほとんどいたるところ成り立つとは、\mu(N)=0 なる N があって X\setminus N のすべての点で P が成り立つことをいう。

測度が完備なら（（3））、ほとんどいたるところ可測関数に等しい関数は可測である。

完備でないと、これが言えない。ボレル測度で議論すると、零集合の部分集合が可測でないかもしれず、「ほとんどいたるところ」の扱いが煩雑になる。第52章★★で完備化を導入した理由である。

エゴロフの定理

\mu(X)<\infty とし、可測関数の列 (f_n) がほとんどいたるところ f に収束するとする。このとき、どの \varepsilon>0 についても可測集合 E で

\mu(X\setminus E)<\varepsilon, \qquad f_n \to f \ \text{は } E \text{ 上で一様収束}

となるものが存在する。

零集合を除いて、いたるところ収束としてよい。

E_{n,k} = \bigcap_{m \ge n}\Big\{\, x \ \Big|\ |f_m(x)-f(x)| < \tfrac1k \,\Big\}

とおく。各 k について E_{1,k}\subseteq E_{2,k}\subseteq\cdots で \bigcup_n E_{n,k}=X（各点収束だから）。

測度の連続性（（1））と \mu(X)<\infty より、\mu(X\setminus E_{n_k,k})<\varepsilon2^{-k} なる n_k が取れる。

E = \bigcap_k E_{n_k,k} とおくと \mu(X\setminus E)<\varepsilon。E 上では、どの k についても m\ge n_k で |f_m-f|<1/k がすべての点で同時に成り立つ——すなわち一様収束。

有限性は外せない

X=\mathbb{R}、f_n = \mathbf{1}_{[n,n+1]} とすると各点で 0 に収束する。

だが、どの有限測度の集合を除いても一様収束しない——除いた集合の外に、つねに f_n=1 となる点が残る。

ルジンの定理

f を [a,b] 上のルベーグ可測関数とする。どの \varepsilon>0 についても閉集合 F \subseteq [a,b] で

\lambda([a,b]\setminus F)<\varepsilon, \qquad f|_F \text{ は連続}

となるものが存在する。

f が単関数の場合。有限個の可測集合 E_k について、各 E_k の内側に閉集合 F_k を \lambda(E_k\setminus F_k) が小さくなるように取る（内部正則性）。F=\bigcup_k F_k 上で f は局所定数、したがって連続。

一般の場合。 で単関数の列 s_n\to f を取り、各 s_n について上の F_n（除外測度 \varepsilon2^{-n-1}）を取る。 で E（除外測度 \varepsilon/2）上の一様収束を得る。

F = E' \cap \bigcap_n F_n（E'\subseteq E は閉）の上では、連続関数の一様極限だから f は連続（第47章）。

エゴロフは「各点収束はほとんど一様収束」、ルジンは「可測関数はほとんど連続関数」と読める。

どちらも「小さい例外を許せば、よい性質が戻る」という形をしている。これが測度論の基本的な手つきである。

ただし「ほとんど連続」は「ほとんどいたるところ連続」ではない。ディリクレ関数はルジンの定理を満たすが、どの点でも連続でない。除く集合を選べることが本質である。

可測性の細部——合成・ボレル可測・像の可測性

合成の問題。f がルベーグ可測、g が連続でも、f\circ g は可測とは限らない。順序が大事である。

g\circ f（g がボレル可測）は可測。なぜなら (g\circ f)^{-1}(B) = f^{-1}(g^{-1}(B)) で、g^{-1}(B) がボレルだから。

一方 f\circ g は、f がルベーグ可測なだけだと f^{-1}(B) はルベーグ可測にすぎず、その g による逆像が可測とは限らない。

具体例。カントール関数 \varphi を使う。\psi(x)=x+\varphi(x) は [0,1]\to[0,2] の同相写像で、\psi(C) の測度は 1（C の外で \psi は長さを保ち、その合計が 1 だから）。

測度 1 の集合 \psi(C) には非可測部分集合 V がある（第53章の演習）。A = \psi^{-1}(V) \subseteq C は測度零なので可測。ところが \mathbf{1}_A \circ \psi^{-1} = \mathbf{1}_V は可測でない。

可測関数と連続関数（しかも同相）の合成が、可測でなくなった。

同じ例から。A はルベーグ可測だがボレルでない。A がボレルなら、同相の像 V=\psi(A) もボレルになり可測になってしまう。

これが「可測だがボレルでない集合」の具体的な構成である。第53章では濃度の比較で存在だけ示したが、ここでは実際に作れた。

像の可測性。可測集合の連続像は可測とは限らない（上の V がそれ）。ボレル集合の連続像は解析集合であり、可測ではある（第53章★★★のルジンの定理）。

実用上の指針。解析では、外側の関数はボレル可測に取るのが安全である。連続関数はボレル可測なので、\varphi(f)（\varphi 連続、f 可測）はつねに可測。

確率論でも同じ約束をする。確率変数は「ボレル可測な関数」と定義するのが標準である。

可測関数の空間と、測度収束の位相

可測関数の全体に位相を入れる。第50章★★で名前だけ挙げた測度収束が、ここで位相になる。

測度収束。f_n \to f が測度収束するとは、どの \varepsilon>0 についても

\mu\big(\{\, x \mid |f_n(x)-f(x)|>\varepsilon \,\}\big) \to 0

となることをいう。

距離化。\mu(X)<\infty のとき

d(f,g) = \int_X \frac{|f-g|}{1+|f-g|}\,d\mu

は（ほとんどいたるところ等しい関数を同一視すれば）距離であり、この距離での収束が測度収束に一致する。

可測関数の全体は、この距離で完備距離空間になる。リーマン可積分関数の空間が完備でなかった（）のと対照的である。

収束の階層。\mu(X)<\infty のとき、

一様収束 \Rightarrow ほとんどいたるところ収束 \Rightarrow 測度収束。

また L^1 収束 \Rightarrow 測度収束（チェビシェフの不等式から）。逆向きはどれも成り立たない。

部分列定理。測度収束する列は、ほとんどいたるところ収束する部分列をもつ。証明は \mu(\{|f_{n_k}-f|>2^{-k}\})<2^{-k} なる部分列を取り、ボレル–カンテリの補題を使う。

ボレル–カンテリの補題。\sum_n \mu(A_n)<\infty なら \mu(\limsup_n A_n)=0。

証明は \limsup_n A_n = \bigcap_N \bigcup_{n\ge N}A_n で、\mu\big(\bigcup_{n\ge N}A_n\big)\le\sum_{n\ge N}\mu(A_n)\to0。

確率論の基本道具だが、内容は測度の連続性と劣加法性だけである。

なぜ「ほとんどいたるところ収束」が位相でないのか。驚くべきことに、ほとんどいたるところ収束を収束とするような位相は、一般には存在しない。

もし位相があれば、「どの部分列も、さらに収束する部分列をもつなら、もとの列も収束する」が成り立つはずである。ところが測度収束するが至るところ収束しない列（第50章の「動く窓」）が、この条件を満たしてしまう。

ほとんどいたるところ収束は、位相に由来しない収束概念である。第12章でネットを導入したときの「収束は位相から来るとは限らない」という話が、ここで具体例をもつ。
