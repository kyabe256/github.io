第VIII部　関数空間

第60章Lp空間とHölder・Minkowskiの不等式

← 第59章　Rieszの表現定理 第61章　完備性——Riesz–Fischerの定理 →

この章の問い

  • 関数の「大きさ」を測るのに、なぜ p 乗積分を使うのか。
  • 三角不等式は、なぜ自明でないのか。
  • p を動かすと、空間はどう変わるのか。

関数にノルムを入れる

第50章で、関数列の収束には何通りもの意味があると見た。それぞれに対応する「大きさ」の測り方がある。

Lᵖ 空間

(X,\mathcal{A},\mu) を測度空間、1 \le p < \infty とする。可測関数 f について

\|f\|_p = \Big(\int_X |f|^p \,d\mu\Big)^{1/p}

と定め、\|f\|_p<\infty なる f の全体を \mathcal{L}^p(\mu) と書く。

p=\infty のときは本質的上限

\|f\|_\infty = \inf\{\, M \ge 0 \mid |f|\le M \text{ がほとんどいたるところ成り立つ} \,\}

を使う。

関数を同一視する

\|f\|_p=0 であることは f=0 ほとんどいたるところと同値だった（（4））。したがって \|\cdot\|_p は半ノルムにすぎない。

ほとんどいたるところ等しい関数を同一視した商空間を L^p(\mu) と書く。これでノルム空間になる。

以下、L^p の元を「関数」と呼ぶが、厳密には関数の同値類である。一点での値は意味をもたない。

二つの不等式

ヤングの不等式

a,b\ge0、1、\frac1p+\frac1q=1 とすると

ab \le \frac{a^p}{p} + \frac{b^q}{q}

等号は a^p=b^q のときに限る。

\log が凹であることから

\log\Big(\frac{a^p}{p}+\frac{b^q}{q}\Big) \ \ge\ \frac1p\log a^p + \frac1q \log b^q = \log(ab)

凹性の等号条件が a^p=b^q。ここで使ったのは、凸関数の性質だけである。

ヘルダーの不等式

\frac1p+\frac1q=1（1\le p\le\infty）とすると

\|fg\|_1 \le \|f\|_p\,\|g\|_q

p=1,\infty の場合は明らか。1 とし、\|f\|_p=\|g\|_q=1 としてよい（そうでなければ定数倍する。どちらかが 0 なら両辺 0）。

を各点で使うと

|f(x)g(x)| \le \frac{|f(x)|^p}{p} + \frac{|g(x)|^q}{q}

積分して \|fg\|_1 \le \frac1p+\frac1q = 1 = \|f\|_p\|g\|_q。

ミンコフスキーの不等式

1\le p\le\infty について \|f+g\|_p \le \|f\|_p + \|g\|_p。

p=1,\infty は明らか。1 とする。

\|f+g\|_p^p = \int|f+g|^p \le \int |f|\,|f+g|^{p-1} + \int |g|\,|f+g|^{p-1}

右辺の各項に を使う。(p-1)q=p なので \big\||f+g|^{p-1}\big\|_q = \|f+g\|_p^{p/q}。よって

\|f+g\|_p^p \le (\|f\|_p+\|g\|_p)\,\|f+g\|_p^{p/q}

\|f+g\|_p^{p/q} で割れば（有限であることは |f+g|^p \le 2^p(|f|^p+|g|^p) から）、p-p/q=1 より結論を得る。

三角不等式が自明でないのが L^p の特徴である。p=1 なら各点の三角不等式を積分するだけ。p>1 では、ヘルダーの不等式という別の道具が要る。

0 では三角不等式が逆向きになり、ノルムにならない。d(f,g)=\int|f-g|^p が距離になるだけである（第63章★★★）。

p を動かす

包含関係

（1）\mu(X)<\infty なら、p について L^r \subseteq L^p であり

\|f\|_p \le \mu(X)^{\frac1p-\frac1r}\,\|f\|_r

（2）数え上げ測度（\ell^p 空間）では逆に、p について \ell^p \subseteq \ell^r。
（3）\mathbb{R} のルベーグ測度では、どちらの包含も成り立たない。

（1）|f|^p と 1 にヘルダーの不等式を指数 r/p と (r/p)' で使う。

（2）\|x\|_\infty \le \|x\|_p より |x_n|\le\|x\|_p、よって |x_n|^r \le \|x\|_p^{r-p}|x_n|^p。和を取る。

（3）f(x)=x^{-1/2}\mathbf{1}_{(0,1)} は L^1 だが L^2 でない。g(x)=x^{-1}\mathbf{1}_{(1,\infty)} は L^2 だが L^1 でない。

向きが逆になる理由

有限測度では「大きい値」だけが問題になり、数え上げ測度では「小さい値の裾」だけが問題になる。

|f|>1 の部分では p が大きいほど厳しく、|f|<1 の部分では p が大きいほど緩い。どちらの部分が効くかで、包含の向きが決まる。

\mathbb{R} では両方が起こりうるので、包含がない。

補間

p、\frac1r=\frac{\theta}{p}+\frac{1-\theta}{s}（0<\theta<1）とすると

\|f\|_r \le \|f\|_p^{\theta}\,\|f\|_s^{1-\theta}

したがって L^p \cap L^s \subseteq L^r。

|f|^r = |f|^{r\theta}\cdot|f|^{r(1-\theta)} と分け、指数 \frac{p}{r\theta} と \frac{s}{r(1-\theta)} でヘルダーの不等式を使う。二つの指数が共役であることが、1/r の式から出る。

等号の条件と、ヘルダーの不等式の使い方

ヘルダーの等号。1 のとき、\|fg\|_1=\|f\|_p\|g\|_q となるのは、|f|^p と |g|^q がほとんどいたるところ比例するときに限る。

の等号条件 a^p=b^q が、各点で成り立つ必要があるからである。

ミンコフスキーの等号。p>1 のとき、f と g が非負定数倍で比例するときに限る。p=1 では条件がゆるく、ほとんどいたるところ f と g の符号が一致すればよい。

この差が、第72章の「単位球の端点」の違いになる。p>1 の球は狭義凸（球面に線分が乗らない）、p=1 の球はそうでない。

双対性の芽。ヘルダーの不等式は、g\in L^q を固定すると

\varphi_g(f) = \int_X fg \,d\mu, \qquad |\varphi_g(f)| \le \|g\|_q\|f\|_p

という有界線型汎関数を与える。しかも \|\varphi_g\|=\|g\|_q——等号条件から、上限が実際に達成される。

確かめ方。f=|g|^{q-1}\mathrm{sgn}(g) と取ると |f|^p=|g|^q で、\varphi_g(f)=\|g\|_q^q=\|g\|_q\|f\|_p。

第66章で、逆に (L^p)^*=L^q（1\le p<\infty、σ-有限）を示す。ヘルダーの不等式は、その片側である。

ノルムを積分で書く。この双対性から

\|f\|_p = \sup\Big\{\, \Big|\int fg\,d\mu\Big| \ \Big|\ \|g\|_q \le 1 \,\Big\}

が出る。ノルムを上限として書けると、しばしば評価が楽になる——p 乗積分を直接扱わずに済むからである。

実例。ミンコフスキーの積分形

\Big\|\int_Y f(\cdot,y)\,d\nu(y)\Big\|_{L^p(\mu)} \ \le\ \int_Y \|f(\cdot,y)\|_{L^p(\mu)}\,d\nu(y)

は、上の表示とフビニの定理（）から二行で出る。「積分のノルムは、ノルムの積分以下」——第86章の畳み込みの評価で繰り返し使う。

補間定理と、Lᵖ の幾何

は「関数の補間」だった。作用素についても同じことができる。

リース–ソリンの補間定理。線型作用素 T が L^{p_0}\to L^{q_0} で有界（ノルム M_0）、L^{p_1}\to L^{q_1} で有界（ノルム M_1）なら、

\frac1p=\frac{1-\theta}{p_0}+\frac{\theta}{p_1}, \qquad \frac1q=\frac{1-\theta}{q_0}+\frac{\theta}{q_1}

について T \colon L^p\to L^q は有界で、ノルムは M_0^{1-\theta}M_1^{\theta} 以下。

証明は複素解析による——\theta を複素変数にして、帯状領域での正則関数に三線定理（アダマール）を使う。第XII部の複素解析が、実解析の不等式を証明する道具になる。

応用。第85章のハウスドルフ–ヤングの不等式 \|\hat f\|_{q} \le \|f\|_p（1\le p\le2）は、p=1 と p=2 の場合を補間して得る。

マルチンキェヴィチの補間定理。弱型の評価（第58章★★★の弱 (1,1)）からも補間できる。こちらは実変数の方法で、極大関数やヒルベルト変換に使う。

一様凸性。1 のとき L^p は一様凸である——クラークソンの不等式

\Big\|\frac{f+g}{2}\Big\|_p^p + \Big\|\frac{f-g}{2}\Big\|_p^p \le \frac{\|f\|_p^p+\|g\|_p^p}{2} \qquad (2\le p<\infty)

から出る。一様凸なバナッハ空間は反射的である（ミルマン–ペティス）。第66章・第70章で効く。

L^1 と L^\infty は一様凸でなく、反射的でもない。この二つだけが仲間外れになる——第VIII部以降、p=1,\infty はつねに別扱いになる。

ヒルベルト空間になるのは p = 2 だけ。L^p のノルムが内積から来るのは p=2 に限る。中線定理（第64章）が p=2 でしか成り立たないからである。

図の「1/p 軸」でいえば、p=2 は共役指数の対称軸上にある唯一の点である。第XI部でフーリエ変換が L^2 で最も美しく働くのも、この自己双対性による。
