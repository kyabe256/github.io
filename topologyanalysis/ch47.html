第VI部　実数と極限

第47章一様連続と一様収束

← 第46章　連続関数——中間値と最大値 第48章　微分と平均値の定理 →

この章の問い

  • 「一様」という語は、何を一様にしているのか。
  • 各点収束では、なぜ連続性が保たれないのか。
  • 一様性は位相的な概念なのか。

δ が点に依存しないこと

第45章で、\varepsilon に対する \delta は点 a ごとに取ってよいと述べた。では、すべての点で共通の \delta が取れるとしたら。

一様連続

f \colon X \to \mathbb{R}（X \subseteq \mathbb{R}）が一様連続であるとは、

\forall \varepsilon > 0\ \exists \delta > 0\ \forall x, y \in X\ \big(|x-y| < \delta \implies |f(x)-f(y)| < \varepsilon\big)

が成り立つことをいう。

連続の定義と比べる。連続は \forall x\ \forall \varepsilon\ \exists \delta、一様連続は \forall \varepsilon\ \exists \delta\ \forall x。\exists \delta が \forall x の前に出た——これだけの違いである。

第45章で述べたとおり、量化子の順序が定義の内容そのものである。

連続だが一様連続でない

f(x) = 1/x は (0,1] で連続だが一様連続でない。x が 0 に近いほど、同じ \varepsilon に対して小さい \delta が要る。

実際、x_n = 1/n、y_n = 1/(n+1) とすると |x_n-y_n| \to 0 だが |f(x_n)-f(y_n)| = 1。

f(x) = x^2 は \mathbb{R} で連続だが一様連続でない。傾きが無限に大きくなる場所があると、一様連続でなくなる。

ハイネ–カントールの定理

コンパクト距離空間 K 上の連続関数は一様連続である。

\varepsilon > 0 を取る。各 x \in K について、連続性より \delta_x > 0 を |f(y)-f(x)| < \varepsilon/2（d(y,x) < \delta_x）となるように取る。

\{\, B(x, \delta_x/2) \,\}_{x \in K} は開被覆なので、有限部分被覆 B(x_1,\delta_{x_1}/2), \ldots, B(x_k,\delta_{x_k}/2) を取る。\delta = \min_i \delta_{x_i}/2 とおく。

d(x,y) < \delta とする。x \in B(x_i, \delta_{x_i}/2) なる i があり、d(y,x_i) \le d(y,x)+d(x,x_i) < \delta + \delta_{x_i}/2 \le \delta_{x_i}。

よって |f(x)-f(x_i)| < \varepsilon/2 かつ |f(y)-f(x_i)| < \varepsilon/2 で、|f(x)-f(y)| < \varepsilon。

証明の骨は「無限個の \delta_x から有限個を選んで、その最小を取る」である。コンパクト性が、無限個の局所的な情報を有限個にまとめる。第20章で述べた「コンパクト性は有限性の代用」が、ここで具体的に働いている。

\delta_x/2 と半分にしておくのは、三角不等式の余裕を作るためである。第24章の細分の議論と同じ技巧である。

関数列の収束

各点収束と一様収束

f_n, f \colon X \to \mathbb{R} とする。

各点収束　\forall x\ \forall \varepsilon\ \exists N\ \forall n \ge N\ (|f_n(x)-f(x)| < \varepsilon)。
一様収束　\forall \varepsilon\ \exists N\ \forall n \ge N\ \forall x\ (|f_n(x)-f(x)| < \varepsilon)。

一様収束は \sup_x |f_n(x)-f(x)| \to 0 と同値である。

ここでも量化子の順序である。各点収束では N が x に依存してよい。一様収束では依存できない。一様連続で \delta が点に依存しなかったのと、まったく同じ構造である。

各点収束では連続性が壊れる

f_n(x) = x^n を [0,1] 上で考える。各点では

f_n(x) \to f(x) = \begin{cases} 0 & (0 \le x < 1) \\ 1 & (x = 1) \end{cases}

に収束するが、f は連続でない。

一様収束でないことは \sup_x|f_n(x)-f(x)| = 1（x \to 1^- で）から。各 f_n が連続でも、極限が連続とは限らない。

連続関数の列 (f_n) が f に一様収束するなら、f は連続である。

\varepsilon > 0、a \in X とする。一様収束より \sup_x|f_N(x)-f(x)| < \varepsilon/3 なる N を取る。f_N の連続性より |f_N(x)-f_N(a)| < \varepsilon/3（|x-a|<\delta）なる \delta を取る。

|f(x)-f(a)| \le |f(x)-f_N(x)| + |f_N(x)-f_N(a)| + |f_N(a)-f(a)| < \varepsilon

これがいわゆる「三分割の議論」である。一様性は、第一項と第三項を x によらず押さえるために使われる。

一様コーシー条件

(f_n) が一様収束することと、

\forall \varepsilon > 0\ \exists N\ \forall m,n \ge N\ \forall x\ \big(|f_m(x)-f_n(x)| < \varepsilon\big)

は同値である。

必要性は三角不等式。十分性は、各 x で (f_n(x)) がコーシー列なので \mathbb{R} の完備性より極限 f(x) が存在し、上の式で m \to \infty とすれば |f(x)-f_n(x)| \le \varepsilon（x によらず）。

一様収束で保たれるもの、保たれないもの

一様収束は連続性を保つ。ほかに何を保ち、何を保たないか。

有界性——保つ。f_n が一様有界で f_n \to f 一様なら f も有界。

リーマン積分——保つ。[a,b] 上で f_n \to f 一様、各 f_n が可積分なら f も可積分で

\int_a^b f_n \to \int_a^b f

\left|\int (f_n - f)\right| \le (b-a)\sup|f_n-f| \to 0。有界区間でなければ、この評価は効かない。

微分——保たない。f_n(x) = \frac{\sin(nx)}{\sqrt{n}} は 0 に一様収束するが、f_n'(x) = \sqrt{n}\cos(nx) は発散する。一様収束は「値の近さ」しか制御しない。傾きは自由である。

微分を保つ条件。(f_n') が一様収束し、ある一点で (f_n) が収束すれば、(f_n) は一様収束してその極限が微分可能で f' = \lim f_n'。仮定を導関数の側に置くのが正しい。第48章で示す。

無限区間での積分——保たない。f_n = \frac{1}{n}\mathbf{1}_{[0,n]} は \mathbb{R} 上で 0 に一様収束するが、\int f_n = 1 で 0 にならない。質量が無限遠へ逃げる。

この「逃げる質量」を扱うのが、第55章の優収束定理である。ルベーグ積分では、一様収束よりずっと弱い仮定で積分と極限が交換できる。

ディニの定理。コンパクト空間 K 上で、連続関数の列 f_n が各点単調に連続関数 f へ収束するなら、収束は一様である。証明は \{x : f_n(x)-f(x) < \varepsilon\} が増加する開被覆をなすことから。

単調性とコンパクト性を足すと、各点収束が一様収束に格上げされる。第20章の有限部分被覆が、また効いている。

一様構造——一様性は位相的でない

一様連続は位相だけでは定まらない。(0,1) と \mathbb{R} は同相だが、f(x) = 1/x は前者で一様連続でなく、対応する関数は後者で一様連続になりうる。

一様性は、位相と距離のあいだの中間層に属する。第30章で導入した一様空間が、その層である。

一様空間の言葉で。X 上の一様構造とは、対角線を含む X \times X の部分集合の族（近縁）で、いくつかの公理を満たすものである。f が一様連続とは、終域の各近縁 V について (x,y) \in U \implies (f(x),f(y)) \in V なる近縁 U があること。

この定義に \varepsilon も \delta も現れない。「点によらない近さ」という概念が、近縁という一つの集合に押し込められている。

コンパクト空間の一様構造は一意。コンパクトハウスドルフ空間には、その位相を与える一様構造がちょうど一つしかない（第30章）。だから が成り立つ——一様構造を選ぶ余地がないので、連続写像は自動的に一様連続になる。

完備性も一様的。第29章で「完備性は位相的でない」と述べた。完備性は一様構造で決まる。コーシー列の定義に近縁を使うからである。

位相的でないが距離にもよらない性質——一様連続・完備性・全有界性——が、ちょうど一様構造の層に収まる。

一様収束の位相。関数の空間 C(X) に、一様収束を収束とする位相を入れられる。X がコンパクトなら \|f\|_\infty = \sup_x|f(x)| がノルムになり、第63章のバナッハ空間になる。

X がコンパクトでないときは、コンパクト集合上で一様に収束する位相（コンパクト開位相、第95章）を使う。第95章のアスコリ–アルツェラの定理は、この位相でのコンパクト性を特徴づける。

そこで現れる条件が同程度連続性——「一様連続の、関数族についての版」である。本章の主題が、関数空間の位相として再登場することになる。
