第X部　スペクトル理論

第75章自己共役作用素

← 第74章　有界作用素とスペクトル 第76章　コンパクト自己共役作用素のスペクトル定理 →

この章の問い

  • 実対称行列の性質のうち、無限次元に残るのはどれか。
  • 自己共役作用素のスペクトルは、なぜ実数なのか。
  • ノルムとスペクトル半径は、いつ一致するのか。

随伴という折り返し

第74章で見たように、スペクトルは一般には複素平面の中の込み入った閉集合になりうる。ところが、ある一つの対称性を課すだけで、スペクトルは実軸の上の有界閉集合に落ちる。その対称性が自己共役性である。

有限次元での対応物は、実対称行列である。実対称行列については、固有値が実で、固有ベクトルが直交し、直交行列で対角化できる——この三点セットが成り立った。無限次元では、第一点はそのまま残り、第三点は形を変えて残り、第二点は「固有ベクトル」が存在しないこともあるため言い換えを要する。本章で第一点を、第76章と第77章で第三点を扱う。

随伴・自己共役・正規・ユニタリ

H を複素ヒルベルト空間、T\in B(H) とする。リースの表現定理（）により、

(Tx,y) = (x,T^*y) \qquad (\forall x,y\in H)

をみたす T^*\in B(H) がただ一つ定まる。これを T の随伴作用素という。

（1）T^*=T のとき T は自己共役（またはエルミート）。
（2）T^*T=TT^* のとき T は正規。
（3）T^*T=TT^*=I のとき T はユニタリ。
（4）すべての x について (Tx,x)\ge0 のとき T は正（T\ge0 と書く）。

随伴の存在の確かめ方

y を固定すると x\mapsto(Tx,y) は有界線形汎関数で、そのノルムは \|T\|\,\|y\| 以下である。リースの表現定理よりこれを内積で表すベクトルがただ一つあり、それを T^*y と書く。線形性と有界性は一意性から従う。

第66章の双対作用素との違いは、リースの同一視を二回挟むかどうかだけである。ただし同一視は共役線形なので、(\lambda T)^*=\bar\lambda T^* となる。随伴は共役線形な対応である。

随伴の基本性質

S,T\in B(H)、\lambda\in\mathbb{C} について次が成り立つ。

（1）(S+T)^*=S^*+T^*、(\lambda T)^*=\bar\lambda T^*、(ST)^*=T^*S^*、(T^*)^*=T。
（2）\|T^*\|=\|T\|。
（3）\|T^*T\|=\|T\|^2（シー・スター恒等式）。
（4）\ker T^* = (\mathrm{ran}\,T)^\perp、\overline{\mathrm{ran}\,T}=(\ker T^*)^\perp。
（5）T が可逆なら T^* も可逆で (T^*)^{-1}=(T^{-1})^*。したがって \sigma(T^*)=\overline{\sigma(T)}。

（3）だけ示す。コーシー–シュワルツ（）より

\|Tx\|^2 = (Tx,Tx) = (T^*Tx,x) \le \|T^*T\|\,\|x\|^2

なので \|T\|^2\le\|T^*T\|。逆向きは \|T^*T\|\le\|T^*\|\|T\|=\|T\|^2。

この等式が、作用素環の理論全体（第79章）の出発点になる。ノルムと代数構造と対合が、たった一本の等式で結びついている。

スペクトルが実軸に載る

自己共役作用素のスペクトル

T\in B(H) を自己共役とする。

（1）すべての x について (Tx,x)\in\mathbb{R}。
（2）\sigma(T)\subset\mathbb{R}。さらに \lambda=\alpha+i\beta（\beta\ne0）のとき

\|(T-\lambda I)^{-1}\| \le \frac{1}{|\beta|}

（3）T は剰余スペクトルをもたない。
（4）異なる固有値に属する固有ベクトルは直交する。

（1）(Tx,x)=(x,Tx)=\overline{(Tx,x)}。

（2）\lambda=\alpha+i\beta、\beta\ne0 とする。S=T-\alpha I は自己共役なので

\|(S-i\beta I)x\|^2 = \|Sx\|^2 + \beta^2\|x\|^2 - 2\,\mathrm{Re}\,(Sx,i\beta x)

最後の項は (Sx,x) が実なので -2\,\mathrm{Re}(-i\beta\overline{(Sx,x)})=0。よって

\|(T-\lambda I)x\| \ge |\beta|\,\|x\|

これで単射性と、値域が閉であることが同時に出る（下からの評価があるから、像のコーシー列は原像のコーシー列を与える）。値域が稠密であることは（4）から (\mathrm{ran}(T-\lambda I))^\perp=\ker(T-\bar\lambda I)=\{0\} と分かる。閉かつ稠密なら全体であり、逆作用素は上の不等式から 1/|\beta| 以下のノルムをもつ。

（3）\lambda\in\mathbb{R} で T-\lambda I が単射なら、(\mathrm{ran}(T-\lambda I))^\perp=\ker(T-\lambda I)=\{0\} だから値域は稠密である。単射なら値域は必ず稠密——これが剰余スペクトルの不在である。

（4）Tx=\lambda x、Ty=\mu y、\lambda\ne\mu とすると \lambda(x,y)=(Tx,y)=(x,Ty)=\mu(x,y)（\mu は実）。

数値範囲

T\in B(H) について

W(T) = \{\,(Tx,x) \mid \|x\|=1\,\}

を T の数値範囲という。自己共役のときは実数の集合で、

m = \inf_{\|x\|=1}(Tx,x), \qquad M = \sup_{\|x\|=1}(Tx,x)

と書く。

数値範囲とスペクトル

T を自己共役とする。

\sigma(T)\subset[m,M], \qquad m\in\sigma(T), \quad M\in\sigma(T)

すなわち m=\min\sigma(T)、M=\max\sigma(T)。さらに

\|T\| = \max(|m|,|M|) = r(T) = \sup_{\|x\|=1}|(Tx,x)|

\lambda>M とする。\varepsilon=\lambda-M>0 と置くと、すべての単位ベクトルについて

((\lambda I-T)x,x) = \lambda-(Tx,x) \ge \varepsilon

コーシー–シュワルツより \|(\lambda I-T)x\|\ge\varepsilon。（2）の証明と同じ議論で \lambda\in\rho(T)。\lambda < m も同様。

M\in\sigma(T) を見るには、S=MI-T\ge0 について「S\ge0 かつ \inf_{\|x\|=1}(Sx,x)=0 なら S は可逆でない」を示せばよい。(Sx_n,x_n)\to0 となる単位ベクトル列をとる。正作用素についてのコーシー–シュワルツ型不等式

\|Sx\|^2 = (Sx,Sx) \le \|S\|\,(Sx,x)

（これは (Su,v) を半内積と見て得られる）より \|Sx_n\|\to0。単位ベクトル列で Sx_n\to0 なら S は下から有界でなく、可逆でない。

ノルムの等式は、\sup|(Tx,x)|=\max(|m|,|M|) と、r(T)=\max(|m|,|M|)（スペクトルが [m,M] に含まれ両端を含むこと）から従う。\|T\|=r(T) は \|T^2\|=\|T^*T\|=\|T\|^2 を繰り返して \|T^{2^k}\|=\|T\|^{2^k} とし、ゲルファントの公式（）に入れれば出る。

ノルムがスペクトルから読めるということ

一般の作用素では r(T)\le\|T\| で、等号は成り立たないことがある（のべき零作用素はノルムが正でスペクトル半径が零）。自己共役——より一般に正規——な作用素では、この隔たりが消える。

これは「解析的な量（ノルム）が代数的な量（スペクトル）で決まる」という主張であり、第79章のゲルファント–ナイマルクの定理の核心である。同じ理由で、自己共役作用素の族の上ではノルムが代数構造から一意に決まってしまう。

例と、正規でない例

自己共役作用素の見本

（1）掛け算作用素。H=L^2(\mu)、\varphi を実数値の本質的有界関数として (M_\varphi f)=\varphi f。このとき M_\varphi^*=M_{\bar\varphi}=M_\varphi で自己共役、\sigma(M_\varphi) は \varphi の本質的値域（\{\lambda : \mu(|\varphi-\lambda| < \varepsilon)>0\ \forall\varepsilon>0\}）である。第77章で、すべての自己共役作用素がこの形に書けることを見る。

（2）直交射影。閉部分空間 V への射影 P（）は P^*=P=P^2。逆に P^*=P=P^2 なら P は \mathrm{ran}\,P への直交射影である。\sigma(P)\subset\{0,1\}。

（3）対称核の積分作用素。k(x,y)=\overline{k(y,x)} が L^2([0,1]^2) に属するとき、(Kf)(x)=\int_0^1 k(x,y)f(y)\,dy は自己共役かつコンパクト（第73章）。第76章のスペクトル定理が直接に効く相手である。

（4）ユニタリ。測度を保つ変換 \tau による f\mapsto f\circ\tau、フーリエ変換（第85章）、両側シフト。ユニタリのスペクトルは単位円周に含まれる（\|U\|=\|U^{-1}\|=1 から）。

正規でない作用素・自己共役でない対称作用素

片側シフトは正規でない。H=\ell^2、S(x_1,x_2,\dots)=(0,x_1,x_2,\dots) とすると S^*(x_1,x_2,\dots)=(x_2,x_3,\dots) で

S^*S = I, \qquad SS^* = I - P_1

（P_1 は第一座標への射影）。等距離なのに正規でない。有限次元では等距離ならユニタリだから、これは無限次元固有の現象である。

対称でも自己共役でない例は、有界な範囲には存在しない。有界作用素では (Tx,y)=(x,Ty) がすべての x,y で成り立てば定義域が全体なので T^*=T である。両者が分かれるのは、定義域が真部分空間である非有界作用素の場合だけである——微分作用素がその典型で、第78章で扱う。ヘリンガー–テプリッツの定理はこの分岐を説明する：定義域が全体である対称作用素は自動的に有界になってしまう。

★★ 学部後半——正の作用素と平方根、極分解

順序。自己共役作用素のあいだに S\le T \iff T-S\ge0 で順序を入れる。これは半順序であって全順序ではない。0\le S\le T なら \|S\|\le\|T\|、\sigma(T)\subset[0,\infty) と T\ge0 は自己共役な T について同値である（から m\ge0）。

平方根の存在。T\ge0 なら S\ge0 でただ一つ S^2=T をみたすものがある。構成は二通りある。

（i）冪級数による構成。\|T\|\le1 と正規化し、A=I-T と置くと 0\le A\le I。\sqrt{1-t}=1-\sum_{n\ge1}c_nt^n（c_n>0、\sum c_n=1）を t=A に代入する。係数が正で和が収束するので級数は絶対収束し、S=I-\sum c_nA^n が S^2=T をみたす。ここで使っているのは、係数の符号が一定という数値的な事実だけである。

（ii）単調列による構成。S_0=0、S_{n+1}=\tfrac12(T+ I -(I-S_n)^2) と定めると S_n は単調増加で有界。自己共役作用素の単調有界列は強作用素位相で収束する（各 x について (S_nx,x) が単調有界な実数列で、シー・スター恒等式から \|(S_n-S_m)x\|^2\le\|S_n-S_m\|((S_n-S_m)x,x)）。極限が求める平方根である。

絶対値と極分解。|T|=\sqrt{T^*T} と定めると \|\,|T|x\,\|=\|Tx\| が成り立つ。これにより \mathrm{ran}\,|T| 上で U(|T|x)=Tx は等距離に定まり、閉包へ、さらに直交補空間へ零で延長すれば

T = U|T|

と書ける。U は \overline{\mathrm{ran}}\,|T| から \overline{\mathrm{ran}}\,T への等距離（部分等距離）である。これが複素数の z=e^{i\theta}|z| の作用素版で、行列の特異値分解（第73章★★）の無限次元版の骨格でもある。正規作用素のときは U と |T| が可換になる。

数値範囲の凸性。一般の T\in B(H) について W(T) は凸集合である（トープリッツ–ハウスドルフの定理）。証明は二次元部分空間に落として楕円を描くことに帰着する。\overline{W(T)}\supset\sigma(T) は常に正しく、正規作用素のときは \overline{W(T)}=\mathrm{conv}\,\sigma(T)（の使い所の一つ）。自己共役ならこれが [m,M] という区間になる、というのがだった。

仮定を外すと。実ヒルベルト空間では (Tx,x) が実なのは自動で、対称性と何の関係もない。「スペクトルが実」という主張が意味をもつのは複素の上だけである。また、シー・スター恒等式は \|T^*T\|=\|T\|^2 という等式であって、これを落とすとノルムとスペクトル半径の一致が崩れる——バナッハ環の一般論（第79章）では、この一本の公理を入れるか入れないかで理論が大きく分かれる。

★★★ 大学院——正規作用素の分類と作用素環

正規作用素はどこまで分類できるか。コンパクト自己共役なら固有値列で決まる（第76章）。一般の正規作用素は、スペクトル測度のユニタリ同値類によって分類される：T は \bigoplus_n M_{\mathrm{id}}（各成分は L^2(\mu_n) 上の掛け算）とユニタリ同値で、測度の同値類の減少列 [\mu_1]\supset[\mu_2]\supset\cdots が完全不変量になる（重複度理論）。第77章で第一段階を扱う。

ワイル–フォン・ノイマンの定理。自己共役 T と任意の \varepsilon>0 に対し、ヒルベルト–シュミットノルムが \varepsilon 未満の自己共役 K があって T+K が離散スペクトルの対角作用素になる。連続スペクトルは、いくらでも小さなコンパクト摂動で壊れる。これに対し本質的スペクトル \sigma_{\mathrm{ess}}(T)=\sigma(\pi(T))（\pi はカルキン環 B(H)/K(H) への商写像）はコンパクト摂動で不変で、第73章の指数理論と結びつく。ブラウン–ダグラス–フィルモアの理論は、本質的正規作用素の分類を K 群で与える。

フォン・ノイマン環。B(H) の * 部分環で弱作用素位相で閉じたものをフォン・ノイマン環という。フォン・ノイマンの二重交換子定理：単位元を含む * 部分環 A について、弱閉包は二重交換子 A'' に等しい。位相的な閉包が、純粋に代数的な操作で書ける。因子環の \mathrm{II}_1 型は、有限次元でもなく可換でもないのに有限的なトレースをもつという逆説的な対象で、ジョーンズの部分因子環の指数が \{4\cos^2(\pi/n)\}\cup[4,\infty] という離散＋連続の値をとることは、この分野の最も意外な定理の一つである。

未解決に近い問い。コンナーの埋め込み予想（すべての \mathrm{II}_1 因子環が超有限因子環の超積に埋め込まれるか）は、量子情報の \mathrm{MIP}^*=\mathrm{RE} という計算量の結果から否定的に解決された（2020年）。作用素環の問いが、計算可能性の言葉で決着した。一方、単一作用素の不変部分空間問題——可分ヒルベルト空間上のすべての有界作用素は自明でない閉不変部分空間をもつか——は依然として未解決である（バナッハ空間では反例が知られている）。

演習

基本
  1. T が自己共役なら T^2\ge0 であることを示せ。
  2. 射影 P について \sigma(P)\subset\{0,1\} を確かめ、P\ne0,I のとき等号が成り立つことを示せ。
  3. ユニタリ作用素のスペクトルが単位円周に含まれることを示せ。
  4. 片側シフトが等距離だがユニタリでないことを、値域を調べて示せ。
証明
  1. （4）を示せ。（25点）
  2. （2）の下からの評価を、自分で式を展開して確かめよ。（30点）
  3. T が正のとき \|Sx\|^2\le\|S\|(Sx,x) を、(Su,v) が半内積であることから示せ。（30点）
  4. 自己共役 T について \|T\|=\sup_{\|x\|=1}|(Tx,x)| を示せ。（35点）
  5. T が正規なら \|T\|=r(T) を示せ（自己共役の場合を T^*T に適用する）。（40点）
発展
  1. 正作用素の平方根の一意性を示せ。（45点）
  2. 極分解 T=U|T| を構成し、T が正規なら U と |T| が可換であることを示せ。（45点）
  3. トープリッツ–ハウスドルフの定理（数値範囲の凸性）を、二次元の場合に確かめよ。（50点）
  4. 掛け算作用素 M_\varphi のスペクトルが \varphi の本質的値域であることを示せ。（40点）
