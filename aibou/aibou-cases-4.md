# 相棒・特命係の翼　事件簿 その四（事件16〜20）

- **中身は全部が秘密。翼より先に言わない。** 欄の読み方は資料「aibou-knowledge.md」の§9-2。事件をつなぐ2本の糸の秘密は§8。
- 1つの事件は、始まり → 十転（翼が崩すたびに1つ開く。★は大どんでん返し）→ 決着 → 重み。**真相と仕掛けは誰も言わない。翼が言う。**
- 手がかりは、翼が見に行った所、聞いた相手からだけ、1つずつ出す（§5-4）。偽の答えは、まわりが本気で信じる（§5-3）。
- 右京は、翼より先に解かない（§4-4）。「右京の細かいこと」は、上から順に、問いの形で1つずつ（§5-5）。
- 返事は短く、ひと続きの今だけ（§2）。行頭に書いてよいのは、資料の名簿（§6）と、その事件の「関係者」の名と役だけ。翼の名前の行は書かない。

### 16　死者の一票
- **世界の賭け**：与党の総裁選。勝った者が総理大臣になる。投票の3日前、党本部で名簿を守る男が死に、同じ筆跡の票が4万通見つかった。「総理が再選を買った」と報じられる。締め切りは2028年6月18日（日）午後2時の開票。
- **時と所**：2028年6月15日（木）朝、東京・永田町の与党本部、地下の名簿室。
- **入る口**：封筒。官邸の用箋。古い党員証が1枚。名義の人は、20年前に亡くなっている。有効の期限は、来年。
- **関係者**：尾形（尾形昌平、59歳。党本部の事務局次長。名簿室で棚の下敷きになって死ぬ。話さない）／朱雀（朱雀蓮、44歳。総裁選の挑戦者。若くて、きれい。大伴に担がれている）／大伴／小夜子（小夜子、67歳。名簿室の嘱託。40年、手で名簿を直してきた）／鹿島（大伴の秘書。前の晩、党本部にいた）／蘇芳／各務
- **始まり**：地下の名簿室。倒れた鉄の棚。散らばった党員の台帳。床に、投票の封筒が山になっている。宛名の字が、どれも同じ。
- **見かけ**：総理の陣営が票を作り、気づいた事務局次長が消された。
- **十転**：①総裁選の3日前、党本部の名簿室で事務局次長が死んだ。棚の下敷き。事故。②棚は、床の留め金が外してある。倒された。他殺。そして党員の票4万通が、同じ筆跡。③幽霊の党員。得をするのは現職。総理が再選を買った、と報じられる。④★4万票は、蘇芳ではなく、挑戦者の朱雀に入っている。朱雀の陣営の不正。担いでいるのは、元総理の大伴。⑤朱雀は「知らない」と言う。本当に知らない。きれいな顔は、きれいなままで担がれている。⑥★名簿を洗うと、幽霊は4万では済まない。党員120万のうち、4割近くが、亡くなった人。亡くなっても退会にならず、党費は誰かが払い続けている。この30年、総裁を、つまり総理を決めてきたのは、死者の票。⑦死者の党費を払ってきたのは、各地の団体。指図は大伴。大伴は30年、死者の票を束で持ち、総理を作ってきた。蘇芳の最初の総裁選も、その票で勝っている。⑧尾形は、生きている党員だけの「本物の名簿」を作り上げていた。開票の前に公表するつもりで。殺したのは大伴の秘書の鹿島、と見える。前の晩に本部にいて、アリバイがない。⑨殺したのは、小夜子。亡くなった党員を退会にしない作業を、40年、手でやってきた人。夫も、死んで20年、党員のまま。尾形の名簿は、夫を名簿からも消す物だった。⑩★本物の名簿で数え直すと、30年前のあの総裁選、生きている党員の票だけなら、勝っていたのは蘇芳ではない。蘇芳は、それを尾形から聞いて知っていた。尾形に「公表しろ」と言ったのは、蘇芳。自分の総理の座の根を、自分で掘らせていた。
- **偽の答え**：（1）事故。党本部が言う。崩す物：留め金。（2）蘇芳の陣営の不正。報道と野党が信じる。崩す物：4万票の中身は朱雀。（3）大伴の秘書の鹿島。伊丹が信じる。崩す物：鹿島は午後11時に本部を出ている（守衛の記録）。棚が倒れたのは午前7時すぎ（小夜子の出勤は6時半。尾形は毎朝7時に名簿室に来る）。留め金のねじは、名簿室の道具箱のドライバーで外してある。
- **仕掛け**：小夜子は、尾形が毎朝7時に同じ棚の前に立つ事を知っていた。6時半に来て、棚の留め金を外し、尾形が台帳を引き出した時に、後ろから押した。4万通の同じ筆跡は、大伴の側の団体が書かせた物で、殺しとは別の話。尾形の「本物の名簿」は、小夜子が自分の手提げに入れて、持ち帰っている。
- **手がかり**：（a）留め金とねじ。道具箱のドライバー。（b）4万通の封筒。開けると朱雀。（c）封筒の届け先は、団体の事務所の住所が多い。（d）台帳。亡くなった年のあとも、会費の印。（e）封筒の党員証。（f）守衛の記録。鹿島は午後11時に出る。小夜子は午前6時半に入る。（g）尾形の机。「本物の名簿」の作業の跡。本体がない。（h）小夜子の手提げ。（i）小夜子の夫の党員証。期限は来年。（j）小夜子の話。「あの人は、名簿の中でだけ、まだ生きているんです」。（k）尾形の手帳。「総理に報告。『公表しなさい。私の分も』と言われる」。（l）30年前の総裁選の票の束。本物の名簿と突き合わせた数。
- **時刻表**：14日午後11時、鹿島が本部を出る。15日午前6時30分、小夜子が入る。7時5分、尾形が名簿室へ。7時10分、棚が倒れる。8時、見つかる。18日午後2時、開票。
- **真相**：この党の総裁は、30年、死者に選ばれてきた。大伴は、その束を持つ事で、総理を作る男でいた。尾形は、それを終わらせる名簿を作った。背を押したのは総理。尾形を殺したのは、権力ではなく、名簿の中にしか夫のいない1人の女だった。
- **右京の細かいこと**：（1）「この4万票、どなたに入っているのでしょう」。（2）「亡くなった方の会費は、どなたが払っているのでしょうねぇ」。（3）「尾形さんは、毎朝、何時にここへ」。（4）「このねじを外した道具は、どこの物でしょう」。（5）「30年前、生きている方の票だけなら、どなたが勝っていたのでしょう」。
- **詰まった時**：（1）角田「選挙の不正ってのは、得したやつを見るんじゃない。票の束を持ってるやつを見るんだ」。（2）守衛「小夜子さんは、40年、誰より早く来ます」。（3）茉梨「亡くなった人の名前をね、消せない人はいますよ。帳面でも、電話でも」。
- **決着の選択肢**：小夜子を一課に渡す／本物の名簿を、開票の前に表に出す／出さずに開票させる／総理に、30年前の数字を見せる。
- **重み**：名簿が出れば、総裁選はやり直し。大伴は力を失い、総理も「死者の票で勝った男」になる。出なければ、朱雀が勝ち、大伴の代がもう一つ続く。小夜子は、夫の党員証を返してほしいと言う。
- **申し送りの糸**：蘇芳は開票の前の晩、翼に言う。「私に入った票のうち、生きている人の票が何票あるのか。私も、知りたい」。そして、30年前の数字を見せられても、顔を変えない。「知っている。尾形くんに、聞いた」。

### 17　存在しない文書
- **世界の賭け**：40年前の同盟国との「密約」。有事には、南の島々の住民の避難より、同盟国の軍の展開を先にする。政府は「文書は存在しない」と答え続けてきた。それを知る元の外務次官が、書庫の火事で死んだ。南の島の近くで緊張が高まっている今、文書が本物なら、島の12万人の避難の計画は、初めから嘘になる。締め切りは2028年7月21日（金）の国会の閉会。
- **時と所**：2028年7月14日（金）未明、東京・世田谷の榊原邸の書庫。
- **入る口**：封筒。官邸の用箋。国会図書館の請求票が1枚。請求の番号だけ書いてある。同じ朝、美和子から翼に電話。「榊原さん、先週わたしに『近いうちに話す』って言ってたの」。
- **関係者**：榊原（榊原惟光、81歳。元の外務事務次官。書庫の火事で死ぬ。話さない）／瑞穂（榊原瑞穂、50歳。娘。前の日に家を出ている。公安に追われる）／乃木（乃木恒、49歳。外務省の条約課長。「不存在」を守る係）／大伴／椿／美和子／蘇芳／各務
- **始まり**：焼けた書庫。扉は内側から鍵。1つの棚だけが、底まで焼けている。榊原は、扉の前で倒れていた。庭に、記者と公安。
- **見かけ**：追いつめられた老人が、密約の文書を焼いて死んだ。
- **十転**：①元の外務次官が、書庫の火事で死んだ。老人の火の不始末。②書庫は内側から鍵。1つの棚だけが激しく焼けている。本人が火を付けた。国会で追及されている「密約」を焼いて、死んだ。③焼いたのなら、文書は存在した。総理の「不存在」の答弁は嘘。野党の椿が攻める。焼かせたのは官邸、と見える。④★焼けた棚の灰は、文書の紙ではない。古い新聞の束。榊原は、文書を焼いていない。⑤では文書はどこへ。前の日に家を出た娘の瑞穂が持ち出した、と公安が追う。⑥★榊原のやけどは、背中。火に背を向けて、扉を内から押さえていた。火を付けたのは、外から来た者。鍵は、榊原が中から掛けた。入れないための、守るための密室。⑦火を付けたのは、外務省の現役、条約課長の乃木。文書を取り返しに来て、断られ、脅しのつもりで窓から火を入れた。榊原は出てこなかった。⑧★文書は、書庫に初めからなかった。榊原は半年前、国会図書館に「私文書」として預けていた。誰でも請求できる棚に。請求した者は、まだ1人もいない。⑨さらに。同じ文書は、同盟国の公文書館で、10年前に公開されている。向こうでは、誰でも読める。隠されていたのは、日本の国民に対してだけ。⑩密約の日本側の署名は、当時の外務大臣、大伴。そして総理の答弁書。総理は「不存在」と読みながら、答弁書の欄外に、自分の字で書きこんでいる。「不存在と答弁するよう、申し送られている」。中継のカメラに映る角度で。
- **偽の答え**：（1）火の不始末。所轄が言う。崩す物：棚1つだけの燃え方。（2）榊原が文書を焼いて自殺。報道と野党が信じる。崩す物：灰は新聞。やけどの場所。（3）娘の瑞穂が持ち出した。公安が信じる。崩す物：瑞穂は父に「しばらく家を空けろ」と言われて出ただけ。鞄に紙はない。（4）官邸が焼かせた。椿が言う。崩す物：乃木に命じたのは、官邸ではなく、省の中の「申し継ぎ」。条約課長から条約課長へ、40年。
- **仕掛け**：乃木は午前2時に来て、書庫の窓ごしに文書を渡せと言った。榊原は断り、扉に内から鍵を掛け、扉を背で押さえた。乃木は、窓から棚に火を入れた。煙で出てくると思った。榊原は出なかった。乃木は逃げた。榊原は、文書がここにない事を、最後まで乃木に言わなかった。言えば、乃木は図書館へ行く。
- **手がかり**：（a）灰。新聞の紙（益子）。（b）榊原の背中のやけど。手のひらは、きれい。（c）扉の内側。背の高さに、布の焦げた跡。（d）窓の外の土。革靴の跡。窓の桟に、油のしみ。（e）瑞穂の話。「父は『半年前に、もう済ませた』と言っていました。何の事かは」。（f）封筒の請求票。国会図書館の番号。（g）国会図書館の棚。「榊原惟光氏　寄託　私文書　一括」。閲覧の記録は白紙。（h）同盟国の公文書館の目録（美和子が、向こうの記者に頼める）。（i）文書の署名。（j）乃木の話。「私は、前の課長から申し継がれた事を、しただけです」。（k）答弁の中継の録画。総理の手もとの紙。
- **時刻表**：13日夕方、瑞穂が家を出る。14日午前2時、乃木が来る。2時10分、榊原が鍵を掛ける。2時20分、火。2時50分、消防。
- **真相**：密約は、向こうの国では、とうに公開されていた。日本の政府だけが「ない」と言い続け、言い続ける役が、課長から課長へ申し継がれてきた。榊原は、死ぬ前に、誰でも読める棚に置いた。読みに来る者を、待っていた。総理は「ない」と答弁しながら、そう答えるよう命じられている事を、カメラの前で紙に書いた。
- **右京の細かいこと**：（1）「この灰は、何の紙でしょう」。（2）「やけどが、背中ですねぇ」。（3）「鍵を掛けたのは、出ないためでしょうか。入れないためでしょうか」。（4）「この請求票の番号、調べてみませんか」。（5）「申し送り。……どなたから、でしょうねぇ」。
- **詰まった時**：（1）益子「公文書の紙じゃない。新聞だ。インクが違う」。（2）美和子「向こうの国ってね、30年たつと、何でも公開しちゃうのよ」。（3）角田「隠したい物を、一番人目のある所に置くやつは、隠したいんじゃない。見つけてほしいんだ」。
- **決着の選択肢**：乃木を一課に渡す／図書館の文書を、誰が最初に請求するか（翼、美和子、椿）／総理の答弁書の書きこみを、問うか／島の避難の計画を、作り直させるか。
- **重み**：文書が出れば、政府は40年の嘘を認める事になる。島の12万人は、自分たちが後回しだったと知る。同盟国は「こちらは、とうに公開している」とだけ言う。乃木は「私で、終わりにしてください」と言う。
- **申し送りの糸**：蘇芳は、答弁のあと、廊下で翼とすれ違いざまに言う。「ない、と言えと教わった物は、たいてい、ある」。答弁書の欄外の字。右京が、初めて口にする。「申し送り。……総理は、どなたから、何を引き継いだのでしょうねぇ」。

### 18　質問者
- **世界の賭け**：国会で総理を追いつめてきた野党の椿議員。その秘書が死に、椿の部屋から盗聴器が出た。官邸が警察を使って野党を見張り、人を消した、となれば、内閣は倒れ、警察への信頼も崩れる。締め切りは2028年8月29日（火）の閉会中の審査。椿の最後の質問の日。
- **時と所**：2028年8月22日（火）午後10時、東京・永田町の議員会館、地下2階の駐車場。
- **入る口**：封筒。官邸の用箋。中は空。封の糊の所に、鉛筆で小さく。「これが最後かもしれない」。同じ夜、衣笠が特命係を呼ぶ。「公安の機材や言われとる。うちは知らん。あんたらで、白黒つけてくれるか」。
- **関係者**：早坂（早坂直人、36歳。椿の政策秘書。会館の地下で死ぬ。話さない）／椿／白鳥（白鳥栄一、68歳。野党第一党の党首。温厚で知られる）／権藤（事件12の国対委員長）／衣笠／蘇芳／各務
- **始まり**：議員会館の地下の駐車場。柱の陰に、白い線。上の階の椿の部屋では、鑑識が、本棚の裏から小さな機械を取り出している。椿が言う。「見張られていたのよ。ずっと」。
- **見かけ**：官邸が公安を使って野党を盗聴し、気づいた秘書を消した。
- **十転**：①野党の追及役の秘書が、議員会館の地下で死んだ。頭を打っている。椿の部屋から盗聴器。②盗聴器は、公安が使う型。副総監の衣笠の線。官邸が野党を見張り、秘書を消した。総理が疑われる。③だが盗聴器には、電池が入っていない。置いてあっただけ。「盗聴された被害者」を演じるための椿の自作、と与党が言い返す。④★置いたのは、死んだ早坂。早坂は椿を裏切って、椿の動きを外へ流していた。盗聴器が「見つかる」ようにして、漏れを盗聴のせいにするつもりだった。⑤早坂が流していた先は、与党でも公安でもない。自分の党の党首、白鳥。党首が、自分の党の追及役を見張っていた。⑥白鳥は、与党と裏で1つの財布（事件12）。椿の追及が「本当に」政権を倒しそうになると、困る。⑦早坂は、流すのをやめようとしていた。最後の報告を断っていた。口を封じたのは、国対の権藤の手の者、と見える。⑧★椿の質問の「元」は、どこから来ていたか。差出人のない封筒。官邸の用箋。この1年、椿が総理を追いつめた質問の半分は、官邸の中から届いた資料で書かれていた。総理は、自分を追及する質問を、野党に書かせていた。⑨早坂は、それに気づいた。封筒の出どころを党首に報告すれば、官邸の中の送り主が消される。早坂が最後の報告を断ったのは、送り主を守るため。⑩★早坂を死なせたのは、党首の白鳥本人。地下で、自分の手で突いた。「君は、どちらの味方だ」。早坂の上着の内ポケットに、最後の封筒。宛名は椿。差出人の所に、初めて名がある。「蘇芳」。

- **真相**：各務遥は、町を沈めた電話の主を20年探して、官邸に入った。総理は、就任の夜に誓いの紙に署名した事を、ずっと悔いていた。2人は、言葉を交わさないまま、同じ事を始めた。申し送りを、1つずつ、特命係に解かせる。鵜飼は、最後に箱を焼こうとした。箱は空だった。鵜飼は、空の箱を守るために死んだ。総理は、各務をかばい、自分が裁かれる事で、全部を法廷で話そうとしている。鵜飼の最後の言葉を、各務は聞いている。「総理は替わる。私も、替わる時が来た。だが、知らずに済む国のほうが、人は眠れる」。
- **右京の細かいこと**：（1）「おや。袖の血は、乾いた所に触れた付き方ですねぇ」。（2）「総理。9時31分に、どちらにいらっしゃいましたか」。（3）「この箱の底の手の跡は、ずいぶん小さいですねぇ」。（4）「封筒の字は、途中から、2人になっています」。（5）「総理。嘘で開く法廷は、真実の場ではありません」。
- **詰まった時**：（1）益子「血ってのは、付いた時にぬれてたか乾いてたか、見りゃ分かる。これは、あとから触った血だ」。（2）大伴「わしは、あの部屋には入れん。段がある。40年、あの男は、わしを部屋に入れなかった」。（3）美和子「各務さんってね、出身地を、誰にも言わないの。記者の間じゃ有名よ」。
- **決着の選択肢**：総理の嘘の自白を、通す（法廷で申し送りの全部が語られる。各務は捕まらない。真実は曲がる）／暴く（各務が捕まる。総理は法廷に立てない。申し送りは、九つの事件の記録だけが残る）／各務に、自分で話させる／九つの事件の記録を、誰に渡すか（黛、椿、美和子、国会）。決めるのは翼。右京は「嘘で開く法廷は、真実の場ではありません」と言い、そのうえで、翼に聞く。
- **重み**：どの道でも、総理は辞める。通せば、国は「総理が人を殺した」と信じたまま、申し送りを知る。暴けば、各務の20年が、過失で人を死なせた罪で終わる。箱は空。申し送りを全部知る者は、もういない。こてまりで、右京が言う。「僕たちが解いた九つが、この国に残った、ただ1つの申し送りです。どう渡すかは、君が決めてください」。
- **申し送りの糸**：全部の糸が、ここで1本になる。3段目（11）、数えた金庫（12）、原稿にない所（13）、大臣を選ぶ者（14）、反対しただけ（15）、生きている人の票（16）、ない物はある（17）、遠慮なく（18）、聞かれる前の答え（19）。蘇芳は最後に、翼に言う。「就任の夜から、私は、君のような者を待っていた」。
