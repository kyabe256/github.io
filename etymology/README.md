# 英単語語源大辞典（第2版）

印欧祖語から現代英語までを通観する、日本語による英語語源辞典。A5判・約760ページ・全2,262項目。

第2版では、初版（400ページ・1,001項目）に対して以下を追加した。

- <b>図版26点</b>（SVG）——系統樹・音変化・派生ツリー・統計図
- <b>辞書の柱</b>——辞書パートの各ページ右上に、そのページの見出し語範囲を表示
- <b>新パート3つ</b>——分野別語源辞典（第VII部）／言語別借用語辞典（第VIII部）／学習直結編（第XI部、確認問題300問付き）
- <b>総説3章</b>——音声と綴りの体系（第13章）／語彙の統計（第14章）／語源から見た英語学習法（第15章）
- <b>索引5種</b>——英語見出し語／印欧語根・語幹／接辞／分野別／人名・地名由来語

## ビルド方法

```bash
pip install weasyprint pypdf
python3 build.py
```

`src/*.txt` を読み込み、`dist/` に PDF と HTML を出力する。ページ番号を表紙に載せるため、初回ビルド後にもう一度実行すると数値が確定する。

## ソースの書式

`src/*.txt` は行指向の軽量マークアップで書かれている。

```
# 見出し1（章。改ページする）
## 見出し2
### 見出し3
== A            アルファベット区切り（改ページ）
:: index en     以降のエントリーを索引に登録（en / root / aff / field / eponym / none）
%fig 図名 ; キャプション   figures.py の SVG 図版を挿入

@ 見出し語 ; 発音 ; 品詞 ; 語義
+lit:   原義
+root:  印欧語根
+chain: 語源系統
+desc:  解説（複数可）
+cog:   同根語
+der:   派生・関連語
+dbl:   二重語
+note:  ノート
+conf:  確実度（確実／通説／一説／不確実／誤り。色分けバッジで表示）
+lvl:   重要度（★〜★★★。見出し行に表示）
+see:   参照
+cf:    参照

- 箇条書き
1. 番号付き
| 表 | の | 行 |
> 注記ボックス
```

インラインは HTML をそのまま書く（`<i>`, `<b>`）。`&` は `&amp;` と書く。
エントリーは `==` 区切りごとに見出し語のアルファベット順へ自動整列される。

## 記述方針

- 確定的な事実、通説、有力な一説、不確実な推測を書き分け、留保は「〜とされる」「不確実」と明記した。
- 広く流布する俗説（`posh` の頭字語説、`salary` の塩給与説、`genuine` の膝説、`sincere` の蝋説など）は第X部に集約し、「誤り」「裏づけなし」と判定を示した。
- 判定基準は (1) 一次史料の有無、(2) 初出年代との整合、(3) 音変化の規則性、(4) 他言語における並行例。
