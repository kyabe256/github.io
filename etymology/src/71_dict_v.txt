== V

@ vaccine ; /ˈvæksiːn/ ; 名 ; ワクチン
+lit: 「雌牛の」
+chain: L <i>vacca</i>「雌牛」→ <i>variolae vaccīnae</i>「牛痘」→ 英語（ジェンナー, 1798）
+desc: エドワード・ジェンナーが牛痘を用いた種痘法を確立したことによる。パストゥールが1881年、ジェンナーへの敬意から、あらゆる免疫原に <i>vaccin</i> の語を拡張した。
+der: vaccination, vaccinate, vaquero/buckaroo（西「牛飼い」）
+note: 語源に「牛」が刻まれたまま、あらゆる感染症の予防接種を指す語になった。

@ vandal ; /ˈvændl/ ; 名 ; 破壊者
+chain: 民族名 Vandals（455年にローマを略奪したゲルマン系部族）
+desc: <i>vandalisme</i> はフランス革命期の1794年、ブロワ司教グレゴワールが芸術破壊を非難して造った語。実際のヴァンダル族の略奪が特に破壊的だったという証拠は乏しく、後世の評判による。
+note: 民族名の普通名詞化（<i>slave</i>, <i>frank</i>, <i>bohemian</i>, <i>philistine</i>, <i>gothic</i>）の一例。

@ vanilla ; /vəˈnɪlə/ ; 名 ; バニラ
+lit: 「小さな鞘」
+chain: L <i>vāgīna</i>「鞘」→ 西 <i>vainilla</i>（縮小形）→ 英語
+desc: 細長い莢の形から。<i>vagina</i>「膣」と同語源で、こちらは解剖学のラテン語命名（1680年代）。
+note: <i>plain vanilla</i>「基本仕様の」の用法は20世紀後半のアメリカ英語から。

@ vaudeville ; /ˈvɔːdəvɪl/ ; 名 ; 寄席演芸
+chain: 仏 <i>chanson du Vau de Vire</i>「ヴィール谷の歌」（ノルマンディーの地名）
+desc: 15世紀にヴィール谷で流行した風刺歌に由来するとされる。<i>voix de ville</i>「街の声」との混同もあった。
+note: 地名由来語で、途中に民間語源による形の変化が加わった例。

@ vermilion ; /vəˈmɪliən/ ; 名 ; 朱色
+lit: 「小さな虫」
+chain: L <i>vermis</i>「虫」→ <i>vermiculus</i>「小さな虫（＝カイガラムシ）」→ OF <i>vermeillon</i>
+desc: 深紅の染料はカイガラムシ（<i>kermes</i>）から採られた。<i>crimson</i>（＜アラビア語 <i>qirmiz</i>）も同じ虫の名。
+der: worm（本来語）, vermin, vermicelli（「小さな虫」＝細いパスタ）, vermiform
+note: <i>crimson</i>, <i>carmine</i>, <i>kermes</i>, <i>vermilion</i> がすべて虫由来。染色史が語彙に刻まれている。

@ villain ; /ˈvɪlən/ ; 名 ; 悪党
+lit: 「農園（<i>vīlla</i>）の労働者」
+chain: L <i>vīllānus</i>「農園に属する者」→ OF <i>vilein</i>
+desc: 「農奴」→「粗野な者」→「悪党」と悪化した（第7章）。支配層の言語における階級的偏見が語義に沈殿した典型例。
+der: villa, village, villein, vicinity(?)
+note: 同型の悪化に <i>churl</i>（自由農民→無礼者）, <i>boor</i>（農民→粗野な人）, <i>peasant</i>。

@ vulgar ; /ˈvʌlɡə/ ; 形 ; 下品な
+lit: 「民衆の」
+chain: L <i>vulgus</i>「民衆」→ <i>vulgāris</i>
+desc: 「一般民衆の」→「ありふれた」→「粗野な」。<i>Vulgate</i>（ラテン語訳聖書）は「民衆の（版）」の意で、原義を保つ。数学の <i>vulgar fraction</i>「普通分数」も中立的な古義。
+der: divulge（「民衆に広める」＝漏らす）, Vulgate, vulgarity

@ vogue ; /vəʊɡ/ ; 名 ; 流行
+lit: 「（船の）進み」
+chain: 伊 <i>voga</i>「漕ぐこと、進行」→ 仏 <i>vogue</i>「流行」→ 英語
+note: 「（時流に）乗っていること」という航海の比喩。<i>in vogue</i>。

@ voice ; /vɔɪs/ ; 名 ; 声
+chain: L <i>vōx, vōcis</i> → OF <i>vois</i>
+der: vocal, vocation（「（神の）呼びかけ」＝天職）, advocate, evoke, invoke, provoke, revoke, vocabulary, vowel（「声の（文字）」）, equivocal
+note: 文法の <i>voice</i>「態（能動態・受動態）」は、ギリシア語 <i>diáthesis</i> のラテン語訳 <i>vōx</i> による用語法。

@ veto ; /ˈviːtəʊ/ ; 名 ; 拒否権
+lit: 「私は禁じる」
+chain: L <i>vetō</i>（<i>vetāre</i>「禁じる」の一人称単数現在）
+desc: ローマの護民官（<i>tribūnus plēbis</i>）が元老院の決議を差し止めるときに発した一語。動詞の活用形がそのまま名詞化した。
+note: <i>recipe</i>（取れ）, <i>credo</i>（我信ず）, <i>exit</i>（彼は去る）, <i>affidavit</i>（彼は誓約した）, <i>caveat</i>（用心せよ）, <i>tenet</i>（彼は保持する）, <i>habeas corpus</i>（身体を持て）と同じく、ラテン語の動詞形がそのまま英語の名詞になった例。

@ vinegar ; /ˈvɪnɪɡə/ ; 名 ; 酢
+lit: 「酸っぱいワイン」
+chain: OF <i>vin aigre</i>（<i>vin</i>「ワイン」+ <i>aigre</i>「鋭い、酸っぱい」）
+der: wine, vine, vintage／acid, acute, acrid, eager, oxygen（ギ）
+note: <i>eager</i>「熱心な」も <i>aigre</i>「鋭い」と同語源。<i>eager</i> の古義「鋭い」はハムレットの "a nipping and an eager air" に残る。

@ virus ; /ˈvaɪrəs/ ; 名 ; ウイルス
+lit: 「毒液、粘液」
+chain: L <i>vīrus</i>「毒、粘液」
+desc: 18世紀まで「感染性の毒素」一般を指した。細菌より小さい濾過性病原体の意味は1898年から。計算機の <i>computer virus</i> は1972年のSFに現れ、1984年に学術用語として定着した。
+note: ラテン語 <i>vīrus</i> は中性の物質名詞で複数形を持たなかった。英語 <i>viruses</i> は英語式の複数形である。

@ volcano ; /vɒlˈkeɪnəʊ/ ; 名 ; 火山
+chain: L <i>Volcānus</i>（火と鍛冶の神ウルカヌス）→ 伊 <i>volcano</i>
+desc: シチリア沖のヴルカーノ島（神の鍛冶場と考えられた）の名から。
+der: vulcanize（加硫。グッドイヤー, 1839）, Vulcan

@ vast ; /vɑːst/ ; 形 ; 広大な
+chain: L <i>vastus</i>「空虚な、荒涼とした、広大な」
+der: waste, devastate, vain, vanity, vacant, vacuum, evacuate, void, avoid
+note: <i>waste</i> と <i>vast</i> は同一語源で、ゲルマン語形と混淆した。「何もない」が「広い」と「荒れた」に分かれた。
+lvl: ★★

@ verdict ; /ˈvɜːdɪkt/ ; 名 ; 評決
+lit: 「真実を言うこと」
+chain: L <i>vērum dictum</i>「真実の言」→ AF <i>verdit</i>
+root: *weh₁r-「真実」／*deyḱ-「示す」
+der: very（「真の」が原義）, verify, verdict, veracity, aver／dictionary, dictate, predict, contradict, index, judge, indicate
+note: <i>very</i> はもと形容詞「真の」（<i>the very man</i> に残る）。強意副詞になったのは中英語後期。
+lvl: ★★

@ vermin ; /ˈvɜːmɪn/ ; 名 ; 害獣、害虫
+chain: L <i>vermis</i>「虫」→ 俗ラテン語 <i>vermīnum</i>
+der: worm（ゲルマン系同根）, vermilion（<i>vermiculus</i>「カイガラムシ」＝朱の染料）, vermicelli（伊「小さな虫」＝細いパスタ）
+note: <i>vermilion</i>「朱色」は虫から採る染料の名。<i>crimson</i>（アラビア語 <i>qirmiz</i>「カイガラムシ」）も同じ発想の別語。

@ vernacular ; /vəˈnækjʊlə/ ; 形名 ; 土着の（言語）
+chain: L <i>verna</i>「家で生まれた奴隷」→ <i>vernāculus</i>
+note: 「家生まれの＝土地固有の」。エトルリア語起源とされる。
+lvl: ★★

@ virtue ; /ˈvɜːtʃuː/ ; 名 ; 美徳
+lit: 「男らしさ」
+chain: L <i>vir</i>「男」→ <i>virtūs</i>「男らしさ、勇気、徳」
+root: *wiH-ro-「男」
+cog: OE <i>wer</i>（<i>werewolf</i>「狼男」に残存）, Skt <i>vīra-</i>
+der: virile, virtual, world（OE <i>weorold</i>＝<i>wer</i>「人」＋<i>ald</i>「年齢」＝「人の世」）, werewolf, triumvirate
+note: <i>world</i> が「人の一生」であることは語源を知らないとわからない。<i>virtual</i>「事実上の」は「（潜在的な）力をもつ」が原義で、計算機用語は1959年から。
+see: world
+lvl: ★★★

@ volume ; /ˈvɒljuːm/ ; 名 ; 巻、体積、音量
+lit: 「巻いたもの」
+chain: L <i>volvere</i>「巻く、転がす」→ <i>volūmen</i>
+der: revolve, revolution, involve, evolve, devolve, convolution, vault, volt は別, walk（ゲルマン系同根）
+note: 巻物が「巻」の単位になり、そこから「かさ」→「体積」→「音の大きさ」へ。三つの意味が一語に同居する。
+lvl: ★★★

@ voyage ; /ˈvɔɪɪdʒ/ ; 名 ; 航海
+chain: L <i>via</i>「道」→ <i>viāticum</i>「旅の糧」→ OF <i>veiage</i>
+see: obvious
+der: via, deviate, obvious, previous, trivial, convey, convoy, envoy, viaduct
+note: <i>viaticum</i> はもと「旅費・旅の食糧」で、キリスト教では「臨終の聖体」（最後の旅の糧）を指す。

@ vacation ; /vəˈkeɪʃn/ ; 名 ; 休暇
+chain: L <i>vacāre</i>「空である」→ <i>vacātiō</i>
+der: vacant, vacuum, evacuate, void, avoid, vanity, vain, waste, vast
+note: 「（職務が）空になること」。英国では大学・法廷の休廷期を指し、一般の休暇は <i>holiday</i>（<i>hāliġ dæġ</i>「聖なる日」）。米英差。
+lvl: ★★

@ vagabond ; /ˈvæɡəbɒnd/ ; 名 ; 放浪者
+chain: L <i>vagārī</i>「さまよう」→ <i>vagābundus</i>
+der: vague（「さまよう＝定まらない」）, extravagant（「外へさまよい出る」）, vagrant, vagary
+note: <i>extravagant</i>「浪費する」が「常軌を逸してさまよう」から。

@ valet ; /ˈvæleɪ/ ; 名 ; 従者
+chain: 俗ラテン語 *<i>vassellittus</i>（ケルト語 *<i>wasso-</i>「若者、従者」）
+dbl: varlet, vassal
+der: vassal, varlet, valet
+note: ケルト語からラテン語に入った数少ない語のひとつ。封建制の語彙（<i>vassal</i>「臣下」）を作った。

@ vampire ; /ˈvæmpaɪə/ ; 名 ; 吸血鬼
+chain: セルビア語 <i>вампир</i> → 独 <i>Vampir</i> → 英語（1734）
+note: 18世紀のハプスブルク帝国辺境での「吸血鬼騒動」の報告書が西欧に伝えた。コウモリの命名（1774）は逆に伝説からの転用。
+see: 第VIII部 スラヴ語

@ velocity ; /vəˈlɒsəti/ ; 名 ; 速度
+chain: L <i>vēlōx</i>「速い」→ <i>vēlōcitās</i>
+der: velocipede（「速い足」＝自転車の前身）
+lvl: ★★

@ vengeance ; /ˈvendʒəns/ ; 名 ; 復讐
+chain: L <i>vindicāre</i>「（法的に）要求する、罰する」→ OF <i>vengier</i>
+der: avenge, revenge, vindicate, vindictive
+note: <i>vindicate</i>「正当性を証明する」と <i>vengeance</i> が同根。法的主張と私的報復が同じ語から分かれた。

@ venue ; /ˈvenjuː/ ; 名 ; 会場
+lit: 「来ること」
+chain: L <i>venīre</i>「来る」→ 仏 <i>venue</i>
+root: *g<sup>w</sup>em-「行く、来る」
+cog: OE <i>cuman</i> → come, Gk <i>baínein</i>
+der: come, become／advent, convene, event, invent, prevent, revenue, souvenir, intervene, avenue, convenient／Gk系 base, basis, acrobat, diabetes
+note: 法律用語で「裁判が行われる地」。英語 <i>come</i> とラテン語 <i>venīre</i> はグリムの法則（g<sup>w</sup> → k<sup>w</sup>）で対応する。
+see: *g<sup>w</sup>em-
+lvl: ★★★

@ verge ; /vɜːdʒ/ ; 名 ; 縁、間際

+der: virgule（斜線）, verger（教会の杖持ち）
+note: <i>on the verge of</i>「〜の間際に」。権威の杖が及ぶ境界が原義。

@ versatile ; /ˈvɜːsətaɪl/ ; 形 ; 多才な

+lvl: ★★

@ veterinary ; /ˈvetrɪnri/ ; 形 ; 獣医の

+der: veteran, inveterate, veteranary

@ vice ; /vaɪs/ ; 名 ; 悪徳／副〜

@ vigilante ; /ˌvɪdʒɪˈlænti/ ; 名 ; 自警団員
