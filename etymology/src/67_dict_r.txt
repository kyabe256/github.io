== R

@ robot ; /ˈrəʊbɒt/ ; 名 ; ロボット
+lit: 「賦役、強制労働」
+chain: チェコ語 <i>robota</i>「賦役」→ カレル・チャペック『R.U.R.』（1920）
+desc: チャペックは当初 <i>labori</i> と名づけようとしたが、兄ヨゼフの助言で <i>robot</i> に決めたと自ら記している。
+der: 独 <i>Arbeit</i>「労働」, 露 <i>работа</i>（同根）
+note: <i>robotics</i>「ロボット工学」はアイザック・アシモフの造語（1941）。

@ rosary ; /ˈrəʊzəri/ ; 名 ; ロザリオ
+lit: 「薔薇園」
+chain: L <i>rosārium</i>「薔薇園」
+desc: 聖母への祈りを「薔薇の花輪」に見立てた中世の比喩による。<i>rosarium</i> はまた「詞華集」の題名にも用いられた。
+der: rose, rosette
+note: 「花を集める」比喩は <i>anthology</i>（詞華集）にも見られる。

@ rummage ; /ˈrʌmɪdʒ/ ; 動 ; かき回して探す
+lit: 「船倉に積み込むこと」
+chain: OF <i>arrumage</i>「積み荷の配置」（<i>run</i>「船倉」＜ ゲルマン語 *rūmaz「空間」）
+der: room, roomy（本来語の同根語）
+note: <i>rummage sale</i> はもと「（税関で処分される）未引き取り貨物の競売」。

@ ridiculous ; /rɪˈdɪkjələs/ ; 形 ; ばかげた

@ rifle ; /ˈraɪfl/ ; 名 ; ライフル銃
+lit: 「溝を刻む」
+chain: OF <i>rifler</i>「引っ掻く、略奪する」→ 英語 <i>rifle</i>「銃身に施条する」→ <i>rifled gun</i> → <i>rifle</i>
+desc: 銃身内部の螺旋溝（施条, rifling）が弾丸を回転させて命中精度を高める。この技術の名が銃そのものの名になった。
+note: 動詞 <i>rifle</i>「（物色して）盗む」は同語源の別義。

@ robust ; /rəʊˈbʌst/ ; 形 ; 頑健な
+lit: 「オークの（ように堅い）」
+chain: L <i>rōbur</i>「オーク、堅材、力」→ <i>rōbustus</i>
+der: corroborate（「（証拠で）強める」）, robustness
+note: 統計学・工学の <i>robust</i>「頑健な（外れ値に強い）」も同じ語。オークは古代地中海世界で最も堅い木の代表だった。

@ romance ; /rəʊˈmæns/ ; 名 ; 恋愛物語
+lit: 「ローマ（俗語）で書かれたもの」
+chain: 俗ラテン語 <i>rōmānicē (scrībere)</i>「ローマ風（俗語）で書く」→ OF <i>romanz</i>
+desc: ラテン語ではなく俗語（フランス語）で書かれた物語を指した。その多くが騎士の冒険と恋を扱ったため、内容の名になった。
+der: Romance languages（ロマンス諸語）, roman（仏「長編小説」）, romantic
+note: 「言語の名」から「文学ジャンル」へ、さらに「感情の質」へと三段跳びした語。

@ restaurant ; /ˈrestrɒnt/ ; 名 ; レストラン
+lit: 「（体力を）回復させるもの」
+chain: 仏 <i>restaurer</i>「回復させる」（L <i>restaurāre</i>）→ <i>restaurant</i>「滋養スープ」→ それを供する店
+desc: 1765年ごろパリで、ブーランジェという店主が滋養スープ（<i>restaurant</i>）を出す店を開いたのが起源とされる（この逸話には異論もある）。
+der: restore, store, instaurate

@ rocket ; /ˈrɒkɪt/ ; 名 ; ロケット

@ rhubarb ; /ˈruːbɑːb/ ; 名 ; ルバーブ

@ rosemary ; /ˈrəʊzməri/ ; 名 ; ローズマリー
+lit: 「海の露」

+note: <i>rose</i>「薔薇」とも <i>Mary</i>「マリア」とも無関係だが、英語形は両者に引き寄せられた民間語源的な綴りである（中英語では <i>rosmarine</i>）。

@ radical ; /ˈrædɪkl/ ; 形 ; 根本的な、急進的な
