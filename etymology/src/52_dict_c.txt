== C

@ calculate ; /ˈkælkjuleɪt/ ; 動 ; 計算する
+lit: 「小石を使う」
+chain: L <i>calculus</i>「小石」（<i>calx</i>「石灰石」の縮小形）→ <i>calculāre</i>
+desc: ローマ人は算盤の珠として小石を用いた。医学の <i>calculus</i>「結石」も同じ語で、こちらは原義に近い。ニュートン・ライプニッツの「微積分学」も <i>calculus</i>（「計算法」）である。
+der: calcium, calcify, chalk（本来語化した借用）, causeway（「石灰を敷いた道」）
+note: 「小石」→「計算」の連想は、日本語の「算木」やインカの <i>quipu</i> にも通じる普遍的な発想。

@ calendar ; /ˈkælɪndə/ ; 名 ; 暦
+lit: 「（新月を）呼ばわる日の帳簿」
+chain: L <i>kalendae</i>「朔日（月の第一日）」（<i>calāre</i>「呼ばわる」）→ <i>kalendārium</i>「利息の帳簿」
+desc: ローマでは朔日に新月を告げ、借金の利息を支払った。その台帳が <i>kalendārium</i> で、これが「暦」の語源となった。
+der: claim, clamor, council は別, ecclesiastic, nomenclature, class（「召集された市民の等級」）
+note: 「ギリシアの朔日に」（<i>ad kalendas Graecas</i>）はアウグストゥスの言葉で、「決して来ない日に」の意。ギリシア暦に kalendae はないため。

@ candidate ; /ˈkændɪdət/ ; 名 ; 候補者
+lit: 「白く輝く衣を着た者」
+chain: L <i>candēre</i>「白く輝く」→ <i>candidātus</i>
+desc: ローマの公職志願者は、清廉を示すため白墨で真っ白にしたトガ（<i>toga candida</i>）を着て市中を回った。<i>ambition</i>（歩き回ること）と対になる。
+der: candle, candid, candor, incandescent, chandelier, incendiary は別

@ cancel ; /ˈkænsl/ ; 動 ; 取り消す
+lit: 「格子（の線）を引く」
+chain: L <i>cancellī</i>「格子、柵」→ <i>cancellāre</i>「×印を引いて無効にする」
+der: chancel（内陣。格子で仕切られた部分）, chancellor（「格子の番人」→ 高官）, chancery, incarcerate（「柵に閉じ込める」）
+note: 文書を無効にするとき、格子状に線を引いて消したことから。<i>chancellor</i>（首相・学長）が同語源であるのは、法廷の柵のそばに座る書記官が起源だから。

@ carnival ; /ˈkɑːnɪvl/ ; 名 ; 謝肉祭

@ cartoon ; /kɑːˈtuːn/ ; 名 ; 漫画

@ cattle ; /ˈkætl/ ; 名 ; 牛
+lit: 「（頭数で数える）財産」

@ chapel ; /ˈtʃæpl/ ; 名 ; 礼拝堂
+lit: 「（聖マルティヌスの）小さな外套」
+chain: 後期ラテン語 <i>cappella</i>「小さな外套」（<i>cappa</i>「外套」の縮小形）
+desc: フランク王家は聖マルティヌスの外套を聖遺物として保管し、その安置所を <i>cappella</i> と呼んだ。転じて小礼拝堂一般を指すようになり、そこに仕える聖職者が <i>chaplain</i>「礼拝堂付き司祭」となった。
+der: chaplain, cape, cap, cope, chaperone（「頭巾」→ 付き添い役）, a cappella（「礼拝堂式に＝無伴奏で」）

@ chess ; /tʃes/ ; 名 ; チェス

@ compute ; /kəmˈpjuːt/ ; 動 ; 計算する

+der: increase, decrease, concrete, recruit, croissant（仏「三日月」＝パン）, cereal
+note: 厳密には「満ちていく月」を指し、欠けていく月は <i>decrescent</i>。

@ crusade ; /kruːˈseɪd/ ; 名 ; 十字軍
+chain: L <i>crux, crucis</i>「十字架」→ 西 <i>cruzada</i>／仏 <i>croisade</i>
+der: cross, crucial, crucify, excruciate, cruise（オランダ語経由）
+note: <i>cruise</i>「巡航する」も「十字に横切る」から（オランダ語 <i>kruisen</i>）。

@ crystal ; /ˈkrɪstl/ ; 名 ; 結晶、水晶
+lit: 「氷」
+chain: Gk <i>krýstallos</i>「氷、水晶」（<i>krýos</i>「冷たさ」）→ L <i>crystallum</i>
+der: cryogenic, crystallize
+note: 古代人は水晶を「永久に融けない氷」と考えた。プリニウスもそう記している。

@ cuisine ; /kwɪˈziːn/ ; 名 ; 料理
+chain: L <i>coquīna</i>「台所」→ 仏 <i>cuisine</i>
+der: kitchen（本来語化した古い借用）, cook, biscuit, precocious, apricot
+note: <i>kitchen</i>（大陸期の借用）と <i>cuisine</i>（近代仏語）は同語源の二重語。

@ culture ; /ˈkʌltʃə/ ; 名 ; 文化、栽培
+lit: 「耕すこと」
+chain: L <i>colere</i>「耕す、住む、崇める」→ <i>cultūra</i>
+der: cultivate, agriculture, colony, cult, cultivar, wheel（本来語の同根語 *kʷel-）
+note: キケロの <i>cultūra animī</i>「精神の耕作」が「文化」の語義の出発点。細菌の「培養」も同語。

@ current ; /ˈkʌrənt/ ; 形・名 ; 現在の、流れ

+note: 「今走っている」→「現在の」。電流の <i>current</i> も「流れ」。

@ curriculum ; /kəˈrɪkjələm/ ; 名 ; 教育課程
+lit: 「走路」
