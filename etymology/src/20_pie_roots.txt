# 第II部　印欧祖語語根辞典

印欧祖語（PIE）の語根から、英語の語彙がどのように派生したかを一覧する。配列は再建形のアルファベット順（喉音 h₁ h₂ h₃ は、伝統的表記の a, e, o の位置に置いたものもある）。

各項の見方：<b>+語形</b>＝アプラウトの各階梯や異形、<b>+同根語</b>＝他言語における反映形、<b>+英語への流入</b>＝英語に現れた語（本来語／ラテン語経由／ギリシア語経由に分けて示す）、<b>+ノート</b>＝補足。

記号：L＝ラテン語、Gk＝ギリシア語、Skt＝サンスクリット語、PGmc＝ゲルマン祖語、OE＝古英語、ON＝古ノルド語、OF＝古フランス語、Goth＝ゴート語、OHG＝古高ドイツ語、Av＝アヴェスター語、OCS＝古教会スラヴ語、Lith＝リトアニア語、W＝ウェールズ語、OIr＝古アイルランド語。

## 一つの語根が、三つの層すべてに届く

印欧祖語の語根は、英語のなかで一か所に留まらない。本来語として直接受け継がれ、ラテン語を経由してもう一度入り、ギリシア語からさらに一度入る。その結果、見た目のまったく違う語が、同じ一点から出ていることになる。

%fig bher-tree ; *bʰer-「運ぶ」から出た英語。三つの層すべてに届いている。

%fig steh2-tree ; *steh₂-「立つ」。英語だけで200語を超える、もっとも多産な語根。

## どの語根から覚えるか

語根には費用対効果の差がある。派生語の多い語根を先に押さえるほど、一語あたりの見返りが大きい。

== A – B

@ *h₂eǵ- ; 「駆る、動かす、導く」
+form: *h₂eǵ- / *h₂oǵ- / *h₂ǵ-
+cog: L <i>agere, āctum</i>「行う、駆る」; Gk <i>ágein</i>「導く」; Skt <i>ajati</i>; ON <i>aka</i>「（車で）行く」
+eng: <b>ラテン系</b> act, action, agent, agenda, agile, agitate, ambiguous（両方へ駆る）, cogent, exact, exigent, essay/assay（<i>exagium</i> 秤量）, navigate, litigate, mitigate, prodigal, transact, castigate, fumigate, purge（<i>pūrigāre</i>）／<b>ギリシア系</b> pedagogue（子を導く）, demagogue, synagogue（集める所）, agony（＜競技会 <i>agōn</i>）, antagonist, strategy（軍を導く術）, axiom（＜「重み」）
+note: L <i>agere</i> の完了分詞 <i>āctum</i> から act 系、現在幹から agent 系が出る（第9章）。<i>ambiguous</i> は「あちこちへ駆り立てる」＝定まらない。

@ *h₂eḱ- ; 「鋭い、尖った」
+form: *h₂eḱ- / *h₂ḱ-
+cog: L <i>acer</i>「鋭い」, <i>acus</i>「針」, <i>aciēs</i>「刃」; Gk <i>akís</i>「先端」, <i>ákros</i>「頂上」, <i>oxýs</i>「鋭い、酸い」
+eng: <b>本来語</b> edge, egg on（＜ ON <i>eggja</i>「けしかける」）, ear（穀物の穂）／<b>ラテン系</b> acid, acute, acumen, acerbic, acrid, exacerbate, eager（＜「鋭い」）, vinegar（酸い酒）, acupuncture, ague／<b>ギリシア系</b> acrobat（先端を歩く）, acropolis, acronym, acrophobia, oxygen（酸を生む）, oxymoron（鋭くて愚か）, paroxysm, amphioxus
+note: <i>oxygen</i> はラヴォアジエが「酸を作るもの」と考えて命名したが、酸の本質は水素イオンであり、命名は誤りだった。

@ *aiw- / *h₂eyu- ; 「生命力、長い時間、永遠」
+cog: L <i>aevum</i>「時代」, <i>aetās</i>「年齢」; Gk <i>aiṓn</i>「永劫」; Skt <i>āyu-</i>「寿命」; Goth <i>aiws</i>
+eng: <b>本来語</b> ever, never, aye（「常に」）, each（OE <i>ǣlc</i> ＜ <i>ā</i>+<i>gelīc</i>）／<b>ラテン系</b> age, eternal（<i>aeternus</i>）, coeval, medieval（中世＝<i>medium aevum</i>）, primeval, longevity, utopia は別語源／<b>ギリシア系</b> eon/aeon
+note: <i>ever</i> と <i>eternal</i> が同根であることは、意味からは自然だが形からは見えにくい。

@ *al- ; 「養う、育つ」
+cog: L <i>alere</i>「養う」, <i>altus</i>「高い＝育った」, <i>alumnus</i>「養い子」, <i>adulēscēns</i>
+eng: <b>本来語</b> old, elder, alderman（OE <i>ealdorman</i>）, world（＜「人の齢」）／<b>ラテン系</b> adult, adolescent, alimony, aliment, altitude, exalt, enhance（＜ <i>altiāre</i>）, coalesce, proletarian（＜「子を産む者」）, alma mater（「育ての母」）, alumnus, abolish
+note: <i>altus</i> は「高い」と「深い」の両義を持つ（育った方向による）。<i>altitude</i> と英語 <i>old</i> は同根。

@ *al- ; 「他の、向こうの」
+cog: L <i>alius</i>「他の」, <i>alter</i>「二者のうち他方」; Gk <i>állos</i>; Goth <i>aljis</i>
+eng: <b>本来語</b> else, other（＜ *an-tero-, 別語根）／<b>ラテン系</b> alias, alibi（「他の場所に」）, alien, alter, alternate, altruism, adulterate（他物を混ぜる）, ultra は別／<b>ギリシア系</b> allegory（別の場で語る）, allergy（別の働き）, allele, parallel, allophone, allopathy
+note: <i>alibi</i> は「（犯行時に）他の場所にいた」というラテン語の副詞そのもの。

@ *ambʰi / *h₂mbʰi ; 「両側、周り」
+cog: L <i>ambi-</i>; Gk <i>amphí</i>; Gaulish <i>ambi-</i>; OHG <i>umbi</i>（＝ <i>um</i>）
+eng: <b>本来語</b> by(?), um- は消失／<b>ラテン系</b> ambition（票を求めて歩き回る）, ambient, ambiguous, ambulance（＜ <i>hôpital ambulant</i> 移動病院）, amputate（周りを切る）／<b>ギリシア系</b> amphibian（両方の生を生きる）, amphitheater（両側に観客席）, amphora（両側に取っ手）
+note: <i>ambition</i> はローマの選挙運動で候補者が有権者のあいだを「歩き回った」ことに由来する。

@ *h₂enh₁- ; 「息をする」
+cog: L <i>animus</i>「心、気息」, <i>anima</i>「魂」; Gk <i>ánemos</i>「風」; Skt <i>ániti</i>「呼吸する」; Goth <i>uz-anan</i>「息を吐く」
+eng: <b>ラテン系</b> animal, animate, animosity, unanimous（心を一つに）, magnanimous, equanimity, pusillanimous（小さい心＝臆病）／<b>ギリシア系</b> anemone（「風の花」）, anemometer
+note: 「息＝魂」の連想は諸言語に共通する（L <i>spīritus</i>, Gk <i>psȳkhḗ</i>, ヘブライ語 <i>rūaḥ</i>, 日本語「息」と「生き」）。

@ *ant- / *h₂ent- ; 「額、前面」
+cog: L <i>ante</i>「前に」; Gk <i>antí</i>「向かい合って」; Skt <i>ánti</i>; Hitt <i>ḫant-</i>「額」
+eng: <b>本来語</b> and(?), along（OE <i>andlang</i>）, answer（OE <i>andswaru</i>「向かって誓う」）／<b>ラテン系</b> ante-, anterior, ancient, antique, advance（＜ <i>abante</i>）, advantage, vanguard, vintage は別／<b>ギリシア系</b> anti-, antagonist, antibiotic, antidote（対抗して与えるもの）
+note: <i>answer</i> の <i>and-</i> は「向かって」で、<i>anti-</i> と同根。<i>advance</i> の d は語源的に誤った挿入（<i>ab ante</i> であって <i>ad-</i> ではない）。

@ *h₂er- ; 「はめ合わせる、組み立てる」
+cog: L <i>ars, artis</i>「技」, <i>arma</i>「武具」, <i>ōrdō</i>「順序」; Gk <i>harmós</i>「継ぎ目」, <i>arithmós</i>「数」, <i>áristos</i>「最良の」; Skt <i>ṛtá-</i>「秩序、真理」
+eng: <b>本来語</b> arm（腕、はめ合わさる部分）, article は別経路／<b>ラテン系</b> art, artisan, artifice, artillery, arm(s)（武器）, army, armistice, inert（技のない→不活発）, order, ordinary, ordain, subordinate, coordinate, adorn（整える）／<b>ギリシア系</b> harmony, arithmetic, aristocracy（最良の者の支配）, rhyme(?)
+note: 「腕(arm)」と「武器(arms)」は同音異義に見えて、実は同じ語根の別経路（前者は本来語、後者はラテン語経由）。

@ *h₂ews- ; 「輝く、暁」
+cog: L <i>aurōra</i>「暁」, <i>aurum</i>「金」; Gk <i>ēṓs</i>「暁」; Skt <i>uṣás</i>; Lith <i>auksas</i>「金」
+eng: <b>本来語</b> east（日の昇る方）, Easter（＜ 女神 <i>Ēostre</i>）／<b>ラテン系</b> aurora, austral, Australia（「南の地」）, aureate, oriole, auriferous／<b>ギリシア系</b> eosin
+note: <i>Easter</i> はベーダによれば春の女神エオストレの名から。他のヨーロッパ諸語ではヘブライ語 <i>pesaḥ</i>「過越」由来（仏 <i>Pâques</i>）。

@ *bʰeh₂- ; 「話す、語る」
+cog: L <i>fārī</i>「話す」, <i>fāma</i>「評判」, <i>fābula</i>「話」, <i>fātum</i>「（神が）語ったこと＝運命」; Gk <i>phēmí</i>「言う」, <i>phōnḗ</i>「声」
+eng: <b>本来語</b> ban（＜「布告する」）, banns, banish, abandon, bandit（追放された者）／<b>ラテン系</b> fable, fabulous, fate, fatal, fairy（＜ <i>fāta</i>）, fame, infamous, infant（「まだ話さない者」）, preface, confess, profess, professor, ineffable（言い表せない）, affable, nefarious（言うも憚る）／<b>ギリシア系</b> phone, symphony, euphemism, blasphemy, prophet（前もって語る者）, aphasia, phase は別語根
+note: <i>infant</i>「幼児」は <i>in-</i>（非）+ <i>fārī</i>（話す）＝「まだ言葉を話さぬ者」。<i>infantry</i>「歩兵」は同じ語がイタリア語で「若者、従者」を経た形。

@ *bʰel- ; 「輝く、白い」
+cog: L <i>flagrāre</i>「燃える」(別説), <i>fulgēre</i>「光る」; Gk <i>phalós</i>「白い」; OE <i>blæc</i>「黒い」/ <i>blāc</i>「青白い」
+eng: <b>本来語</b> bald（白い斑のある）, blaze, blank, bleach, bleak, blind, blond(?), blush, black（「焼けた」）, blank／<b>ラテン系</b> flame, flagrant, conflagration, flamingo（炎の色）, effulgent, refulgent, fulminate（雷）／<b>ギリシア系</b> phalanx(?)
+note: <i>black</i>「黒」と <i>blank/blanc</i>「白」が同じ語根から出る。焼けたものは黒く、火は白く輝く——反対の色が同源になる好例。

@ *bʰel- ; 「膨らむ、吹く」
+cog: L <i>follis</i>「ふいご、革袋」, <i>flōs</i>「花」（*bʰleh₃-）; Gk <i>phallós</i>
+eng: <b>本来語</b> ball, balloon, bowl, bloat, bold, bull(?), belly, bellows, billow, bulge, boulder(?), blow（花が咲く）, bloom, blossom, blade, bladder, bless(?)／<b>ラテン系</b> follicle, fool（＜ <i>follis</i>「ふいご＝空気袋」→ 中身のない者）, flower, floral, flourish, flour（花＝最良の部分）, effloresce
+note: <i>flour</i> と <i>flower</i> は同一語の綴り分化（18世紀に定着）。小麦粉は「小麦の花＝精華」。<i>fool</i> は「ふいご」で、中身が空気だけの者。

@ *bʰendʰ- ; 「縛る」
+cog: Skt <i>bandh-</i>; Goth <i>bindan</i>; L <i>offendix</i>
+eng: <b>本来語</b> bind, band, bond, bundle, bend（弓に弦を張る）, bandage は仏経由, ribbon(?)／<b>その他</b> bandana（ヒンディー語、同根）, cummerbund（ペルシア語 <i>kamar-band</i>「腰帯」）
+note: <i>bend</i> はもと「弓に弦を張る」で、そこから「弓を曲げる」→「曲げる」に転じた。<i>bend</i> と <i>band</i> と <i>bond</i> はアプラウトの三階梯。

@ *bʰer- ; 「運ぶ、もたらす、産む」
+form: e階梯 *bʰer-、o階梯 *bʰor-、零階梯 *bʰr̥-
+cog: L <i>ferre</i>「運ぶ」; Gk <i>phérein</i>; Skt <i>bharati</i>; Goth <i>bairan</i>; OCS <i>bĭrati</i>; Arm <i>berem</i>
+eng: <b>本来語</b> bear（運ぶ・産む）, birth, born, borne, bairn, burden, bier（死体を運ぶ台）, barrow（手押し車）, bring(?), forbear／<b>ラテン系</b> fertile, transfer, refer, prefer, confer, differ, offer, suffer, infer, defer, circumference, vociferous, Lucifer（光を運ぶ者＝明けの明星）, Christopher, -ferous（carboniferous）／<b>ギリシア系</b> metaphor（意味を運び越す）, periphery, euphoria（よく運ぶ＝快い状態）, phosphorus（光を運ぶ）, amphora, paraphernalia（＜ 花嫁が「持参する」財）
+note: ラテン語 <i>ferre</i> の完了分詞は不規則に <i>lātum</i>（別語根 *telh₂-）で、そこから relate, translate, dilate, oblate, prelate, superlative が出る。

@ *bʰerǵʰ- ; 「高い」
+cog: OHG <i>berg</i>「山」; Skt <i>bṛhánt-</i>「高い」; Hitt <i>parku-</i>
+eng: <b>本来語</b> barrow（古墳）, iceberg（「氷の山」オランダ語経由）, borough/burgh/-bury（丘の砦→町）, burgess, burglar(?)／<b>その他</b> bourgeois, burgher（独・仏経由）, belfry は別語源
+note: 地名の -burgh（Edinburgh）, -borough（Peterborough）, -bury（Canterbury）, 独 -burg（Hamburg）, 仏 -bourg（Strasbourg）はすべて同源。

@ *bʰeh₂ǵ- ; 「ブナ」
+cog: L <i>fāgus</i>「ブナ」; Gk <i>phēgós</i>「樫」; OHG <i>buohha</i>
+eng: <b>本来語</b> beech, book（ブナ材の板に文字を刻んだことから、とされる）, buckwheat（ブナの実に似た穀）
+note: <i>book</i> ＜ OE <i>bōc</i> と <i>beech</i> ＜ OE <i>bēce</i> の関係は通説だが、異論もある。第2章の「ブナ論争」も参照。

@ *bʰeudʰ- ; 「目覚める、気づく」
+cog: Skt <i>bodhati</i>「目覚める」, <i>buddha-</i>「目覚めた者」; Lith <i>budėti</i>; OCS <i>bŭděti</i>
+eng: <b>本来語</b> bid（＜ OE <i>bēodan</i>「告げる、命じる」）, forbid, bode, forebode, beadle（触れ役）／<b>その他</b> Buddha, bodhisattva（サンスクリット）
+note: <i>Buddha</i>「仏陀」と英語 <i>bid</i>「命じる」は同根。<i>bid</i>（競売で値をつける）はもと別語 OE <i>biddan</i>「請う」（＝ <i>bead</i>「祈り→数珠玉」と同根）と混同した結果である。

@ *bʰeh₂wH- / *bʰeu- ; 「なる、成長する、存在する」
+cog: L <i>fuī</i>「私はあった」, <i>futūrus</i>; Gk <i>phýein</i>「生じる」, <i>phýsis</i>「本性」; Skt <i>bhavati</i>
+eng: <b>本来語</b> be, been, boor（農夫＝耕す者）, neighbor（近くに住む者）, bower, byre, build, booth／<b>ラテン系</b> future, futile(?)／<b>ギリシア系</b> physics, physique, physiology, imp（＜ <i>emphytos</i> 接ぎ木）, euphuism
+note: 英語 <i>be</i> の活用は三つの異なる語根の混成である。<i>be, being, been</i> ＜ *bʰeu-、<i>am, is, are</i> ＜ *h₁es-、<i>was, were</i> ＜ *h₂wes-「留まる」。

@ *bʰrāter- / *bʰréh₂tēr ; 「兄弟」
+cog: L <i>frāter</i>; Gk <i>phrā́tēr</i>「同族員」; Skt <i>bhrā́tṛ</i>; Goth <i>brōþar</i>; OCS <i>bratrŭ</i>
+eng: <b>本来語</b> brother／<b>ラテン系</b> fraternal, fraternity, fratricide, friar（＜ <i>frère</i>）, confrere／<b>ギリシア系</b> phratry
+note: グリムの法則で *bʰ → b、語頭アクセントゆえ *t → þ が保たれた（<i>father</i> の d と対照。第3章）。


== C – D

@ *deh₃- ; 「与える」
+cog: L <i>dare, datum</i>「与える」, <i>dōnum</i>「贈り物」; Gk <i>dídōmi</i>, <i>dôron</i>「贈り物」; Skt <i>dadāti</i>; OCS <i>dati</i>
+eng: <b>ラテン系</b> date（手紙の「与えられた日」<i>datum</i> より）, data, donate, donor, pardon, condone, edition, tradition（引き渡し）, treason（同語源の二重語）, betray, render, surrender, rent, vend（<i>vēnum dare</i>「売りに出す」）, add（<i>ad-dere</i>）, dose／<b>ギリシア系</b> dose, antidote, anecdote（「公にされなかったもの」）, Dorothy/Theodore（「神の贈り物」）
+note: <i>date</i>（日付）はローマの書簡の定型句 <i>datum Rōmae</i>「ローマにて与えられた（書かれた）」から。<i>date</i>（ナツメヤシ）は Gk <i>dáktylos</i>「指」で別語源。

@ *deḱ- ; 「取る、受け入れる、適する」
+cog: L <i>decēre</i>「ふさわしい」, <i>decus</i>「飾り」, <i>doctus</i>「教えられた」, <i>dignus</i>「値する」; Gk <i>dékhomai</i>「受け取る」, <i>dokeîn</i>「思われる」
+eng: <b>本来語</b> teach(?), token(?)（*deiḱ- 系）／<b>ラテン系</b> decent, decorate, decorum, dignity, dainty（二重語）, deign, disdain, indignant, doctor, doctrine, document, docile, disciple, discipline／<b>ギリシア系</b> dogma, orthodox（正しく思われる）, paradox（通念に反する）, doxology
+note: <i>doctor</i> は「教える者」（<i>docēre</i>）で、もと学位の称号。医師の意味は後発（意味の縮小、第7章）。

@ *deḱm̥ ; 「十」
+cog: L <i>decem</i>; Gk <i>déka</i>; Skt <i>dáśa</i>; Goth <i>taíhun</i>; OCS <i>desętĭ</i>; Lith <i>dešimt</i>
+eng: <b>本来語</b> ten, -teen, -ty（thirteen, thirty）, hundred（＜ *ḱm̥tóm）／<b>ラテン系</b> decimal, decade, December（もとローマ暦の第10月）, decimate, dean（<i>decānus</i> 十人隊長）, dime（<i>decima</i> 十分の一）, denary／<b>ギリシア系</b> decathlon, dodecahedron

+cog: L <i>ego</i>; Gk <i>egṓ</i>; Skt <i>ahám</i>; Goth <i>ik</i>; Lith <i>àš</i>
+eng: <b>本来語</b> I（OE <i>ic</i>）／<b>ラテン系</b> ego, egoism, egotism, alter ego
+note: 英語の <i>I</i> は、印欧祖語の二音節語がここまで摩耗した極端な例。大文字で書くのは、中英語期に小文字の i が読みにくかったための書記上の慣習。

@ *h₁er- ; 「動く、達する」
+cog: L <i>orīrī</i>「昇る」, <i>orīgō</i>「起源」; Gk <i>órnymi</i>「起こす」; Hitt <i>arāi-</i>
+eng: <b>本来語</b> earnest(?), run(?)／<b>ラテン系</b> origin, original, aborigine, orient, oriental, abort, abortion
+note: <i>orient</i>「東洋」は「日が昇る方」、<i>abort</i>「流産する」は「昇らない＝生まれ出ない」。

@ *h₁eus- ; 「焼く」
+cog: L <i>ūrere</i>「焼く」, <i>ustus</i>; Gk <i>heúein</i>; Skt <i>óṣati</i>
+eng: <b>本来語</b> ember(?)／<b>ラテン系</b> combustion, adust, ustulate
+note: <i>combustion</i>「燃焼」の -bust- はこの語根とされる。

@ *h₁leudʰ- ; 「育つ、人民」
+cog: L <i>līber</i>「自由な」（「一族の成員」から）, <i>līberī</i>「子どもたち」; Gk <i>eleútheros</i>「自由な」; OCS <i>ljudŭ</i>「人民」; 独 <i>Leute</i>
+eng: <b>本来語</b> lede（古語「人民」）／<b>ラテン系</b> liberty, liberal, liberate, deliver, libertine
+note: 「自由」は本来「（奴隷ではなく）一族に属する者」の意。共同体の成員であることが自由の条件だった。

@ *h₁newn̥ ; 「九」
+cog: L <i>novem</i>; Gk <i>ennéa</i>; Skt <i>náva</i>; Goth <i>niun</i>
+eng: <b>本来語</b> nine, ninety, noon（「第九時」）／<b>ラテン系</b> November, novena, nonagenarian
+note: <i>noon</i>「正午」がもと午後3時ごろだったことは第VI部の項を参照。

@ *ǵʰeh₁- ; 「去る、空になる」
+cog: Gk <i>khḗra</i>「未亡人」; Skt <i>jáhāti</i>
+eng: <b>本来語</b> go(?), gone(?)
+note: 英語 <i>go</i> の語源は不確実で、この語根とする説と PGmc 独自語とする説がある。

@ *ǵʰer- ; 「短い、欠ける」
+cog: L <i>hērēs</i>「相続人」(?); Gk <i>khḗra</i>「寡婦」
+eng: <b>ラテン系</b> heir, heritage, inherit, heredity, hereditary
+note: <i>heir</i>「相続人」を「（死者の）欠けた場所を埋める者」と解する説。

@ *ǵʰeys- ; 「驚く、恐れる」
+cog: Goth <i>usgeisnan</i>「驚く」
+eng: <b>本来語</b> ghost, ghastly, aghast, ghoul は別（アラビア語）
+note: <i>ghost</i> の h は15世紀にオランダ語の影響で入った書記上の追加（第VI部）。

@ *ǵʰreh₁- ; 「育つ、緑」
+cog: OE <i>grōwan</i>「育つ」; ON <i>gróa</i>
+eng: <b>本来語</b> grow, green, grass, graze（草を食む）
+note: <i>green</i>「緑」が <i>grow</i>「育つ」と同根であるのは、「育つものの色」だから。色名が事物から作られる典型。

@ *gʷeh₂- ; 「行く、来る」
+cog: Gk <i>baínein</i>「歩く」, <i>básis</i>「歩み、台」; Skt <i>gāti</i>
+eng: <b>ギリシア系</b> base, basis, basement, acrobat（「先端を歩く」）, diabetes（「（尿が）通り抜ける」）, anabasis, hyperbaton
+note: 前掲 *gʷem-（come, venue）と近縁の別語根とされる。

@ *gʷelbʰ- ; 「子宮」
+cog: Gk <i>delphýs</i>「子宮」, <i>adelphós</i>「兄弟（同じ子宮の）」
+eng: <b>ギリシア系</b> Philadelphia（「兄弟愛」）, dolphin（<i>delphís</i>「子宮を持つ魚＝胎生」）
+note: <i>dolphin</i>「イルカ」が「子宮」に遡るのは、魚と違って胎生であることをギリシア人が知っていたため。

@ *gʷelH- ; 「投げる、届く」
+cog: Gk <i>bállein</i>「投げる」, <i>bolḗ</i>「投擲」
+eng: <b>ギリシア系</b> ball（球技のそれは別）, ballistic, symbol（「投げ合わせる」）, problem（「前に投げ出されたもの」）, emblem, parable/parabola, hyperbole, metabolism, devil（<i>diábolos</i>「投げ違える者＝中傷者」）, diabolic
+note: <i>devil</i>「悪魔」の原義は「（言葉を）投げつけて中傷する者」。<i>symbol</i>「象徴」は割符を「投げ合わせる」。

@ *gʷetH- ; 「言う」
+cog: Goth <i>qiþan</i>「言う」; ON <i>kveða</i>
+eng: <b>本来語</b> quoth（古語「言った」）, bequeath（「言い残す」＝遺贈する）, bequest
+note: <i>bequeath</i>「遺贈する」は「（遺言で）言い置く」。<i>quoth the Raven, "Nevermore"</i>（ポー）に古形が残る。

@ *kagʰ- ; 「捕える、囲う」
+cog: L <i>cohum</i>「くびき紐」; W <i>cae</i>「垣」
+eng: <b>本来語</b> hedge, haw（サンザシの実）, haggard(?)／<b>ラテン系</b> cage(?), incarcerate は別
+note: <i>hedge</i>「生垣」と <i>haw</i>「サンザシ」（<i>hawthorn</i>＝「垣の刺」）が同根。

@ *keh₂d- ; 「憎む」
+cog: Gk <i>kêdos</i>「気遣い、悲しみ」; Goth <i>hatis</i>「憎しみ」
+eng: <b>本来語</b> hate, hatred, heinous（仏語経由）
+note: ギリシア語では「気遣い」、ゲルマン語では「憎しみ」と正反対に振れた。強い感情という点で共通する。

@ *keh₂p- ; 「つかむ」→ *kap- を見よ
+cf: → <b>*kap-</b>（取る・つかむ）。capture, have, heavy。

@ *kel- ; 「打つ、切る」
+cog: L <i>-cellere</i>「打つ」, <i>clādēs</i>「損害」; Gk <i>kláein</i>「折る」
+eng: <b>本来語</b> halt(?)／<b>ラテン系</b> clast は ギ／<b>ギリシア系</b> iconoclast（「像を打ち砕く者」）, clastic
+note: 前掲の *kel-「覆う」「呼ぶ」「丘」とは別語根。同形の語根が複数あることに注意。

@ *kerp- ; 「摘む、集める」
+cog: L <i>carpere</i>「摘む」; Gk <i>karpós</i>「果実」
+eng: <b>本来語</b> harvest（「収穫」）／<b>ラテン系</b> carpet（「むしり取った布」）, excerpt, carpe diem（「日を摘め」）, scarce(?)
+note: <i>harvest</i>（本来語）と <i>carpet</i>（ラテン系）が同根。ホラティウスの <i>carpe diem</i> も同じ語根。

@ *kes- ; 「切る」
+cog: L <i>castrāre</i>「切る」, <i>castus</i>「純潔な」(?); Skt <i>śásati</i>
+eng: <b>ラテン系</b> castrate, caste（「混じり気のない（血統）」）, chaste, chasten, incest（「純潔でない」）
+note: <i>caste</i>「カースト」はポルトガル語 <i>casta</i>「純血」から。<i>chaste</i>「純潔な」と同語源。

@ *kʷelp- ; 「丸天井、屋根」

+eng: <b>本来語</b> gulf（ギリシア語経由）, engulf
+note: <i>gulf</i>「湾」の原義は「ふところ」。

@ *kʷerp- ; 「回る」
+cog: Gk <i>karpós</i>「手首」（回る関節）
+eng: <b>本来語</b> wharf(?)
+note: ギリシア語では「果実」の <i>karpós</i> と同綴だが別語。

@ *legʷʰ- ; 「軽い、素早い」
+cog: L <i>levis</i>「軽い」; Gk <i>elakhýs</i>「小さい」; Skt <i>laghú-</i>
+eng: <b>本来語</b> light（軽い）, lung（「軽い臓器」＝水に浮く）, lever は仏経由／<b>ラテン系</b> levity, alleviate, elevate, relieve, relevant, lever, leaven, carnival
+note: <i>lung</i>「肺」が「軽い」であるのは、水に入れると浮くから。ロシア語 <i>лёгкое</i>「肺」も「軽い」から。

@ *leikʷ- ; → 前掲
+cf: → <b>*leikʷ-</b>（残す）。relinquish, eclipse, lend。

@ *leig- ; 「跳ぶ、震える」
+cog: OIr <i>lingid</i>「跳ぶ」
+eng: <b>本来語</b> lick は別／<i>delight</i> は L <i>dēlectāre</i> で別語源
+note: 語根としては痕跡が薄い。

@ *lengʷʰ- ; 「軽い」→ *legʷʰ- を見よ
+cf: → <b>*legʷʰ-</b>
