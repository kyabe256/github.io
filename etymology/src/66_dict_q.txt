== Q

@ quarantine ; /ˈkwɒrəntiːn/ ; 名 ; 検疫
+lit: 「四十（日）」
+chain: 伊（ヴェネツィア方言）<i>quarantina</i>「四十日間」（<i>quaranta</i>「四十」）→ 英語（1660年代）
+desc: 14世紀のペスト流行時、ラグーサ（ドゥブロヴニク）とヴェネツィアが疫病流行地からの船を沖に停泊させた期間。当初は30日（<i>trentina</i>）だったが、40日に延長された。40という数は、キリストの荒野の40日など聖書的な象徴数でもある。
+der: quarter, quart, four（本来語）, square, quadrant

@ quarry ; /ˈkwɒri/ ; 名 ; 採石場／獲物
+desc: 二つの別語が同綴になった例。（1）採石場：L <i>quadrāre</i>「四角に切る」→ OF <i>quarriere</i>。（2）獲物：OF <i>cuiree</i>「（狩りの後、猟犬に与える）獣の内臓（を皮 <i>cuir</i> に載せたもの）」。
+der: (1) square, quadrant, quarter／(2) cuirass, curry（革をなめす）

@ quick ; /kwɪk/ ; 形 ; 速い
+lit: 「生きている」
+root: *gʷeyh₃w-「生きる」
+chain: OE <i>cwic</i>「生きた」
+desc: 「生きている」→「活発な」→「速い」。<i>the quick and the dead</i>「生者と死者」（使徒信条）、<i>cut to the quick</i>「生身まで切る」、<i>quicksilver</i>「水銀＝生きた銀」、<i>quicksand</i>「動く（生きた）砂」に古義が残る。
+der: vital, vivid, survive, revive, biology, zoo（同根語）

@ quiz ; /kwɪz/ ; 名 ; クイズ
+chain: 語源不明（1780年代、「変人」の意で初出）
+note: 「ダブリンの劇場支配人デイリーが、無意味な語を一晩で流行らせられるという賭けをして街中に QUIZ と落書きさせた」という有名な逸話があるが、初出年代と合わず、作り話とされる。語源不明の語に付きまとう典型的な創作説（第1章）。

@ quaint ; /kweɪnt/ ; 形 ; 古風で趣のある
+chain: L <i>cognitus</i>「知られた」→ OF <i>cointe</i>「巧みな、粋な」
+desc: 「巧みな」→「凝った」→「風変わりな」→「古風で愛らしい」。原義の「知られた」からは遠い。
+see: know

@ quell ; /kwel/ ; 動 ; 鎮圧する
+chain: OE <i>cwellan</i>「殺す」
+see: kill
+note: 古英語の「殺す」の主要語が、「鎮める」に弱まった。強い語が弱化する例（<i>starve</i>「死ぬ」→「飢える」も同型）。

@ query ; /ˈkwɪəri/ ; 名動 ; 問い合わせ
+chain: L <i>quaerere</i>「求める、問う」の命令形 <i>quaere</i>
+root: 語源不確実（ラテン語独自）
+der: question, quest, inquire, require, acquire, conquer, exquisite, inquest, request, perquisite（→ perk）
+note: 欄外に「調べよ」と書き入れた指示語 <i>quaere</i> が名詞化した。
+lvl: ★★

@ queue ; /kjuː/ ; 名 ; 列
+lit: 「尻尾」
+chain: L <i>cauda</i>「尾」→ 仏 <i>queue</i>
+der: coward（「尾を巻く者」の説）, coda（音楽の「終結部」）, cue（撞球の棒）
+note: 英国で「行列」の意になったのは19世紀。米語は <i>line</i> を使う。計算機の <i>queue</i> は1946年。

@ quorum ; /ˈkwɔːrəm/ ; 名 ; 定足数
+lit: 「その者たちのうち」
+chain: L <i>quōrum</i>（関係代名詞の複数属格）
+desc: 治安判事の任命状の定型句 <i>quōrum vōs … ūnum esse volumus</i>「そのうちの一人であってほしい」から、句の一語が切り出された。
+see: omnibus, propaganda（屈折形の名詞化）

@ quota ; /ˈkwəʊtə/ ; 名 ; 割当量
+chain: L <i>quota pars</i>「何分の一の部分」
+der: quotient, quote, quotidian（「毎日の」）
+note: <i>quote</i>「引用する」は「章節番号を付ける」が原義。

@ quixotic ; /kwɪkˈsɒtɪk/ ; 形 ; 非現実的に理想主義の
+chain: <i>Don Quixote</i>（セルバンテス、1605）
+note: 文学の登場人物名から作られた形容詞。同型に <i>gargantuan</i>（ラブレー）, <i>malapropism</i>（シェリダン）, <i>panglossian</i>（ヴォルテール）, <i>Orwellian</i>, <i>Kafkaesque</i>。
+see: 人名由来語索引

@ quintessence ; /kwɪnˈtesns/ ; 名 ; 真髄
+lit: 「第五の本質」
+chain: 中世ラテン語 <i>quīnta essentia</i>（Gk <i>pémptē ousía</i> の訳）
+desc: アリストテレスが四大元素（土・水・風・火）に加えた第五元素＝天体を構成するエーテル。錬金術師はこれを抽出しようとした。「最も純粋な essence」の意はそこから。
+der: quintet, quintuple, essence, essential

@ quarrel ; /ˈkwɒrəl/ ; 名 ; 口論
+chain: L <i>querī</i>「嘆く、訴える」→ <i>querēla</i>「苦情」
+der: querulous（「不平がましい」）
+note: <i>quarry</i>（採石場、<i>quadra</i> 系）とは無関係。
