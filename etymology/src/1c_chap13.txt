# 第13章　英語の音声と綴りの体系

英語の綴りは「でたらめ」と言われる。だが実際には、でたらめなのではなく<b>複数の時代の規則が地層のように重なっている</b>。ある綴りは1400年の発音を、別の綴りは1600年のラテン語学者の判断を、また別の綴りは写字生の勘違いを記録している。読めない綴りは、読めない語源のしるしである。

この章では、音と綴りのずれがどこから来たのかを、体系として整理する。語源をたどるうえでも、綴りを覚えるうえでも、ここが基礎になる。

## 13-1　調音の座標——音はどこで作られるか

子音は、<b>どこで（調音位置）</b>・<b>どうやって（調音法）</b>・<b>声帯を震わせるか（有声・無声）</b>の三つで決まる。この三軸が分かると、グリムの法則も、接頭辞の同化も、なぜその音がその音に変わるのかが見えるようになる。音変化は気まぐれではなく、<b>座標上の隣へ動く</b>のである。

%fig place-of-articulation ; 調音位置——唇から喉へ

| 調音位置 | 無声破裂音 | 有声破裂音 | 摩擦音 | 鼻音 |
|---|---|---|---|---|
| 両唇 | p | b | (f, v は唇歯) | m |
| 歯・歯茎 | t | d | θ, ð, s, z | n |
| 硬口蓋 | — | — | ʃ, ʒ | — |
| 軟口蓋 | k | ɡ | (x) | ŋ |
| 声門 | ʔ | — | h | — |

この表を横に読むと<b>調音法の系列</b>、縦に読むと<b>調音位置の系列</b>になる。グリムの法則（第3章）は、この表の上で「有声帯気音 → 有声音 → 無声音 → 摩擦音」という<b>縦の玉突き</b>が起きた現象だった。ヴェルナーの法則は、同じ縦の動きが「アクセントの位置」という条件で分岐した現象である。

接頭辞の同化も同じ座標で説明できる。<i>ad-</i> は次の子音の位置へ引き寄せられて <i>ac-, af-, ag-, al-, an-, ap-, ar-, as-, at-</i> になる（<i>accept, affect, aggregate, allocate, announce, appear, arrive, assist, attend</i>）。<i>in-</i> は両唇音の前で <i>im-</i> になる（<i>impossible, immediate</i>）——これは <i>n</i>（歯茎）が <i>p, b, m</i>（両唇）に位置を合わせる動きである。<b>調音の楽をする方向へ動く</b>という一点で、すべて説明がつく。

> <b>実用上の要点。</b>同化は「知らないと語が分解できない」ところで効く。<i>arrogant</i> を <i>ar-+rogant</i> と見ても何も出てこないが、<i>ad-+rogāre</i>「自分に向かって要求する」と見えれば意味が通る。二重子音は<b>同化した接頭辞の痕跡</b>だと覚えておくとよい。

## 13-2　母音の四辺形と大母音推移

母音は舌の<b>高さ</b>と<b>前後</b>で位置づけられる。この平面を母音四辺形と呼ぶ。

15世紀から18世紀にかけて、英語の長母音がこの平面上で<b>一斉に上へずり上がった</b>のが大母音推移（Great Vowel Shift）である。すでに最も高かった /iː/ と /uː/ は上に行き場がなく、二重母音 /aɪ/ /aʊ/ に外れた。

| 中英語 | 現代英語 | 例（綴りは中英語のまま） |
|---|---|---|
| /iː/ | /aɪ/ | <i>time</i>（ティーメ → タイム） |
| /eː/ | /iː/ | <i>meet</i>（メート → ミート） |
| /ɛː/ | /iː/ | <i>meat</i>（メート → ミート） |
| /aː/ | /eɪ/ | <i>name</i>（ナーメ → ネイム） |
| /ɔː/ | /oʊ/ | <i>boat</i>（ボート → ボウト） |
| /oː/ | /uː/ | <i>moon</i>（モーン → ムーン） |
| /uː/ | /aʊ/ | <i>house</i>（フース → ハウス） |

<b>綴りは推移の前に固定されていた。</b>カクストンが印刷術を導入したのが1476年、推移の進行中である。その結果、綴りは中英語の発音を、発音は近代英語を表すという不一致が生まれた。英語の綴りが他のヨーロッパ言語より不透明なのは、主としてこの一事による。

同語根の語で母音が食い違う現象も、多くはここに起因する。<i>divine / divinity</i>、<i>serene / serenity</i>、<i>sane / sanity</i>、<i>nation / national</i>、<i>please / pleasant</i>——いずれも、長母音のまま推移した形と、短母音化して推移を免れた形の対である。<b>母音がずれている二語は、たいてい同語源である。</b>

## 13-3　黙字の三類型

発音されない文字には、由来のはっきり違う三つの種類がある。混同すると綴りの理屈を見誤る。

<b>(1) かつては発音された（音変化で消えた）</b>
<i>knight, knee, knife, know, gnaw, gnome, write, wrong, wrist, half, talk, walk, castle, listen, often</i>。<i>kn-</i> は17世紀まで /kn/ と読まれ、<i>wr-</i> は /wr/ だった。<i>knight</i> の <i>gh</i> はドイツ語 <i>Knecht</i> と同じ /x/ の音である。<b>綴りは正しく、発音のほうが変わった</b>類型で、ドイツ語やオランダ語の同源語と比べると綴りの根拠が見える。

<b>(2) 語源に合わせて後から足された（語源的復元）</b>
<i>debt, doubt, subtle, receipt, salmon, victual, indict, reign, verdict</i>。中英語では <i>dette, doute, sotil, receite</i> と、フランス語のまま綴られ、そう発音されていた。16世紀の人文主義者たちが「ラテン語の <i>dēbitum, dubitāre, subtīlis, recepta</i> に合わせるべきだ」として文字を挿入した。<b>発音は正しく、綴りのほうが後から歪められた</b>類型である。

<b>(3) 語源を誤解して足された（誤った復元）</b>
<i>island</i> の <i>s</i>——古英語 <i>īeġland</i>「島の land」で、フランス語 <i>isle</i>（L <i>īnsula</i>）とは無関係なのに、似ているという理由で <i>s</i> が入れられた。<i>scissors</i> の <i>c</i>——L <i>cīsōrium</i>（<i>caedere</i>「切る」）なのに、<i>scindere</i>「裂く」と誤って結びつけられた。<i>could</i> の <i>l</i>——<i>would, should</i>（こちらは <i>will, shall</i> があるので語源的に正しい）に引きずられた完全な類推で、<i>can</i> には <i>l</i> の根拠がない。<i>anchor</i> の <i>h</i>、<i>ptarmigan</i> の <i>p</i>、<i>rhyme</i> の <i>h</i> も同型である。

> <b>三類型の見分け方。</b>ドイツ語・オランダ語に同源語があり、そこで文字が発音されていれば (1)。ラテン語の原形と綴りが一致すれば (2)。どちらでもなく、似た語からの類推が疑われれば (3)。<i>debt</i> と <i>doubt</i> が (2)、<i>island</i> が (3) という違いは、綴りを「理不尽」で片づけないために知っておく価値がある。

## 13-4　同じ音の多様な綴り、同じ綴りの多様な音

英語では音と文字が一対一に対応しない。/iː/ は <i>me, see, sea, field, receive, key, quay, people, machine</i> と九通りに綴られ、逆に <i>-ough</i> は <i>though</i> /əʊ/、<i>through</i> /uː/、<i>thought</i> /ɔː/、<i>tough</i> /ʌf/、<i>cough</i> /ɒf/、<i>bough</i> /aʊ/、<i>hiccough</i> /ʌp/ と七通りに読まれる。

この混乱の原因は三つある。第一に<b>大母音推移</b>（13-2）。第二に<b>借用元言語ごとの綴り規則の並存</b>——フランス語式（<i>ch</i> = /ʃ/：<i>machine, chef</i>）、ラテン語式（<i>ch</i> = /k/：<i>chorus, character</i>）、英語本来（<i>ch</i> = /tʃ/：<i>church, child</i>）が同居している。第三に<b>写字生の慣習</b>——中英語の写本で <i>u, n, m, v, w</i> が縦棒の連続になり読みにくいため、<i>u</i> を <i>o</i> に書き換えた（<i>cume → come</i>, <i>sunu → son</i>, <i>munuc → monk</i>, <i>wumman → woman</i>, <i>luve → love</i>）。<b><i>o</i> と綴って /ʌ/ と読む語群は、書きやすさのための綴り換えの痕跡である。</b>

## 13-5　綴り字改革の歴史

英語の綴りを合理化しようという試みは繰り返されてきた。

- <b>16〜17世紀</b>　スミス、ハート、ブルカーらが表音的な綴り字を提案。いずれも普及せず。
- <b>1755年</b>　ジョンソンの辞典が、それまでの揺れを固定した。改革ではなく<b>現状の権威づけ</b>だったことが、以後の綴りを凍結させた。
- <b>1806/1828年</b>　ノア・ウェブスターの米語辞典。<i>colour → color</i>, <i>centre → center</i>, <i>defence → defense</i>, <i>traveller → traveler</i>, <i>catalogue → catalog</i>, <i>plough → plow</i>。米国のアイデンティティ形成と結びついたため、これだけが定着した。<b>綴り字改革は、言語学的な正しさではなく政治的な意志によって成功する。</b>
- <b>20世紀初頭</b>　カーネギーが資金を出した簡易綴り字協会（Simplified Spelling Board）にセオドア・ローズヴェルト大統領が加勢し、公文書での採用を命じたが、議会と世論の反発で撤回された。
- <b>現在</b>　改革運動は事実上停止している。国際語となった英語では、綴りの変更コストが利益を上回るためである。

> <b>学習上の含意。</b>英語の綴りは覚えるしかない部分が残るが、<b>不規則の大半には理由がある</b>。<i>debt</i> の <i>b</i> は「ラテン語だから」、<i>knight</i> の <i>k</i> は「昔は読んだから」、<i>island</i> の <i>s</i> は「間違いだから」。理由の分類を知っていると、綴りは丸暗記の対象から、読み解きの対象に変わる。語源を学ぶ実利のひとつがここにある。
