== U

@ umbrella ; /ʌmˈbrelə/ ; 名 ; 傘
+lit: 「小さな影」
+chain: L <i>umbra</i>「影」→ <i>umbella</i>（縮小形）→ 伊 <i>ombrella</i> → 英語
+desc: 本来は日傘。雨傘としての用法は18世紀の英国から（ジョナス・ハンウェイが街中で使い嘲笑された逸話が知られる）。
+der: umbrage（「日陰→気を悪くすること」<i>take umbrage</i>）, somber（「影の下」）, penumbra, adumbrate, umbel（植物の散形花序）
+note: 仏語 <i>parapluie</i>「雨を防ぐもの」、<i>parasol</i>「日を防ぐもの」は機能で命名。

@ umpire ; /ˈʌmpaɪə/ ; 名 ; 審判
+lit: 「対等でない者（＝第三者）」
+chain: OF <i>nonper</i>（<i>non</i>「非」+ <i>per</i>「同輩」）→ ME <i>a noumpere</i> → <i>an umpire</i>
+desc: 冠詞との境界の切り直し（異分析、第6章）。同じ現象で <i>a napron</i> → <i>an apron</i>、<i>a nadder</i> → <i>an adder</i>。
+der: par, pair, peer, nonpareil, compare, disparage

@ uncouth ; /ʌnˈkuːθ/ ; 形 ; 無骨な
+lit: 「知られていない」
+chain: OE <i>uncūþ</i>（<i>un-</i> + <i>cūþ</i>「知られた」＜ <i>cunnan</i>「知る」）
+desc: 「未知の」→「なじみのない」→「異様な」→「粗野な」。
+der: know, can, ken, cunning, kith（<i>kith and kin</i>「知人と親族」）, couth（20世紀の逆成による戯語）
+note: <i>couth</i>「洗練された」は、<i>uncouth</i> から un- を外して20世紀に作られた冗談めいた逆成語。

@ university ; /juːnɪˈvɜːsəti/ ; 名 ; 大学
+lit: 「（教師と学生の）全体としての組合」
+chain: L <i>ūniversitās</i>「全体、団体」（<i>ūnus</i>「一」+ <i>vertere</i>「向ける」）
+desc: 中世の <i>ūniversitās magistrōrum et scholārium</i>「教師と学生の組合」の略。建物ではなく人の団体を指す語だった。
+der: universe（「一つに向けられたもの」＝万物）, universal, verse, version, convert, divert
+note: <i>college</i>（共に規約を持つ団体）も同様に、人の集団を指す語である。

@ utopia ; /juːˈtəʊpiə/ ; 名 ; 理想郷
+lit: 「どこにもない場所」
+chain: Gk <i>ou</i>「ない」+ <i>tópos</i>「場所」→ トマス・モアの造語（1516）
+desc: モアは同時に <i>eu-tópos</i>「良い場所」との掛詞を意図しており、著書の付録詩でその両義性を明示している。
+der: dystopia（19世紀。J.S.ミルの議会演説, 1868）, topic, topography, isotope
+note: 造語者が意識的に多義性を仕込んだ稀な例。

@ urchin ; /ˈɜːtʃɪn/ ; 名 ; わんぱく小僧
+lit: 「ハリネズミ」
+chain: L <i>ēricius</i>「ハリネズミ」→ 北仏 <i>herichon</i> → ME
+desc: 「ハリネズミ」→（比喩で）「（髪の逆立った）小僧」。<i>sea urchin</i>「ウニ」に原義が残る。
+der: hedgehog（本来語の別表現）, echinoderm（ギ <i>ekhînos</i>「ハリネズミ、ウニ」）

@ understand ; /ˌʌndəˈstænd/ ; 動 ; 理解する
+chain: OE <i>understandan</i>
+conf: 一説　<i>under</i> は「下に」ではなく古義の「間に」（L <i>inter</i> と同根の *n̥ter-）とする説が有力。「物事の間に立つ」＝内側から把握する。
+note: 独 <i>verstehen</i>、L <i>comprehendere</i>「掴み込む」、Gk <i>syn-hienai</i>「送り合わせる」と、理解の比喩は言語ごとに異なる。
+see: 第8章
+lvl: ★★★

@ undermine ; /ˌʌndəˈmaɪn/ ; 動 ; 弱体化させる
+lit: 「（城壁の）下に坑道を掘る」
+chain: <i>under</i>＋<i>mine</i>「坑道を掘る」
+note: 攻城戦の技術用語。城壁の下を掘って支柱を焼き崩落させた。<i>mine</i>「地雷」もこの坑道戦から。
+lvl: ★★

@ union ; /ˈjuːniən/ ; 名 ; 結合、組合
+chain: L <i>ūnus</i>「一」→ 後期ラテン語 <i>ūniō</i>
+root: *óynos「一」
+cog: OE <i>ān</i> → one, a/an, Gk <i>oínē</i>「（賽の）一の目」
+der: one, once, only, alone, atone（<i>at one</i>「一つになる」＝贖罪する）, none, unit, unite, universe, unique, onion（L <i>ūniō</i>「大きな真珠、玉ねぎ」）
+note: <i>onion</i> と <i>union</i> は同一語。層が一つに合わさった球根の形から。<i>atone</i> は英語内部で作られた語で、<i>at one</i> の綴りが融合した。
+see: *óynos
+lvl: ★★★

@ universe ; /ˈjuːnɪvɜːs/ ; 名 ; 宇宙
+lit: 「一つに向けられたもの」
+chain: L <i>ūnus</i>「一」＋<i>vertere</i>「向ける」→ <i>ūniversum</i>
+der: version, convert, divert, invert, pervert, reverse, adverse, controversy, vertebra, versatile, worth（ゲルマン系同根）
+note: <i>-verse</i> をもつ語群は英語で最大級。<i>vertebra</i>「椎骨」は「回るもの」＝関節。
+see: *wert-
+lvl: ★★★

@ urban ; /ˈɜːbən/ ; 形 ; 都市の
+chain: L <i>urbs</i>「都市」→ <i>urbānus</i>
+dbl: urbane
+note: <i>urban</i>（地理的）と <i>urbane</i>（「都会的に洗練された」）が同一語から価値を分けた。<i>rural</i>／<i>rustic</i>、<i>human</i>／<i>humane</i> と同型のペア。
+see: rural
+lvl: ★★

@ urge ; /ɜːdʒ/ ; 動 ; 促す
+chain: L <i>urgēre</i>「押す」
+der: urgent, urgency
+lvl: ★★

@ usher ; /ˈʌʃə/ ; 名 ; 案内係
+lit: 「扉番」
+chain: L <i>ōstium</i>「入口」→ <i>ōstiārius</i> → OF <i>uissier</i>
+der: oral, oscillate（<i>ōs</i>「口」）
+note: <i>ōstium</i> は <i>ōs</i>「口」から。建物の「口」＝入口。

@ utensil ; /juːˈtensl/ ; 名 ; 器具
+chain: L <i>ūtī</i>「使う」→ <i>ūtēnsilia</i>「使えるもの」
+der: use, utility, usual, abuse, utilize, usury（「使用料」＝利息）
+note: <i>usury</i>「高利貸し」はもと中立の「利息」。中世教会が利息を禁じたため悪義に固定した。

@ uncanny ; /ʌnˈkæni/ ; 形 ; 不気味な
+chain: スコットランド語 <i>canny</i>「賢い、（魔術に）通じた」＋<i>un-</i>
+note: フロイトの <i>das Unheimliche</i>（1919）の英訳語に採用され、精神分析・美学の術語になった。

@ upholster ; /ʌpˈhəʊlstə/ ; 動 ; 椅子張りをする
+chain: <i>uphold</i>「支える、（商品を）保持する」→ <i>upholder</i>「古物商」→ <i>upholsterer</i> → 逆成 <i>upholster</i>
+see: 逆成（第6章）

@ utter ; /ˈʌtə/ ; 動形 ; 発する／まったくの
+chain: OE <i>ūt</i>「外へ」の比較級 <i>ūtera</i>「より外の」
+der: out, outer, utmost, utterance, about
+note: 動詞は「（言葉を）外に出す」、形容詞は「外側の＝極端な」→「まったくの」。<i>outer</i> と <i>utter</i> は同一語。

@ unkempt ; /ʌnˈkempt/ ; 形 ; ぼさぼさの
+chain: <i>un-</i>＋ME <i>kempt</i>「櫛で梳かれた」（OE <i>cemban</i>、<i>comb</i> と同根）
+see: overwhelm
+note: 肯定形 <i>kempt</i> はほぼ廃語。<i>disgruntled/gruntled</i>, <i>ruthless/ruth</i>, <i>reckless/reck</i>, <i>feckless/feck</i> と同型。
