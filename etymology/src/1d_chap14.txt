# 第14章　語彙の統計——何語覚えれば何％読めるか

語彙学習には、どこかで必ず「あと何語やればいいのか」という問いが来る。この章はその問いに数字で答える。ここで示す数値は英語コーパス言語学（Nation, Schmitt, Browne らの研究および British National Corpus / COCA の頻度表）に基づく概算であり、テキストの種類によって上下するが、桁の感覚としては信頼してよい。

## 14-1　頻度順位とカバー率——最初の1,000語が半分を占める

英語の語彙は極端に偏って分布する。使用頻度の上位から数えていくと、テキストを覆う割合は次のように伸びる。

%fig coverage ; 語彙サイズとテキストカバー率

| 覚えた語数（語族単位） | 一般テキストのカバー率 | 何が読めるか |
|---|---|---|
| 100 | 約50% | 機能語ばかり。文の骨格だけ |
| 1,000 | 約72% | 日常会話の大半。読解はまだ困難 |
| 2,000 | 約82% | 平易な物語。4語に1語未満が未知 |
| 3,000 | 約86% | 平易な新聞記事。辞書があれば読める |
| 5,000 | 約89% | 一般的な新聞・雑誌 |
| 8,000 | 約93% | 小説・専門外の記事が概ね読める |
| 10,000 | 約95% | 大学教育レベル |
| 20,000 | 約98% | 教養ある母語話者の下限 |

ここで決定的に重要なのが、<b>読解に必要なカバー率は95〜98%</b>だという研究上の知見である。カバー率90%（10語に1語が未知）では文脈から推測することさえ難しい。<b>95%でようやく辞書なしで大意がつかめ、98%で快適に読める。</b>

この表の非対称性に注目してほしい。<b>最初の2,000語で82%まで行くが、そこから95%へ行くのに8,000語かかる。</b>語彙学習の後半は、努力に対する見返りが桁違いに悪くなる。だからこそ、後半では効率を上げる手段——<b>語源による束ね直し</b>——が必要になる。

## 14-2　頻度帯ごとの語源構成——高頻度はゲルマン、低頻度はラテン

英語の語彙全体では、ゲルマン系が約25%、ラテン・フランス語系が約58%、ギリシア語系が約5%を占める（第5章の円グラフ）。ところが<b>頻度帯で切ると構成比は劇的に変わる。</b>

%fig freq-origin ; 頻度順位帯ごとの語源構成（累積）

図は「上位N語をまとめて見たときの構成比（累積）」を示している。下の表はこれを<b>帯ごとに切り分けた</b>もので、同じ現象を別の角度から見た数字である。累積で見ると変化はなだらかだが、帯ごとに見ると逆転がはっきり出る。

| 頻度順位 | ゲルマン系 | ラテン・仏語系 | ギリシア語系・その他 |
|---|---|---|---|
| 1–1,000 | 約83% | 約16% | 約1% |
| 1,001–2,000 | 約60% | 約37% | 約3% |
| 2,001–5,000 | 約40% | 約55% | 約5% |
| 5,001–10,000 | 約25% | 約64% | 約11% |
| 10,001– | 約15% | 約60% | 約25% |

この表は、語彙学習の戦略を根本から決める。

- <b>最初の1,000語（＝カバー率約72%）はほぼゲルマン系</b>で、しかも <i>get, take, put, come, go, make, do, run, set</i> のような多義の基本動詞である。<b>ここに語源は効かない。</b>必要なのは語源知識ではなく、用法と共起の反復である。
- <b>2,000語を超えたあたりからラテン系が過半を占める。</b>ここから語源が効き始める。
- <b>5,000語以上の帯では、ラテン・ギリシア系が四分の三を超える。</b>この帯は、語根と接辞の知識があれば初見でも推測でき、なければ一語ずつ丸暗記するしかない。<b>語源学習の投資回収はこの帯で起きる。</b>

> <b>要点。</b>「語源で英単語を覚える」は、初級では効かず、中級以降で急速に効き始める。TOEIC 440点・英検3〜準2級の段階では基本語の反復が最優先で、TOEIC 600点・英検2級を超えたあたりから語源が主力になる。<b>順番を間違えると、どちらの方法も無駄になる。</b>

## 14-3　語族の大きさ——一つの語根が何語を生むか

語根の生産性も極端に偏る。英語で最大の語族を作るラテン語動詞の上位は次のとおり。

| 語根 | 派生する英語（概数） | 代表例 |
|---|---|---|
| <i>pōnere / positus</i>（置く） | 50語超 | compose, expose, deposit, position, purpose |
| <i>capere / captus</i>（取る） | 45語超 | receive, accept, capable, participate, recipe |
| <i>ferre / lātus</i>（運ぶ） | 40語超 | confer, differ, refer, transfer, relate |
| <i>tenēre</i>（保つ） | 35語超 | contain, maintain, obtain, tenant, content |
| <i>mittere / missus</i>（送る） | 35語超 | admit, permit, mission, promise, dismiss |
| <i>dūcere / ductus</i>（導く） | 30語超 | conduct, produce, reduce, educate, duct |
| <i>facere / factus</i>（なす） | 30語超 | factory, affect, perfect, benefit, difficult |
| <i>specere / spectus</i>（見る） | 30語超 | aspect, inspect, respect, species, despise |
| <i>vertere / versus</i>（向ける） | 30語超 | convert, diverse, universe, version, controversy |
| <i>stāre / status</i>（立つ） | 30語超 | state, statue, institute, assist, stable |

<b>上位20の語根を完全に覚えると、およそ600語がカバーされる。</b>そのほとんどが 3,000〜10,000語の頻度帯、つまり「覚えるのが最もつらい帯」に属する。これが語源学習の費用対効果の正体である（具体的なリストは第XI部）。

一方、ゲルマン系の語根はこれほど大きな語族を作らない。<i>bear</i>（*bʰer-）や <i>stand</i>（*steh₂-）は印欧語根としては巨大だが、英語内部での派生は少なく、大半はラテン語側の同根語として現れる。<b>英語における「語族の大きさ」は、ラテン語動詞の活用形が接頭辞と組み合わさる仕組みが作り出している。</b>

## 14-4　試験別・必要語彙数の目安

| 目標 | 必要語彙数（語族） | 語源学習の比重 |
|---|---|---|
| 英検3級 | 約1,500 | ほぼ不要 |
| 英検準2級 | 約2,500 | 補助的 |
| TOEIC 500 | 約3,000 | 補助的 |
| 英検2級 | 約4,000 | 有効になり始める |
| TOEIC 600 | 約4,500 | 有効 |
| TOEIC 730 | 約6,000 | 主力になりうる |
| 英検準1級 | 約7,500 | 主力 |
| TOEIC 860 | 約8,500 | 主力 |
| 英検1級 | 約10,000〜12,000 | 必須 |

> <b>数字の読み方。</b>「語族」とは <i>nation / national / nationality / international / nationalize</i> をまとめて1と数える単位である。単語数で数えると2〜3倍になる。市販の単語帳が「1,900語収録」と言うとき、それは見出し語の数であって語族数ではないことが多い。

## 14-5　この統計から出る三つの実務的結論

1. <b>カバー率95%が実用の分水嶺。</b>それ以下では読解が推測の連続になり、伸びが実感できない。逆に言えば、95%（約10,000語族）に達すると学習の性質が変わる。
2. <b>語彙の増加は逓減する。</b>最初の1,000語は毎日20語で50日、次の1,000語は同じ日数でも定着率が落ちる。<b>同じ努力で伸びなくなるのが正常</b>であり、そこで方法を変えるべきであって、努力量を増やすべきではない。方法の変更とは、具体的には<b>語源による束ね直し</b>と<b>多読による遭遇回数の確保</b>である。
3. <b>語源が効き始める地点は明確に測れる。</b>あなたの語彙が3,000語族に届いたら、語根表を持ち出す時期である。それ以前は基本語の反復に集中したほうが速い。

現在 TOEIC 440点（語彙 2,500〜3,000語族と推定）であれば、<b>ちょうど語源が効き始める入口に立っている。</b>基本語の反復を続けながら、第XI部の語根トップ100を並行して回していくのが、この統計から導かれる最適配分である。
