# 付録

## 付録A　印欧語族系統図

印欧祖語（Proto-Indo-European, 前4500〜前2500頃）

- <b>アナトリア語派</b>（最初に分岐）── ヒッタイト語、ルウィ語、パラー語、リュディア語、リュキア語　※すべて死語
- <b>トカラ語派</b> ── トカラ語A（焉耆語）、トカラ語B（亀茲語）　※死語
- <b>インド・イラン語派</b>
  - インド・アーリア語群 ── サンスクリット語 → プラークリット諸語 → ヒンディー語、ウルドゥー語、ベンガル語、パンジャーブ語、マラーティー語、ネパール語、シンハラ語、ロマ語
  - イラン語群 ── アヴェスター語、古代ペルシア語 → 中期ペルシア語 → ペルシア語（ファールシー）、クルド語、パシュトー語、バローチー語、オセット語
- <b>ギリシア語派</b> ── ミュケナイ・ギリシア語 → 古典ギリシア語（アッティカ、イオニア、ドーリス、アイオリス） → コイネー → 中世ギリシア語 → 現代ギリシア語
- <b>アルメニア語派</b> ── 古典アルメニア語（グラバル） → 現代アルメニア語
- <b>アルバニア語派</b> ── アルバニア語（ゲグ方言、トスク方言）
- <b>イタリック語派</b>
  - オスク・ウンブリア語群 ── オスク語、ウンブリア語　※死語
  - ラテン・ファリスキ語群 ── ラテン語 → 俗ラテン語 → ロマンス諸語（イタリア語、フランス語、スペイン語、ポルトガル語、ルーマニア語、カタルーニャ語、ガリシア語、オック語、サルデーニャ語、ロマンシュ語）
- <b>ケルト語派</b>
  - 大陸ケルト語 ── ガリア語、ケルティベリア語、レポント語　※死語
  - ゴイデル語群 ── 古アイルランド語 → アイルランド語、スコットランド・ゲール語、マン島語
  - ブリソン語群 ── ウェールズ語、コーンウォール語、ブルトン語
- <b>ゲルマン語派</b>
  - 東ゲルマン語群 ── ゴート語、ヴァンダル語、ブルグント語　※死語
  - 北ゲルマン語群 ── 古ノルド語 → アイスランド語、フェロー語、ノルウェー語、デンマーク語、スウェーデン語
  - 西ゲルマン語群
    - 北海ゲルマン語（Ingvaeonic）── 古英語 → <b>英語</b>／古フリジア語 → フリジア語／古サクソン語 → 低地ドイツ語
    - 低地フランク語 ── 古低フランク語 → オランダ語、アフリカーンス語
    - 高地ドイツ語 ── 古高ドイツ語 → 中高ドイツ語 → ドイツ語、イディッシュ語
- <b>バルト・スラヴ語派</b>
  - バルト語群 ── リトアニア語、ラトビア語、（古プロシア語 ※死語）
  - スラヴ語群 ── 古教会スラヴ語／東（ロシア語、ウクライナ語、ベラルーシ語）／西（ポーランド語、チェコ語、スロヴァキア語、ソルブ語）／南（セルビア・クロアチア語、ブルガリア語、スロヴェニア語、マケドニア語）

### B-2　ヴェルナーの法則

アクセントが直前の音節にない場合、グリムの法則で生じた f θ h hʷ s が有声化して b̄ ð ɣ ɣʷ z となる。

| 現象 | 例 |
|---|---|
| θ → ð → d | *ph₂tḗr → <i>father</i>（cf. *bʰréh₂tēr → <i>brother</i>） |
| s → z → r（ロタシズム） | <i>was</i> : <i>were</i>；L <i>flōs</i> : <i>flōris</i>；<i>genus</i> : <i>generis</i> |
| 文法的交替 | <i>freeze</i> : <i>frozen</i>；<i>seethe</i> : <i>sodden</i>；<i>choose</i> : <i>chosen</i>；<i>lose</i> : <i>forlorn</i> |

| v/f → b | give, have, seven, love | geben, haben, sieben, lieben |

| 変化 | 例（原形 → ウムラウト形） |

## 付録F　語源不明・不確実な語

日常語のなかにも、起源の分からない語は少なくない。

<i>dog, big, bad, boy, girl, pig, bird(?), job, jump, jaw, curse, fun, kick, lad, lass, pimp, prank, puzzle, quiz, slang, tantrum, toad, tot, gadget, gimmick, blizzard, condom, gizmo, hunch, jazz, bloke, dodge, fudge, gawk, gawky, jolly(?), niche(?), pun, rat(?), skulk, slum, snob, spree, stunt, tag, tote, trek(?), zest(?)</i>

これらは、（1）方言や隠語からの浮上、（2）擬音・擬態からの発生、（3）記録の欠落、のいずれかによると考えられる。語源辞典の「of unknown origin」という記述は、探究の放棄ではなく、証拠の限界を示す誠実な表現である。
