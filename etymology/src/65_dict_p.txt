== P

@ pandemonium ; /pændəˈməʊniəm/ ; 名 ; 大混乱
+lit: 「すべての悪魔（の館）」
+chain: Gk <i>pân</i>「すべて」+ <i>daimōn</i>「霊、悪魔」→ ミルトン『失楽園』（1667）の造語
+desc: ミルトンが地獄の首都の名として造った語 <i>Pandæmonium</i>。18世紀に「大混乱」の普通名詞となった。
+der: demon, pantheon, panorama, pandemic

@ panic ; /ˈpænɪk/ ; 名 ; 恐慌
+lit: 「牧神パーンの（引き起こす）」
+chain: Gk <i>Pānikós</i>「パーンの」→ 仏 <i>panique</i> → 英語
+desc: 山野に住む牧神パーンは、旅人や家畜に突然の理由なき恐怖を吹き込むとされた。<i>panic</i> はもと形容詞（<i>panic fear</i>）で、名詞化は18世紀。
+note: 経済用語の <i>bank panic</i>「取り付け騒ぎ」も同じ語。

@ paradise ; /ˈpærədaɪs/ ; 名 ; 楽園
+lit: 「（壁で）囲われた庭園」
+chain: アヴェスター語 <i>pairi-daēza</i>（<i>pairi</i>「周りに」+ <i>daēza</i>「壁」）→ Gk <i>parádeisos</i>「（ペルシア王の）猟園」→ L → OF
+desc: クセノフォンがペルシア王の庭園を指して用いた語。七十人訳聖書がエデンの園の訳語に採用し、「天国」の意味を得た。
+der: peri-（周りに）, paries（ラ「壁」）, dough（*dʰeigʰ-「こねる」＝土を積む）
+note: 第一要素は Gk <i>perí</i>、英語 <i>far</i>, <i>for</i> と同根。

@ pedigree ; /ˈpedɪɡriː/ ; 名 ; 家系
+lit: 「鶴の足」
+chain: OF <i>pié de grue</i>「鶴の足」→ ME <i>pedegru</i>
+desc: 系図で分岐を示す三叉の記号が、鶴の足跡に似ていたことによる。
+der: pedal, pedestrian, biped／crane（本来語）, geranium（「鶴の（嘴）」）
+note: 同じ形からの命名に <i>crowbar</i>（烏のくちばし）, <i>crane</i>（起重機）がある。

@ person ; /ˈpɜːsn/ ; 名 ; 人
+lit: 「（劇の）仮面」
+chain: エトルリア語 <i>phersu</i>「仮面」（説）→ L <i>persōna</i>「仮面、役、人格」→ OF
+desc: 「仮面」→「劇中の役」→「法律上の資格」→「人格」→「人」。ラテン語 <i>per-sonāre</i>「（仮面を）通して響かせる」とする古来の説は民間語源とされる。
+dbl: <i>parson</i>（「（教区を代表する）人格」＝教区司祭）, <i>persona</i>
+der: personal, personality, impersonate, personnel

@ planet ; /ˈplænɪt/ ; 名 ; 惑星
+lit: 「さまようもの」
+chain: Gk <i>planâsthai</i>「さまよう」→ <i>planḗtēs (astḗr)</i>「さまよう星」→ L <i>planēta</i>
+desc: 恒星（<i>fixed stars</i>）に対して、天球上を不規則に動く天体を指した。日本語「惑星」（本木良永の訳語）も同じ発想の翻訳借用。
+der: aberrant は別／planetarium, planetary

@ plumber ; /ˈplʌmə/ ; 名 ; 配管工
+lit: 「鉛を扱う者」
+chain: L <i>plumbum</i>「鉛」→ <i>plumbārius</i> → OF → ME
+desc: ローマ以来、水道管は鉛で作られた。元素記号 Pb もこの語による。
+der: plumb（測鉛）, plumb line, aplomb（仏「垂直に＝落ち着き」）, plunge（「鉛のように沈める」）
+note: 綴りの b は発音されない。<i>plumb</i>「垂直の」から「まったく」（<i>plumb crazy</i>）の副詞用法も生じた。

@ posthumous ; /ˈpɒstjʊməs/ ; 形 ; 死後の
+lit: 「最後の（子）」
+chain: L <i>postumus</i>「最後の」（<i>post</i> の最上級）
+desc: 父の死後に生まれた子を指すようになり、<i>humus</i>「土（＝埋葬）」との民間語源的な連想から h が挿入された。
+der: post-, posterior／humus, humble, human（誤って結びつけられた語）
+note: 綴りの h は語源的に誤りだが、意味の理解を助けたために定着した。

@ punch ; /pʌntʃ/ ; 名 ; パンチ（飲料）
+lit: 「五」
+chain: ヒンディー語／サンスクリット語 <i>pāñč</i>「五」→ 英語（1632）
+desc: 酒・砂糖・レモン・水・香辛料の五種の材料から。インドの英国人が本国に持ち帰った。
+der: five, fist（本来語）, pentagon, quintet（同根語）
+note: 拳の <i>punch</i>、道具の <i>punch</i>、人形劇の <i>Punch</i> はいずれも別語源。

@ pupil ; /ˈpjuːpl/ ; 名 ; 生徒、瞳孔
+lit: 「小さな人形／少女」
+chain: L <i>pūpus/pūpa</i>「子ども、人形」→ <i>pūpillus/pūpilla</i>
+desc: 二つの意味は同一語。「生徒」は「未成年の被後見人」から。「瞳孔」は、人の瞳に映る自分の小さな姿を「人形」に見立てたことによる。ギリシア語 <i>kórē</i>「少女／瞳」、ヘブライ語「目の中の小さな人」も同じ比喩を持つ。
+der: puppet, puppy, pupa（さなぎ）, puberty は別

@ pyjamas / pajamas ; /pəˈdʒɑːməz/ ; 名 ; パジャマ
+lit: 「脚の衣」
+chain: ペルシア語／ウルドゥー語 <i>pāy-jāma</i>（<i>pāy</i>「脚」+ <i>jāma</i>「衣」）→ 英語（1800年ごろ）
+der: <i>pāy</i> は L <i>pēs</i>, 英 <i>foot</i> と同根（*ped-）
+note: インド在住の英国人が現地の緩やかなズボンを寝間着に採用した。

@ pandemic ; /pænˈdemɪk/ ; 形・名 ; 世界的流行（の）
+lit: 「すべての民の」
+chain: Gk <i>pân</i>「すべて」+ <i>dêmos</i>「民」→ <i>pandēmos</i>
+der: epidemic（「民の間に来る」）, endemic（「民の中にある」）, democracy, demagogue, demography
+note: 三語の接頭辞の違い（pan-/epi-/en-）が、そのまま疫学の定義の違いに対応している。

@ pencil ; /ˈpensl/ ; 名 ; 鉛筆
+lit: 「小さな尾（＝筆）」
+chain: L <i>pēnis</i>「尾」→ <i>pēnicillus</i>「小さな筆」→ OF <i>pincel</i>
+desc: 本来は細い絵筆。黒鉛の筆記具を指すようになったのは16世紀、ボローデール鉱山の発見以降。
+der: penicillin（1929年フレミング。菌の房が筆状であることから）, pencil
+note: <i>pen</i>「ペン」は別語源（L <i>penna</i>「羽根」）。<i>pencil</i> と <i>pen</i> は無関係である。

@ pen ; /pen/ ; 名 ; ペン
+lit: 「羽根」
+chain: L <i>penna</i>「羽根」→ OF <i>penne</i>
+desc: 羽根ペン（quill）の時代の名が、金属ペン・ボールペンにまで受け継がれた。
+der: pennant, pinnate, pinnacle, feather（本来語の同根語）
+note: <i>penknife</i>「小刀」は、もと羽根ペンの先を削るための刃物。

@ police ; /pəˈliːs/ ; 名 ; 警察
+lit: 「都市の統治」
+chain: Gk <i>pólis</i>「都市国家」→ <i>politeíā</i>「国制」→ L <i>polītīa</i> → 仏 <i>police</i>
+dbl: <i>policy</i>（同語源の二重語）
+desc: 「国家の統治」一般を指す語だったが、18世紀に「治安機構」に特殊化した。<i>policy</i>（保険証券）はギリシア語 <i>apódeixis</i>「証明」由来の別語で、同綴の混同がある。
+der: politics, polity, metropolis, cosmopolitan, acropolis

@ palace ; /ˈpæləs/ ; 名 ; 宮殿
+chain: 地名 <i>Palātium</i>（ローマのパラティヌスの丘。アウグストゥス以後、皇帝の邸宅が置かれた）→ L <i>palātium</i>「宮殿」→ OF <i>palais</i>
+der: paladin, palatine, palatial
+note: 丘の名が「宮殿」を意味する普通名詞になり、独 <i>Pfalz</i>、仏 <i>palais</i>、伊 <i>palazzo</i> として全ヨーロッパに広がった。

@ pants ; /pænts/ ; 名 ; ズボン

@ paragraph ; /ˈpærəɡrɑːf/ ; 名 ; 段落
+lit: 「傍らに書かれた（印）」
+chain: Gk <i>pará</i>「傍らに」+ <i>gráphein</i>「書く」
+desc: 古代の写本で、段落の切れ目を示すために行の脇に書き入れた記号。記号の名が単位の名になった。
+note: 現在の段落記号 ¶（pilcrow）は、この記号の子孫で、<i>paragraph</i> の語形が中世に訛ったもの（<i>pilcrow</i> ＜ <i>paragraph</i>）。

@ pedagogue ; /ˈpedəɡɒɡ/ ; 名 ; 教育者
