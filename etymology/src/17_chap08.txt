# 第8章　二重語――同じ語が二度入ってくるとき

## 8.1　二重語（doublet）とは

同一の起源を持ちながら、異なる経路・異なる時代に借用されたために別語となった語のペアを二重語（doublet）と呼ぶ。三つあれば三重語（triplet）である。英語は借用の層が厚いため、二重語の宝庫になっている。

二重語が生じる典型的な経路は次の三つである。

1. <b>ラテン語から直接／フランス語経由</b>：<i>fragile</i>（L 直）と <i>frail</i>（OF 経由）。
2. <b>ノルマン方言経由／中央フランス語経由</b>：<i>warranty</i> と <i>guarantee</i>。
3. <b>本来語／借用語</b>：<i>shirt</i>（OE）と <i>skirt</i>（ON）。

一般に、直接借用形は原形に近く堅い語感を持ち、フランス語経由形は音が摩耗し日常的である。

## 8.6　同根語をどう見抜くか

英語のなかで、見た目の似ていない語が同根であることは珍しくない。手がかりは次の通りである。

1. <b>グリムの法則の対応</b>を当てる（第3章）。<i>heart</i> と <i>cardiac</i>、<i>kin</i> と <i>genetic</i>。
2. <b>ラテン語の語幹交替</b>を知る。ラテン動詞は現在幹と完了分詞幹で形が変わる（<i>agere/āctum</i>, <i>ferre/lātum</i>, <i>ferre</i> の完了分詞は <i>lātum</i>）。<i>act</i> と <i>agent</i>、<i>refer</i> と <i>relate</i>、<i>mit</i> と <i>miss</i>（<i>mittere/missum</i>：<i>transmit/transmission</i>）、<i>ced</i> と <i>cess</i>（<i>cēdere/cessum</i>）、<i>vid</i> と <i>vis</i>（<i>vidēre/vīsum</i>）、<i>scrib</i> と <i>script</i>、<i>duc</i> と <i>duct</i>、<i>fer</i> と <i>lat</i>、<i>fac</i>/<i>fic</i> と <i>fact</i>。
3. <b>母音交替（アプラウト・i-ウムラウト）</b>を疑う。<i>sit/set/seat/settle/soot(?)/nest</i>（*ni-sd-o-「下に座る所」）。
4. <b>接頭辞の同化</b>を戻す。<i>ad-</i> は後続子音に同化して <i>ac-, af-, ag-, al-, an-, ap-, ar-, as-, at-</i> になる（<i>accept, affect, aggregate, allude, annex, apply, arrive, assign, attend</i>）。<i>in-</i> は <i>il-, im-, ir-</i> に、<i>com-</i> は <i>col-, con-, cor-, co-</i> に、<i>sub-</i> は <i>suc-, suf-, sug-, sup-, sur-, sus-</i> になる。
5. <b>語頭の s-（s-mobile）</b>を疑う。印欧祖語には、同じ語根に付いたり付かなかったりする語頭の *s があった。<i>(s)tegō</i>「覆う」：<i>thatch</i>（覆う物）と <i>protect</i>／<i>toga</i>。<i>(s)mer-</i>：<i>memory</i> と <i>mourn</i>。<i>(s)neu-</i>：<i>nerve</i> と <i>sinew</i>。

> <b>練習</b>　次の各組は同根である。理由を考えてみよう。<i>guest / hostile</i>、<i>cow / beef</i>、<i>wheel / cycle / collar(?)</i>、<i>five / punch(飲料) / pentagon</i>、<i>tooth / dentist</i>、<i>eight / octopus</i>、<i>naked / nude</i>、<i>day / diary(?)</i>（最後は同根ではない、が答え）。
