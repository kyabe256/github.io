# 第15章　語源から見た英語学習法

前章までで、語源の仕組みと、語彙の統計を見た。この章は、その二つをつないで<b>実際に何をするか</b>を決める。第XI部（学習直結編）への橋渡しである。

語源学習には熱心な支持者と、冷ややかな批判者がいる。どちらも部分的に正しい。正しく切り分ければ、批判のほとんどは「使う場所を間違えている」という指摘に還元できる。

## 15-1　語源が効く領域・効かない領域

<b>効く領域</b>

1. <b>抽象語・多音節語。</b><i>comprehensive, subordinate, inevitable, unprecedented, indispensable</i>。接頭辞＋語根＋接尾辞に分解でき、分解すると意味が立ち上がる。この帯は頻度順位 3,000〜15,000 に集中しており（第14章）、丸暗記が最もつらい層と完全に重なる。
2. <b>語族が大きい語根。</b><i>ten-</i> ひとつで <i>contain, maintain, obtain, retain, sustain, detain, abstain, tenant, tenure, tenacious, content, continent, continue</i> が一挙に整理される。一語ずつ覚えれば13回、語根で束ねれば1回である。
3. <b>既視感はあるが定着しない語。</b>語源は「新しく覚える」よりも「すでに何度も見た語を固定する」ほうに強く効く。フックがひとつ増えるだけで想起率が変わる。
4. <b>紛らわしい語の識別。</b><i>adopt / adapt / adept</i>、<i>affect / effect</i>、<i>imply / infer</i>、<i>comprise / compose</i>。接頭辞の方向が意味の方向をそのまま決めているので、語源が最も明快な判別基準になる。
5. <b>専門語彙の初見推測。</b>医学・法律・IT の術語はギリシア・ラテン要素の合成である。<i>nephrectomy</i> を「腎（nephro-）＋切除（-ectomy）」と読めれば辞書は要らない。

<b>効かない領域</b>

1. <b>基本動詞。</b><i>get, take, put, run, set, make, come, go</i>。語源をたどっても現代の用法は出てこない。これらの語の実体は語義ではなく<b>共起パターン</b>であり、覚えるべきは <i>get over, get through, get by</i> のほうである。第14章の統計どおり、高頻度帯はゲルマン系で、語源分析の余地が小さい。
2. <b>句動詞・イディオム。</b>同上。
3. <b>語源と現代語義が離れすぎた語。</b><i>nice</i>（無知な→よい）、<i>silly</i>（幸福な→愚かな）、<i>pretty</i>（狡猾な→きれいな）、<i>naughty</i>（無一物の→いたずらな）。語源は面白いが、意味の推測には使えない。むしろ<b>誤誘導する</b>。
4. <b>正確な語義の確定。</b>語源は意味の<b>方向</b>を示すが、精度は与えない。<i>obnoxious</i> を「害に晒された」と分解しても「不快な」までは届かない。最後は文脈と用例が決める。

> <b>批判への回答。</b>「語源で覚えるのは非効率だ」という批判は、上の「効かない領域」に語源を持ち込んだ場合には完全に正しい。「語源で覚えれば単語帳は要らない」という主張は、逆方向に同じ誤りを犯している。<b>語源は単語帳の代替ではなく、単語帳の増幅器である。</b>

## 15-2　三段階の手順

語源の使いどころは、学習の<b>順序</b>で決まる。

<b>第一段階：出会う（単語帳・多読）</b>
語彙は語源からではなく、実際のテキストか単語帳から入る。ここは反復量がすべてで、語源の出番はない。1日に触れる語数を確保することだけを考える。

<b>第二段階：束ね直す（語源）</b>
<b>その日のうちに</b>、出会った語を語根で束ね直す。「今日出た <i>retain</i>・<i>detain</i>・<i>sustain</i> はどれも <i>ten-</i>（保つ）だ」と気づいて、紙に3語並べて接頭辞の意味を書き添える。所要時間は5分。この一手間が、翌週の想起率を大きく変える。<b>語根リストを先に暗記してはいけない。</b>出会っていない語の語根を覚えても、掛ける相手がいない。

<b>第三段階：確かめる（文脈）</b>
束ねた語を、実際の文の中で確認する。<i>tenant</i> が契約書に、<i>tenure</i> が大学の記事に、<i>tenacious</i> が人物評に出てくる——語根が同じでも使われる場所が違うことを、実例で見る。ここで語義の精度が付く。

この三段階を、<b>一日単位で回す</b>。週末にまとめて語源をやるのではなく、その日出会った語をその日のうちに束ねる。

## 15-3　語源ノートの作り方

第XI部の語根表を丸写ししても身につかない。<b>自分が出会った語だけ</b>を材料に、次の形で書く。

| ten-（保つ） | | |
|---|---|---|
| con-（ともに）＋ten | contain | 含む |
| de-（離して）＋tain | detain | 拘留する |
| sus-（下から）＋tain | sustain | 支える |
| （接頭辞なし） | tenant / tenure | 借家人（保つ人）／保有権 |
| 反対方向は？ | release, relinquish | lig-「縛る」の否定 |

要点は三つ。<b>(1) 語根を見出しにする</b>（語をアルファベット順に並べない）。<b>(2) 接頭辞の意味を必ず書く</b>——意味の方向を決めているのは接頭辞のほうである。<b>(3) 出会うたびに同じページに書き足す</b>。ノートは完成させるものではなく、育てるものである。1年後にそのページを見ると、自分がその語根で何語知っているかが一目で分かる。

## 15-4　語源辞典の引き方

本書を含め、語源辞典は「読む」のではなく「引く」ものである。効率のよい引き方がある。

1. <b>まず第VI部（A–Z）を引く。</b>その語が単独で立項されていればそこで終わる。
2. <b>立項されていなければ、語根を推定して第II〜V部を引く。</b>接頭辞を外し、母音の交替（<i>cap/cip/cept</i>, <i>fac/fic/fect</i>, <i>ten/tin/tain</i>）を戻すのがこつである（第9章）。
3. <b>分野が分かっていれば第VII部から。</b>医学語なら医学の節に、法律語なら法律の節にまとまっている。
4. <b>外来語らしければ第VIII部から。</b>語形が英語離れしていれば（<i>bazaar, tsunami, kiosk</i>）、言語別の部が早い。
5. <b>索引は5種ある。</b>英語見出し語／印欧語根・語幹／接辞／分野別／人名・地名由来語。人名らしい語（<i>boycott, sandwich, silhouette</i>）は最後の索引が最短である。
6. <b>疑わしい語源譚を聞いたら第X部（俗説）を引く。</b>「<i>posh</i> は Port Out, Starboard Home の略」「<i>golf</i> は Gentlemen Only, Ladies Forbidden」の類は、ほぼすべて後世の作り話である。

> <b>柱（ページ上端の見出し語範囲）を使う。</b>辞書パートでは、各ページの右上にそのページに載っている見出し語の範囲が出る。目的の語を探すときは本文ではなく柱を追う。紙の辞書と同じ引き方が、この PDF でもできるようにしてある。

## 15-5　三か月の運用例

語源を実際の学習計画に組み込む例を挙げる。TOEIC 440点前後から600点を目指す場合を想定した（第14章の統計に基づき、基本語の反復を主、語源を従とする配分）。

| 週 | 主（毎日） | 従（毎日15分） |
|---|---|---|
| 1–4 | 単語帳 1日100語×高速回し | その日の語を語根で束ねる（第XI部の語根トップ20を参照） |
| 5–8 | 単語帳を継続＋公式問題集のパート5 | 語根トップ50まで拡張。第XI部の確認問題 A・B 群 |
| 9–12 | 公式問題集を通し＋苦手パート集中 | 語根トップ100完成。確認問題 C・D・E 群、TOEIC語彙の節 |

<b>従（語源）は主（単語帳）を置き換えない。</b>15分という枠を守ることが重要で、語源が面白くなって主客が逆転すると点は伸びない。語源は<b>反復の定着率を上げるための投資</b>であり、反復そのものの代わりにはならない。

三か月後、語彙が 4,000語族に届いたあたりで比重を変えてよい。そこから先——英検準1級・TOEIC 730 以上の帯——では、第14章の統計が示すとおり、ラテン・ギリシア系が語彙の三分の二を占める。<b>その帯に入ったとき、語源は補助輪ではなく主動力になる。</b>
