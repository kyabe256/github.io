# まえがき

英語の <i>window</i> が「風の目」であり、<i>lord</i> が「パンの番人」であり、<i>muscle</i> が「小さなねずみ」であることを知ったとき、語はただの記号ではなくなる。そこには、家にガラスがなかった時代の暮らしがあり、パンの分配が権力そのものだった社会があり、皮膚の下を走る筋肉に小動物を見た人間の目がある。語源とは、語のなかに畳み込まれた歴史のことである。

本書は、英語の語彙を「丸暗記する対象」から「導出できる体系」へと転換するために編まれた。柱は三本ある。

第一に、<b>音の対応</b>。印欧祖語からゲルマン語派への規則的な子音推移（グリムの法則）を知れば、<i>foot</i> と <i>pedal</i>、<i>heart</i> と <i>cardiac</i>、<i>know</i> と <i>diagnosis</i> が同じ祖形の兄弟であることが一目で分かる。

第二に、<b>形の分解</b>。ラテン語系語彙は、接頭辞の同化（ad- → ac-, af-, ag-…）と母音弱化（cap → cip → cept）という二つの規則を戻せば、機械的に分解できる。<i>accept</i>, <i>except</i>, <i>perceive</i>, <i>occupy</i>, <i>municipal</i>, <i>prince</i> が同じ語根から出ていることも、規則を知れば見える。

第三に、<b>意味の変化</b>。<i>nice</i> は「無知な」から、<i>silly</i> は「祝福された」から来ている。意味の変化には型があり、その型を知ることは、語の現在の姿を深く理解することでもある。

本書の構成は次の通りである。第I部（総説15章）で方法と歴史を通観し、第II部で印欧祖語の語根、第III部でラテン語の語幹、第IV部でギリシア語の語幹、第V部で接辞を配列する。第VI部は A–Z の語源辞典本体である。第VII部は分野別（医学・法律・IT・金融・料理ほか）、第VIII部は言語別（アラビア語・オランダ語・インド諸語・日本語ほか）に語彙を束ね直した辞典で、「この分野の語はどこから来たか」という角度から引けるようにした。第IX部は主題別の語源誌、第X部は俗説の検証、第XI部は語源を実際の英語学習に接続するための実務編（確認問題300問付き）である。巻末に付録と、五種類の索引を置いた。

第2版では、図版26点を新たに描き起こした。系統樹・音変化・派生ツリー・統計図はいずれも、文字だけでは伝わりにくい「関係の形」を示すためのものである。また辞書パートには柱（ページ上端の見出し語範囲）を入れ、紙の辞書と同じ引き方ができるようにした。

語源学は仮説の学である。本書でも、確定的な事実、通説、有力な一説、不確実な推測を書き分けるよう努めた。「〜とされる」「〜説がある」「不確実」という留保は、慎重さの表れであって曖昧さではない。逆に、巷間に流布する魅力的な語源譚——<i>posh</i> の頭字語説、<i>salary</i> の「塩で給与」説、<i>genuine</i> の「膝」説、<i>sincere</i> の「蝋なしで」説——については、明確に「誤り」「裏づけなし」と記した。

そして最後に、もっとも大切なことをひとつ。<b>語源は現在の語義を規定しない。</b>　<i>decimate</i> がローマ軍の「十人に一人を殺す刑」に由来するからといって、現代英語で「壊滅させる」の意で使うことが誤りになるわけではない。語源をもって現用法を裁断することを、語源論的誤謬（etymological fallacy）と呼ぶ。語源が与えてくれるのは規範ではなく、奥行きである。

この一冊が、読者にとって英語という言語の地層を掘り進むための鶴嘴となれば幸いである。
