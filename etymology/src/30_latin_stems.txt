== A

@ ac- / acr- ; L <i>acer</i>「鋭い」, <i>acidus</i>「酸っぱい」, <i>acuere</i>「尖らせる」
+root: *h₂eḱ-「鋭い」
+der: acid, acidity, acute, acumen, acuity, acerbic, exacerbate, acrid, acrimony, acrimonious, eager（古義「鋭い」）, vinegar（<i>vin aigre</i>「酸い酒」）, acupuncture, aglet（靴紐の金具）, ague（「鋭い（熱）」）
+note: 同源のギリシア系は <i>oxy-</i>（oxygen, oxymoron, paroxysm）、<i>acro-</i>（acrobat, acropolis）。

@ ag- / act- / ig- ; L <i>agere, āctum</i>「駆る、行う」
+root: *h₂eǵ-
+der: act, action, active, actor, actual, agent, agency, agenda, agile, agitate, ambiguous, cogent, cogitate(?), exact, exigent, exigency, essay, assay, navigate, litigate, mitigate（「柔らかくする」）, castigate, fumigate, prodigal, transact, react, retroact, coagulate, examine（<i>exāmen</i>「秤の舌」）, purge（<i>pūrigāre</i>）, ambage
+note: -igate で終わる動詞は、この語幹に別要素が付いたものが多い（<i>navis</i>+<i>agere</i>＝船を進める＝navigate）。

@ agr- ; L <i>ager, agrī</i>「畑」
+root: *h₂éǵros「放牧地」（*h₂eǵ-「駆る」から）
+der: agriculture, agrarian, agronomy, agribusiness, peregrine（「畑を越えて＝異国の」）, pilgrim（<i>peregrīnus</i> の摩耗形）
+note: <i>pilgrim</i>「巡礼者」と <i>peregrine</i>「隼、外来の」は二重語。本来語 <i>acre</i> も同根（*h₂eǵros）。

@ alt- ; L <i>altus</i>「高い、深い」（<i>alere</i>「養う」の分詞＝「育った」）
+root: *h₂el-「育つ」
+der: altitude, alto, altar(?), exalt, enhance（<i>altiāre</i>）, haughty（<i>haut</i>）, hautboy/oboe（「高い木」）
+note: 本来語 <i>old</i>, <i>elder</i>, <i>world</i> と同根。

@ am- / amic- ; L <i>amāre</i>「愛する」, <i>amīcus</i>「友」
+root: 語源不確実（幼児語起源説）
+der: amateur, amatory, amorous, amour, paramour, enamored, amiable, amicable, amity, inimical, enemy（<i>inimīcus</i>「友でない者」）, enmity
+note: <i>enemy</i> は <i>in-</i>（非）+ <i>amīcus</i>（友）。ギリシア系の対応は <i>phil-</i>（philosophy, philanthropy）。

@ ambul- ; L <i>ambulāre</i>「歩く」
+root: *ambʰi + *h₂el-（諸説）
+der: ambulance, ambulatory, amble, preamble（「前を歩く」＝前文）, perambulate, somnambulist, ramble(?)
+note: <i>ambulance</i> は仏 <i>hôpital ambulant</i>「移動病院」から。

@ anim- ; L <i>animus</i>「心、意気」, <i>anima</i>「息、魂」
+root: *h₂enh₁-「息をする」
+der: animal, animate, animation, animism, animosity, animadvert, unanimous, magnanimous, pusillanimous（「小心な」）, equanimity, longanimity
+note: 「息」と「魂」を同一視する語は諸言語に共通する。

@ ann- / enn- ; L <i>annus</i>「年」
+root: *h₂et-no-「巡るもの」（説）
+der: annual, annuity, anniversary, annals, biennial, triennial, perennial（「年を通す」＝多年生）, centennial, millennium, superannuated, annuity, per annum
+note: 複合語で ann- → enn- と母音弱化する（第9章）。

@ aqu- ; L <i>aqua</i>「水」
+root: *h₂ekʷeh₂-
+der: aquatic, aquarium, aqueduct, aquamarine, aqueous, aquifer, ewer, sewer(?), gouache（伊経由）
+note: ギリシア系の対応は <i>hydr-</i>、本来語は <i>water</i>。

@ arm- ; L <i>arma</i>「武具」（＜「はめ合わせるもの」）
+root: *h₂er-「合わせる」
+der: arms, army, armor, armistice（「武器を止める」）, armada, alarm（伊 <i>all'arme!</i>「武器を取れ」）, armadillo（「武装した小さいもの」）, disarm, gendarme（<i>gens d'armes</i>「武装の人々」）
+note: 英語 <i>arm</i>（腕）は本来語だが、同じ語根から出ている。<i>alarm</i>「警報」はイタリア語の号令に由来する。

@ art- ; L <i>ars, artis</i>「技」
+root: *h₂er-
+der: art, artist, artisan, artifice, artificial, artillery, article（「小さな継ぎ目」＝関節→項目）, articulate, inert（「技のない」→ 不活発な）
+note: <i>article</i>「冠詞・記事・条項」の原義は「小さな関節」。文を関節で区切るもの。

@ aud- / audit- ; L <i>audīre, audītum</i>「聞く」
+root: *h₂ew-is-dʰh₁-「知覚を置く」（説）
+der: audio, audible, audience, audit, auditor, auditorium, audition, obey（<i>ob-audīre</i>「（下から）聞く」）, obedient, obeisance
+note: <i>obey</i>「従う」は「（耳を傾けて）聞く」から。フランス語経由で大きく摩耗した。

@ aug- / auct- ; L <i>augēre, auctum</i>「増やす」
+root: *h₂ewg-「増す」
+der: augment, auction（「せり上げること」）, author（<i>auctor</i>「増やす者、創始者」）, authority, authorize, auxiliary, august（「威厳ある」＝増大した）, August（アウグストゥス帝）, inaugurate（鳥占いで就任を占う <i>augur</i> から）, augur
+note: 本来語 <i>eke</i>（増す）, <i>nickname</i>（<i>an eke-name</i>「追加の名」）と同根。

== B – C

@ bell- ; L <i>bellum</i>「戦争」
+root: *dwellom（古形 <i>duellum</i>）
+der: belligerent, bellicose, rebel, rebellion, antebellum, duel（<i>duellum</i> の古形が「二人の戦い」と再解釈された）
+note: <i>duel</i> は <i>duo</i>「二」との民間語源的な結びつきで意味が固まった例。

@ ben- / bon- ; L <i>bene</i>「よく」, <i>bonus</i>「よい」
+root: *dwenos（<i>duonus</i>）
+der: benefit, benefactor, beneficial, benediction（「よく言うこと」＝祝福）, benevolent, benign, bonus, bounty, bonanza, boon(?), debonair
+note: ギリシア系の対応は <i>eu-</i>（eulogy＝benediction、euphoria、euthanasia）。

@ brev- ; L <i>brevis</i>「短い」
+root: *mreǵʰu-（→ Gk <i>brakhýs</i>）
+der: brief, brevity, abbreviate, abridge（同語源の二重語）, breve, brassiere は別
+note: <i>abbreviate</i>（ラテン直輸入）と <i>abridge</i>（仏語経由）は二重語。

@ cad- / cid- / cas- ; L <i>cadere, cāsum</i>「落ちる」
+root: *ḱad-
+der: cadence, cadaver, case（格・場合）, casual, casualty, accident, incident, coincidence, decay, decadent, deciduous, occasion, occident（「日が落ちる方」＝西洋）, recidivist, chance, cascade, chute, escheat
+note: <i>occident</i>「西洋」＝日の落ちる地、<i>orient</i>「東洋」＝日の昇る地（<i>orīrī</i>）。

@ caed- / cid- / cis- ; L <i>caedere, caesum</i>「切る、殺す」
+root: *kh₂eyd-
+der: -cide（homicide, suicide, genocide, insecticide, pesticide, patricide, regicide, fratricide, infanticide）, incise, incision, decide（「切り離す」＝決定）, decision, concise（「切り詰めた」）, precise, excise, circumcise, scissors（綴りは <i>scindere</i> の誤影響）, chisel, caesura, Caesarean(?)
+note: <i>decide</i>「決める」の原義は「切り離す」。迷いを断つイメージ。<i>scissors</i> の sc- は語源的に誤った綴り直し（第4章）。

@ cand- ; L <i>candēre</i>「白く輝く」
+root: *(s)kend-「輝く」
+der: candle, candid（「白い」＝率直な）, candidate（白いトガを着た者）, candor, incandescent, chandelier, chandler, incense は別
+note: ローマの公職志願者は清廉を示すため白墨で白く輝かせたトガ（<i>toga candida</i>）を着た。ここから <i>candidate</i>「候補者」。

@ cap- / cip- / cept- / ceive ; L <i>capere, captum</i>「取る、つかむ」
+root: *kap-
+der: capture, captive, captor, caption, capable, capacity, capacious, accept, acceptance, except, exception, intercept, precept, susceptible, concept, conception, deception, reception, receipt, perception, anticipate, participate, emancipate（「手から放す」）, municipal（「義務を引き受ける」）, occupy, occupation, principal, principle, prince, recuperate, recover, cater(?), catch, chase, purchase（「追い求める」）／<b>仏語経由の摩耗形</b> receive, deceive, conceive, perceive, escape（「マントを脱ぐ」）
+note: 母音弱化の代表例（cap → cip → cept）。本来語 <i>have</i>, <i>heave</i>, <i>heavy</i> と同根（グリムの法則 *k → h）。

@ capit- / cipit- ; L <i>caput, capitis</i>「頭」
+root: *kaput-
+der: capital, capitol, capitulate（「条項に分ける」＝降伏する）, recapitulate, decapitate, precipitate（「頭から落とす」）, precipice, captain, chief, chef, chieftain, cape（岬）, cap, cattle, chattel, chapter, cadet, cadre, achieve, mischief, kerchief, biceps, triceps, occiput
+note: 一語根から10以上の英語が出る。<i>achieve</i> は仏 <i>à chief venir</i>「頭（＝終わり）に至る」。

@ carn- ; L <i>carō, carnis</i>「肉」
+root: *sker-「切る」
+der: carnal, carnage, carnival, carnation, carnivore, incarnation, reincarnation, carrion, charnel, carnelian
+note: <i>carnival</i> は「肉を取り去る（四旬節前の祭）」。「肉よさらば（<i>carne vale</i>）」説は民間語源。

@ ced- / cess- ; L <i>cēdere, cessum</i>「行く、退く、譲る」
+root: *ked-「行く」
+der: cede, cession, accede, access, accessory, antecedent, concede, concession, precede, precedent, procedure, proceed, process, procession, recede, recession, secede, secession, succeed, success, succession, intercede, exceed, excess, ancestor（<i>ante-cessor</i>「先に行く者」）, cease（<i>cessāre</i>）, decease, necessary（「退くことのできない」）
+note: <i>necessary</i>「必要な」は <i>ne-cess-</i>「退けない」。綴りの c と s の数はここから覚えられる。

@ celer- ; L <i>celer</i>「速い」
+root: *kel-「駆る」
+der: accelerate, acceleration, celerity, decelerate
+note: <i>celerity</i>「敏速」は文語。<i>celery</i>（セロリ）は別語源（Gk <i>sélinon</i>）。

@ cent- ; L <i>centum</i>「百」
+root: *ḱm̥tóm
+der: cent, century, centennial, centurion, centipede, percent, centigrade, centimeter, centennial
+note: 本来語 <i>hundred</i> と同根（グリムの法則 *ḱ → h）。

@ cern- / cret- / cri- ; L <i>cernere, crētum</i>「ふるい分ける、識別する」
+root: *krei-「ふるう」
+der: discern, discrete, discreet（同語源の二重語）, discriminate, secret（「分け隔てたもの」）, secretary（「秘密を託された者」）, secrete, excrete, concern, certain（<i>certus</i>「定まった」）, certify, decree, crime（「判決、告発」）, criminal, critic は ギ
+note: <i>discrete</i>「離散的な」と <i>discreet</i>「思慮深い」は綴り違いの二重語。数学の「離散」は前者。

@ cid- / cis- ; → caed- / cid- / cis- を見よ
+cf: → <b>caed-</b>（切る）。<i>homicide</i>, <i>decide</i>, <i>concise</i> など。

@ circ- ; L <i>circus</i>「輪」, <i>circum</i>「周りに」
+root: *(s)ker-「曲がる」
+der: circle, circus, circuit, circulate, circumference, circumstance, circumvent, circumspect, circumcise, search（<i>circāre</i>「巡る」）, research, encircle
+note: <i>search</i>「探す」は「（周囲を）巡る」から。

@ claim- / clam- ; L <i>clāmāre</i>「叫ぶ」
+root: *kelh₁-「呼ぶ」
+der: claim, clamor, acclaim, acclamation, exclaim, exclamation, proclaim, proclamation, reclaim, declaim, disclaim, council は別
+note: 同根に <i>calendar</i>（<i>calendae</i>「（新月を）呼ばわる日」）, <i>class</i>（<i>classis</i>「召集された市民の等級」）, <i>nomenclature</i>, <i>ecclesiastic</i>（「呼び出された者の集まり」＝教会）。

@ clar- ; L <i>clārus</i>「明るい、明晰な」
+root: *kelh₁-「呼ぶ」（「よく聞こえる」→「明瞭な」）
+der: clear, clarity, clarify, declare, clarion, clairvoyant（「はっきり見える」）, Clara/Claire
+note: 原義は「（声が）よく通る」で、視覚の語ではなかった。

@ claud- / clud- / clus- ; L <i>claudere, clausum</i>「閉じる」
+root: *kleh₂w-「鍵」
+der: close, closet, clause, cloister, exclude, exclusive, include, inclusive, conclude, conclusion, preclude, seclude, recluse, occlude, disclose, enclose, claustrophobia, sluice, clavicle（「小さな鍵」＝鎖骨）, clef, clavier
+note: <i>clavicle</i>「鎖骨」は形が鍵（<i>clāvis</i>）に似ているため。

@ cor- / cord- ; L <i>cor, cordis</i>「心臓」
+root: *ḱerd-
+der: cordial, accord, concord, discord, record, courage, encourage, discourage, core(?), misericord
+note: <i>record</i>「記録する」＝「心に呼び戻す」。

@ corp- ; L <i>corpus, corporis</i>「体」
+root: *krep-「体、姿」
+der: corpse, corps, corpus, corporal, corporate, corporation, corpulent, corpuscle, incorporate, corset（「小さな体」）, corsage, leprechaun は別
+note: <i>corps</i>（軍団、発音 /kɔː/）と <i>corpse</i>（死体）は同一語の綴り分化。

@ cred- ; L <i>crēdere</i>「信じる、託す」
+root: *ḱred-dʰeh₁-「心を置く」
+der: credit, credible, credential, creed, credo, credulous, incredible, incredulous, discredit, accredit, miscreant（「誤信者」→ 悪党）, grant（仏語経由）
+note: 第一要素 <i>ḱred-</i> は <i>cor</i>「心」と、第二要素は <i>-dʰeh₁-</i>（＝ <i>do</i>）と同根。

@ cresc- / cret- ; L <i>crēscere, crētum</i>「成長する」
+root: *ḱerh₃-「養う」
+der: crescent（「増えつつある（月）」）, crescendo, increase, decrease, accrue, accretion, concrete（「共に成長した」＝凝固した）, recruit（「新しく育ったもの」）, croissant（仏「三日月」）, Ceres/cereal
+note: <i>concrete</i>「具体的な、コンクリート」は「一緒に固まった」が原義。抽象（abstract＝引き離された）の対義。

@ cur- / curs- ; L <i>currere, cursum</i>「走る」
+root: *ḱers-
+der: current, currency, cursor, cursory, course, courier, corridor, concur, concurrent, occur, occurrence, recur, incur, excursion, discourse, intercourse, precursor, succor（「下から走り寄る」＝救援）, curriculum（「走路」）, corsair, car, career, cargo, charge, discharge
+note: <i>car</i>, <i>career</i>, <i>cargo</i>, <i>charge</i> はケルト語起源の <i>carrus</i>「荷車」経由で、同じ語根に遡る。

@ cur- / curat- ; L <i>cūra</i>「配慮、世話」
+root: 語源不確実
+der: cure, curator, curious（「気にかける」→ 詮索好き→ 好奇心のある）, curiosity, accurate（「注意して作られた」）, secure（「心配なしに」）, sure, sinecure（「世話のない（聖職禄）」）, procure, proctor, scour(?), manicure, pedicure
+note: <i>secure</i>（<i>sē-</i> 離れて + <i>cūra</i> 心配）と <i>sure</i> は二重語。


== D – F

@ dic- / dict- ; L <i>dīcere, dictum</i>「言う」

@ don- / dat- ; L <i>dōnum</i>「贈り物」, <i>dare, datum</i>「与える」

@ duc- / duct- ; L <i>dūcere, ductum</i>「導く」

@ dur- ; L <i>dūrus</i>「硬い」, <i>dūrāre</i>「続く」

@ fac- / fic- / fect- / fy ; L <i>facere, factum</i>「作る、する」

@ fer- / lat- ; L <i>ferre, lātum</i>「運ぶ」
