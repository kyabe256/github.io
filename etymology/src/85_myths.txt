# 第VIII部　語源の俗説と真説

語源ほど作り話の生まれやすい分野はない。「もっともらしい物語」は記憶に残りやすく、繰り返されるうちに事実として流通する。ここでは、広く流布している語源説を「誤り」「裏づけなし」「一部正しい」に分類して整理する。

## 1　頭字語による偽の語源（backronym）

語を単語の頭文字の並びとして説明する説は、ほぼすべて誤りである。頭字語による語形成は20世紀の現象であり、それ以前の語には適用できない。

| 語 | 俗説 | 真相 |
|---|---|---|
| posh | Port Out, Starboard Home（英印航路の高級船室） | <b>誤り</b>。船会社の記録に該当する表記はない。俗語 <i>posh</i>「金、洒落者」（19世紀）から |
| golf | Gentlemen Only, Ladies Forbidden | <b>誤り</b>。中世オランダ語 <i>colf</i>「棍棒」から |
| news | North East West South | <b>誤り</b>。<i>new</i> の複数形（仏 <i>nouvelles</i> の写し） |
| fuck | Fornication Under Consent of the King | <b>誤り</b>。ゲルマン系の古い語で16世紀以前から記録がある |
| cop | Constable On Patrol | <b>誤り</b>。<i>cop</i>「捕まえる」（＜ L <i>capere</i>）から |
| tip | To Insure Promptness | <b>誤り</b>。<i>tip</i>「軽く触れる、渡す」から |
| wog / pom | 各種の頭字語説 | <b>誤り</b>。いずれも別の由来 |
| SOS | Save Our Souls / Ship | <b>誤り</b>。モールス信号で打ちやすい符号（・・・－－－・・・）として選ばれたもので、意味はない |

例外的に頭字語が本当の語源である語もある。<i>radar</i>, <i>laser</i>, <i>scuba</i>, <i>NATO</i>, <i>zip code</i>, <i>AIDS</i>, <i>snafu</i>, <i>jeep</i>（諸説あるが GP＝General Purpose 説が有力）。いずれも20世紀の語である。

## 2　もっともらしい物語型の俗説

| 語 | 俗説 | 真相 |
|---|---|---|
| sincere | <i>sine cērā</i>「蝋なしで」（像のひびを蝋で埋めない誠実な彫刻家） | <b>誤り</b>。<i>sincērus</i> は「純粋な」で、語形成が説明と合わない。第二要素は不確実 |
| genuine | 父が新生児を膝（<i>genū</i>）に載せて認知した習慣から | <b>裏づけなし</b>。主説は「生まれつきの」（*ǵenh₁-）。<i>genū</i>「膝」とは別語根 |
| salary | ローマ兵が塩そのものを給与として受け取った | <b>一部正しいが誇張</b>。<i>salārium</i> は「塩を買うための手当」とされるが、塩の現物支給を示す一次史料はない |
| testify | ローマ人は睾丸に手を置いて誓った | <b>裏づけなし</b>。<i>testis</i>「証人」＜「第三者として立つ者」。解剖学用語のほうが比喩的転用 |
| rule of thumb | 妻を打ってよい棒の太さの上限を定めた法 | <b>誤り</b>。そのような法は存在しない。親指を用いた大まかな測定から |
| the whole nine yards | 機銃弾帯の長さ／布地の長さ／コンクリートミキサーの容量 | <b>不明</b>。1960年代の初出で、諸説すべて後付け |
| carnival | <i>carne vale</i>「肉よ、さらば」 | <b>誤り</b>。<i>carnem levāre</i>「肉を取り除く」 |
| marmalade | メアリー女王が病のとき（<i>Marie est malade</i>） | <b>誤り</b>。Gk <i>melímēlon</i>「蜜のリンゴ」＜ マルメロ |
| sirloin | 英国王が肉に「サー」の称号を与えた | <b>誤り</b>。仏 <i>surlonge</i>「腰の上（の肉）」 |
| honeymoon | 北欧で新婚一か月間、蜂蜜酒を飲む風習 | <b>裏づけなし</b>。16世紀英語の警句的表現（甘さが月のように欠ける） |
| quiz | ダブリンの劇場支配人が賭けで無意味な語を流行らせた | <b>誤り</b>。初出年代が合わない |
| sabotage | 労働者が機械に木靴を投げ込んだ | <b>誤り</b>。仏 <i>saboter</i>「乱雑に仕事をする」から |
| picnic | 「ピック・ア・ニガー」（リンチの隠語） | <b>完全な誤り</b>。仏 <i>pique-nique</i>（17世紀）。悪質なデマとして流布した例 |
| crap | 便器発明者トマス・クラッパーの名 | <b>誤り</b>。<i>crap</i> は中英語からある語。クラッパーは実在するが語源ではない（偶然の一致） |
| shit | Ship High In Transit（船倉の肥料） | <b>誤り</b>。古英語 <i>scitan</i> |
| bug（不具合） | ハーヴァード Mark II に挟まった蛾 | <b>一部正しいが逆</b>。1947年の蛾は実話だが、<i>bug</i>「不具合」の用法は1870年代のエジソンにすでにある |
| OK | オック語／チョクトー語 <i>okeh</i>／ドイツ語 <i>alles korrekt</i>／ハイチの港 Aux Cayes | <b>いずれも裏づけ弱い</b>。<i>oll korrect</i>（1839、ボストンの略語遊び）説が定説 |
| 420（大麻の隠語） | カリフォルニア州法の条文番号／警察無線コード | <b>誤り</b>。1971年カリフォルニアの高校生グループの午後4時20分の待ち合わせ時刻 |

## 3　名前が語源だと誤解される語

実在の人名が由来である語（eponym）と、偶然名前と一致するだけの語を区別する必要がある。

<b>本当に人名由来</b>：sandwich, boycott, lynch, guillotine, silhouette, nicotine, saxophone, diesel, pasteurize, volt, watt, ampere, ohm, hertz, newton, kelvin, curie, cardigan, mackintosh, wellington, leotard, mesmerize, chauvinism, sadism, masochism, maverick, bowdlerize, quisling, shrapnel, dunce, gerrymander, tantalize, jumbo, guy, tuxedo（地名）, jeans（地名）, denim（地名）, mausoleum。

<b>人名由来ではない</b>：crap（クラッパー）, hooker（フッカー将軍。この語は将軍より前から使われている）, John Doe（架空名）, jack（<i>Jacques</i> から一般化したが特定の人物ではない）, teddy bear（セオドア・ローズヴェルトは実在するが、命名の逸話には脚色がある）, silhouette は実在の人物由来で正しい。

## 4　「英語には〜という語がない」という俗説

- 「エスキモーには雪を表す語が数十ある」——ボアズの記述が伝言のうちに誇張された「大雪語彙デマ」。イヌイット諸語は膠着的で複合語を無限に作れるため、語数の比較自体が意味をなさない。
- 「日本語の『木漏れ日』に相当する英語はない」——単語としてはないが、これはどの言語間でも普通に起こることで、語彙の「豊かさ」の指標にはならない。逆に <i>serendipity</i>（ホレス・ウォルポールが1754年、ペルシアの童話『セレンディップの三王子』から造語）や <i>petrichor</i>（1964年の造語、「石のイコル（神の血）」＝雨後の土の匂い）のような英語独自の語もある。

## 5　語源をめぐる誤りの類型

なぜ語源の俗説はこれほど生まれやすいのか。整理すると次の五つに分類できる。

1. <b>頭字語化</b>：現代人にとって最も馴染みのある語形成を過去に投影する。
2. <b>物語の魅力</b>：具体的な逸話は抽象的な音法則より記憶に残る。
3. <b>民間語源による形の変化</b>：<i>crayfish</i>, <i>penthouse</i>, <i>sparrowgrass</i> のように、実際に語形が変わってしまう場合がある。この場合、俗説が言語事実の一部になっている。
4. <b>偶然の一致</b>：<i>crap</i> と Crapper、<i>have</i> と <i>habēre</i>、英語 <i>day</i> とラテン語 <i>diēs</i>。音と意味が似ていても同源とは限らない。
5. <b>留保の消失</b>：辞書が「said to be」「perhaps」と書いた説が、引用の連鎖のなかで断定に変わる。

真偽を確かめる原則は単純である。<b>（1）初出年代は説と整合するか。（2）音の変化は規則に合うか。（3）意味の橋は他言語の並行例で支えられるか。（4）一次史料はあるか。</b>　この四つを問えば、俗説のほとんどはふるい落とせる。
