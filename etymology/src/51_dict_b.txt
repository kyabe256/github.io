== B

@ bank ; /bæŋk/ ; 名 ; 銀行、土手
+lit: 「（両替商の）台」
+chain: ゲルマン語 *bankiz「台、ベンチ」→ 伊 <i>banca</i>「両替台」→ 仏 <i>banque</i> → 英語
+der: bench, bank（土手）, embankment, bankrupt（伊 <i>banca rotta</i>「壊された台」）
+note: 中世イタリアの両替商は市場に台を出して業務を行った。破産すると、その台が壊されたことから <i>bankrupt</i>。<i>bank</i>「土手」も同じゲルマン語（「盛り上がったもの」）に遡る。

@ barbarian ; /bɑːˈbeəriən/ ; 名 ; 野蛮人
+lit: 「バルバルと訳の分からぬことを言う者」
+chain: Gk <i>bárbaros</i>「異国語を話す者」→ L <i>barbarus</i>
+desc: ギリシア人には外国語が「バルバル」という無意味な音に聞こえた、という擬音起源。サンスクリット語 <i>barbara-</i>「どもる」にも並行形がある。
+der: Barbary, Berber, rhubarb（「野蛮な（地の）根」）, Barbara
+note: <i>rhubarb</i>「ルバーブ」は「ロー川（ヴォルガ）の蛮地の根」。

@ bead ; /biːd/ ; 名 ; ビーズ
+lit: 「祈り」
+chain: OE <i>gebed</i>「祈り」（＜ <i>biddan</i>「請う」）→ ME <i>bede</i>
+desc: ロザリオの珠を繰りながら祈りを数えたため、「祈り」を表す語が「珠」の意味に転じた（換喩、第7章）。<i>to count one's beads</i>「数珠を繰る＝祈る」に古義が残る。
+der: bid（請う）, bidding

@ berserk ; /bəˈzɜːk/ ; 形 ; 狂乱した
+lit: 「熊の（毛皮の）上着（を着た者）」
+chain: ON <i>berserkr</i>（<i>ber-</i>「熊」+ <i>serkr</i>「上着」）→ 英語（1822、スコットによる紹介）
+desc: 古ノルドの伝承で、熊の毛皮をまとい、鎧をつけずに狂乱状態で戦った戦士。「上着なし（bare-sark）」とする別説もある。
+der: bear（動物）, sark（方言「シャツ」）

@ bishop ; /ˈbɪʃəp/ ; 名 ; 司教
+lit: 「上から見る者、監督者」
+chain: Gk <i>epískopos</i>（<i>epi-</i>「上」+ <i>skopós</i>「見る者」）→ 俗ラテン語 <i>ebiscopus</i> → OE <i>biscop</i>
+dbl: <i>episcopal</i>（後代の学術借用形）
+der: scope, telescope, skeptic, spectacle（ラテン系）, spy
+note: 語頭の e- が脱落し、p → b と変化した、徹底的に英語化された借用語。

@ bless ; /bles/ ; 動 ; 祝福する
+lit: 「血で聖別する」
+chain: OE <i>blētsian</i>（＜ *blōdisōjan「血を注ぐ」＜ <i>blōd</i>「血」）
+desc: ゲルマン異教の犠牲儀礼で、祭壇に血を振りかけて聖別した。キリスト教化の際、ラテン語 <i>benedīcere</i>「よく言う」の訳語に転用され、意味が上書きされた。さらに <i>bliss</i>「至福」との連想も加わった。
+der: blood, bliss（別語源だが影響）

@ blockbuster ; /ˈblɒkbʌstə/ ; 名 ; 大ヒット作

+note: もとは一街区を破壊できる大型爆弾。比喩が定着して原義が忘れられた例。

@ bonfire ; /ˈbɒnfaɪə/ ; 名 ; たき火
+lit: 「骨の火」
+chain: ME <i>bonefire</i>（<i>bone</i> + <i>fire</i>）
+desc: 中世に聖ヨハネ祭などで獣骨を焼いた慣習に由来する。後に <i>bon</i>「良い」（仏語）と誤解されたが、初期の綴りは <i>banefyre</i> であり骨で確定している。

@ book ; /bʊk/ ; 名 ; 本
+chain: OE <i>bōc</i> ← PGmc *bōks
+desc: ゲルマン語の <i>bōk</i>「ブナ」との関連が古くから説かれる。ブナ材の板にルーン文字を刻んだためとされるが、異論もある。
+cog: 独 <i>Buch</i>, ゴート語 <i>bōka</i>「文字」
+der: beech(?), bookkeeper（英語で唯一、三組の連続同字（oo-kk-ee）を持つ語として知られる）

@ boycott ; /ˈbɔɪkɒt/ ; 動・名 ; ボイコット（する）
+chain: 人名 Charles C. Boycott（1832–97）
+desc: アイルランド、メイヨー州の土地差配人。1880年、小作料引き下げを拒んだため土地連盟に絶交・排斥され、その名が「集団的排斥」の代名詞になった。同年のうちに新聞で普通名詞化し、フランス語・ドイツ語・日本語にも広まった。
+cf: → 固有名詞由来語（第6章）

@ brand ; /brænd/ ; 名 ; 銘柄、焼き印

+chain: OE <i>brand</i>「炎、燃え木」→「焼き印」→「商標」
+der: burn, brandy（オランダ語 <i>brandewijn</i>「焼いた（蒸留した）ワイン」）, brindled, brandish（「（剣を）ひらめかす」）
+note: 家畜への焼き印から、19世紀に商品の「銘柄」へ。マーケティング用語の <i>brand</i> はここから。

@ bribe ; /braɪb/ ; 名・動 ; 賄賂（を贈る）

@ budget ; /ˈbʌdʒɪt/ ; 名 ; 予算
+lit: 「小さな革袋」
+chain: L <i>bulga</i>「革袋」（ケルト語起源）→ OF <i>bougette</i>（縮小形）→ 英語
+desc: 英国の大蔵大臣が議会に財政案を持参する革鞄を <i>budget</i> と呼び、「鞄を開ける」（to open the budget）が財政演説を意味した。ここから「予算」へ。
+der: bulge, bilge, budge は別

@ bureau ; /ˈbjʊərəʊ/ ; 名 ; 事務局、机
+lit: 「（机を覆う）粗い毛織物」
+chain: 後期ラテン語 <i>burra</i>「粗毛」→ OF <i>burel</i>「粗布」→ 仏 <i>bureau</i>「机」→「執務室」→「官庁」
+der: bureaucracy（仏＋ギの混成語, 1818）, burlesque(?)
+note: 布 → 布を掛けた机 → 机のある部屋 → 役所、と換喩が四段重なった語。

@ butterfly ; /ˈbʌtəflaɪ/ ; 名 ; 蝶
+chain: OE <i>butorflēoge</i>（<i>butere</i>「バター」+ <i>flēoge</i>「蠅」）
+desc: 語源の理由は不明。（1）黄色い種（モンキチョウ）の色から、（2）ミルクやバターを盗むという民間信仰から、（3）オランダ語 <i>boterschijte</i>「糞の色」からの婉曲、などの説がある。
+note: 各言語で蝶の名は一致せず、独 <i>Schmetterling</i>（＜「クリーム」）, 仏 <i>papillon</i>（＜ L <i>pāpiliō</i>）, 露 <i>бабочка</i>（＜「おばあさん」＝死者の霊）と、それぞれ独自である。

@ bug ; /bʌɡ/ ; 名 ; 虫、不具合
+chain: 語源不確実。ME <i>bugge</i>「幽霊、お化け」（ウェールズ語 <i>bwg</i> と関係か）
+desc: 機械の不具合を <i>bug</i> と呼ぶ用法は、1870年代のエジソンの書簡にすでに見られる。1947年にハーヴァード Mark II のリレーに挟まった蛾が「実際の bug」として日誌に貼られた逸話は有名だが、これは既存の語法を踏まえた洒落であり、語源ではない。
+der: bugbear, bogey, bogeyman, humbug(?)

@ bulletin ; /ˈbʊlətɪn/ ; 名 ; 公報

+chain: L <i>bulla</i>「泡、金属の印章」→ 伊 <i>bullettino</i> → 仏 → 英語

+note: 教皇勅書 <i>papal bull</i> の <i>bull</i> は雄牛ではなく、文書に付けられた鉛の印章のこと。

@ bureaucracy ; /bjʊəˈrɒkrəsi/ ; 名 ; 官僚制

+desc: 1745年ごろフランスの経済学者ヴァンサン・ド・グルネーが皮肉として造った語 <i>bureaucratie</i>。当初から批判的な含みを持つ。

@ blackmail ; /ˈblækmeɪl/ ; 名 ; 恐喝
