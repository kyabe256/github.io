== O

@ ostracize ; /ˈɒstrəsaɪz/ ; 動 ; 追放する
+lit: 「陶片（で投票する）」
+chain: Gk <i>óstrakon</i>「陶片、貝殻」→ <i>ostrakízein</i>
+desc: 古代アテナイの陶片追放（オストラキスモス）。市民が僭主になりそうな人物の名を陶片に刻んで投票し、規定数に達すると10年間の国外追放とした。
+der: oyster（<i>óstreon</i>「牡蠣」）, osteo-（骨）は関連語根
+note: 実際に出土した陶片には、テミストクレスやアリステイデスの名が刻まれている。

@ orchestra ; /ˈɔːkɪstrə/ ; 名 ; 管弦楽団
+lit: 「踊る場所」
+chain: Gk <i>orkheîsthai</i>「踊る」→ <i>orkhḗstrā</i>
+desc: ギリシア劇場で、舞台と客席のあいだにある合唱隊の踊り場。ローマでは元老院席、近代では楽団席となり、やがて楽団そのものを指すようになった（換喩、第7章）。

@ ordeal ; /ɔːˈdiːl/ ; 名 ; 厳しい試練
+lit: 「（神の）裁き」
+chain: OE <i>ordāl</i>「神判」（*uz-「外へ」+ <i>dāl</i>「分配、判決」）
+desc: 中世の神明裁判——熱した鉄を握らせる、水に沈める——を指した語。1215年の第四ラテラノ公会議で聖職者の関与が禁じられ、制度は衰退したが語は残った。
+cog: 独 <i>Urteil</i>「判決」
+der: deal, dole（本来語の同根語）

@ ostrich ; /ˈɒstrɪtʃ/ ; 名 ; ダチョウ
+lit: 「鳥のスズメ」
+chain: L <i>avis</i>「鳥」+ Gk <i>strouthíōn</i>「（大きな）スズメ、ダチョウ」→ 俗ラテン語 <i>avis struthio</i> → OF <i>ostrusce</i>
+note: ギリシア語で <i>strouthós</i> は「スズメ」で、ダチョウは <i>megálē strouthós</i>「大きなスズメ」と呼ばれた。<i>ostrich</i> は「鳥・スズメ」という同義反復の複合。

@ outrage ; /ˈaʊtreɪdʒ/ ; 名 ; 憤慨、暴虐
+lit: 「度を越すこと」
+chain: L <i>ultrā</i>「越えて」+ <i>-āticum</i> → OF <i>outrage</i>
+note: <i>out</i> + <i>rage</i> と分析するのは民間語源。語源的には <i>ultra</i> の派生語で、<i>rage</i>（＜ L <i>rabiēs</i>）とは無関係。ただしこの誤分析が現代の語感を強く規定している。

@ ovation ; /əʊˈveɪʃn/ ; 名 ; 大喝采
+lit: 「小凱旋式」
+chain: L <i>ovāre</i>「歓呼する」→ <i>ovātiō</i>
+desc: ローマで、正式の凱旋式（<i>triumphus</i>）に値しない小さな勝利に与えられた略式の祝典。将軍は馬でなく徒歩で入城し、羊（<i>ovis</i>）を犠牲に捧げた——この語源説は民間語源とされるが、古代から言われていた。
+note: <i>standing ovation</i> の用法は20世紀。

@ ozone ; /ˈəʊzəʊn/ ; 名 ; オゾン
+lit: 「におうもの」
+chain: Gk <i>ózein</i>「におう」→ 独 <i>Ozon</i>（シェーンバイン, 1840）
+desc: 放電時の特有の刺激臭から命名された。
+der: osmium（「におう」金属）, odor（ラテン系の同根語）, olfactory

@ opportunity ; /ɒpəˈtjuːnəti/ ; 名 ; 好機
+lit: 「港に向かって（吹く風）」
+chain: L <i>ob portum (veniens)</i>「港に向かう」→ <i>opportūnus</i>「都合のよい」
+desc: 帆船時代、港へ吹き入れる順風こそが好機だった。対語の <i>importune</i>「しつこくせがむ」は「港に入れない（＝不都合な）」から。
+der: port, portal, import, export, transport, opportune, importunate

@ orgy ; /ˈɔːdʒi/ ; 名 ; 乱痴気騒ぎ
+lit: 「（秘儀の）祭儀」
+chain: Gk <i>órgia</i>「秘儀、祭礼」→ L <i>orgia</i> → 仏 <i>orgie</i>
+desc: ディオニュソス（バッコス）の密儀を指した語。儀式の熱狂的性格から意味が悪化した。
+der: work, energy, organ, surgery（同根語）
+note: <i>érgon</i>「仕事」と同根で、原義は「（神への）働きかけ・儀式」。

@ obese ; /əʊˈbiːs/ ; 形 ; 肥満の
+lit: 「食べ尽くした」
+chain: L <i>ob-</i>「すっかり」＋ <i>edere</i>「食べる」→ <i>obēsus</i>
+root: *h₁ed-「食べる」
+cog: OE <i>etan</i> → eat, Gk <i>édein</i>, Skt <i>ad-</i>
+der: eat, edible, comestible, etch は別
+note: ラテン語では「痩せた」の意でも使われた（<i>ob-</i> を「食べ尽くされた」と取るか「食べ込んだ」と取るかで正反対）。

@ obituary ; /əˈbɪtʃuəri/ ; 名 ; 死亡記事
+lit: 「（現世から）去ること」
+chain: L <i>obīre</i>「（死に）赴く」（<i>ob-</i>＋<i>īre</i>「行く」）→ <i>obitus</i>
+root: *h₁ey-「行く」
+der: exit, transit, initial, ambition, circuit, itinerary, perish, issue, sudden, county は別
+note: <i>ambition</i> は「（票を求めて）まわり歩くこと」。政治家の行動が抽象名詞になった。
+see: *h₁ey-

@ obvious ; /ˈɒbviəs/ ; 形 ; 明らかな
+lit: 「道の前に立ちはだかる」
+chain: L <i>ob viam</i>「道の前に」→ <i>obvius</i>
+root: *weǵʰ-「運ぶ」
+der: via, voyage, convey, convoy, deviate, obviate, previous, trivial（「三叉路の＝どこにでもある」）, vehicle, wagon, way, weigh
+note: 「つまずくほど目の前にある」が原義。<i>trivial</i>「些細な」は「三叉路で誰もが話す程度のこと」。
+lvl: ★★★

@ ocean ; /ˈəʊʃn/ ; 名 ; 大洋
+chain: Gk <i>Ōkeanós</i>「世界を取り巻く大河（の神）」→ L <i>ōceanus</i>
+desc: 古代の世界観では大地を環流する川。地中海（<i>mare</i>）と区別される「外の水」。<i>Oceania</i>（1831、仏の造語）。

@ odd ; /ɒd/ ; 形 ; 奇妙な、奇数の
+lit: 「（三角形の）先端」
+chain: 古ノルド語 <i>oddi</i>「先端、三角形、奇数」
+desc: 三角形の頂点＝対にならないもの→「奇数」→「余りの」→「変な」。北欧語からの借用で、古英語 <i>unefen</i> を駆逐した。
+note: <i>odds</i>「見込み」は「不均衡」から。

@ offend ; /əˈfend/ ; 動 ; 怒らせる
+chain: L <i>ob-</i>「〜に向かって」＋ <i>fendere</i>「打つ」
+der: defend, fence, offense, defense, infest は別
+note: <i>fendere</i> は単独では現れず、接頭辞付きでのみ残る。<i>fence</i> は <i>defence</i> の頭音消失形。
+lvl: ★★

@ office ; /ˈɒfɪs/ ; 名 ; 職務、事務所
+chain: L <i>opus</i>「仕事」＋ <i>facere</i>「なす」→ <i>officium</i>
+root: *h₃ep-「働く」／*dʰeh₁-「置く」
+der: opera, operate, opus, copious, opulent, maneuver／officer, official, officious
+note: <i>officious</i>「おせっかいな」は「職務熱心な」から下降した。
+lvl: ★★★

@ ointment ; /ˈɔɪntmənt/ ; 名 ; 軟膏
+chain: L <i>unguere</i>「塗る」→ OF <i>oignement</i>
+der: unguent, unction, anoint
+note: <i>Christ</i>（Gk <i>khristós</i>「油を塗られた者」）、<i>Messiah</i>（ヘブライ語 <i>māshīaḥ</i> 同義）と発想が一致する。塗油は王と祭司の即位儀礼。

@ omen ; /ˈəʊmən/ ; 名 ; 前兆
+chain: L <i>ōmen</i>（語源不確実）
+der: ominous, abominable（「凶兆として忌む」）
+note: <i>abominable</i> の綴りは中世に <i>ab homine</i>「人間離れした」と誤解され <i>abhominable</i> と書かれた時期がある。語源俗説が綴りを変えた例。
+see: 第X部

@ omnibus ; /ˈɒmnɪbəs/ ; 名 ; 乗合馬車、総集編
+lit: 「すべての人のために」
+chain: L <i>omnis</i>「すべて」の複数与格 <i>omnibus</i>
+desc: 1820年代パリの乗合馬車。ナントの業者 Omnès の店の看板 <i>Omnes omnibus</i> の洒落が語源という説がある。短縮されて <i>bus</i>（1832）。
+note: 語尾の屈折語尾だけが残って独立語になった、きわめて珍しい例。
+see: bus
+lvl: ★★

@ orient ; /ˈɔːriənt/ ; 動名 ; 方向づける、東洋
+lit: 「（太陽が）昇る（方）」
+chain: L <i>orīrī</i>「昇る」→ <i>oriēns</i>「昇る（太陽）＝東」
+der: origin, original, aborigine, abort（「（発生から）離れる」）
+note: <i>orientate</i>「方向づける」は、教会堂を東（エルサレム）に向けて建てる慣習から。<i>Occident</i>「西洋」は <i>occidere</i>「（太陽が）沈む」で、<i>occasion</i>, <i>occident</i>, <i>decay</i> と同根。
+see: occident
+lvl: ★★

@ ounce ; /aʊns/ ; 名 ; オンス
+lit: 「十二分の一」
+chain: L <i>uncia</i>「十二分の一」（<i>ūnus</i>「一」）
+dbl: inch
+note: ローマの <i>lībra</i>（ポンド）と <i>pēs</i>（フィート）をそれぞれ12分した単位。同じ語が重さでは <i>ounce</i>、長さでは <i>inch</i> に分かれた。記号 oz は伊 <i>onza</i> の略。lb は <i>lībra</i>。
+see: inch, pound
+lvl: ★★

@ oxygen ; /ˈɒksɪdʒən/ ; 名 ; 酸素
+lit: 「酸を生むもの」
+chain: Gk <i>oxýs</i>「鋭い、酸っぱい」＋ <i>-genēs</i>「生む」（ラヴォアジエ、1777）
+note: すべての酸に酸素が含まれるという当時の誤った理論に基づく命名。塩酸に酸素がないことが後に判明したが、名は残った。<i>hydrogen</i>「水を生むもの」、<i>nitrogen</i>「硝石を生むもの」も同じ命名体系。
+der: oxymoron（「鋭くて鈍い」＝それ自体が撞着語法）, paroxysm, acid（L <i>acēre</i>、別根だが同義）
+see: 第9章 科学語彙の造語
+lvl: ★★

@ obscene ; /əbˈsiːn/ ; 形 ; わいせつな
+conf: 不確実　L <i>obscēnus</i>「不吉な、汚らわしい」。<i>ob-</i>＋<i>caenum</i>「汚物」説と、<i>scaena</i>「舞台」（＝舞台に出せない）説がある。後者は俗説とされる。

@ obsolete ; /ˈɒbsəliːt/ ; 形 ; 廃れた

+der: insolent（「習慣に反する＝不遜な」）
+note: <i>insolent</i> と同根。

@ omelette ; /ˈɒmlət/ ; 名 ; オムレツ
+chain: L <i>lāmina</i>「薄板」→ <i>lāmella</i> → 仏 <i>alemelle</i> →（異分析で）<i>alumelle</i> → <i>amelette</i> → <i>omelette</i>
+der: laminate, lamella, omelette
+note: 冠詞との境界の取り違えと音位転換が重なった、語形変化の見本のような語。薄く広げた形からの命名。

@ orange ; /ˈɒrɪndʒ/ ; 名 ; オレンジ
+chain: サンスクリット <i>nāraṅga</i> → ペルシア語 <i>nārang</i> → アラビア語 <i>nāranj</i> → 伊 <i>arancia</i> → 仏 <i>orange</i>
+desc: 語頭の n- が冠詞に取られて脱落した（伊 <i>una narancia</i> → <i>un'arancia</i>）。<i>or-</i> になったのは仏 <i>or</i>「金」の連想。
+note: 英語で色名として使われるのは1512年以降。それ以前この色は <i>ġeolurēad</i>「黄赤」と呼ばれた。色名が果物名より新しい珍しい例。
+see: 異分析, 第VIII部 インド諸語
+lvl: ★★

@ ordinary ; /ˈɔːdnri/ ; 形 ; 普通の
+chain: L <i>ōrdō</i>（属格 <i>ōrdinis</i>）「（織機の）縦糸の並び、順序」→ <i>ōrdinārius</i>
+der: order, ordain, ordinance, coordinate, subordinate, primordial, exordium
+note: 織機の縦糸の整列が「秩序」の原イメージ。<i>ordinary</i> は「規定どおりの」→「並の」。
+lvl: ★★★

@ organ ; /ˈɔːɡən/ ; 名 ; 器官、オルガン
+chain: Gk <i>órganon</i>「道具」← <i>érgon</i>「仕事」
+root: *werǵ-「働く」
+der: work, wright, energy, surgery（<i>kheirourgía</i>「手仕事」）, allergy, synergy, orgy, ergonomics
+note: 英語 <i>work</i> とギリシア語 <i>órganon</i> は同根。身体の「器官」は「魂の道具」というアリストテレスの比喩。<i>surgery</i> は「手の仕事」で、<i>chirurgeon</i>→<i>surgeon</i> と磨滅した。
+see: *werǵ-
+lvl: ★★★

@ orphan ; /ˈɔːfn/ ; 名 ; 孤児

@ overwhelm ; /ˌəʊvəˈwelm/ ; 動 ; 圧倒する

@ oyster ; /ˈɔɪstə/ ; 名 ; カキ
