@ decimate ; /ˈdesɪmeɪt/ ; 動 ; 大量に殺す

@ dinosaur ; /ˈdaɪnəsɔː/ ; 名 ; 恐竜

@ dunce ; /dʌns/ ; 名 ; 劣等生

+desc: ドゥンス・スコトゥスの学派（<i>Dunses</i>）は、16世紀の人文主義者から「屁理屈をこねる時代遅れの徒」として嘲笑された。ここから「愚か者」の普通名詞となった。中世随一の精緻な思索家（<i>doctor subtilis</i>）に対する、あまりに酷い後世の扱いである。
+note: 三角帽子の <i>dunce cap</i> は19世紀の創作。

@ dexterity ; /dekˈsterəti/ ; 名 ; 器用さ
