付録 A　依存の地図

2000 題は部ごとに並んでいるが、最適化の定理は互いに深く依存している。ここでは部をまたぐ主要な依存の筋を挙げる。番号は大問番号である。

幹：分離定理から双対へ

分離 → 選択肢定理{{R:proj}}（最近点射影）→ {{R:sep}}（真分離定理）→ {{R:farkas}}（Farkas）→ {{R:mw}}（Minkowski–Weyl）→ {{R:lpdual}}（LP 強双対）→ {{R:gt}}（Goldman–Tucker）。最適化のほぼすべての双対定理は分離定理の変奏である。
共役 → 双対{{R:conj}}（Fenchel 共役）→ {{R:fm-thm}}（Fenchel–Moreau）→ {{R:fenchel}}（Fenchel 双対）→ {{R:pert}}（Rockafellar の摂動双対）→ {{R:fr}}（Fenchel–Rockafellar）→ {{R:kdual}}（Kantorovich 双対）→ {{R:brenier}}（Brenier）。
分離 → KKT{{R:farkas}} → {{R:fj}}（Fritz John）→ {{R:kkt}}（KKT）← {{R:mfcq}}（MFCQ）, {{R:rcq}}（Robinson の制約想定）。凸では {{R:slater}}（Slater）と {{R:strongdual}}（強双対）が同じ定理の二つの顔。
minimax → ゲーム{{R:lpdual}} ⇔ {{R:vn}}（von Neumann）→ {{R:sion}}（Sion）→ {{R:nash}}（Nash）。一方、Brouwer を経由する {{R:nash}} は PPAD 完全、LP を経由する {{R:vn}} は多項式時間 ― 計算量の分水嶺である。

解析 → アルゴリズム

平滑性 → 収束率{{R:smooth}}（$L$-平滑の基本不等式）→ {{R:gd-c}}, {{R:gd-sc}}（勾配法）→ {{R:agd}}（Nesterov 加速）→ {{R:ogm}}（OGM）。下界は {{R:pep}}, {{R:pep2}}（性能推定問題）で厳密化される。
共役 → 平滑化{{R:dual-smooth}}（強凸 ⇔ 共役が平滑）→ {{R:menv}}（Moreau 包）→ {{R:nest-smooth}}（Nesterov の平滑化）→ {{R:cp}}（Chambolle–Pock）。
単調作用素 → 分割法{{R:minty}}（Minty）→ {{R:km}}（Krasnosel'skii–Mann）→ {{R:ppa}}（近接点法）→ {{R:fbs}}, {{R:dr}}, {{R:admm}}（前進後退・Douglas–Rachford・ADMM）→ {{R:auglag}}（拡張 Lagrangian は双対の近接点法）→ {{R:alm}}。
自己共役性 → 内点法{{R:newton}}, {{R:kantorovich}}（Newton 法）→ {{R:selfconc}}（自己共役関数）→ {{R:scb}}（自己共役障壁）→ {{R:ipm-complexity}}（$O(\sqrt\nu\log(1/\varepsilon))$）→ {{R:pd-short}}（LP の主双対法）。
体積 → 切除平面{{R:john}}（John の楕円体）, {{R:bm}}（Brunn–Minkowski）→ {{R:ellipsoid}}（楕円体法）→ {{R:gls}}（最適化と分離の等価性）, {{R:cog}}（重心法）。
誤差限界 → 線形収束{{R:hoffman}}（Hoffman）→ {{R:mreg}}（計量正則性）→ {{R:loj}}, {{R:kl}}（Łojasiewicz・KŁ）→ {{R:abs}}（Attouch–Bolte–Svaiter）。非凸一階法の収束理論はすべてここに帰着する。

緩和と確率

S-補題 → SDP 緩和{{R:slemma}}（S-補題）→ {{R:trs}}（信頼領域部分問題）→ {{R:sdpdual}}（SDP 双対）→ {{R:bp}}（Barvinok–Pataki）→ {{R:gw}}（Goemans–Williamson）, {{R:groth}}（Grothendieck）。
非負性 → SOS{{R:hilbert}}, {{R:motzkin}}（非負 ≠ SOS）→ {{R:sos-sdp}}（SOS は SDP）→ {{R:putinar}}（Putinar）→ {{R:lasserre}}（Lasserre 階層）。
凸幾何 → 確率{{R:pl}}（Prékopa–Leindler）→ 確率制約の凸性（第 IX 部）, 対数凹サンプリング（第 X 部 X-10）。{{R:sf}}（Shapley–Folkman）→ {{R:aubin}}（双対ギャップの消滅）。
確率近似 → SGD{{R:rm}}（Robbins–Monro）→ {{R:ode}}（ODE 法）→ {{R:pr}}（Polyak–Ruppert）→ {{R:sgd}}, {{R:svrg}}（SGD・分散削減）→ {{R:ogd}}, {{R:ftrl}}（オンライン学習）。
双対 → ロバスト{{R:lpdual}}, {{R:conedual}} → {{R:rlp}}（ロバスト LP）→ {{R:dro}}, {{R:wdro}}（分布ロバスト）。Wasserstein DRO の双対は {{R:kdual}} そのもの。

無限次元への合流

変分法 ↔ 凸解析{{R:wlsc}}（凸汎関数の弱下半連続性）→ {{R:tonelli}}（Tonelli）→ {{R:morrey}}（準凸性）→ {{R:polyconvex}}（多凸性と Ball の定理）。
制御 ↔ 双対{{R:lagrange}}（Lagrange 乗数）→ {{R:pmp}}（Pontryagin の最大原理）；{{R:bellman}}（Bellman）→ {{R:dp}}, {{R:visc}}（HJB と粘性解）→ {{R:are}}（Riccati）。
変分不等式{{R:minty}}, {{R:proj}} → {{R:ls}}（Lions–Stampacchia）→ {{R:obstacle}}（障害物問題）；{{R:eg}}（外挿勾配法）は Nash 均衡・交通均衡・鞍点問題に共通のアルゴリズム。
最終合流点大問 {{R:finale}}：Kantorovich 双対（{{R:kdual}}）＋ Brenier（{{R:brenier}}）＋ 変位凸性 ＋ JKO スキーム ＋ 関数不等式 ＋ Langevin 動力学。凸共役・双対・変分・勾配流・確率過程が一題で出会う。
