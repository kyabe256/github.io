付録 A　依存の地図

2000 題は部ごとに並んでいるが、関数解析の定理は部をまたいで深く依存している。ここでは主要な依存の筋を挙げる。番号は大問番号である。

幹：三大原理から双対へ

Hahn–Banach → 双対{{R:hb}}（Hahn–Banach）→ {{R:weak}}（弱位相）→ {{R:alaoglu}}（Banach–Alaoglu）→ {{R:km}}（Krein–Milman）→ {{R:choquet}}（Choquet）。凸集合・双対・端点の理論はすべてここから始まる。
Baire → 三大定理{{R:baire}}（Baire）→ {{R:ubp}}（一様有界性）, {{R:omt}}（開写像）→ {{R:cgt}}（閉グラフ）→ {{R:crt}}（閉値域）→ {{R:barrelled}}（樽型空間）。開写像定理は非線形版 {{R:ift}}（逆関数定理）・{{R:nash-moser}}（Nash–Moser）へ延びる。
反射性と弱コンパクト性{{R:reflexive}}（Kakutani）→ {{R:es}}（Eberlein–Šmulian）→ {{R:james}}（James）；{{R:milman-pettis}}（Milman–Pettis）→ {{R:uc}}（一様凸性）→ {{R:enflo-renorm}}（超反射性）→ {{R:ribe}}（Ribe）。
不動点{{R:banach-fp}}（縮小写像）→ {{R:ift}}；{{R:schauder}}（Schauder）→ {{R:ls-deg}}（Leray–Schauder 写像度）→ {{R:rabinowitz-global}}（大域分岐）；{{R:mk}}, {{R:rn}}（Markov–角谷・Ryll-Nardzewski）→ Haar 測度 {{R:haar}}。

Gelfand → スペクトル定理{{R:spec-nonempty}}, {{R:spec-rad}} → {{R:gelfand-mazur}} → {{R:gelfand}}（Gelfand 変換）→ {{R:cfc}}（連続関数計算）→ {{R:st-mult}}, {{R:pvm}}（スペクトル定理）→ {{R:st-unbdd}}（非有界版）→ {{R:stone}}（Stone）。
非有界作用素 → 量子力学{{R:closed}} → {{R:sa-crit}} → {{R:deficiency}}（不足指数）, {{R:friedrichs}}（Friedrichs 拡張）→ {{R:kato-rellich}}（Kato–Rellich）→ {{R:hvz}}（HVZ）→ {{R:cook}}, {{R:bkr}}, {{R:mourre}}（散乱理論）。
半群{{R:stone}} → {{R:c0}} → {{R:hy}}（Hille–Yosida）→ {{R:lp}}（Lumer–Phillips）→ {{R:analytic-sg}}（解析半群）→ {{R:maxreg}}, {{R:weis}}（最大正則性）← {{R:umd}}（UMD）；非線形版は {{R:komura}}, {{R:brezis}} を経て {{R:minty}}（単調作用素）へ。
膨張と関数モデル{{R:vn-ineq}}（von Neumann）→ {{R:nagy}}（Sz.-Nagy）→ {{R:char-fn}}（特性関数）→ {{R:clt}}（可換子持ち上げ）→ {{R:pick}}（Pick）；{{R:stinespring}} → {{R:arveson-ext}}（Arveson）→ 完全正値写像と量子情報（第 X 部 X-8）。

非線形・確率・最終合流

変分と位相{{R:direct}}（直接法）→ {{R:quasiconvex}}（準凸性）→ {{R:gamma-conv}}（Γ-収束）；{{R:ekeland}}（Ekeland）→ {{R:deformation}} → {{R:mp}}（峠の定理）→ {{R:ls-cat}}（Lusternik–Schnirelmann）；{{R:brouwer-deg}} → {{R:ls-deg}} → {{R:cr}}, {{R:rabinowitz-global}}（分岐）。
凸解析 → 輸送{{R:fenchel-moreau}} → {{R:fr-dual}} → {{R:kr-dual}}, {{R:kantorovich}}（Kantorovich 双対）→ {{R:brenier}}（Brenier）→ 勾配流・曲率次元条件（第 IX 部 IX-9）。
ガウス測度 → Malliavin{{R:prokhorov}} → {{R:fernique}}, {{R:cameron-martin}} → {{R:dudley}}, {{R:mm}}（chaining）→ {{R:bdg}} → Malliavin 解析（IX-6）→ {{R:mild}}（確率偏微分方程式）。
関数不等式 → 大偏差{{R:nelson-hyp}}（Nelson）→ {{R:bakry-emery}}（Bakry–Émery）→ 集中不等式 → {{R:cramer}}, {{R:sanov}}, {{R:varadhan}}（大偏差）。
群と表現{{R:haar}} → {{R:pontryagin}}, {{R:peter-weyl}} → {{R:mackey}}（Mackey の機械）→ 離散系列と $L^{2}$ 指数（X-2, X-4）。
最終合流点大問 {{R:finale}}：三大原理 ＋ Fredholm 指数の安定性（{{R:ind-stab}}）＋ Gelfand 理論（{{R:gelfand}}）＋ 擬微分作用素（{{R:parametrix}}）＋ K 理論と Bott 周期性（{{R:bott}}）＋ Toeplitz 指数（{{R:toeplitz-ind}}）。関数解析の全部門が一つの定理で出会う。
