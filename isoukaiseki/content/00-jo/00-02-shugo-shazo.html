この章の問い

  • 「集合とは、ものの集まりである」という説明は、なぜ通用しないのか。
  • 写像の像と逆像は、なぜこれほど振る舞いが違うのか。
  • 同値関係で割るという操作は、何を捨てて何を残しているのか。
  • 無限には大小があるのか。

素朴な定義が壊れるところ

集合を「ものの集まり」と説明するのは分かりやすい。そして、その分かりやすさがそのまま矛盾を生む。どんな条件を書いても、それを満たすものを全部集めれば集合になる——この素朴な原則を認めると、次の集合を考えることができてしまう。

R = \{\, x \mid x \notin x \,\}

自分自身を元として含まないもの全体である。ここで R \in R かどうかを問う。含むとすれば条件により含まない。含まないとすれば条件を満たすので含む。どちらに転んでも矛盾する。ラッセル Russell が一九〇一年に見つけたこの逆説は、集合論をいったん壊した。

修復の方針は、「集める」操作を制限することだった。現在の標準的な公理系では、条件を満たすものを無制限に集めることは許されない。許されるのはすでに存在する集合の中から、条件を満たす元を選び出すことだけである。これを分出の公理という。

この制限のもとでは、上の R は作れない。作れるのは、あらかじめ与えられた集合 A に対する \{\, x \in A \mid x \notin x \,\} だけである。そしてこの集合は A の元ではない——それを示すのが演習である。「すべての集合の集合」も同じ理由で存在しない。

本書はこれ以上集合論の公理には立ち入らない。必要なのは、無制限な内包が許されないという一点だけである。位相空間論では「ある空間のすべての開集合の族」のように大きな族をしばしば扱うが、それらはいずれも冪集合の部分集合として作られており、危険はない。

演算——任意個の合併と交叉

二つの集合の合併と交叉は既知とする。位相空間論で本質的に効いてくるのは、添字集合が有限でなくてもよいという点である。

添字集合 I と、各 i \in I に対する集合 A_i が与えられたとき、

\bigcup_{i \in I} A_i = \{\, x \mid \exists i \in I,\ x \in A_i \,\}, \qquad \bigcap_{i \in I} A_i = \{\, x \mid \forall i \in I,\ x \in A_i \,\}

と定める。合併には存在量化子が、交叉には全称量化子が対応している。この対応は覚える価値がある。後に開集合の公理が「任意個の合併で閉じ、有限個の交叉で閉じる」という非対称な形をとるとき、その非対称性の意味を考える手掛かりになるからである（第5章）。

ド・モルガン De Morgan の法則も任意個で成り立つ。全体集合 X の中で補集合をとるとき、

X \setminus \bigcup_{i \in I} A_i = \bigcap_{i \in I} (X \setminus A_i), \qquad X \setminus \bigcap_{i \in I} A_i = \bigcup_{i \in I} (X \setminus A_i)

である。補集合をとる操作が、合併と交叉を入れ替える。この事実によって、開集合について証明したことは自動的に閉集合についての主張に翻訳される。第6章で繰り返し使う。

写像——像と逆像は対等ではない

写像 f \colon X \to Y とは、X の各元に Y の元をただ一つ対応させる規則である。厳密には X \times Y の部分集合 f であって、各 x \in X に対して (x, y) \in f となる y がちょうど一つ存在するもの、と定める。規則という語を使わずに済ませたいときは、この定義に戻ればよい。

f \colon X \to Y とし、A \subseteq X、B \subseteq Y とする。

f(A) = \{\, f(x) \mid x \in A \,\} \subseteq Y, \qquad f^{-1}(B) = \{\, x \in X \mid f(x) \in B \,\} \subseteq X

f(A) を A の像、f^{-1}(B) を B の逆像という。

記号 f^{-1} は逆写像を意味しない。逆写像が存在しなくても逆像は定義される。逆像は集合に対する操作であり、点に対する操作ではない。この混同は非常によく起きるので、最初に断っておく。

さて、ここからがこの節の要点である。逆像は集合演算のすべてと可換であるが、像はそうではない。

逆像は集合演算を保つ

f \colon X \to Y とし、\{B_i\}_{i \in I} を Y の部分集合の族、B \subseteq Y とする。

f^{-1}\Big(\bigcup_{i \in I} B_i\Big) = \bigcup_{i \in I} f^{-1}(B_i), \qquad f^{-1}\Big(\bigcap_{i \in I} B_i\Big) = \bigcap_{i \in I} f^{-1}(B_i) f^{-1}(Y \setminus B) = X \setminus f^{-1}(B)

交叉の場合を示す。他も同様であり、ここでは省略してよい——同じ書き換えを繰り返すだけだからである。

x \in f^{-1}(\bigcap_i B_i) であることは、定義により f(x) \in \bigcap_i B_i と同値であり、これは「すべての i について f(x) \in B_i」と同値であり、さらに「すべての i について x \in f^{-1}(B_i)」と同値である。最後の条件は x \in \bigcap_i f^{-1}(B_i) にほかならない。

証明の全体が、定義を書き下して量化子の位置を動かさずに読み替えるだけで終わっていることに注意してほしい。逆像がこれほど素直なのは、x \in f^{-1}(B) が f(x) \in B という一点の条件に還元されるからである。

像はそうはいかない。y \in f(A) は「ある x \in A があって f(x) = y」という存在の主張であり、存在量化子は交叉と可換でない。

像は交叉を保たない

X = \{a, b\}、Y = \{c\} とし、f(a) = f(b) = c とする。A_1 = \{a\}、A_2 = \{b\} とおくと、

f(A_1 \cap A_2) = f(\varnothing) = \varnothing, \qquad f(A_1) \cap f(A_2) = \{c\} \cap \{c\} = \{c\}

となって一致しない。一般に成り立つのは f(A_1 \cap A_2) \subseteq f(A_1) \cap f(A_2) という片側の包含だけである。等号が常に成り立つのは f が単射のときに限る。

この非対称が、本書の構成を決めている。連続写像を「開集合の逆像が開集合」と定義するのは、逆像だけが集合演算を壊さないからである。「開集合の像が開集合」という条件も考えられるが（開写像という）、それは連続性とは別の、もっと強くて扱いにくい条件になる。第8章で正面から扱う。

同値関係——何を捨てるか

数学で「同じとみなす」という操作は、同値関係によって形式化される。

集合 X 上の関係 \sim が同値関係であるとは、次の三つを満たすことをいう。

反射律　すべての x について x \sim x。
対称律　x \sim y ならば y \sim x。
推移律　x \sim y かつ y \sim z ならば x \sim z。

x を含む同値類を [x] = \{\, y \in X \mid y \sim x \,\} と書き、同値類全体の集合を X/{\sim} と書いて商集合という。

X 上の同値関係 \sim に対し、同値類の全体は X の分割をなす。すなわち、どの同値類も空でなく、和集合が X に等しく、異なる二つの同値類は交わらない。逆に、X の任意の分割は、ちょうど一つの同値関係から得られる。

反射律より x \in [x] なので、同値類は空でなく、和集合は X を覆う。交わらないことを示す。[x] \cap [y] \ne \varnothing とし、z をその元とする。z \sim x かつ z \sim y である。対称律と推移律より x \sim y が従う。すると任意の w \in [x] について w \sim x \sim y なので w \in [y]、つまり [x] \subseteq [y]。役割を入れ替えて逆向きも得られ、[x] = [y]。交われば一致する——これが分割の意味である。

逆を示す。分割 \mathcal{P} が与えられたとき、x \sim y を「x と y が同じ要素に属する」と定めれば、三つの条件はただちに確かめられる。一意性は、同値関係が同値類によって完全に決まることから従う。

商集合を作るとは、区別する必要のない違いを捨てることである。何を捨てるかを決めるのが同値関係であり、捨てた後に何が残るかを見極めることが、商を扱う際の実質的な作業になる。整数の合同、ベクトル空間の商、そして第10章の商空間は、いずれも同じ構造をしている。

濃度——無限の大小

二つの集合のあいだに全単射があるとき、濃度が等しいという。有限集合では元の個数が一致することと同じだが、無限集合ではこの定義が直観を裏切る。自然数全体と偶数全体は、真部分集合でありながら濃度が等しい。

自然数全体と濃度の等しい集合を可算無限といい、有限または可算無限であることを可算という。有理数全体は可算である。では、すべての無限集合が可算なのか。この問いに答えたのがカントール Cantor であった。

カントールの定理

任意の集合 X について、X から冪集合 \mathcal{P}(X) への全射は存在しない。

f \colon X \to \mathcal{P}(X) を任意の写像とし、

D = \{\, x \in X \mid x \notin f(x) \,\}

とおく。D は X の部分集合であるから \mathcal{P}(X) の元である。もし f が全射なら、f(d) = D となる d \in X がある。ここで d \in D かどうかを問う。d \in D とすれば D の定義より d \notin f(d) = D。d \notin D とすれば d \notin f(d) なので定義より d \in D。いずれも矛盾する。よって全射は存在しない。

この証明は、本章の冒頭で見たラッセルの逆説とまったく同じ仕掛けを使っている。違いは、無制限に集めていないことである。D は既存の集合 X から分出しているので、正当に存在する。逆説を生んだ対角線の議論が、制限のもとでは定理を生む。

x \mapsto \{x\} は単射なので、X の濃度は \mathcal{P}(X) の濃度より真に小さい。したがって無限には限りなく多くの段階がある。特に実数全体は自然数全体と濃度が等しくない——第43章で実数を構成したのち、この事実が解析学でどう効くかを見る。

逆像の可換性は、どこまで自明か

「逆像は演算と可換、像は可換でない」という事実は、暗記すべき公式のように見える。しかし理由を押さえておくと、忘れても再構成できる。

述語の言葉で見る。部分集合 B \subseteq Y は、述語 P_B(y) \equiv (y \in B) と同一視できる。このとき逆像は

x \in f^{-1}(B) \iff P_B(f(x))

であり、逆像をとる操作は述語に f を代入する操作にすぎない。代入は論理結合子と可換である——P \land Q に代入したものは、代入したもの同士の \land に等しい。逆像の可換性は、代入が論理結合子を透過するという、それだけの事実である。

像はなぜ違うのか。像は代入ではなく、存在量化である。

y \in f(A) \iff \exists x\ \big(x \in A \land f(x) = y\big)

\exists は \lor とは可換だが \land とは可換でない。\exists x (P \lor Q) と \exists x P \lor \exists x Q は同値だが、\exists x (P \land Q) は \exists x P \land \exists x Q より真に強い。左辺は同じ x が両方を満たすことを要求し、右辺は別々の x でよい。この一点が、反例 の正体である。

補集合はどうか。像と補集合の関係はさらに悪い。一般には f(X \setminus A) と Y \setminus f(A) のあいだにどちらの包含も成り立たない。f が全射でなければ左辺に入らない点が右辺にあり、f が単射でなければ右辺に入らない点が左辺にある。両方の包含が成り立つのは、f が全単射のときに限る。

まとめると次の表になる。成り立つ包含だけを書く。

f(A_1 \cap A_2) \subseteq f(A_1) \cap f(A_2), \qquad f(A_1 \cup A_2) = f(A_1) \cup f(A_2) A \subseteq f^{-1}(f(A)), \qquad f(f^{-1}(B)) \subseteq B

最後の二つも向きを間違えやすい。A \subseteq f^{-1}(f(A)) の等号は f が単射のとき、f(f^{-1}(B)) \subseteq B の等号は f が全射のときに成り立つ。どちらも、証明を書けば一行で終わる。書いてみることを勧める。

選択公理なしで、どこまで進めるか

本章の結果は、どれも選択公理を使っていない。分出と冪集合と対の公理だけで足りる。しかし「可算」という概念のまわりには、選択公理の影が早くも差している。

可算和は可算か。「可算個の可算集合の合併は可算である」という主張は、教科書で当然のように使われる。証明は、各 A_n に自然数からの全単射 f_n を取り、(n, k) \mapsto f_n(k) で数え上げるというものである。ここに 可算個の選択が隠れている——各 n について f_n を「取る」操作は、可算選択公理を使っている。

実際、選択公理を完全に否定するある種のモデルでは、実数全体が可算個の可算集合の合併になることが知られている。フェファーマン Feferman とレヴィ Lévy によるこのモデルでは、カントールの定理は依然として成り立つ（それは選択公理を使わない）が、可算性についての直観は崩れる。定理が成り立つことと、直観が通用することは別である。

濃度の比較可能性。「任意の二つの集合は、一方から他方への単射があるか、その逆があるかのいずれかである」——これを濃度の三分律という。三分律は選択公理と同値である。選択公理を仮定しなければ、比較できない濃度の対が存在しうる。次章でこの事実を正面から扱う。

ベルンシュタインの定理は例外である。一方で、「X から Y への単射と Y から X への単射があれば、全単射がある」というカントール–ベルンシュタイン Cantor–Bernstein の定理は、選択公理を使わずに証明できる。証明は構成的で、二つの単射の合成を繰り返して軌道を追い、軌道の型に応じて対応を定める。比較可能性は選択を要するが、比較した後の話は要しない——この境界は覚えておく価値がある。

本書での扱い。以降、選択公理を使う証明にはそのつど断りを入れる。特に第21章のチコノフ Tychonoff の定理は選択公理と同値であり、第27章のベール Baire のカテゴリー定理は従属選択公理と同値である。これらは単なる注釈ではない。位相空間論の主要定理のいくつかは、集合論の公理の強さをそのまま反映している。
