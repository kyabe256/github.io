畳み込みという積

ここまでの章で、畳み込みは繰り返し現れた——フーリエ部分和（f*D_N）、フェイェール平均（f*K_N）、熱方程式の解（f*H_t）、平滑化（f*\varphi_\varepsilon）。本章でその理由を整理する。

畳み込み

f,g:\mathbb{R}^d\to\mathbb{C} について

(f*g)(x) = \int_{\mathbb{R}^d} f(x-y)\,g(y)\,dy

を畳み込みという（右辺が定義されるとき）。変数変換により f*g=g*f、また (f*g)*h=f*(g*h)。

ヤングの不等式

1\le p,q,r\le\infty が \frac1p+\frac1q=1+\frac1r をみたすとき、f\in L^p、g\in L^q について f*g はほとんどいたるところ定義され

\|f*g\|_r \le \|f\|_p\,\|g\|_q

とくに（1）L^1*L^1\subset L^1、（2）L^1*L^p\subset L^p、（3）L^p*L^{p'}\subset L^\infty（1/p+1/p'=1、このとき f*g は一様連続）。

（2）を示す（一般の場合はここから補間で出る）。ミンコフスキーの積分不等式より

\|f*g\|_p = \Big\|\int f(y)g(\cdot-y)\,dy\Big\|_p \le \int|f(y)|\,\|g(\cdot-y)\|_p\,dy = \|f\|_1\|g\|_p

平行移動が L^p ノルムを変えないことだけを使っている。

（3）はヘルダーの不等式（）そのもの。一様連続性は、|(f*g)(x)-(f*g)(x')|\le\|f\|_p\|g(x-\cdot)-g(x'-\cdot)\|_{p'} と平行移動の L^{p'} 連続性（p' < \infty のとき）から出る。

一般の場合は |f*g|\le(|f|^{p/r}|g|^{q/r})*1 のような分解にヘルダーを三重に使うか、と同じくリース–ソリンの補間による。

畳み込みが現れる三つの理由

（1）平行移動と可換な作用素は、畳み込みしかない。T:L^p\to L^p が有界で、すべての平行移動 \tau_h と可換（T\tau_h=\tau_hT）なら、T はある超関数との畳み込みである。逆も明らか。「空間のどこでも同じように働く」という要請が、畳み込みという形を強制する。物理でいう並進不変性である。

（2）フーリエ変換が積に変える。\widehat{f*g}=\hat f\hat g（（5））。したがって畳み込みの解析は、周波数側では各点の掛け算にすぎない。

（3）独立な確率変数の和の分布が畳み込みである。X,Y が独立で密度 f,g をもつなら、X+Y の密度は f*g。中心極限定理は、畳み込みを繰り返すと形がガウスに近づくという主張である。

三つはどれも同じ事実の別の顔である：畳み込みは、平行移動という群作用に関する「積」である。第79章の言葉では、群環の積にほかならない。

畳み込みは滑らかさを継ぐ

（1）f\in L^1、g\in C^k で導関数が有界なら f*g\in C^k で \partial^\alpha(f*g)=f*\partial^\alpha g。微分を g の側に押しつけられる。

（2）したがって \varphi\in C_c^\infty なら f*\varphi\in C^\infty。どれほど荒い f も、滑らかな関数と畳み込めば滑らかになる。これが平滑化（）の原理である。

（3）台の加法性。\mathrm{supp}(f*g)\subset\overline{\mathrm{supp}f+\mathrm{supp}g}。両方が有界なら畳み込みも有界な台をもつ。

（4）単位元は存在しない。f*e=f（すべての f\in L^1）をみたす e\in L^1 はない。もしあれば \hat e\equiv1 だが、これはリーマン–ルベーグの補題に反する。L^1(\mathbb{R}^d) は単位元をもたないバナッハ環である（（3））。

近似単位元

近似単位元（実直線上）

\varphi\in L^1(\mathbb{R}^d)、\int\varphi=1 とし、\varphi_\varepsilon(x)=\varepsilon^{-d}\varphi(x/\varepsilon) と置く。この族 (\varphi_\varepsilon)_{\varepsilon>0} を \varphi から作った近似単位元という。

拡大縮小の規約により \int\varphi_\varepsilon=1 がすべての \varepsilon で成り立ち、\|\varphi_\varepsilon\|_1=\|\varphi\|_1、そして任意の \delta>0 について \int_{|x|\ge\delta}|\varphi_\varepsilon|\to0（\varepsilon\downarrow0）。

近似単位元による収束

（1）f\in L^p(\mathbb{R}^d)（1\le p < \infty）なら \|f*\varphi_\varepsilon-f\|_p\to0。
（2）f が有界連続なら、f*\varphi_\varepsilon\to f がコンパクト集合上一様に。
（3）\varphi\ge0 かつ \varphi(x)\le C(1+|x|)^{-d-\eta}（\eta>0）なら、f\in L^1_{\mathrm{loc}} のルベーグ点で f*\varphi_\varepsilon(x)\to f(x)。とくにほとんどすべての点で収束する。

（1）\int\varphi_\varepsilon=1 を使って

(f*\varphi_\varepsilon-f)(x) = \int\big(f(x-y)-f(x)\big)\varphi_\varepsilon(y)\,dy

ミンコフスキーの積分不等式より \|f*\varphi_\varepsilon-f\|_p\le\int\|\tau_yf-f\|_p\,|\varphi_\varepsilon(y)|dy。ここで \omega(y)=\|\tau_yf-f\|_p は有界（\le2\|f\|_p）で y\to0 のとき零に行く。積分を |y| < \delta と |y|\ge\delta に分ければ、と同じ議論が通る。

（3）ルベーグ点では \frac{1}{|B_r|}\int_{B_r}|f(x-y)-f(x)|dy\to0（）。\varphi の減衰条件から、\varphi_\varepsilon を球面上の平均の重ね合わせに分解して評価する。正確には、ハーディ–リトルウッドの最大作用素で \sup_\varepsilon|f*\varphi_\varepsilon|\le C\,Mf を示し、第83章の三段の手順を使う。

使われる近似単位元

（1）箱。\varphi=\frac{1}{|B_1|}\chi_{B_1}。f*\varphi_\varepsilon(x) は球平均で、ルベーグの微分定理そのもの。

（2）ガウス（熱核）。\varphi=(4\pi)^{-d/2}e^{-|x|^2/4}。フーリエ変換が e^{-|\xi|^2} なので、周波数側では高周波の指数的な切り落としになる。反転公式の証明に使った（）。

（3）ポアソン核。P_y(x)=c_d\,y/(|x|^2+y^2)^{(d+1)/2}。フーリエ変換は e^{-y|\xi|}。上半空間の調和関数の境界値の理論（第94章）の中心にある。

（4）なめらかな山（軟化子）。\varphi(x)=c\,e^{-1/(1-|x|^2)}\chi_{|x| < 1}。C_c^\infty に属するので、f*\varphi_\varepsilon は C^\infty かつ台がわずかに広がるだけ。「滑らかにしたいが台を保ちたい」ときの標準の道具で、1の分割（第24章）と組み合わせて偏微分方程式論の至るところで使われる。

（5）フェイェール核・ディリクレ核。周期の場合（第81章）。ディリクレ核は近似単位元ではないことを思い出しておく。

不確定性関係

ハイゼンベルクの不確定性関係

f\in L^2(\mathbb{R})、\|f\|_2=1 とする。任意の x_0,\xi_0\in\mathbb{R} について

\left(\int (x-x_0)^2|f(x)|^2dx\right)\left(\frac{1}{2\pi}\int(\xi-\xi_0)^2|\hat f(\xi)|^2d\xi\right) \ \ge\ \frac14

等号は f が x_0 を中心とするガウス関数に変調 e^{i\xi_0x} を掛けたもののときに限る。

x_0=\xi_0=0 としてよい（平行移動と変調で帰着する）。f\in C_c^\infty として示せば、稠密性で一般の場合に移る。部分積分より

1 = \int|f|^2dx = -\int x\,\frac{d}{dx}|f(x)|^2dx = -2\,\mathrm{Re}\int x\,f(x)\overline{f'(x)}\,dx

コーシー–シュワルツを使うと

1 \le 2\Big(\int x^2|f|^2dx\Big)^{1/2}\Big(\int|f'|^2dx\Big)^{1/2}

プランシュレル（）より \int|f'|^2dx=\frac{1}{2\pi}\int\xi^2|\hat f|^2d\xi。両辺を二乗すれば結論。

等号はコーシー–シュワルツの等号条件、すなわち f'(x)=-cxf(x)（c>0）のとき。これを解けば f(x)=Ae^{-cx^2/2}、ガウス関数である。

証明の実質は部分積分一回とコーシー–シュワルツ一回である。作用素の言葉で言えば、交換関係 [\frac{d}{dx},x]=I と、非可換な二つの自己共役作用素の分散の積に対するロバートソンの不等式（第75章★★の数値範囲の議論）である。

畳み込みの落とし穴

（1）ヤングの不等式の条件は外せない。f,g\in L^2(\mathbb{R}) なら f*g\in L^\infty だが L^2 に入るとは限らない。\frac12+\frac12=1+\frac1r より r=\infty が正しい指数である。

（2）定義できない場合。f=g=|x|^{-1/2}\chi_{|x| < 1}（d=1）とすると両方 L^1 だが、f*g(0)=\int|y|^{-1}\chi\,dy=\infty。ヤングの不等式は「ほとんどいたるところ定義される」としか言わない。

（3）近似単位元の条件を外すと。\int\varphi=1 を \int\varphi=c\ne1 にすると極限が cf になる。\varphi\notin L^1（たとえば \varphi(x)=\sin x/x、これはディリクレ核の連続版）だと一様有界性が失われ、L^1 での収束が壊れる——第81章のディリクレ核と同じ現象である。

（4）不確定性は「片方を零にできない」より強い。分散が有限でない場合（コーシー分布など）には不等式が自明になるが、台に関する定性的な不確定性（第84章★★★）はそのような場合も排除する。

★★ 学部後半——リトルウッド–ペイリー分解と特異積分

周波数を二進の帯に分ける。\psi\in C_c^\infty を 1/2\le|\xi|\le2 に台をもつように選び、\sum_{j\in\mathbb{Z}}\psi(2^{-j}\xi)=1（\xi\ne0）となるようにする。\Delta_jf=(\psi(2^{-j}\cdot)\hat f)^\vee と置くと f=\sum_j\Delta_jf。各 \Delta_jf は周波数が 2^j 程度の成分だけを含む。

リトルウッド–ペイリーの定理：1 < p < \infty のとき

\|f\|_{L^p} \ \asymp\ \Big\|\Big(\sum_j|\Delta_jf|^2\Big)^{1/2}\Big\|_{L^p}

「周波数帯ごとの大きさの二乗和」が、もとのノルムと同値になる。p=2 ではプランシュレルから自明だが、p\ne2 では非自明で、ランダムな符号（ヒンチンの不等式）と特異積分の理論を使う。これによってソボレフ空間・ベゾフ空間・ハーディ空間が周波数分解の言葉で定義でき、第88章の非線形評価が可能になる。

カルデロン–ジグムントの理論。核 K(x) が |K(x)|\le C|x|^{-d}、|\nabla K(x)|\le C|x|^{-d-1}、\int_{a < |x| < b}K=0 をみたすとき、主値

Tf(x) = \mathrm{p.v.}\int K(x-y)f(y)\,dy

は L^p（1 < p < \infty）で有界、L^1 から弱 L^1 へ有界。核が L^1 に属さないので、ヤングの不等式は効かない——代わりに カルデロン–ジグムント分解（関数を「良い部分」と「悪い部分」に分け、悪い部分を二進立方体ごとに平均を引いて処理する）を使う。ヒルベルト変換（d=1、K=1/\pi x）とリース変換（K=c_dx_j/|x|^{d+1}）がその原型である。

仮定を外すと。核の消去条件 \int_{a < |x| < b}K=0 を外すと主値が収束しない。滑らかさ条件（ヘルマンダー条件）を外すと L^1 弱型が壊れる。どちらも最小限の仮定に近い。

★★★ 大学院——畳み込みの逆問題と、群の上の解析

ウィーナーのタウバー型定理。f\in L^1(\mathbb{R}) について、\{f*g : g\in L^1\} が L^1 で稠密であることと、\hat f がどこでも零でないことは同値。証明はゲルファント理論（第79章）：閉イデアルの零点集合が空であることと、イデアルが全体であることの対応である。

この定理から素数定理が導ける（ウィーナー–池原の定理）。ゼータ関数が \mathrm{Re}\,s=1 上で零をもたないことが、ちょうど「\hat f がどこでも零でない」に翻訳される。解析的整数論の中心的な結果が、バナッハ環のイデアル論の一行に帰着する。

スペクトル総合問題。逆に、\hat f が零点をもつとき、f が生成する閉イデアルは零点集合だけで決まるか。\mathbb{R} では答えは否：シュヴァルツが \mathbb{R}^3 で反例を与え（1948年）、マリアヴァンがすべての非コンパクト局所コンパクト可換群で反例を構成した（1959年）。零点集合が同じでも別のイデアルになりうる——「重複度」の情報が失われている。

非可換群の畳み込み。G が非可換なら f*g\ne g*f で、L^1(G) は非可換バナッハ環になる。指標が足りないのでゲルファント変換は使えず、既約ユニタリ表現の族が双対の役割を果たす。プランシュレルの定理は

\|f\|_{L^2(G)}^2 = \int_{\hat G}\|\pi(f)\|_{HS}^2\,d\mu(\pi)

という形になる（\|\cdot\|_{HS} はヒルベルト–シュミットノルム、\mu はプランシュレル測度）。第76章★★の跡クラス・ヒルベルト–シュミットクラスが、ここで双対側の「積分の重み」として現れる。コンパクト群ではピーター–ワイルの定理がこれを離散和として与え、半単純リー群ではハリシュ–チャンドラのプランシュレル公式が明示的な答えを与える。

未解決に近い問い。カジュダンの性質 (T) をもつ群では、畳み込み作用素のスペクトルギャップが存在し、これが拡大グラフの構成やバナッハ–ルジン問題に使われる。ラマヌジャングラフの最適性（アロン–ボッパナ限界の達成）は、群の表現論と数論の一致によるものである。一方、自由群のフォン・ノイマン環の同型問題（L(F_n)\cong L(F_m) が n\ne m で成り立つか）は、自由確率論の発展にもかかわらず未解決のままである。
