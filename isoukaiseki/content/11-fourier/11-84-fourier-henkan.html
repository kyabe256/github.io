この章の問い

  • 周期をもたない関数を、どうやって波に分解するのか。
  • フーリエ変換の像は、どんな関数なのか。
  • 反転公式は、いつ成り立つのか。

周期を無限に伸ばす

周期 2L の関数のフーリエ級数は、周波数 n\pi/L の波の重ね合わせである。L\to\infty とすると、周波数の刻み \pi/L が零に近づき、和が積分に変わる。形式的には

f(x) = \sum_n c_n e^{in\pi x/L} \ \longrightarrow \ \frac{1}{2\pi}\int_{-\infty}^{\infty}\hat f(\xi)e^{ix\xi}\,d\xi

双対の側が \mathbb{Z} から \mathbb{R} に変わる。第79章の言葉では、群 \mathbb{T} の双対群が \mathbb{Z}、群 \mathbb{R} の双対群が \mathbb{R} だということである（（2））。

フーリエ変換

f\in L^1(\mathbb{R}^d) について

\hat f(\xi) = \mathcal{F}f(\xi) = \int_{\mathbb{R}^d} f(x)\,e^{-i x\cdot\xi}\,dx \qquad (\xi\in\mathbb{R}^d)

を f のフーリエ変換という。形式的な逆変換を

\check g(x) = \frac{1}{(2\pi)^d}\int_{\mathbb{R}^d} g(\xi)\,e^{i x\cdot\xi}\,d\xi

と書く。係数 2\pi の置き場所には流儀がいくつかあるが、本書では上の規約を用いる。

基本性質

f,g\in L^1(\mathbb{R}^d) について次が成り立つ。

（1）\hat f は有界連続で \|\hat f\|_\infty\le\|f\|_1。
（2）リーマン–ルベーグ：\hat f(\xi)\to0（|\xi|\to\infty）。すなわち \mathcal{F}:L^1\to C_0。
（3）平行移動と変調：\widehat{f(\cdot-h)}(\xi)=e^{-ih\cdot\xi}\hat f(\xi)、\widehat{e^{ih\cdot x}f}(\xi)=\hat f(\xi-h)。
（4）拡大縮小：f_\lambda(x)=f(\lambda x)（\lambda>0）なら \widehat{f_\lambda}(\xi)=\lambda^{-d}\hat f(\xi/\lambda)。
（5）畳み込み：\widehat{f*g}=\hat f\,\hat g。
（6）微分：\widehat{\partial_jf}(\xi)=i\xi_j\hat f(\xi)、\widehat{x_jf}(\xi)=i\,\partial_{\xi_j}\hat f(\xi)（それぞれ左辺が L^1 のとき）。
（7）乗法公式：\int\hat f\,g=\int f\,\hat g。

（1）連続性は優収束定理（）による。（3）（4）は変数変換、（5）（7）はフビニの定理（）。

（2）e^{-i\pi}=-1 を使う。h=\pi\xi/|\xi|^2 と置くと e^{-ih\cdot\xi}=-1 なので（3）より

\hat f(\xi) = -\widehat{f(\cdot-h)}(\xi), \qquad\text{よって}\qquad \hat f(\xi) = \frac12\widehat{\big(f-f(\cdot-h)\big)}(\xi)

（1）より |\hat f(\xi)|\le\frac12\|f-f(\cdot-h)\|_1。|\xi|\to\infty のとき |h|\to0 で、平行移動の L^1 連続性（から出る）により右辺は零に行く。稠密性を経由しない、直接の証明である。

（6）第一式は部分積分、第二式は積分記号下の微分（優収束定理）。

三つの規則が理論のすべてを動かす

畳み込みが積になり、微分が多項式倍になり、平行移動が位相の回転になる——この三つが、フーリエ変換が微分方程式に効く理由である。

定数係数の偏微分方程式 P(\partial)u=f は、変換すると P(i\xi)\hat u(\xi)=\hat f(\xi) という代数方程式になる。微分が割り算に変わる。あとは \hat u=\hat f/P(i\xi) を逆変換すればよい——ただし P(i\xi) の零点で何が起こるかが、方程式の性質（楕円型・双曲型・放物型）を決める。第88章でこの視点を仕上げる。

計算できる変換

基本的な変換の表

（1）矩形関数。f=\chi_{[-a,a]} なら

\hat f(\xi) = \int_{-a}^{a}e^{-ix\xi}dx = \frac{2\sin(a\xi)}{\xi}

これは L^1 に属さない（\int|\sin(a\xi)/\xi|d\xi=\infty）。フーリエ変換は L^1 を L^1 に写さない——像は C_0 の真部分集合で、その特徴づけは知られていない。

（2）三角関数（矩形の畳み込み）。\chi_{[-a,a]}*\chi_{[-a,a]} は三角形で、変換は (2\sin(a\xi)/\xi)^2\ge0。こちらは可積分である。

（3）ガウス関数。f(x)=e^{-a|x|^2}（a>0）なら

\hat f(\xi) = \Big(\frac{\pi}{a}\Big)^{d/2} e^{-|\xi|^2/(4a)}

a=1/2 のとき f は（定数倍を除いて）自分自身に写る。フーリエ変換の固有関数がガウス関数だという事実が、確率論（中心極限定理）・量子力学（コヒーレント状態）・不確定性関係のすべてに効いてくる。

（4）ポアソン核。f(x)=e^{-a|x|}（d=1）なら \hat f(\xi)=2a/(a^2+\xi^2)。逆に \frac{1}{\pi}\frac{a}{a^2+x^2}（コーシー分布）の変換は e^{-a|\xi|}。

（5）熱核。H_t(x)=(4\pi t)^{-d/2}e^{-|x|^2/4t} の変換は e^{-t|\xi|^2}。熱方程式 \partial_tu=\Delta u が、変換すると \partial_t\hat u=-|\xi|^2\hat u という常微分方程式になる。

（3）を d=1、a=1/2 で示す。g(\xi)=\hat f(\xi) と置くと、（6）の二式から

g'(\xi) = \widehat{(-ix)f}(\xi) = -i\,\widehat{xf}(\xi), \qquad xf(x) = -f'(x)

よって g'(\xi)=i\widehat{f'}(\xi)=i(i\xi)g(\xi)=-\xi g(\xi)。この常微分方程式と g(0)=\int e^{-x^2/2}dx=\sqrt{2\pi} から g(\xi)=\sqrt{2\pi}e^{-\xi^2/2}。

ガウス関数が「微分と掛け算が同じ働きをする」唯一の関数であることが、自己相似性の理由である。多次元はフビニで積に分解する。

反転公式

反転公式

（1）f\in L^1(\mathbb{R}^d) かつ \hat f\in L^1(\mathbb{R}^d) ならば、ほとんどすべての x で

f(x) = \frac{1}{(2\pi)^d}\int_{\mathbb{R}^d}\hat f(\xi)e^{ix\cdot\xi}\,d\xi

が成り立ち、f は（測度零の修正で）連続関数になる。
（2）f\in L^1 のみの仮定でも、ガウス総和法により

\lim_{\varepsilon\downarrow0}\ \frac{1}{(2\pi)^d}\int \hat f(\xi)e^{-\varepsilon|\xi|^2}e^{ix\cdot\xi}\,d\xi = f(x)

が L^1 ノルムで、また f の連続点では各点で成り立つ。
（3）一意性：\hat f\equiv0 ならば f=0。

（2）を示し、（1）（3）をそこから導く。乗法公式（（7））を g(\xi)=(2\pi)^{-d}e^{-\varepsilon|\xi|^2}e^{ix\cdot\xi} に適用する。（3）より \hat g(y)=H_\varepsilon(x-y)（熱核）だから

\frac{1}{(2\pi)^d}\int\hat f(\xi)e^{-\varepsilon|\xi|^2}e^{ix\cdot\xi}\,d\xi = \int f(y)H_\varepsilon(x-y)\,dy = (f*H_\varepsilon)(x)

熱核は正の近似単位元である（\int H_\varepsilon=1、正、原点の外の質量が零に行く）。したがってがそのまま使えて、f*H_\varepsilon\to f が L^1 で、また連続点では各点で成り立つ。

（1）：\hat f\in L^1 なら左辺で \varepsilon\to0 が優収束定理で通り、極限は反転積分になる。右辺の極限は L^1 で f だから、部分列をとればほとんどいたるところ一致する。反転積分は（1）の形から連続関数である。

（3）：\hat f\equiv0 なら（2）の左辺が恒等的に零なので f*H_\varepsilon\equiv0、極限をとって f=0。

L^1 の理論の限界

（1）像が特徴づけられない。\mathcal{F}(L^1)\subsetneq C_0(\mathbb{R}^d) であり、この包含は真である（矩形関数の変換は C_0 に属するが、L^1 の像に「近い」関数で像に入らないものが構成できる）。「どんな C_0 関数がフーリエ変換か」に答えはない。

（2）反転が素朴にはできない。\hat f\notin L^1 が普通に起こる（矩形関数）。総和法を挟まなければ反転公式は書けない。

（3）L^1 は変換で閉じない。したがって \mathcal{F} を L^1 上の作用素として反復できない。この不都合を解消する空間が二つある：L^2（第85章）とシュワルツ空間（第87章）。どちらもフーリエ変換で自分自身に写る。

（4）正定値性の落とし穴。\hat f\ge0 でも f\ge0 とは限らないし、逆も成り立たない。正しい対応はボホナーの定理（f が正定値関数であることと \hat f が正測度であることが同値）である。

反転公式から出てくるもの

（1）ポアソンの和公式。十分減衰する f について

\sum_{n\in\mathbb{Z}} f(n) = \sum_{k\in\mathbb{Z}} \hat f(2\pi k)

証明は F(x)=\sum_nf(x+n) を周期 1 の関数と見て、そのフーリエ係数が \hat f(2\pi k) であることを確かめ、x=0 と置くだけ。級数と積分の二つの世界を結ぶ橋であり、テータ関数の変換公式、ゼータ関数の関数等式、格子の幾何（Minkowskiの定理）のすべてがここから出る。

（2）標本化定理。\hat f が [-\Omega,\Omega] に台をもつなら

f(x) = \sum_{n\in\mathbb{Z}} f\Big(\frac{n\pi}{\Omega}\Big)\,\frac{\sin(\Omega x-n\pi)}{\Omega x-n\pi}

帯域が制限された信号は、等間隔の標本から完全に復元できる（ナイキスト–シャノン）。証明は \hat f を [-\Omega,\Omega] 上のフーリエ級数に展開し、反転するだけである。デジタル信号処理の全体が、この一行に乗っている。

（3）中心極限定理。確率変数の和の分布は畳み込みだから、特性関数（＝フーリエ変換）は積になる。\hat\mu(\xi)=1-\sigma^2\xi^2/2+o(\xi^2) を n 乗して \xi\to\xi/\sqrt n と縮めると e^{-\sigma^2\xi^2/2} に収束し、これはガウス関数の変換である。レヴィの連続性定理が、特性関数の収束から分布の収束を保証する。

（4）ハイゼンベルクの不確定性。\|f\|_2=1 のとき

\Big(\int x^2|f|^2dx\Big)\Big(\int \xi^2|\hat f|^2\frac{d\xi}{2\pi}\Big) \ \ge\ \frac14

等号はガウス関数のときのみ。第86章で証明する。

★★ 学部後半——乗子、正定値性、そして群への一般化

乗子作用素。有界関数 m(\xi) について T_mf=(m\hat f)^{\vee} と定める。L^2 では \|T_m\|=\|m\|_\infty（パーセヴァル、第85章）だが、L^p（p\ne2）で有界になる条件はずっと厳しい。

ミヒリン–ヘルマンダーの定理：|\partial^\alpha m(\xi)|\le C|\xi|^{-|\alpha|}（|\alpha|\le\lfloor d/2\rfloor+1）なら T_m は L^p（1 < p < \infty）で有界。リース変換 m=\xi_j/|\xi| がこの条件をみたすので、\|\partial_i\partial_ju\|_p\le C\|\Delta u\|_p という楕円型評価が出る。「ラプラシアンを押さえれば二階微分がすべて押さえられる」——偏微分方程式の正則性理論の出発点である。

ボホナーの定理。\varphi:\mathbb{R}^d\to\mathbb{C} が連続で \varphi(0)=1、かつ任意の x_1,\dots,x_n と c_1,\dots,c_n について

\sum_{j,k}c_j\bar c_k\,\varphi(x_j-x_k) \ \ge\ 0

（正定値）であることと、\varphi がある確率測度のフーリエ変換であることは同値。これが確率論における特性関数の完全な特徴づけである。証明はゲルファント理論（第79章）でも、直接の総和法でも与えられる。

局所コンパクト可換群への一般化。G を局所コンパクト可換群、\hat G を指標の群（双対群）とすると、フーリエ変換 L^1(G)\to C_0(\hat G) が定義され、反転公式とプランシュレルの定理が成り立つ。ポントリャーギン双対性 \hat{\hat G}\cong G が、反転公式の構造的な内容である。

具体例：\hat{\mathbb{T}}=\mathbb{Z}（フーリエ級数）、\hat{\mathbb{R}}=\mathbb{R}（フーリエ変換）、\widehat{\mathbb{Z}/N}=\mathbb{Z}/N（離散フーリエ変換）、\hat{\mathbb{Q}_p}=\mathbb{Q}_p（p 進解析）。本章と第80章は、同じ定理の二つの場合だったのである。非可換群では指標が足りず、表現論が必要になる（第79章★★★のGNS構成の方向）。

仮定を外すと。f\in L^1 を外すと積分が定義できない——それを救うのが第87章の超関数である。d=1 を外しても理論は変わらないが、球形の切り落としの振る舞いだけが劇的に変わる（第82章★★★のフェファーマンの反例）。

★★★ 大学院——不確定性の定理群

「両方が小さい台をもてない」の諸相。ハイゼンベルクの不等式は分散による定量化だが、定性的にはもっと強い主張が成り立つ。

ベンドキソンの定理：f\ne0 なら f と \hat f の台が両方とも有限測度をもつことはない。より精密に、|\mathrm{supp}f|\cdot|\mathrm{supp}\hat f|\ge1（アミレイ–ベルクマン）。

ハーディの不確定性定理：|f(x)|\le Ce^{-a|x|^2} かつ |\hat f(\xi)|\le Ce^{-b|\xi|^2} で ab>1/4 なら f=0。ab=1/4 ならガウス関数の定数倍に限る。証明はフラグメン–リンデレーフの定理（第90章の最大値原理の拡張）による。複素解析の剛性が、そのまま不確定性の剛性になっている。

ベールリングの定理：\int\int|f(x)||\hat f(\xi)|e^{|x\xi|}dxd\xi < \infty なら f=0。これはハーディの定理を含む最も強い形である。

離散版と数論。有限群 \mathbb{Z}/p（p 素数）では、タオの不確定性定理が成り立つ：f\ne0 なら |\mathrm{supp}f|+|\mathrm{supp}\hat f|\ge p+1。証明はシュヴァレー–ヴァルニングの定理と、ヴァンデルモンド行列式の非退化性を使う。素数であることが本質的で、合成数では成り立たない。この定理が圧縮センシングの理論的な基礎の一つになっている。

球充填との接触。ヴィアゾフスカによる 8 次元と 24 次元の球充填問題の解決（2016年、2022年フィールズ賞）は、コーン–エルキーズの線形計画法的な枠組みで、ポアソンの和公式をみたす「魔法の関数」を明示的に構成することによってなされた。関数は準モジュラー形式の積分表示として与えられる。フーリエ変換の符号条件と格子の幾何が、一行の等式で結ばれている。同じ手法が球面符号のフーリエ補間問題（ラドチェンコ–ヴィアゾフスカ）に発展している。

演習

基本
  1. 矩形関数のフーリエ変換を計算し、可積分でないことを確かめよ。
  2. ガウス関数のフーリエ変換を、常微分方程式を解いて求めよ。
  3. 畳み込みの変換が積になることを、フビニの定理で確かめよ。
  4. 熱方程式がフーリエ変換で常微分方程式になることを確かめよ。
証明
  1. リーマン–ルベーグの補題を、平行移動の L^1 連続性から示せ。（30点）
  2. 乗法公式 \int\hat fg=\int f\hat g を示せ。（25点）
  3. （2）を、熱核が近似単位元であることから示せ。（40点）
  4. 一意性（\hat f\equiv0\Rightarrow f=0）を示せ。（30点）
  5. ポアソンの和公式を、周期化した関数のフーリエ係数から示せ。（40点）
発展
  1. 標本化定理を、反転公式とフーリエ級数展開から示せ。（45点）
  2. 中心極限定理を、特性関数の収束から示せ。（50点）
  3. ボホナーの定理の必要性（正測度の変換は正定値）を示せ。（40点）
  4. ハーディの不確定性定理を、ab>1/4 の場合にフラグメン–リンデレーフの定理を使って示せ。（50点）
