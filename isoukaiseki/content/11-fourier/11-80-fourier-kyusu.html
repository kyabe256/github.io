この章の問い

  • なぜ三角関数で展開するのか。他の関数系ではいけないのか。
  • フーリエ係数は、何を測っているのか。
  • 「展開できる」とは、どの意味での収束を指すのか。

熱が方程式を選んだ

フーリエ級数は、純粋な好奇心から生まれたのではない。フーリエは熱伝導方程式を解こうとしていた（1807年、1822年）。棒の上の温度分布 u(x,t) が

\frac{\partial u}{\partial t} = \frac{\partial^2u}{\partial x^2}, \qquad u(0,t)=u(\pi,t)=0

をみたすとする。u=f(x)g(t) と変数分離すれば f''/f=g'/g=-\lambda（定数）となり、境界条件から f(x)=\sin(nx)、\lambda=n^2、g(t)=e^{-n^2t}。したがって

u(x,t) = \sum_{n=1}^\infty b_n e^{-n^2t}\sin(nx)

が解の候補である。初期条件 u(x,0)=f(x) を満たすには、任意の関数 f が \sum b_n\sin(nx) と書けなければならない。フーリエはこれを主張した。当時の数学者は信じなかった——ラグランジュは公然と反対し、審査報告は留保つきだった。

この主張が正しいかどうかを確かめる作業が、その後二百年の解析学をほぼ作った。収束の概念、積分の概念、集合論、測度論——すべてこの問いから出てきた。本書の第43章以降で積み上げてきた道具は、いまこの問いに答えるために揃えられたものである。

なぜ三角関数なのか——三つの答え

（1）微分作用素の固有関数である。-d^2/dx^2 の固有関数が \sin(nx) であり、境界条件がその選択を決める。第76章のスペクトル定理が、この事実を「グリーン関数の積分作用素の固有関数」として保証していた（）。微分方程式を解くために対角化する——三角関数は、そのための基底である。

（2）平行移動と両立する。円周上の関数を考えると、e^{in\theta} は回転 \theta\mapsto\theta+\alpha によって定数倍 e^{in\alpha} になる。平行移動の作用を対角化する関数系が、指数関数系にほかならない——これが群の表現論からの答えで、第79章のゲルファント変換がフーリエ変換になることと同じ事実である（（3））。

（3）直交系である。次の計算がすべての出発点になる。

\frac{1}{2\pi}\int_{-\pi}^{\pi} e^{in\theta}\overline{e^{im\theta}}\,d\theta = \frac{1}{2\pi}\int_{-\pi}^{\pi}e^{i(n-m)\theta}\,d\theta = \delta_{nm}

直交していれば係数が内積で読める。これが第65章の正規直交基底の理論に載る条件である。

フーリエ係数と、三つの見方

フーリエ係数とフーリエ級数

f\in L^1(\mathbb{T})（\mathbb{T}=\mathbb{R}/2\pi\mathbb{Z}、周期 2\pi の可積分関数）について

\hat f(n) = \frac{1}{2\pi}\int_{-\pi}^{\pi} f(\theta)e^{-in\theta}\,d\theta \qquad (n\in\mathbb{Z})

をフーリエ係数、形式的な級数

S[f](\theta) = \sum_{n\in\mathbb{Z}} \hat f(n)e^{in\theta}

を f のフーリエ級数という。N 次の部分和を S_Nf(\theta)=\sum_{|n|\le N}\hat f(n)e^{in\theta} と書く。

実形式では a_n=\frac1\pi\int f\cos n\theta\,d\theta、b_n=\frac1\pi\int f\sin n\theta\,d\theta とし、

S[f](\theta) = \frac{a_0}{2} + \sum_{n\ge1}\big(a_n\cos n\theta + b_n\sin n\theta\big)

フーリエ係数の基本性質

f,g\in L^1(\mathbb{T}) について次が成り立つ。

（1）|\hat f(n)|\le\|f\|_{L^1}/(2\pi)\cdot2\pi=\|f\|_1（正規化した L^1 ノルムで |\hat f(n)|\le\|f\|_1）。
（2）平行移動：f_h(\theta)=f(\theta-h) なら \widehat{f_h}(n)=e^{-inh}\hat f(n)。
（3）畳み込み：\widehat{f*g}(n)=\hat f(n)\hat g(n)。
（4）微分：f が絶対連続で f'\in L^1 なら \widehat{f'}(n)=in\hat f(n)。
（5）リーマン–ルベーグ：\hat f(n)\to0（|n|\to\infty）。
（6）一意性：すべての n で \hat f(n)=0 ならば f=0（ほとんどいたるところ）。

（2）は変数変換、（3）はフビニの定理（）、（4）は部分積分（境界項が周期性で消える）。

（5）三角多項式は L^1(\mathbb{T}) で稠密である（、または連続関数の稠密性と）。三角多項式 p については \hat p(n)=0 が大きい |n| で成り立つ。\|f-p\|_1 < \varepsilon をとれば（1）より |\hat f(n)|\le|\widehat{f-p}(n)|+|\hat p(n)| < \varepsilon（|n| 大）。稠密性＋一様評価という、本書で繰り返し現れた型の議論である。

（6）\hat f\equiv0 なら、すべての三角多項式 p について \int f\bar p=0。三角多項式は C(\mathbb{T}) で一様稠密（、あるいは第96章のストーン–ワイエルシュトラス）だから、すべての連続関数 g について \int f\bar g=0。これは f が定める複素測度 f\,d\theta が零であることを意味し、リースの表現定理の一意性（）から f=0。

フーリエ係数は何を測っているか

（1）直交射影の係数。L^2(\mathbb{T}) では \{e^{in\theta}\} が正規直交系だから、\hat f(n)=(f,e^{in\theta}) で、S_Nf は f の \mathrm{span}\{e^{in\theta}\}_{|n|\le N} への直交射影である（）。したがって S_Nf は「N 次の三角多項式による最良の L^2 近似」である。

（2）指標の値。\hat f(n) は、L^1(\mathbb{T}) を畳み込み環と見たときのゲルファント変換の値である（（3））。（3）の畳み込み定理は「代数準同型である」ことの言い換えにすぎない。

（3）減衰の速さが滑らかさを測る。（4）を繰り返せば、f が k 回微分可能で f^{(k)}\in L^1 なら \hat f(n)=o(|n|^{-k})。逆向きの主張も成り立ち、第88章のソボレフ空間はこの対応を定義そのものにする。「なめらかさ＝高周波成分の小ささ」という辞書が、ここで生まれる。

収束するのか

二乗平均収束

f\in L^2(\mathbb{T}) について \|S_Nf-f\|_{L^2}\to0、かつ

\frac{1}{2\pi}\int_{-\pi}^{\pi}|f|^2\,d\theta = \sum_{n\in\mathbb{Z}}|\hat f(n)|^2

（パーセヴァルの等式）。すなわち \{e^{in\theta}\} は L^2(\mathbb{T}) の正規直交基底である。

より、正規直交系が基底であることと、その張る空間が稠密であることは同値である。三角多項式は C(\mathbb{T}) で一様稠密（）で、C(\mathbb{T}) は L^2(\mathbb{T}) で稠密（）。一様収束は L^2 収束を導くので、三角多項式は L^2(\mathbb{T}) で稠密。

フーリエの主張は、L^2 の意味では完全に正しい。そしてその証明は第65章の抽象論に、稠密性という一点だけを足したものである。第82章でこの定理の含意を詰める。

各点では収束しない

L^2 での収束は、各点での収束を意味しない。実際には次のことが知られている。

（1）連続関数でも各点で発散しうる。ある f\in C(\mathbb{T}) と点 \theta_0 があって \sup_N|S_Nf(\theta_0)|=\infty（デュ・ボワ–レーモン、1876年）。本書ではすでにで、一様有界性の原理からこの存在を導いている。

（2）可積分関数ではほとんどいたるところ発散しうる。f\in L^1(\mathbb{T}) で S_Nf がほとんどすべての点で発散する例がある（コルモゴロフ、1923年）。L^1 ではフーリエの主張は成り立たない。

（3）L^2 ならほとんどいたるところ収束する。これは非自明な定理で、カールソンの定理（1966年）として第83章で扱う。証明には四十年かかった。

（4）連続関数でも一様収束しない。（1）から従う。しかしフェイェール平均（第81章）をとれば一様収束する——部分和が悪いのであって、級数の情報が足りないわけではない。

これらを並べると、「収束」という語をどの意味で使うかが決定的であることが分かる。第81章から第83章まで、この一点を追う。

計算してみる

（1）方形波。f(\theta)=1（0 < \theta < \pi）、-1（-\pi < \theta < 0）。奇関数なので a_n=0、

b_n = \frac2\pi\int_0^\pi\sin n\theta\,d\theta = \frac{2(1-\cos n\pi)}{n\pi} = \begin{cases}4/(n\pi) & n \text{ 奇} \\ 0 & n \text{ 偶}\end{cases}

係数の減衰は 1/n でしかない——跳びがあると \hat f(n)=O(1/n) より速くならない。\theta=\pi/2 で 1=\frac4\pi(1-\tfrac13+\tfrac15-\cdots)、すなわちライプニッツの級数が出る。

（2）三角波。f(\theta)=|\theta|。a_0=\pi、a_n=-4/(\pi n^2)（n 奇）、他は零。折れ目はあるが跳びがないので O(1/n^2)。\theta=0 とすれば \sum_{n\ \text{奇}}1/n^2=\pi^2/8。

（3）放物線。f(\theta)=\theta^2。a_0=2\pi^2/3、a_n=4(-1)^n/n^2。\theta=\pi から バーゼル問題 \sum1/n^2=\pi^2/6 が出る。オイラーが技巧で得た値が、フーリエ級数では計算の副産物になる。

（4）ポアソン核。0\le r < 1 について P_r(\theta)=\sum_{n}r^{|n|}e^{in\theta}=\frac{1-r^2}{1-2r\cos\theta+r^2}。これが第94章の調和関数とディリクレ問題の中心にある。係数が幾何級数的に減衰するので、収束は絶対かつ一様である。

フェイェールの定理（予告）

f\in C(\mathbb{T}) について、フーリエ部分和の算術平均

\sigma_Nf = \frac{1}{N+1}\sum_{k=0}^{N}S_kf

は f に一様収束する。とくに三角多項式は C(\mathbb{T}) で一様稠密である。

本章で使ったものと、次章で返すもの

（5）（6）との証明では、を先取りして使った。循環を避けるため、第81章ではフェイェールの定理をフーリエ級数の一意性に依存せずに証明する——核の性質だけから出る、独立した議論である。

三角多項式の稠密性は、フーリエ解析のすべての基礎にある。第96章のストーン–ワイエルシュトラスの定理はこれを一般化し、「点を分離する自己共役な部分環は稠密」という位相的な理由に還元する。

★★ 学部後半——係数から関数を読む

絶対収束の判定。\sum|\hat f(n)| < \infty ならフーリエ級数は一様絶対収束し、和は連続関数で f に等しい。十分条件：f が絶対連続で f'\in L^2。実際、コーシー–シュワルツと（4）から

\sum_{n\ne0}|\hat f(n)| = \sum_{n\ne0}\frac{|\widehat{f'}(n)|}{|n|} \le \Big(\sum_{n\ne0}\frac{1}{n^2}\Big)^{1/2}\Big(\sum|\widehat{f'}(n)|^2\Big)^{1/2} < \infty

滑らかさをほんの少し（半階分）足すだけで、絶対収束が保証される。ベルンシュタインの定理はこれを精密化し、f がヘルダー指数 \alpha>1/2 で連続なら絶対収束することを述べる。\alpha=1/2 では反例があり、境目は鋭い。

跳びは 1/n を強制する。f が点 \theta_0 で跳び d=f(\theta_0^+)-f(\theta_0^-) をもてば、n\hat f(n) は零に収束しない。逆に \hat f(n)=o(1/n) なら跳びはない。この観測からギブズ現象が説明される：跳びの近くで S_Nf は f を約 8.9\% 超過し、N\to\infty でもその超過量は減らない（位置だけが跳びに近づく）。超過量は

\frac{2}{\pi}\int_0^\pi\frac{\sin t}{t}\,dt - 1 \approx 0.0895

で、これは |d| に比例する普遍的な定数である。ディリクレ核の振動（第81章）が原因で、平均をとれば消える。

ワイルの一様分布判定法。数列 (x_n)\subset\mathbb{T} が一様分布する（任意の区間 I について \#\{n\le N:x_n\in I\}/N\to|I|/2\pi）ことと、

\frac1N\sum_{n\le N}e^{ikx_n} \to 0 \qquad (\forall k\ne0)

は同値である。証明は、特性関数を三角多項式で近似する——つまり三角多項式の稠密性そのものである。これから「\alpha 無理数なら (n\alpha) は一様分布する」が直ちに出る（幾何級数の和を評価するだけ）。無理数回転の軌道が稠密であるという定性的な事実が、ここで「どう分布するか」まで定量化される。

仮定を外すと。周期性を外すと \mathbb{Z} ではなく \mathbb{R} が双対になり、級数が積分に変わる（第84章）。直交性を外すと、係数が内積で読めなくなり、係数の一意性も失われる——非直交系による展開はフレームの理論として別に整備されている。

★★★ 大学院——一意性集合とビーリングの問い

一意性集合。E\subset\mathbb{T} が一意性集合であるとは、三角級数 \sum c_ne^{in\theta} が \mathbb{T}\setminus E のすべての点で 0 に収束すればすべての c_n=0 となること。カントールがこの問題から集合論を作った（1872年）——「例外集合の構造を語る言葉」が必要だったのである。本書の第43章の実数論と第53章の測度論は、もとをたどればこの問いに行き着く。

可算集合は一意性集合である（カントール–ヤング）。測度正の集合は一意性集合でない。ところが測度零で一意性集合でないものが存在する（メンショフ、1916年）——完全集合の構造が問題になる。ラジャチマンは、比 \xi のカントール集合 C_\xi が一意性集合であることと 1/\xi がピゾー数（代数的整数で、共役がすべて単位円内）であることが同値、という驚くべき結果を得た。整数論的な条件が、収束の問題を決めている。

記述集合論との結合。一意性集合の族 \mathcal{U} は \Pi^1_1 完全であり、ボレル集合ではない（ソロヴァイ、カウフマン）。「この集合が一意性集合か」という問いは、本質的に解析的階層の第一段に属する。第53章で扱った記述集合論の階層が、フーリエ解析の具体的な問題の複雑さを測る尺度として現れる。

ビーリングの問いとカレイマンの定理。指数の集合 \Lambda\subset\mathbb{Z} について、\{e^{in\theta}\}_{n\in\Lambda} が L^2(E)（E\subset\mathbb{T}）で完全になる条件は何か。ランダウの密度条件が答えの一部を与え、完全な解決はセイプとオルトガ–セルダの仕事に至る。応用は標本化定理（ナイキスト–シャノン）の一般化で、「どれだけ疎に標本をとれば信号が復元できるか」という問いが、指数系の完全性の問題に翻訳される。

加法的組合せ論との接点。ゴワーズ一様性ノルムは、フーリエ係数の一様な小ささを高次に一般化したもので、グリーン–タオのアーベル素数定理（素数の中に任意長の等差数列がある）の証明の骨格をなす。「フーリエ係数が小さい＝構造がない」という直観が、どこまで正しいか——それが高次フーリエ解析の主題である。
