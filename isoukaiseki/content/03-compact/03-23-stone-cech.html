この章の問い

  • もっとも大きいコンパクト化とは、何が大きいのか。
  • 「有界連続関数がすべて延びる」という性質は、なぜ最大性と同じなのか。
  • \beta\mathbb{N} という空間は、どれほど奇妙なのか。

構成

第14章で、チコノフ空間が立方体に埋め込めることを見た。その埋め込みの閉包を取れば、コンパクト化が得られる。

ストーン–チェックのコンパクト化

X をチコノフ空間、C = \{\, f \colon X \to [0,1] \mid f \text{ 連続} \,\} とする。 の埋め込み e \colon X \to [0,1]^{C}、e(x) = (f(x))_{f \in C} に対し、

\beta X = \overline{e(X)} \subseteq [0,1]^{C}

と定める。これを X のストーン–チェックのコンパクト化という。

[0,1]^C はチコノフの定理（第21章）よりコンパクトハウスドルフであり、その閉部分集合 \beta X もコンパクトハウスドルフである。e(X) は \beta X で稠密であり、e は埋め込みだから、これはコンパクト化である。

普遍性

構成そのものより、次の性質が \beta X を特徴づける。

ストーン–チェックの普遍性

X をチコノフ空間とする。

（1）どの有界連続関数 f \colon X \to \mathbb{R} も、連続に \beta X \to \mathbb{R} へ延びる。
（2）どのコンパクトハウスドルフ空間 K と連続写像 g \colon X \to K に対しても、連続な \tilde{g} \colon \beta X \to K で \tilde{g} \circ e = g となるものがただ一つ存在する。
（3）この性質をもつコンパクト化は、同型を除いて \beta X に限る。

（1）。f の値域を [0,1] に正規化してよい。すると f \in C であり、射影 p_f \colon [0,1]^C \to [0,1] を \beta X に制限したものが求める拡張である。実際 p_f(e(x)) = f(x)。射影は連続だから、制限も連続。拡張の存在が、構成そのものに組み込まれている。

（2）。K はコンパクトハウスドルフだから正規、よってチコノフ（第15章の系）。 より K は [0,1]^{D}（D = C(K, [0,1])）に埋め込める。各 h \in D について h \circ g \colon X \to [0,1] は連続だから、（1）により \beta X へ延びる。それらを束ねて \tilde{G} \colon \beta X \to [0,1]^{D} を得る。

\tilde{G}(\beta X) \subseteq K を示す。K は [0,1]^D でコンパクト、したがって閉である。\tilde{G}(e(X)) = g(X) \subseteq K であり、e(X) は稠密だから \tilde{G}(\beta X) = \tilde{G}(\overline{e(X)}) \subseteq \overline{\tilde{G}(e(X))} \subseteq K（第8章（5））。

一意性は、稠密集合上で一致する連続写像がハウスドルフな値域では全体で一致すること（第13章の演習）による。

（3）。普遍性をもつ二つのコンパクト化のあいだには、互いに逆な連続写像が誘導される。一意性より、それらの合成は恒等写像である。

（2）が「最大のコンパクト化」の意味である。どのコンパクト化 Y についても、Y 自身がコンパクトハウスドルフだから、\beta X \to Y という潰す写像がある。第22章の★★で導入した順序で、\beta X が最大元になる。

βN——離散空間のコンパクト化

もっとも研究されているのが \beta\mathbb{N} である。離散空間 \mathbb{N} のコンパクト化だが、その構造は驚くほど複雑である。

\beta\mathbb{N} は、\mathbb{N} 上の超フィルター全体の集合と自然に同一視できる。位相は、A \subseteq \mathbb{N} に対する

\hat{A} = \{\, \mathcal{U} \mid A \in \mathcal{U} \,\}

の全体を基底とする。各 \hat{A} は開かつ閉である。

骨子だけ述べる。n \in \mathbb{N} には主超フィルター（n を含む集合の全体）を対応させる。これが \mathbb{N} の埋め込みを与える。

超フィルター全体がコンパクトハウスドルフになることは、第20章★★★のストーン双対性による。\hat{A} の補集合が \widehat{\mathbb{N} \setminus A} であることは、超フィルターの性質（）から直ちに従う。したがって \hat{A} は開かつ閉であり、空間は全不連結である。

普遍性の確認。有界連続 f \colon \mathbb{N} \to \mathbb{R}（すなわち有界数列）に対し、\tilde{f}(\mathcal{U}) = \lim_{\mathcal{U}} f（超フィルターに沿った極限）と定めれば連続な拡張になる。有界数列は、どの超フィルターに沿っても極限をもつ。

βN の奇妙さ

濃度。|\beta\mathbb{N}| = 2^{2^{\aleph_0}}。可算集合のコンパクト化が、実数全体よりはるかに大きい。

点列が収束しない。\beta\mathbb{N} \setminus \mathbb{N} のなかの点列で、収束するものは最終的に定数になるものに限る。コンパクトなのに点列コンパクトでない。

稠密だが小さい。\mathbb{N} は可算で稠密。したがって \beta\mathbb{N} は可分である——濃度 2^{2^{\aleph_0}} の可分空間。

主でない超フィルターは見えない。\beta\mathbb{N} \setminus \mathbb{N} の点は、選択公理なしには一つも存在を示せない（第12章★★★）。この空間の大部分は、構成的には手に入らない。

コンパクト化からもとの空間を復元できるか

\beta X は X の情報をどれだけ保っているのか。逆に、\beta X から X を取り出せるのか。

関数環との対応。C^b(X) を X 上の有界連続実数値関数の全体とする。（1）より、

C^b(X) \cong C(\beta X)

という対応がある。\beta X は「X 上の有界連続関数が作る代数」を空間として実現したものである。

したがって、\beta X が決まれば C^b(X) が決まる。逆に C^b(X) から \beta X が復元できる——これが第79章のゲルファント理論の内容である。

X は復元できない。\beta X = \beta Y でも X \ne Y でありうる。たとえば X = \mathbb{N} と Y = \mathbb{N} \cup \{p\}（p \in \beta\mathbb{N} \setminus \mathbb{N} を一つ足した部分空間）は、同じストーン–チェックのコンパクト化をもつ。

より一般に、X \subseteq Y \subseteq \beta X なる Y はすべて \beta Y = \beta X を満たす。したがって \beta X は X を決めない。

復元できる場合。X がコンパクトなら \beta X = X である。コンパクト空間は自分自身のストーン–チェックのコンパクト化である。

これが第79章で効く。コンパクトハウスドルフ空間 K は、関数環 C(K) から完全に復元できる。ゲルファント–ナイマルクの定理は、可換 C^* 環と コンパクトハウスドルフ空間が圏同値であることを述べる。

実用的な帰結。コンパクト化の理論は、次の形で解析学に入ってくる。

第59章のリースの表現定理——C(K) 上の正線形汎関数が K 上の測度で表せる。K がコンパクトであることが本質的である。

第96章のストーン–ワイエルシュトラスの定理——C(K) の部分代数が稠密になる条件。ここでもコンパクト性が前提になる。

局所コンパクトな X については、C_0(X)（無限遠で消える連続関数）を使い、一点コンパクト化 X^* 経由で C(X^*) の話に帰着させる。ストーン–チェックではなく一点コンパクト化を使うのは、そのほうが小さくて扱いやすいからである。

βN の余部分——組合せ論と独立性

\mathbb{N}^* = \beta\mathbb{N} \setminus \mathbb{N} を考える。この空間の構造には、集合論が深く入り込む。

P点は存在するか。\mathcal{U} \in \mathbb{N}^* がP点であるとは、可算個の近傍の交叉が再び近傍を含むことをいう。言い換えれば、\mathcal{U} の可算個の元 A_n に対し、A \setminus A_n が有限になる A \in \mathcal{U} が存在する。

P点の存在は、集合論の公理系から証明も反証もできない。連続体仮説を仮定すれば存在する（ルドゥイン）。一方、シェラー Shelah はP点が存在しないモデルを構成した。

第4章の★★★で述べた独立性が、ここでも具体的な空間の点の存在として現れている。

組合せ論への応用。\beta\mathbb{N} には半群の構造が入る。\mathbb{N} の加法を超フィルターへ延ばすと、

A \in \mathcal{U} + \mathcal{V} \iff \{\, n \mid \{\, m \mid n + m \in A \,\} \in \mathcal{V} \,\} \in \mathcal{U}

という演算が定まる。この演算は結合的で、片側からは連続である。

エリス Ellis の定理により、コンパクトな右位相半群には冪等元が存在する。\mathcal{U} + \mathcal{U} = \mathcal{U} なる超フィルターが存在する。

この事実から、ヒンドマン Hindman の定理が短く証明できる。自然数を有限個に色分けすると、ある色のなかに、無限集合のすべての有限和が含まれる。組合せ論の定理が、位相的な議論で出てくる。

ファン・デル・ヴェルデンの定理も同様。「自然数を有限個に色分けすると、ある色に任意の長さの等差数列が含まれる」という定理も、\beta\mathbb{N} の力学系を使って証明できる。

なぜこれが可能なのか。\beta\mathbb{N} はコンパクトである。コンパクト性が「無限に続く選択」を一つの点として実体化する。組合せ論で「うまい部分集合を取り続ける」という議論が、位相では「ある超フィルターを取る」という一行になる。

第20章の★★★で述べた論理のコンパクト性定理と、同じ構図である。有限的な情報の整合性が、無限の対象の存在を保証する。

本書の扱い。この方向には進まない。だが \beta\mathbb{N} は、本書の後半で一度だけ顔を出す。第71章でバナッハ極限を扱うとき、「収束しない有界数列に極限を割り当てる」という操作が、超フィルターに沿った極限として実現される。ハーン–バナッハの定理（第67章）による構成と、\beta\mathbb{N} による構成は、同じものを別の言葉で述べている。
