この章の問い

  • 「有限である」ことの、どの部分を取り出したのがコンパクト性なのか。
  • 被覆・有限交叉性・超フィルターという三つの定義は、なぜ同じものなのか。
  • コンパクト性があると、何が自動的に手に入るのか。

有限性の代用

有限集合には便利な性質が多い。連続関数は最大値を取り、どんな被覆からも全体が作れ、どんな点列にも収束する部分列がある。無限集合では、これらが一般に壊れる。

コンパクト性は、無限集合でありながら有限集合のように振る舞うための条件である。ただし「有限に見える」度合いをどう定式化するかに、複数の道がある。

コンパクト空間

位相空間 X がコンパクトであるとは、X のどの開被覆も有限部分被覆をもつことをいう。すなわち、X = \bigcup_{i \in I} U_i（U_i 開）ならば、有限個の i_1, \ldots, i_n があって X = U_{i_1} \cup \cdots \cup U_{i_n}。

本書ではコンパクト性にハウスドルフ性を含めない。文献によっては「コンパクト」にハウスドルフを含め、含めない場合を「擬コンパクト」や「準コンパクト」と呼ぶ。必要なときは「コンパクトハウスドルフ」と明記する。

三つの定義が同値であること

集合の族 \mathcal{F} が有限交叉性をもつとは、\mathcal{F} のどの有限部分族の交叉も空でないことをいう。

コンパクト性の三つの形

X について、次は同値である。

（1）どの開被覆も有限部分被覆をもつ。
（2）有限交叉性をもつ閉集合の族は、全体の交叉が空でない。
（3）X 上のどの超フィルターも収束する。
（4）X のどのネットも収束する部分ネットをもつ。

（1）と（2）。補集合を取るだけである。閉集合の族 \{F_i\} に対し \bigcap_i F_i = \varnothing は \bigcup_i (X \setminus F_i) = X と同値であり、「有限部分被覆がある」は「有限個の F_i の交叉が空」と同値。対偶を取れば（2）になる。

（2）から（3）。\mathcal{U} を超フィルターとする。\{\overline{F} \mid F \in \mathcal{U}\} は有限交叉性をもつ（フィルターは有限交叉で閉じ、空集合を含まない）。（2）より x \in \bigcap_{F \in \mathcal{U}} \overline{F} なる点がある。

この x に \mathcal{U} が収束することを示す。V を x の近傍とする。もし V \notin \mathcal{U} なら、超フィルターの性質（第12章）より X \setminus V \in \mathcal{U}、よって x \in \overline{X \setminus V}。ところが V は x の近傍で V \cap (X \setminus V) = \varnothing だから、第6章の特徴づけに反する。よって V \in \mathcal{U}、すなわち \mathcal{U} \to x。

（3）から（2）。\{F_i\} を有限交叉性をもつ閉集合の族とする。有限交叉全体はフィルターの基をなすので、それを含む超フィルター \mathcal{U} が取れる（第12章、選択公理）。（3）より \mathcal{U} \to x なる x がある。各 i について F_i \in \mathcal{U} であり、x の任意の近傍も \mathcal{U} に属するから、両者は交わる。よって x \in \overline{F_i} = F_i。

（3）と（4）。第12章で見たネットとフィルターの翻訳による。超フィルターに対応するのが普遍ネットであり、収束する部分ネットの存在が超フィルターの収束に対応する。

（3）の形が、第21章のチコノフの定理をもっとも短く証明する。被覆による直接証明は、同じ定理に対してはるかに長くなる。定義の選び方が証明の長さを決める——これが第12章でフィルターを導入した理由である。

コンパクト性が与えるもの

（1）コンパクト空間の閉部分集合はコンパクト。
（2）ハウスドルフ空間のコンパクト部分集合は閉。
（3）コンパクト空間の連続像はコンパクト。
（4）コンパクト空間上の連続実数値関数は最大値と最小値を取る。
（5）コンパクト空間からハウスドルフ空間への連続な全単射は同相。
（6）コンパクトハウスドルフ空間は正規である。

（1）F \subseteq X を閉、\{U_i\} を F の（X の開集合による）被覆とする。\{U_i\} \cup \{X \setminus F\} は X の開被覆だから有限部分被覆をもち、X \setminus F を除けば F の有限被覆になる。

（2）K \subseteq X をコンパクト、x \notin K とする。各 y \in K についてハウスドルフ性より交わらない近傍 U_y \ni x、V_y \ni y を取る。\{V_y\} は K の開被覆だから有限個 V_{y_1}, \ldots, V_{y_n} で覆える。U = U_{y_1} \cap \cdots \cap U_{y_n} は x の近傍で K と交わらない。有限交叉だから開である——ここに有限性が効く。よって X \setminus K は開。

（3）f \colon X \to Y 連続全射、\{V_i\} を Y の開被覆とすると \{f^{-1}(V_i)\} は X の開被覆。有限部分被覆の像が Y を覆う。

（4）（3）より f(X) \subseteq \mathbb{R} はコンパクト。ハイネ–ボレルの定理（第29章）よりコンパクトな \mathbb{R} の部分集合は有界閉であり、上限を含む。

（5）f が閉写像であることを示せばよい（第8章）。F \subseteq X 閉なら（1）よりコンパクト、（3）より f(F) はコンパクト、（2）より Y で閉。

（6）A, B を交わらない閉集合とする。（1）より両方コンパクト。（2）の証明を二段階に行う——まず各 x \in A について、x と B を分離する開集合 U_x, V_x を（2）の議論で作る。\{U_x\} は A の被覆だから有限個で覆え、対応する V_x の有限交叉を取ればよい。コンパクト性を二回使う。

コンパクトな空間、そうでない空間

コンパクト。有限集合（どんな位相でも）。[0,1]（第29章のハイネ–ボレル）。[0,1]^{\mathbb{N}}（第21章）。カントール集合。順序数の空間 [0,\omega_1]。

コンパクトでない。\mathbb{R}（\{(-n,n)\} に有限部分被覆がない）。(0,1)（\{(1/n, 1)\} に有限部分被覆がない）。無限離散空間。[0,\omega_1)（各 [0,\alpha) で覆えるが有限では足りない）。

コンパクト性は遺伝しない

[0,1] はコンパクトだが (0,1) はそうでない。開部分空間では壊れる。閉部分空間では保たれる（（1））。

第19章の表でコンパクト性が「閉遺伝的」に分類されたのは、この非対称のためである。

コンパクト性と、量化子の順序

コンパクト性の証明は、しばしば同じ型をとる。「各点について何かが成り立つ」から「一様に何かが成り立つ」へ移る型である。

典型例——一様連続性。コンパクト距離空間上の連続関数は一様連続である（第47章で証明する）。証明はこうである。各点 x について \delta_x が取れる。\{U_{\delta_x/2}(x)\} はコンパクト空間の被覆だから有限個で覆え、\delta = \min_k \delta_{x_k}/2 が一様な値を与える。

第1章の★★で述べた量化子の順序の問題が、ここで解決している。

\forall x\ \exists \delta \quad\longrightarrow\quad \exists \delta\ \forall x

この入れ替えは一般には許されない。コンパクト性が、有限個への還元を通してそれを許す。

もう一つの型——被覆を縮める。（6）の証明で、コンパクト性を二回使った。一回目で B 側を有限個に還元し、二回目で A 側を還元する。この二段構えは、第24章のパラコンパクト性でも繰り返される。

ルベーグ数。コンパクト距離空間の開被覆 \{U_i\} に対し、次の性質をもつ \lambda > 0 が存在する。直径が \lambda 未満の部分集合は、ある U_i に丸ごと含まれる。この \lambda をルベーグ数という。

証明は、各 x について U_{2\varepsilon_x}(x) \subseteq U_{i(x)} なる \varepsilon_x を取り、\{U_{\varepsilon_x}(x)\} の有限部分被覆から \lambda = \min_k \varepsilon_{x_k} を作る。ここでも「各点ごと」が「一様」に変わっている。

ルベーグ数は、第95章でアスコリ–アルツェラの定理を扱うときと、道のホモトピーを細かく分割するときに使われる。

なぜ有限性がこれを可能にするのか。無限個の正の数の最小値は 0 になりうる（第5章の反例）。有限個なら最小値は正である。コンパクト性は、この一点のためにある。第5章で位相の公理が「有限交叉」を要求した理由と、同じ根から来ている。

コンパクト性の別の顔——論理と代数

コンパクト性は位相空間論の概念だが、同じ名前が論理学にも現れる。偶然ではない。

一階述語論理のコンパクト性定理。文の集合 \Sigma について、「\Sigma のどの有限部分集合もモデルをもつならば、\Sigma 自身もモデルをもつ」——これを論理のコンパクト性定理という。

この定理は、実際に位相的なコンパクト性として理解できる。言語 L の完全理論全体に適切な位相（ストーン位相）を入れると、得られる空間はコンパクトである。文 \varphi に対応する集合が開かつ閉であり、有限交叉性の議論がそのまま働く。

ストーン双対性。より一般に、ブール代数 B に対し、その超フィルター全体に位相を入れた空間 S(B) を考える。S(B) はコンパクトハウスドルフで、しかも開かつ閉な集合が基底をなす（全不連結）。このような空間をストーン空間という。

逆に、ストーン空間から開閉集合全体を取るとブール代数が得られる。この対応は圏同値である——ストーン Stone の双対定理という。

第23章のストーン–チェックのコンパクト化は、この双対性の特別な場合にあたる。\beta \mathbb{N} は、\mathbb{N} の冪集合というブール代数に対応するストーン空間である。

なぜ超フィルターが橋渡しをするのか。（3）が鍵である。コンパクト性とは、超フィルターがすべて「行き先」をもつことだった。論理の側では、超フィルターは無矛盾な極大理論——すなわち完全な世界像——にあたる。

「有限的に矛盾しない情報は、実際に実現できる」というのが、両方の定理の内容である。位相では点として実現し、論理ではモデルとして実現する。

代数における現れ方。可換環のスペクトル \mathrm{Spec}(A)（素イデアル全体にザリスキ位相を入れたもの）もコンパクトである。ここでも有限交叉性の議論が働く——イデアルが有限個の元で生成されることが、有限部分被覆を与える。

ただし \mathrm{Spec}(A) はハウスドルフでない（第13章で触れた）。コンパクト性は、分離公理を仮定しなくても意味をもつ。この事実が、代数幾何でコンパクト性が有用である理由である。

本書はこれらの方向に進まないが、第79章のゲルファント理論では、可換 C^* 環のスペクトルがコンパクトハウスドルフ空間になることを見る。そこで「空間と関数環の双対性」という同じ主題に、解析の側から到達する。
