局所有限性——有限性の局所化

コンパクト性は有限部分被覆を要求した。それでは強すぎる。\mathbb{R}^n も多様体も、コンパクトとは限らない。

そこで要求を緩める。全体として有限であることは諦め、各点のまわりで有限であることを求める。

局所有限・細分

部分集合の族 \mathcal{A} が局所有限であるとは、各点が近傍をもち、その近傍と交わる \mathcal{A} の元が有限個であることをいう。

被覆 \mathcal{B} が被覆 \mathcal{A} の細分であるとは、\mathcal{B} の各元がある \mathcal{A} の元に含まれることをいう。

パラコンパクト空間

ハウスドルフ空間 X がパラコンパクトであるとは、どの開被覆も局所有限な開細分をもつことをいう。

「有限部分被覆」から「局所有限な開細分」へと、二か所が緩んでいる。部分被覆でなく細分でよく、有限でなく局所有限でよい。コンパクトならパラコンパクトである——有限部分被覆は局所有限な細分だからである。

パラコンパクトな空間

距離空間はすべてパラコンパクト。スミルノフ Smirnov とストーン Stone の定理。証明は込み入っており、選択公理を使う。この事実が第32章の距離化定理の土台になる。

コンパクト空間。定義から直ちに。

局所コンパクトで \sigma-コンパクトな空間。\mathbb{R}^n や多様体がこれにあたる。コンパクト集合の増大列で覆えることを使って、局所有限な細分を作る。

ゾルゲンフライ直線。パラコンパクトである。ところがゾルゲンフライ平面 \mathbb{R}_\ell^2 はパラコンパクトでない——第17章で正規でないことを見たが、パラコンパクトなら正規なので（次の定理）、当然である。

パラコンパクト性は正規性を含む

パラコンパクト空間は正規である。

まず正則性を示す。x \notin F、F 閉とする。各 y \in F について、ハウスドルフ性より交わらない開集合 U_y \ni x、V_y \ni y を取る。\{V_y\}_{y \in F} \cup \{X \setminus F\} は開被覆だから、局所有限な開細分 \mathcal{W} がある。

V = \bigcup \{\, W \in \mathcal{W} \mid W \cap F \ne \varnothing \,\} と置く。局所有限な族の合併の閉包は、閉包の合併に等しい（次の補題）。したがって

\overline{V} = \bigcup \{\, \overline{W} \mid W \cap F \ne \varnothing \,\}

である。各 W はある V_y に含まれるので \overline{W} \subseteq \overline{V_y} \subseteq X \setminus U_y。x の近傍で有限個の W としか交わらないものを取り、対応する U_y の有限交叉と合わせれば、x の近傍で \overline{V} と交わらないものが得られる。よって正則。

正規性は、同じ議論で点 x を閉集合 A に置き換えれば得られる。正則性を使って各 y \in B のまわりを取り、局所有限な細分で束ねる。

\mathcal{A} が局所有限なら \overline{\bigcup \mathcal{A}} = \bigcup_{A \in \mathcal{A}} \overline{A}。

\supseteq は明らか。\subseteq を示す。x \in \overline{\bigcup \mathcal{A}} とし、x の近傍 N で有限個の A_1, \ldots, A_n \in \mathcal{A} としか交わらないものを取る。

もし x \notin \overline{A_k} がすべての k で成り立つなら、N \cap \bigcap_k (X \setminus \overline{A_k}) は x の近傍で \bigcup \mathcal{A} と交わらない。有限個の交叉なので開である。これは x \in \overline{\bigcup \mathcal{A}} に反する。局所有限性が、無限個の閉包の合併を閉にしている。

この補題が、局所有限性が「有限性の代用」として働く理由である。一般には無限個の閉集合の合併は閉でない（第6章）。局所有限なら閉である。各点のまわりで有限個しか効かないので、有限合併の議論がそのまま通る。

1の分割

開被覆 \{U_i\}_{i \in I} に従属する1の分割とは、連続関数の族 \{\varphi_i \colon X \to [0,1]\} で次を満たすものをいう。

（1）\mathrm{supp}\,\varphi_i = \overline{\{\, x \mid \varphi_i(x) \ne 0 \,\}} \subseteq U_i。
（2）\{\mathrm{supp}\,\varphi_i\} は局所有限。
（3）各点で \sum_i \varphi_i(x) = 1（局所有限性より、各点で有限和）。

ハウスドルフ空間 X がパラコンパクトであることと、どの開被覆にも従属する1の分割が存在することは同値である。

逆向き（1の分割から）。\{\varphi_i\} を取れば \{\mathrm{supp}\,\varphi_i\} の内部が局所有限な開細分を与える。

順向き。\{U_i\} を開被覆とする。パラコンパクト性と正規性（）から、被覆を二段階縮める。すなわち、局所有限な開被覆 \{V_i\}、\{W_i\} で \overline{W_i} \subseteq V_i \subseteq \overline{V_i} \subseteq U_i となるものを作る。各段で正規性（）を使う。

ウリゾーンの補題（）より、\overline{W_i} で 1、X \setminus V_i で 0 となる連続 \psi_i が取れる。\{V_i\} が局所有限だから \Psi = \sum_i \psi_i は局所有限和であり連続、かつ \{W_i\} が被覆だから \Psi > 0。\varphi_i = \psi_i / \Psi と置けばよい。

何が解けるようになるか

1の分割の用途

リーマン計量の構成。多様体の各座標近傍で内積を定め、1の分割で足し合わせる。正定値性は凸結合で保たれるので、和も内積になる。これが「どんな多様体にもリーマン計量が入る」という定理の証明である。

積分の定義。多様体上の微分形式の積分は、座標近傍ごとの積分を1の分割で足し合わせて定義する。局所有限性が、和が有限であることを保証する。

偏微分方程式の局所解の貼り合わせ。第88章でソボレフ空間を扱うとき、局所的な評価から大域的な評価を得るのに使う。

ティーツェの拡張定理の別証明。第16章の定理は、1の分割を使っても証明できる。

パラコンパクト性の同値な形

パラコンパクト性には、細分の種類を変えた同値な言い換えがいくつもある。どれを使うかで証明の見通しが変わる。

マイケルの定理。正則空間 X について、次は同値である。

（1）パラコンパクト。（2）どの開被覆も局所有限な細分（開とは限らない）をもつ。（3）どの開被覆も\sigma-離散な開細分をもつ。（4）どの開被覆も\sigma-局所有限な開細分をもつ。

ここで \sigma-局所有限とは、局所有限な族の可算合併であることをいう。(4) が第32章のナガタ–スミルノフの距離化定理で使われる形である。

なぜ \sigma-局所有限で足りるのか。可算個の局所有限な族があれば、それらを「一段ずつ削る」ことで真に局所有限な族が作れる。第16章★★★と第18章で使った対角線的な構成と同じ手法である。

W_{n,i} = V_{n,i} \setminus \bigcup_{m < n} \overline{\bigcup_i V_{m,i}}

可算性が、この削り方を可能にする。

被覆を縮める形。もう一つの同値な形がある。X がパラコンパクトであることと、どの開被覆 \{U_i\} に対しても、\overline{V_i} \subseteq U_i なる局所有限な開被覆 \{V_i\} が存在することは同値である。

この形は、第15章の★★で述べた正規性の「被覆を縮める」形の無限版である。正規性は有限被覆を縮め、パラコンパクト性は任意の被覆を縮める。

階層のなかの位置。

\text{コンパクト} \implies \text{パラコンパクト} \implies \text{正規}

どちらの逆も成り立たない。\mathbb{R} はパラコンパクトだがコンパクトでない。第17章のチコノフ板 [0,\omega_1] \times [0,\omega] は正規（コンパクトだから）だが、その部分空間 [0,\omega_1) は正規でパラコンパクトでない。

[0,\omega_1) がパラコンパクトでない理由は、共終数にある。\{[0,\alpha)\}_{\alpha < \omega_1} という被覆の局所有限な細分を取ろうとすると、可算個の条件では \omega_1 に届かないという第4章の事実に突き当たる。

パラコンパクト性は積で壊れる——ドウカー空間再訪

第19章の表を、パラコンパクト性について埋める。結果は正規性とほぼ同じで、良くない。

遺伝しない。開部分空間には遺伝するが、一般の部分空間には遺伝しない。閉部分空間には遺伝する。

積で壊れる。\mathbb{R}_\ell はパラコンパクトだが \mathbb{R}_\ell^2 はそうでない。積で保たれる被覆性質は、実質的にコンパクト性だけである。

コンパクト空間との積。ただし一つ救いがある。パラコンパクト空間とコンパクト空間の積はパラコンパクトである。証明は、コンパクトな成分を有限個で覆えることを使う「チューブ補題」による。

可算パラコンパクト性。可算な開被覆に限って局所有限な細分を要求する条件を、可算パラコンパクト性という。パラコンパクトより真に弱い。

第17章の★★★で触れたドウカー空間は、正規だが可算パラコンパクトでない空間である。ドウカーの定理により、これは X \times [0,1] が正規でないことと同値である。

なぜ [0,1] との積が関わるのか。証明の筋を述べる。X が正規で可算パラコンパクトなら、可算開被覆 \{U_n\} を縮めて \overline{V_n} \subseteq U_n とし、1の分割を作れる。その関数を使って X \times [0,1] のなかの閉集合を分離できる。

逆に、可算パラコンパクトでなければ、縮められない可算被覆があり、それを使って X \times [0,1] のなかに分離できない閉集合の対が作れる。積の第二成分 [0,1] が、可算な「目盛り」の役割を果たしている。

ルドゥインの構成。一九七一年に構成された最初のドウカー空間は、\aleph_\omega のまわりの順序数を使う。共終数 \mathrm{cf}(\aleph_\omega) = \omega という性質が本質的である。可算個で届いてしまうのに、各段では届かない——この微妙な状況が、正規性と可算パラコンパクト性を分ける。

第4章で共終数を導入したとき、それが位相空間の性質として現れると予告した。チコノフ板（\mathrm{cf}(\omega_1) > \omega を使う）とドウカー空間（\mathrm{cf}(\aleph_\omega) = \omega を使う）は、その二つの現れ方である。
