この章の問い

  • 次元は、積で足し算になるのか。
  • 一致定理が破れる空間は、どう作られるのか。
  • 次元という素朴な概念のどこに、集合論が入り込むのか。

積で足し算にならない

第38章で \mathrm{ind}(X \times Y) \le \mathrm{ind}\,X + \mathrm{ind}\,Y を述べた。等号が成り立ちそうに見える。

ポントリャーギンの曲面

一九三〇年、ポントリャーギン Pontryagin は二次元のコンパクト距離空間 P_2, P_3 で

\dim P_2 = \dim P_3 = 2, \qquad \dim (P_2 \times P_3) = 3

となるものを構成した。積の次元が、和より真に小さい。

構成の骨子。二次元単体複体から出発し、係数が \mathbb{Z}/2 と \mathbb{Z}/3 のコホモロジーで次元が違うように作る。

具体的には、P_p（p は素数）を「\mathbb{Z}/p-係数のコホモロジー次元が 2、他の素数 q については 1」となるように構成する。積を取ると、係数が素であるところで次元が打ち消し合う。

次元が「足し算で決まらない」のは、位相的な次元が代数的な情報（コホモロジー）の最大値として振る舞うためである。

この現象は、コホモロジー次元 \dim_G（係数群 G）を導入すると説明がつく。\dim_G は素直に足し算になり、\dim X = \max_G \dim_G X のような関係がある。

したがって \dim(X\times Y) \ge \dim X + \dim Y - 1 は成り立つが、等号は保証されない。差は高々 1 である（有限次元コンパクト距離空間で）。

一致定理が破れる例

ロクトノフの空間

完備距離空間 \Delta で

\mathrm{ind}\,\Delta = 0, \qquad \mathrm{Ind}\,\Delta = \dim\Delta = 1

となるものが存在する（ロクトノフ Roy、一九六二）。

何が起きているか。\mathrm{ind}\,\Delta = 0 は、開かつ閉な集合が基底をなすことを意味する。各点のまわりは、いくらでも細かく「切り離せる」。

ところが \mathrm{Ind}\,\Delta = 1 は、ある交わらない閉集合の対が、空集合では分離できないことを意味する。

なぜ両立するのか。点ごとに切り離せても、閉集合全体を一度に切り離すには、無限個の切り口を「束ねる」必要がある。

可分ならば可算個で済み、対角線的に処理できる（第41章の証明）。\Delta は可分でない——\{0,1\}^{\omega_1} の部分空間として作られる。非可算個の切り口は束ねられない。

第4章の共終数が、ここでも効いている。

フィリポフの空間

コンパクトハウスドルフ空間 F で \dim F = 1 かつ \mathrm{Ind}\,F = 2 となるものが存在する（フィリポフ Filippov、一九七〇）。構成に連続体仮説を使う。

距離化できない空間では、被覆で測る次元と帰納的に測る次元が分かれる。第40章で「\dim はパラコンパクト性と相性がよい」と述べたが、距離化できないコンパクト空間ではその相性が効かない。

その他の反例

次元の奇妙な例

エルデシュ空間（第28章★★★）。E = \{\, x \in \ell^2 \mid \text{各 } x_n \in \mathbb{Q} \,\} は全不連結だが \dim E = 1。零次元でない全不連結空間である。

メンガーの普遍曲線。\dim = 1 のコンパクト距離空間で、どの 1 次元可分距離空間もこれに埋め込める。立方体から繰り返し穴を開けて作る。

ヌーベリングの普遍空間。\dim \le n の可分距離空間の普遍空間が \mathbb{R}^{2n+1} のなかに作れる（第41章★★）。

次元が上がる連続像。ペアノ曲線——[0,1]（\dim=1）から [0,1]^2（\dim=2）への連続全射がある。次元は連続像で保たれない。ただし単射なら保たれる（領域不変性）。

次元が下がる閉写像。零次元空間から n 次元空間への連続全射も作れる（カントール集合から [0,1]^n へ）。

次元が連続像で保たれないのは、第19章の表でコンパクト性や連結性が連続像で保たれたのと対照的である。次元は「細かさ」の量であり、像を取ると細かさが失われる。第19章★★で述べた「細かさは制限で保たれ、粗さは像で保たれる」という構図に従っている。

次元を上げる写像と下げる写像

写像で次元がどう変わるかを整理する。方向によってまったく違う。

単射で次元は上がらない。f \colon X \to Y が埋め込みなら \dim X \le \dim Y（\dim は遺伝的だから）。

連続全射では上がりうる。ペアノ曲線が例である。[0,1] \to [0,1]^2 の連続全射。

より強く、カントール集合からどのコンパクト距離空間へも連続全射がある（第33章★★で触れた）。零次元から任意の次元へ上がる。

閉写像で下がることはない。f \colon X \to Y がコンパクト距離空間のあいだの連続全射なら、一般に \dim Y と \dim X の関係は決まらない。

だが条件を付けると評価が出る。ヒューレヴィッチ Hurewicz の公式——

\dim X \le \dim Y + \sup_{y \in Y} \dim f^{-1}(y)

ファイバーの次元を足せば押さえられる。直観的には「底空間の次元＋繊維の次元」である。

逆向きの評価もある。f が閉写像で、各ファイバーが高々 k+1 点なら \dim Y \le \dim X + k。

次元を上げない写像。\dim f^{-1}(y) = 0（各ファイバーが零次元）の閉写像では \dim X \le \dim Y。とくに、有限個の点しか重ならない写像は次元を上げない。

ペアノ曲線を読み直す。[0,1] \to [0,1]^2 の連続全射では、ファイバーが有限（多くの点で）なのに次元が上がる。これは f が閉写像だが単射でなく、しかもファイバーの構造が場所によって変わるためである。

ヒューレヴィッチの公式は \dim X \le \dim Y + \sup \dim f^{-1}(y) の形なので、1 \le 2 + 0 で矛盾しない。逆向きの評価が効かないだけである。

本書での意味。第VI部以降で「次元」という語はほとんど使わない。だが第88章のソボレフ空間の埋め込み定理では、次元が指数に現れる。

そこでの次元は \mathbb{R}^n の n であり、本章で確立した「位相的に定まる量」である。領域不変性がなければ、その n は座標の取り方に依存してしまう。

次元論の未解決問題と独立命題

第4章の方針に従い、未解決と独立を区別して残された問題を挙げる。

独立な命題。

フィリポフの例は連続体仮説を使う。連続体仮説なしで \dim \ne \mathrm{Ind} のコンパクトハウスドルフ空間が作れるかは、長く問題だった。現在は、公理系だけで構成できることが知られている。

可分距離空間の次元の振る舞いに関する一部の問いは、マーティンの公理などに依存する。

未解決の問題。

積の次元の正確な値。\dim(X \times Y) を \dim X、\dim Y と付加的な情報から決定する一般的な公式は知られていない。コホモロジー次元を使うと部分的に説明できるが、完全ではない。

コホモロジー次元と被覆次元の差。コンパクト距離空間で \dim_{\mathbb{Z}} X = n なら \dim X = n か。有限次元の場合は真である（ドラニシニコフ Dranishnikov の理論）。

ところがドラニシニコフは一九八八年に、\dim_{\mathbb{Z}} X = 3 だが \dim X = \infty のコンパクト距離空間を構成した。アレクサンドロフが一九三二年に提起した問題の解決である。

次元の定義を変える方向。非可算な状況で \mathrm{ind} が落ちることを受けて、別の定義が試みられている。

基底次元、局所次元、超限次元など。どれも可分距離空間では一致し、一般の空間で分かれる。

第V部の総括。この部で見たことをまとめる。

第一に、「はい／いいえ」の条件を量に変えると、不等式の網が見えてくる（第35章）。

第二に、その網のなかに、公理系から決まらない関係がある（第36章・第37章）。

第三に、次元という素朴な概念も、三つの定義が一致するのは可分距離空間に限られる（第38〜42章）。

第四に、一致・不一致を決めているのは、つねに可算と非可算の境界である。第4章で導入した共終数が、ここまでのすべての反例に現れた。

第VI部への移行。次の部から解析学に入る。そこでは可算な操作だけで閉じた世界を扱う。

実数を構成し（第43章）、極限を定義し（第45章）、測度を作る（第52章）——どれも可算個の操作で完結する。第V部で見た非可算性の複雑さは、表に出てこない。

それが解析学の強みであり、同時に限界でもある。第97章でこの対比を地図にする。
