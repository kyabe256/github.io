この章の問い

  • 点ではなく閉集合から始めると、何が変わるのか。
  • 大域的に定義した次元のほうが、なぜ扱いやすいのか。
  • 二つの帰納的次元は、いつ一致するのか。

点を閉集合に置き換える

第38章の \mathrm{ind} は「点と近傍」を扱った。正則性の水準である。

点を閉集合に置き換えると、正規性の水準になる。第15章で正規性が正則性より強かったのと同じ構図である。

大きい帰納的次元

正規空間 X について、大きい帰納的次元 \mathrm{Ind}\,X を次のように定める。

（1）\mathrm{Ind}\,X = -1 \iff X = \varnothing。
（2）\mathrm{Ind}\,X \le n とは、各閉集合 A と各開集合 U \supseteq A に対し、開集合 V で

A \subseteq V \subseteq U, \qquad \mathrm{Ind}\,(\partial V) \le n-1

となるものが存在することをいう。

T_1 正規空間について \mathrm{ind}\,X \le \mathrm{Ind}\,X。また \mathrm{Ind}\,X = 0 であることと \mathrm{ind}\,X = 0 であることは同値である。

前半。T_1 より一点集合は閉だから、\mathrm{Ind} の条件を A = \{x\} に適用すれば \mathrm{ind} の条件が得られる。

後半。\mathrm{ind}\,X = 0 なら開かつ閉な集合が基底をなす。閉集合 A と開集合 U \supseteq A に対し、各 x \in A のまわりに U に収まる開かつ閉な集合を取る。

一般にはこれを有限個にまとめられないが、可分距離空間（リンデレーフ）なら可算個で足り、対角線的に削って開かつ閉な V が作れる。一般の正規空間では \mathrm{ind} = 0 でも \mathrm{Ind} > 0 でありうる（第42章）。

Ind が素直な理由

和の公式

X を正規空間、X = A \cup B（A, B 閉）とすると

\mathrm{Ind}\,X \le \mathrm{Ind}\,A + \mathrm{Ind}\,B + 1

が成り立つ。とくに \mathrm{Ind}\,B = -1（B = \varnothing）なら \mathrm{Ind}\,X = \mathrm{Ind}\,A。

\mathrm{Ind} は閉部分空間に遺伝する。すなわち A \subseteq X が閉なら \mathrm{Ind}\,A \le \mathrm{Ind}\,X。

n についての帰納法。\mathrm{Ind}\,X \le n とし、B \subseteq A を A で閉（A が X で閉だから X でも閉）、U を A で開かつ B \subseteq U とする。U = U' \cap A（U' は X で開）と書く。

U'' = U' \cup (X \setminus A) とおくと X で開で、B \subseteq U''。\mathrm{Ind}\,X \le n より、B \subseteq V \subseteq U''、\mathrm{Ind}\,(\partial V) \le n-1 なる開集合 V が取れる。

V \cap A は A で開で B \subseteq V \cap A \subseteq U'' \cap A = U。\partial_A(V \cap A) \subseteq (\partial V) \cap A であり、右辺は \partial V の閉部分集合。帰納法の仮定を閉部分空間 (\partial V) \cap A \subseteq \partial V に使えば \mathrm{Ind}\,\partial_A(V \cap A) \le n-1。よって \mathrm{Ind}\,A \le n。□

\mathrm{Ind} は一般の部分空間には遺伝しない。閉部分空間だけである。対して \mathrm{ind} は遺伝的だった（（2））。

これは第19章の表と同じ構図である——正則性は遺伝し、正規性は閉遺伝的だった。次元の定義が、分離公理の振る舞いをそのまま引き継いでいる。

分離による特徴づけ

閉集合 A, B（交わらない）に対し、閉集合 S が A と B を分離するとは、X \setminus S = U \sqcup V（U, V 開、交わらない）で A \subseteq U、B \subseteq V となることをいう。

正規空間 X について、\mathrm{Ind}\,X \le n であることと、交わらないどの閉集合の対も \mathrm{Ind} \le n-1 の閉集合で分離できることは同値である。

\mathrm{Ind}\,X \le n とする。A, B を交わらない閉集合とし、U = X \setminus B に条件を適用して A \subseteq V \subseteq U、\mathrm{Ind}\,\partial V \le n-1 なる V を得る。S = \partial V と置けば、X \setminus S = V^\circ \sqcup (X \setminus \overline{V}) が分離を与える。

逆も同様に、A と X \setminus U を分離する S から V を作る。

この形が第40章の \dim との比較に使われる。「低次元の壁で仕切れるか」というのが、帰納的次元の内容である。直線は一点で仕切れ、平面は曲線で仕切れる——これが \mathrm{Ind}\,\mathbb{R}=1、\mathrm{Ind}\,\mathbb{R}^2=2 の直観的な意味である。

Ind の和の公式を証明する

を示す。\mathrm{ind} では一般の空間で成り立たなかった公式が、\mathrm{Ind} では正規空間で成り立つ。

主張の形。X = A \cup B（閉）、\mathrm{Ind}\,A \le p、\mathrm{Ind}\,B \le q なら \mathrm{Ind}\,X \le p+q+1。

証明の骨子。p+q についての帰納法。C を閉集合、U \supseteq C を開集合とする。

まず A のなかで仕事をする。C \cap A は A で閉、U \cap A は A で開だから、\mathrm{Ind}\,A \le p より A のなかで \mathrm{Ind}\,\partial_A W \le p-1 なる開集合 W が取れる。

次に、この W を X 全体へ延ばす。W = O \cap A（O は X で開）と書き、

V = \big(O \cup (X \setminus A)\big) \cap U \cap \big(X \setminus (A \setminus W)\big)

とおく。A \setminus W は A で閉、A は X で閉だから A \setminus W は X で閉——ここで A が閉であることが効く。よって V は開で、V \cap A = W かつ C \subseteq V \subseteq U。

境界を評価する。\partial V \subseteq (\partial_A W) \cup (\partial V \cap B) が成り立つ。前者は \mathrm{Ind} \le p-1、後者は B の閉部分集合だから より \mathrm{Ind} \le q。

帰納法の仮定（(p-1)+q の場合）より \mathrm{Ind}\,\partial V \le (p-1)+q+1 = p+q。よって \mathrm{Ind}\,X \le p+q+1。

どこが効いたか。二か所である。

第一に、閉遺伝性（）。境界を B に制限したとき、次元が上がらないことが要る。

第二に、A が閉であること。A のなかで作った開集合を、A との交わりを変えずに X 全体へ延ばせる。A が閉でないと A \setminus W が X で閉にならず、この延長が作れない。正規性は、\mathrm{Ind} の定義そのもの（閉集合を開集合で囲む）に使われている。

ind で同じことができない理由。\mathrm{ind} は点についての条件なので、「A のなかで作ったものを延ばす」という操作が定義に噛み合わない。

可分距離空間では、第41章の一致定理により \mathrm{ind} = \mathrm{Ind} となるので、和の公式が \mathrm{ind} についても成り立つ。だがそれは一致定理を経由した結果であって、\mathrm{ind} の定義から直接出るのではない。

可算和定理と、その限界

和の公式を可算個に拡張したい。ここに次元論のもう一つの中心定理がある。

可算和定理。X を全正規（正規かつ可算パラコンパクト）な空間、X = \bigcup_{n} F_n（各 F_n は閉）とする。

\mathrm{Ind}\,X = \sup_n \mathrm{Ind}\,F_n

可算個の閉集合に分けたとき、次元は上がらない。有限和の公式と違って +1 がつかない。

なぜ +1 が消えるのか。有限和の公式の +1 は、A と B が「重なる」ところで余分な次元が出ることによる。可算和では、対角線的に削る操作で重なりを処理できる——第16章★★★や第18章で使った手法である。

ただし可算パラコンパクト性が要る。第24章★★★のドウカー空間では、この定理が破れる。

ドウカー空間での破れ。ドウカー空間 X（正規だが可算パラコンパクトでない）について、可算和定理が成り立たない例が知られている。可算個の閉零次元集合の合併なのに、全体の次元が正になる。

第24章で「共終数 \mathrm{cf}(\aleph_\omega) = \omega が本質的」と述べたが、次元論でもその構造が効いている。

ind の可算和定理。可分距離空間では \mathrm{ind} についても可算和定理が成り立つ。これは第41章の一致定理から従う。

一般の距離空間（可分でない）では、\mathrm{ind} の可算和定理は成り立たない。ここに \mathrm{ind} と \mathrm{Ind} の実質的な差が現れる。

距離空間での関係。カトゥートフ Katětov とモリタ Morita の定理により、距離空間では \mathrm{Ind} = \dim が成り立つ（可分でなくても）。

一方 \mathrm{ind} は一般の距離空間では \mathrm{Ind} と一致しない。ロクトノフ Roy が一九六二年に、完備距離空間で \mathrm{ind} = 0 だが \mathrm{Ind} = 1 という例を作った。

第42章でこの例に触れる。可分性がなければ、三つの次元は一致しない。

まとめ。一致定理の成立範囲は次のようになる。

\begin{array}{ll} \text{可分距離空間} & \mathrm{ind} = \mathrm{Ind} = \dim \\ \text{一般の距離空間} & \mathrm{Ind} = \dim \ne \mathrm{ind}\ (\text{一般に}) \\ \text{一般の正規空間} & \dim \le \mathrm{Ind},\ \mathrm{ind} \le \mathrm{Ind}\ \text{のみ} \end{array}

第41章でこの表を確定させる。
