この章の問い

  • 被覆の重なり方を数えると、なぜ次元が出るのか。
  • ルベーグの被覆定理は、何を言っているのか。
  • この定義は、なぜ扱いやすいのか。

重なりを数える

三つ目の次元は、まったく違う発想から来る。被覆の重なり方を数えるのである。

直線を短い区間で覆うと、どう工夫しても高々二つが重なるようにできる。平面を小さい円板で覆うと、高々三つが重なるようにできるが、二つに抑えることはできない。

この観察を定義にする。

被覆次元

被覆 \mathcal{A} の位数とは、n+1 個の元が共通点をもつような最大の n をいう（どの点も高々 n+1 個の元に属する、と言ってもよい）。

正規空間 X について、\dim X \le n とは、どの有限開被覆も、位数 n 以下の有限開細分をもつことをいう。\dim \varnothing = -1 と約束する。

「位数 n」とは「高々 n+1 個が重なる」ことである。添字のずれに注意してほしい。直線が \dim = 1 なのは、高々二つが重なるようにできるからである。

基本的な値

\dim \mathbb{R} = 1。どの有限開被覆も、長さの十分小さい区間による細分をもつ。区間を互い違いに並べれば、重なるのは隣り合う二つだけである。

\dim \mathbb{R}^n = n。\le n は、立方体をずらして並べる構成による。\ge n がルベーグの被覆定理である（次節）。

\dim X = 0。どの有限開被覆も、互いに交わらない開集合による細分をもつ。零次元空間（第38章）にあたる。

ルベーグの被覆定理

ルベーグの被覆定理

n 次元立方体 [0,1]^n を、直径が十分小さい閉集合で覆うと、必ずどこかで n+1 個が重なる。すなわち \dim [0,1]^n \ge n。

骨子を述べる。証明はスペルナー Sperner の補題（組合せ論）を使う。

スペルナーの補題。n 単体を小さい単体に分割し、各頂点に 0 から n のラベルを「面の条件」を守って付けると、すべてのラベルをもつ小単体が奇数個存在する。

被覆への翻訳。立方体の被覆 \{F_0,\ldots,F_k\}（直径が小さい閉集合）が与えられたとする。n+1 個が重ならないと仮定する。

立方体を n 単体に分け、細かく分割する。各頂点に、それを含む F_i のうち「対応する面に整合する」ものの番号を付ける。直径が小さいので、この付け方は可能である。

スペルナーの補題より、すべてのラベルをもつ小単体がある。その頂点たちは近くにあるので、対応する F_i が n+1 個すべて交わる。仮定に反する。

分割を細かくする極限を取ることで、閉集合の被覆についての主張が得られる。

この定理がブラウワーの不動点定理と同値であることが知られている。またブラウワーの領域不変性（\mathbb{R}^n \not\cong \mathbb{R}^m）も、これから従う。次元が「よく定義された」ことの証明が、組合せ論の補題に帰着する。

dim の性質

正規空間 X について、

（1）\dim は閉部分空間に遺伝する。
（2）\dim X \le \mathrm{Ind}\,X。
（3）全正規空間では可算和定理が成り立つ。
（4）\dim(X \times Y) \le \dim X + \dim Y（コンパクトハウスドルフで）。
（5）\dim X \le n であることと、どの有限開被覆 \{U_1,\ldots,U_k\} も、位数 n 以下の縮小被覆 \{V_1,\ldots,V_k\}（\overline{V_i} \subseteq U_i）をもつことは同値である。

（5）が実用上の形である。細分ではなく「同じ添字の縮小」で述べられる。第15章★★の被覆を縮める議論（正規性）を使う。

（2）\mathrm{Ind}\,X \le n とする。有限開被覆 \{U_1,\ldots,U_k\} を取り、各段で を使って境界の次元を下げながら縮小していく。帰納法で位数を n に抑える。

（1）閉部分空間の被覆を、全体の被覆に延ばして細分し、制限する。正規性が延ばす操作を保証する。

写像による特徴づけ

\dim のもっとも強力な性質は、球面への写像で言い換えられることである。

定理。正規空間 X について、\dim X \le n であることと

どの閉集合 A \subseteq X とどの連続写像 f \colon A \to S^n も、X 全体への連続な拡張をもつ

ことは同値である。

なぜこの形が有用か。第16章★★で述べたとおり、球面への写像は一般には延びない。「どこまで延びるか」が次元を測っている。

円周 S^1 への写像を考える。X = [0,1]、A = \{0,1\} なら、f は必ず延びる（S^1 は弧状連結）。X = \overline{D^2}、A = S^1、f = \mathrm{id} なら延びない。\dim \overline{D^2} = 2 > 1 だから。

次元を上げる例。この特徴づけから、次元の下からの評価が得やすくなる。「延びない写像を一つ作れば、次元が下限を超える」と言えるからである。

第42章で反例を作るとき、この手法を使う。

本質的写像。関連する概念として、f \colon X \to [0,1]^n が本質的であるとは、境界 f^{-1}(\partial [0,1]^n) 上で f と一致する写像で、値域が \partial[0,1]^n に収まるものが存在しないことをいう。

\dim X \ge n であることと、X から [0,1]^n への本質的写像が存在することは同値である。

ルベーグの被覆定理は、恒等写像 [0,1]^n \to [0,1]^n が本質的であるという主張として読める。

ホモトピー論との接続。これらの特徴づけは、代数的位相幾何学の道具（ホモトピー群、コホモロジー）と直接つながっている。

チェックコホモロジーを使うと、次元のさらに精密な理論（コホモロジー次元）が得られる。一般に \dim_{\mathbb{Z}} X \le \dim X であり、等号が成り立たない例がある——第42章で触れる。

無限次元の分類

\dim X = \infty の空間にも、区別がある。「無限次元」は一種類ではない。

強無限次元と弱無限次元。X が強無限次元であるとは、閉集合の対の無限列 \{(A_i,B_i)\} で、どのように分離集合 S_i を取っても \bigcap_i S_i \ne \varnothing となるものが存在することをいう。そうでないとき弱無限次元という。

ヒルベルト立方体 [0,1]^{\mathbb{N}} は強無限次元である。有限次元の空間はすべて弱無限次元である。

可算次元。X が可算次元であるとは、可算個の有限次元部分集合の合併として書けることをいう。

可算次元ならば弱無限次元である。逆は成り立たない——ポール Pol が一九八一年に、弱無限次元だが可算次元でないコンパクト距離空間を構成した。

この問題は五十年近く未解決だった。アレクサンドロフが一九五一年に提起している。

超限次元。次元の定義を超限順序数まで延ばすこともできる。\mathrm{ind} の再帰を順序数で行い、\mathrm{trind}（超限小帰納的次元）を定める。

可算次元なコンパクト距離空間は、\mathrm{trind} < \omega_1 をもつ。第4章で導入した順序数が、次元の値として現れる。

無限次元位相幾何学。ヒルベルト立方体と \ell^2 を扱う分野がある。驚くべき定理がいくつもある。

アンダーソン Anderson の定理——\ell^2 は \mathbb{R}^{\mathbb{N}} と同相である。ノルムの入った空間と、単なる積空間が同相になる。

ケラー Keller の定理——\ell^2 の無限次元コンパクト凸集合は、すべてヒルベルト立方体と同相である。

有限次元では、コンパクト凸集合は球体と同相になる（次元が決まる）。無限次元では次元による区別が消える。

本書での扱い。第42章で次元論の反例を扱うが、無限次元位相幾何学には立ち入らない。

ただし第VIII部以降で \ell^2 と L^2 を扱うとき、それらが位相空間としては区別できないという事実を心に留めておくとよい。解析学がそこで見ているのは、位相ではなく内積構造である。
