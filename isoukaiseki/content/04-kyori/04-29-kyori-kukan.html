この章の問い

  • 完備性は位相的な性質ではない。では何なのか。
  • コンパクト性と完備性は、どこで重なりどこで違うのか。
  • 完備でない空間を、完備にできるか。

距離空間に戻る

距離空間

集合 X と関数 d \colon X \times X \to [0,\infty) の対が距離空間であるとは、

d(x,y) = 0 \iff x = y, \qquad d(x,y) = d(y,x), \qquad d(x,z) \le d(x,y) + d(y,z)

を満たすことをいう。開球 B(x,r) = \{\, y \mid d(x,y) < r \,\} の全体を基底とする位相を、d の定める位相という。

第5章から第28章まで、位相の言葉で議論してきた。ここで距離に戻るのは、距離でしか言えないことを扱うためである。

完備性・全有界性

点列 (x_n) がコーシー列であるとは、どの \varepsilon > 0 に対してもある N があって m,n \ge N で d(x_m,x_n) < \varepsilon となることをいう。すべてのコーシー列が収束するとき (X,d) は完備であるという。

どの \varepsilon > 0 に対しても有限個の \varepsilon-球で X を覆えるとき、全有界であるという。

完備性と全有界性は位相的な性質でない。(0,1) と \mathbb{R} は同相だが、通常の距離では前者が全有界で完備でなく、後者は完備で全有界でない。同じ位相を与える距離のなかに、完備なものと完備でないものが共存する（第8章）。

これらは一様構造に属する性質である——第30章でその中間層を取り出す。

コンパクト性の特徴づけ

距離空間のコンパクト性

距離空間 (X,d) について、次は同値である。

（1）コンパクト。（2）可算コンパクト。（3）点列コンパクト。（4）完備かつ全有界。

（1）から（3）と（2）と（3）の同値は第25章で述べた。残りを示す。

（3）から（4）。コーシー列は収束部分列をもち、コーシー列で部分列が収束すれば全体が収束する。よって完備。全有界でないとすると、ある \varepsilon について有限個の \varepsilon-球で覆えない。そこで x_1 を任意に取り、x_{n+1} を B(x_1,\varepsilon) \cup \cdots \cup B(x_n,\varepsilon) の外に取る。この点列は互いに \varepsilon 以上離れているので、収束部分列をもたない。

（4）から（3）。点列 (x_n) を取る。全有界性より、X は有限個の 1-球で覆える。無限個の項を含む球 B_1 がある。B_1 は全有界だから、そのなかで 1/2-球について同じことを繰り返し、B_1 \supseteq B_2 \supseteq \cdots（半径 2^{-n}）で各々が無限個の項を含むものを作る。

各 B_n から項を一つずつ、添字が増加するように選べば、それはコーシー列である。完備性より収束する。

（3）から（1）。（4）より全有界、したがって可分（各 \varepsilon = 1/n について有限個の中心を集める）。可分な距離空間は第二可算（第7章）、したがってリンデレーフ（第25章）。リンデレーフかつ可算コンパクトならコンパクト。

ハイネ–ボレルの定理

\mathbb{R}^n の部分集合がコンパクトであることと、有界閉であることは同値である。

\mathbb{R}^n は完備である（第43章で実数の構成から示す）。有界閉集合は、完備空間の閉部分集合だから完備であり、有界だから全有界である（有界集合が全有界になるのは \mathbb{R}^n の特殊事情——次元が有限だから）。 よりコンパクト。

逆に、コンパクトなら全有界だから有界であり、ハウスドルフ空間のコンパクト部分集合は閉である（第20章）。

「有界ならば全有界」は一般には成り立たない。無限次元ノルム空間の単位球は有界だが全有界でない（第22章★★★、第71章）。ハイネ–ボレルの定理が有限次元でしか成り立たないのは、この一点による。

完備化

完備化の存在と一意性

どの距離空間 (X,d) も、完備距離空間 (\hat{X}, \hat{d}) のなかに等距離に稠密に埋め込める。この \hat{X} は等距離同型を除いて一意である。

構成。X のコーシー列全体に、(x_n) \sim (y_n) \iff d(x_n,y_n) \to 0 という同値関係を入れ、商集合を \hat{X} とする。距離を

\hat{d}([(x_n)], [(y_n)]) = \lim_{n \to \infty} d(x_n, y_n)

と定める。右辺の極限が存在することは、|d(x_m,y_m) - d(x_n,y_n)| \le d(x_m,x_n) + d(y_m,y_n) より数列 (d(x_n,y_n)) がコーシー列になることから従う。ここで実数の完備性を使う——第43章でこの循環を解く。

埋め込み。x \in X に定数列 [(x,x,\ldots)] を対応させる。等距離であり、像は稠密である——コーシー列 (x_n) に対し、定数列 [(x_N, x_N, \ldots)] は N を大きく取れば [(x_n)] にいくらでも近い。

完備性。\hat{X} のコーシー列を取る。稠密性より、各項に X の点を近く取れる。それらがコーシー列をなし、その類が極限になる。

一意性。X を稠密に含む二つの完備化のあいだに、X 上で恒等な等距離写像が一意に定まる（稠密集合上で決まるから）。

完備化の例

\mathbb{Q} の完備化は \mathbb{R}。これが第43章で採る実数の構成法の一つである。

C([0,1]) を L^1 ノルムで完備化すると L^1([0,1])。第62章で扱う。連続関数だけでは足りず、測度論が必要になる——これが第VII部を要する理由の一つである。

有理数を p-進距離で完備化すると p-進数体。同じ \mathbb{Q} から、距離の取り方で違う完備化が得られる。完備化は距離に依存する——位相だけでは決まらない。

縮小写像の不動点定理

完備性がもっとも直接に働く定理を挙げる。存在と一意性を同時に、しかも構成的に与える珍しい定理である。

主張。(X,d) を空でない完備距離空間、T \colon X \to X を縮小写像——すなわちある 0 \le k < 1 について d(Tx, Ty) \le k\, d(x,y)——とする。このとき T は不動点をただ一つもつ。

証明。x_0 を任意に取り x_{n+1} = Tx_n と定める。

d(x_{n+1}, x_n) \le k^n d(x_1, x_0)

なので、m > n について d(x_m,x_n) \le \frac{k^n}{1-k} d(x_1,x_0) \to 0。コーシー列だから完備性より収束する。極限 x は Tx = \lim Tx_n = \lim x_{n+1} = x を満たす（T は連続）。一意性は d(x,y) = d(Tx,Ty) \le k\,d(x,y) から d(x,y)=0。

なぜ構成的か。不動点は x_0 から始めて T を繰り返すだけで得られる。しかも収束の速さが k^n で評価できる。第1章で述べた「背理法による存在証明と構成による存在証明」の違いで言えば、これは完全に構成的である。

用途。常微分方程式の解の存在と一意性（ピカール–リンデレーフの定理）。陰関数定理。ニュートン法の収束。積分方程式の解法。いずれも「適当な関数空間を完備にして、縮小写像を作る」という形をとる。

第63章でバナッハ空間を導入したあと、この定理が線型作用素の逆の存在（ノイマン級数）として現れる。

完備性が外せないこと。X = (0,1]、Tx = x/2 とすると k = 1/2 の縮小写像だが、不動点 0 は X にない。完備性がなければ、極限が空間の外へ逃げる。

コンパクト性では代用できない。コンパクト空間上の連続写像には不動点がないことがある（円の回転）。縮小という条件が本質的である。逆に、コンパクト凸集合上の連続写像については不動点があり（ブラウワー、第72章で触れる）、そちらは構成的でない。

完備性は位相的でないが、完備化可能性は位相的である

完備性が位相的でないことを何度も述べた。ところが、「完備な距離が入るか」という問いは位相的である。この微妙な区別を押さえておく。

定義。位相空間 X が完備距離化可能であるとは、X の位相を与える完備な距離が存在することをいう。ポーランド空間とは、可分かつ完備距離化可能な空間のことをいう。

位相的であること。この条件は「ある距離が存在する」という形なので、同相で保たれる。したがって完備距離化可能性は位相的性質である。

(0,1) は通常の距離では完備でないが、\mathbb{R} と同相なので完備距離化可能である。完備でない空間と、完備距離化できない空間は違う。

特徴づけ。第33章で扱うが、結論を先に述べる。完備距離化可能な空間は、チェック完備な距離化可能空間として特徴づけられる。

より具体的な形として、アレクサンドロフの定理がある。完備距離空間の G_\delta 部分空間は完備距離化可能であり、逆も成り立つ。

したがって \mathbb{Q} は完備距離化可能でない。\mathbb{Q} は \mathbb{R} の G_\delta 部分集合でないからである（第27章でベールの定理から示した）。

無理数全体はどうか。無理数全体 \mathbb{R} \setminus \mathbb{Q} は \mathbb{R} の G_\delta 集合である（\bigcap_q (\mathbb{R} \setminus \{q\})）。したがって完備距離化可能である。

実際、無理数全体は \mathbb{N}^{\mathbb{N}}（可算離散空間の可算積、ベール空間と呼ばれる）と同相である。連分数展開がその同相を与える。通常の距離では完備でないのに、別の距離では完備になる。

なぜこの区別が重要か。第VII部以降で扱う定理の多くが「完備距離空間で」という仮定をもつ。実際に必要なのは完備距離化可能性である——適切な距離を選び直せばよい。

とくに第54章で可測関数を扱うとき、ポーランド空間という枠組みが自然に現れる。\mathbb{R}、[0,1]、\mathbb{R}^n、可分バナッハ空間、コンパクト距離空間——解析学で出会う空間はほとんどポーランド空間である。

記述集合論はポーランド空間の上で展開される。第7章★★★で触れたボレル階層の理論も、この設定でもっとも整った形になる。
