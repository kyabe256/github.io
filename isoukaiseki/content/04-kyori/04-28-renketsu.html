この章の問い

  • 「つながっている」を、開集合だけでどう言うのか。
  • 道でつなげることと、切り離せないことは同じか。
  • 連結成分は開集合か。

切り離せないこと

直観的には、[0,1] はつながっていて、[0,1] \cup [2,3] は二つに分かれている。この違いを開集合の言葉で述べたい。

後者では、[0,1] と [2,3] がそれぞれ全体のなかで開かつ閉である。前者では、開かつ閉な部分集合は \varnothing と全体しかない。これを定義に採る。

連結空間

位相空間 X が連結であるとは、X を二つの空でない交わらない開集合の合併として書けないことをいう。同値な言い方として、開かつ閉な部分集合が \varnothing と X に限ることをいう。

X が連結であることと、X から二点離散空間 \{0,1\} への連続写像が定数に限ることは同値である。

f \colon X \to \{0,1\} が連続で定数でないなら、f^{-1}(0) と f^{-1}(1) はともに空でない開集合で、交わらず、合併が X。逆に分割 X = U \sqcup V があれば、U で 0、V で 1 と定めた関数が連続で定数でない。

この言い換えが実用上もっとも使いやすい。連結性を示すには「定数でない \{0,1\} 値連続関数がない」ことを言えばよい。

連結な空間、そうでない空間

連結。区間（\mathbb{R} の連結部分集合は区間に限る）。\mathbb{R}^n。凸集合。球面。トーラス。密着位相をもつ空間。

連結でない。\mathbb{Q}（第9章）。無理数全体。カントール集合。離散空間（二点以上）。\mathbb{R} \setminus \{0\}。

\mathbb{Q} が連結でないのは、\sqrt{2} が穴になるからである。各点のまわりがいくらでも細かく切れる——こういう空間を全不連結という。連結成分が一点集合に限る空間である。カントール集合と \beta\mathbb{N}（第23章）もそうである。

保たれ方

（1）連結空間の連続像は連結である。
（2）連結な部分集合の族が共通点をもつなら、その合併は連結である。
（3）A が連結で A \subseteq B \subseteq \overline{A} なら B は連結である。
（4）連結空間の任意個の積は連結である。

（1）f \colon X \to Y 連続全射で Y が分割 U \sqcup V をもつなら、f^{-1}(U) \sqcup f^{-1}(V) が X の分割になる。

（2）\{A_i\} が連結で p \in \bigcap_i A_i とする。f \colon \bigcup_i A_i \to \{0,1\} を連続とすると、各 A_i 上で定数（）。どれも p を含むので、その定数値は f(p) に等しい。よって全体で定数。

（3）f \colon B \to \{0,1\} 連続とする。A 上で定数 c。B \subseteq \overline{A} より A は B で稠密であり、稠密集合上で一致する連続写像はハウスドルフな値域では全体で一致する（第13章）。よって f \equiv c。

（4）まず有限積。X \times Y で点 (a,b) を固定する。各 x について (\{x\} \times Y) \cup (X \times \{b\}) は、二つの連結集合が (x,b) で交わるので（2）より連結。これらはすべて (a,b) を含むので、再び（2）より合併が連結。合併は X \times Y 全体である。

無限積。a = (a_i) を固定し、有限個の座標を除いて a と一致する点の全体を D とする。D は連結集合（有限積の連結性を使う）の合併で共通点 a をもつから連結。D は積で稠密である——基本開集合が有限個の座標しか制限しないから。（3）より \overline{D} = \prod_i X_i も連結。

（4）の証明で、積位相の「有限個を除いて全体」という形が二度効いている。有限積を使って D を作り、稠密性を言うのにも使う。第11章で箱位相を退けた理由が、ここでも現れる——箱位相では D が稠密にならない。

弧状連結

X が弧状連結であるとは、任意の二点 x, y に対し連続写像 \gamma \colon [0,1] \to X で \gamma(0)=x、\gamma(1)=y となるものが存在することをいう。

弧状連結ならば連結である。

x を固定する。各 y について道 \gamma_y を取ると、\gamma_y([0,1]) は [0,1] の連続像だから連結（（1））。これらはすべて x を含むので、（2）より合併が連結。合併は X 全体。

位相幾何学者の正弦曲線

逆は成り立たない。\mathbb{R}^2 のなかで

S = \{\, (x, \sin(1/x)) \mid 0 < x \le 1 \,\}, \qquad T = S \cup (\{0\} \times [-1,1])

と置く。S は (0,1] の連続像だから連結であり、\overline{S} = T である——x \to 0 のとき \sin(1/x) が [-1,1] の全体を無限回往復するので、線分のすべての点が集積点になる。よって （3）より T は連結。

しかし弧状連結でない。原点 (0,0) と S の点を結ぶ道 \gamma があったとする。t_0 = \sup\{\, t \mid \gamma(t) \in \{0\}\times[-1,1] \,\} と置くと、t_0 のどんな右近傍でも \gamma の第二成分は [-1,1] 全体を動く。t_0 での連続性に反する。

連結だが弧状連結でない——この例が、二つの概念が別物であることを示す。

連結成分

x \in X を含む連結部分集合すべての合併を、x の連結成分という。（2）より、これは x を含む最大の連結集合である。

連結成分はつねに閉である。開とは限らない。各点が連結な近傍基をもつとき（局所連結）、連結成分は開である。

閉であること。C を成分とすると （3）より \overline{C} も連結であり、最大性より \overline{C} \subseteq C。

開でない例。\mathbb{Q} では成分は一点集合であり、開でない。

局所連結なら開であること。x \in C に対し連結近傍 V \ni x を取ると、最大性より V \subseteq C。よって C は各点の近傍を含む。

局所連結性は連結性を含まないし、含まれもしない。\mathbb{R} \setminus \{0\} は局所連結だが連結でない。 の T は連結だが局所連結でない。大域的な条件と局所的な条件は独立である——第19章の★★で述べた構図がここにも現れる。

弧状連結成分と、局所弧状連結

連結成分と同じく、弧状連結成分が定義できる。だが振る舞いが違う。

弧状連結成分は閉とは限らない。 の T では、弧状連結成分は二つ——曲線部分 S と線分 \{0\}\times[-1,1] である。S は閉でない。連結成分は T 全体の一つだけなので、連結成分が弧状連結成分より真に大きいことがある。

局所弧状連結なら一致する。各点が弧状連結な近傍基をもつとき、連結成分と弧状連結成分は一致する。

証明。C を連結成分、P \subseteq C を弧状連結成分とする。局所弧状連結性より P は開である（上と同じ議論）。同時に C \setminus P も他の弧状連結成分の合併だから開である。C が連結で P \ne \varnothing だから P = C。

多様体では一致する。多様体は局所的に \mathbb{R}^n と同相だから、局所弧状連結である。したがって多様体では「連結」と「弧状連結」を区別しなくてよい。

開集合についても同様である。\mathbb{R}^n の開集合は局所弧状連結なので、連結な開集合は弧状連結である。複素解析で「領域」を連結開集合と定義し、そこで道に沿った積分を考えられるのは、この事実による（第90章）。

なぜ道のほうが強いのか。道は [0,1] という具体的な空間からの写像を要求する。連結性は「切れない」という否定的な条件にすぎない。

存在を主張する条件（弧状連結）と、非存在を主張する条件（連結）——前者のほうが強く、そのぶん使いやすい。第1章で背理法と構成の違いを述べたが、同じ対比がここにある。

ホモトピー論が弧状連結性を基礎に据えるのは、そのためである。基本群を定義するには道が要る。連結なだけの空間では、道が足りなくて理論が立たない。

全不連結性の階層

で全不連結空間に触れた。「つながっていない」にも程度がある。

三つの条件。強い順に並べる。

零次元——開かつ閉な集合が基底をなす。

全分離——異なる二点を、開かつ閉な集合で分離できる。

全不連結——連結成分が一点集合に限る。

一般に 零次元 \Rightarrow 全分離 \Rightarrow 全不連結 であり、逆はいずれも成り立たない。

コンパクトなら一致する。コンパクトハウスドルフ空間では三つが同値になる。証明には、成分が「x を含む開かつ閉な集合すべての交叉」に等しいことを使う。

この事実が第20章★★★のストーン双対性を支えている。ストーン空間（ブール代数に対応する空間）はコンパクトハウスドルフかつ零次元である。

反例。全不連結だが零次元でない空間がある。エルデシュ Erdős 空間

E = \{\, x \in \ell^2 \mid \text{すべての } x_n \text{ が有理数} \,\}

は全不連結だが零次元でない。さらに E は自分自身と同相な位相的性質をもち、次元論で重要な例になる（第42章）。

次元論への接続。零次元性は、第38章で導入する小さい帰納的次元 \mathrm{ind} が 0 であることと同値である。したがって本章の三つの条件は、次元 0 の三つの定義にあたる。

第41章の一致定理は、可分距離空間で \mathrm{ind} = \mathrm{Ind} = \dim を主張する。その一番下の段——次元 0 の場合——が、ここで述べた同値性である。

連結性の次元論的な意味。逆に、連結性は「次元が 0 でない」ための条件の一つである。連結で二点以上ある空間は \mathrm{ind} \ge 1 である——開かつ閉な集合が自明なものしかないので、境界が空でない近傍が取れないからである。

第V部でこの関係を正面から扱う。本章の連結性は、そこへの入口にあたる。
