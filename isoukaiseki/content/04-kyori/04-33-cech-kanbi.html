この章の問い

  • 「完備な距離が入るか」を、位相の言葉で言い当てられるか。
  • コンパクト化のなかで、もとの空間はどんな位置を占めるのか。
  • ベール性は完備性から来るのか、もっと弱いものから来るのか。

完備距離化可能性を位相で述べる

第29章★★★で述べたとおり、完備性は位相的でないが、完備距離化可能性は位相的である。それを位相の言葉だけで特徴づけたい。

アレクサンドロフの定理

距離空間 X について、次は同値である。

（1）X は完備距離化可能。
（2）X は、ある完備距離空間の G_\delta 部分空間と同相。
（3）X は、自分の完備化 \hat{X} のなかで G_\delta である。

（1）から（3）。d を完備な距離とし、\hat{X} を別の距離 \rho による完備化とする。

U_n = \{\, y \in \hat{X} \mid \exists\, \rho\text{-近傍 } V \ni y,\ \mathrm{diam}_d(V \cap X) < 1/n \,\}

と置く。各 U_n は開であり X \subseteq U_n である（x \in X のまわりで d-径が小さい近傍が取れる）。

逆に y \in \bigcap_n U_n とすると、y に近づく X の点列が d-コーシーになる。d が完備だから極限が X にあり、y \in X。よって X = \bigcap_n U_n。

（2）から（1）。Y を完備距離空間、X = \bigcap_n U_n（U_n 開）とする。新しい距離を

d(x,y) = \rho(x,y) + \sum_{n=1}^{\infty} \min\Big( 2^{-n},\ \Big| \tfrac{1}{\rho(x, Y\setminus U_n)} - \tfrac{1}{\rho(y, Y\setminus U_n)} \Big| \Big)

と定める。d-コーシー列は \rho-コーシーであり、しかも各 U_n の境界に近づけない——近づくと第二項が発散するからである。よって極限が X のなかに留まる。

（3）から（2）は自明である。

完備距離化できる空間、できない空間

できる。\mathbb{R}、(0,1)（\mathbb{R} と同相）、無理数全体（G_\delta）、コンパクト距離空間、バナッハ空間、\mathbb{R} の開集合と閉集合。

できない。\mathbb{Q}。\mathbb{R} のなかで G_\delta でないからである（第27章）。

同じ理由で、\mathbb{Q} と同相な空間（可算で孤立点をもたない距離空間はすべて \mathbb{Q} と同相——シェルピンスキの定理）はどれも完備距離化できない。

チェック完備性

は距離空間の話だった。一般のチコノフ空間に拡張する。

チェック完備空間

チコノフ空間 X がチェック完備であるとは、X がストーン–チェックのコンパクト化 \beta X のなかで G_\delta であることをいう。

（1）この条件は \beta X に依らない。どのコンパクト化について G_\delta でも同じことである。
（2）コンパクトハウスドルフ空間と、局所コンパクトハウスドルフ空間はチェック完備である。
（3）距離化可能な空間について、チェック完備であることと完備距離化可能であることは同値である。
（4）チェック完備な空間はベール空間である。

（2）コンパクトなら \beta X = X で、X は自分のなかで開（したがって G_\delta）。局所コンパクトなら X は \beta X で開である——一点コンパクト化への潰す写像を考えればよい。

（3）は と、距離化可能空間の完備化がコンパクト化に埋め込めることによる。

（4）が重要である。証明は第27章のベールの定理の構成を、\beta X のコンパクト性を使って行う。X = \bigcap_n V_n（V_n は \beta X で開）とし、稠密開集合の列に沿って \beta X のなかで入れ子のコンパクト集合を作る。各段で V_n のなかに収まるようにすれば、交叉が X のなかに落ちる。

（4）が第27章のベールの定理を統一する。完備距離空間と局所コンパクトハウスドルフ空間は、どちらもチェック完備である。二つの別々に見えた定理が、一つの条件の帰結だった。

保存

（1）チェック完備性は G_\delta 部分空間に遺伝する。とくに開部分空間と閉部分空間に遺伝する。
（2）可算個のチェック完備空間の積はチェック完備である。
（3）一般の部分空間には遺伝しない。非可算積では保たれない。

（1）Y が X で G_\delta、X が \beta X で G_\delta なら、Y は \beta X で G_\delta である（Y = X \cap \bigcap_n W_n と書いて交叉をとる）。\beta Y が \beta X の閉部分集合として得られることを使う。

（2）X_k = \bigcap_n V_{k,n} とすると \prod_k X_k = \bigcap_{k,n} p_k^{-1}(V_{k,n}) であり、添字の対 (k,n) は可算である。可算個の積でしか成り立たないのは、この数え上げが可算でなければならないからである。

（3）\mathbb{Q} は \mathbb{R} の部分空間でチェック完備でない。

ポーランド空間

可分かつ完備距離化可能な空間をポーランド空間という。解析学で出会う空間のほとんどがこれである。

例。\mathbb{R}^n、コンパクト距離空間、可分バナッハ空間、[0,1]^{\mathbb{N}}、\mathbb{N}^{\mathbb{N}}（無理数全体と同相）、\{0,1\}^{\mathbb{N}}（カントール集合）。

性質。ポーランド空間は次を満たす。

ベール空間である（（4））。G_\delta 部分空間はポーランド。可算積はポーランド。第二可算（可分＋距離化可能、第7章）。

普遍性。どのポーランド空間も、ヒルベルト立方体 [0,1]^{\mathbb{N}} の G_\delta 部分空間と同相である。第31章の埋め込みと を合わせればよい。

さらに、空でないポーランド空間はすべて \mathbb{N}^{\mathbb{N}} の連続像である。ベール空間 \mathbb{N}^{\mathbb{N}} がポーランド空間の「もと」になる。

なぜこの枠組みが有用か。三つの理由がある。

第一に、ベール性が保証される。第IX部の関数解析の基本定理が使える。

第二に、ボレル階層が整った形になる。第52章で導入するボレル集合の理論は、ポーランド空間でもっとも完全な形をとる。

第三に、測度論との相性がよい。ポーランド空間上の有限ボレル測度は正則（内部からコンパクト集合で、外部から開集合で近似できる）になり、第59章のリースの表現定理が使いやすい形で成り立つ。

標準ボレル空間。ポーランド空間のボレル構造だけを取り出したものを標準ボレル空間という。驚くべきことに、非可算な標準ボレル空間はすべて同型である。

すなわち、\mathbb{R}、[0,1]、\mathbb{N}^{\mathbb{N}}、\{0,1\}^{\mathbb{N}} は、ボレル構造としては区別がつかない。位相としてはまったく違う（コンパクトかどうか、連結かどうか）のに、可測構造では同じである。

第54章で可測関数を扱うとき、この事実が背景にある。測度論は位相の情報の多くを見ていない。

ベール性はチェック完備性より真に弱い

（4）の逆は成り立たない。ベール空間だがチェック完備でない空間がある。この落差に何があるのかを見る。

反例。\mathbb{R} のなかで、ベルンシュタイン集合を取る。どの非可算閉集合とも交わり、どの非可算閉集合も含まない集合である。超限帰納法で構成できる（\mathbb{R} の閉集合は 2^{\aleph_0} 個しかないことを使う）。

ベルンシュタイン集合 B とその補集合はどちらもベール空間になるが、どちらもチェック完備でない——G_\delta 集合は非可算なら非可算閉集合を含むからである。

もっと自然な例。関数解析にも現れる。無限次元バナッハ空間の稠密な真部分空間は、ベール空間でないことが多い。だが位相群のなかには、ベールだが完備化できないものがある。

ベール性を保証する条件の階層。チェック完備性とベール性のあいだに、いくつもの条件がある。

擬完備——減少する空でない開集合の列で、各段の閉包が次に含まれるものの交叉が空でない。

チェック完備——本章の条件。

完備距離化可能——距離化可能な場合のチェック完備。

\text{完備距離化可能} \implies \text{チェック完備} \implies \text{擬完備} \implies \text{ベール}

どの逆も成り立たない。ベール性は結論であって、それ自体は構造を与えない。

ゲームによる特徴づけ。ベール性は無限ゲームで特徴づけられる。二人が交互に空でない開集合を選び、U_1 \supseteq V_1 \supseteq U_2 \supseteq \cdots と縮めていく。交叉が空でなければ一方の勝ち、空なら他方の勝ち。

バナッハ–マズール Banach–Mazur のゲームという。X がベール空間であることと、一方のプレイヤーが勝つ戦略をもたないことが同値である。

擬完備性は、もう一方のプレイヤーが勝つ戦略をもつことに対応する。「負けない」と「勝てる」の差が、ベール性と擬完備性の差である。

この種の特徴づけは決定性の公理とも関係する。第4章★★★で触れた独立性の話題が、ここにも接続する。本書はこの方向に進まないが、ベール性が「構造」ではなく「結論」であることは押さえておく価値がある。
