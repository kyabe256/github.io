この章の問い

  • 上限は最大値とどう違うのか。なぜ最大値では足りないのか。
  • 上限をとる操作は、和や積とどう噛み合うのか。
  • 上極限・下極限は、何のためにあるのか。

最大値では足りない

第43章で、完備性を「上に有界なら上限がある」という形で述べた。なぜ「最大値がある」ではないのか。

開区間 (0,1) には最大値がない。それでも「1 より上には行けない」という情報はある。その情報を数にしたのが上限である。

上限・下限

S \subseteq \mathbb{R} を空でない集合とする。s \in \mathbb{R} が S の上限であるとは、

（1）どの x \in S についても x \le s（上界である）。
（2）どの t < s についても x > t なる x \in S がある（最小の上界である）。

これを \sup S と書く。下限 \inf S も同様。S が上に有界でないとき \sup S = +\infty と約束する。

（2）は実際の計算でこう使う。s = \sup S なら、どの \varepsilon > 0 についても x > s - \varepsilon なる x \in S がある。「いくらでも上限に近い元が取れる」——これが上限の使い方のほとんどすべてである。

いくつかの上限

\sup (0,1) = 1（最大値なし）。\sup [0,1] = 1（最大値あり）。

\sup \{\, 1 - 1/n \mid n \in \mathbb{N} \,\} = 1。\sup \{\, q \in \mathbb{Q} \mid q^2 < 2 \,\} = \sqrt{2}。

\sup \varnothing は定めない（あるいは -\infty と約束する）。\inf S = -\sup(-S) なので、上限だけ扱えば十分である。

上限と演算

A, B \subseteq \mathbb{R} を空でない上に有界な集合とする。

（1）\sup(A+B) = \sup A + \sup B（A+B = \{a+b\}）。
（2）c > 0 なら \sup(cA) = c \sup A。c < 0 なら \sup(cA) = c \inf A。
（3）A \subseteq B なら \sup A \le \sup B。
（4）\sup(A \cup B) = \max(\sup A, \sup B)。

（1）\le。a + b \le \sup A + \sup B だから右辺は上界。

\ge。\varepsilon > 0 に対し a > \sup A - \varepsilon/2、b > \sup B - \varepsilon/2 を取れば a+b > \sup A + \sup B - \varepsilon。\varepsilon が任意なので不等式が出る。

（2）（3）（4）も同じ形の議論。上限の証明は、つねに「上界であること」と「\varepsilon だけ下げれば届く元があること」の二本立てになる。

積では等号にならない

\sup(AB) = \sup A \cdot \sup B は一般に成り立たない。

A = B = \{-2, 1\} とすると \sup A = \sup B = 1 だが AB = \{4, -2, 1\} で \sup(AB) = 4。

負の数が入ると、大きい値どうしの積が最大になるとは限らない。A, B \subseteq [0,\infty) なら等号が成り立つ。

単調列

単調収束定理

上に有界な単調増加列 (x_n) は収束し、\lim_n x_n = \sup_n x_n。下に有界な単調減少列も同様。

s = \sup_n x_n とおく。\varepsilon > 0 に対し、上限の定義から x_N > s - \varepsilon なる N がある。

単調性より n \ge N で s - \varepsilon < x_N \le x_n \le s。よって |x_n - s| < \varepsilon。

この定理は、極限の値を知らなくても収束が言えるという点で強力である。「増えていて、上に押さえがある」だけで収束する。第49章の正項級数の議論は、ほとんどこの定理で動く。

上極限と下極限

収束しない数列にも、何か言えることはあるか。x_n = (-1)^n は収束しないが、値が -1 と 1 のあいだを動くことはわかる。

上極限・下極限

有界な数列 (x_n) について

\limsup_n x_n = \lim_{N \to \infty} \sup_{n \ge N} x_n, \qquad \liminf_n x_n = \lim_{N \to \infty} \inf_{n \ge N} x_n

と定める。右辺の \sup_{n \ge N} x_n は N について単調減少で下に有界なので、 により極限が存在する。

有界数列 (x_n) について、

（1）\liminf_n x_n \le \limsup_n x_n。
（2）(x_n) が収束することと、両者が一致することは同値であり、そのとき極限に等しい。
（3）\limsup_n x_n は、(x_n) の部分列の極限のうち最大のものである。

（1）\inf_{n \ge N} x_n \le \sup_{n \ge N} x_n で N \to \infty。

（2）一致して値を L とすると、N を大きく取れば L - \varepsilon < \inf_{n\ge N} x_n \le x_n \le \sup_{n \ge N} x_n < L + \varepsilon。逆は定義から明らか。

（3）L = \limsup x_n とおく。各 k について |x_{n_k} - L| < 1/k なる n_k が（増加するように）取れるので、L は部分列の極限。逆に部分列の極限 M について M \le \sup_{n \ge N} x_n がすべての N で成り立つので M \le L。上極限は「集積点のうち最大のもの」である。

上極限の不等式と、等号が崩れる場所

上極限は不等式としては扱いやすいが、等号はめったに成り立たない。どこで崩れるかを見ておく。

劣加法性。有界数列 (x_n), (y_n) について

\limsup_n (x_n + y_n) \le \limsup_n x_n + \limsup_n y_n

証明は \sup_{n \ge N}(x_n+y_n) \le \sup_{n \ge N} x_n + \sup_{n \ge N} y_n で N \to \infty。

等号が崩れる例。x_n = (-1)^n、y_n = (-1)^{n+1} とすると左辺は 0、右辺は 2。二つの数列が「逆位相で振動する」と、和の振動が消える。

片方が収束すれば等号。(y_n) が収束するなら \limsup(x_n+y_n) = \limsup x_n + \lim y_n。収束列は上限をとる操作と可換である。

下極限との関係。\liminf_n(x_n+y_n) \ge \liminf x_n + \liminf y_n。上極限は劣加法的、下極限は優加法的。向きが逆になる。

積について。非負の数列なら \limsup(x_n y_n) \le (\limsup x_n)(\limsup y_n)。負の値が入ると と同じ理由で崩れる。

なぜ不等式で十分なのか。解析の多くの場面で、示したいのは「極限が存在して値が L」ではなく「\limsup \le L かつ \liminf \ge L」である。二つを挟めば収束が出る。不等式を二本立てて挟む——これが上極限の標準的な使い方である。

実例。第49章のコーシー–アダマールの公式 1/R = \limsup_n |a_n|^{1/n} は、|a_n|^{1/n} が収束しなくても収束半径を与える。収束を仮定せずに値が定まるところに、上極限の意味がある。

上限・下限の一般化——束と、順序位相

上限と下限は、実数に固有の概念ではない。順序があれば定義できる。

完備束。半順序集合 P が完備束であるとは、任意の部分集合が上限と下限をもつことをいう。\mathbb{R} は完備束ではない——空集合と非有界集合で破れる。[-\infty, +\infty] にすれば完備束になる。

第6章の位相の全体（ある集合上の位相をなす族）は、包含について完備束である。第7章で「生成される位相」を扱ったのは、この束の上限を取る操作だった。

タルスキの不動点定理。完備束 L 上の単調写像 f は不動点をもち、不動点の全体もまた完備束になる。証明は \sup\{\, x \mid x \le f(x) \,\} が不動点であることを確かめるだけである。上限を取る操作が、不動点を生む。

方向づけられた集合と上極限。第12章のネットを使うと、上極限は

\limsup_{n} x_n = \inf_{N} \sup_{n \ge N} x_n

という「下向きの族の下限」として書ける。一般のネット (x_\lambda)_{\lambda \in \Lambda} についても同じ式で定義できる。

ムーア–スミス収束との関係。第12章で、位相空間の収束は点列では足りずネットが要ると見た。上極限・下極限は、順序があるおかげで「収束しなくても値が決まる」代用品である。一般の位相空間には、これにあたるものがない。

バナッハ極限。有界数列の空間 \ell^\infty 上に、線型で、平行移動で不変で、\liminf \le \Lambda(x) \le \limsup を満たす汎関数 \Lambda が存在する。これは第67章のハーン–バナッハの定理から出る。

\Lambda は収束列では極限に一致し、(-1)^n には 0 を与える。「振動する数列に無理やり極限を与える」操作が、選択公理に依存する形で存在する。第67章で構成を見る。
