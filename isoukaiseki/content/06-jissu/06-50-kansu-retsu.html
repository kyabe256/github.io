この章の問い

  • 関数列の極限で、何が保たれ何が壊れるのか。
  • 「極限と極限の交換」は、いつ許されるのか。
  • 第VI部で足りなくなったものは何か。

保存の表を作る

第19章で、位相的性質が部分空間・積・連続像で保たれるかを表にした。同じことを、関数列の収束について行う。

各点収束で壊れるもの

連続性。f_n(x)=x^n は [0,1] で不連続な関数に収束する（第47章）。

有界性。f_n = n\mathbf{1}_{(0,1/n)} は各点で 0 に収束するが、各 f_n は最大値 n を取る。

積分。同じ例で \int_0^1 f_n = 1 だが \int_0^1 0 = 0。

微分可能性。f_n(x) = \sqrt{x^2+1/n} は |x| に一様収束する。各 f_n は滑らかだが、極限は 0 で微分できない。

一様収束でも微分可能性は保たれない。

何が保たれるか

f_n \to f とする。

（1）各点収束で保たれる——可測性（第54章）、ボレル可測性。
（2）一様収束で保たれる——連続性、一様連続性、有界性、有界区間上のリーマン可積分性と積分値。
（3）一様収束でも保たれない——微分可能性、無限区間上の積分値。
（4）導関数の一様収束を仮定すれば保たれる——微分可能性と導関数（第48章★★）。

極限の交換

関数列の問題は、ほとんどすべて「二つの極限を交換してよいか」という形に書ける。

交換の四つの場面

連続性　\lim_{x\to a}\lim_n f_n(x) = \lim_n \lim_{x\to a} f_n(x)。

積分　\int \lim_n f_n = \lim_n \int f_n。

微分　\frac{d}{dx}\lim_n f_n = \lim_n \frac{d}{dx}f_n。

二重級数　\sum_m \sum_n a_{mn} = \sum_n \sum_m a_{mn}。

どれも「極限と極限を入れ替える」である。一様収束は、この交換を許す十分条件の一つにすぎない。

二重極限の定理

a_{mn} について、各 m で \lim_n a_{mn} = b_m、各 n で \lim_m a_{mn} = c_n が存在するとする。収束の一方が m について一様なら、

\lim_m b_m = \lim_n c_n

が存在して一致する。

\lim_n a_{mn}=b_m が m について一様とする。\varepsilon>0 に対し |a_{mn}-b_m|<\varepsilon/3（すべての m、n \ge N）なる N を取る。

(b_m) がコーシー列であること。|b_m - b_{m'}| \le |b_m - a_{mN}| + |a_{mN}-a_{m'N}| + |a_{m'N}-b_{m'}|。両端は \varepsilon/3 以下、中央は \lim_m a_{mN}=c_N から m,m' を大きくすれば \varepsilon/3 以下。

よって b = \lim_m b_m が存在する。同様の三分割で \lim_n c_n = b も出る。

「一様」が要るのは、三分割の両端を添字によらず押さえるためである。第47章の連続性の証明とまったく同じ構造である。

一様性がないと結論は破れる。a_{mn} = \frac{m}{m+n} とすると \lim_n a_{mn}=0、\lim_m a_{mn}=1。順序を変えると 0 と 1 になる。

一様収束では足りない場面

一様収束が強すぎる、弱すぎる

強すぎる例。f_n = \mathbf{1}_{[0,1/n]} は [0,1] 上で各点収束するが一様収束しない。それでも \int f_n = 1/n \to 0 = \int 0 で、積分は交換できる。

一様収束は、積分の交換には必要でない。

弱すぎる例。f_n = \frac{1}{n}\mathbf{1}_{[0,n]} は \mathbb{R} 上で 0 に一様収束するが \int f_n = 1。

一様収束は、無限区間での積分の交換には十分でない。一様収束は、積分と極限の交換について必要でも十分でもない。

では何が正しい条件か

第55章の優収束定理がそれである。f_n \to f がほとんどいたるところ各点収束し、|f_n| \le g（g は可積分）なら \int f_n \to \int f。

上の二例で確かめる。強すぎる例では |f_n| \le 1（[0,1] 上で可積分）なので、優収束定理が使えて交換できる。弱すぎる例では、f_n を押さえる可積分関数がない（\sup_n f_n = 1/n 上の階段で、積分が発散する）。

「一様に近い」ではなく「一様に押さえられる」が正しい条件だった。第VII部で測度を導入するのは、この定理に到達するためである。

一様収束より弱い収束

各点収束と一様収束のあいだに、いくつもの収束概念がある。第VIII部以降で使うものを、ここで名前だけ挙げておく。

広義一様収束（コンパクト一様収束）。各コンパクト部分集合の上で一様収束すること。f_n(x)=x^n は (-1,1) で広義一様収束する。

第89章以降の複素解析では、これが標準的な収束概念になる。正則関数の列が広義一様収束すれば、極限も正則で、導関数も広義一様収束する（ワイエルシュトラスの定理）。実解析での「微分は保たれない」が、複素では逆転する。

平均収束。\int|f_n-f| \to 0。第60章の L^1 収束である。

f_n = n\mathbf{1}_{(0,1/n)} は各点収束するが平均収束しない。逆に f_n = \mathbf{1}_{[k/2^m,(k+1)/2^m]} を並べた「動く窓」の列は、平均収束するが各点収束しない。各点収束と平均収束は、どちらも他方を含まない。

測度収束。どの \varepsilon>0 についても \mu(\{|f_n-f|>\varepsilon\}) \to 0。平均収束すれば測度収束する。

測度収束する列は、ほとんどいたるところ収束する部分列をもつ。動く窓の例で、実際に部分列を取れば各点収束する。

エゴロフの定理。有限測度の集合上で f_n \to f がほとんどいたるところ収束するなら、どの \varepsilon>0 についても測度 \varepsilon 未満の集合を除けば一様収束する。

「ほとんど一様収束」が、各点収束からほぼ無料で出る。第54章で示す。この定理が、各点収束と一様収束の距離を測っている。

まとめ。一様収束はもっとも強く、扱いやすいが、実際の解析では強すぎることが多い。第VIII部で、各収束概念に対応する関数空間の位相を導入する。

関数空間の位相と、第VI部の限界

第VI部で扱った収束は、すべて関数空間の位相として記述できる。そう見ると、何が足りなかったかがはっきりする。

各点収束は積位相。\mathbb{R}^X = \prod_{x \in X}\mathbb{R} の積位相での収束が、各点収束である。第11章で「積位相は各座標の収束」と述べたことの、そのままの応用である。

この位相は、X が非可算なら第一可算でない（第37章）。だから点列では位相を記述できず、ネット（第12章）が要る。

一様収束はノルム位相。\|f\|_\infty = \sup_x|f(x)| が定める距離での収束である。X がコンパクトなら C(X) はバナッハ空間（第63章）。

広義一様収束はコンパクト開位相。第95章で扱う。X が局所コンパクト \sigma-コンパクトなら、可算個の半ノルムで距離化できる。

足りなかったもの——完備性と、コンパクト性。

第VI部で作れたのは C[a,b] と、一様ノルムである。この空間は完備だが、単位球がコンパクトでない。無限次元ノルム空間では、閉単位球がコンパクトになることはない（リースの補題、第63章）。

したがって第46章の最大値の定理が、関数空間では使えない。「最良近似が存在するか」「汎関数が最大値を取るか」という問いに、答えられない。

三つの解決。第VII部以降は、この壁を三方向から崩す。

第一に、測度と収束定理（第VII部）。一様収束より弱い条件で極限が扱えるようにする。

第二に、弱位相（第70章）。位相を弱くして、単位球をコンパクトにする（バナッハ–アラオグルの定理、第71章）。

第三に、同程度連続性（第95章）。関数族に条件を課して、一様ノルムでコンパクトな集合を特徴づける（アスコリ–アルツェラの定理）。

第VI部で見た「極限の交換ができない」という現象は、ここまでの道具では関数空間がコンパクトでないことの現れだった。残る十一の部は、この一点をめぐって展開する。

演習

基本
  1. f_n = n\mathbf{1}_{(0,1/n)} の各点極限を求め、積分が交換しないことを確かめよ。
  2. a_{mn}=\frac{m}{m+n} で二つの反復極限を計算し、一致しないことを示せ。
  3. f_n(x)=\sqrt{x^2+1/n} が |x| に一様収束することを示せ。
  4. f_n(x)=x^n が (-1,1) で広義一様収束することを示せ。
証明
  1. の \lim_n c_n = b の部分を示せ。（25点）
  2. 一様収束する連続関数列の極限について、\lim_{x\to a}\lim_n f_n = \lim_n\lim_{x\to a}f_n を から導け。（25点）
  3. 各点収束するが平均収束しない列、平均収束するが各点収束しない列をそれぞれ作れ。（30点）
  4. 広義一様収束が、ある距離による収束として書けることを、X=\mathbb{R} の場合に示せ。（30点）
