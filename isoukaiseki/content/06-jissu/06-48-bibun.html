この章の問い

  • 微分は「接線の傾き」以上の何を表しているのか。
  • 平均値の定理は、なぜあれほど多くの結果を生むのか。
  • 導関数は、どこまで自由な関数になれるのか。

微分は一次近似である

微分可能性

f が a の近傍で定義されているとする。f が a で微分可能であるとは、

f'(a) = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}

が存在することをいう。

言い換え

同値な言い方がある。ある数 c があって

f(a+h) = f(a) + ch + o(h) \qquad (h \to 0)

と書けること。ここで o(h) は o(h)/h \to 0 を意味する。微分可能とは「一次関数でよく近似できる」ことである。

この形は高次元へそのまま拡張できる（c を線型写像に置き換える）。商の形のほうは拡張できない——ベクトルで割れないからである。

微分可能なら連続である。逆は成り立たない。

f(a+h)-f(a) = f'(a)h + o(h) \to 0。逆の反例は f(x)=|x|（a=0）。

平均値の定理

ロルの定理

f が [a,b] で連続、(a,b) で微分可能、f(a)=f(b) なら、f'(\xi)=0 なる \xi \in (a,b) が存在する。

f が定数なら明らか。そうでないなら、最大値の定理（）より f は [a,b] で最大値と最小値を取り、少なくとも一方は端点以外で取られる。

その点を \xi とする。\xi が最大値を与えるとすると、h>0 で \frac{f(\xi+h)-f(\xi)}{h} \le 0、h<0 で \ge 0。両側の極限が一致するので f'(\xi)=0。

平均値の定理

f が [a,b] で連続、(a,b) で微分可能なら

f(b)-f(a) = f'(\xi)(b-a)

なる \xi \in (a,b) が存在する。

g(x) = f(x) - \frac{f(b)-f(a)}{b-a}(x-a) とおくと g(a)=g(b)=f(a)。 を g に使えばよい。

なぜこれが効くのか

平均値の定理は局所的な情報（導関数）を大域的な情報（増分）に変換する。「各点で傾きがわかれば、二点間の差がわかる」——これが解析の基本的な橋渡しである。

コンパクト性（最大値の存在）を使っていることに注意する。有界閉区間でないと、この橋は架からない。

平均値の定理から出るもの

導関数がゼロなら定数。f'\equiv 0（区間上）なら f(x)-f(y) = f'(\xi)(x-y) = 0。区間でないと成り立たない——定義域が二つに分かれていれば、別々の定数になりうる。

単調性の判定。f' > 0 なら狭義単調増加。f' \ge 0 なら単調増加。

リプシッツ評価。|f'| \le M なら |f(x)-f(y)| \le M|x-y|。よって一様連続（第47章）。

テイラーの定理。コーシーの平均値定理を繰り返すと、剰余項つきのテイラー展開が出る。

テイラーの定理（ラグランジュの剰余）

f が [a,x] で n 回連続微分可能、(a,x) で n+1 回微分可能なら

f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}

なる \xi が a と x のあいだに存在する。

導関数はどこまで自由か

ダルブーの定理

f が [a,b] で微分可能なら、f' は中間値性をもつ。すなわち f'(a) と f'(b) のあいだのどの値も f' は取る。

f'(a) < c < f'(b) とし、g(x) = f(x)-cx とおく。g'(a)<0。

g は [a,b] で最小値を取る。g'(a)<0 より a の右側で g が減るので、最小は a でない。g'(b)>0 より同様に b でない。

よって最小は内点 \xi で取られ、g'(\xi)=0 すなわち f'(\xi)=c。

第46章★★で述べたダルブー関数が、ここで出た。導関数は連続でなくてよいが、中間値性は必ずもつ。

したがって跳びのある関数は導関数になれない。たとえば \mathbf{1}_{[0,\infty)} は、どんな関数の導関数でもない。

連続でない導関数

f(x) = x^2 \sin(1/x)（x \ne 0）、f(0)=0 とする。

f'(0) = \lim_{h\to 0} h\sin(1/h) = 0。x \ne 0 では f'(x) = 2x\sin(1/x) - \cos(1/x)。

x \to 0 で \cos(1/x) が振動するので、f' は 0 で連続でない。それでも f' は中間値性をもつ——振動しながら、すべての値を取り続ける。

関数列の微分と、微分と極限の交換

第47章で、一様収束は微分を保たないと述べた。正しい仮定を置き直す。

定理。(f_n) を [a,b] 上の微分可能関数の列とし、

（1）ある点 x_0 で (f_n(x_0)) が収束する、
（2）(f_n') が [a,b] で一様収束する

とすると、(f_n) は一様収束し、極限 f は微分可能で f' = \lim_n f_n'。

証明の骨子。まず (f_n) が一様コーシーであることを示す。f_m - f_n に平均値の定理を使うと

|(f_m-f_n)(x) - (f_m-f_n)(x_0)| \le |x-x_0| \cdot \sup_t |f_m'(t)-f_n'(t)|

となり、右辺は（2）から小さくできる。x_0 での収束（1）と合わせて一様コーシー。

次に微分可能性。\varphi_n(t) = \frac{f_n(t)-f_n(x)}{t-x} とおくと、同じ評価から (\varphi_n) は t について一様コーシー。一様収束する連続関数列の極限で、t \to x の極限と n \to \infty の極限が交換できる。

仮定を導関数の側に置いたことで、平均値の定理が使えるようになった。これが要点である。

系——項別微分。級数 \sum f_n について、\sum f_n' が一様収束し \sum f_n(x_0) が収束すれば、\left(\sum f_n\right)' = \sum f_n'。第49章の冪級数で使う。

どこまで弱められるか。ルベーグ積分を使うと、もっと弱い仮定で交換できる。f_n \to f 各点収束、|f_n'| \le g（g 可積分）なら、f はほとんどいたるところ微分可能で f' = \lim f_n' がほとんどいたるところ成り立つ。

「すべての点で」を「ほとんどすべての点で」に弱めると、仮定が格段に軽くなる。これが第VII部の主題である。

いたるところ微分不可能な関数と、導関数の集合

ワイエルシュトラス関数。

W(x) = \sum_{n=0}^{\infty} a^n \cos(b^n \pi x) \qquad (0 1 + \tfrac{3}{2}\pi)

は \mathbb{R} 上で連続だが、どの点でも微分可能でない。一八七二年の構成である。

一様収束（\sum a^n < \infty）から連続性が出る。微分不可能性は、b が大きいと各段の振動が前段を打ち消せないことによる。

典型的である。バナッハ（一九三一）は、C[0,1]（一様ノルム）のなかでどこかで微分可能な関数の全体は第一類集合（痩せた集合）であることを示した。

証明はベールのカテゴリー定理（第27章）による。「微分できる関数のほうが例外である」——連続関数の空間ではそうなっている。

どの集合が導関数の不連続点になれるか。f' は第一級ベール関数（連続関数の各点極限）である。実際 f'(x) = \lim_n n(f(x+1/n)-f(x))。

第一級ベール関数の不連続点の全体は、第一類集合かつ F_\sigma 集合である。したがって導関数はどこかで連続——それも稠密な集合の上で連続である。

の f' は一点でだけ不連続だった。不連続点を稠密にすることもできるが、余集合をなくすことはできない。

単調関数の微分可能性。ルベーグの定理——単調関数は、ほとんどいたるところ微分可能である。証明にはヴィタリの被覆定理が要る（第53章）。

これは強い主張である。単調性という順序だけの条件から、測度論的な結論が出る。第46章★★で「単調関数の不連続点は可算」と述べたのと同じ構図で、順序の条件が解析的な結論を生んでいる。

有界変動関数。単調関数の差として書ける関数を有界変動という。ジョルダン分解により、有界変動関数はほとんどいたるところ微分可能。第57章のハーン–ジョルダン分解は、これを測度について述べたものである。

ただし微分した結果をもとに戻せるとは限らない——カントール関数（第53章）は連続・単調で、導関数がほとんどいたるところ 0 なのに、0 から 1 まで増える。微積分の基本定理が破れる例である。第58章のラドン–ニコディムの定理が、破れる条件を確定させる。
