この章の問い

  • どんな測度が「密度をもつ」のか。
  • 絶対連続と特異は、どう分けられるのか。
  • 微積分の基本定理は、測度の言葉でどう書けるのか。

絶対連続と特異

絶対連続・特異

\mu,\nu を (X,\mathcal{A}) 上の測度（\nu は符号付でもよい）とする。

\nu が \mu について絶対連続（\nu\ll\mu）であるとは、\mu(A)=0 \implies \nu(A)=0 が成り立つことをいう。

\nu と \mu が互いに特異（\nu\perp\mu）であるとは、X=A\sqcup B で |\nu|(A)=0、\mu(B)=0 となる分解があることをいう。

三つの例

絶対連続。\nu(A)=\int_A f\,d\lambda。\lambda(A)=0 なら積分も 0。

特異（離散）。ディラック測度 \delta_0(A)=\mathbf{1}_A(0)。\lambda(\{0\})=0 だが \delta_0(\{0\})=1。

特異（連続）。カントール関数 \varphi（第53章）の定める測度 \nu_\varphi((a,b])=\varphi(b)-\varphi(a)。台はカントール集合で \lambda(C)=0。しかし一点の測度はどこでも 0。

特異には、点に集中する型と、測度零の連続体に広がる型がある。

ε-δ による言い換え

\nu が有限測度なら、\nu\ll\mu であることと

\forall\varepsilon>0\ \exists\delta>0\ \forall A\ \big(\mu(A)<\delta \implies |\nu|(A)<\varepsilon\big)

は同値である。

\Leftarrow。\mu(A)=0 ならどの \delta でも \mu(A)<\delta、よって |\nu|(A)<\varepsilon がすべての \varepsilon で成り立つ。

\Rightarrow。対偶。ある \varepsilon について、各 n で \mu(A_n)<2^{-n} かつ |\nu|(A_n)\ge\varepsilon なる A_n がある。A=\limsup_n A_n とおくと、ボレル–カンテリの補題（第54章★★★）より \mu(A)=0。一方 |\nu| が有限なので測度の連続性より |\nu|(A)\ge\varepsilon>0。

「絶対連続」という名が、この \varepsilon-\delta の形に由来する。

ラドン–ニコディムの定理

ラドン–ニコディムの定理

\mu,\nu を σ-有限測度とし、\nu\ll\mu とする。このとき非負可測関数 f がただ一つ（ほとんどいたるところの差を除いて）存在して

\nu(A)=\int_A f\,d\mu \qquad (A\in\mathcal{A})

と書ける。この f を \dfrac{d\nu}{d\mu} と書き、ラドン–ニコディム導関数という。

有限測度の場合を示す（σ-有限の場合は分けて貼り合わせる）。

候補の集合。\mathcal{F}=\{\, g\ge0 \text{ 可測} \mid \forall A,\ \int_A g\,d\mu \le \nu(A) \,\} とおく。0\in\mathcal{F} なので空でない。

束になっている。g,h\in\mathcal{F} なら \max(g,h)\in\mathcal{F}。A を \{g>h\} と \{g\le h\} に分けて足せばよい。

上限を取る。\alpha=\sup_{g\in\mathcal{F}}\int_X g\,d\mu \le \nu(X)<\infty。\int g_n\to\alpha なる列を取り、h_n=\max(g_1,\ldots,g_n)\in\mathcal{F}、f=\lim_n h_n とおく。

単調収束定理より \int_A f = \lim_n\int_A h_n \le \nu(A) で f\in\mathcal{F}、かつ \int_X f=\alpha。

等号であること。\nu_0(A)=\nu(A)-\int_A f\,d\mu とおく。これは測度で \nu_0 \ll \mu。\nu_0\ne0 と仮定する。

\nu_0(X)>0 なので \nu_0(X)-\varepsilon\mu(X)>0 なる \varepsilon>0 が取れる。符号付測度 \nu_0-\varepsilon\mu にハーンの分解（）を適用し、正集合 P を得る。

\mu(P)>0 である。もし \mu(P)=0 なら \nu_0\ll\mu より \nu_0(P)=0、すると \nu_0(X)-\varepsilon\mu(X)=(\nu_0-\varepsilon\mu)(P)+(\nu_0-\varepsilon\mu)(X\setminus P)\le0+0 で矛盾。

すると f+\varepsilon\mathbf{1}_P \in \mathcal{F}——\int_A(f+\varepsilon\mathbf{1}_P) = \int_A f + \varepsilon\mu(A\cap P) \le \int_A f + \nu_0(A\cap P) \le \nu(A)。ところが \int_X(f+\varepsilon\mathbf{1}_P)=\alpha+\varepsilon\mu(P)>\alpha で \alpha の定義に反する。

一意性。\int_A f=\int_A g がすべての A で成り立てば、A=\{f>g\} と取って \int_A(f-g)=0、f-g>0 より \mu(A)=0。逆も同様。

証明はハーンの分解を一度だけ使う。「もし足りないなら、足りない部分が正になる場所がある」——そこで f を持ち上げられる、という論法である。

σ-有限性が要るのは、上限 \alpha を有限に保つためである。外すと定理は破れる（後述）。

ルベーグの分解定理

\mu,\nu を σ-有限測度とする。\nu は

\nu = \nu_{\mathrm{ac}} + \nu_{\mathrm{s}}, \qquad \nu_{\mathrm{ac}}\ll\mu,\quad \nu_{\mathrm{s}}\perp\mu

と一意に分解される。

\rho=\mu+\nu とおくと \mu\ll\rho、\nu\ll\rho。 より \mu=\int g\,d\rho、\nu=\int h\,d\rho と書ける。

B=\{g=0\}、A=X\setminus B=\{g>0\} とおく。\mu(B)=\int_B g\,d\rho=0。

\nu_{\mathrm{s}}(E)=\nu(E\cap B)、\nu_{\mathrm{ac}}(E)=\nu(E\cap A) とおく。\nu_{\mathrm{s}}\perp\mu は \mu(B)=0 から。

\nu_{\mathrm{ac}}\ll\mu。\mu(E)=0 なら \int_E g\,d\rho=0、E\cap A で g>0 なので \rho(E\cap A)=0、よって \nu(E\cap A)=0。

微積分の基本定理

測度論版の微積分の基本定理

F \colon [a,b]\to\mathbb{R} について、次は同値である。

（1）F は絶対連続——どの \varepsilon>0 についても \delta>0 があって、互いに交わらないどの有限個の区間 (a_k,b_k) についても \sum_k(b_k-a_k)<\delta \implies \sum_k|F(b_k)-F(a_k)|<\varepsilon。
（2）ある f\in L^1[a,b] があって F(x)=F(a)+\int_a^x f\,d\lambda。

このとき F はほとんどいたるところ微分可能で F'=f ほとんどいたるところ。

三つの水準

絶対連続 \Rightarrow 有界変動 \Rightarrow ほとんどいたるところ微分可能。逆はどちらも成り立たない。

カントール関数は連続・単調（したがって有界変動）でほとんどいたるところ微分可能だが、絶対連続でない。だから F(b)-F(a)=\int_a^b F' が破れる。

第53章で「微積分の基本定理が破れる」と述べたのは、ルベーグ分解で特異部分が残っているということだった。

実数直線上の測度の三分解

\mathbb{R} 上の有限測度 \nu は

\nu = \nu_{\mathrm{ac}} + \nu_{\mathrm{pp}} + \nu_{\mathrm{sc}}

と一意に分かれる。絶対連続部分（密度をもつ）、純点部分（可算個の点に集中）、特異連続部分（カントール型）。

第76章以降のスペクトル理論で、作用素のスペクトルがこの三つに分類される。絶対連続スペクトルは散乱、純点スペクトルは束縛状態、特異連続スペクトルは中間的な現象に対応する。

σ-有限性の必要性と、連鎖律

σ-有限性が要る。X=[0,1]、\mu＝数え上げ測度、\nu=\lambda（ルベーグ測度）とする。

\mu(A)=0 \iff A=\varnothing なので \nu\ll\mu。ところが \nu(A)=\int_A f\,d\mu=\sum_{x\in A}f(x) と書けたとすると、一点集合について 0=\nu(\{x\})=f(x)、よって \nu=0 で矛盾。

密度が存在しない。\mu が σ-有限でないことが原因である。

連鎖律。\nu\ll\mu\ll\rho（すべて σ-有限）なら

\frac{d\nu}{d\rho} = \frac{d\nu}{d\mu}\cdot\frac{d\mu}{d\rho} \qquad \rho\text{-ほとんどいたるところ}

証明は単関数から単調収束定理で上げる標準的な手順。

同値な測度。\nu\ll\mu かつ \mu\ll\nu のとき \mu\sim\nu（同値）と書く。このとき \frac{d\nu}{d\mu}>0 ほとんどいたるところで、\frac{d\mu}{d\nu}=\big(\frac{d\nu}{d\mu}\big)^{-1}。

同値な測度は「零集合が同じ」測度である。確率論では、測度変換（ギルサノフの定理）がこの形をしている。

変数変換。T \colon X\to Y 可測、\mu を X 上の測度とすると、像測度 T_*\mu(B)=\mu(T^{-1}B) が定まる。

\int_Y g\,d(T_*\mu) = \int_X g\circ T\,d\mu

単関数で確かめて単調収束定理で上げる。\mathbb{R}^n の滑らかな変換については \frac{d(T_*\lambda)}{d\lambda}=|\det DT^{-1}| となり、重積分の変数変換公式がラドン–ニコディム導関数として現れる。

条件つき期待値。\mathcal{B}\subseteq\mathcal{A} を部分 σ-加法族、f\in L^1(\mu) とする。\nu(B)=\int_B f\,d\mu（B\in\mathcal{B}）は \mu|_{\mathcal{B}} について絶対連続なので、密度 \mathbb{E}[f\mid\mathcal{B}]=\frac{d\nu}{d\mu|_{\mathcal{B}}} が定まる。

確率論の中心概念である条件つき期待値は、ラドン–ニコディムの定理の直接の帰結である。

微分定理と、極大関数

の「F'=f ほとんどいたるところ」は、次の定理の系である。

ルベーグの微分定理。f\in L^1_{\mathrm{loc}}(\mathbb{R}^n) について、ほとんどすべての x で

\lim_{r\to0}\frac{1}{\lambda(B(x,r))}\int_{B(x,r)}f\,d\lambda = f(x)

さらに ほとんどすべての x で \lim_{r\to0}\frac{1}{\lambda(B(x,r))}\int_{B(x,r)}|f-f(x)|\,d\lambda=0（ルベーグ点）。

証明の道具——ハーディ–リトルウッドの極大関数。

Mf(x) = \sup_{r>0}\frac{1}{\lambda(B(x,r))}\int_{B(x,r)}|f|\,d\lambda

弱 (1,1) 評価。\lambda(\{Mf>t\}) \le \frac{C_n}{t}\|f\|_1。

証明はヴィタリ型の被覆補題（第53章★★）を使う。\{Mf>t\} の各点に半径 r_x の球を取り、互いに交わらない部分族を選んで 3 倍に膨らませると全体を覆える。

微分定理の証明。連続関数については明らか。一般の f については、\|f-g\|_1<\varepsilon なる連続関数 g を取り（C_c が L^1 で稠密、第62章）、極大関数の評価で誤差を押さえる。

「稠密な部分集合で成り立つ主張を、極大関数の評価で全体へ運ぶ」——調和解析の基本的な論法である。第83章のカルレソンの定理も、同じ骨格をもつ。

極大関数の L^p 評価。1 について \|Mf\|_p \le C_{n,p}\|f\|_p。弱 (1,1) と L^\infty の自明な評価を、マルチンキェヴィチの補間定理でつなぐ。

p=1 では成り立たない。Mf\in L^1 となるのは f=0 のときだけである——Mf(x)\ge C/|x|^n（|x| 大）となるから。

密度点。可測集合 E について f=\mathbf{1}_E に微分定理を適用すると、ほとんどすべての x\in E で \lambda(E\cap B(x,r))/\lambda(B(x,r))\to1。

「可測集合は、ほとんどすべての点で局所的に全体に見える」。この事実（ルベーグの密度定理）は、第53章のヴィタリの非可測集合の議論を別の角度から説明する——非可測集合は、密度が 0 でも 1 でもない点をどこにでももつ。
