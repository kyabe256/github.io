この章の問い

  • リーマン積分はどこまで通用し、どこで行き詰まるのか。
  • 可積分な関数は、どういう関数なのか。
  • 行き詰まりを解くには、何を取り替えればよいのか。

リーマン積分の定義を確認する

リーマン積分

f \colon [a,b] \to \mathbb{R} を有界とする。分割 P \colon a = x_0 < \cdots < x_n = b に対し

\underline{S}(f,P) = \sum_{k} \Big(\inf_{[x_{k-1},x_k]} f\Big)\Delta x_k, \qquad \overline{S}(f,P) = \sum_{k} \Big(\sup_{[x_{k-1},x_k]} f\Big)\Delta x_k

とおく。\sup_P \underline{S} = \inf_P \overline{S} のとき f はリーマン可積分であるといい、その値を \int_a^b f と書く。

定義に現れるのは区間の長さだけである。「定義域を区間に切り、各区間での値の幅を見る」——これがリーマン積分の設計である。

この設計が、あとで見る限界の原因になる。切り方が区間に縛られているからである。

リーマンの可積分条件

有界な f がリーマン可積分であることと、どの \varepsilon > 0 についても

\overline{S}(f,P) - \underline{S}(f,P) < \varepsilon

なる分割 P が存在することは同値である。

可積分な関数

（1）連続関数はリーマン可積分。
（2）単調関数はリーマン可積分。
（3）有界変動関数はリーマン可積分。
（4）有界な f がリーマン可積分であることと、f の不連続点の集合が測度零であることは同値である（ルベーグの判定条件）。

（1）第47章のハイネ–カントールの定理より f は一様連続。\varepsilon/(b-a) に対する \delta を取り、幅 \delta 未満の分割を使えば \overline{S}-\underline{S} < \varepsilon。

（2）単調増加なら \overline{S}-\underline{S} = \sum_k (f(x_k)-f(x_{k-1}))\Delta x_k \le \max_k \Delta x_k \cdot (f(b)-f(a))。等分割で幅を小さくすればよい。

（3）有界変動なら二つの単調関数の差（第48章★★★）なので（2）から。

（4）は測度を定義してから示す（第53章★★）。

四つの行き詰まり

第一——極限が可積分でない

[0,1] \cap \mathbb{Q} = \{q_1, q_2, \ldots\} と番号づけ、f_n = \mathbf{1}_{\{q_1,\ldots,q_n\}} とおく。

各 f_n は有限個の点でだけ 1 なのでリーマン可積分で \int f_n = 0。ところが各点極限は f = \mathbf{1}_{\mathbb{Q}\cap[0,1]}（ディリクレ関数）であり、これはリーマン可積分でない。

実際、どの分割でも \overline{S} = 1、\underline{S} = 0。単調増加する可積分関数の列の極限が、可積分にならない。

第二——可積分関数の空間が完備でない

リーマン可積分関数の全体に \|f\|_1 = \int_0^1|f|（正確には半ノルム）を入れる。

の (f_n) はこのノルムでコーシー列（\|f_m-f_n\|_1 = 0）だが、極限がこの空間にない——というより、極限の候補がすべてノルム零の関数に見えてしまう。

完備でない空間では、第63章以降の関数解析が何も始まらない。

第三——微積分の基本定理が完全でない

f が微分可能で f' が有界でも、f' がリーマン可積分とは限らない。

ヴォルテラの構成により、f' の不連続点が測度正になる例が作れる。そのとき （4）より f' はリーマン可積分でなく、\int_a^b f' = f(b)-f(a) という式が書けない。

「微分してから積分すると戻る」が、リーマン積分の枠では言えない場合がある。

第四——定義域が区間でないと使えない

リーマン積分の定義は、定義域を区間に切ることに依存している。

そのため、円周上の関数、無限次元空間上の関数、確率空間上の関数には、そのままでは適用できない。第83章のフーリエ解析、第VIII部の関数空間、確率論はどれも、区間でない台の上で積分を必要とする。

何を取り替えるか

切り方を変える

リーマン積分は定義域を縦に切る。ルベーグ積分は値域を横に切る。

値 y のあたりを取る点の集合 \{\, x \mid y \le f(x) < y + \Delta y \,\} を考え、その集合の「大きさ」に y をかけて足す。

この集合は区間ではない——一般には、とても複雑な集合になる。だから「区間でない集合の大きさ」を先に定義しなければならない。

それが測度である。第52章で構成する。

測度零

N \subseteq \mathbb{R} が測度零であるとは、どの \varepsilon > 0 についても可算個の区間 I_1, I_2, \ldots で

N \subseteq \bigcup_k I_k, \qquad \sum_k |I_k| < \varepsilon

となるものが取れることをいう。

測度零の例

可算集合。N = \{a_1,a_2,\ldots\} なら I_k = (a_k - \varepsilon 2^{-k-1}, a_k + \varepsilon 2^{-k-1}) と取れば長さの和は \varepsilon。

カントール集合。可算でないのに測度零である。第 n 段で長さ (2/3)^n の区間が残り、これが 0 に行く。

「小さい」の意味が、濃度と測度で食い違う。第53章で詳しく見る。

ダルブー積分・リーマン和・広義積分

は上和と下和で書いた。これはダルブーの定式化である。リーマン自身の定義とは形が違う。

リーマン和による定義。分割 P と各小区間の代表点 \xi_k \in [x_{k-1},x_k] に対し S(f,P,\xi) = \sum_k f(\xi_k)\Delta x_k とおく。分割の幅 |P| = \max_k \Delta x_k を 0 にしたとき、代表点の取り方によらず極限が存在することを可積分性とする。

二つは同値。\underline{S} \le S(f,P,\xi) \le \overline{S} であり、\inf_\xi S = \underline{S}、\sup_\xi S = \overline{S}。上和・下和は、代表点を最悪に取ったリーマン和である。

ダルブーの形が扱いやすいのは、単調性（分割を細かくすると上和は減り下和は増える）がはっきり見えるからである。

広義積分。\int_0^1 x^{-1/2}dx や \int_1^\infty x^{-2}dx は、有界性か有界区間性が破れているのでリーマン積分の定義が直接使えない。極限で定義する。

\int_0^1 x^{-1/2}dx = \lim_{\epsilon \to 0^+}\int_\epsilon^1 x^{-1/2}dx = 2

広義積分の落とし穴。\int_0^\infty \frac{\sin x}{x}dx = \pi/2 は収束するが、\int_0^\infty \left|\frac{\sin x}{x}\right|dx = \infty。条件収束する級数（第49章）と同じ状況である。

ルベーグ積分は絶対可積分を基本にするので、この関数はルベーグ可積分でない。広義リーマン積分にできてルベーグ積分にできないことが、ここだけある。

第49章で述べたとおり、可算加法性を成り立たせるには絶対収束が要る。ルベーグ積分は収束定理を得る代わりに、条件収束型の積分を手放している。

補う方法。主値積分として扱うか、第87章の超関数として扱う。実際に解析で必要なのは、後者のほうである。

リーマン積分を救う道——ヘンストック–クルツヴァイル積分

行き詰まりのうち第三（微積分の基本定理）だけは、測度論を使わずに解決できる。分割の「幅」の測り方を変えればよい。

定義。\delta \colon [a,b] \to (0,\infty) を任意の正値関数（ゲージ）とする。タグつき分割 \{([x_{k-1},x_k], \xi_k)\} が \delta-細かいとは、各 k で

[x_{k-1},x_k] \subseteq (\xi_k - \delta(\xi_k),\ \xi_k + \delta(\xi_k))

が成り立つことをいう。f がヘンストック–クルツヴァイル可積分であるとは、ある A があって、どの \varepsilon>0 についてもゲージ \delta が取れて、\delta-細かいどのタグつき分割についても |S(f,P,\xi)-A| < \varepsilon となることをいう。

リーマン積分の \delta を定数から関数に変えただけである。第45章の言葉でいえば、\delta が点に依存してよくなった——一様性を捨てたのである。

何が得られるか。三つある。

第一に、微積分の基本定理が無条件で成り立つ。f が [a,b] で微分可能なら f' はこの意味で可積分で \int_a^b f' = f(b)-f(a)。 が解消する。

第二に、ルベーグ可積分な関数はすべてこの意味で可積分で、値も一致する。さらに \int_0^\infty \frac{\sin x}{x}dx のような条件収束型も扱える。ルベーグ積分より真に広い。

第三に、単調収束定理と優収束定理も成り立つ。 も解消する。

ではなぜ標準にならないのか。三つ理由がある。

第一に、絶対値を取ると可積分でなくなることがある。|f| が可積分でない可積分関数がある（\sin x / x がそれ）。したがって \|f\|_1 = \int|f| がノルムにならず、第60章の L^1 空間が作れない。第VIII部以降の関数解析が立たない。

第二に、一般の測度空間へ一般化しにくい。ゲージの定義が区間の構造を使うので、 が残る。確率論には使えない。

第三に、測度論が積分以外にも要る。ハウスドルフ次元、確率測度、表現定理（第59章）——どれも測度そのものを対象にする。積分を作るためだけに測度を導入するのではない。

まとめ。ヘンストック–クルツヴァイル積分は、一次元の微積分としてはルベーグ積分より優れている。だが完備な関数空間を与えないので、解析の土台にはならない。本書は第52章から測度を構成する。
