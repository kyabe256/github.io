この章の問い

  • 二つの測度空間の積に、どう測度を入れるのか。
  • 重積分と逐次積分は、いつ一致するのか。
  • σ-有限性を外すと、何が壊れるのか。

積測度を作る

積 σ-加法族と積測度

(X,\mathcal{A},\mu)、(Y,\mathcal{B},\nu) を測度空間とする。

矩形とは A\times B（A\in\mathcal{A}、B\in\mathcal{B}）の形の集合をいう。矩形の全体が生成する σ-加法族を \mathcal{A}\otimes\mathcal{B} と書く。

\mathcal{A}\otimes\mathcal{B} 上の測度 \mu\times\nu で (\mu\times\nu)(A\times B)=\mu(A)\nu(B) を満たすものを積測度という。

積測度の存在と一意性

\mu,\nu が σ-有限なら、積測度は存在してただ一つである。

矩形の有限個の互いに交わらない合併の全体は有限加法族をなし、その上で \mu_0(A\times B)=\mu(A)\nu(B) は前測度になる（第52章★★）。可算加法性は、矩形を可算個の矩形に分けたときの （5）から出る。

カラテオドリの拡張定理（）で測度が得られ、σ-有限性から一意である。

切り口

E \subseteq X\times Y に対し、x-切り口を E_x = \{\, y \mid (x,y)\in E \,\}、y-切り口を E^y = \{\, x \mid (x,y)\in E \,\} と書く。

E\in\mathcal{A}\otimes\mathcal{B} なら、すべての x について E_x\in\mathcal{B}。証明は「切り口が可測な集合の全体」が σ-加法族で矩形を含むことによる。

切り口の測度

\mu,\nu を σ-有限とし、E\in\mathcal{A}\otimes\mathcal{B} とする。このとき x\mapsto\nu(E_x) は可測で

(\mu\times\nu)(E) = \int_X \nu(E_x)\,d\mu(x) = \int_Y \mu(E^y)\,d\nu(y)

有限測度の場合。\mathcal{D} を「主張が成り立つ E の全体」とする。矩形については \nu((A\times B)_x)=\mathbf{1}_A(x)\nu(B) なので成り立つ。

\mathcal{D} が λ 系（全体を含み、差と増加列の極限で閉じる）であることを確かめる。増加列については測度の連続性と単調収束定理、差については有限性を使った引き算。

矩形の全体は π 系（有限交叉で閉じる）なので、ディンキンの補題より \mathcal{D} \supseteq \sigma(\text{矩形}) = \mathcal{A}\otimes\mathcal{B}。

σ-有限の場合は、有限測度の部分に分けて単調収束定理でつなぐ。

トネリとフビニ

トネリの定理

\mu,\nu を σ-有限、f \colon X\times Y \to[0,\infty] を \mathcal{A}\otimes\mathcal{B}-可測とする。このとき

\int_{X\times Y} f\,d(\mu\times\nu) = \int_X\Big(\int_Y f(x,y)\,d\nu(y)\Big)d\mu(x) = \int_Y\Big(\int_X f(x,y)\,d\mu(x)\Big)d\nu(y)

が成り立つ（値が \infty でもよい）。

f=\mathbf{1}_E の場合が 。線型性から単関数の場合が出る。

一般の非負可測 f については で s_n\uparrow f を取り、単調収束定理を三か所（内側の積分・外側の積分・左辺）で使う。

フビニの定理

同じ設定で、f が \mu\times\nu について可積分とする。このとき

（1）ほとんどすべての x について y\mapsto f(x,y) は \nu-可積分。
（2）x\mapsto\int_Y f(x,y)d\nu(y) は \mu-可積分。
（3）三つの積分がすべて一致する。

|f| に を使うと \int_X\big(\int_Y|f(x,y)|d\nu\big)d\mu<\infty。よって内側の積分はほとんどすべての x で有限——これが（1）。

f=f^+-f^- と分け、それぞれにトネリを使って引けばよい。

二つの定理の役割分担

トネリは「非負なら無条件に交換してよい」、フビニは「可積分なら交換してよい」。

実際の使い方はこうである。まず |f| にトネリを使って逐次積分を計算し、それが有限だと確かめる。そのうえで f にフビニを使う。

この二段構えが標準的な手順である。「可積分性は、絶対値の逐次積分で確かめる」——それがトネリの使いどころである。

可積分でないと交換できない

X=Y=[0,1]、

f(x,y)=\frac{x^2-y^2}{(x^2+y^2)^2} \qquad ((x,y)\ne(0,0))

とすると

\int_0^1\!\!\Big(\int_0^1 f\,dy\Big)dx = \frac{\pi}{4}, \qquad \int_0^1\!\!\Big(\int_0^1 f\,dx\Big)dy = -\frac{\pi}{4}

二つの逐次積分が違う値をもつ。\int\int|f| = \infty なので、フビニの仮定が満たされていない。

第49章のリーマンの再配列定理と同じ現象である——絶対収束しないものは、足す順序に依存する。

σ-有限性を外すと壊れる

X=Y=[0,1]、\mu=\lambda（ルベーグ測度）、\nu＝数え上げ測度（σ-有限でない）とする。

E=\{(x,x)\mid x\in[0,1]\}（対角線）について

\int_X \nu(E_x)\,d\mu = \int_0^1 1\,dx = 1, \qquad \int_Y \mu(E^y)\,d\nu = \int 0\,d\nu = 0

切り口の積分が一致しない。 が σ-有限性を要求する理由である。

完備化と積測度

完備性は積で保たれない

\lambda は完備だが、\lambda\times\lambda は \mathcal{M}\otimes\mathcal{M} 上では完備でない。

N\subseteq[0,1] を非可測とすると、\{0\}\times N \subseteq \{0\}\times[0,1] は測度零の集合の部分集合。ところが切り口が可測でないので \mathcal{M}\otimes\mathcal{M} に属さない。

\mathbb{R}^2 のルベーグ測度は、\lambda\times\lambda の完備化として定義する。

完備化版のフビニ

(X\times Y,\overline{\mathcal{A}\otimes\mathcal{B}},\overline{\mu\times\nu}) を完備化とする。f がこの意味で可積分なら、フビニの結論は「ほとんどすべての x について f(x,\cdot) は \nu-可測かつ可積分」という形で成り立つ。

「すべての x について可測」が「ほとんどすべての x について可測」に弱まる。

フビニの応用——畳み込み・分布関数・層の公式

層の公式。f\ge0 可測について

\int_X f\,d\mu = \int_0^\infty \mu(\{\, x \mid f(x)>t \,\})\,dt

証明は E=\{(x,t)\mid 0 にトネリを適用するだけ。

第51章で「値域を横に切る」と述べたことが、ここで厳密な等式になった。右辺の \mu(\{f>t\}) を分布関数という。

系。\int|f|^p\,d\mu = p\int_0^\infty t^{p-1}\mu(\{|f|>t\})\,dt。第60章の L^p ノルムの評価で繰り返し使う。

畳み込み。f,g \in L^1(\mathbb{R}) に対し

(f*g)(x) = \int_{\mathbb{R}} f(x-y)g(y)\,dy

とおく。トネリより

\int\!\!\int |f(x-y)g(y)|\,dy\,dx = \int |g(y)|\Big(\int|f(x-y)|dx\Big)dy = \|f\|_1\|g\|_1<\infty

（内側で平行移動不変性を使った）。よって f*g はほとんどすべての x で定義され、\|f*g\|_1\le\|f\|_1\|g\|_1。

フビニより f*g=g*f と結合律も出る。第86章の畳み込みの理論は、すべてここから始まる。

可測性の確認。(x,y)\mapsto f(x-y)g(y) が \mathcal{B}\otimes\mathcal{B}-可測であることは、(x,y)\mapsto x-y が連続、f がボレル可測であることから出る。ルベーグ可測なだけだと第54章★★の問題が生じるので、代表をボレル可測に取っておく。

面積としての積分。f\ge0 について、\mathbb{R}^2 のルベーグ測度で

\lambda_2\big(\{\,(x,y)\mid 0\le y\le f(x)\,\}\big) = \int f\,d\lambda

「グラフの下の面積が積分である」が、フビニの帰結として証明される。直観のほうが定理として出てくる——定義を積分から始めたからである。

フビニが成り立たない世界と、独立性

連続体仮説とフビニ。シェルピンスキの構成。連続体仮説を仮定すると、[0,1]^2 の集合 E で

ほとんどすべての x について E_x が可算（したがって測度零）、ほとんどすべての y について E^y の補集合が可算

となるものが作れる。[0,1] を \omega_1 で整列し、E=\{(x,y)\mid x \preceq y\} と取ればよい。

すると \int\nu(E_x)dx = 0、\int\mu(E^y)dy = 1。ただし E は可測でない—— と矛盾しない。

この E は「切り口はすべて可測なのに、全体が可測でない」集合である。フビニの逆（切り口の可測性から全体の可測性）は成り立たない。

独立性。「切り口がすべて可測で、二つの逐次積分が存在して一致するなら、全体は可測か」——この問いは公理系から決まらない。

連続体仮説のもとでは偽（上の構成）。マーティンの公理と連続体仮説の否定のもとでは、フビニ型の結論が可測性の仮定なしで成り立つ（フリードマン）。

第36章のスーリン問題、第53章★★★の射影可測性と、同じ独立性の構図である。

有限加法的測度での失敗。第52章で「有限加法性だけなら全部の集合に長さを与えられる」と述べた。そのような測度でフビニは成り立たない。

実際、平行移動不変な有限加法的測度 m について、m\times m の逐次積分は一般に交換できない。フビニは可算加法性に依存している。

無限次元の積。可算個の確率空間の積 \prod_n(X_n,\mathcal{A}_n,\mu_n) には、つねに積確率測度が存在する（イオネスク–トゥルチャの定理）。各 \mu_n が確率測度であることが効いている。

非可算個の積でも、確率測度なら存在する（コルモゴロフの拡張定理）。確率論が無限次元で動くのは、測度が有限だからである。

一方、\mathbb{R}^{\mathbb{N}} に「無限次元ルベーグ測度」は存在しない。平行移動不変で、単位立方体の測度が正で有限な測度は作れない——単位立方体が、可算無限個の合同な小立方体に分割できてしまうからである。

第87章のガウス測度は、この困難を「平行移動不変性を捨てる」ことで回避している。
