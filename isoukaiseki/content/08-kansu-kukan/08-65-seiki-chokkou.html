この章の問い

  • 無限次元で「基底」とは何を意味するのか。
  • なぜ係数は内積で書けるのか。
  • パーセヴァルの等式は、何を保存しているのか。

無限次元の基底

二種類の基底

ハメル基底——線型代数の意味の基底。どの元も有限個の一次結合で一意に書ける。選択公理で存在するが、無限次元バナッハ空間では非可算（ベールのカテゴリー定理から）。解析には使えない。

シャウダー基底——どの元も無限級数として一意に書ける。収束が関わるので、位相に依存する概念である。

ヒルベルト空間では、直交性のおかげで話が格段に簡単になる。

正規直交系

\{e_i\}_{i\in I}\subseteq H が正規直交系であるとは、\langle e_i,e_j\rangle = \delta_{ij} を満たすことをいう。

さらに \overline{\mathrm{span}}\{e_i\} = H のとき完全（正規直交基底）であるという。

ベッセルの不等式

\{e_i\}_{i\in I} を正規直交系とすると、どの x\in H についても

\sum_{i\in I}|\langle x,e_i\rangle|^2 \ \le\ \|x\|^2

とくに \langle x,e_i\rangle\ne0 なる i は高々可算個である。

有限部分集合 F\subseteq I について、y=\sum_{i\in F}\langle x,e_i\rangle e_i とおく。

0 \le \|x-y\|^2 = \|x\|^2 - \sum_{i\in F}|\langle x,e_i\rangle|^2

F について上限を取ればよい。

可算性。\{\,i \mid |\langle x,e_i\rangle|>1/n\,\} は高々 n^2\|x\|^2 個。その可算合併だから、非零の係数は高々可算個。

この「高々可算」が効いている。正規直交系がどんなに大きくても、一つの元を展開するのに使うのは可算個だけである。

第35章の言葉でいえば、ヒルベルト空間の指標が可算であることの現れである。

完全性の特徴づけ

パーセヴァルの等式

\{e_i\}_{i\in I} を正規直交系とすると、次は同値である。

（1）\{e_i\} は完全（\overline{\mathrm{span}}\{e_i\}=H）。
（2）\langle x,e_i\rangle=0（\forall i）ならば x=0。
（3）どの x についても x = \sum_{i}\langle x,e_i\rangle e_i（無条件収束）。
（4）どの x についても \|x\|^2 = \sum_i |\langle x,e_i\rangle|^2（パーセヴァルの等式）。
（5）どの x,y についても \langle x,y\rangle = \sum_i \langle x,e_i\rangle\overline{\langle y,e_i\rangle}。

（1）から（2）。x\perp e_i なら x\perp\overline{\mathrm{span}}\{e_i\}=H、とくに x\perp x。

（2）から（3）。 より \sum_i|\langle x,e_i\rangle|^2<\infty なので、部分和はコーシー列（直交性からピタゴラスの定理が使える）。完備性より収束して y=\sum_i\langle x,e_i\rangle e_i が定まる。

\langle x-y,e_j\rangle = \langle x,e_j\rangle - \langle x,e_j\rangle = 0 なので（2）より x=y。

（3）から（4）。ノルムの連続性と、部分和でのピタゴラスの定理。

（4）から（1）。M=\overline{\mathrm{span}}\{e_i\} とし、x\in M^\perp とすると（4）より \|x\|^2=0。 より M=H。

（3）と（5）は、内積の連続性で行き来する。

何が保存されているか

パーセヴァルの等式は、展開がノルムを保つことをいう。

つまり x\mapsto(\langle x,e_i\rangle)_i は H から \ell^2(I) への等距離同型である。

ピタゴラスの定理の無限版と読める。第85章のプランシュレルの定理は、この等式のフーリエ変換版である。

ヒルベルト空間の分類

どのヒルベルト空間にも正規直交基底が存在し、その濃度は基底の取り方によらない（ヒルベルト次元）。

二つのヒルベルト空間がユニタリ同型であることと、ヒルベルト次元が等しいことは同値である。

存在。正規直交系の全体を包含で順序づけ、ツォルンの補題（第3章）を使う。極大な正規直交系は完全である（（2））。

濃度の一意性。\{e_i\}_{i\in I}、\{f_j\}_{j\in J} を二つの基底とする。各 i について \langle e_i,f_j\rangle\ne0 なる j は高々可算個で、どの j もある i とは非零の内積をもつ（そうでなければ f_j=0）。よって |J|\le|I|\cdot\aleph_0。

無限次元なら |J|\le|I|、対称に |I|\le|J|。有限次元は線型代数。

同型。基底どうしを対応させる線型写像を延ばせば、パーセヴァルの等式から等距離になる。

可分なヒルベルト空間は、すべて \ell^2 と同型である。

第61章★★で述べた L^p の可分性より、L^2(\mathbb{R}^n)、L^2[0,1]、\ell^2 はすべて同じ空間である。

「関数の空間」と「数列の空間」が同じものだという事実は、一九〇七年にリースとフィッシャーが示した。当時これは驚きをもって受け取られた。第80章のフーリエ級数が、その同型を具体的に与える。

正規直交基底の例

三角関数系。L^2(\mathbb{T}) で \{e^{inx}/\sqrt{2\pi}\}_{n\in\mathbb{Z}}。完全性は第62章★★★のストーン–ワイエルシュトラスから出る。第80章で扱う。

ルジャンドル多項式。L^2[-1,1] で \{1,x,x^2,\ldots\} をグラム–シュミットしたもの。

エルミート関数。L^2(\mathbb{R}) で H_n(x)e^{-x^2/2}。フーリエ変換の固有関数である（第85章）。

ハール系。L^2[0,1] で、階段関数からなる基底。ウェーブレットの原型である。

標準基底。\ell^2 で e_n=(0,\ldots,0,1,0,\ldots)。

最良近似と、部分和の最適性

正規直交系による展開には、近似としての最適性がある。

定理。\{e_1,\ldots,e_N\} を正規直交系、M=\mathrm{span}\{e_1,\ldots,e_N\} とすると

\min_{y\in M}\|x-y\| = \Big\|x-\sum_{k\le N}\langle x,e_k\rangle e_k\Big\|

すなわち、部分和がちょうど M への直交射影である。

証明。y=\sum c_ke_k とすると

\|x-y\|^2 = \|x\|^2 - \sum_k|\langle x,e_k\rangle|^2 + \sum_k|c_k-\langle x,e_k\rangle|^2

第三項を 0 にするのが最善——係数はフーリエ係数に取るしかない。

最小二乗法。この事実が、統計と数値解析の最小二乗法そのものである。「データへの最良近似は、直交射影で与えられる」。

フーリエ級数の部分和。L^2(\mathbb{T}) で S_Nf = \sum_{|n|\le N}\hat f(n)e^{inx} は、次数 N 以下の三角多項式のなかで f に最も近い。

そして完全性から \|f-S_Nf\|_2\to0。L^2 ではフーリエ級数が必ず収束する——第80章以降で見るとおり、これは L^2 に特有の恵まれた事情である。

各点収束とは別物。L^2 収束は各点収束を意味しない（第61章）。各点でどうなるかは、第81章から第83章の主題である。

無条件収束。（3）の収束は無条件である——並べ替えても同じ極限になる。

第49章★★★で「無限次元バナッハ空間では無条件収束と絶対収束が一致しない」と述べた。ヒルベルト空間の直交展開は、まさにその例である——\sum\|\langle x,e_i\rangle e_i\|=\sum|\langle x,e_i\rangle| は発散しうる。

フレームとリース基底——直交性を緩める

正規直交基底は理想的だが、実際の応用では作りにくいことがある。条件を緩めた概念がある。

リース基底。\{f_i\} が、ある有界可逆作用素 T によって正規直交基底の像 f_i=Te_i と書けるもの。展開の一意性は保つが、直交性を失う。

A\|x\|^2 \le \sum_i|\langle x,f_i\rangle|^2 \le B\|x\|^2 \qquad (0

フレーム。上の不等式だけを要求し、一次独立性すら要求しないもの。冗長な「基底もどき」である。

フレームがあれば、双対フレーム \{\tilde f_i\} が存在して

x = \sum_i \langle x,f_i\rangle \tilde f_i = \sum_i \langle x,\tilde f_i\rangle f_i

展開は一意でないが、安定した再構成ができる。

なぜ冗長性が役立つのか。係数の一部が失われても復元できる。通信路の誤りやノイズに強い。ウェーブレット、ガボール解析、圧縮センシングはすべてこの枠組みを使う。

バリアン–ロウの定理。ガボール系 \{e^{2\pi ibnx}g(x-am)\} が ab=1 でリース基底になるとき、g は「時間と周波数の両方で良い減衰」をもてない——

\Big(\int x^2|g|^2\Big)\Big(\int \xi^2|\hat g|^2\Big) = \infty

不確定性原理（第85章）の、基底についての版である。冗長にすれば（ab<1）この制約は消える——フレームを使う実質的な理由の一つである。

ヒルベルト空間以外では。バナッハ空間にシャウダー基底が存在するかは長らく未解決だった。エンフロの反例（一九七三年）により、存在しない可分バナッハ空間があることがわかった。

これは近似性質（有限階作用素で恒等作用素を近似できるか）とも関わる。ヒルベルト空間では、直交射影のおかげで何の問題も起こらない。
