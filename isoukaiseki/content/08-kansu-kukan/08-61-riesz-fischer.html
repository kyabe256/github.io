  • なぜ完備性がそれほど大事なのか。
  • Lᵖ が完備であることは、測度論の何に支えられているのか。
  • ノルム収束と各点収束は、どうつながるのか。

完備性は何のためにあるか

第29章で、完備性は「コーシー列が収束すること」と定めた。なぜそれが要るのか。

完備性が与えるもの

極限の存在が無料になる。「収束先を知らなくても、近づいていれば収束する」——第44章の単調収束定理と同じ効き方である。

不動点定理が使える。縮小写像の原理（第29章）は完備性を要求する。微分方程式の解の存在は、ここから出る。

ベールのカテゴリー定理が使える。第27章の定理は完備距離空間で成り立つ。第IX部の三大定理（一様有界性・開写像・閉グラフ）は、すべてこれを土台にしている。

第51章で「リーマン可積分関数の空間が完備でない」と述べた。この章で、ルベーグ積分がその欠陥を埋めることを示す。

リース–フィッシャーの定理

リース–フィッシャーの定理

1\le p\le\infty について、L^p(\mu) は完備である。すなわちバナッハ空間である。

1\le p<\infty とする（p=\infty は後述）。

級数に置き換える。コーシー列 (f_n) から、\|f_{n_{k+1}}-f_{n_k}\|_p < 2^{-k} なる部分列を取る。部分列が収束すれば、コーシー列全体が同じ極限に収束する。

優関数を作る。g_K = \sum_{k=1}^{K}|f_{n_{k+1}}-f_{n_k}| とおくと、 より \|g_K\|_p \le \sum_{k}2^{-k} < 1。

g_K \uparrow g = \sum_{k=1}^{\infty}|f_{n_{k+1}}-f_{n_k}| なので、単調収束定理（）より \|g\|_p \le 1。

各点で収束する。\|g\|_p<\infty より g<\infty ほとんどいたるところ。その点では級数 f_{n_1}+\sum_k(f_{n_{k+1}}-f_{n_k}) が絶対収束する。

極限を f とおく（g=\infty の零集合では f=0 とする）。f は可測（（3））で、|f| \le |f_{n_1}|+g \in L^p。

ノルムで収束する。|f-f_{n_k}|^p \le (2(|f_{n_1}|+g))^p が可積分な優関数なので、優収束定理（）より \|f-f_{n_k}\|_p\to0。

もとの列も収束する。\|f-f_n\|_p \le \|f-f_{n_k}\|_p + \|f_{n_k}-f_n\|_p で、両項とも小さくできる。

証明の骨格

完備性は、単調収束定理と優収束定理の二つに支えられている。

すなわち可算加法性である（第55章）。リーマン積分で完備性が破れたのは、可算加法性に相当するものがなかったからだった。

部分列を取って級数に直すのは、ノルム空間の完備性を示すときの定型である。「絶対収束する級数が収束すれば完備」という同値条件を使っている（第63章）。

L^∞ の場合

L^\infty(\mu) も完備である。

コーシー列 (f_n) を取る。E_{m,n}=\{\,|f_m-f_n|>\|f_m-f_n\|_\infty\,\} は零集合で、E=\bigcup_{m,n}E_{m,n} も零集合。

X\setminus E の上では (f_n) が一様コーシー列なので、一様収束する（）。零集合を可算個ぶん除いておけるのが要点である。

ノルム収束と各点収束

部分列定理

f_n\to f が L^p で収束するなら、ほとんどいたるところ f に収束する部分列が存在する。

の証明で作った部分列がそれである。あるいはチェビシェフの不等式（）から測度収束が出て、第54章★★★の部分列定理を使ってもよい。

全体では各点収束しない

「動く窓」の列——[0,1] 上で、m=0,1,2,\ldots、k=0,\ldots,2^m-1 に対し \mathbf{1}_{[k2^{-m},(k+1)2^{-m}]} を辞書式に並べる。

この列は L^p で 0 に収束する（\|\cdot\|_p^p=2^{-m}\to0）が、どの点でも 0 と 1 を無限回ずつ取るので、各点収束しない。

部分列（各段の最初の窓だけ取る）を選べば、[0,1] のほとんどすべての点で 0 に収束する。

各点収束しても L^p 収束しない

f_n = n^{1/p}\mathbf{1}_{(0,1/n)} は各点で 0 に収束するが \|f_n\|_p = 1。

第50章の「背が伸びる」型である。優関数がないので、優収束定理が使えない。

Lᵖ が可分かどうか

完備性の次に効く性質が可分性（第7章）である。可算稠密集合があると、近似の議論が格段に扱いやすくなる。

定理。\mu を \mathbb{R}^n のルベーグ測度とすると、1\le p<\infty について L^p は可分である。L^\infty は可分でない。

可分性の証明。有理数の端点をもつ矩形の定義関数の、有理係数の有限一次結合。これは可算集合で、第62章の稠密性定理から L^p で稠密になる。

L^\infty が可分でない理由。\{\mathbf{1}_{[0,t]}\}_{t\in[0,1]} は非可算個の元からなり、互いの距離が 1。

距離 1 離れた非可算族があれば、可分でない——各元のまわりの半径 1/2 の球が互いに交わらず、稠密集合はそれぞれに点をもたねばならない。

第35章の言葉でいえば、L^\infty のセル数が非可算だということである。第VIII部の道具が、第V部の基数不変量と噛み合う場面である。

なぜ可分性が要るのか。三つある。

第一に、可算基底が取れる（第65章の正規直交基底、可分ヒルベルト空間の場合）。

第二に、弱位相が単位球上で距離化できる（第70章）。可分でないと、弱収束を点列で扱えない。

第三に、測度論的な議論が可算個の条件に帰着する。第54章のエゴロフ・ルジンの証明が、その典型だった。

一般の測度空間では。L^p(\mu) が可分であることと、\mathcal{A} が「可算生成 + 零集合」の意味で可分であることが同値になる。確率論で扱う標準的な空間（ポーランド空間上のボレル測度）は、すべてこれを満たす。

完備化という操作と、Lᵖ の抽象的な特徴づけ

完備化としての L^p。第62章で示すとおり、C_c(\mathbb{R}^n) は L^p（p<\infty）で稠密である。

したがって L^p(\mathbb{R}^n) は、C_c(\mathbb{R}^n) を \|\cdot\|_p で完備化したものにほかならない。

これは定義の別の入り口を与える。測度論を経由せず、「連続関数の空間を完備化したもの」として L^p を定義できる。ダニエル積分（第55章★★★）の立場である。

ただしその定義では、元が「関数」であることが自明でなくなる。完備化の元は抽象的なコーシー列の同値類にすぎない。測度論は、それが実際に関数（の同値類）だと教える。

バナッハ束としての特徴づけ。L^p は順序（ほとんどいたるところの大小）をもち、ノルムと順序が

|f|\le|g| \implies \|f\|_p\le\|g\|_p

で噛み合う。このような空間をバナッハ束という。第57章★★の M(X) も、その一例だった。

カクタニの表現定理。抽象 L^p 空間（\||f|+|g|\|^p=\|f\|^p+\|g\|^p（f\wedge g=0 のとき）を満たすバナッハ束）は、ある測度空間の L^p(\mu) と同型である。

「順序とノルムの噛み合い方」だけから、測度空間が復元される。第59章のリースの表現定理と同じ構図——構造から、それを実現する測度が出てくる。

等距離同型の分類。ラミの定理——p\ne2 のとき、L^p(\mu) から L^p(\nu) への全射等距離写像は、必ず「測度変換 \times 符号」の形をしている。

(Tf)(y) = h(y)\,f(\sigma(y))

p=2 だけが例外である——そこではユニタリ作用素が大量にあり、この形に限らない。

p=2 の特別さが、ここでも顔を出す。第64章で、その源が内積であることを見る。

同型かどうか。p\ne q なら L^p[0,1] と L^q[0,1] は同型でない。証明には、第70章の弱位相と、コティプ・タイプという幾何的な不変量が要る。

各 p が、本質的に違う空間を与えている。「関数の大きさ」の測り方を変えると、空間そのものが変わる。
