この章の問い

  • 凸集合は、どの点で決まるのか。
  • 「端点」は、どんな空間にも十分にあるのか。
  • 端点を知ると、何がわかるのか。

端点

端点と端面

C を凸集合とする。x\in C が端点であるとは、

x = \tfrac12(y+z), \ \ y,z\in C \qquad \Longrightarrow \qquad y=z=x

が成り立つことをいう。端点の全体を \mathrm{ext}\,C と書く。

F\subseteq C が端面であるとは、F が凸で、C の線分の内点が F に入るならその線分全体が F に入ることをいう。一点からなる端面が端点である。

端点の例

多面体。頂点が端点。線型計画法の基本定理——線型汎関数の最大値は頂点で取られる。

球（ヒルベルト空間）。球面のすべての点が端点。一様凸だから（第60章★★★）。

\ell^1 の単位球。端点は \{\pm e_n\} だけ。

c_0 の単位球。端点が一つもない。\|x\|_\infty\le1 なら x_n\to0 なので、大きい n の座標を動かせる。

L^1[0,1] の単位球。端点がない。f の台を二つに割って、それぞれを定数倍すればよい。

C[0,1] の単位球。端点は |f|\equiv1 なる f、すなわち実の場合 \pm1 の二つだけ。

端点が一つもない凸集合がある——コンパクトでなければ。

c_0 と L^1 の単位球は、閉で有界で凸だが、端点をもたない。これらは反射的でないので、弱コンパクトでもない（）。

クレイン–ミルマンの定理

クレイン–ミルマンの定理

X を局所凸ハウスドルフ空間、K\subseteq X を空でないコンパクト凸集合とする。このとき

K = \overline{\mathrm{conv}}\,(\mathrm{ext}\,K)

とくに \mathrm{ext}\,K\ne\varnothing。

第一段——端点の存在。K の空でないコンパクトな端面の全体を、逆包含で順序づける。

鎖 \{F_i\} の上限は \bigcap_i F_i。コンパクト集合の減少族なので空でない（有限交叉性、第20章）。ツォルンの補題より極小な端面 F が存在する。

F が一点であること。そうでなければ x\ne y\in F を取り、分離定理（）より \varphi で \mathrm{Re}\,\varphi(x)\ne\mathrm{Re}\,\varphi(y)。

F'=\{\,z\in F \mid \mathrm{Re}\,\varphi(z)=\max_F \mathrm{Re}\,\varphi \,\} は F の真の端面（コンパクト性より最大値が存在）。極小性に反する。

第二段——閉凸包が全体。C=\overline{\mathrm{conv}}(\mathrm{ext}\,K)\subseteq K。C\ne K と仮定し、x_0\in K\setminus C を取る。

分離定理より \varphi と \gamma があって \mathrm{Re}\,\varphi(x_0)>\gamma\ge\mathrm{Re}\,\varphi(c)（c\in C）。

F=\{\,z\in K \mid \mathrm{Re}\,\varphi(z)=\max_K\mathrm{Re}\,\varphi\,\} は空でないコンパクト端面で、C と交わらない。

第一段を F に適用すると F は端点をもつ。端面の端点は K の端点なので、C と交わり、矛盾。

二つの道具

コンパクト性（極小端面の存在と最大値の存在）と、分離定理（端面を作る）。

どちらもこの定理に不可欠である。コンパクトでない c_0 の単位球には端点がなく、局所凸でない L^p（p<1）には分離定理がない。

ミルマンの定理（部分的な逆）

K をコンパクト凸、A\subseteq K が \overline{\mathrm{conv}}\,A = K を満たすなら、\mathrm{ext}\,K \subseteq \overline{A}。

端点は「どうしても必要な点」である。どの生成集合も、端点をすべて（閉包の意味で）含まねばならない。

第59章★★★で M(X) の単位球の端点が \{\pm\delta_x\} だと述べた。ミルマンの定理より、確率測度の空間を生成する集合はディラック測度をすべて含む。

応用

クレイン–ミルマンの使い道

バナッハ–ストーンの定理。第59章★★★で述べたとおり、C(X)^* の単位球の端点が \{\pm\delta_x\} であることから、C(X)\cong C(Y) ならば X\cong Y が出る。

ストーンの表現定理。ブール代数が集合代数として表せることの証明に使う。

エルゴード分解。T-不変確率測度の全体はコンパクト凸で、その端点がエルゴード測度である。クレイン–ミルマンより、どの不変測度もエルゴード測度の「混合」として書ける。

反射的でない空間の判定。c_0 や L^1 の単位球に端点がないので、これらは他の空間の双対になりえない（双対の単位球は弱*コンパクトなので端点をもつ）。

双対になれない空間

E がノルム空間 F の双対 F^* と等距離同型なら、B_E は端点をもつ。

したがって c_0 と L^1[0,1] は、どのノルム空間の双対にもなれない。

B_{F^*} は弱*コンパクト（）で凸。(F^*,\text{弱*}) は局所凸ハウスドルフなので が使える。

ショケの定理——積分表示へ

クレイン–ミルマンの定理は「閉凸包」としか言わない。もっと精密に、積分として書けないか。

ショケの定理。K を局所凸空間の距離化可能なコンパクト凸集合とすると、どの x\in K についても \mathrm{ext}\,K 上の確率測度 \mu が存在して

\varphi(x) = \int_{\mathrm{ext}\,K}\varphi(e)\,d\mu(e) \qquad (\forall\varphi\in X^*)

が成り立つ（x は \mu の重心である、と書く）。

「端点の凸結合の極限」が、「端点上の測度による積分」になった。

距離化可能性が要るのは、\mathrm{ext}\,K がボレル集合になるためである（一般には G_\delta にすぎない）。距離化できない場合は、\mathrm{ext}\,K を含むベール集合の上の測度で述べる（ビショップ–ド・レーウ）。

一意性——ショケ単体。表示が一意になるのは、K が単体のときに限る。三角形では一意（重心座標）、正方形では一意でない（二つの対角線の交点として二通り）。

応用——完全単調関数。ベルンシュタインの定理。f \colon[0,\infty)\to\mathbb{R} が完全単調（(-1)^nf^{(n)}\ge0）なら

f(t) = \int_0^\infty e^{-ts}\,d\mu(s)

と書ける。\{e^{-ts}\} が端点であることを示し、ショケの定理を使う。

応用——正定値関数。ボホナーの定理。\mathbb{R} 上の連続正定値関数は、有限測度のフーリエ変換として書ける（第84章）。

正定値関数のなす凸集合の端点が \{e^{i\xi t}\} である。第XI部のフーリエ解析の基本定理が、凸性の言葉で説明される。

応用——エルゴード分解。 で触れた分解が、ショケの定理により積分表示になる。不変測度の空間はショケ単体なので、分解は一意である。

露出点・強端点と、微分可能性

端点よりも強い概念がある。

露出点。x\in C が露出点であるとは、ある \varphi\in X^* について \varphi が C の上で x だけで最大値を取ることをいう。

露出点は端点だが、逆は成り立たない——正方形に半円をつないだ図形の、接続点が反例になる。

ストラスチェヴィチの定理。コンパクト凸集合は、強露出点（最大化列が必ず収束する露出点）の閉凸包に等しい。

クレイン–ミルマンより強い結論である。

ラドン–ニコディム性との関係。第57章★★★でバナッハ空間のラドン–ニコディム性に触れた。

幾何的な特徴づけがある——E がラドン–ニコディム性をもつことと、どの有界閉凸集合も「切片」（\{x\in C : \varphi(x)>\alpha\}）をいくらでも小さい直径で取れることは同値。

さらにどの有界閉凸集合も強露出点をもつことと同値（ブールガン）。

c_0 と L^1[0,1] はこの性質をもたない。その単位球に端点がないことと、整合している。

ノルムの微分可能性との双対。E^* のノルムがフレシェ微分可能であることと、E のノルムが一様凸であることは（ほぼ）双対である。

より正確に——E^* のノルムがフレシェ微分可能なら E は反射的。E のノルムがガトー微分可能であることと、E^* が狭義凸（球面に線分が乗らない）であることは同値。

再ノルム化。可分なバナッハ空間には、ノルムを取り替えて狭義凸にできる（クリー）。反射的なら一様凸にできるか——これはエンフロの定理によりはい（超反射的な空間について）。

第60章★★★で「L^p は一様凸」と述べた。一般の反射的空間も、ノルムを取り替えれば同じ恩恵を受けられる。凸性の幾何が、関数解析の構造を決めている。
