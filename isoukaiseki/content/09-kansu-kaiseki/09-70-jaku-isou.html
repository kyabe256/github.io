この章の問い

  • 位相を弱めると、何が得られて何を失うのか。
  • 弱収束と強収束は、どこで食い違うのか。
  • 弱位相と弱*位相は、どう違うのか。

位相を弱める

第63章で、無限次元では閉単位球がコンパクトでないと見た。コンパクト性を取り戻す第一の道が、位相を弱めることである。

弱位相と弱*位相

E をノルム空間とする。

弱位相 \sigma(E,E^*)——すべての \varphi\in E^* を連続にする最弱の位相。第7章の始位相である。

弱*位相 \sigma(E^*,E)——E^* の上で、すべての評価写像 \varphi\mapsto\varphi(x)（x\in E）を連続にする最弱の位相。

近傍の形

弱位相の x_0 の基本近傍は

V(x_0;\varphi_1,\ldots,\varphi_n;\varepsilon) = \{\, x \mid |\varphi_k(x-x_0)|<\varepsilon \ (k=1,\ldots,n) \,\}

有限個の汎関数しか見ない。だから E が無限次元なら、どの弱近傍も無限次元の部分空間（\bigcap_k\ker\varphi_k）を含む。

したがって弱位相では、どの 0 の近傍も有界でない。第63章★★★のコルモゴロフの定理より、弱位相はノルムで定まらない。

第11章の積位相と同じ構造である。弱位相は、E を \mathbb{K}^{E^*} の部分空間と見たときの相対位相にほかならない。

基本性質

（1）弱位相はハウスドルフである（ハーン–バナッハの定理から）。
（2）弱位相 \subseteq ノルム位相。無限次元なら真に弱い。
（3）x_n \rightharpoonup x（弱収束）\iff すべての \varphi\in E^* で \varphi(x_n)\to\varphi(x)。
（4）弱収束列は有界で、\|x\|\le\liminf_n\|x_n\|（ノルムの弱下半連続性）。

（1）x\ne y なら （1）より \varphi(x)\ne\varphi(y) なる \varphi がある。

（4）有界性は （1）。下半連続性は、\|\varphi\|=1、\varphi(x)=\|x\| を取れば \|x\|=\lim\varphi(x_n)\le\liminf\|x_n\|。

下半連続性が重要

ノルムは弱連続でないが、弱下半連続である。

これが変分法の基礎になる——「最小化列が弱収束すれば、極限が最小値を与える」。第71章で、弱コンパクト性と合わせて使う。

弱収束の実際

弱収束するが強収束しない例

正規直交系。ヒルベルト空間で e_n\rightharpoonup0（ベッセルの不等式より \langle x,e_n\rangle\to0）だが \|e_n\|=1。

振動。f_n(x)=\sin(nx) は L^2[0,2\pi] で 0 に弱収束する（リーマン–ルベーグの補題、第84章）。

集中。f_n=n^{1/p}\mathbf{1}_{(0,1/n)} は L^p（1）で 0 に弱収束する。

平行移動。f_n(x)=f(x-n) は L^p(\mathbb{R})（1）で 0 に弱収束する。

弱収束が捉えられないのは「振動」「集中」「逃走」の三つである。第50章で見た積分と極限が交換しない三つの型と、同じ顔ぶれである。

ラドン–リースの性質

E が一様凸なら（第60章★★★）、

x_n\rightharpoonup x \ \ \text{かつ}\ \ \|x_n\|\to\|x\| \qquad \Longrightarrow \qquad \|x_n-x\|\to0

x=0 なら明らか。x\ne0 とし、y_n=x_n/\|x_n\|、y=x/\|x\| とおく。y_n\rightharpoonup y で \|y_n\|=\|y\|=1。

\frac{y_n+y}{2}\rightharpoonup y なので、下半連続性より \liminf\|\frac{y_n+y}{2}\|\ge1。一様凸性より \|y_n-y\|\to0。

「弱収束 + ノルムの収束 = 強収束」。

ヒルベルト空間では直接に確かめられる——\|x_n-x\|^2=\|x_n\|^2-2\mathrm{Re}\langle x_n,x\rangle+\|x\|^2\to0。

L^1 では成り立たない（一様凸でない）。f_n=n\mathbf{1}_{(0,1/n)} は L^1 で弱収束しないが、似た現象が起こる。

閉集合と凸性

マズールの定理

C\subseteq E を凸集合とすると、C が弱閉であることとノルム閉であることは同値である。

弱閉ならノルム閉は明らか（弱位相のほうが弱いから）。

逆。C をノルム閉凸、x_0\notin C とする。分離定理（（2））より、\varphi\in E^* と \gamma_1<\gamma_2 があって \mathrm{Re}\,\varphi(x_0)\le\gamma_1<\gamma_2\le\mathrm{Re}\,\varphi(c)（c\in C）。

\{\,x \mid \mathrm{Re}\,\varphi(x)<\gamma_2\,\} は x_0 の弱開近傍で C と交わらない。よって C の補集合は弱開。

マズールの補題

x_n\rightharpoonup x なら、\{x_n\} の凸結合からなる列で x にノルム収束するものが存在する。

C=\overline{\mathrm{conv}}\{x_n : n\ge N\}（ノルム閉包）は凸閉なので弱閉。x は \{x_n : n\ge N\} の弱閉包に属するので x\in C。

凸集合については、弱位相とノルム位相が「閉」に関して同じ結論を出す。

これが弱位相を実用的にしている。凸な対象（凸関数の下位集合、凸最適化の制約集合）を扱うかぎり、位相を弱めても閉性を失わない。

距離化できる場合と、点列で足りるか

弱位相は無限次元では距離化できない。ところが、部分集合に制限すれば距離化できることがある。

定理。E^* が可分なら、E の閉単位球 B_E 上の弱位相は距離化できる。

d(x,y) = \sum_{n=1}^{\infty}2^{-n}\,|\varphi_n(x-y)| \qquad (\{\varphi_n\} \text{ は } B_{E^*} \text{ の稠密列})

定理。E が可分なら、B_{E^*} 上の弱*位相は距離化できる。

どちらも「有界集合の上でだけ」である。空間全体では、無限次元なら距離化できない。

点列で足りるか。距離化できれば、閉包・コンパクト性を点列で扱える。そうでないとネット（第12章）が要る。

エベルライン–シュミュリアンの定理。それでも、弱位相については点列で足りる。

すなわち——A\subseteq E について、A が弱コンパクトであることと、弱点列コンパクト（どの列も弱収束部分列をもつ）であることは同値。

これは驚くべき定理である。第25章で「一般の位相空間ではコンパクトと点列コンパクトが一致しない」と見た。弱位相は距離化できないのに、この同値が成り立つ。

弱*位相では成り立たない。B_{E^*} は弱*コンパクト（第71章）だが、E が非可分なら弱*点列コンパクトとは限らない。

例。E=\ell^\infty のとき、B_{(\ell^\infty)^*} は弱*点列コンパクトでない。評価汎関数 \delta_n の列が、弱*収束部分列をもたない。

第23章の \beta\mathbb{N} が点列コンパクトでないという事実（第25章）の、双対空間での姿である。

弱位相の一般論——双対対と、極集合

双対対。ベクトル空間の対 (X,Y) と双線型形式 \langle\cdot,\cdot\rangle \colon X\times Y\to\mathbb{K} で、互いに点を分離するものを双対対という。

\sigma(X,Y) を、Y の元が定める汎関数をすべて連続にする最弱の位相とする。弱位相 \sigma(E,E^*) と弱*位相 \sigma(E^*,E) は、この枠組みの二つの例である。

マッキー–アレンスの定理。(X,\sigma(X,Y))^* = Y。すなわち、弱位相での連続汎関数はちょうど Y の元に限る。

位相を弱めても、双対は変わらない。だから (E,\text{弱})^*=E^* であり、マズールの定理の証明で分離定理が使えた。

マッキー位相。同じ双対 Y を与える位相のうち、最強のものが存在する（マッキー位相 \tau(X,Y)）。

ノルム位相はその間にある——\sigma(E,E^*) \subseteq \|\cdot\| \subseteq \tau(E,E^*)。実は E がバナッハなら、ノルム位相 = マッキー位相。

極集合。A\subseteq X の極を A^\circ=\{\,y\in Y \mid |\langle x,y\rangle|\le1 \ (\forall x\in A)\,\} と定める。

双極定理。A^{\circ\circ}=\overline{\mathrm{conv}}(A\cup\{0\})（弱閉包）。第66章★★の零化域は、極の線型部分空間版である。

双極定理は、分離定理の言い換えにすぎない。だがこの形にすると、多くの命題が計算だけで出る。

応用——凸共役。凸関数 f に対し f^*(\varphi)=\sup_x(\varphi(x)-f(x)) をルジャンドル–フェンシェル変換という。

双極定理から f^{**}=f（f が下半連続な真凸関数なら）。凸解析と最適化理論の中心的な道具である。

第72章への橋。極集合は凸でコンパクト（第71章）になる。その端点を調べるのが、クレイン–ミルマンの定理である。
