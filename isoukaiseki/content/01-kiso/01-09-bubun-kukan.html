この章の問い

  • 空間の一部分に、どうやって位相を入れるのが自然か。
  • 「開である」という言葉は、どの空間のなかでの話なのか。
  • 空間のもつ性質は、部分に受け継がれるのか。

相対位相——一つしかない自然な選び方

X が位相空間で、A \subseteq X とする。A に位相を入れたい。どう入れるべきか。

方針は第8章の★★で述べた始位相の考え方に従う。包含写像 \iota \colon A \to X が連続になるような、最小の位相を選ぶ。そうすれば、A に余分な開集合が増えず、しかも A の点が X のなかで近かったものは A のなかでも近いままになる。

相対位相

A \subseteq X に対し、

\mathcal{T}_A = \{\, U \cap A \mid U \in \mathcal{T}_X \,\}

は A 上の位相である。これを相対位相といい、(A, \mathcal{T}_A) を X の部分空間という。

位相であることを確かめる。\varnothing = \varnothing \cap A、A = X \cap A なので（T1）。第2章の分配法則より

\bigcup_i (U_i \cap A) = \Big(\bigcup_i U_i\Big) \cap A, \qquad (U \cap A) \cap (V \cap A) = (U \cap V) \cap A

であり、（T2）（T3）が従う。「A と交わる」という操作が、合併とも交叉とも可換であることが効いている。

最小性を示す。\iota が連続なら \iota^{-1}(U) = U \cap A が開でなければならないから、どの位相も \mathcal{T}_A を含む。\mathcal{T}_A 自身で \iota は連続だから、これが最小である。

「開集合」という語は、つねにどの空間のなかでの話かを伴う。A のなかで開であることと、X のなかで開であることは別である。混乱を避けるため、本書では必要に応じて「A において開」「X において開」と書き分ける。

部分空間で開になるもの

X = \mathbb{R}、A = [0, 1] とする。[0, 1/2) は X では開でないが、A では開である。実際 [0,1/2) = (-1, 1/2) \cap A であり、(-1,1/2) は X で開である。

同様に A = \mathbb{Q} のとき、\{\, q \in \mathbb{Q} \mid q^2 < 2 \,\} は \mathbb{Q} において開であり、かつ閉である。\sqrt{2} が \mathbb{Q} に属さないので、境界が取れてしまう。有理数全体は、\varnothing と全体以外に開かつ閉な部分集合をもつ——すなわち連結でない（第28章）。

相対位相の基本的な性質

A \subseteq X を部分空間とする。

（1）F \subseteq A が A で閉 \iff X の閉集合 G があって F = G \cap A。
（2）B \subseteq A の A における閉包は \overline{B}^{\,X} \cap A に等しい。
（3）\mathcal{B} が X の基底なら、\{\, B \cap A \,\} は A の基底である。
（4）A が X で開（閉）なら、A で開（閉）な集合は X でも開（閉）である。
（5）B \subseteq A \subseteq X のとき、B に A 経由で入る位相と X から直接入る位相は一致する。

（1）は補集合をとるだけである。A \setminus F = U \cap A と書けば F = (X \setminus U) \cap A。

（2）を示す。\overline{B}^{\,X} \cap A は（1）より A で閉であり B を含むから、\overline{B}^{\,A} \subseteq \overline{B}^{\,X} \cap A。逆を示す。\overline{B}^{\,A} = G \cap A と書くと G は X で閉で B を含むから \overline{B}^{\,X} \subseteq G、よって \overline{B}^{\,X} \cap A \subseteq G \cap A = \overline{B}^{\,A}。

（4）を示す。A が X で開、V が A で開とする。V = U \cap A と書けば、二つの X-開集合の交叉だから X で開である。閉の場合も同様。

（5）は (U \cap A) \cap B = U \cap B による。部分空間をとる操作は推移的である。

（4）の仮定を外すと結論は崩れる。A = [0,1] は \mathbb{R} で開でないので、A で開な [0,1/2) は \mathbb{R} で開でない。「部分空間で開なら全体でも開」は、部分空間自身が開であるときにだけ言える。

遺伝性——性質は部分に受け継がれるか

位相的性質 P が遺伝的であるとは、P をもつ空間のすべての部分空間が P をもつことをいう。閉部分空間についてだけ成り立つとき閉遺伝的という。

第一可算性、第二可算性、距離化可能性は遺伝的である。コンパクト性は閉遺伝的だが遺伝的でない。連結性は閉遺伝的ですらない。

第二可算を示す。\mathcal{B} を X の可算基底とすると、（3）より \{ B \cap A \} は A の基底であり、可算集合の像だから可算である。第一可算も同様。距離化可能性は、距離を A に制限すればよい。

コンパクト性が遺伝的でないことは、[0,1] がコンパクトで (0,1) がそうでないことによる。閉遺伝的であることは第20章で示す。連結性については、\mathbb{R} は連結だが閉部分空間 \mathbb{Z} は連結でない。

どの性質が遺伝し、どの性質が遺伝しないかは、その性質が何を言っているかの指標になる。「各点のまわり」を語る性質は遺伝しやすく、「空間全体」を語る性質は遺伝しにくい。可算公理や距離化可能性は前者、コンパクト性や連結性は後者である。

中間に位置するのが分離公理である。ハウスドルフ性と正則性は遺伝するが、正規性は遺伝しない。この一点が第18章の主題になる——遺伝的に正規な空間を完全正規空間といい、正規性とは別の階層をなす。

埋め込みと、部分空間の特徴づけ

部分空間の概念は、集合として部分であることに縛られない。同相なコピーが入っていれば同じことである。

埋め込みの定義を思い出す。第8章で、単射 f \colon X \to Y が X から f(X)（相対位相）への同相であるとき埋め込みと呼んだ。埋め込みが存在すれば、X は Y の部分空間と「同じ」空間だと見なせる。

単射連続だけでは足りない。第8章の反例 [0, 2\pi) \to S^1 は単射連続だが埋め込みでない。像への写像が同相でないからである。埋め込みであるためには、X の開集合の像が f(X) のなかで開でなければならない。

始位相との関係。埋め込みは「f による始位相が X のもとの位相に一致する単射」と言い換えられる。この言い方は、第11章で積空間への埋め込みを扱うときに効いてくる。

なぜ埋め込みが重要か。位相空間論の多くの定理が「ある空間は、よく知られた空間に埋め込める」という形をとるからである。

ウリゾーンの距離化定理（第31章）は、第二可算かつ正則な空間がヒルベルト立方体 [0,1]^{\mathbb{N}} に埋め込めることを示す。埋め込めれば、距離が遺伝的であることから距離化可能性が従う。チコノフ空間の特徴づけ（第14章）は、立方体 [0,1]^{\kappa} への埋め込みとして与えられる。ストーン–チェックのコンパクト化（第23章）も、この立方体への埋め込みの閉包として構成される。

「どんな空間か」を問う代わりに「どこに入るか」を問う——これが位相空間論の主要な方法の一つである。そして入り先として使われる空間は、たいてい立方体か、その部分空間である。

普遍空間。ある族のすべての空間を埋め込める空間を、その族の普遍空間という。ヒルベルト立方体は可分距離空間の普遍空間であり、カントール集合はコンパクト距離空間の連続像としての普遍性をもつ。第42章で次元を扱うとき、次元 n の空間の普遍空間としてメンガー Menger の普遍曲線が登場する。

遺伝性の破れ方を測る——第18章への伏線

正規性が遺伝しないという事実は、単なる不便ではない。破れ方を調べることが、正規性という概念の内実を明らかにする。

まず、どこまで遺伝するか。正規空間の閉部分空間は正規である。証明は易しい——閉部分空間で閉な集合は、もとの空間でも閉だからである（（4））。遺伝性が破れるのは、開部分空間や一般の部分空間を取ったときである。

典型的な反例。チコノフ板と呼ばれる空間がある。順序数の空間を使って

T = [0, \omega_1] \times [0, \omega]

と置く（順序位相を入れる）。T はコンパクトハウスドルフだから正規である。ところが角の一点 (\omega_1, \omega) を除いた開部分空間

T_\infty = T \setminus \{(\omega_1, \omega)\}

は正規でない。二つの辺——上辺と右辺——が、開集合で分離できない。この分離不能性の根は、第4章で見た共終数にある。\mathrm{cf}(\omega_1) = \omega_1 > \omega なので、可算個の条件では \omega_1 を押さえきれないのである。

集合論の基数の性質が、位相空間の分離不能性として目に見える形で現れる。第4章の★★★で予告したことの、最初の具体例である。

完全正規性。遺伝的に正規な空間を完全正規空間という。これは「すべての閉集合が G_\delta 集合である正規空間」と同値である——証明は第18章で与える。この同値が示すのは、遺伝性という大域的な要求が、閉集合の局所的な構造に翻訳できるということである。

階層のなかの位置。完全正規性は、正規性より真に強く、距離化可能性より真に弱い。

\text{距離化可能} \implies \text{完全正規} \implies \text{正規}

どちらの含意も逆は成り立たない。ゾルゲンフライ直線は完全正規だが距離化できない。チコノフ板は正規だが完全正規でない。第17章で、この種の階層と反例を体系的に扱う。

遺伝性を一般に問う。どの性質が遺伝的かを一覧にすることは、第19章の課題である。そこでは遺伝だけでなく、積・商・連続像で何が保たれるかも併せて整理する。位相的性質を、四つの操作（部分・積・商・連続像）に対する振る舞いで分類すること——これが第II部を貫く視点になる。
