この章の問い

  • 閉集合は「開集合でない集合」ではない。では何か。
  • 閉包と内部は、どちらが基本的なのか。
  • 「稠密」という語は、どれだけ強い主張をしているのか。

閉集合——開集合の裏返し

位相は開集合の族として与えられた。だがその補集合の族も、まったく同じ情報をもっている。

位相空間 (X, \mathcal{T}) において、F \subseteq X が閉集合であるとは、X \setminus F が開集合であることをいう。

開と閉は排反ではない。両方であるもの（\varnothing と X は常にそう）も、どちらでもないものもある。\mathbb{R} の [0,1) はどちらでもない。「閉集合」は「開集合の否定」ではなく、「補集合が開である集合」である。この混同は初学者の誤りの筆頭に来る。

第2章のド・モルガンの法則により、位相の公理はそのまま閉集合の性質に翻訳される。

閉集合の族は次を満たす。（F1）\varnothing と X は閉。（F2）任意個の閉集合の交叉は閉。（F3）有限個の閉集合の合併は閉。

（F2）を示す。\{F_i\} を閉集合の族とすると、

X \setminus \bigcap_{i} F_i = \bigcup_{i} (X \setminus F_i)

であり、右辺は開集合の任意合併だから開である。よって左辺の補集合、すなわち \bigcap_i F_i は閉である。（F1）と（F3）も同様に、ド・モルガンで移すだけである。

合併と交叉の役割が、開と閉で入れ替わっている。無限個の閉集合の合併は閉とは限らない。実際 \bigcup_n [1/n, 1] = (0, 1] は閉でない。第5章の反例を補集合で読み替えたものである。

閉包・内部・境界

任意の集合 A に対して、それを含む最小の閉集合と、それに含まれる最大の開集合が定まる。

A \subseteq X に対し、

\overline{A} = \bigcap \{\, F \mid A \subseteq F,\ F \text{ は閉} \,\}, \qquad A^{\circ} = \bigcup \{\, U \mid U \subseteq A,\ U \text{ は開} \,\}

をそれぞれ A の閉包、内部という。また \partial A = \overline{A} \setminus A^{\circ} を A の境界という。

（F2）より \overline{A} は閉であり、（T2）より A^\circ は開である。したがって \overline{A} は A を含む最小の閉集合、A^\circ は A に含まれる最大の開集合である。次の特徴づけが、実際の計算では使いやすい。

閉包の点ごとの特徴づけ

x \in \overline{A} であることと、x を含むどの開集合も A と交わることは同値である。

対偶で示す。x \notin \overline{A} とすると、U = X \setminus \overline{A} は x を含む開集合であり、\overline{A} \supseteq A より U \cap A = \varnothing である。よって A と交わらない開集合が取れた。

逆に、x を含む開集合 U で U \cap A = \varnothing となるものがあったとする。すると X \setminus U は A を含む閉集合だから \overline{A} \subseteq X \setminus U。x \in U より x \notin \overline{A} である。

この特徴づけは「x にいくらでも近いところに A の点がある」という直観を、距離を使わずに述べたものである。距離空間なら「どんな \varepsilon についても U_\varepsilon(x) \cap A \ne \varnothing」と書けるが、一般の空間では \varepsilon がない。開集合の族が、\varepsilon の役割を代行している。

閉包と内部は、補集合を通して互いに移り合う。

X \setminus \overline{A} = (X \setminus A)^{\circ}, \qquad X \setminus A^{\circ} = \overline{X \setminus A}

したがって、どちらか一方を基本概念に選べば、他方は定義できる。どちらを選ぶかは趣味の問題である。本書は閉包を主に使う——収束の議論と相性がよいからである。

稠密・疎・そのあいだ

A \subseteq X が稠密であるとは \overline{A} = X となることをいい、疎であるとは (\overline{A})^{\circ} = \varnothing となることをいう。

有理数と無理数

\mathbb{Q} は \mathbb{R} のなかで稠密である。どの開区間にも有理数があるからである。同時に \mathbb{Q}^{\circ} = \varnothing である——どの開区間も無理数を含むので、\mathbb{Q} に含まれる開区間はない。無理数全体も同じく稠密で内部が空である。

互いに交わらない二つの稠密集合が共存できる。「稠密」は「たくさんある」ことを意味しない。実際、有理数は可算であり、実数の濃度からすれば無視できるほど少ない。

疎でないが内部も空

\mathbb{Q} は疎ではない——\overline{\mathbb{Q}} = \mathbb{R} の内部は \mathbb{R} であって空でないからである。にもかかわらず \mathbb{Q} 自身の内部は空である。「内部が空」と「疎」を混同してはならない。疎であるとは、閉包をとってもなお内部が空であることをいう。

整数全体 \mathbb{Z} は閉集合であり内部が空なので、疎である。カントール集合も疎である。第27章のベールのカテゴリー定理は、この「疎」という概念の上に立っている。

集積点と孤立点

閉包の点は二種類に分かれる。

x が A の集積点であるとは、x を含むどの開集合 U についても (U \setminus \{x\}) \cap A \ne \varnothing となることをいう。集積点全体を A' と書く。A の点であって集積点でないものを孤立点という。

定義から \overline{A} = A \cup A' が従う。x \in \overline{A} なら、x 自身が A の点であるか、x の近くに x と異なる A の点があるか、どちらかである。

集積点の計算

A = \{\, 1/n \mid n \in \mathbb{N} \,\} とすると、A' = \{0\} である。A の点はすべて孤立点であり、\overline{A} = A \cup \{0\}。集積点は A に属さなくてよい。

A = \mathbb{Q} なら A' = \mathbb{R} であり、孤立点はない。A = \mathbb{Z} なら A' = \varnothing で、すべてが孤立点である。孤立点をもたない閉集合を完全集合という——カントール集合がその例であり、第27章と第53章で再登場する。

閉包作用素から位相を復元する

第5章の★★★で触れたクラトフスキの公理を、ここで証明しておく。閉包を原始概念に選んでも、同じ構造が得られる。

閉包が満たす四条件。位相空間の閉包作用素は次を満たす。

\overline{\varnothing} = \varnothing, \quad A \subseteq \overline{A}, \quad \overline{\overline{A}} = \overline{A}, \quad \overline{A \cup B} = \overline{A} \cup \overline{B}

最初の三つは定義から直ちに出る。第四のものを示す。A \cup B \subseteq \overline{A} \cup \overline{B} であり、右辺は二つの閉集合の合併だから（F3）より閉である。よって \overline{A \cup B} \subseteq \overline{A} \cup \overline{B}。逆向きは A \subseteq A \cup B より \overline{A} \subseteq \overline{A \cup B}、B についても同様だから従う。

逆の構成。集合 X と、四条件を満たす作用素 c が与えられたとする。\mathcal{F} = \{\, A \mid c(A) = A \,\} と置き、その補集合の族を \mathcal{T} とする。\mathcal{T} が位相になり、その閉包作用素が c に一致することを示せばよい。

まず、第四条件から c は単調である。A \subseteq B なら c(B) = c(A \cup B) = c(A) \cup c(B) \supseteq c(A)。合併を保つことが、単調性を含んでいる。

（F3）は第四条件そのものである。（F2）を示す。\{A_i\} を \mathcal{F} の族、A = \bigcap_i A_i とする。各 i について A \subseteq A_i だから単調性より c(A) \subseteq c(A_i) = A_i。よって c(A) \subseteq A であり、第二条件と合わせて c(A) = A。単調性だけで任意交叉が出るのが要点である。

なぜ交叉の条件が要らないのか。四条件には \overline{A \cap B} についての要求がない。それは \overline{A \cap B} = \overline{A} \cap \overline{B} が一般には成り立たないからである。有理数と無理数を取れば、左辺は \overline{\varnothing} = \varnothing、右辺は \mathbb{R} である。

ここにも第2章の非対称が顔を出している。閉包は合併を保ち、交叉を保たない。そして位相の公理は、合併を任意個で、交叉を有限個で許した。二つの非対称は同じ根から出ている。

クラトフスキの14集合問題

一つの集合から出発して、閉包をとる操作と補集合をとる操作を繰り返すと、いくつの相異なる集合が得られるか。答えは、どんな位相空間のどんな部分集合から始めても、高々14個である。クラトフスキが一九二二年に示した。

なぜ有限で止まるのか。閉包を k、補集合を c と書く。c は対合（cc = \mathrm{id}）であり、k は冪等（kk = k）である。鍵になるのは kckckck = kck という等式である。これが成り立つと、長い語はすべて短い語に潰れ、可能な語は14個に限られる。

等式の証明には、kck が単調であることと、A \subseteq kckA が閉集合 A について成り立つことを使う。技術的には短いが、見通しをつけるのが難しい種類の議論である。

14個すべてが実現するか。する。\mathbb{R} のなかで

A = (0,1) \cup (1,2) \cup \{3\} \cup \big([4,5] \cap \mathbb{Q}\big)

と置くと、14個の相異なる集合が得られる。四つの成分が、それぞれ別の役割を果たしている——開区間の切れ目、孤立点、稠密だが内部のない部分。この例は、本章で導入した概念がすべて独立であることを一つの式で示している。

一般化。同じ問いを、閉包と内部の組合せ、あるいは閉包・補集合・合併の組合せで問うこともできる。閉包と内部だけなら7個、閉包・補集合・合併を許すと無限個になる。どの操作を許すかで答えが変わるので、問題としては操作の集合を指定して初めて意味をもつ。

これは何の役に立つのか。直接の応用は乏しい。だが、この問題は位相空間論の一つの性格をよく表している。単純な操作の組合せが、有限で止まるか止まらないかを問うこと——第38章からの次元論も、第35章からの基数不変量も、突き詰めればこの形の問いである。「どこまでが有限で、どこから先が無限か」を測ることが、この分野の仕事の一つになる。
