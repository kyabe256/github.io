この章の問い

  • 閉集合の上で定義された連続関数を、全体に延ばせるか。
  • 延ばせるための条件は、ウリゾーンの補題と同じものか。
  • 閉集合でなければならない理由は何か。

拡張という問題

A \subseteq X を閉集合、f \colon A \to \mathbb{R} を連続関数とする。F|_A = f となる連続な F \colon X \to \mathbb{R} は存在するか。

ウリゾーンの補題は、この問題の特別な場合を解いていた。A \cup B の上で「A で 0、B で 1」という関数が与えられていて、それを全体に延ばしたのである。一般の f でも同じことができるだろうか。

ティーツェの拡張定理

X が正規、A \subseteq X が閉、f \colon A \to [a,b] が連続とする。このとき連続な F \colon X \to [a,b] で F|_A = f となるものが存在する。

f \colon A \to \mathbb{R}（有界でない場合）についても、連続な拡張 F \colon X \to \mathbb{R} が存在する。

区間は [-1,1] としてよい。証明は、ウリゾーンの補題で作った関数を無限級数として足し合わせる。

近似の一歩。g \colon A \to [-1,1] が連続なとき、連続な h \colon X \to [-1/3, 1/3] で

\sup_{x \in A} |g(x) - h(x)| \le \tfrac{2}{3}

となるものが作れることを示す。A_- = g^{-1}([-1, -1/3])、A_+ = g^{-1}([1/3, 1]) は A で閉、したがって A が X で閉だから X でも閉であり、交わらない。ここで A が閉であることが使われる。

ウリゾーンの補題（）より、h \colon X \to [-1/3, 1/3] で h|_{A_-} \equiv -1/3、h|_{A_+} \equiv 1/3 となるものが取れる。三つの場合を確かめると、A 上で |g - h| \le 2/3 が成り立つ。

反復。g_0 = f とし、上の一歩で h_0 を作る。g_1 = f - h_0|_A は A 上で |g_1| \le 2/3 なので、(3/2) g_1 に同じ一歩を適用して h_1（値域 [-\frac13 \cdot \frac23,\ \frac13 \cdot \frac23]）を作る。以下同様に

|h_n| \le \tfrac{1}{3}\Big(\tfrac{2}{3}\Big)^n, \qquad \sup_A \Big| f - \sum_{k=0}^{n} h_k \Big| \le \Big(\tfrac{2}{3}\Big)^{n+1}

が成り立つ。

収束。F = \sum_{n=0}^{\infty} h_n と置く。\sum \frac13 (\frac23)^n = 1 なので級数は一様収束し、一様収束極限は連続である（第47章で証明するが、ここでは既知としてよい）。値域は [-1,1] に収まる。そして A 上で |f - F| = 0、すなわち F|_A = f。

有界でない場合。同相 \varphi \colon \mathbb{R} \to (-1,1)（たとえば \varphi(t) = t/(1+|t|)）を使って \varphi \circ f \colon A \to (-1,1) を [-1,1] へ拡張し、値が \pm 1 になる部分を処理する。具体的には、拡張 G に対し C = G^{-1}(\{-1,1\}) は A と交わらない閉集合なので、ウリゾーンの補題で A で 1、C で 0 の関数 u を取り、uG を考えれば値域が (-1,1) に収まる。最後に \varphi^{-1} を合成する。

この証明は解析学の議論そのものである。一様収束する級数を作り、極限の連続性を使う。位相空間論の定理が、一様収束という解析の道具で証明された。逆に第47章では、一様収束の必要性が解析の側から改めて論じられる。二つの部の往復は、第97章で回収する。

A が閉でなければ、定理は成り立たない。X = \mathbb{R}、A = (0,1)、f(x) = \sin(1/x) とすると、0 での極限が存在しないので連続に延ばせない。A = \mathbb{R} \setminus \{0\}、f(x) = 1/x も延ばせない。閉集合であることが、近似の一歩で A_\pm が X で閉になることに使われていた。

ウリゾーンとの同値性

T_1 空間 X について、次は同値である。（1）X は正規。（2）ウリゾーンの補題が成り立つ。（3）ティーツェの拡張定理が成り立つ。

（1）から（2）は 、（2）から（3）は で示した。（3）から（1）を示す。

A, B を交わらない閉集合とする。A \cup B は閉であり、その上で f|_A \equiv 0、f|_B \equiv 1 と定めた f は連続である——A と B がともに A \cup B で閉なので、この定義は各点の近傍で局所定数になる。（3）より F \colon X \to [0,1] に拡張でき、F^{-1}([0,1/2)) と F^{-1}((1/2,1]) が分離を与える。

三つの主張がすべて同値であることは、正規性という条件が「拡張が可能であること」と同じ内容だと言っている。

拡張定理が働く場面

三つの応用

境界値問題。領域の境界で与えられた連続関数を、内部まで連続に延ばせる。ただし延ばしただけでは方程式を満たさない——第94章のディリクレ問題は、延ばしたうえで調和にすることを要求する。ティーツェの定理は、そこでの出発点を与える。

レトラクション。A \subseteq X が閉で、連続な r \colon X \to A が r|_A = \mathrm{id} を満たすとき、A を X のレトラクトという。A が \mathbb{R}^n の凸集合に同相なら、ティーツェの定理を座標ごとに適用してレトラクションが作れる。凸性が座標ごとの独立な拡張を許すのが要点である。

関数の貼り合わせ。X = A \cup B（A, B 閉）で、f_A と f_B が A \cap B で一致するとき、貼り合わせた関数は連続である。これは拡張定理を使わずに直接示せるが、拡張定理と組み合わせると「片方だけ与えて他方を作る」ことができる。

拡張できるかどうかは、値域にもよる

ティーツェの定理は値域が \mathbb{R} または区間の場合である。値域を変えると、何が起きるか。

\mathbb{R}^n なら大丈夫。座標ごとに適用すればよい。f \colon A \to \mathbb{R}^n の各成分を拡張し、束ねれば連続である（）。値域が積であれば、拡張は成分ごとに独立に行える。

凸集合なら大丈夫。C \subseteq \mathbb{R}^n が凸閉集合のとき、f \colon A \to C は C への拡張をもつ。まず \mathbb{R}^n へ拡張し、最近点への射影 \pi \colon \mathbb{R}^n \to C（凸集合では一意で連続）を合成する。A 上では f の値が既に C に入っているので \pi は何も変えない。

球面では駄目。S^1 への拡張は一般にできない。X = \overline{D^2}（閉円板）、A = S^1、f = \mathrm{id} とすると、拡張 F \colon \overline{D^2} \to S^1 は存在しない。

存在すれば、S^1 が円板のレトラクトになる。これはホモトピー論の道具（基本群が \mathbb{Z} であること、あるいはブラウワーの不動点定理）で否定される。拡張の可否は、値域の位相的な「穴」に依存する。

絶対レトラクト。「どんな正規空間のどんな閉部分集合からの連続写像も拡張できる」という値域を、絶対レトラクト（\mathrm{AR}）という。[0,1] と \mathbb{R}^n の凸閉集合は \mathrm{AR} であり、ヒルベルト立方体も \mathrm{AR} である。

より弱い概念として、近傍からの拡張だけを要求する絶対近傍レトラクト（\mathrm{ANR}）がある。多様体や単体複体は \mathrm{ANR} である。球面は \mathrm{ANR} だが \mathrm{AR} でない——局所的には延ばせるが、大域的には延ばせない。

この局所と大域の落差が、代数的位相幾何学の出発点の一つになる。本書はこの方向に進まないが、第94章の調和関数の境界値問題で、局所的な拡張と大域的な解の違いに再び出会う。

拡張定理から距離化定理へ

ティーツェの定理は、それ自体が目的ではない。第31章の距離化定理への部品になる。その接続を先に述べておく。

埋め込みを作るという戦略。第14章で見たとおり、チコノフ空間は立方体 [0,1]^\kappa に埋め込める。距離化するには、埋め込み先を可算次元の立方体 [0,1]^{\mathbb{N}} にしなければならない——それがコンパクト距離空間だからである（第11章の★★）。

そのためには、点と閉集合を分離する連続関数が可算個で足りる必要がある。ここに第二可算性が効く。可算基底 \{B_n\} から可算個の関数を作れれば、埋め込みが [0,1]^{\mathbb{N}} に収まる。

正則＋第二可算から正規が出る。驚くべきことに、正則な第二可算空間は正規である。証明の骨子はこうである。交わらない閉集合 A, B を取る。正則性より、各 x \in A について \overline{B_{n(x)}} \cap B = \varnothing なる基底元 B_{n(x)} \ni x が取れる。基底は可算だから、A を覆う可算個の \{B_{n_k}\} が選べる。B についても同様に \{C_{m_j}\} を取る。

あとは可算個の被覆から交わらない開集合を作る。U = \bigcup_k (B_{n_k} \setminus \bigcup_{j \le k} \overline{C_{m_j}})、V = \bigcup_j (C_{m_j} \setminus \bigcup_{k \le j} \overline{B_{n_k}}) と置けばよい。添字の大小で「先に取ったものを避ける」ことが、交わらなさを保証する。可算性が、この対角線的な構成を可能にしている。

したがって。正則かつ第二可算な空間は正規であり、ウリゾーンの補題が使える。可算基底から可算個の分離関数が作れ、[0,1]^{\mathbb{N}} への埋め込みが得られる。これがウリゾーンの距離化定理（第31章）の筋である。

\text{正則} + \text{第二可算} \implies \text{正規} \implies \text{関数が作れる} \implies \text{立方体に入る} \implies \text{距離化可能}

可算性を外すとどうなるか。第32章のナガタ–スミルノフの定理は、第二可算性を「\sigma-局所有限基底」という弱い条件に置き換える。そこでは正規性の代わりにパラコンパクト性（第24章）が主役になる。

大づかみに言えば、距離化定理の歴史は「可算性」をどこまで弱められるかの歴史である。ウリゾーンが可算基底で解き、ナガタとスミルノフとビングが局所有限性で解いた。第34章では、この一連の定理が距離空間の何を特徴づけたのかを振り返る。
