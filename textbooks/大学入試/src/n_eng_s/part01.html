動詞の後ろに名詞が2つ → 「イコール」なら SVOC

「V + 名詞 + 名詞／形容詞」の文の和訳・文型判定。
2つ目の語を1つ目の語の「説明」と読めるか確かめる。O＝C なら SVOC で「O を C にする／O が C だとわかる」。O≠C なら SVOO で「O に C をあげる」。find O C は「O が C だとわかる」、leave O C は「O を C のままにする」、keep O C は「O を C に保つ」。
I found the book easy. と I found the book easily. の違いは？
解　前者は SVOC「その本は簡単だとわかった（読んでみたら易しかった）」。後者は SVO＋副詞「その本を簡単に見つけた」。

日本語につられて前置詞をつけない（他動詞）

選択肢に discuss about / marry with / enter into / reach to などが並ぶ。
「〜について」「〜と」「〜に」と訳しても前置詞をとらない他動詞を覚えておく：discuss, marry, enter, reach, resemble, approach, attend, mention, consider, answer, obey, survive。逆に apologize to, complain about, graduate from, object to, reply to は前置詞が必要。
She will (　) the meeting tomorrow.　① attend to　② attend　③ attend at　④ attend with
解　②（attend「出席する」は他動詞。attend to は「〜に注意を払う・世話をする」で意味が違う）

lie / lay、rise / raise は「目的語の有無」で選ぶ

空所に lie, lay, lain, laid, rise, raise などの活用形を入れる。
①空所の後ろに目的語があるかで自動詞か他動詞かを決める → ②時制を決めて活用形を選ぶ。
自：lie – lay – lain – lying（横たわる）／他：lay – laid – laid – laying（横たえる・置く）
自：rise – rose – risen（上がる）／他：raise – raised – raised（上げる・育てる）
The cat was (　) in the sun.　① laying　② lying　③ laid　④ lain
解　②（目的語がない → 自動詞 lie。進行形なので lying）
lay は「lie の過去形」と「他動詞 lay の原形」の2つの顔をもつ。最も狙われる。

使役・知覚の「O ＋ 何の形？」は O と動詞の関係で決める

have / get / make / let / see / hear + O + (　) の空所。
O がする側（能動）なら：make・let・have・see・hear は原形、get は to do、知覚動詞は進行中なら -ing。
O がされる側（受動）なら：どれも過去分詞（have my hair cut, hear my name called）。
I couldn't make myself (　) in English.　① understand　② understanding　③ understood　④ to understand
解　③（myself は「理解される」側 → 過去分詞。「英語で意思を通じさせることができなかった」）

使役・知覚動詞の受動態は to が復活

be made / be seen / be heard + (　)。
能動態の原形不定詞は、受動態では to 不定詞になる：They made him work. → He was made to work.。let は受動態にせず be allowed to を使う。
She was heard (　) a song in her room.　① sing　② to sing　③ sang　④ sung
解　②（「歌っているところ」を強調するなら singing も可だが、選択肢では to sing）

第4文型をとれない動詞は「物 to 人」

explain / suggest / introduce / describe / say / propose の後ろに人と物が並ぶ。
これらは SVOO をとらないので、explain 物 to 人 の語順にする。逆に、SVOO を前置詞で書きかえるときは、to 型（give, show, tell, send, lend, teach）と for 型（buy, make, cook, find, choose）を区別。
並べかえ：彼は私たちにその問題の解き方を説明した。（how / he / to / explained / us / to / solve / the problem）
解　He explained to us how to solve the problem.（目的語が長いので to us を前に出した形）

提案・要求・必要の that 節は「原形」

suggest / propose / demand / insist / recommend / require that S (　)、It is necessary / essential / important that S (　)。
S が三人称単数でも、主節が過去でも、that 節の動詞は原形（または should ＋原形）。否定は not ＋原形（that he not go）。
The manager insisted that the report (　) by Friday.　① is finished　② was finished　③ be finished　④ finishes
解　③
suggest「示唆する」、insist「（事実だと）言い張る」の意味では原形にならない。意味で判断する。
後ろの形代表的な動詞
V + O + to doallow, enable, cause, force, encourage, persuade, want, ask, tell, advise, expect, require
V + doing のみavoid, enjoy, finish, mind, give up, put off, deny, consider, admit, practice, miss, escape, postpone
V + to do のみdecide, hope, plan, refuse, promise, afford, manage, fail, pretend, offer, agree
to do と doing で意味が違うremember / forget（to do＝これから、doing＝過去に）、stop（to do＝〜するために立ち止まる）、try（to do＝しようとする、doing＝試しにやってみる）
