## 読者と水準
- 大学入試（共通テスト〜国公立二次・難関私大）を目指す高校生。現代文（評論・小説・記述・共通テスト）、古文（文法・和歌・古文常識・読解）、漢文（句法・読解・漢詩）。
- わかりやすく、しかし正確に。文法用語・句法の名称は日本の高校で標準的なもの（四段活用、ラ行変格活用、連用形、係り結び、再読文字、使役形 など）。
- **現代文の本文（評論・小説）はすべて書き下ろし**（既存の文章・入試問題を写さない）。小説も短い場面を自作する。
- **古文・漢文の本文は、古典作品（著作権の切れた原典）から短く引用してよい**（徒然草・枕草子・方丈記・伊勢物語・竹取物語・源氏物語・大鏡・宇治拾遺物語・土佐日記・更級日記・平家物語・古今和歌集・新古今和歌集・百人一首、論語・孟子・荀子・韓非子・史記・戦国策・十八史略・唐詩 など）。引用するのは、**本文を正確に覚えている有名な一節だけ**にし、出典を明記する。自信がない箇所は、引用せずに短い作例（「作例」と明記）にする。現代語訳は自分で作る。
- 特定の大学名・年度を出典として書かない。

## 共通の書式ルール（必ず守る）
- 現代文の本文は `<div class="bun">…</div>`、古文の本文は `<div class="kobun">…</div>`、和歌は `<div class="waka">…</div>`、漢文は `<div class="kanbun">…</div>`。
- **漢文の書き方**：返り点は `<sub>`（赤字で漢字の左下に出る）、送り仮名は `<sup>`（カタカナ）。例：`<div class="kanbun">子曰<sup>ハク</sup>、学<sup>ビテ</sup>而時<sup>ニ</sup>習<sub>レ</sub>之<sup>ヲ</sup>、不<sub>二</sub>亦説<sup>バシカラ</sup><sub>一</sub>乎。</div>`。書き下し文・現代語訳は普通の段落か表で示す。
- 傍線は `<u>`、空欄は （　　）、選択肢は ①〜⑤。太字は `<b>`。表は `<table class="l w">`。
- 数式は使わない。`$` 記号を本文で使わない。
- 記述問題の解答例には字数を（〇〇字）と付け、**その字数が正しいことを Python の len() で確かめる**（句読点も1字）。
- 1つの章の分量の目安は見本（第1章）と同程度〜1.5倍。

## 書式の見本（まず必ず読む）

### 教科書（n_jpn_k）の章の構成
`<!--CH n-->` で始め、
1. `<div class="box point">` 章の要点（読解の原則・文法事項を3〜5行）
2. `<h3>講義k　見出し</h3>` + `<div class="box lect">`（読み方・考え方・文法の理由）+ `<div class="box ex">例題… <div class="solx"><b>解</b>…</div></div>` を3〜4セット
3. `<div class="box chk">` 確認問題（4問前後）
4. `<div class="box aim">` 入試の着眼点
5. `<h3 class="deep">講義k　…</h3>` 発展的な話題（背景知識・紛らわしい識別・応用）1つ
6. `<div class="box warn">` よくあるミス
7. 最後に `<div class="box ans">` 確認問題の答え（略解）

### 参考書（n_jpn_s）の章の構成
`<!--CH n-->` で始め、解法カードを 7〜9 枚：
```
<div class="pat"><h4>カードの題名（解法の要点を一言で）</h4>
<div class="when">どんな問題のときに使うか</div>
<div class="how">解き方の手順・公式・判断基準</div>
<div class="pex">例題文<br><b>解</b>　簡潔な解答</div>
<div class="pnote">失点しやすい注意点（任意）</div>
</div>
```
番号はビルダーが自動でつけるので書かない。章の最後に `<div class="box memo">` で重要表現の一覧表（`<table class="l w">`）を入れてもよい。

### 問題集（n_jpn_m）の章の構成
章ごとに Python ファイル `pNN.py`（NN は2桁の章番号）。p01.py と同じ形式：
- `CH = {n: {"goal": "...", "items": [ {"lv":"A|B|C", "tag":"任意", "q": r"...", "a": r"答えの要約", "s": r"くわしい解説（<b>ポイント</b>：… で締める）"}, ... ]}}`
- 1章あたり **A 4問・B 4〜5問・C 2問**（合計10〜11問）。A＝基本（語句・接続語・指示語・文法の識別・句法の書き下し）、B＝入試の典型（傍線部説明の選択肢・短い記述・現代語訳・和歌の解釈）、C＝難関大レベル（長めの文章での記述・要約・内容説明）。`"tag"` に問題形式を書く。
- 本文は q に入れる（p01.py の `B()` のようなヘルパーで `<div class="bun">` などに包む）。同じ本文に複数の設問をつけるときは、前の問題番号（例「1-9 の文章について」）で参照してよい。
- `def verify():` は p01.py と同じく形式の点検（lv の数・空欄がないか）と、**記述の解答例の字数チェック**（指定字数以内か）。

## 正確さの確認（最重要）
- 選択肢問題は**正解が1つに決まる**こと（他の選択肢には本文と食い違う点が必ずある）を確認する。
- 古典文法（活用表・助動詞の接続と意味・敬語の種類）、句法（読み方・意味）は教科書的に正確に。活用の種類・活用形の判定、助動詞の識別（「なり」「ぬ」「る・らる」「に」「なむ」など）の説明は、例文の上で正しいか一つずつ確かめる。
- 古典の引用は正確な本文だけ。現代語訳と本文が対応しているか確認。
- 字数制限つきの解答例は len() で字数を確認し、（〇〇字）の表示と一致させる。
- 解説は自己矛盾がないこと（書きながら訂正するような文を残さない）。
