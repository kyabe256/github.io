## どんな本か
市販の「網羅系」参考書・問題集（例題が1000題前後のもの）と同じ役割の本。全26章で例題約1000題。
- 入試で出る典型問題の型を**すべて**例題として網羅する（その単元で網羅系の本が扱う型は漏らさない）。
- 難易度は5段階：
  - ★1 基礎：教科書の例題レベル（定義・公式の直接の利用）
  - ★2 基本：教科書の章末・共通テストの基礎
  - ★3 標準：一般的な国公立・私大の入試の典型
  - ★4 発展：旧帝大・早慶・医学部の標準問題
  - ★5 最難関：東大・京大・医学部の難問レベル。**本気で難しくしてよい**（複数の発想の組合せ、鋭い評価、論証、場合分けの多い問題など）。ただし高校数学の範囲で、完全で正しい模範解答が書けるものに限る。
- 各章の配分の目安：★1 約20%、★2 約25%、★3 約25%、★4 約18%、★5 約12%（★5 は最低3題、大きい章は5〜7題）。
- **問題はすべてオリジナル**。既存の本・入試問題を写さない。特定の大学名・年度を出典として書かない（「最難関レベル」などの難易度表現は可）。
- 担当章の範囲（その科目とそれ以前の科目）の道具だけで解けること。例：数学I・A の章で微分を使わない。

## ファイルの形式（見本：SP/books/mou_math/example_c01.py を**必ず読む**）
- 1章1ファイル `mou_math/cNN.py`（NN は2桁の章番号）。
- `SEC = []` のあと、**節ごとに `SEC.append({...})`**。最後に `CH = {"no": 章番号, "sections": SEC}` と `def verify():`。
- 節：`{"title": 節の題, "base": r"基本事項（要点・公式を2〜5行）", "items": [例題, ...]}`。1章を 4〜9 節に分け、節の中は易しい順に並べる。
- 例題：`{"lv": 1〜5, "title": 例題の題（解法の型が分かる名前）, "q": 問題, "hint": 指針, "sol": 解答, "note": 検討（任意）, "ex": 練習, "exa": 練習の答え}`
  - **hint（指針）**：方針の立て方・着眼点を1〜3行。「なぜその方法を選ぶか」。
  - **sol（解答）**：答案として通用する模範解答。途中式の要点を省かない。証明問題は完全な証明。答えは `\boldsymbol{}` で強調。
  - **note（検討）**：別解・一般化・よくある誤り・関連する型（任意だが ★3 以上はできるだけ）。
  - **ex（練習）**：同じ考え方で解ける類題（数値や設定を変える）。難易度は例題と同程度。
  - **exa（練習の答え）**：答えだけ（短く）。証明問題の練習なら証明の要点を1〜2行で。
- 番号（例題 n・練習 n）はビルダーが巻の通し番号でつける。**本文中で他の例題の番号を参照しない**（「前の例題」「1.3 節の例題」などは可）。
- 文字列はすべて raw 文字列 `r"..."`。改行は `<br>`。

## 表記のルール
- 数式はインライン `$...$` のみ（`$$` は使わない）。大きく見せたいときは `$\displaystyle ...$` や `\dfrac`。
- 数式中の `<` `>` はそのまま書いてよい（ビルダーが変換）。数式の外の不等号は全角 ＜ ＞ か `&lt;` `&gt;`。
- 高校の標準記号：`\geqq` `\leqq` `\fallingdotseq`、組合せ `{}_n\mathrm{C}_r`、順列 `{}_n\mathrm{P}_r`、ベクトル `\vec{a}` `\overrightarrow{\mathrm{AB}}`、`\log` は底を明記（自然対数は数学III の章のみ `\log x`）。
- KaTeX で通る記法だけ。数式の中に日本語を入れない（`\text{}` で日本語を書かない）。
- 図は必要なときだけ `<svg class="fig" width="220" height="160" viewBox="0 0 220 160">…</svg>`（幅 260 以下、座標は Python で計算、文字は font-size 10〜12）。q や sol の中に置くと右側に回り込んで配置される。

## 正確さ（最重要）
- **例題の答え・練習の答えはすべて `verify()` の中で検算**する（sympy / fractions / 総当たり / 数値計算）。
  - 計算問題：答えの値・式を assert。最大最小・範囲は、数値サンプリングで端と内側を確認。
  - 場合の数・確率：全列挙か Fraction で厳密に。
  - 整数問題：十分広い範囲の総当たりで解がそれだけであることを確認。
  - 証明問題：使う恒等式を sympy で、主張を多数の数値例（ランダム）で確認。
- 解答の途中式も、その通りに計算すると答えになることを確かめる。書きながら訂正するような文（「…ではなく」「失礼」等）を残さない。
- 条件（$a\gt0$、$a\neq1$、実数条件、定義域、等号成立条件）の書き落としがないか確認する。
- verify() の最後で、例題数と難易度の配分も assert する（例：`len(items)` が目標±3、★5 が3題以上）。
