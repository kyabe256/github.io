## 書式の見本（まず必ず読む）
科目は違うが、**構成と書式は次の見本と同じ**にする（中身は真似しない）：
- 教科書: SP/books/n_math_k/part01.html（数式あり）と SP/books/n_jpn_k/part01.html（文章中心）
- 参考書: SP/books/n_math_s/part01.html
- 問題集: SP/books/n_math_m/p01.py（計算あり）と SP/books/n_jpn_m/p01.py（文章中心）
- 使える class: nyushi.py の CSS（point, lect, ex(+solx), chk, ans, aim, warn, memo / pat(when, how, pex, pnote)）。表は `<table class="l w">`、図は `<svg class="fig" ...>`。

### 教科書（_k）の章の構成
`<!--CH n-->` で始め、
1. `<div class="box point">` 章の要点（3〜5行）
2. `<h3>講義k　見出し</h3>` + `<div class="box lect">`（しくみ・理由・つながり）+ `<div class="box ex">例題… <div class="solx"><b>解</b>…</div></div>` を3〜4セット
3. `<div class="box chk">` 確認問題（4問前後）
4. `<div class="box aim">` 入試の着眼点
5. `<h3 class="deep">講義k　…</h3>` 発展的な話題1つ
6. `<div class="box warn">` よくあるミス
7. 最後に `<div class="box ans">` 確認問題の答え（略解）
分量の目安は1章あたり A4 で約3ページ（多くても4ページ）。

### 参考書（_s）の章の構成
`<!--CH n-->` で始め、解法カードを 7〜9 枚：
```
<div class="pat"><h4>カードの題名（解法・知識の要点を一言で）</h4>
<div class="when">どんな問題のときに使うか</div>
<div class="how">解き方の手順・公式・判断基準・整理のしかた</div>
<div class="pex">例題文<br><b>解</b>　簡潔な解答</div>
<div class="pnote">失点しやすい注意点（任意）</div>
</div>
```
番号はビルダーが自動でつけるので書かない。章の最後に `<div class="box memo"><table class="l w">…</table></div>` で重要事項の一覧表を入れる（年表・比較表・公式表など）。

### 問題集（_m）の章の構成
章ごとに `pNN.py`（NN は2桁の章番号）。形式は p01.py の見本と同じ：
- `CH = {n: {"goal": "...", "items": [ {"lv":"A|B|C", "tag":"問題形式", "q": r"...", "a": r"答えの要約", "s": r"くわしい解説（<b>ポイント</b>：… で締める）"}, ... ]}}`
- 1章あたり **A 4問・B 4〜5問・C 2問**。A＝基本（用語・基本計算・一問一答的な確認）、B＝入試の典型（計算・資料読解・正誤・論述の短いもの）、C＝難関大レベル（総合問題・論述）。小問 (1)(2)(3) で誘導してよい。
- `def verify():` で、**計算で答えが出る問題はすべて Python（sympy / fractions）で検算**する。文章の問題は形式の点検（lv の数・空欄がないか）と、論述の解答例の字数チェック（len()）。

## 表記のルール
- 数式・化学式・単位は KaTeX のインライン `$...$`（meta.json の math が true の科目）。**`$$` は使わない**。化学式は `$\mathrm{H_2SO_4}$`、イオンは `$\mathrm{Fe^{3+}}$`、矢印は `$\to$`、平衡は `$\rightleftarrows$`、単位は `$\mathrm{mol/L}$` のように。
- math が false の科目（生物・日本史・世界史）は `$` を使わず、化学式は HTML（CO<sub>2</sub>、Ca<sup>2+</sup>）で書く。
- 数式中の `<` `>` はビルダーが自動変換するのでそのまま書いてよい。数式の外の不等号は全角 ＜ ＞ か `&lt;` `&gt;`。
- 資料文・会話文・リード文は `<div class="bun">…</div>`、史料（原典の引用）は `<div class="shiryo">…</div>`。
- 英語（専門用語・人名の綴り）は必要なときだけ `<span class="en">…</span>`。
- 図が有効なところは SVG で描いてよい（座標は Python で計算して正確に、文字は font-size 10〜12）。

## 正確さの確認（最重要）
- 計算問題・例題の数値はすべて Python で検算してから書く。途中式もその通りに計算して答えになることを確かめる。有効数字・単位をそろえる。
- 用語の定義、法則・公式、年号・人名・出来事・地名・条約名などの事実は、確信があるものだけを書く。曖昧な事実は書かない（書き換えるか省く）。
- 選択肢・正誤問題は、正解が1つに決まること（他の選択肢には明確な誤りがあること）を確認する。
- 解説は自己矛盾がないこと（書きながら訂正するような文を残さない）。
- 検算スクリプトは SP/books/scratch_<担当名>/ に置いてよい。
