## 読者と水準
- 大学入試（共通テスト〜国公立二次・難関私大）を目指す高校生。英文法・語法、英文解釈、長文読解、和文英訳・自由英作文、リスニング。
- 説明は日本語で、わかりやすく、しかし文法的に正確に。英文は自然で正しい現代英語（アメリカ英語を基本）。
- **英文・問題はすべてオリジナル**（既存の入試問題・教材・新聞記事などを写さない。特定の大学名・年度を書かない）。長文はテーマの例：環境、テクノロジー、教育、言語、健康、文化、科学など。
- 文法用語は日本の高校で標準的なもの（第5文型、関係代名詞の非制限用法、仮定法過去完了、分詞構文 など）。

## 共通の書式ルール（必ず守る）
- **英文は必ず `<span class="en">...</span>` で囲む**（英語用の書体になる）。日本語の文中の短い英単語も同様。長文は `<p class="en">...</p>` でもよい。
- 下線は `<u>`、空所は `(　)`（全角スペース）、選択肢は「① ② ③ ④」。
- 太字は `<b>`。表は `<table class="l w">`。
- 数式は使わない（math は false）。`$` 記号を本文で使わない。
- 1つの章の分量の目安は見本（第1章）と同程度〜1.5倍。長文の章（17〜19）は 200〜350 語程度の英文を1〜2本含めてよい。

### 教科書（n_eng_k）の章の構成
`<!--CH n-->` で始め、
1. `<div class="box point">` 章の要点（文法事項・規則を3〜5行）
2. `<h3>講義k　見出し</h3>` + `<div class="box lect">`（なぜその形になるか・使い分け・訳し方）+ `<div class="box ex">例題… <div class="solx"><b>解</b>…</div></div>` を3〜4セット
3. `<div class="box chk">` 確認問題（4問前後）
4. `<div class="box aim">` 入試の着眼点
5. `<h3 class="deep">講義k　…</h3>` 発展的な話題（ネイティブの感覚・紛らわしい用法・応用）1つ
6. `<div class="box warn">` よくあるミス
7. 最後に `<div class="box ans">` 確認問題の答え（略解）

### 参考書（n_eng_s）の章の構成
`<!--CH n-->` で始め、解法カードを 7〜9 枚：
```
<div class="pat"><h4>カードの題名（解法の要点を一言で）</h4>
<div class="when">どんな問題のときに使うか</div>
<div class="how">解き方の手順・公式・判断基準</div>
<div class="pex">例題文<br><b>解</b>　簡潔な解答</div>
<div class="pnote">失点しやすい注意点（任意）</div>
</div>
```
番号はビルダーが自動でつけるので書かない。章の最後に `<div class="box memo">` で重要表現の一覧表（`<table class="l w">`）を入れてもよい。

### 問題集（n_eng_m）の章の構成
章ごとに Python ファイル `pNN.py`（NN は2桁の章番号）。p01.py と同じ形式：
- `CH = {n: {"goal": "...", "items": [ {"lv":"A|B|C", "tag":"任意", "q": r"...", "a": r"答えの要約", "s": r"くわしい解説（<b>ポイント</b>：… で締める）"}, ... ]}}`
- 1章あたり **A 4問・B 4〜5問・C 2問**（合計10〜11問）。A＝基本（文法4択・語彙）、B＝入試の典型（整序・正誤・空所補充・和訳・短めの読解）、C＝難関大レベル（長めの和訳・要約・英作文・長文の設問）。`"tag"` に問題形式（文法4択・整序・正誤・和訳・英作文・長文 など）を書く。
- 英作文の答えは模範解答を示し、別解や採点のポイントを解説に書く。長文問題は英文を q に入れ、設問を複数つけてよい（答え a にまとめて書く）。
- `def verify():` は p01.py と同じく形式の点検（lv の数・空欄がないか）。可能なら、4択の答えの番号が選択肢の範囲内かも点検。
- p01.py の `E()` 関数のように、英文を `<span class="en">` で囲むヘルパーを使ってよい。

## 正確さの確認（最重要）
- 文法問題は**正解が1つに決まる**ことを、選択肢を1つずつ当てはめて確認する（別の選択肢でも文法的に成り立つ問題を作らない）。
- 英文は文法・語法・コロケーションが自然か見直す。不自然な英語や、和訳と食い違う英文を残さない。
- 動詞の活用、不規則変化、可算・不可算、前置詞の選択など、事実関係を確かめる。
- 解説は自己矛盾がないこと（書きながら訂正するような文を残さない）。
