旧石器・縄文・弥生は「道具・生業・住まい」で区別する

遺物・遺跡・生活のようすを示した文の時代を判定する正誤問題。
時代道具生業・住まい代表的な遺跡
旧石器（更新世）打製石器（ナイフ形石器・尖頭器、終わりごろに細石器）。土器なしナウマンゾウなど大型動物の狩猟、移動生活岩宿遺跡（群馬）＝関東ローム層から打製石器
縄文（完新世）縄文土器・弓矢・磨製石器・骨角器狩猟・漁労・採集、竪穴住居、貝塚。土偶・抜歯・屈葬三内丸山遺跡（青森）＝大規模集落
弥生弥生土器・金属器（青銅器・鉄器）・石包丁・木製農具水稲耕作、高床倉庫、環濠集落。伸展葬、甕棺墓・方形周溝墓吉野ヶ里遺跡（佐賀）・登呂遺跡（静岡）
判定の順は ①土器があるか（なければ旧石器）→ ②稲作・金属器があるか（あれば弥生）。
次の文の正誤を判定せよ。「縄文時代の人々は、石包丁で稲の穂を摘み取り、収穫物を高床倉庫に蓄えた。」
解　誤り。石包丁（穂首刈り）と高床倉庫は弥生時代の稲作にともなうもの。
縄文時代晩期の水田跡が九州北部（佐賀県の菜畑遺跡、福岡県の板付遺跡）で見つかっている。「稲作＝弥生」は原則で、時期の境目を問う出題もある。黒曜石の分布（産地から遠く離れた場所で出土）は縄文時代の交易を示す。

青銅器の分布図は「銅鐸＝近畿、銅矛・銅戈＝九州北部」で読む

弥生時代の青銅器の分布を示した地図、または出土地を問う問題。
青銅器は大陸では武器だったが、日本では大型化して祭りの道具（祭器）になった（実用の武器・工具は鉄器）。分布のまとまり：銅鐸＝近畿地方を中心、平形銅剣＝瀬戸内海中部、銅矛・銅戈＝九州北部を中心。島根県の荒神谷遺跡（銅剣358本など）と加茂岩倉遺跡（銅鐸39個）の発見で、出雲にも大量の青銅器が集められていたことがわかった。
九州北部を中心に分布し、大型化して祭器となった青銅器を2つ答えよ。
解　銅矛・銅戈
地図問題では「近畿に集中する記号」がまず銅鐸。銅鐸の表面に描かれた絵（臼と杵による脱穀、高床倉庫など）は弥生時代の生活を知る手がかりになる。

キーワードと読み取る内容：

時期墳丘・分布埋葬施設副葬品と被葬者の性格

初期荘園と寄進地系荘園は「成立のしかた」と「税の扱い」で区別する

荘園の種類・成立の過程・荘園整理令を問う問題。
初期荘園（8〜9世紀）＝墾田永年私財法を背景に、貴族・大寺院が国司・郡司の協力で開墾・買収した土地。租を納める輸租田。郡司の力の衰えとともに多くが衰退。
寄進地系荘園（11世紀以降）＝開発領主が国司の圧迫を逃れるため、中央の貴族・寺社に土地を寄進して領家とし、さらに上級の皇族・摂関家に寄進して本家とする。開発領主は荘官（預所・下司など）として実際の支配を続ける。
不輸の権＝官物・臨時雑役の免除（太政官符・民部省符で認められた官省符荘、国司が認めた国免荘）。不入の権＝国司が派遣する検田使の立ち入りを拒む。
荘園整理令：延喜（902年、醍醐天皇）＝効果は限定的。延久（1069年、後三条天皇）＝記録荘園券契所を置き、証拠書類の不備な荘園を停止。摂関家の荘園も例外としなかった。
肥後国鹿子木荘の例では、開発領主の子孫が貴族に寄進して年貢の一部を納め、自分は預所として荘園の管理を続けた。さらにその貴族の子孫が皇族に寄進した。このとき、最初の寄進先と2番目の寄進先を何とよぶか。
解　最初の寄進先＝領家、2番目の上級の寄進先＝本家。

承久の乱の論述は「朝廷と幕府の力関係の変化」を軸に組み立てる

背景：後鳥羽上皇が西面の武士を置き、院政の強化をはかる。1219年 源実朝が暗殺され、上皇と幕府の関係が悪化。
経過：1221年 上皇が北条義時追討の命令を出す → 北条政子が御家人に頼朝の恩を説く → 幕府軍（北条泰時・時房）が京都を占領。
結果：①後鳥羽（隠岐）・土御門（土佐、のち阿波）・順徳（佐渡）の3上皇を配流、仲恭天皇を廃位。②京都に六波羅探題を置き、朝廷を監視・西国の御家人を統轄。③上皇方の所領3000余カ所を没収し、東国御家人を新補地頭に。
→ 影響：幕府の支配が西国にも及び、皇位の継承にも幕府が介入するなど、幕府が朝廷に優越した。
承久の乱が朝廷と幕府の関係に与えた影響を、60字程度で述べよ。
解　幕府は上皇方の所領を没収して新補地頭を置き、六波羅探題で朝廷を監視したので、幕府の力が西国に及び朝廷に優越した。

元禄と正徳の貨幣改鋳は「金の含有量を減らしたか、戻したか」で区別する

綱吉の政治と正徳の政治の財政・貨幣・貿易政策を問う問題。
綱吉：明暦の大火後の再建や寺社造営で財政が悪化 → 勘定吟味役（のち勘定奉行）荻原重秀の意見で、1695年 元禄金銀（金の含有量を減らす）→ 差益（出目）で幕府の収入は増えたが、物価が上昇。
正徳の政治：新井白石が 1714年 正徳金銀（品位を慶長金銀の水準に戻す）で物価の安定をはかる。1715年 海舶互市新例（長崎新令）＝金銀の流出を防ぐため、清船は年30隻・銀6000貫、オランダ船は年2隻・銀3000貫に貿易額を制限。将軍の権威を高めるため閑院宮家を創設し、朝鮮通信使の待遇を簡素にして、国書の将軍の称号を「日本国王」とした。
次の文の正誤を判定せよ。「新井白石は、金の含有量を減らした小判を発行して幕府の収入を増やしたが、物価の上昇を招いた。」
解　誤り。説明は綱吉時代の元禄金銀（荻原重秀）。白石は品位を戻した正徳金銀を発行した。
吉宗の元文金銀（1736年）は品位を下げて通貨量を増やし、低迷していた米価を引き上げるねらいがあった。「品位を下げる＝悪い政策」と決めつけない。

国学者は「契沖 → 荷田春満 → 賀茂真淵 → 本居宣長 → 平田篤胤」の流れでつかむ

国学者と主著・主張の組合せ問題。国学が幕末の思想に与えた影響を問う問題。
契沖『万葉代匠記』（『万葉集』の実証的研究）→ 荷田春満（国学の学校の設立を幕府に願う）→ 賀茂真淵『国意考』（儒教・仏教が伝わる前の日本古来の精神を重視）→ 本居宣長『古事記伝』（伊勢松坂の医師、「もののあはれ」、漢意を排除）→ 平田篤胤（復古神道を説き、幕末の尊王攘夷運動に影響）。
塙保己一は幕府の援助で和学講談所を開き、『群書類従』を編纂した。
日本の古典を研究して、儒教・仏教の影響を受ける以前の日本人の心を明らかにしようとし、『古事記伝』を著した人物はだれか。
解　本居宣長
「国学は幕府の正学」は誤り（正学は朱子学）。国学の天皇中心の考えは、水戸学とともに尊王論を支えた。

洋学の発達は「吉宗の緩和 → 解体新書 → 幕府の翻訳機関 → 弾圧」の順で整理する

洋学者と業績の組合せ問題、洋学の発達を年代順に並べる問題。
先駆：西川如見『華夷通商考』、新井白石『西洋紀聞』『采覧異言』（潜入した宣教師シドッチを尋問して著す）。
1720年 吉宗が漢訳洋書の輸入制限をゆるめ、青木昆陽・野呂元丈にオランダ語を学ばせる。
1774年 前野良沢・杉田玄白らが『解体新書』（オランダ語の解剖書を翻訳）。のちに玄白は回想録『蘭学事始』。大槻玄沢（芝蘭堂、『蘭学階梯』）、稲村三伯（蘭日辞書『ハルマ和解』）、平賀源内（エレキテル）。
幕府の事業：天文方の高橋至時（寛政暦）、伊能忠敬の全国測量（『大日本沿海輿地全図』）、1811年 天文方に蛮書和解御用（翻訳機関）。
弾圧：1828年 シーボルト事件（国外持ち出し禁止の地図）、1839年 蛮社の獄。蘭学は医学・天文学など実用の学問として発達し、政治批判は抑えられた。緒方洪庵の適塾（大坂）、シーボルトの鳴滝塾（長崎）で人材が育つ。
次のⅠ〜Ⅲを年代の古い順に並べよ。Ⅰ　『解体新書』が刊行された。Ⅱ　徳川吉宗が漢訳洋書の輸入制限をゆるめた。Ⅲ　幕府が天文方に蛮書和解御用を設けた。
解　Ⅱ（1720年）→ Ⅰ（1774年）→ Ⅲ（1811年）

経世論・尊王論は「何を主張し、どう処罰されたか」で区別する

江戸中・後期の思想家と主張・事件の組合せ問題。
封建社会の批判：安藤昌益『自然真営道』（武士が農民を支配する社会を批判し、万人が自ら耕す自然の世を理想とした）。
経世論（社会・経済の改革策）：太宰春台『経済録』（藩の専売）、海保青陵（商業を卑しまない）、本多利明『経世秘策』（開国・貿易・蝦夷地開発）、佐藤信淵。
町人の思想：石田梅岩の心学（商業の利益を正当なものとし、正直・倹約を説く）。大坂の懐徳堂から富永仲基、山片蟠桃（『夢の代』で地動説・無鬼論）。
尊王論：宝暦事件（1758年、竹内式部が京都で公家に尊王論を説き処罰）、明和事件（1767年、山県大弐が処刑）。水戸学（『大日本史』の編纂から。藤田幽谷・東湖、会沢安『新論』）が尊王攘夷論を唱えた。
海防論：林子平『海国兵談』『三国通覧図説』（寛政の改革で処罰）。
次の文の正誤を判定せよ。「安藤昌益は、すべての人が自ら耕作して生活する社会を理想とし、武士が農民から年貢を取る身分社会を批判した。」
解　正しい。
二宮尊徳（報徳仕法）・大原幽学（性学）は、農村の復興を実践した人物。思想家と実践家を混同しない。
