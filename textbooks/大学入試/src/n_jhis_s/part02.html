日米和親条約と日米修好通商条約は「開港地」と「不平等な条項」で区別する

開国の条約の内容・締結者・不平等性を問う問題。
日米和親条約（1854年）日米修好通商条約（1858年）
日本側老中 阿部正弘大老 井伊直弼（孝明天皇の勅許なしに調印）
相手ペリー総領事 ハリス
開港下田・箱館箱館に加え神奈川・長崎・新潟・兵庫（神奈川開港後に下田は閉鎖）。江戸・大坂の開市
主な内容燃料・食料の供給、漂流民の救助、下田に領事を置く、アメリカに一方的な最恵国待遇自由貿易、居留地、領事裁判権を認める、関税は相互の協定で決める（関税自主権がない）
同様の条約をオランダ・ロシア・イギリス・フランスとも結ぶ（安政の五カ国条約）。日露和親条約（1854年）では、国境を択捉島と得撫島の間とし、樺太は両国人の雑居地とした。
次の文の正誤を判定せよ。「日米和親条約によって、日本はアメリカに領事裁判権を認め、横浜・長崎などで自由な貿易が始まった。」
解　誤り。領事裁判権と自由貿易は日米修好通商条約。和親条約は下田・箱館の開港と燃料・食料の供給などを定めたもので、貿易は始まっていない。
「神奈川」は実際には横浜、「兵庫」は神戸が開港地となった。ペリー来航時、阿部正弘は朝廷に報告し諸大名にも意見を求めた → 朝廷の権威が高まり、大名の発言力が強まるきっかけとなった。

開港後の貿易は「横浜・イギリス・生糸」と「金の流出 → 万延小判」で答える

開港が日本の経済・社会に与えた影響を問う問題（論述を含む）。
1859年 横浜・長崎・箱館で貿易開始。最大の貿易港は横浜、最大の相手国はイギリス（アメリカは南北戦争で後退）。
輸出品：生糸（最大）・茶・蚕卵紙・海産物 ／ 輸入品：毛織物・綿織物・武器・艦船。初めは輸出超過。
影響：①輸出品の生産が追いつかず物価が上昇。安い綿織物の輸入で国内の綿作・綿織物業が打撃。②生糸などが産地から横浜へ直送され、江戸の流通が混乱 → 1860年 五品江戸廻送令（雑穀・水油・蠟・呉服・生糸は江戸の問屋を通す）→ 外国と在郷商人の反対で効果なし。③金と銀の交換比率が日本（約1：5）と外国（約1：15）で違い、金貨が大量に流出 → 幕府は金の含有量を大きく減らした万延小判を発行 → 物価がさらに上昇。
→ 生活の苦しくなった下級武士・民衆の不満が攘夷運動を高めた。
開港によって金貨が国外に大量に流出した理由と、幕府の対策を説明せよ。
解　金銀の交換比率が国内は約1対5、外国は約1対15で、外国の銀を日本の金に替えると利益が出たため。幕府は金の含有量を減らした万延小判を発行して流出を防いだが、物価の上昇を招いた。

幕末の政局は「1863〜64年」を境に、攘夷から倒幕への転換で整理する

幕末の事件を年代順に並べる問題、薩摩・長州の動きを問う問題。
井伊直弼の時代：将軍継嗣問題（一橋派＝徳川慶喜 ⇔ 南紀派＝徳川慶福、慶福が家茂となる）、1858〜59年 安政の大獄（吉田松陰・橋本左内ら処刑）→ 1860年 桜田門外の変。

次のⅠ〜Ⅲを年代の古い順に並べよ。Ⅰ　長州藩が京都に攻め上り、会津・薩摩などの兵に敗れた。Ⅱ　イギリス人殺傷事件の報復として、イギリス艦隊が鹿児島を攻撃した。Ⅲ　坂本龍馬らの仲介で、薩摩藩と長州藩が軍事同盟の密約を結んだ。
解　Ⅱ（薩英戦争 1863年）→ Ⅰ（禁門の変 1864年）→ Ⅲ（薩長同盟 1866年）
「八月十八日の政変＝長州が京都から追放される（1863年）」「禁門の変＝長州が武力で京都に入ろうとして敗れる（1864年）」。順序が逆の選択肢に注意。

版籍奉還と廃藩置県は「旧藩主の地位」で区別する

中央集権化の過程を問う問題。
版籍奉還（1869年）＝薩長土肥の4藩主が土地（版）と人民（籍）を天皇に返すことを願い出て、他藩も続く。旧藩主はそのまま知藩事に任命 → 藩の実態は残る。
廃藩置県（1871年）＝薩摩・長州・土佐の兵からなる御親兵の武力を背景に、藩を廃止して府県を置く。知藩事は罷免されて東京に住むこととされ、中央から府知事・県令を派遣。はじめ3府302県、同年中に3府72県に整理。
→ 藩の借金は政府が引き継ぎ、旧藩主・藩士には家禄を支給（のち1876年に秩禄処分で打ち切り、金禄公債証書を与える）。
身分：華族（旧公家・大名）・士族・平民。1871年 いわゆる解放令で、えた・非人の呼称を廃止。
次の文の正誤を判定せよ。「版籍奉還によって旧藩主は地位を失い、中央政府から派遣された県令が各地を治めることになった。」
解　誤り。説明は廃藩置県。版籍奉還では旧藩主が知藩事として藩の政治を続けた。
秩禄処分と廃刀令（1876年）で士族の特権が失われ、士族反乱（1874年 佐賀の乱 〜 1877年 西南戦争）につながる。

地租改正は「課税基準・税率・納め方・納税者」の4点で年貢と比べる

地租改正の内容・目的・影響を問う問題（論述の定番）。学制・徴兵令とあわせた三大改革。
江戸時代の年貢地租（1873年 地租改正条例）
課税基準収穫高（石高）地価（地券に記載）
税率藩ごとにばらばら・豊凶で変動地価の3%（豊作・凶作にかかわらず一定）
納め方米など現物金納
納税者耕作者（村単位で納入）土地所有者（地券所有者）

学制（1872年、フランスにならう、国民皆学）、徴兵令（1873年、満20歳以上の男子に兵役、初めは免除規定が多い。「血税」の語から血税一揆）。

明治十四年の政変の論述は「払下げ事件 → 大隈追放 → 国会開設の勅諭」の因果で書く

「明治十四年の政変の背景と結果」などの論述。
背景：国会開設を求める運動が高まる中、政府内では早期の国会開設とイギリス流の議院内閣制を主張する大隈重信と、慎重な伊藤博文らが対立。1881年、北海道開拓使長官黒田清隆が官有物を同じ薩摩出身の商人らに安く払い下げようとした開拓使官有物払下げ事件で世論が政府を激しく攻撃。
内容：政府は払下げを中止し、世論と結んでいるとみた大隈を罷免。同時に国会開設の勅諭を出して、1890年の国会開設を約束。
結果・影響：①伊藤博文を中心とする薩長藩閥政府の体制が固まる。②ドイツ流の君主権の強い欽定憲法をつくる方針が決まる。③民権派は国会開設に備えて政党を結成（自由党・立憲改進党）。④大蔵卿が松方正義に代わり、緊縮財政（松方財政）へ。
明治十四年の政変の内容と、それが憲法制定に与えた影響を60字程度で述べよ。
解　開拓使官有物払下げ事件の批判の中で政府は大隈重信を追放し、国会開設を約束するとともに、ドイツ流の欽定憲法を制定する方針を固めた。

解　デフレで米や繭の価格が下がり、定額金納の地租の負担が重くなったため、自作農の多くが土地を失って小作農となり、地主に土地が集中した。

普通選挙法と治安維持法が同じ1925年に成立した理由を論述する

「普通選挙法と治安維持法が同時期に制定された理由」などの論述。
背景：1924年 貴族院を基盤とする清浦奎吾内閣に対し、憲政会・立憲政友会・革新倶楽部の護憲三派が第二次護憲運動 → 総選挙で勝利し加藤高明内閣。
内容：普通選挙法＝納税資格を撤廃し、満25歳以上の男子に選挙権。治安維持法＝「国体」の変革や私有財産制度の否認を目的とする結社を組織・加入した者を処罰。
理由：①選挙権の拡大で労働者・農民が政治に参加し、社会主義勢力が議会に進出することを警戒。②同じ1925年の日ソ基本条約でソ連と国交を結び、共産主義思想の流入を防ぐ必要があった。
その後：1928年 田中義一内閣が緊急勅令で最高刑を死刑に引き上げ、全国に特別高等警察（特高）を設置。
普通選挙法とともに治安維持法が制定された理由を、60字程度で述べよ。
解　選挙権の拡大で無産政党などの社会主義勢力が台頭することや、日ソ国交樹立にともなう共産主義思想の広がりを取り締まるため。
普通選挙法による最初の総選挙は1928年。このとき無産政党から当選者が出たことが、直後の共産党員の一斉検挙（三・一五事件）につながった。

女性の地位の変化は「相続」と「参政権」の2本で整理する

女性の歴史を時代をこえて問う問題。
古代：女性の王・天皇（卑弥呼、推古から称徳まで6人8代の女性天皇）。律令では女性にも口分田（男子の3分の2）、調・庸・雑徭は男子の負担。平安時代の女房（紫式部・清少納言）の文学、妻問婚。
中世：鎌倉時代は分割相続で女性も所領を相続し、女性の地頭もいた。御成敗式目は女性が養子に所領を譲ることを認めた。後期には本人一代限りの一期分が増え、地位が低下。室町時代には嫁入婚が一般化。
近世：家を継ぐのは原則として男子。『女大学』などで従順を説く。明正天皇・後桜町天皇の女性天皇。
近代：1871年 津田梅子らの留学。1898年 明治民法（戸主の権限が強い家制度）。治安警察法で政治活動を制限 → 1911年 青鞜社 → 1920年 新婦人協会 → 1922年 政治集会への参加が可能に → 1924年 婦人参政権獲得期成同盟会。
戦後：1945年 女性参政権、1946年の総選挙で女性議員39人。1947年 民法改正（家制度の廃止）。1985年 男女雇用機会均等法、1999年 男女共同参画社会基本法。
次の文の正誤を判定せよ。「鎌倉時代の武士の家では、女性は所領を相続することが認められず、惣領が単独で所領を受け継いだ。」
解　誤り。鎌倉時代は分割相続が原則で、女性も所領を相続できた。単独相続が広がるのは鎌倉後期から室町時代にかけて。
