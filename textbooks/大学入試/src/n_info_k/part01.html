・データ（事実や観測の記録）を目的に応じて整理し意味をもたせたものが情報、情報を蓄積・体系化して問題解決に使えるようにしたものが知識
・情報の特性：残存性（渡しても手元から消えない）・複製性（簡単に複製できる）・伝播性（すばやく広く伝わる）。デジタル化でこの3つがいっそう強まった
・メディアには「表現」「伝達」「記録」の3つの意味がある。情報は一次情報（原典）にさかのぼり、複数の情報源で確かめる
・IoT・ビッグデータ・AI が結びつき、現実の世界（フィジカル空間）と仮想の世界（サイバー空間）が融合した社会へ変わりつつある
・問題解決は「発見 → 明確化 → 情報の収集・分析 → 解決案の検討・決定 → 実行 → 評価」。改善をくり返す考え方が PDCA サイクル

講義1　データ・情報・知識と情報の特性

「今朝6時の気温は 18.2 ℃」という記録はデータである。これに「平年より 4 ℃低い」と比較を加えて意味をもたせると情報になり、「平年より寒い朝は体調を崩しやすいので、一枚多く着るとよい」のように経験や他の情報と結びつけて判断に使える形にしたものが知識である。同じデータでも、受け手や目的によって価値は変わる（個別性）。
情報には、形のある「もの」とは違う性質がある。
・残存性：人に伝えても、自分の手元（記憶・ファイル）から消えない。いったん広まった情報は回収できない。
・複製性：容易に複製できる。デジタルデータは何度複製しても劣化しない。
・伝播性：短時間で広い範囲に伝わる。インターネットでは一人の投稿が世界中に届く。
この3つは便利さの源であると同時に、個人情報の流出や著作物の無断複製、デマの拡散といった問題の原因にもなる（第2章）。
(1) 次の①〜③は、情報のどの特性によるものか。
① 誤って送信したメールを取り消しても、相手のもとには届いたまま残っている。
② 動画の違法なコピーが大量に出回り、制作会社が損害を受けた。
③ ある店の口コミが SNS で共有され、翌日には全国から客が訪れた。
(2) 次の a〜c を、データ・情報・知識に分類せよ。
a 「この1か月、雨の日は来店者数が晴れの日のおよそ半分だった」
b 「6月3日 雨 来店者 42人」「6月4日 晴れ 来店者 85人」…という記録
c 「雨の予報の日は仕入れを減らし、雨の日限定の割引で集客するとよい」
解　(1) ① 残存性（送った側の操作で消せない）　② 複製性　③ 伝播性
(2) b は記録そのものなのでデータ、a は記録を整理・比較して意味をもたせたので情報、c は情報をもとに行動の判断に使える形にしたので知識。

講義2　メディアとコミュニケーション、情報の信頼性

メディア（媒体）という言葉には3つの意味がある。
・表現のメディア：文字・音声・図・画像・動画など、情報を表す手段
・伝達のメディア：新聞・テレビ・電話・インターネットなど、情報を伝える手段
・記録のメディア：紙・USB メモリ・光ディスク・SSD など、情報を保存する手段
コミュニケーションは、送り手と受け手の人数（1対1：電話・電子メール、1対多：放送・Web ページ、多対1：アンケート・投票、多対多：SNS・電子掲示板）や、やりとりが同時に行われるかどうか（同期型：対面・電話・ビデオ会議、非同期型：電子メール・SNS の投稿・掲示板）で分類できる。
情報の信頼性を確かめるには、①発信者は誰か（専門性・利害関係）、②いつの情報か、③根拠（データや調査方法）は示されているか、④一次情報（調査した本人・当事者が出した原典）か、他者がまとめ直した二次情報か、を確認し、⑤複数の独立した情報源で照合する（クロスチェック）。
人には自分の考えに合う情報ばかり集めてしまう傾向（確証バイアス）がある。また、SNS や検索サービスが利用者の好みに合わせて情報を選んで表示するため、似た情報ばかりに囲まれる状態（フィルターバブル）や、同じ意見の人どうしで意見が強まる状態（エコーチェンバー）も起こる。情報を主体的に読み解き、評価し、発信する力をメディアリテラシーという。
SNS で「飲料 X を毎日飲むと記憶力が 2 倍になると研究で判明！」という投稿が大量に共有されている。この情報の信頼性を確かめる行動として適切なものをすべて選べ。
① 共有された回数が多いので、正しい情報だと判断する。
② 投稿が根拠とする研究の論文や発表（一次情報）を探し、誰が・どのように調べたのかを確認する。
③ 報道機関や公的機関など、投稿者と独立した複数の情報源に同じ内容があるか調べる。
④ 自分も以前から効果があると思っていたので、その考えを支持する記事だけを読む。
⑤ 投稿者が飲料 X の販売元と関係していないか確かめる。
解　②・③・⑤。①共有数は正しさの根拠にならない。④は確証バイアスそのもの。⑤は利害関係の確認で、宣伝目的の情報を見抜く手がかりになる。

講義3　情報社会の変化 ― IoT・ビッグデータ・AI

・IoT（モノのインターネット）：家電・自動車・工場の機械・センサーなど、あらゆるモノがネットワークにつながり、データをやりとりするしくみ。
・ビッグデータ：センサーの測定値、購買履歴、位置情報、SNS の投稿など、量が膨大で、種類が多様で、発生する頻度が高いデータ。
・AI（人工知能）：大量のデータから規則性を学習し（機械学習）、予測・分類・判断を行う技術。文章や画像をつくる生成 AI も広まったが、もっともらしい誤りを出力することがあるため、内容を確かめて使う必要がある。
これらは「IoT でデータを集める → ビッグデータとして蓄積する → AI で分析する → 結果を現実の世界に返す（機械の制御・人への提案）」という流れで結びつく。日本ではこうしたしくみで経済の発展と社会的課題の解決を両立する社会を Society 5.0 とよんでいる（狩猟・農耕・工業・情報に続く5番目の社会）。
一方で、情報技術を使える人と使えない人の格差（デジタルデバイド）、大量の個人データの扱い（プライバシー）、システム障害が社会全体に及ぼす影響などの課題もある。
次の農業のしくみについて答えよ。
温室に温度・湿度・土の水分を測るセンサーを置き、10分ごとの測定値をインターネット経由でクラウド上のサーバに送る。サーバには何年分もの測定値と収穫量の記録が蓄えられており、コンピュータがそこから「収穫量が多くなる水やりの条件」を学習して、散水装置を自動で動かす。
(1) IoT、ビッグデータ、AI にあたる部分をそれぞれ答えよ。　(2) このしくみの課題を1つ挙げよ。
解　(1) IoT：センサーや散水装置がネットワークにつながり、測定値を送ったり遠隔で動かされたりする部分。ビッグデータ：サーバに蓄えられた何年分もの測定値と収穫量の記録。AI：記録から水やりの条件を学習して判断する部分。
(2) 例：通信障害やサーバの故障で散水が止まるおそれがある／不正アクセスで装置を操作される危険がある／導入費用がかかり、使いこなせる人とそうでない人の差が生まれる。

講義4　問題解決の手順と PDCA サイクル

問題とは「あるべき姿（理想・目標）と現状のギャップ」である。問題解決は次の手順で進める。
①問題の発見 → ②問題の明確化（目標を「いつまでに・何を・どれだけ」と数値で決める） → ③情報の収集・分析（原因を調べる） → ④解決案の検討・決定 → ⑤実行 → ⑥評価（目標を達成できたか、手順に問題はなかったか）。
一度で解決しないことも多いので、PDCA サイクル（Plan 計画 → Do 実行 → Check 評価 → Act 改善）を回し、改善を次の計画に生かす。
アイデアを出すときはブレーンストーミング（①他人の意見を批判しない、②自由奔放に、③質より量、④他人の意見に便乗・結合してよい）、出たアイデアを整理するときは、カードをグループにまとめて関係を図にする KJ 法や、中心のテーマから枝分かれさせて書くマインドマップが使われる。
図書委員会が「図書室の貸出冊数を増やす」ことに取り組む。次の a〜d を PDCA の P・D・C・A に分類し、P の段階で決めるべき目標の例を1つ書け。
a 4月と6月の貸出冊数を比べたところ、1年生だけが増えていなかった。
b 1年生向けに、各教科の先生のおすすめ本コーナーを設けることにした。
c 委員が毎週、新着本の紹介ポスターを掲示した。
d 生徒へのアンケートをもとに、新着本の紹介ポスターを毎週掲示する計画を立てた。
解　d → P（計画）、c → D（実行）、a → C（評価）、b → A（評価をもとにした改善。次の P につながる）。
目標の例：「7月末までに、1か月の貸出冊数を4月の1.5倍にする」。達成できたかを C で判断できるよう、期限と数値を入れる。
(1) 次のうち一次情報はどれか。　ア 新聞記事で紹介された世論調査の結果　イ 自分たちで実施したアンケートの集計結果　ウ 友人から聞いた、ある店の評判
(2) 次のコミュニケーション手段を、同期型と非同期型に分けよ。　ア 電話　イ 電子メール　ウ ビデオ会議　エ SNS への投稿
(3) ブレーンストーミングの進め方として不適切なものを1つ選べ。　ア 思いついたことは実現性を気にせず出す　イ 実現できそうにない意見は、その場で指摘して取り下げてもらう　ウ 他人の意見を組み合わせて新しい案を出す
(4)「友人にだけ送った写真が、受け取った人によって次々に転送され、短時間で多くの人に見られた」ことに最も関係が深い情報の特性を2つ挙げよ。
共通テストでは、具体的な場面を読んで「どの特性・どの段階・どの手法にあたるか」を判断させる出題が中心。用語を暗記するだけでなく、定義のキーワード（残存性＝手元から消えない、複製性＝コピーできる、伝播性＝広がる）を事例に当てはめる練習をしておく。問題解決では、目標の数値化と評価（C）の重要性がよく問われる。情報の信頼性では「一次情報にあたる」「複数の情報源で確かめる」「発信者の利害を考える」が正解の柱になる。

講義5　解決案を選ぶ ― 重み付け評価とトレードオフ

解決案が複数あるとき、「効果は大きいが費用がかかる」のように、ある条件をよくすると別の条件が悪くなる関係（トレードオフ）がしばしば生じる。そこで、評価項目に重み（重要度）をつけて点数化し、比較する方法がある。

上の図書室の例で、3つの案を「効果」「費用の低さ」「実現のしやすさ」で5段階評価し、重み（効果3・費用2・実現1）を掛けて合計した。
案効果（×3）費用の低さ（×2）実現のしやすさ（×1）合計
A 朝読書の時間を設ける5 → 154 → 82 → 225
B おすすめ本の掲示3 → 95 → 105 → 524
C 電子書籍の導入4 → 121 → 23 → 317
この重みでは A が選ばれる。しかし「すぐに始められること」を最も重視して重みを効果1・費用2・実現3にすると、A は $5+8+6=19$、B は $3+10+15=28$、C は $4+2+9=15$ となり、B が選ばれる。
このように、結論は重みの決め方に左右される。重み付け評価を使うときは、何を重視するのかを関係者で話し合って先に決め、その根拠を説明できるようにしておくことが大切である。
・複製性と伝播性の取り違え。「コピーが出回る」は複製性、「短時間に広く伝わる」は伝播性。SNS の拡散は両方が関わるが、問われている側面（コピーされること／広がる速さ・範囲）で判断する。
・「多くの人が共有している」「検索で上位に出る」ことを信頼性の根拠にしてしまう。
・PDCA の C（評価）を「感想を言うこと」と考える。C は、P で決めた数値目標と結果を比べることである。
(1) イ（ア は新聞社がまとめ直した二次情報、ウ は伝聞）　(2) 同期型：ア・ウ、非同期型：イ・エ　(3) イ（批判しないのがルール）　(4) 複製性（転送のたびに複製される）と伝播性（短時間で広く伝わる）
・知的財産権＝人の知的な創作物を守る権利。産業財産権（特許権・実用新案権・意匠権・商標権）は特許庁に出願・登録して発生し、著作権は創作した時点で自動的に発生する（登録不要）
・著作者の権利は、著作者人格権（公表権・氏名表示権・同一性保持権。譲渡できない）と著作権（財産権）（複製権・公衆送信権など。譲渡・相続できる）。保護期間は原則著作者の死後70年
・引用は、必然性・主従関係・明確な区別・出所の明示などの条件を満たせば、許諾なしにできる
・個人情報＝生存する個人を識別できる情報。事業者は利用目的を示し、本人の同意なく第三者に提供してはならない（例外あり）
・他人の ID・パスワードを無断で使うログインは不正アクセス禁止法違反

講義1　知的財産権の全体像

発明や作品は「情報」なので、複製性・伝播性によって簡単にまねされてしまう。そこで、創作した人に一定期間の独占的な権利を与えて、創作の意欲を守るしくみが知的財産権である。
権利守る対象権利の発生保護期間
特許権発明（自然法則を利用した高度な技術的アイデア）出願し、審査を経て登録出願から20年
実用新案権考案（物品の形状・構造・組合せの工夫）出願・登録（技術内容の審査は行わない）出願から10年
意匠権物品などのデザイン（形・模様・色彩）出願し、審査を経て登録出願から25年
商標権商品やサービスの名称・マーク出願し、審査を経て登録登録から10年（更新できる）
著作権著作物（小説・音楽・絵画・写真・映画・プログラムなど）創作した時点で自動的に（無方式主義）原則 著作者の死後70年
上の4つが産業財産権で、産業の発達を目的とする。これに対し著作権は文化の発展を目的とする。ほかに、植物の新品種を守る育成者権や、企業の営業秘密を守るしくみ（不正競争防止法）などもある。商標権だけは更新をくり返せば実質的に永続できるのは、商標が「長年の信用」を表すものだからである。
次の①〜⑤を守る権利として最も適切なものを答えよ。
① 新しい原理で充電時間を大幅に短くした電池　② 清涼飲料水の商品名とロゴマーク　③ 新しい形の椅子のデザイン　④ 自分で作曲した曲　⑤ 定規の縁に滑り止めをつけるという、形状の工夫
解　① 特許権（高度な技術的アイデア＝発明）　② 商標権　③ 意匠権　④ 著作権（作曲した時点で発生）　⑤ 実用新案権（物品の形状の工夫＝考案）

講義2　著作権のしくみと例外

著作物とは「思想または感情を創作的に表現したもの」である。したがって、単なる事実やデータ（「昨日の最高気温は 35 ℃」）、アイデアそのもの、ありふれた表現は著作物ではない。プログラムは著作物だが、そのもとになったアルゴリズム（考え方）自体は保護されない。
著作者には次の権利がある。
・著作者人格権：公表権（公表するかどうか、いつ公表するかを決める）・氏名表示権（名前を表示するか、どう表示するかを決める）・同一性保持権（意に反して内容や題名を改変されない）。著作者だけがもち、譲渡できない。
・著作権（財産権）：複製権・公衆送信権（インターネットで公開する、放送する）・上演権・演奏権・譲渡権・貸与権・翻案権（編曲・映画化など）など。譲渡・相続できる。
・著作隣接権：歌手・演奏家などの実演家、レコード製作者、放送事業者など、著作物を人々に伝える人の権利。
著作物を使うには原則として許諾が必要だが、例外として、私的使用のための複製（自分や家族など限られた範囲で使うためのコピー）、引用、学校の授業で必要な範囲の複製、営利を目的としない上演・演奏（入場無料・出演者に報酬なし）などは許諾なしにできる。ただし、違法にアップロードされたものと知りながらダウンロードすることは、私的使用の目的でも違法になる場合がある。
次の①〜⑤のうち、正しいものをすべて選べ。
① 著作権は、著作物を文化庁に登録した時点で発生する。
② 購入した音楽 CD の曲を、自分だけで聴くために自分のスマートフォンに複製するのは、私的使用のための複製として認められる。
③ 購入したマンガをスキャンし、誰でも閲覧できる Web サイトに掲載しても、紙の本を持っているので問題ない。
④ 著作者人格権は、出版社などに譲渡することができる。
⑤ 新聞に載っていた「昨日の最高気温は 35 ℃だった」という事実そのものは、著作物ではない。
解　②・⑤。① 登録は不要（無方式主義）。③ 公衆送信権の侵害。私的使用の範囲を超える。④ 著作者人格権は譲渡できない（譲渡できるのは財産権としての著作権）。

講義3　引用のルールとクリエイティブ・コモンズ

他人の著作物を自分の作品の中で紹介する引用は、次の条件を満たせば許諾なしにできる。
①すでに公表された著作物である　②引用する必然性がある　③自分の文章が「主」、引用部分が「従」という主従関係がある　④かぎかっこなどで引用部分を明確に区別する　⑤出所（著者名・作品名・掲載元など）を明示する　⑥引用部分を改変しない
「出所を書けば何をどれだけ使ってもよい」わけではない。他人の文章が中心になるような使い方は引用にあたらない。
著作者が「この条件を守れば自由に使ってよい」と意思表示するしくみにクリエイティブ・コモンズ・ライセンス（CC ライセンス）がある。4つの条件を組み合わせて表す。
・BY（表示）：作者名などのクレジットを表示する　・NC（非営利）：営利目的で使わない
・ND（改変禁止）：元の作品を改変しない　・SA（継承）：改変した作品を、元と同じライセンスで公開する
（ND と SA は同時には付かない。）
「CC BY-NC-SA」のライセンスで公開されたイラストがある。次の利用のうち、ライセンスの範囲内のものをすべて選べ。
① 作者名とライセンスを表示し、部活動で無料配布する冊子にそのまま載せる。
② 色を塗りかえて加工し、作者名を表示して、同じ CC BY-NC-SA で公開する。
③ 加工した作品を、「改変禁止（CC BY-NC-ND）」の条件で公開する。
④ 作者名を表示して、販売用の T シャツに印刷する。
解　①・②。③ SA（継承）により、改変した作品は元と同じライセンスで公開しなければならない。④ NC（非営利）に反する。

講義4　個人情報の保護と情報に関する法律

個人情報保護法でいう個人情報とは、生存する個人に関する情報で、氏名・生年月日・顔写真などにより特定の個人を識別できるもの（他の情報と容易に照合して識別できるものを含む）である。指紋や顔の特徴をコンピュータで扱えるようにしたデータや、マイナンバー・旅券番号・運転免許証番号などの個人識別符号も、それだけで個人情報になる。病歴や犯罪の経歴など、差別や偏見につながるおそれのある情報は要配慮個人情報として、取得に原則として本人の同意が必要である。
個人情報を扱う事業者は、①利用目的を特定して本人に通知・公表し、目的外に使わない、②安全に管理する、③本人の同意なく第三者に提供しない（法令に基づく場合などの例外あり）、④本人からの開示請求などに応じる、といったルールを守る。
ほかに、情報に関するおもな法律として次のものがある。
・不正アクセス禁止法：他人の ID・パスワードを無断で使ってログインする、システムの弱点を突いて侵入する、他人の ID・パスワードを無断で第三者に教える、偽のログイン画面で ID・パスワードを入力させる（フィッシング）などを禁止。
・刑法：正当な理由なくコンピュータウイルスを作成・提供すること（不正指令電磁的記録に関する罪）、名誉毀損、電子計算機を使った詐欺など。
・特定電子メール法：広告・宣伝のメールは、原則としてあらかじめ同意した相手にだけ送れる（オプトイン方式）。
次の行為は、おもにどの法律に違反するか。
① 友人の ID とパスワードを無断で使って、友人の SNS アカウントにログインした。
② 他人を困らせる目的で、パソコンのファイルを勝手に消去するプログラムを作成した。
③ 会員から集めた住所と氏名を、本人の同意を得ずに他の会社に売った。
④ 人気マンガのページを撮影して、動画投稿サイトに公開した。
解　① 不正アクセス禁止法　② 刑法（不正指令電磁的記録作成の罪。いわゆるウイルス作成罪）　③ 個人情報保護法（第三者提供の制限）　④ 著作権法（複製権・公衆送信権の侵害）
(1) 著作権が発生するのはいつか。また、そのために必要な手続きは何か。
(2) 産業財産権のうち、存続期間を更新できるものはどれか。
(3) 引用の条件として誤っているものを1つ選べ。　ア 引用部分をかぎかっこで区別する　イ 出所を明示すれば、自分の文章より引用部分が長くてもよい　ウ 引用部分の文章を勝手に書きかえない
(4) 次のうち個人情報にあたるものをすべて選べ。　ア 氏名と顔写真がのったクラス名簿　イ 運転免許証の番号　ウ 全国の高校生の平均身長
・「どの権利か」は、何を守るか（技術・形の工夫・デザイン・マーク・表現）で判断する。登録が必要か（産業財産権は必要、著作権は不要）、譲渡できるか（人格権は不可）は正誤問題の定番。
・著作権の例外（私的使用・引用・授業）は「範囲が限られている」点が問われる。SNS や Web で公開すると、私的使用の範囲を超える。
・CC ライセンスは BY・NC・ND・SA の意味を確実に。
・法律の問題は、事例の行為が「ID の無断使用か」「個人情報の提供か」「著作物の公開か」を見極めて答える。

講義5　SNS 時代の情報モラル ― 写真・位置情報・デジタルタトゥー

法律に違反しなくても、他人を傷つけたり自分を危険にさらしたりする情報の扱いは避けなければならない。情報社会で適切に活動するための考え方や態度を情報モラルという。

・肖像権：自分の顔や姿を無断で撮影・公開されない権利。法律の条文はないが、裁判で認められてきた。友人の写真を SNS に載せるときは本人の許可をとる。有名人の氏名や肖像がもつ経済的な価値を守るパブリシティ権もある。
・位置情報：スマートフォンで撮影した写真のファイルには、撮影日時や機種のほか、設定によっては撮影場所の緯度・経度（Exif 情報）が記録される。そのまま投稿すると自宅の場所が知られるおそれがある。写真の背景（制服、最寄り駅、窓からの景色）からも場所は特定されうる。
・デジタルタトゥー：一度インターネットに公開した情報は、複製・転載されて完全には消せない（残存性・複製性・伝播性）。軽い気持ちの投稿が進学や就職の場面で問題になることもある。
・炎上と誹謗中傷：匿名でも、発信者は法的な手続きによって特定されうる。被害者がプロバイダなどに発信者の情報の開示を求めるしくみがある。
投稿する前に「この情報は誰が見てもよいか」「後で消せなくても困らないか」を考える習慣をつけたい。
・「インターネットで公開されているものは自由に使ってよい」は誤り。公開されていても著作権は存在する。
・「出典を書けば引用になる」も誤り。主従関係や必然性などの条件をすべて満たす必要がある。
・著作権も特許庁への出願が必要だと考えてしまう（著作権は登録不要）。
・個人情報を「氏名」だけだと考える。顔写真や個人識別符号（指紋のデータ、マイナンバーなど）も個人情報。逆に、亡くなった人の情報や、個人を識別できない統計の数値は個人情報保護法の個人情報にあたらない。
(1) 著作物を創作した時点で自動的に発生する。手続き（登録・申請）は不要。　(2) 商標権　(3) イ（自分の文章が主、引用部分が従でなければならない）　(4) ア・イ（ウ は個人を識別できない統計の数値）
・情報デザイン＝情報を受け手にわかりやすく、正確に伝えるための表現と設計。抽象化（ピクトグラム・路線図）、可視化（グラフ・図解）、構造化（見出し・箇条書き・表）を使う
・情報の整理のしかたは5つ：位置・五十音（アルファベット）・時間・分類・階層（連続量）（頭文字から LATCH）
・グラフは目的で選ぶ（量の比較＝棒、時間変化＝折れ線、割合＝円・帯、2つの量の関係＝散布図）。縦軸の省略などで誤った印象を与えない
・ユニバーサルデザイン＝はじめから誰もが使いやすいように設計すること。アクセシビリティ＝情報やサービスへの到達・利用のしやすさ
・Web ページは HTML（文書の構造）と CSS（見た目）で作る

講義1　情報を整理する ― 抽象化・構造化と LATCH

情報デザインでは、伝えたい内容の本質だけを残して余分な要素を省く抽象化（非常口のピクトグラム、駅の位置関係だけを示す路線図）、数量や関係を目に見える形にする可視化（グラフ、図解）、情報どうしの関係や順序を明らかにする構造化（見出し、箇条書き、表、手順の番号）を組み合わせる。
大量の情報を整理する基準は5つにまとめられる（LATCH）：位置（Location：地図、フロアガイド）、五十音・アルファベット（Alphabet：辞書、索引）、時間（Time：年表、時刻表）、分類（Category：売り場の区分、図書の分類）、階層（Hierarchy：大きさ・重要度などの連続量の順。ランキング、価格順）。
同じ情報でも、受け手が何を探すかで最適な整理は変わる（レシピ集なら料理の種類＝分類でも、調理時間の短い順＝階層でも並べられる）。
次の①〜⑤は、LATCH のどの基準で整理されているか。
① 国語辞典　② 歴史の年表　③ スーパーマーケットの「野菜・精肉・鮮魚」の売り場　④ 駅の構内図　⑤ 売上ランキング
解　① 五十音　② 時間　③ 分類　④ 位置　⑤ 階層（売上という連続量の順）

講義2　可視化とプレゼンテーション

グラフは何を伝えたいかで選ぶ。
棒グラフは量の比較、折れ線グラフは時間にともなう変化、円グラフは全体に対する割合、帯グラフは割合を複数の集団・年で比べる、散布図は2つの量の関係（第12章）、レーダーチャートは複数の項目のバランスを示すのに向く。
数値は正しくても、見せ方によって誤った印象を与えることがある。棒グラフの縦軸を途中から始める、3D の円グラフで手前の部分を大きく見せる、目盛りの間隔を不均等にする、などである。縦軸を省略するなら、省略していることを波線などで明示し、数値も添える。
プレゼンテーションは、①目的と聞き手の分析 → ②構成（序論・本論・結論。結論を先に述べる方法もある）→ ③スライド作成（1枚に1つのメッセージ、文字は大きく少なく、図や表を活用）→ ④リハーサル（時間配分）→ ⑤発表 → ⑥評価（聞き手のアンケート、評価基準表）の流れで準備する。
3つの店の1か月の売上（A 店 102 万円、B 店 105 万円、C 店 110 万円）を、2通りの棒グラフで表した。 (1) (イ) では、C 店の棒の高さは A 店の棒の高さの何倍か。また、実際の売上は何倍か（小数第2位を四捨五入）。
(2) (イ) のグラフを見た人が受ける印象の問題点と、改善のしかたを述べよ。
解　(1) (イ) の棒の高さは縦軸の 100 からの長さなので、A 店は $102-100=2$、C 店は $110-100=10$ にあたり、5 倍。実際の売上は $110\div102\fallingdotseq$ 1.1 倍（約 1.08 倍）。
(2) 売上の差がわずかであるのに、C 店が A 店の何倍も売っているように見える。縦軸を 0 から始めるか、省略する場合は省略を波線で示し、棒に数値を書き添える。差を強調したいなら「差（増減）」そのものをグラフにする方法もある。

講義3　ユニバーサルデザインとアクセシビリティ

バリアフリーは、高齢者や障がいのある人にとっての障壁（バリア）を後から取り除く考え方である。これに対しユニバーサルデザイン（UD）は、年齢・言語・能力などにかかわらず、はじめから誰もが使いやすいように設計する考え方で、次の7原則が知られている。
①誰でも公平に使える　②使い方を選べる（柔軟性）　③使い方が簡単で直感的にわかる　④必要な情報がすぐにわかる　⑤うっかりミスが危険につながらない　⑥少ない力で楽に使える　⑦使いやすい大きさと空間がある
色の見え方には個人差（色覚の多様性）があるので、色だけで情報を区別しないことが大切である。形・模様・線の種類・文字を併用し、文字と背景の明るさの差（コントラスト）を大きくする。
アクセシビリティは、誰もが情報やサービスに到達し利用できるかどうかを表す。Web ページでは、画像に代替テキストをつける（音声読み上げソフトで内容がわかる）、動画に字幕をつける、文字の大きさを変えられるようにする、見出しを正しく構造化する、などの工夫をする。使う人が目的を効率よく、満足して達成できるかという使いやすさはユーザビリティという。
ある鉄道会社の路線図は、路線を赤・緑・茶色などの色の違いだけで区別している。色覚の多様性に配慮した改善として適切でないものを1つ選べ。
① 路線ごとにアルファベットの記号と番号（例：「G05」）を駅名に添える。
② 色の組合せを見直し、明るさの差が大きい色どうしを隣り合わせる。
③ 線の太さや実線・破線の違いも使って路線を区別する。
④ 赤と緑をより鮮やかな色に変え、色の違いを強調する。
解　④。赤と緑は、色覚の特性によっては鮮やかにしても区別しにくい。色以外の手がかり（①記号・番号、③線の種類）を加えることや、②明るさの差を大きくすることが有効である。

講義4　Web ページのしくみ ― HTML の考え方

Web ページは HTML（HyperText Markup Language）で書かれた文書である。文字列をタグで囲み、「ここは見出し」「ここは段落」という文書の構造（意味）を指定する。開始タグ <p> と終了タグ </p> で囲んだまとまりを要素といい、タグの中に属性（href="…" など）を書いて情報を追加する。 
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>情報部</title>
</head>
<body>
  <h1>情報部のお知らせ</h1>
  <p>次回の活動は<strong>金曜日</strong>です。</p>
  <img src="map.png" alt="昇降口から部室までの地図">
  <ul>
    <li>持ち物：ノートパソコン</li>
    <li>集合：16時</li>
  </ul>
  <a href="https://www.example.jp/">学校</a>
</body>
</html>
おもな要素：
・<title> ブラウザのタブなどに出る題名
・<h1>〜<h6> 見出し（数字が小さいほど上位）
・<p> 段落　・<strong> 強調
・<img> 画像（src は画像ファイル、alt は代替テキスト）
・<ul>・<li> 箇条書き
・<a> リンク（href はリンク先）
・<table> 表
<head> には文書の情報（文字コード・題名など）を、<body> には表示する内容を書く。
色・文字の大きさ・配置などの見た目は CSS で別に指定する。構造と見た目を分けておくと、デザインの変更が楽になり、音声読み上げソフトなども見出しや段落を正しく理解できる。
上の HTML について答えよ。
(1) ブラウザのタブに表示される文字列は何か。
(2) 画像が表示できないときや、音声読み上げソフトで読まれるときに使われる文字列は何か。
(3)「学校」と表示された文字列をクリックするとどうなるか。
(4)「金曜日」を見出しにするのではなく <strong> で囲んでいるのはなぜか。

(1) 1年間の気温の移り変わりを示すのに最も適したグラフは何か。
(2) バリアフリーとユニバーサルデザインの考え方の違いを簡潔に述べよ。
(3) HTML で画像を表示する <img> 要素の alt 属性には、どのような内容を書くべきか。
(4) 次のうち、プレゼンテーションのスライドの作り方として適切なものを1つ選べ。　ア 伝えたいことをすべて1枚に詰め込む　イ 1枚のスライドで伝えるメッセージを1つにしぼる　ウ 背景と文字を似た明るさの色にする
・グラフの選択や、「誤解を招くグラフ」の指摘は頻出。縦軸の始点・目盛り・面積の見せ方を必ず確認する。
・UD・アクセシビリティでは「色だけに頼らない」「代替テキスト」が定番。バリアフリーとの違い（後から除く／はじめから設計）も問われる。
・HTML は細かな文法よりも、タグが構造を表すこと、href・src・alt の役割、HTML と CSS の分担を理解しておけば対応できる。

講義5　CSS と色の表し方

CSS では「どの要素に（セレクタ）」「何を（プロパティ）」「どうする（値）」を指定する。

h1 { color: #0B5F84; font-size: 24px; }
p  { line-height: 1.8; }
これは「すべての h1 要素の文字色を #0B5F84 にし、文字の大きさを 24 ピクセルにする」「段落の行間を文字の高さの 1.8 倍にする」という指定である。
色の #RRGGBB は、光の三原色（赤 R・緑 G・青 B）の強さを、それぞれ 16 進数2けた（00〜FF、10進数で 0〜255）で表したもの（第4章）。#FF0000 は赤、#FFFF00 は赤と緑を最大にした黄、#FFFFFF は白、#000000 は黒、#808080 は灰色。#0B5F84 は R＝11、G＝95、B＝132 で、青みの強い暗い色である。各色 256 段階なので、表せる色は $256^3=16{,}777{,}216$ 通り。
CSS を使えば、画面の幅に応じてレイアウトを切りかえ、パソコンでもスマートフォンでも読みやすくすること（レスポンシブデザイン）もできる。見た目を CSS にまとめると、ページ全体のデザインを一か所の変更で統一できる。
・円グラフを「時間の変化」や「量の比較」に使う。円グラフは1つの全体の割合を示すためのもの。
・見出しの文字を大きくしたいだけで <h1> を使う、逆に見出しを <p> と CSS だけで大きく見せる。見た目は CSS、意味は HTML。
・UD を「障がいのある人専用の設計」と考える。UD はすべての人を対象にする。

・情報量の最小単位はビット（0 か 1）。$n$ ビットで $2^n$ 通りを区別できる。8 ビット＝1 バイト（B）
・2進数の各けたの重みは $1,2,4,8,16,\dots$。16進数の1けたは2進数の4けたにちょうど対応する

・可逆圧縮（完全に元に戻る：ZIP・PNG）と非可逆圧縮（一部の情報を捨てる：JPEG・MP3）。ランレングス圧縮は同じ値の連続を「値と個数」で表す

講義1　ビットと2進数・16進数

連続的に変化する量を連続的なまま表すのがアナログ、段階的な数値で表すのがデジタルである。デジタルデータは、複製や伝送をくり返しても劣化せず、コンピュータで加工・圧縮・誤り検出ができる。コンピュータは電圧の高低などの2つの状態で 0 と 1 を表すので、すべての情報を2進数で扱う。
・1 ビットで2通り、2 ビットで $2^2=4$ 通り、$n$ ビットで $2^n$ 通り。$k$ 種類のものを区別するには $2^n\geqq k$ となる最小の $n$ ビットが必要。
・単位：$1\ \mathrm{B}=8$ ビット、$1\ \mathrm{KB}=2^{10}\ \mathrm{B}=1024\ \mathrm{B}$、$1\ \mathrm{MB}=1024\ \mathrm{KB}$、$1\ \mathrm{GB}=1024\ \mathrm{MB}$、$1\ \mathrm{TB}=1024\ \mathrm{GB}$（$1\ \mathrm{KB}=1000\ \mathrm{B}$ とする流儀もある。入試では問題文の指示に従う。本書では特に断らないかぎり 1024 倍で換算する）。
基数変換：10進数を2進数にするには、2で割った余りを順に求め、下から（最後の余りから）並べる。2進数を10進数にするには、1 のけたの重み（$2^k$）を足す。2進数と16進数（0〜9、A〜F の16種類の数字）は、右から4けたずつ区切って変換する（$1111_{(2)}=\mathrm{F}_{(16)}=15$）。
(1) 10進数の 45 を2進数と16進数で表せ。　(2) 2進数 $11010110_{(2)}$ を10進数と16進数で表せ。　(3) 2進数の計算 $1011_{(2)}+0110_{(2)}$ を行え。　(4) 英大文字26種類と数字10種類を区別して表すには、1文字あたり最低何ビット必要か。
解　(1) $45\div2=22$ 余り 1、$22\div2=11$ 余り 0、$11\div2=5$ 余り 1、$5\div2=2$ 余り 1、$2\div2=1$ 余り 0、$1\div2=0$ 余り 1。下から並べて $\boldsymbol{101101_{(2)}}$。4けたずつ区切ると $0010\,|\,1101$ なので $\boldsymbol{2\mathrm{D}_{(16)}}$（$2\times16+13=45$）。
(2) $128+64+16+4+2=\boldsymbol{214}$。$1101\,|\,0110$ より $\boldsymbol{\mathrm{D}6_{(16)}}$。
(3) 1 のけたから、$1+0=1$、$1+1=10$（0 を書いて 1 くり上げ）、$0+1+1=10$（0 を書いて 1 くり上げ）、$1+0+1=10$ より $\boldsymbol{10001_{(2)}}$（10進数で $11+6=17$）。
(4) $26+10=36$ 種類。$2^5=32\lt 36\leqq 2^6=64$ より 6 ビット。

講義2　文字と画像のデジタル表現

文字コードは、文字に番号（2進数）を割り当てた対応表である。
・ASCII：英数字・記号を 7 ビット（128 種類）で表す。「A」は $41_{(16)}$（65）、「B」は $42_{(16)}$、…、「a」は $61_{(16)}$（97）、数字の「0」は $30_{(16)}$（48）。
・日本語用には JIS コード・シフト JIS・EUC-JP（漢字1文字を2バイト）がある。
・Unicode：世界中の文字を1つの体系で扱う。その符号化方式の UTF-8 は可変長で、ASCII の文字は1バイト、ひらがな・カタカナ・多くの漢字は3バイト、絵文字などは4バイト。
書いたときと異なる文字コードで読みこむと、別の文字として表示される（文字化け）。
画像は細かい点（画素、ピクセル）に分け、各画素の色を数値で表す。画素の細かさを解像度、1画素で表せる色や明るさの段階数を階調という。光の三原色 R（赤）・G（緑）・B（青）をそれぞれ 8 ビット（256 階調）で表すと、1画素 24 ビットで $2^{24}=16{,}777{,}216$ 色（フルカラー）。光の三原色を重ねると明るくなり（加法混色）、全部重ねると白。印刷では色料の三原色（シアン・マゼンタ・イエロー）を使い、重ねると暗くなる（減法混色）。
画素の集まりで表すラスタ形式（写真向き。拡大すると輪郭がギザギザになる）に対し、図形を座標と線・面の情報で表すベクタ形式は、拡大しても輪郭がなめらかで、図やロゴに向く。
(1) ASCII で $48_{(16)}$、$49_{(16)}$ と表される2文字は何か。　(2) UTF-8 で「データ123」は何バイトか。　(3) 横 1920 画素、縦 1080 画素で、1画素を 24 ビットで表す画像のデータ量は何バイトか。また約何 MB か（小数第2位を四捨五入）。　(4) (3) と同じ画素数で白黒2値（1画素1ビット）にすると、データ量は (3) の何分の1か。
解　(1)「A」が $41_{(16)}$ なので、$48_{(16)}$ はその7つ後の「H」、$49_{(16)}$ は「I」。
(2) カタカナ3文字 × 3バイト ＋ 数字3文字 × 1バイト ＝ $9+3=$ 12 バイト（長音「ー」もカタカナと同じく3バイト）。
(3) $1920\times1080\times24\div8=\boldsymbol{6{,}220{,}800}$ バイト。$6{,}220{,}800\div1024\div1024\fallingdotseq$ 5.9 MB。
(4) 1画素のビット数が 24 → 1 になるので 24分の1（$1920\times1080\div8=259{,}200$ バイト）。

講義3　音と動画のデジタル化

音は空気の振動で、マイクで電圧の変化（アナログ信号）に変えられる。これを次の3段階でデジタルにする（PCM 方式）。
①標本化（サンプリング）：一定の時間間隔（標本化周期）ごとに波の高さを取り出す。1秒間に取り出す回数が標本化周波数（単位 Hz）。
②量子化：取り出した値を、あらかじめ決めた段階のうち最も近い値に置きかえる。段階数を表すビット数が量子化ビット数（3 ビットなら $2^3=8$ 段階）。
③符号化：量子化した値を2進数の符号に置きかえる。
標本化周波数を高く、量子化ビット数を大きくするほど元の波形に近くなるが、データ量は増える。
　音のデータ量（ビット）＝ 標本化周波数 × 量子化ビット数 × チャンネル数 × 時間（秒）
元の音に含まれる最も高い周波数の2倍より高い周波数で標本化すれば、元の波形を再現できる（標本化定理）。人が聞きとれる音の上限は約 20 kHz なので、音楽 CD は 44.1 kHz で標本化している。
動画は少しずつ異なる静止画（フレーム）を連続して表示したもので、1秒あたりのフレーム数をフレームレート（fps）という。圧縮しない場合、動画のデータ量＝1フレームのデータ量 × フレームレート × 時間。
下の図は、ある音の波形を1ミリ秒ごとに標本化し、3ビット（0〜7 の8段階）で量子化したものである。標本化した値は t＝0 から順に 4.0、5.2、6.2、6.2、4.0、1.0、0.2、2.0 であった。 (1) 各値を最も近い段階に量子化し、3ビットの2進数で符号化せよ。　(2) この8個の標本のデータ量は何ビットか。また標本化周波数は何 Hz か。　(3) 音楽 CD と同じ条件（標本化周波数 44.1 kHz、量子化ビット数 16 ビット、ステレオ2チャンネル）で1分間録音したときのデータ量は何バイトか。
解　(1) 量子化した値は 4、5、6、6、4、1、0、2。符号化すると 100　101　110　110　100　001　000　010。
(2) $8\times3=$ 24 ビット。1ミリ秒（0.001 秒）ごとなので、1秒間に 1000 回で 1000 Hz（1 kHz）。
(3) $44100\times16\times2\times60=84{,}672{,}000$ ビット。$\div8$ して 10,584,000 バイト（約 10.1 MB）。

講義4　データの圧縮

データの意味を保ったまま量を減らすことを圧縮、元に戻すことを展開（解凍）という。
・可逆圧縮：展開すると完全に元に戻る。文書やプログラムに必須。ZIP、PNG、GIF など。
・非可逆圧縮：人が気づきにくい情報を捨てて大きく圧縮する。元には完全には戻らない。写真の JPEG、音楽の MP3・AAC、動画の MPEG 形式など。
圧縮率＝圧縮後のデータ量 ÷ 圧縮前のデータ量 × 100（%）。値が小さいほどよく圧縮できている。
ランレングス圧縮は、同じ値が続く部分を「値と連続する個数」で表す方法。「AAAAABBB」なら「A5B3」とする。白黒の図やイラストのように同じ色が続く画像では効果が大きいが、値が頻繁に変わるデータではかえって量が増えることもある。圧縮の効果はデータの性質で決まる。
(1) 文字列「AAAAABBBCCCCCCCCAA」を、1文字と連続数（1けたの数字1文字）の組で表すランレングス圧縮で表し、圧縮率を求めよ（小数第2位を四捨五入）。
(2) 同じ方法で「ABCDE」を圧縮するとどうなるか。
(3) 白黒画像の1行16画素が「白12個、黒4個」の順に並んでいる（白＝0、黒＝1 の1ビットで表すと16ビット）。「白から始めて、同じ色が続く個数を4ビットの2進数で交互に記録する」方式で表すと何ビットになるか。
解　(1) A5B3C8A2。18文字が8文字になるので $8\div18\times100\fallingdotseq$ 44.4 %。
(2)「A1B1C1D1E1」の10文字になり、5文字から2倍に増える（圧縮率 200 %）。
(3) 白12 → $1100$、黒4 → $0100$ で「11000100」の 8 ビット（元の半分）。
(1) 16進数 $3\mathrm{C}_{(16)}$ を2進数（8けた）と10進数で表せ。　(2) 256 色を区別するには、1画素あたり何ビット必要か。
(3) 標本化周波数 8 kHz、量子化ビット数 8 ビット、モノラル（1チャンネル）で1分間録音した音のデータ量は何バイトか。
(4) 横 640 画素、縦 480 画素、1画素 24 ビットのフレームを毎秒 30 枚表示する動画を、圧縮せずに 10 秒間保存するとデータ量は何バイトか。また約何 MB か（整数に四捨五入）。
・データ量の計算は「ビットかバイトか」「1 KB は 1000 か 1024 か」を問題文で確認し、掛け算をすべて書いてから最後に 8 や 1024 で割る。
・標本化周波数・量子化ビット数・解像度・階調を上げると品質とデータ量がどう変わるか、可逆・非可逆の区別、ランレングスが効くデータの見きわめもよく問われる。

講義5　ハフマン符号化 ― よく出る文字に短い符号を

文字の種類が5種類なら、固定長の符号では1文字3ビット（$2^3=8\geqq5$）必要である。しかし、出現回数に偏りがあるなら、よく出る文字に短い符号、まれな文字に長い符号を割り当てると全体を短くできる。これを体系的に行うのがハフマン符号化（可逆圧縮）である。

16文字の文章で、A が8回、B が4回、C が2回、D と E が1回ずつ出たとする。
①出現回数の少ない2つを組にして、回数の和をもつ節点をつくる（D:1 と E:1 → 2）。
②これを1つの文字とみなして、また少ない2つを組にする（C:2 と 2 → 4、B:4 と 4 → 8、A:8 と 8 → 16）。
③できた木（右図）の枝に 0・1 をつけ、根から文字までの 0・1 の並びを符号にする。
符号は A＝0、B＝10、C＝110、D＝1110、E＝1111 となる。
全体のビット数は $8\times1+4\times2+2\times3+1\times4+1\times4=30$ ビットで、固定長（$16\times3=48$ ビット）の $62.5\,\%$。1文字あたり平均 $30\div16=1.875$ ビットになる。
どの符号も他の符号の先頭部分になっていない（たとえば A の「0」で始まる符号は A だけ）ので、区切り記号がなくても先頭から一意に読める。「0101100」は 0｜10｜110｜0 と区切れて「ABCA」となる。
・データ量の計算で 8 で割り忘れる（または二重に割る）。10進数→2進数で余りを上から並べる（最後の余りが最上位）。
・「量子化ビット数を2倍（8 → 16 ビット）にすると段階数も2倍」と考える。段階数は $2^8=256$ から $2^{16}=65{,}536$ へと 256倍になる（データ量は2倍）。
・圧縮率を「減った割合」と取り違える。圧縮率 30 % は「元の 30 % の大きさになった」という意味。
(1) $00111100_{(2)}$、$3\times16+12=60$　(2) $2^8=256$ より 8 ビット　(3) $8000\times8\times1\times60\div8=480{,}000$ バイト　(4) 1フレーム $640\times480\times3=921{,}600$ バイト。$921{,}600\times30\times10=276{,}480{,}000$ バイト $\fallingdotseq264$ MB
・コンピュータは入力・出力・記憶・演算・制御の5つの装置からなる。演算装置と制御装置をまとめたものが CPU
・プログラムもデータも主記憶装置に置き、CPU が命令を1つずつ取り出し → 解読 → 実行する（プログラム内蔵方式）
・OS（基本ソフトウェア）はハードウェアを管理し、アプリケーションに共通の機能を提供する
・論理回路の基本は AND・OR・NOT。XOR と AND を組み合わせた半加算器で1けたの2進数の足し算ができる
・負の数は2の補数で表す。コンピュータの数は有限のビット数なので、桁あふれ・丸め誤差などが生じる

講義4　コンピュータの中の数 ― 補数と誤差

負の数は2の補数で表す。8 ビットの場合、正の数はそのまま、負の数 $-n$ は「$n$ の2進数の各ビットを反転して 1 を足す」。たとえば $45=00101101$ → 反転 $11010010$ → $+1$ で $-45=11010011$。最上位ビットが 1 なら負の数で、8 ビットでは $-128$〜$127$ を表せる。2の補数を使うと、引き算を足し算で行える（$50-45=50+(-45)$。9けた目へのけた上がりは捨てる）。
