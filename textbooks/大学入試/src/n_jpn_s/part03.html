「なり」は直前の語の形で4つに分ける

「なり（なる・なれ）」の意味・文法的説明を問われたとき。
①終止形（ラ変型の語には連体形）＋なり → 伝聞・推定（〜そうだ・〜ようだ。音や声が根拠）。
②体言・連体形＋なり → 断定（〜だ・〜である）・存在（〜にある）。
③「あはれなり」「静かなり」のように状態を表す語の一部 → 形容動詞の活用語尾（上に「いと」を付けて意味が通る）。
④「〜になる」の意味 → 四段動詞「成る」。
「男もすなる日記といふものを、女もしてみむとてするなり。」（土佐日記）の「すなる」「するなり」の「なる・なり」を識別せよ。
解　「す」はサ変の終止形なので「すなる」は伝聞（男も書くと聞いている日記）。「する」はサ変の連体形なので「するなり」は断定（書いてみようと思って書くのである）。
四段・上一段・下一段は終止形と連体形が同じ形なので、接続だけでは決まらない。音・声の描写があれば伝聞・推定、なければ断定を考え、文脈で確定する。「あなり」「ななり」「ざなり」（あるなり・なるなり・ざるなりの撥音便の無表記）の「なり」は伝聞・推定。

断定「なり」は「存在」と「に＋あり」の形も見抜く

「体言＋なる＋体言」の訳を問われたとき。「にや」「にか」「にこそ」で文が切れているとき。
①場所・方角を表す体言＋なる＋体言 → 存在「〜にある」。
②断定「なり」の連用形「に」の下には「あり・侍り・候ふ・おはす」が来る（間に「は・も・や・か・こそ」などが入ることが多い）。訳は「〜で（ある）」。
③「〜にや」「〜にか」の下には「あらむ・ありけむ」、「〜にこそ」の下には「あらめ」が省略されている（結びの省略）。
次の歌の「春日なる」を訳せ。
天の原ふりさけ見れば春日なる三笠の山に出でし月かも（古今和歌集・安倍仲麻呂）
解　「春日」は地名なので存在の「なり」で、春日にある。歌全体は「大空をはるかに仰ぎ見ると（見える月は）、（故郷の）春日にある三笠の山に出た月なのだなあ」。

「ぬ」「ね」は上の形と下の形の両方で決める

「ぬ」「ね」が完了か打消かを問われたとき。
完了「ぬ」＝連用形接続。な・に・ぬ・ぬる・ぬれ・ね（「ぬ」は終止形、「ね」は命令形）。
打消「ず」＝未然形接続。連体形がぬ、已然形がね。
①上が未然形なら打消、連用形なら完了。
②上一段・上二段・下一段・下二段など未然形と連用形が同じ形なら、下を見る：「ぬ」の下が体言・係助詞（ぞ・なむ・や・か）の結び → 連体形 → 打消。文末で言い切り・引用の「と」の上 → 終止形 → 完了。「ね」の下が「ど・ども・ば」・「こそ」の結び → 已然形 → 打消。命令の意味 → 完了。
次の歌の「来ぬ」「見えね」「おどろかれぬる」の「ぬ・ね・ぬる」を識別せよ。
秋来ぬと目にはさやかに見えねども風の音にぞおどろかれぬる（古今和歌集・藤原敏行）
解　「来ぬ」は引用の「と」の上なので終止形。打消なら終止形は「ず」になるはずなので、完了「ぬ」の終止形（「来」はカ変の連用形「き」。秋が来た）。
「見えねども」は「ども」が已然形接続なので「ね」は已然形 → 打消「ず」の已然形（はっきりとは見えないけれど）。
「おどろかれぬる」は係助詞「ぞ」の結びの連体形。「ず」の連体形は「ぬ」で「ぬる」という形はないので、完了「ぬ」の連体形（はっと気づかされた）。
「来ぬ」はカ変なので「きぬ」（連用形＋完了）と「こぬ」（未然形＋打消）の両方がありうる。読みが示されない和歌では、文法と意味の両方から決める。

「に」は下に続く語で見分ける

文中の「に」の文法的説明を問われたとき。
①連用形＋に＋き・けり・たり・けむ → 完了「ぬ」の連用形。
②体言・連体形＋に＋（助詞）＋あり系 → 断定「なり」の連用形（〜で）。
③体言・連体形＋に（場所・時・対象・目的など） → 格助詞。
④連体形＋に、（文が続く） → 接続助詞（〜ので・〜のに・〜と）。
⑤「あはれに」「げに」「死に」 → 形容動詞の活用語尾・副詞の一部・ナ変動詞の活用語尾。
次の文の「御時にか」「なかに」「際には」の「に」を識別せよ。
いづれの御時にか、女御、更衣あまたさぶらひたまひけるなかに、いとやむごとなき際にはあらぬが、すぐれて時めきたまふありけり。（源氏物語・桐壺）
解　「御時にか」＝断定「なり」の連用形（下に「ありけむ」が省略された結びの省略。どの帝の御代であったか）。
「なかに」＝格助詞（体言「なか」について範囲を表す。お仕えなさっていた中に）。
「際には」＝断定「なり」の連用形（「に＋は＋あら」の形。身分ではない）。
「にて」の「に」も、「〜であって」と訳せるときは断定「なり」の連用形＋接続助詞「て」。

「る・れ」は直前がア段かエ段か

「る」「れ」が助動詞「る」か完了「り」かを問われたとき。
①ア段の音（四段・ナ変・ラ変の未然形）＋る・れ → 助動詞「る」（受身・尊敬・自発・可能）。
②エ段の音（サ変の未然形「せ」・四段の已然形）＋る・れ → 完了・存続「り」（「る」は連体形、「れ」は已然形・命令形）。覚え方は「サ未四已（さみしい）」。
③それ以外 → 動詞の一部（「流る」「忘る」など下二段動詞の活用語尾）。
作例「a 人に笑はる。　b 花咲ける里。　c 涙流る。」の「る」を識別せよ。
解　a＝「笑は」（ア段・四段の未然形）＋助動詞「る」の終止形。「人に」とあるので受身。
b＝「咲け」（エ段・四段の已然形）＋完了・存続「り」の連体形（花が咲いている里）。
c＝下二段動詞「流る」の活用語尾。
「らる」は四段・ナ変・ラ変以外の動詞の未然形につく。「り」は「〜ている」（存続）で訳すことが多い。

「る・らる」の意味は4つの手がかりで決める

「る・らる」の意味（受身・尊敬・自発・可能）を問われたとき。
①自発：心情・知覚の動詞（思ふ・偲ぶ・泣く・ながむ・おどろく）につく → 「自然と〜される」。
②受身：「〜に」（動作をする人）があり、される側の立場で書かれている → 「〜される」。
③可能：下に打消・反語が来る（平安時代の可能はほぼ打消とともに使う） → 「〜できない」。
④尊敬：主語が身分の高い人 → 「〜なさる」。
次の文の「仰せらるれば」の「らるれ」の意味は？
「少納言よ、香炉峰の雪いかならむ」と仰せらるれば、御格子上げさせて、御簾を高く上げたれば、笑はせたまふ。（枕草子）
解　尊敬（「らる」の已然形）。主語は中宮定子で、「おっしゃるので」。「仰せ」は下二段「仰す」の未然形なので「る」ではなく「らる」がつく。
参考：作例「昔のこと思ひ出でらる」＝自発（自然と思い出される）、作例「夜も寝られず」＝可能（眠ることができない）。
「る・らる」の下に尊敬の「給ふ」がつく「れ給ふ」「られ給ふ」では、「る・らる」は尊敬にならない（受身・自発など）。

「す・さす・しむ」は下に尊敬語があるかを見る

「す・さす・しむ」が使役か尊敬かを問われたとき。
①下に「給ふ」「おはします」などの尊敬語がない → 使役（〜させる）。
②「せ給ふ」「させ給ふ」 → ふつうは尊敬（尊敬を重ねた最高敬語。主語は帝・中宮・皇族など）。ただし、させる相手（「〜に」「〜して」）が文脈にあれば使役＋尊敬。
接続：「す」は四段・ナ変・ラ変の未然形、「さす」はそれ以外の未然形、「しむ」は未然形全般（漢文訓読調の文に多い）。
前のカードの枕草子の文の「上げさせて」の「させ」と「笑はせたまふ」の「せ」は？
解　「上げさせて」は下に尊敬語がないので使役（清少納言が女官たちに格子を上げさせて）。「笑はせたまふ」は尊敬（中宮がお笑いになる。「せ給ふ」の最高敬語）。
「せ給ふ」を見たら機械的に尊敬にしない。「誰かに〜させる」話になっていないか、前後を確かめる。

「なむ」は直前の形で4つに分ける

「なむ」の文法的説明・訳を問われたとき。
①未然形＋なむ → 他者への願望の終助詞（〜してほしい）。
②連用形＋なむ → 完了（強意）「ぬ」の未然形「な」＋推量・意志「む」（きっと〜だろう・〜してしまおう）。
③体言・連体形・助詞など＋なむ → 強意の係助詞（文末は連体形。取り除いても文が成り立つ）。
④「死なむ」「往なむ」 → ナ変動詞の未然形の活用語尾「な」＋推量・意志「む」。
作例「a 花咲かなむ。　b 花咲きなむ。　c 花なむ咲きける。　d 我は死なむ。」の「なむ」を識別せよ。
解　a＝未然形「咲か」＋終助詞（花が咲いてほしい）。b＝連用形「咲き」＋「ぬ」の未然形＋「む」（きっと咲くだろう）。c＝係助詞（文末「ける」が連体形の結び）。d＝ナ変「死ぬ」の未然形の一部＋意志「む」（死のう）。
下二段などの未然形と連用形が同じ語（「見えなむ」など）は、形では決まらない。「〜してほしい」か「きっと〜だろう」か、文脈で判断する。

「らむ」は終止形接続かエ段接続か

「らむ」の文法的説明・訳を問われたとき。和歌の「らむ」の訳。
①終止形（ラ変型には連体形）＋らむ → 現在推量の助動詞：「今ごろ〜しているだろう」（現在推量）、「どうして〜しているのだろう」（原因推量）、「〜とかいう・〜ような」（伝聞・婉曲）。
②エ段の音（サ変の未然形・四段の已然形）＋らむ → 完了・存続「り」の未然形「ら」＋推量「む」。
③「知らむ」「あらむ」 → 動詞の未然形の活用語尾「ら」＋推量・意志「む」。
次の歌の「らむ」の意味は？
ひさかたの光のどけき春の日にしづ心なく花の散るらむ（古今和歌集・紀友則）
解　四段「散る」の終止形＋現在推量「らむ」。目の前で花が散っている理由を推し量る原因推量で、「日の光がのどかな春の日に、どうして落ち着いた心もなく花が散っているのだろう」。
疑問の語がなくても、目の前の事実に「らむ」がついたら原因推量（どうして）を補う。過去のことを推量するのは「けむ」。

係り結びは「係助詞→文末の形」をセットで確認

文末の活用形を問われたとき。空欄に係助詞や結びの語を入れる問題。
ぞ・なむ（強意）、や・か（疑問・反語） → 文末は連体形。こそ（強意） → 文末は已然形。
訳：強意は訳に出さなくてよい。「や・か」は「〜か」（疑問）または「〜だろうか、いや〜ない」（反語）。
結びの省略：「〜にや」「〜にか」（あらむ・ありけむ）、「〜にこそ」（あらめ）。結びの消滅（流れ）：結ぶはずの語に接続助詞がついて文が続くと、結びの形にならない。
「その竹の中に、もと光る竹なむ一筋ありける。」（竹取物語）の係り結びを指摘し、訳せ。
解　係助詞「なむ」→結び「ける」（過去「けり」の連体形）。強意なので訳には出さず「その竹の中に、根元の光る竹が一本あった」。

「こそ〜已然形、」で文が続けば逆接

「こそ」の結びの後に読点があり、文が続いているとき。「もぞ」「もこそ」が出たとき。
①「こそ」＋已然形で文が終わらずに続くと、「〜けれども」と逆接で訳す。
②「もぞ（連体形）」「もこそ（已然形）」は懸念「〜したら困る・〜するといけない」。
「中垣こそあれ、一つ家のやうなれば、望みて預かれるなり。」（土佐日記）を訳せ。また、作例「雨もぞ降る。」を訳せ。
解　「（隣との間に）隔ての垣根はあるけれども、一つの家のようなものなので、（隣人が）自分から望んで（留守の家を）預かったのである」。「あれ」は「こそ」の結びの已然形で、文が続くので逆接。
作例は「雨が降ったら困る」（懸念）。

主語は接続助詞で「続く／変わる」を予想する

主語が省略されていて、動作をしたのが誰かを問われたとき。
①「て・して・で」 → 前後で主語が同じまま続きやすい。
②「を・に・ば・ど・ども・が」 → 前後で主語が変わりやすい。
あくまで目安なので、最後は敬語の有無と文脈で確かめる。
次の文の各動作の主語は？
あやしがりて、寄りて見るに、筒の中光りたり。それを見れば、三寸ばかりなる人、いとうつくしうてゐたり。（竹取物語）
解　「あやしがり・寄り・見る」＝翁（「て」で同じ主語が続く）。「光りたり」＝筒の中（「に」で主語が変わる）。「見れ」＝翁、「ゐたり」＝三寸ばかりなる人（「ば」で主語が変わる）。

「ば」の上が未然形なら仮定、已然形なら確定

「〜ば」「〜ども」「〜とも」を含む部分の訳。
未然形＋ば → 順接仮定（もし〜ならば）。
已然形＋ば → 順接確定（①〜ので　②〜と・〜ところ　③〜といつも）。
逆接は、終止形＋とも（たとえ〜としても＝仮定）、已然形＋ど・ども（〜けれども＝確定）。
次の歌の「吹かば」と、前のカードの「それを見れば」の「見れば」を訳し分けよ。
東風吹かばにほひおこせよ梅の花あるじなしとて春な忘れそ（拾遺和歌集・菅原道真）
解　「吹か」は四段の未然形 → 仮定「（春になって）東風が吹いたならば、（香りを）送ってよこせ」。「見れ」は上一段の已然形 → 確定「それを見ると」。なお「な忘れそ」は禁止で「（主人がいないからといって）春を忘れるな」。

願望・禁止の終助詞は「誰の願いか」で訳し分ける

文末の「ばや」「なむ」「てしがな」「もがな」「な〜そ」の訳。
ばや（未然形＋）＝自分の願望「〜したい」。なむ（未然形＋）＝他者への願望「〜してほしい」。てしがな・にしがな（連用形＋）＝自分の願望「〜したいものだ」。もがな（体言など＋）＝「〜があればなあ」。な〜そ＝禁止「〜するな」。終止形＋な＝禁止「〜するな」。
作例「a 月見ばや。　b 雨やまなむ。　c 都へ行きてしがな。　d よき友もがな。」を訳せ。
解　a＝月を見たい。b＝雨がやんでほしい（「やま」は四段の未然形）。c＝都へ行きたいものだ。d＝よい友がいればなあ。
「なむ」は連用形につけば「ぬ」＋「む」（きっと〜だろう）。願望の「なむ」かどうかは、必ず直前の形で確かめる。

敬語は「種類」→「誰から」→「誰へ」の順に

「誰から誰への敬意か」を問われたとき。
①種類：尊敬語（給ふ・おはす・のたまふ・思す・御覧ず・召す）、謙譲語（申す・聞こゆ・奉る・参る・まかる・承る）、丁寧語（侍り・候ふ）。
②誰から：地の文なら作者、会話文・手紙なら話し手（書き手）。
③誰へ：尊敬語は動作をする人、謙譲語は動作を受ける人、丁寧語は聞き手（地の文なら読者）。
作例「女房、大臣に『殿の御文を御覧ぜよ』と申す。」の「申す」「御覧ぜよ」は誰から誰への敬意か。
解　「申す」＝謙譲語・地の文 → 作者から、言われる側の大臣へ。「御覧ぜよ」＝尊敬語・会話文 → 話し手の女房から、見る動作をする大臣へ。
「侍り」「候ふ」は、本動詞で「お仕えする・お控えする」の意味なら謙譲語、「あります・ございます」や補助動詞なら丁寧語。「奉る」「参る」には尊敬（お召しになる・召し上がる）の用法もある。

「給ふ」は四段なら尊敬、下二段なら謙譲

「給ふ（たまふ）」の敬語の種類を問われたとき。会話文の「思ひ給ふ」「見給ふ」など。
四段（は・ひ・ふ・ふ・へ・へ）＝尊敬（お与えになる／〜なさる）。
下二段（へ・へ・○・ふる・ふれ・○）＝謙譲（〜ております・〜させていただく）。会話文・手紙で、話し手自身の「思ふ・見る・聞く・知る」につき、聞き手への敬意を表す。
見分け方：「給へ」の下が未然形・連用形につく語（ず・む・て・き など）なら下二段。「給へば・給へど」（已然形）や命令の「給へ」なら四段。「給ふる」「給ふれ」は下二段だけの形。
作例の会話文「かかることは、昔も聞き給へず。」の「給へ」は？
解　下が打消「ず」（未然形接続）なので未然形「給へ」→下二段・謙譲。話し手自身の「聞く」について、聞き手への敬意を表す。「このようなことは、昔も聞いたことがございません」。
「給へり」は四段の已然形「給へ」＋完了「り」なので尊敬。「り」はエ段（四段の已然形）につくことを思い出す。

二方面への敬語は「謙譲＋尊敬」に分解する

「奉り給ふ」「聞こえ給ふ」「参り給ふ」のように敬語が二つ重なっているとき。
謙譲語 → 動作の受け手への敬意、尊敬語 → 動作をする人への敬意、と二方向に分ける。「誰から」は、地の文ならどちらも作者。並ぶ順はふつう謙譲が先、尊敬が後。
作例「大臣、帝に御文を奉り給ふ。」の敬意の方向を説明し、訳せ。
解　「奉り」（謙譲・本動詞「差し上げる」）→ 作者から受け手の帝へ。「給ふ」（尊敬・補助動詞）→ 作者から動作をする大臣へ。訳「大臣が帝にお手紙を差し上げなさる」。

最高敬語と敬語の有無で主語を決める

主語が省略された文が続き、登場人物の身分に差があるとき。
①地の文の「せ給ふ・させ給ふ」「おはします」など最高敬語 → 帝・中宮・皇子など最上位の人。
②謙譲語で高められている人（動作の受け手）は、動作をする人より上。
③敬語がない動作 → 作者自身や身分の低い人。
登場人物に敬意の度合いで序列をつけ、省略された主語を補う。
作例（中宮の御前の場面）「女房を召す。参りて、御前にさぶらふ。『近う』と仰せらるれば、少し進み出でたり。」の各動作の主語は？
解　「召す」（尊敬語）＝中宮。「参り」「さぶらふ」（謙譲語：中宮のもとへ参上し、お控えする）＝女房。「仰せらるれ」（尊敬語）＝中宮。「進み出でたり」＝「ば」で主語が変わり、敬語もないので女房。

句切れは「言い切りの形」を探す

「この歌は何句切れか」を問われたとき。和歌を訳す最初の段階。
五・七・五・七・七の各句末を順に見て、意味の切れ目になる形を探す：①終止形・命令形　②係り結びの結び　③終助詞（かな・な・ばや・なむ など）　④体言で切れて詠嘆を表すところ。
初句切れ〜四句切れ、句切れなし。句切れの前後で「景と心」「出来事と感動」が分かれやすい。
次の歌は何句切れか。
春過ぎて夏来にけらし白妙の衣ほすてふ天の香具山（新古今和歌集・持統天皇）
解　二句切れ。「けらし」は「けるらし」がつまった形で、推定「らし」の終止形。「春が過ぎて夏が来たらしい。（夏になると）真っ白な衣を干すという天の香具山に（衣が干してある）」。結句は体言止め。「白妙の」は「衣」にかかる枕詞、「てふ」は「といふ」がつまった形。

枕詞は5音・決まった語にかかる・訳さない

「枕詞を抜き出せ」「どの語にかかるか」を問われたとき。
原則5音で、決まった語を導く。意味は原則として訳さない。代表的なものは暗記する：
あしひきの→山　ひさかたの→光・天・空・月　たらちねの→母　ぬばたまの→黒・夜・夢　しろたへの→衣・袖・雪　ちはやぶる→神　あをによし→奈良　あらたまの→年・月　くさまくら→旅　からころも→着る・袖・裾
「ひさかたの光のどけき春の日にしづ心なく花の散るらむ」（古今和歌集・紀友則）の枕詞と、それがかかる語は？
解　「ひさかたの」→「光」。訳では省き「日の光がのどかな春の日に」と訳す。

序詞は「長い前置き」と主想の切れ目を探す

「序詞を指摘せよ」「どの語を導くか」を問われたとき。上の句が景色ばかりで、下の句と意味がつながりにくいとき。
序詞は作者が自由に作る7音以上の前置きで、ある語を導く。導き方は①比喩（〜のように）、②掛詞、③同じ音のくり返しの3型。
序詞の部分は景物で、歌の主想（心情）は序詞の後ろにある。
次の歌の修辞を説明せよ。
あしひきの山鳥の尾のしだり尾のながながし夜をひとりかも寝む（拾遺和歌集・柿本人麻呂）
解　「あしひきの山鳥の尾のしだり尾の」（上三句）が「ながながし」を導く序詞（比喩：山鳥の垂れ下がった尾のように）。その中の「あしひきの」は「山」にかかる枕詞。主想は「長い長い夜を独りで寝るのだろうか」（係助詞「か」の結びで、「む」は連体形）。

掛詞はひらがな・地名・定番の語を疑う

「掛詞を指摘せよ」と問われたとき。和歌の訳がどうもつながらないとき。
①ひらがなで書かれた部分　②地名（歌枕）　③定番の掛詞：まつ（松・待つ）、ながめ（長雨・眺め）、ふる（降る・経る）、あき（秋・飽き）、かれ（枯れ・離れ）、よ（世・夜・節）、うき（憂き・浮き）、おく（置く・起く）、ね（根・寝・音）、ひ（日・火・思ひ）、みをつくし（澪標・身を尽くし）、あふ（逢ふ・逢坂）、いく（生野・行く）、ふみ（文・踏み）。
一語に自然の意味と人事（心）の意味が重なっていないかを確かめる。
次の歌の掛詞を指摘せよ。
花の色はうつりにけりないたづらにわが身世にふるながめせしまに（古今和歌集・小野小町）
解　「ふる」＝降る／経る（時を過ごす）、「ながめ」＝長雨／眺め（もの思いにふけること）。自然＝長雨が降り続く間に桜の花の色があせてしまった。人事＝むなしくもの思いにふけって過ごす間に、わが身の容色も衰えてしまった。二句切れ（「けり」の終止形＋詠嘆の終助詞「な」）。

掛詞は二つの意味を両方とも訳に出す

掛詞を含む和歌の現代語訳・解釈。
掛詞は、前の語とつながる意味と後ろの語とつながる意味に分かれることが多い。それぞれを確定し、訳では「〜（意味A）し、〜（意味B）」と両方を書く。「掛詞を説明せよ」では、二つの漢字（意味）を両方示す。
次の歌の掛詞を挙げ、歌を訳せ。
大江山いく野の道の遠ければまだふみもみず天の橋立（金葉和歌集・小式部内侍）
解　「いく野」＝生野（地名）／行く、「ふみ」＝踏み／文（手紙）。訳「大江山を越え、生野を通って行く道は遠いので、まだ天の橋立を踏んでみたこともありませんし、（母からの）手紙も見ていません」。「踏み」は「橋」の縁語でもある。

縁語は「中心の語」から仲間の語を拾う

「縁語を指摘せよ」と問われたとき。歌の中に「糸・緒・衣・露・舟」などの物の名があるとき。
ある語（多くは物の名）と意味のうえで関係の深い語が、一首の中に意図的に詠みこまれる。縁語は掛詞と重なることが多い（掛詞の片方の意味が縁語になる）。
代表：糸・緒→絶ゆ・ながらふ・弱る・乱る・張る・縒る／衣→着る・張る・褄・裁つ／露→置く・消ゆ・玉／舟→漕ぐ・渡る・寄る。
次の歌の縁語を指摘せよ。
玉の緒よ絶えなば絶えねながらへば忍ぶることの弱りもぞする（新古今和歌集・式子内親王）
解　「緒」の縁語＝「絶え」「ながらへ」「弱り」。訳「私の命よ、絶えるのならば絶えてしまえ。生きながらえるならば、恋を忍ぶ心が弱って（人に知られて）しまうといけないから」。「絶えなば」＝完了「ぬ」の未然形＋ば（仮定）、「絶えね」＝完了「ぬ」の命令形（二句切れ）、「もぞする」＝懸念。

体言止め・倒置・見立ては「効果」まで答える

「表現技法とその効果を説明せよ」と問われたとき。
体言止め＝名詞で終え、余情・余韻を残す（新古今和歌集に多い）。倒置＝語順を入れかえて強調する。見立て＝ある物を別の物になぞらえる（散る花を雪に、紅葉を錦に）。擬人法＝人でないものを人のように扱う。
技法の名前だけでなく、「何を強調し、どんな情景・気分を生むか」まで書く。
次の歌の句切れと表現技法を説明せよ。
見渡せば花も紅葉もなかりけり浦の苫屋の秋の夕暮れ（新古今和歌集・藤原定家）
解　三句切れ（「けり」の終止形）・体言止め（「秋の夕暮れ」）。華やかな花や紅葉を「なかりけり」と打ち消して示したうえで、何もない海辺の粗末な小屋の秋の夕暮れのさびしい情景を、余韻として残している。

和歌の解釈は「修辞を外す→景と心に分ける→場面と結ぶ」

和歌の内容・心情を問う選択肢・記述問題。
①句切れで区切る。②枕詞・序詞は外し、掛詞は二重に訳す。③自然の描写（景）と作者の思い（心）に分ける。④詞書や前後の文から「誰が・誰に・どんな場面で」詠んだかを確かめ、心情を一文にまとめる。
新古今時代には、有名な古歌の語句を取りこみ、もとの歌の世界を重ねる本歌取りも多い。
次の歌に①〜④の手順を当てはめよ。
来ぬ人をまつほの浦の夕なぎに焼くや藻塩の身もこがれつつ（新勅撰和歌集・藤原定家）
解　①句切れなし。②「まつ」＝待つ／松帆（の浦）の掛詞。「まつほの浦の夕なぎに焼くや藻塩の」が「こがれ」を導く序詞。「焼く」「藻塩」「こがれ」は縁語。③景＝夕なぎの松帆の浦で焼かれる藻塩。心＝来ない恋人を待ち、身も焦がれる思い。④訳「いくら待っても来ない人を待つ私は、松帆の浦の夕なぎのころに焼く藻塩のように、身も恋い焦がれ続けている」。「来ぬ」は体言「人」に続く連体形なので打消「ず」（こぬ）。

リード文・注・設問を本文より先に読む

初めて見る古文の文章を読み始めるとき。
①本文の前のリード文（出典・場面・人物関係）を読み、登場人物を簡単な相関図にする。②注（人物・官職・語義）に目を通す。注で説明された人物は本文で主語になりやすい。③設問と選択肢にざっと目を通す（選択肢は本文の内容の大きなヒント）。
リード文に「ある姫君の乳母が、姫君の将来を案じる場面である」とある。本文で敬語のついていない「嘆く」の主語として、まず考えるべき人物は？
解　乳母。姫君には敬語が使われるのがふつうなので、敬語のない動作は仕える側の乳母と考え、文脈で確かめる。

会話文の主語は「敬語」と「と言ふ」で補う

「 」の中や会話の前後で、誰が誰に言ったか・誰の動作かを問われたとき。
①会話文の中では、話し手（私）と聞き手（あなた）が省略されやすい。②会話の中の尊敬語は聞き手や第三者の動作、謙譲語・丁寧語は話し手自身の動作であることが多い。③会話の後の「と言ふ」「とのたまふ」「と申す」の敬語で、話し手の身分がわかる。
作例「『いかでかかる所におはしつらむ』と問へば、『道に迷ひて侍り』といらふ。」の「おはし」「侍り」の主語は？
解　「おはし」（尊敬語）＝聞き手（あなた）。「どうしてこのような所にいらっしゃったのだろう」。「侍り」（丁寧語）＝答えた人自身。「道に迷っております」。問う人と答える人は「ば」で入れかわる。

人物は官職・呼び名で追う

同じ人物が「中将」「君」「男」など違う名前で出てくるとき。
古文の人物は、本名でなく官職・住まい・立場で呼ばれる。昇進すると呼び名も変わる。
主な呼び名：帝・主上・内（天皇）、院（上皇）、宮（皇族）、殿（摂政・関白・大臣など）、女御・更衣（帝の妻。女御が上）、上（天皇／貴人の妻）、女房（宮仕えする女性）。「内裏（うち）」は宮中。
作例「大将、内裏に参り給ふ。上、このことを聞こしめして、いみじう感ぜさせ給ふ。」の「内裏」と「上」は何を指すか。
解　「内裏」＝宮中（帝の住まい）。「上」＝帝。帝などに使う尊敬語「聞こしめす」（お聞きになる）や最高敬語「させ給ふ」が使われていることからも確かめられる（「感ぜ」はサ変「感ず」の未然形）。「上」は文脈によって貴人の妻（北の方）を指すこともある。

古今異義語は「今の意味」で訳さない

今も使う言葉が傍線部にあり、その意味を問われたとき。
形は同じでも意味が違う語は、選択肢で今の意味のわなになる。
ありがたし（めったにない）、めでたし（すばらしい）、うつくし（かわいい）、やがて（そのまま・すぐに）、なかなか（かえって）、おどろく（目を覚ます・はっと気づく）、ながむ（もの思いにふける）、ののしる（大騒ぎする・評判になる）、あさまし（驚きあきれる）、すさまじ（興ざめだ）、かなし（いとしい）、としごろ（長年）、おとなし（大人びている）。
「ありがたきもの。舅にほめらるる婿。」（枕草子）を訳せ。
解　「めったにないもの。舅にほめられる婿」。「ありがたし」は「有り＋難し」で「存在することが難しい」。「らるる」は受身「らる」の連体形。

心情語・評価語は「プラスかマイナスか」から決める

心情を表す形容詞・形容動詞の意味を問われたとき。心情説明の選択肢。
まずプラス（好ましい）かマイナス（好ましくない）かを決め、次に細かい意味で選ぶ。
心もとなし（待ち遠しい・不安だ）、うしろめたし（気がかりだ）、ゆかし（見たい・知りたい）、いとほし（気の毒だ）、心苦し（気の毒だ・心が痛む）、はしたなし（きまりが悪い）、かたはらいたし（はらはらする・きまりが悪い）、あいなし（つまらない・気に入らない）、さうざうし（物足りない）、らうたし（かわいい）、あてなり（高貴だ・上品だ）、なまめかし（優美だ）。
作例「月の出づるを待つほど、いと心もとなし。」の「心もとなし」の意味は？
解　待ち遠しい（じれったい）。月が出るのを待つ場面なので、「不安だ」ではなく「待ち遠しい」をとる。

呼応の副詞は下の語とセットで訳す

「え」「さらに」「よも」「ゆめ」などの副詞を含む部分の訳。
え〜打消（〜できない）、な〜そ（〜するな）、さらに・つゆ・たえて・おほかた〜打消（まったく〜ない）、をさをさ〜打消（ほとんど〜ない）、いと〜打消（たいして〜ない）、よも〜じ（まさか〜ないだろう）、ゆめ〜な・禁止（決して〜するな）、いかで〜意志・願望（なんとかして〜たい）。
「いとやむごとなき際にはあらぬが」（源氏物語・桐壺）と、作例「え言はず」を訳せ。
解　前者は「いと〜打消」で「たいして高貴な身分ではない方で」（「いと」を「とても」と訳すと誤り）。後者は「言うことができない」。

恋愛・結婚の常識で場面を読む

男女の関係が話題の文章（物語・日記・説話）。
貴族の女性は御簾や几帳の内にいて顔を見せない。男は噂を聞き、垣間見（のぞき見）をし、和歌・手紙を贈る。女の返歌があれば、男が夜に女のもとへ通う。三晩続けて通うと結婚が成立する。翌朝の別れは後朝（きぬぎぬ）で、男はすぐに後朝の文を贈る。
「見る」「逢ふ」「契る」は男女が結ばれること、「世」「世の中」は男女の仲を表すことがある。
作例「男、その女を見てけり。」の「見る」の意味は？
解　（女と）結婚した・契りを結んだ。単に「見た」と訳さない。

暦・時刻・信仰の常識で状況を補う

月名・時刻・季節・方角・仏教や陰陽道の語が出てきたとき。

現代語訳は「品詞分解→重要語→文法→補足」の4段階

「傍線部を現代語訳せよ」と問われたとき。
①品詞分解：単語に区切り、助動詞・助詞に印をつける。②重要古語を辞書的な訳に置きかえる。③助動詞・助詞・敬語の意味を一つ残らず訳に出す（打消・推量・完了・係り結びの強意など）。④主語・目的語など省略された語を（　）で補い、自然な日本語に整える。
次の文を訳せ。
つれづれなるままに、日暮らし、硯にむかひて、心にうつりゆくよしなし事を、そこはかとなく書きつくれば、あやしうこそものぐるほしけれ。（徒然草・序段）
解　重要語：つれづれなり（することがなく退屈だ）、ままに（〜にまかせて）、日暮らし（一日中）、よしなし事（つまらないこと）、そこはかとなく（とりとめもなく）。文法：「書きつくれば」＝已然形＋ば（〜していると）、「こそ〜ものぐるほしけれ」＝係り結び（已然形）。
訳「することもなく退屈なのにまかせて、一日中、硯に向かって、心に浮かんでは消えていくつまらないことを、とりとめもなく書きつけていると、妙に気が変になりそうな気持ちがする」。

同格の「の・が」は「〜で」と訳し、後ろに体言を補う

「体言＋の（が）、……連体形、」の形で、文の主語がはっきりしないとき。
「AのB（連体形）」の連体形の下に、上の体言Aを補って意味が通るなら同格。訳は「Aで、Bである（A）」。
次の文を訳せ。
白き鳥の、はしとあしと赤き、しぎの大きさなる、水の上に遊びつつ魚を食ふ。（伊勢物語・第九段）
解　「鳥の」は同格。「赤き」「大きさなる」の下に「鳥」を補う。訳「白い鳥で、くちばしと脚とが赤い、鴫ぐらいの大きさの（鳥）が、水の上で遊びながら魚を食べている」。
「白き鳥の」を主語（白い鳥が）と訳してしまうと、「赤き」の下でつながらなくなる。「の」の後ろに読点があり、連体形が続いたら同格を疑う。

解釈の選択肢は「傍線部の単語」で先に絞る

傍線部の解釈・現代語訳として適当なものを選ぶ問題。
選択肢を読む前に、傍線部を単語に区切っておく。①重要古語の訳、②助動詞の意味（打消・推量・完了・可能など）、③敬語（主語は誰か）が正しく反映されているかで消去する。最後に文脈に合うかを確かめる。
作例：傍線部「やがて出でぬ」の解釈として適当なものは？　① しばらくして出かけた　② そのまま出て行った　③ いつか出かけるだろう　④ やっと出ることができた
解　②。「やがて」＝そのまま・すぐに。「ぬ」は文末で言い切る終止形なので完了（出て行った）。①は「やがて」を今の意味（まもなく）にした誤り、③は推量、④は可能の意味を加えた誤り。

心情説明は「きっかけ＋心情語」の形で書く

「このときの〜の心情を説明せよ」と問われたとき。
①傍線部や前後から心情語（うれし・あはれなり・心憂し・口惜し・心もとなし…）を探す。②その心情を生んだ出来事（きっかけ）を前から探す。③「（きっかけ）ので、（心情）という気持ち」の形にまとめる。古語の心情語は現代語に直す。
作例「月ごろ待ちわたりつる文の、つひに来ず。いと心憂くて、泣く泣く臥しぬ。」の女の心情を、30字以内で説明せよ。
解　きっかけ＝何か月も待ち続けた手紙がついに来なかった。心情語＝心憂し（つらい・情けない）。
解答例：何か月も待ち続けた手紙がついに来ず、つらく情けない気持ち。（29字）
「月ごろ」は「数か月来」。「悲しい」だけでは「心憂し」の訳として不十分なことがある。古語の意味に合う現代語を選ぶ。

理由説明は「已然形＋ば」の前を探す

「なぜ〜したのか」「理由を説明せよ」と問われたとき。
①傍線部の直前に已然形＋ば（〜ので）があれば、その前が理由。②「〜に」「〜を」（接続助詞）の前、「〜ゆゑ」「〜により」の前も理由になりやすい。③会話文の中の「さるは」（実は）の後ろに本当の理由が述べられることもある。答えは「〜から」で結ぶ。
「中垣こそあれ、一つ家のやうなれば、望みて預かれるなり。」（土佐日記）で、隣人が自分から家を預かった理由は？
解　隔ての垣根はあっても、（隣同士で）一つの家のような親しい間柄だったから。根拠は「やうなれば」（断定「なり」の已然形＋ば＝〜なので）。

指示語「さ・かく・しか」は内容を代入して訳す

「さ」「かく」「さる」「かかる」などを含む部分の内容説明。
「さ・しか」＝そう・そのように、「かく」＝このように、「さる・さやうなる」＝そのような、「かかる」＝このような、「さるべき」＝しかるべき・そうなるはずの。指す内容はふつう直前の会話・動作。見つけた内容を現代語にして指示語の位置に入れ、意味が通るか確かめる。
作例「『明日は必ず来む』と言ひしかど、さもあらず。」の「さもあらず」を、指示内容を明らかにして訳せ。
解　「さ」＝明日は必ず来るということ。「（明日は必ず来ようと言ったけれど）その通りにもならなかった（来なかった）」。「しか」は過去「き」の已然形＋逆接の「ど」。

文中の和歌は「誰が・誰に・何のために」から読む

物語・日記の中の和歌について、内容や詠んだ意図を問われたとき。
①詠み手と相手（贈答歌の返歌は、相手の歌の言葉や掛詞を受けて切り返す）。②詠んだきっかけ（直前の出来事）。③修辞を外した心情。④和歌を聞いた人の反応（後ろの文）で、歌の意味を確かめる。
伊勢物語・第九段で、「かきつばた」の五文字を各句の頭に置いて旅の心を詠めと言われた男が詠んだ次の歌は、何を詠んだものか。
から衣きつつなれにしつましあればはるばるきぬる旅をしぞ思ふ
解　各句の頭に「か・き・つ・は・た」を置く折句。「から衣きつつ」が「なれ」を導く序詞で、「なれ（慣れ／萎れ）」「つま（妻／褄）」「はるばる（遥々／張る）」「き（来／着）」が掛詞、「着・萎れ・褄・張る」が衣の縁語。心情＝都に残してきた妻を思い、はるばる遠くまで来た旅をしみじみと思う。後に「みな人、乾飯の上に涙落としてほとびにけり」とあり、一行がみな望郷の思いに泣いたことがわかる。

敬語と省略を訳に必ず出す

敬語を含む部分の現代語訳。採点基準が細かい記述式の訳。
尊敬語→「〜なさる・お〜になる」、謙譲語→「お〜申し上げる・差し上げる」、丁寧語→「〜です・〜ます・ございます」。本動詞は固有の訳（のたまふ＝おっしゃる、参る＝参上する、奉る＝差し上げる）。省略された主語・目的語は（　）で補う。敬語の訳もれ・主語の補いもれは減点の対象。
作例「（大臣が帝に）御文を奉り給ふ。」を訳せ。
解　「（大臣が帝に）お手紙を差し上げなさる」。「奉り」（謙譲）と「給ふ」（尊敬）の両方を訳に出す。

内容合致は「主語・時・否定」のすり替えを探す

本文の内容と合致するものを選ぶ問題。
選択肢を要素に区切り、本文の該当箇所と一つずつ照合する。古文の誤りの選択肢の典型は、①主語（誰の行動・心情か）のすり替え、②打消・推量の見落とし（していない／するだろう を、した とする）、③時間の前後の入れかえ、④本文にない理由の追加。
本文「男、文をやれども、女、返りごともせず」。選択肢「女は男に手紙を送ったが、男は返事をしなかった」は合致するか。
解　合致しない（主語のすり替え）。手紙を送ったのは男で、返事をしなかったのは女。「ども」（逆接）の前後で主語が変わっている。

返り点は「レは一字、一二は飛び越え、上下は一二をはさむ」

返り点のついた文の読む順序・書き下し文を問われたとき。
①返り点のない字は上から順に読む。②レ点：下の一字を読んでから、すぐ上の字に返る。③一・二・三点：「一」の字を読んだら「二」、さらに「三」へ返る（二字以上離れて返る）。④上・（中）・下点：一二点をはさんで、さらに上へ返る。⑤一レ（上レ）：まずレ点に従って返り、次にその字の「一（上）」から「二（下）」へ返る。
次の文の読む順序を示し、書き下し文にせよ。
不ル下以テ二千里ヲ一称セラレ上也。（韓愈「雑説」）
解　千里（一）→以（二）→称（上）→不（下）→也。書き下し「千里を以て称せられざるなり」。訳「千里の名馬だとたたえられることがないのである」。「不」は助動詞「ず」、「也」は「なり」なので、書き下し文ではひらがなにする。

書き下し文は「ひらがなにする字」と「書かない字」を区別

「書き下し文に改めよ」と問われたとき。
①漢字かな交じり文にし、送り仮名は歴史的仮名遣いのひらがなにする。②日本語の助詞・助動詞にあたる字はひらがなにする（不→ず、也→なり、之（の）→の、可→べし、見・被→る・らる、使・令→しむ、乎・哉・与→か・や、者（は）→は）。③置き字は書かない。④再読文字は1回目を漢字、2回目をひらがなで書く。
次の文を書き下し文にせよ。
子曰ハク、学ビテ而時ニ習フレ之ヲ、不二亦説バシカラ一乎。（論語）
解　「子曰はく、学びて時に之を習ふ、亦説ばしからずや」。「而」は置き字なので書かない。「不」「乎」は助動詞・助詞にあたるのでひらがな（ず・や）。「之」は「これ」と読む代名詞なので漢字のまま。訳「先生がおっしゃるには、学んで、機会があるたびにそれを復習する、なんとうれしいことではないか」。

置き字は読まないが、働きは送り仮名に出る

「而」「於」「于」「乎」「矣」「焉」が文中にあるとき。置き字の働きを問われたとき。
而：接続（順接「て・して」、逆接「ども・も」）。直前の字の送り仮名で表す。
於・于・乎：場所・時・対象・起点・比較・受身の相手（に・を・より・よりも）。下の語の送り仮名で表す。
矣・焉（文末）：断定・強意。
注意：文末の「乎」を「や・か」と読むときは疑問・反語の助字で、置き字ではない。「焉」も「いづくんぞ」と読めば疑問詞。
次の文を書き下し文にし、二つの「於」の働きを答えよ。
青ハ取リテ二之ヲ於藍ヨリ一、而青シ二於藍ヨリモ一。（荀子）
解　「青は之を藍より取りて、藍よりも青し」。一つ目の「於」は起点（藍から取る）、二つ目は比較（藍よりも青い）。「而」も置き字で、接続の働きは「取りて」の「て」で表されている。訳「青色の染料は藍草から取るが、もとの藍よりも青い」（弟子が師をしのぐ「出藍の誉れ」の由来）。

再読文字は「1回目は副詞、2回目は助動詞・動詞」

「未・将・且・当・応・宜・須・猶・由・盍」が出てきたとき。
①返り点を無視して、その字に来たら1回目を読む（副詞として）。②返り点に従って戻ってきたとき2回目を読む（助動詞・動詞として）。③書き下しでは1回目を漢字、2回目をひらがなで書く。
読みと意味は下の表で確実に覚える。とくに「当（当然）」と「応（推量）」、「宜（適当）」と「須（必要）」の区別が問われる。
次の文を書き下し文にし、訳せ。
過ギタルハ猶ホレ不ルガレ及バ。（論語）
未ダレ知ラレ生ヲ、焉クンゾ知ランレ死ヲ。（論語）
解　①「過ぎたるは猶ほ及ばざるがごとし」＝行き過ぎは、ちょうど足りないのと同じようなものだ。「猶」は1回目「なほ」、2回目「ごとし」。
②「未だ生を知らず、焉くんぞ死を知らん」＝まだ生のこともわからない。どうして死のことがわかろうか（いや、わからない）。「未」は1回目「いまだ」、2回目「ず」。

否定は「不・無・非・未・勿」の読みで意味を分ける

否定の字を含む文の書き下し・訳。
不・弗（ず）＝動作・状態の否定「〜しない」。無・莫（なシ）＝存在の否定「〜がない」。非（あらズ）＝判断の否定「〜ではない」（「〜に非ず」と体言の下に「に」を入れて読む）。未（いまダ〜ず）＝「まだ〜ない」。勿・毋・莫・無（なカレ）＝禁止「〜するな」。
書き下しでは「不」は助動詞なのでひらがな（ず）、「無・莫・勿」は形容詞「なし」、「非」は「あらず」なので漢字のまま書く。
次の文を書き下し文にし、訳せ。
己ノ所ハレ不ルレ欲セ、勿カレレ施スコト二於人ニ一。（論語）
解　「己の欲せざる所は、人に施すこと勿かれ」。訳「自分が望まないことは、他人にしてはならない」。「不」は打消（連体形「ざる」）、「勿」は禁止、「於」は対象を表す置き字。

部分否定と全部否定は「否定語と副詞の順」で決まる

「不常」「常不」「不必」「必不」「不倶」「倶不」「不甚」「甚不」などが出てきたとき。
否定語が先（不＋副詞）→ 部分否定：「常には〜ず」（いつも〜とは限らない）、「必ずしも〜ず」（必ずしも〜とは限らない）、「倶には〜ず」（両方とも〜というわけではない）、「甚だしくは〜ず」（それほど〜ではない）。
副詞が先（副詞＋不）→ 全部否定：「常に〜ず」（いつも〜ない）、「必ず〜ず」（必ず〜ない）、「倶に〜ず」（両方とも〜ない）、「甚だ〜ず」（まったく〜ない）。
部分否定の読みでは、副詞に「は」がつくことが多い（常には・倶には）。
次の文を書き下し文にし、訳せ。
家貧シクシテ不二常ニハ得一レ油ヲ。（蒙求）
解　「家貧しくして常には油を得ず」。否定語「不」が副詞「常」より先なので部分否定。訳「家が貧しくて、いつも（灯火の）油を手に入れられるとは限らなかった」。読む順は 家→貧→常→油→得（一レ）→不（二）。

二重否定は「強い肯定」に訳す

否定語が二つ重なっているとき（無不・非不・不可不・未嘗不・不敢不）。
「無不〜」＝〜ざるは無し（〜しないものはない＝すべて〜する）。「非不〜」＝〜ざるに非ず（〜しないのではない）。「不可不〜」＝〜ざるべからず（〜しなければならない）。「未嘗不〜」＝未だ嘗て〜ずんばあらず（今まで〜しなかったことはない）。「不敢不〜」＝敢へて〜ずんばあらず（〜しないわけにはいかない）。訳は打消を二つとも訳してから、肯定の意味を確かめる。
次の文を書き下し文にし、訳せ。
吾ガ矛之利ナルコト、於イテレ物ニ無キレ不ルレ陥サ也。（韓非子）
解　「吾が矛の利なること、物に於いて陥さざる無きなり」。訳「私の矛の鋭いことといったら、どんな物でも突き通さないものはないのだ」（＝何でも突き通す）。「之」は「の」、「也」は「なり」とひらがなで書く。

可能・不可能は「能・可・得・足」の読みで

「能」「可」「得」「足」を含む文の書き下し・訳。
「能〜」（よく〜：〜できる）、「不能〜」（〜〔こと〕能はず：〜できない）。「可〜」（〜べし：〜できる・〜してよい）、「不可〜」（〜べからず：〜できない・〜してはならない）。「得〜」（〜を得：〜できる）、「不得〜」（〜を得ず：〜できない）。「足〜」（〜に足る：〜する価値がある・十分〜できる）。
「能」は否定されると「あたは」と読む。「可」は助動詞なので書き下しではひらがな（べし）。

疑問か反語かは、文末の「〜ん（や）」で見当をつける

疑問詞（何・誰・孰・安・焉・悪・胡・奚・豈）や文末の「乎・哉・也・与」がある文の書き下し・訳。
①文末が連体形＋か／終止形＋やなど推量を含まない形 → 疑問が多い（〜か）。②文末が推量「ん」＋（や） → 反語が多い（どうして〜だろうか、いや〜ない）。③「豈に〜んや」は必ず反語。
反語の訳は「いや、〜ない」という打消しまで書く。最後は、筆者が強く打ち消したい内容かどうか、文脈で確かめる。
次の文を書き下し文にし、訳せ。
王侯将相寧クンゾ有ランレ種乎。（史記）
解　「王侯将相寧くんぞ種有らんや」。文末が「有らんや」なので反語。訳「王・諸侯・将軍・宰相になるのに、どうして決まった家柄などあろうか、いや、ありはしない」。

「何如」は様子・是非、「如何」は方法・処置

「何如」「如何」「奈何」「何以」「何為」が出てきたとき。
何如（いかん）＝どうであるか（状態・是非・相手の考えを問う）。如何・奈何（いかん）＝どうしようか・どうしたらよいか（方法・処置を問う）。「如A何」「奈A何」＝Aを如何せん（Aをどうしようか・どうしようもない）。何以（なにをもつて）＝どうして・どのようにして。何為（なんすれぞ）＝どうして。
次の二つの文を書き下し文にし、訳せ。
以テ二子之矛ヲ一、陥サバ二子之盾ヲ一、何如。（韓非子）
虞ヤ兮虞ヤ兮奈レ若ヲ何セン。（史記）
解　①「子の矛を以て、子の盾を陥さば、何如」＝あなたの矛で、あなたの盾を突いたら、どうなるか（結果・状態を問う）。
②「虞や虞や若を奈何せん」＝虞よ、虞よ、お前をどうしたらよいのか（どうしようもない）。「兮」は語調を整える置き字。

使役は「AをしてBしむ」の形をつかむ

「使・令・教・遣」があり、その下に人と動作が続くとき。
「使A B」＝AをしてBしむ（AにBさせる）。Aに送り仮名「ヲシテ」、Bの送り仮名は未然形、「使」はしむと読み、書き下しではひらがなにする。返り点は「使（二）A B（一）」、Bの下にさらに目的語があれば「使（三）A B（二）C（一）」。
「命・召・遣」など使役の意味をふくむ動詞の後は、下の動詞を「〜しむ」と読むことがある（命じて〜せしむ）。
次の文を書き下し文にし、訳せ。
天帝使ム三我ヲシテ長タラ二百獣ニ一。（戦国策）
解　「天帝我をして百獣に長たらしむ」。訳「天の神は私を百獣の長にならせたのだ」。読む順は 天帝→我→百獣（一）→長（二）→使（三）。

受身は「見・被・為〜所」と「於」で見抜く

「見・被・為・所」がある文、または「動詞＋於＋人」の形の文。
①「見V」「被V」＝Vる・らる（Vされる）。「見・被」は助動詞なのでひらがな（る・らる）で書く。②「為A所V」＝AのVする所と為る（AにVされる）。③「V於A」＝AにVせらる（置き字「於」の下が動作をする人）。④受身の字がなくても、送り仮名「〜（セ）ラル」で受身を表すことがある。
次の二つの文を書き下し文にし、訳せ。
先ンズレバ即チ制シレ人ヲ、後ルレバ則チ為ル二人ノ所一レ制スル。（史記）
信ニシテ而見レレ疑ハ、忠ニシテ而被ルレ謗ラ。（史記）
解　①「先んずれば即ち人を制し、後るれば則ち人の制する所と為る」＝先に行動すれば人を支配し、遅れれば人に支配される。
②「信にして疑はれ、忠にして謗らる」＝誠実であるのに疑われ、忠義を尽くしているのに悪く言われる。「見」は「れ」、「被」は「る」とひらがなで書く。

比較は「於（よりも）」「不如（しかず）」「莫如（しくはなし）」

「於・于・乎」が形容詞の後にあるとき。「如・若」が「不・莫・無」と組んでいるとき。
①「A＋形容詞＋於B」＝AはBよりも〜。②「A不如B」＝AはBに如かず（AはBに及ばない＝Bのほうがよい）。③「莫如B」「無若B」＝Bに如くは莫し（Bに及ぶものはない＝Bが一番だ）。④「与其A、寧B」＝其のAせんよりは、寧ろBせよ（AするよりはむしろBするほうがよい：選択）。
次の二つの文を書き下し文にし、訳せ。
百聞ハ不レ如カ二一見ニ一。（漢書）
霜葉ハ紅ナリ二於二月ノ花ヨリモ一。（杜牧「山行」）
解　①「百聞は一見に如かず」＝百回聞くことは、一回見ることに及ばない。
②「霜葉は二月の花よりも紅なり」＝霜にあたって色づいた葉は、春二月の花よりも赤い。「於」は比較を表す置き字。

仮定は「如・若・苟・縦・雖」と送り仮名「バ・トモ」

「もし〜ならば」「たとえ〜でも」の意味の文。仮定の字や「〜バ」「〜トモ」の送り仮名があるとき。
如・若（もシ〜バ：もし〜ならば）、苟（いやしクモ〜バ：かりにも〜ならば）、縦・縦令（たとヒ〜トモ：たとえ〜としても）、雖（〜トいへどモ：〜けれども・たとえ〜でも）。
仮定の字がなくても、送り仮名が「未然形＋バ」「〜トモ」なら仮定で訳す。
次の文を書き下し文にし、訳せ。
朝ニ聞カバレ道ヲ、夕ベニ死ストモ可ナリ矣。（論語）
解　「朝に道を聞かば、夕べに死すとも可なり」。訳「朝に人として生きる道を聞いて悟ることができたなら、その日の夕方に死んでもかまわない」。「聞かば」（未然形＋ば）、「死すとも」が仮定。「矣」は置き字。ここの「可なり」は「よい」という意味の語なので漢字で書く。

限定「唯・独・耳・而已」と累加「不唯・豈唯」を区別

「唯・惟・但・只・徒・独」や文末の「耳・已・爾・而已・而已矣」があるとき。
限定：唯・惟・但・只・徒・直（たダ〜のみ）、独（ひとリ〜のみ）、文末の耳・已・爾・而已・而已矣（のみ）＝「ただ〜だけだ」。
累加：「不唯A」（唯だにAのみならず：Aだけではない）、「豈唯A」（豈に唯だにAのみならんや：どうしてAだけであろうか、いやAだけではない）。限定の字の上に否定・反語がつくと累加になる。
次の文を書き下し文にし、訳せ。
夫子之道ハ、忠恕ノミ而已矣。（論語）
解　「夫子の道は、忠恕のみ」。訳「先生の道は、まごころと思いやりだけである」。文末の「而已矣」で限定。書き下し文では「のみ」とひらがなで書く。

抑揚「A且B、況C乎」は後半が本題

「且」「猶」と「況」が呼応しているとき。前半で軽いもの、後半で重いものを比べているとき。
「Aスラ且ツB、況ンヤCヲや」＝AでさえBだ、ましてCはなおさらBだ。前半で程度の軽いものを抑え、後半で本題を持ち上げて強調する。後半が「況んや」ではなく、反語（安くんぞ〜ん）になる型もある。
次の二つの文を書き下し文にし、訳せ。
死馬スラ且ツ買フレ之ヲ。況ンヤ生ケル者ヲ乎。（十八史略）
臣死スラ且ツ不レ避ケ。卮酒安クンゾ足ランレ辞スルニ。（史記）
解　①「死馬すら且つ之を買ふ。況んや生ける者をや」＝死んだ馬でさえ（大金で）買うのだ。まして生きている馬ならなおさら（高く買う）だ。
②「臣死すら且つ避けず。卮酒安くんぞ辞するに足らん」＝私は死でさえ避けない。大杯の酒などどうして辞退しようか、いや、辞退などしない（後半が反語の型）。

詠嘆・願望は「亦〜ずや」「豈不〜哉」「願・請」

文末に「哉・夫・乎」があり、疑問・反語では意味が通らないとき。「願」「請」で始まる会話文。
詠嘆：嗚呼・噫（ああ）、文末の哉・夫・矣乎（かな）、「不亦〜乎」（亦〜ずや：なんと〜ではないか）、「豈不〜哉」（豈に〜ずや：なんと〜ではないか）。
願望：「願〜」「請〜」（願はくは・請ふ）＋自分の動作「〜ん」＝どうか〜させてください、＋相手の動作「〜せよ」（命令形）＝どうか〜してください。
論語「不亦説乎」（亦説ばしからずや。第15章）は疑問・反語・詠嘆のどれか。また、次の文を書き下し文にし、訳せ。
願ハクハ大王急ギ渡レ。（史記）
解　「亦説ばしからずや」は詠嘆（なんとうれしいことではないか）。後の文は「願はくは大王急ぎ渡れ」＝どうか大王様、急いで（川を）お渡りください（相手への願望なので命令形「渡れ」）。

故事成語は「話の筋→教訓→今の意味」をつなげる

故事成語の由来となった話が本文に出たとき。「この話から生まれた故事成語は？」「その意味は？」と問われたとき。
①登場人物と出来事（何をして、どうなったか）をつかむ。②結末の一文や、話の後の作者の評言から教訓を読み取る。③教訓と現代の意味を結びつける。
代表的な故事成語は、出典と意味をセットで覚える（下の表）。
韓非子の「矛盾」の話（楚の人が「どんな物も突き通せない盾」と「どんな物でも突き通す矛」を売り、「あなたの矛であなたの盾を突いたらどうなるか」と問われて答えられなかった）で、楚の人が答えられなかったのはなぜか。また「矛盾」の意味を答えよ。
解　何も通さない盾と何でも通す矛は、同時には成り立たないから（どちらと答えても、自分の言葉のどちらかがうそになる）。「矛盾」＝前後のつじつまが合わないこと。

会話は「曰」から始まり「と」で閉じる

会話の範囲、話し手・聞き手、代名詞の指すものを問われたとき。
①「A曰（Aいはく）」の後から会話が始まる。会話の終わりを見つけて「〜と」で閉じる（書き下し文では「〜と。」）。②会話中の吾・我・臣・寡人は話し手、子・君・汝・若は聞き手。③人物は、最初に姓名で出たあと、名・字（あざな）・官職で呼ばれることがある。④主語の省略は、前の文の主語が続いていることが多い。
次の文を書き下し文にし、会話の範囲と「之」「吾」の指すものを答えよ（楚の人が盾と矛を売る場面）。
誉メテレ之ヲ曰ハク、吾ガ盾之堅キコト、莫キ二能ク陥スモノ一也ト。（韓非子）
解　「之を誉めて曰はく、吾が盾の堅きこと、能く陥すもの莫きなりと」。会話は「吾が盾の〜莫きなり」まで。「之」は（楚の人が売っている）盾、「吾」は話し手の楚の人。訳「盾をほめて言うには、『私の盾の堅いことといったら、突き通せるものはない』と」。

対句は「対応する語どうし」で意味を決める

同じ構造の句が二つ並んでいるとき。語の意味や空欄の字を問われたとき。
漢文は対句（同じ組み立ての句を並べる）が多い。対応する位置の語は、似た意味か反対の意味になる。意味のわからない語は、対になる語から推測する。対句の一方を手がかりに、もう一方の書き下しや送り仮名もそろえる。
次の文を書き下し文にし、「罔」と「殆」の意味の違いを説明せよ。
学ビテ而不レバレ思ハ則チ罔シ、思ヒテ而不レバレ学バ則チ殆フシ。（論語）
解　「学びて思はざれば則ち罔し、思ひて学ばざれば則ち殆ふし」。「学」と「思」を入れかえた対句。訳「学んでも自分で考えなければ、（物事が）はっきりわからない。考えても学ばなければ、（独りよがりになって）危うい」。「罔」は学ぶだけで考えないために理解がぼんやりしたままであること、「殆」は考えるだけで学ばないために独断に陥って危ういこと。

思想の文章は「誰の、何に対する主張か」を軸に読む

諸子百家（孔子・孟子・荀子・老子・荘子・韓非子など）の文章。
儒家：孔子（論語）＝仁・礼による徳治。孟子＝性善説、仁義による王道政治。荀子＝性悪説、礼による教化。
道家：老子・荘子＝無為自然。人為的な道徳や知恵を退ける。
法家：韓非子＝法と賞罰による統治。墨家：墨子＝兼愛（区別のない愛）・非攻（侵略戦争の否定）。
思想の文章は、対立する考え（儒家と道家、性善と性悪）との対比で主張をつかむ。
次の二つの文を書き下し文にし、それぞれの主張を説明せよ。
人之性ハ悪ナリ、其ノ善ナル者ハ偽也。（荀子）
大道廃レテ、有リ二仁義一。（老子）
解　①「人の性は悪なり、其の善なる者は偽なり」＝人の本性は悪であり、善であるのは人為（後天的な努力・教育）によるものだ（性悪説）。「偽」は「いつわり」ではなく「人為」の意味。
②「大道廃れて、仁義有り」＝大いなる道（自然のままの道）がすたれたから、仁義（という人為的な道徳）が説かれるようになった。儒家の仁義を批判する道家の主張。

漢詩の形式は「句の数×1句の字数」で決まる

「この詩の形式（詩形）を答えよ」と問われたとき。
近体詩（唐代に完成）：絶句＝4句（起句・承句・転句・結句）、律詩＝8句（首聯・頷聯・頸聯・尾聯）。1句が5字なら五言、7字なら七言。→ 五言絶句・七言絶句・五言律詩・七言律詩。10句以上の律詩は排律。
古体詩（古詩・楽府）：句数が自由で、押韻・対句の決まりがゆるい。
次の詩の形式を答え、書き下し文にせよ。
春眠不覚暁　処処聞啼鳥
夜来風雨声　花落知多少（孟浩然「春暁」）
解　4句・1句5字なので五言絶句。「春眠暁を覚えず　処処啼鳥を聞く　夜来風雨の声　花落つること知る多少」。訳「春の眠りは心地よく、夜が明けたのにも気づかない。あちこちで鳥の鳴く声が聞こえる。昨夜は風雨の音がしていた。花はどれほど散ったことだろう」。

押韻は「偶数句末」、七言は「第1句末」も

「押韻している字をすべて抜き出せ」と問われたとき。句末の空欄補充。
押韻＝句末の字の音読みの響き（韻）をそろえること。原則：五言詩は偶数句末、七言詩は第1句末と偶数句末。ただし五言詩でも第1句末で踏むことがある（「春暁」の暁・鳥・少）。
音読みにして、頭の子音を除いた部分（例：ジン・シン → 「イン」）が同じかどうかで確かめる。
次の詩の形式と、押韻している字を答えよ。
渭城朝雨浥軽塵　客舎青青柳色新
勧君更尽一杯酒　西出陽関無故人（王維「送元二使安西」）
解　七言絶句。押韻は第1・2・4句末の「塵（ジン）・新（シン）・人（ジン）」。書き下し「渭城の朝雨軽塵を浥し　客舎青青柳色新たなり　君に勧む更に尽くせ一杯の酒　西のかた陽関を出づれば故人無からん」。訳の要点：（別れの朝）さあもう一杯飲みほしてくれ、西の陽関を出たら、もう親しい友はいないだろうから。

律詩は頷聯・頸聯が対句になる

律詩で「対句になっている句を答えよ」「対句をふまえて訳せ」と問われたとき。
律詩は2句ずつで1聯（首聯・頷聯・頸聯・尾聯）。原則として頷聯（第3・4句）と頸聯（第5・6句）がそれぞれ対句。対句では文法の組み立てが同じで、名詞と名詞、数と数、色と色のように語が一つずつ対応する。首聯が対句になることもある。
次の詩の押韻の字と対句を指摘せよ。
国破山河在　城春草木深
感時花濺涙　恨別鳥驚心
烽火連三月　家書抵万金
白頭掻更短　渾欲不勝簪（杜甫「春望」）
解　五言律詩。押韻は偶数句末の「深・心・金・簪」（シン・シン・キン・シン）。対句は頷聯「感時花濺涙／恨別鳥驚心」と頸聯「烽火連三月／家書抵万金」（首聯「国破山河在／城春草木深」も対句）。
書き下し「国破れて山河在り　城春にして草木深し　時に感じては花にも涙を濺ぎ　別れを恨んでは鳥にも心を驚かす　烽火三月に連なり　家書万金に抵る　白頭掻けば更に短く　渾べて簪に勝へざらんと欲す」。

漢詩の設問は「押韻・対句・景から情へ」で解く

漢詩の空欄補充、主題・心情を問う問題。
空欄補充：①空欄が押韻の位置なら、韻の合う字を選ぶ。②対句の位置なら、対になる字と同じ品詞・関連する意味の字を選ぶ。③詩全体の情景と矛盾しないか確かめる。
主題：前半に景（自然の描写）、後半に情（作者の思い）が来ることが多い。絶句では転句で場面や視点が変わり、結句に主題が置かれやすい。
「春望」の第2句を「城春草木（　）」とした場合、空欄に入る字を「深・緑・花・春」から選び、理由を述べよ。
解　「深」。偶数句末で押韻の位置にあり、「心・金・簪」と韻が合う（シン）。また、対句の「山河在」（山河はもとのまま在る）に対して「草木深」（草木が深く生い茂る）と、人の世の荒廃と変わらない自然を対比する意味にもなる。
