挿入ソートは「整列済みの部分に1つずつ差し込む」。ほぼ整列済みなら比較が少ない

挿入ソートの手順、データの並びによる比較回数の違いを問う。
先頭の1個を整列済みとし、次の要素を取り出して、整列済み部分を右から順に比べる。取り出した値より大きい要素は1つ右にずらし、そうでない要素に当たったら（または先頭まで来たら）その位置に入れる。

速さは「データ数を2倍・10倍にしたとき、手間が何倍になるか」で比べる

データ数を増やしたときの処理時間の見積もり、アルゴリズムの選び方を問う。
手間（比較回数など）がデータ数 $n$ にどう比例するかで比べる。
線形探索：$n$ に比例（2倍 → 2倍）。二分探索：$\log_2n$ に比例（2倍 → 1回増えるだけ）。選択・バブル・挿入ソート：$n^2$ に比例（2倍 → 4倍、10倍 → 100倍）。クイックソート（平均）：$n\log_2n$ に比例。
二分探索は速いが、あらかじめ整列しておく手間がかかる。探索を何度も行うなら、一度整列して二分探索を使う方が有利。
(1) 選択ソートで1000個を並べかえるのに0.2秒かかった。3000個ではおよそ何秒か。(2) 整列済みの100万個のデータを探索するとき、比較の最大回数は二分探索と線形探索でそれぞれ何回か。
解　(1) $n^2$ に比例するので $0.2\times3^2=$ 1.8秒　(2) $2^{19}=524288\lt10^6\lt2^{20}=1048576$ より二分探索は 20回、線形探索は 100万回。

パケット通信は「小さく分けて宛先と番号を付ける」。パケット数＝データ量÷1パケットのデータ部分（切り上げ）

パケット通信の利点、必要なパケット数や送信量を問う。
データを小さなパケットに分け、それぞれにヘッダ（送信元・宛先の IP アドレス、順番を表す番号など）を付けて送る。
利点：1本の回線を多くの通信で共有できる（回線交換のように1対1で占有しない）。経路の一部が故障しても別の経路で届けられる。誤りがあっても、そのパケットだけを再送すればよい。
パケットは別々の経路を通り、順番が入れかわって届くことがあるので、受信側で番号順に組み立てる。
必要なパケット数＝データ量÷（1パケットの大きさ－ヘッダの大きさ）の切り上げ。
1つのパケットは最大1500バイトで、そのうちヘッダが40バイトとする。10000バイトのデータを送るのに必要なパケットの最小の数と、ヘッダを含めた送信量の合計を求めよ。
解　データ部分は1パケットあたり $1500-40=1460$ バイト。$10000\div1460=6.84\dots$ なので 7個。送信量は $10000+40\times7=$ 10280バイト。

IP アドレスは「ネットワーク部＋ホスト部」。/n なら割り当てられる数は $2^{32-n}-2$ 個

サブネットマスク、ネットワークアドレス、ブロードキャストアドレス、割り当てられるアドレスの数を問う。
IPv4 は32ビット（8ビットずつ10進数で表して点で区切る）。総数は $2^{32}$（約43億）で不足するため、128ビットの IPv6 への移行が進む。
サブネットマスク：1のビットがネットワーク部、0のビットがホスト部。先頭から n ビットが1なら「/n」と書く（255.255.255.0 は /24）。
ネットワークアドレス：ホスト部をすべて0にしたもの（IP アドレス AND サブネットマスク）。ブロードキャストアドレス：ホスト部をすべて1にしたもの。この2つは機器に割り当てないので、割り当てられる数は $2^h-2$（$h$ はホスト部のビット数）。
192.168.10.75/26 について、(1) サブネットマスク、(2) ネットワークアドレス、(3) ブロードキャストアドレス、(4) 機器に割り当てられるアドレスの数を求めよ。
解　ネットワーク部は26ビットで、第4オクテットの上位2ビットまで。(1) $11000000_{(2)}=192$ より 255.255.255.192　(2) $75=01001011_{(2)}$ の下位6ビットを0にすると $01000000_{(2)}=64$ で 192.168.10.64　(3) 下位6ビットを1にすると $01111111_{(2)}=127$ で 192.168.10.127　(4) $2^6-2=$ 62個
「$2^6=64$ 個」と答えるミスが多い。ネットワークアドレスとブロードキャストアドレスの2つを引く。

同じネットワークかどうかは「IP アドレス AND サブネットマスク」が一致するかで判定する

2つの機器がルータを経由せずに通信できるか（同じネットワークに属するか）を問う。
それぞれの IP アドレスとサブネットマスクの AND をとり（ネットワーク部だけを取り出し）、比べる。一致すれば同じネットワーク（直接通信できる）、違えばルータ（デフォルトゲートウェイ）を経由する。
マスクが 255 の部分は IP アドレスの値のまま、0 の部分は 0 になる。それ以外（128, 192, 224 など）の部分だけ2進数で計算すればよい。
サブネットマスクが 255.255.255.128 のとき、172.16.5.100 は 172.16.5.130、172.16.5.20 とそれぞれ同じネットワークか。
解　第4オクテットだけ見る。マスク $128=10000000_{(2)}$ との AND：$100=01100100_{(2)}$ → 0、$130=10000010_{(2)}$ → 128、$20=00010100_{(2)}$ → 0。ネットワークアドレスは 172.16.5.0、172.16.5.128、172.16.5.0 なので、172.16.5.130 とは異なるネットワーク、172.16.5.20 とは同じネットワーク。

Web ページの表示は「DNS で名前を IP アドレスに → HTTP で要求 → 応答」の順

URL・ドメイン名の構造、DNS の役割、Web ページが表示されるまでの流れを問う。

流れ：①ブラウザが DNS サーバに IP アドレスを問い合わせる → ②その IP アドレスの Web サーバに HTTP で要求（リクエスト）を送る → ③Web サーバが HTML などを返す（レスポンス）→ ④ブラウザが解釈して表示する。HTTPS では通信が暗号化される。

転送時間＝データ量［ビット］÷（通信速度×伝送効率）。バイトはビットに直してから割る

ファイルの転送にかかる時間、一定時間に送れるデータ量を問う。
通信速度の単位 bps（ビット毎秒）は、1秒間に送れるビット数。$1\ \mathrm{Mbps}=10^6\ \mathrm{bps}$、$1\ \mathrm{Gbps}=10^9\ \mathrm{bps}$。
データ量がバイトなら8倍してビットにする。伝送効率（実際に使える割合）が与えられたら、通信速度にかけて実効速度にする。
時間［秒］＝データ量［ビット］÷（通信速度［bps］×伝送効率）
(1) 600 MB の動画ファイルを、通信速度 100 Mbps、伝送効率80％の回線でダウンロードすると何秒かかるか（$1\ \mathrm{MB}=10^6\ \mathrm B$）。(2) 同じ回線で30秒間に送れるデータ量は何 MB か。
解　(1) $600\times8=4800$ Mbit、実効速度 $100\times0.8=80$ Mbps なので $4800\div80=$ 60秒　(2) $80\times30=2400$ Mbit、$2400\div8=$ 300 MB
B（バイト）と b（ビット）を見分ける。8倍を忘れると答えが $\frac18$ になる。

サイバー攻撃は「手口」と「対策」を組で覚える。人をだます攻撃は技術だけでは防げない

攻撃の名称、事例に対する有効な対策を問う。
フィッシング：実在の企業などを装ったメールや SMS で偽サイトに誘導し、ID・パスワードなどを入力させる → リンクを開かず、公式アプリや登録済みのブックマークから確認する。
標的型攻撃：特定の組織を狙い、業務を装ったメールでマルウェアを送り込む。
ソーシャルエンジニアリング：人の心理のすきを突いて情報を盗む（肩越しにのぞき見る、管理者を名のって電話で聞き出す、捨てた書類をあさる）。
DoS 攻撃：大量のアクセスを送りつけてサービスを止める（多数の機器から行うのが DDoS 攻撃）。
パスワードを狙う攻撃：総当たり攻撃、辞書攻撃、パスワードリスト攻撃（ほかのサイトから流出した ID とパスワードの組を使う → 使い回しをしない）。
技術的な対策：ファイアウォール（外部との通信を制限）、ソフトウェアの更新、多要素認証。
次の攻撃の名称と、有効な対策を答えよ。(1)銀行を名のる SMS のリンクから本物そっくりのページに誘導され、パスワードを入力させられた。(2)別のサイトから流出した ID とパスワードの組を使って、ログインを試みられた。(3)システム管理者を名のる電話で、パスワードを聞き出された。
解　(1) フィッシング：SMS やメールのリンクを開かず、公式アプリやブックマークからアクセスする。(2) パスワードリスト攻撃：パスワードをサイトごとに変える、多要素認証を使う。(3) ソーシャルエンジニアリング：電話やメールでパスワードを教えない（正規の管理者がパスワードを尋ねることはない）。

共通鍵暗号は「同じ鍵で暗号化と復号」、公開鍵暗号は「受信者の公開鍵で暗号化し、受信者の秘密鍵で復号」

2つの暗号方式の違い、必要な鍵の数、どの鍵を使うかを問う。
共通鍵暗号：暗号化と復号に同じ鍵を使う。処理は速いが、鍵を相手に安全に渡すのが難しい（鍵配送の問題）。$n$ 人が互いに通信するには $\frac{n(n-1)}{2}$ 個の鍵が必要。
公開鍵暗号：公開鍵と秘密鍵のペアを使う。送信者は受信者の公開鍵で暗号化し、受信者の秘密鍵を持つ受信者だけが復号できる。公開鍵は公開してよいので鍵配送の問題が解決するが、処理は遅い。$n$ 人なら鍵は $2n$ 個。
HTTPS（SSL/TLS）などでは、共通鍵を公開鍵暗号で安全に送り、データ本体は速い共通鍵暗号で暗号化する（ハイブリッド方式）。

解　(1) 共通鍵暗号 $\frac{10\times9}{2}=$ 45個、公開鍵暗号 $2\times10=$ 20個　(2) 暗号化は B さんの公開鍵、復号は B さんの秘密鍵

データが名義・順序・間隔・比例尺度のどれか、使える代表値や計算を問う。
質的データ
名義尺度：区別のためだけの値（血液型、郵便番号、出席番号）。
順序尺度：順序に意味があるが、差は一定でない（順位、5段階評価、「満足〜不満」の回答）。

代表値は外れ値の影響で選ぶ：極端な値があれば平均値より中央値

平均値・中央値・最頻値を求め、データを代表する値としてどれが適切かを問う。
平均値：合計÷個数。極端な値（外れ値）に引っぱられやすい。
中央値（メジアン）：小さい順に並べて真ん中の値。個数が偶数なら真ん中の2つの平均。外れ値の影響を受けにくい。
最頻値（モード）：最も多く現れる値。度数分布表では度数が最大の階級の階級値。
分布が左右対称なら3つはほぼ一致し、右にすそが長い分布（所得など）では「平均値 ＞ 中央値」になりやすい。
7人の1か月の小遣い（千円）が 3, 4, 4, 5, 6, 7, 41 である。平均値・中央値・最頻値を求め、このデータの代表値として適切なものを答えよ。
解　平均値 $70\div7=$ 10、中央値（4番目）5、最頻値 4（単位は千円）。41 という外れ値に平均値が引っぱられ、7人中6人が平均より少ない。代表値には中央値が適切。

分散は「偏差の2乗の平均」、標準偏差はその正の平方根。全体を $a$ 倍すると標準偏差も $|a|$ 倍

分散・標準偏差の計算、データを変換したときの変化を問う。
①平均値 $\bar x$ を求める → ②各値の偏差 $x-\bar x$ → ③偏差の2乗の平均が分散 $s^2$ → ④$s=\sqrt{s^2}$ が標準偏差（もとのデータと同じ単位）。
分散 $=$（2乗の平均）$-$（平均の2乗）でも求められる。
すべての値に $b$ を足すと、平均は $b$ 増え、分散・標準偏差は変わらない。すべての値を $a$ 倍すると、平均は $a$ 倍、標準偏差は $|a|$ 倍、分散は $a^2$ 倍。
データ 4, 6, 7, 9, 14 の分散と標準偏差を求めよ。また、各値を2倍して3を足したデータの平均値と標準偏差を求めよ。
解　平均 $40\div5=8$。偏差は $-4,-2,-1,1,6$、2乗の和は $16+4+1+1+36=58$。分散 $58\div5=$ 11.6、標準偏差 $\sqrt{11.6}\fallingdotseq$ 3.41。（検算：2乗の平均 $378\div5=75.6$、$75.6-8^2=11.6$）
変換後の平均は $2\times8+3=$ 19、標準偏差は $2\times3.41\fallingdotseq$ 6.81（3を足しても変わらない）。

四分位数は中央値で前半・後半に分けて求め、外れ値は四分位範囲の1.5倍を目安に判定する

四分位数・四分位範囲を求める、外れ値を判定する、箱ひげ図をかく。
小さい順に並べ、中央値（第2四分位数 $Q_2$）でデータを前半と後半に分ける（個数が奇数なら、中央値そのものはどちらにも入れない）。前半の中央値が第1四分位数 $Q_1$、後半の中央値が第3四分位数 $Q_3$。
四分位範囲 $\mathrm{IQR}=Q_3-Q_1$（真ん中の約半分のデータの散らばり）。
外れ値の基準の例：$Q_1-1.5\times\mathrm{IQR}$ より小さい値、または $Q_3+1.5\times\mathrm{IQR}$ より大きい値。
11個のデータ 2, 5, 7, 8, 10, 12, 13, 15, 18, 21, 40 の四分位数と四分位範囲を求め、上の基準で外れ値があるか調べよ。
解　中央値は6番目の 12。前半 2, 5, 7, 8, 10 の中央値 $Q_1=$ 7、後半 13, 15, 18, 21, 40 の中央値 $Q_3=$ 18。$\mathrm{IQR}=18-7=$ 11。$Q_3+1.5\times11=34.5$ より 40 は外れ値（下側の基準 $7-16.5=-9.5$ より小さい値はない）。

相関係数は「共分散÷（標準偏差の積）」で $-1\leqq r\leqq1$。相関があっても因果関係とは限らない

散布図から相関の強さ・向きを読む、相関係数を計算する、相関と因果を区別する。
共分散 $s_{xy}$ ＝（$x$ の偏差 × $y$ の偏差）の平均。相関係数 $r=\dfrac{s_{xy}}{s_xs_y}$。
$r$ が1に近いほど強い正の相関（右上がり）、$-1$ に近いほど強い負の相関（右下がり）、0に近いと直線的な相関がない。
外れ値が1つあるだけで $r$ は大きく変わる。また、2つの量の両方に影響する別の要因（第3の変数）があると、因果関係がなくても相関が出る（疑似相関）。例：アイスの売上と水難事故の件数は、どちらも気温が高いと増える。
5人の勉強時間 $x$（時間）と得点 $y$ が (1, 52), (2, 60), (3, 56), (4, 70), (5, 72) である。相関係数を求めよ（小数第2位まで）。
解　$\bar x=3$、$\bar y=62$。偏差は $x$：$-2,-1,0,1,2$、$y$：$-10,-2,-6,8,10$。
偏差の積の和 $20+2+0+8+20=50$、$x$ の偏差の2乗の和 $10$、$y$ の偏差の2乗の和 $304$。
$r=\dfrac{50}{\sqrt{10\times304}}=\dfrac{50}{\sqrt{3040}}\fallingdotseq$ 0.91（強い正の相関）
$r$ の分母・分子の「÷5（個数）」は約分で消えるので、和のまま計算してよい。

回帰直線は「傾き＝共分散÷ $x$ の分散」で、点 $(\bar x,\ \bar y)$ を通る

回帰直線の式を求める、回帰直線を使って値を予測する。
$y=ax+b$ の傾きは $a=\dfrac{s_{xy}}{s_x^2}=r\cdot\dfrac{s_y}{s_x}$。回帰直線は平均の点 $(\bar x,\ \bar y)$ を通るので $b=\bar y-a\bar x$。
表計算ソフトでは、散布図に近似直線（線形近似）を追加すると式が表示される。
予測は、データの範囲内なら比較的信頼できるが、範囲の外（外挿）では当てはまる保証がない。
前のカードのデータで、$y$ の $x$ への回帰直線を求め、勉強時間6時間のときの得点を予測せよ。
解　共分散 $50\div5=10$、$x$ の分散 $10\div5=2$ より $a=10\div2=5$。$b=62-5\times3=47$。回帰直線は $y=5x+47$。
$x=6$ のとき $y=5\times6+47=$ 77点（右図の白丸。データの範囲外なので参考程度）。

仮説検定は「偶然だとしたら、これほど極端な結果が出る確率は？」を計算し、5％と比べる

仮説検定の考え方、確率の計算やシミュレーション結果からの判断を問う。
①確かめたいことの反対の仮説（帰無仮説：「差はない」「偶然である」）を立てる。
②帰無仮説が正しいとしたときに、実際の結果以上に極端な結果が起こる確率を、計算や乱数のシミュレーションで求める。
③その確率が有意水準（5％など）より小さければ、帰無仮説を棄却して「偶然とは考えにくい」と判断する。小さくなければ「差があるとはいえない」とする（差がないと証明されたわけではない）。
あるコインを10回投げたら、表が9回出た。「このコインは表が出やすい」と言えるか、有意水準5％で判断せよ。また、表が8回だった場合はどうか。
解　帰無仮説「表と裏は等しく $\frac12$ で出る」。表が9回以上出る確率は $({}_{10}\mathrm C_9+{}_{10}\mathrm C_{10})\div2^{10}=11\div1024\fallingdotseq1.1\%$。5％より小さいので帰無仮説を棄却し、表が出やすいと判断できる。8回の場合、8回以上の確率は $(45+10+1)\div1024=56\div1024\fallingdotseq5.5\%$ で5％より大きいので、表が出やすいとはいえない。
「ちょうど9回」の確率ではなく、「9回以上（それ以上に極端な場合）」の確率で判断する。
