総合演習分野をまたぐ 20 題 ── 現象・しくみ・計算をつなげる

中学範囲（A）と高校範囲（B）に分けています。計算問題は途中式も書いて確認しましょう。

A　中学理科（高校入試レベル）

A1【生物】オオカナダモを入れた試験管 A と、何も入れない試験管 B に、息をふきこんで緑色にした BTB 液を入れ、光を当てた。A の色が青色になった理由を説明せよ。また B を用意した理由は？
A ではオオカナダモが光合成で二酸化炭素を吸収したため、液が酸性から中性→アルカリ性側に変わって青色になった。B は、色の変化がオオカナダモのはたらきによることを確かめるための対照実験。
A2【化学】炭酸水素ナトリウム 2.1g を加熱したら、固体の質量は 1.33g になった。発生した気体と水の質量の合計は何 g か。また、残った固体の水溶液にフェノールフタレイン液を加えると何色になるか。
$2.1-1.33=$ 0.77g（二酸化炭素と水）。残った固体は炭酸ナトリウムで、水溶液は強いアルカリ性なので赤色（濃い赤）。
A3【物理】6V の電源に 2Ω と 4Ω の電熱線を直列につないだ。回路に流れる電流と、4Ω の電熱線が 5 分間に発生する熱量を求めよ。
電流 $6\div(2+4)=$ 1A。4Ω の電圧 4V、電力 4W。熱量 $4\times300=$ 1200J
A4【地学】ある地震で、震源から 48km の地点 A では初期微動が 8 秒続き、地点 B では 14 秒続いた。B の震源からの距離を求めよ。また P 波の速さが 6km/s のとき、S 波の速さは？
初期微動継続時間は震源距離に比例。P 波と S 波の到着時刻の差＝距離/S波 − 距離/P波。
B：$48\times\frac{14}{8}=$ 84km。S 波の速さを $v$ とすると $\frac{48}{v}-\frac{48}{6}=8$ → $\frac{48}{v}=16$ → $v=$ 3km/s
A5【物理】質量 300g の物体を、斜面にそって 2.0m 引き上げたら、高さが 0.50m 上がった。斜面にそって引く力の大きさは何 N か（摩擦なし、100g＝1N）。
仕事の原理：$3\times0.50=F\times2.0$ → $F=$ 0.75N
A6【化学】うすい塩酸 20cm³ にマグネシウムリボン 0.12g を入れると、すべて溶けて水素が 120cm³ 発生した。同じ塩酸 20cm³ にマグネシウム 0.30g を入れると、水素が 240cm³ 発生してマグネシウムが残った。マグネシウムはあと何 g 溶けずに残っているか。
0.12g で 120cm³ → 240cm³ は 0.24g 分。塩酸が不足して反応が止まった。残りは $0.30-0.24=$ 0.06g
A7【天体】ある日の午後9時に、オリオン座が南中していた。1か月後にオリオン座が南中するのは何時ごろか。
1か月で 30° 西へずれる＝2時間早く同じ位置に来る。午後7時ごろ
A8【生物】エンドウの丸い種子（AA）としわの種子（aa）から得た子（Aa）に、しわの種子（aa）をかけ合わせた。できる種子の丸としわの比は？
Aa × aa → Aa：aa＝1：1。丸：しわ＝1：1（この方法を検定交雑という）

B　高校理科

B1【物理】地面から 19.6m/s で真上に投げ上げた小球の、最高点の高さと、地面に戻るまでの時間を求めよ（$g=9.8$）。
最高点：$0^2-19.6^2=-2\times9.8\times h$ → $h=$ 19.6m。上昇時間 $19.6\div9.8=2.0$ 秒、往復 4.0 秒
B2【物理】なめらかな水平面上で、質量 1.0kg・速度 +4.0m/s の球 A と、質量 3.0kg で静止している球 B が弾性衝突した。衝突後のそれぞれの速度は？
運動量保存と反発係数 $e=1$ の2式を連立。
$1.0\times4.0=1.0v_A+3.0v_B$、$v_B-v_A=4.0$。解いて $v_B=$ 2.0m/s、$v_A=$ −2.0m/s（A ははね返る）
B3【物理】27℃・$1.0\times10^5$Pa・体積 3.0L の気体を、127℃・体積 2.0L にした。圧力は？
$\frac{PV}{T}$ 一定：$\frac{1.0\times10^5\times3.0}{300}=\frac{P\times2.0}{400}$ → $P=$ $2.0\times10^5$Pa
B4【化学】プロパン $\mathrm{C_3H_8}$ 11g を完全燃焼させた。$\mathrm{C_3H_8 + 5O_2 \to 3CO_2 + 4H_2O}$。生じる $\mathrm{CO_2}$ の標準状態での体積と、水の質量を求めよ。
$\mathrm{C_3H_8}$＝44 → 0.25mol。$\mathrm{CO_2}$ 0.75mol → $22.4\times0.75=$ 16.8L。水 1.0mol → 18g
B5【化学】0.10mol/L 酢酸（電離度 0.010）の pH と、この酢酸 20mL を中和するのに必要な 0.10mol/L 水酸化ナトリウム水溶液の体積を求めよ。
$[\mathrm{H^+}]=0.10\times0.010=1.0\times10^{-3}$ → pH 3。中和は電離度に関係なく酸の全量で決まる：20mL
B6【化学】次の反応で、酸化された物質と還元された物質を答えよ。$\mathrm{Cu + 2Ag^+ \to Cu^{2+} + 2Ag}$
Cu は 0 → +2 で酸化された。$\mathrm{Ag^+}$ は +1 → 0 で還元された（Cu は還元剤、$\mathrm{Ag^+}$ は酸化剤）。
B7【化学】$\mathrm{H_2(気) + \frac12O_2(気) \to H_2O(液)}$ $\Delta H=-286$kJ、$\mathrm{H_2O(液) \to H_2O(気)}$ $\Delta H=+44$kJ のとき、$\mathrm{H_2 + \frac12O_2 \to H_2O(気)}$ の $\Delta H$ は？
へスの法則：$-286+44=$ −242kJ
B8【生物】ある DNA の 2 本鎖全体で、G が 22％をしめる。A・T・C の割合を求めよ。
C＝G＝22％、A＋T＝56％ → A＝T＝28％
B9【生物】ワクチンを接種すると病気にかかりにくくなるしくみを、「記憶細胞」「二次応答」の語を使って説明せよ。
ワクチン（無毒化した抗原など）で獲得免疫がはたらき、抗原の情報をもつ記憶細胞がつくられて残る。本物の病原体が侵入すると、記憶細胞がすばやく増えて大量の抗体などがつくられる二次応答が起こり、発症をおさえる。
B10【地学】風上側で 0m・25℃ の空気が山を上昇し、800m で雲ができはじめ、2000m の山頂をこえて風下へ雲のないまま下降した。風下 0m の気温を求めよ（乾燥 1.0℃/100m、湿潤 0.5℃/100m）。
0→800m：$25-8=17$℃。800→2000m：$17-6=11$℃。下降 2000m：$11+20=$ 31℃（フェーン現象）
B11【地学】半減期 5730 年の $\mathrm{^{14}C}$ が、生きている生物の $\frac18$ に減っていた木材の年代は？
$\left(\frac12\right)^3$ → $5730\times3=$ 17190年前（約1万7千年前）
B12【総合】地球温暖化について、「温室効果」「炭素の循環」の語を使い、原因と対策を説明せよ。
（例）化石燃料の大量消費や森林の減少で、炭素の循環のバランスがくずれ、大気中の二酸化炭素が増えた。二酸化炭素などの温室効果ガスは地表からの赤外線を吸収して地表をあたためる温室効果をもつため、平均気温が上がっている。対策として、再生可能エネルギーの利用や省エネルギー、森林の保全で二酸化炭素の排出を減らし吸収を増やすことが考えられる。
