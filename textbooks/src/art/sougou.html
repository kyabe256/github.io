総合演習5教科をまたぐ 20 題 ── 手順と理由を説明する力をつける

中学範囲（A）と高校範囲（B）に分けています。計算は途中式を書き、記述は「理由 → 結論」の順で書きましょう。

A　中学（実技4教科）

A1【保健】倒れている人を見つけた。周囲の安全を確認した後、心肺蘇生を行うまでの手順を順に3つ答えよ。
①肩をたたきながら大声で呼びかけ、反応を確認する。②反応がなければ大声で助けを呼び、119番通報とAEDの手配を頼む。③胸と腹の動きを見て10秒以内に呼吸を確認し、普段どおりの呼吸がなければ（判断に迷っても）すぐに胸骨圧迫を始める。
A2【保健】次の(1)〜(3)は、感染症の予防の3つの対策のどれにあたるか。(1) 調理器具の熱湯消毒　(2) マスクの着用　(3) 十分な睡眠と栄養
(1) 感染源をなくす　(2) 感染経路を断つ　(3) 体の抵抗力を高める
A3【体育】持久走の記録を伸ばしたい。トレーニングの原則のうち「過負荷」「漸進性」「個別性」を使って、練習計画の立て方を説明せよ。
今の自分の体力に合わせて（個別性）、ふだんより少し長い距離や速いペースで走り（過負荷）、体が慣れてきたら少しずつ距離やペースを上げていく（漸進性）。休養日も設けて疲労をためない。
A4【技術・計算】100Vのコンセントで、1000Wの電子レンジと600Wのトースターと200Wの炊飯器を、定格15Aのテーブルタップで同時に使った。合計の電流を求め、安全かどうか判断せよ。
電流は $1000\div100=10$A、$600\div100=6$A、$200\div100=2$A で、合計 18A。定格15Aをこえるので危険（過熱・発火のおそれ）。同時に使わないか、別のコンセントに分ける。
A5【技術・計算】モーターに取り付けた歯数12の歯車が毎分1200回転し、歯数48の歯車とかみ合っている。従動歯車の回転速度と、回転の速さ・力の大きさの変化を答えよ。
$12\times1200=48\times n$ → $n=$ 毎分300回転（速度伝達比4）。回転は$\frac14$に遅くなるが、回す力（トルク）は大きくなる。
A6【家庭・計算】ある日の昼食で、たんぱく質25g、脂質20g、炭水化物90gをとった。エネルギーはおよそ何kcalか（1gあたり たんぱく質4・脂質9・炭水化物4kcal）。
$25\times4+20\times9+90\times4=100+180+360=$ 640kcal
A7【家庭】電話で勧誘されて英会話教材の契約をした。6日後、解約したくなった。どうすればよいか。また、ネット通販で買った教材の場合はどうか。
電話勧誘販売なので、契約書面を受け取ってから8日以内ならクーリング・オフできる。書面または電磁的記録で通知し、記録を残す。ネット通販はクーリング・オフの対象外で、販売者の返品特約に従う（特約の表示がなければ受け取りから8日以内は返品可）。
A8【音楽・計算】4分の3拍子の曲の1小節に、8分音符2つと付点4分音符1つが入っている。この小節はあと何拍分必要か。また、それを満たす休符を1つ答えよ。
8分音符2つで1拍、付点4分音符で$1\frac12$拍、合計$2\frac12$拍。あと $\frac12$拍 → 8分休符1つ。
A9【音楽】ベートーヴェンの交響曲第5番の第1楽章について、(1) 用いられている形式、(2) 冒頭の短いまとまりが曲全体で果たしている役割を答えよ。
(1) ソナタ形式（提示部・展開部・再現部・コーダ）　(2) 冒頭の「タタタ・ターン」という動機が、楽器や音の高さを変えながらくり返し現れ、曲全体に統一感と緊張感を与えている。
A10【美術】夕焼けの空を背景に、手前の建物を目立たせたい。色の性質を使って配色の工夫を2つ答えよ。
（例）①空が暖色（橙・赤）なら、建物には補色に近い寒色（青紫・青）を使い、互いを引き立てる。②建物を空より暗い明度にしてシルエットのように見せ、明度差で形をはっきりさせる。（遠くの景色を青っぽく淡くする空気遠近法で奥行きを出すのもよい）

B　高校（保健・家庭基礎・情報I）

B1【保健】「健康寿命を延ばす」ための取り組みを、ヘルスプロモーションの考え方にもとづいて、個人と社会の両面から1つずつ挙げよ。
個人：適度な運動・バランスのよい食事・禁煙などの生活習慣、定期的な健康診断やがん検診の受診。社会：運動できる公園や歩道の整備、受動喫煙防止のルール、地域の健康教室や介護予防事業、検診を受けやすい制度づくり。
B2【家庭・計算】200,000円を年利5％で2年間預けた。単利と複利（1年ごと）の元利合計の差は何円か。
単利：利息は毎年 $200000\times0.05=10{,}000$円 → $200000+10000\times2=$ 220,000円。複利：$200000\times1.05^2=200000\times1.1025=$ 220,500円。差は 500円（1年目の利息10,000円にも2年目に5％の利息がつくため）。
B3【家庭】実収入が月38万円で、所得税・住民税が3万円、社会保険料が5万円の世帯の可処分所得を求めよ。また、この世帯の消費支出が26万円のとき、黒字（貯蓄などに回せる額）はいくらか。
可処分所得 $38-(3+5)=$ 30万円。黒字 $30-26=$ 4万円。
B4【情報・計算】(1) 10進数の 77 を2進数と16進数で表せ。(2) 2進数の 1100 と 0111 の和を2進数で答えよ。
(1) $77=64+8+4+1$ → 1001101。8桁にして 0100｜1101 → 4D。　(2) $12+7=19$ → 10011
B5【情報・計算】横1200×縦800画素、1画素24ビットの画像（圧縮なし）のデータ量は何MBか（1MB＝1,000,000B）。また、この画像50枚を通信速度80Mbpsで送るのに何秒かかるか。
$1200\times800\times24\div8=2{,}880{,}000$B＝2.88MB。50枚で144MB＝$144\times8=1152$メガビット。$1152\div80=$ 14.4秒。
B6【情報】公開鍵暗号方式で、AさんがBさんに秘密のメッセージを送る。(1) Aさんは誰のどの鍵で暗号化するか。(2) 復号できるのは誰か。(3) Bさんが「確かにAさんから届いた」ことを確かめるには、Aさんは何をすればよいか。
(1) Bさんの公開鍵で暗号化する。(2) 対になる秘密鍵を持つBさんだけ。(3) Aさんが自分の秘密鍵でデジタル署名をつけ、BさんはAさんの公開鍵で署名を検証する。
B7【情報・プログラム】次のプログラムを実行したときに表示される値を答えよ。 
Data = [4, 9, 2, 7, 5]
合計 = 0
個数 = 0
i を 0 から 4 まで 1 ずつ増やしながら繰り返す:
│ もし Data[i] >= 5 ならば:
│ │ 合計 = 合計 + Data[i]
│ └ 個数 = 個数 + 1
表示する(合計, 個数)
5以上の要素は 9, 7, 5 → 合計 21、個数 3。（「5以上の値の合計と個数」を求めるプログラム）
B8【情報・アルゴリズム】整列済みの 2000 個のデータから、二分探索で目的の値を探す。比較の回数は最大何回か。また、線形探索では最大何回か。
二分探索：$2^{10}=1024\lt2000\leqq2048=2^{11}$ なので最大 11回。線形探索：最大 2000回。
B9【情報・データ】データ 4, 6, 6, 8, 11 について、平均値・中央値・分散を求めよ。また、11 を 31 に変えたとき、平均値と中央値はどうなるか。
平均値 $35\div5=$ 7、中央値 6。偏差 $-3,-1,-1,1,4$ → 2乗の和 28 → 分散 $28\div5=$ 5.6。11→31にすると平均値は $55\div5=$ 11 に大きく上がるが、中央値は 6のまま（中央値は外れ値の影響を受けにくい）。
B10【情報・データ】「睡眠時間が長い生徒ほど朝食をよく食べる」という正の相関が見つかった。ここから「朝食を食べれば睡眠時間が長くなる」と言えるか。説明せよ。
言えない。相関関係は因果関係を意味しない。早寝早起きの生活習慣や家庭の生活リズムなど、両方に影響する第三の要因がある可能性がある。因果関係を調べるには、条件をそろえた比較や実験が必要。
