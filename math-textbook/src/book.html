第1部 中学数学計算の道具をそろえ、関数と図形の基礎をつくる

中学数学は「高校数学の道具箱」です。特に 文字式・方程式・因数分解・一次関数・三平方の定理 は高校で毎日使います。ここが速く正確になるだけで高校数学はぐっと楽になります。

1正負の数 中1

・マイナスは「逆向き」のこと。数直線で 0 より左。
・ひき算は「逆向きのたし算」：$a-b = a+(-b)$
・かけ算・わり算の符号：マイナスが偶数個なら＋、奇数個なら−
・計算の順番：( ) → 累乗 → ×÷ → ＋−
数直線を歩く人を想像しよう。「$+3$」は右へ3歩、「$-3$」は左へ3歩。
「$-$ をかける」は「回れ右」。回れ右を2回すると元の向き。だから $(-)\times(-)=(+)$。

絶対値

0 からの距離のこと。$|-5|=5$、$|3|=3$。向きを無視した「大きさ」です。

累乗の注意

$(-3)^2 = (-3)\times(-3) = 9$ だが、$-3^2 = -(3\times 3) = -9$。かっこの有無で答えが変わる。

$-2 + 5 \times (-3) - (-4)^2 \div 8$ を計算せよ。
解　累乗：$(-4)^2=16$。×÷：$5\times(-3)=-15$, $16\div 8=2$。
よって $-2-15-2 = \boldsymbol{-19}$
(1) $-7+(-3)-(-12)$　(2) $(-2)^3\times 3$　(3) $-2^4 + (-6)\div(-2)$
(1) $2$　(2) $-24$　(3) $-16+3=-13$

2文字式 中1・中2

・文字は「まだ決まっていない数の入れ物」。
・ルール：×は省略（$3\times a = 3a$）、数字を前に、÷は分数に（$a\div 2=\frac{a}{2}$）。
・同類項（文字の部分が同じ項）だけまとめられる：$3x+5x=8x$、でも $3x+5y$ はそのまま。
・分配法則：$a(b+c)=ab+ac$
$x$ を「りんご」、$y$ を「みかん」と思おう。りんご3個＋りんご5個＝りんご8個。でもりんご3個＋みかん5個は、まとめて「8個の何か」にはできません。
$3(2x-y) - 2(x-4y)$ を簡単にせよ。
解　$=6x-3y-2x+8y = \boldsymbol{4x+5y}$　（$-2$ をかけるとき、後ろの項の符号も変わるのに注意）

式の値・等式の変形

「$x=-2$ のとき $x^2-3x$ の値」→ そのまま代入：$(-2)^2-3(-2)=4+6=10$。負の数は必ずかっこ付きで代入。

等式の変形（例：$2x+3y=6$ を $y$ について解く）：$3y = 6-2x$ → $y = \dfrac{6-2x}{3}$。方程式と同じ操作です。

(1) $5a-3b-2a+7b$　(2) $\dfrac{x+1}{2}-\dfrac{x-2}{3}$　(3) $V=\frac{1}{3}Sh$ を $h$ について解け
(1) $3a+4b$　(2) $\dfrac{3(x+1)-2(x-2)}{6}=\dfrac{x+7}{6}$　(3) $h=\dfrac{3V}{S}$

3一次方程式 中1

・方程式＝「天秤がつり合っている」状態。両辺に同じことをすればつり合いは崩れない。
・移項：項を反対側へ移すと符号が変わる。
・手順：①かっこ・分数をなくす → ②$x$ を左、数を右へ移項 → ③まとめる → ④$x$ の係数でわる
天秤の左に「箱 $x$ ×2 と おもり3」、右に「おもり11」。両側から3を取り除くと「箱2個 = 11−3 = 8」。箱1個は4。これが $2x+3=11 \Rightarrow x=4$ です。
$\dfrac{x-1}{3} = \dfrac{x}{2} - 1$ を解け。
解　両辺に 6 をかける：$2(x-1) = 3x - 6$ → $2x-2=3x-6$ → $-x=-4$ → $\boldsymbol{x=4}$

文章題のコツ

  1. 求めたいものを $x$ とおく
  2. 「等しいもの」を2通りに表して $=$ で結ぶ
  3. 解いたら問題に合うか確かめる（人数が負になっていないか等）
1個120円のパンと1個80円のおにぎりを合わせて10個買い、1000円だった。パンは何個？
解　パン $x$ 個、おにぎり $(10-x)$ 個。$120x+80(10-x)=1000$ → $40x=200$ → $\boldsymbol{x=5}$ 個
(1) $5x-7=2x+8$　(2) $0.3x+1.2=0.5x$　(3) 比例式 $x:6=4:3$
(1) $x=5$　(2) 10倍して $3x+12=5x$ → $x=6$　(3) 外項の積=内項の積：$3x=24$ → $x=8$

4連立方程式 中2

・文字が2つなら式も2本必要。1つの文字を消して一次方程式にする。
・加減法：式をたしたりひいたりして消す。代入法：$y=\cdots$ の形を他方に代入。
「りんご2個とみかん1個で 300円」「りんご1個とみかん1個で 200円」。2つを比べると差は「りんご1個＝100円」。このように比べて片方を消すのが加減法。
$\begin{cases} 2x+3y=12 \\ 3x-y=7 \end{cases}$
解　下の式を3倍：$9x-3y=21$。上の式とたす：$11x=33$ → $x=3$。代入：$9-y=7$ → $y=2$。
答え $\boldsymbol{(x,y)=(3,2)}$
(1) $\begin{cases}x+y=10\\x-y=4\end{cases}$　(2) $\begin{cases}y=2x-1\\3x+2y=12\end{cases}$
(1) $(7,3)$　(2) $3x+2(2x-1)=12$ → $7x=14$ → $(x,y)=(2,3)$

5比例・反比例・一次関数 中1・中2

・関数：$x$ を決めると $y$ がただ1つ決まる関係（自販機：ボタンを押すと商品が1つ出る）。
・比例 $y=ax$（原点を通る直線）／反比例 $y=\dfrac{a}{x}$（双曲線, $xy=a$ 一定）
・一次関数 $y=ax+b$：$a$＝傾き（$x$ が1増えたときの $y$ の増え方）、$b$＝切片（$y$軸との交点）
・傾き $a = \dfrac{y\text{の増加量}}{x\text{の増加量}}$（変化の割合）
一次関数は「基本料金 + 従量料金」。スマホ代が「基本 $b$ 円 + 1GB ごと $a$ 円」なら $y=ax+b$。
グラフは $y$ 軸の $b$ からスタートして、右に1進むごとに $a$ 上がる直線。

6平面図形・空間図形 中1

・円：周 $=2\pi r$、面積 $=\pi r^2$
・おうぎ形（中心角 $a^\circ$）：弧 $=2\pi r\times\dfrac{a}{360}$、面積 $=\pi r^2\times\dfrac{a}{360}$ $\left(=\dfrac12 \ell r\right)$

球の公式の覚え方：体積「身の上に心配ある参上」 $\frac{4}{3}\pi r^3$、表面積「心配ある事情」 $4\pi r^2$。

9展開と因数分解 中3

乗法公式（左→右が展開、右→左が因数分解）
① $(x+a)(x+b)=x^2+(a+b)x+ab$
② $(x+a)^2=x^2+2ax+a^2$　　③ $(x-a)^2=x^2-2ax+a^2$
④ $(x+a)(x-a)=x^2-a^2$
展開は「長方形の面積を分割して数える」こと。縦 $x+b$、横 $x+a$ の長方形は4つのブロックに分かれ、合計 $x^2+ax+bx+ab$。
因数分解はその逆で「バラバラのブロックを長方形に組み立て直す」作業です。

因数分解の手順

  1. 共通因数をくくり出す：$3x^2-6x=3x(x-2)$
  2. 公式に当てはめる。①は「かけて $ab$、たして $a+b$」になる2数を探す
$x^2-x-12$ を因数分解。
解　かけて $-12$、たして $-1$ → $3$ と $-4$。答え $\boldsymbol{(x+3)(x-4)}$
$(a+b)^2=a^2+b^2$ はまちがい！ 真ん中の $2ab$ を忘れない。図の2つのオレンジの長方形の分です。
(1) $(2x-3)^2$ を展開　(2) $x^2+7x+10$　(3) $4x^2-9$　(4) $2x^2-8x+8$
(1) $4x^2-12x+9$　(2) $(x+2)(x+5)$　(3) $(2x+3)(2x-3)$　(4) $2(x-2)^2$

10二次方程式 中3

・まず因数分解を試す：$AB=0$ なら $A=0$ または $B=0$
・ダメなら解の公式：$ax^2+bx+c=0$ の解は　$x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$

「かけて0」になるのは、どちらかが0のときだけ。だから $(x-2)(x+5)=0$ なら $x=2$ か $x=-5$。
解の公式は「どんな二次方程式でも開けられるマスターキー」。時間はかかるけど必ず開く。

この「$(x+\square)^2$ を作る」操作を一般の $ax^2+bx+c$ でやると解の公式になります。平方完成は高校の二次関数でも主役です。
