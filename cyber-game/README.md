# 総監・翼　FILE 001　止まった病院

「日米統合サイバー捜査総監・翼」の世界（`cyber/`）の事件001を、推理アドベンチャーゲームにしたもの。

- 遊ぶ：`index.html` を開く（`voice.mp3` を同じフォルダに置く）。
- 中身：調べる／話す／移動／視点（翼・小野寺・千早）と、追及（証拠・推理・視点・観察）。3章と終章。
- 声：全台詞。`src/voices.py` が `src/story.txt` から作る。
- 作り直す：`src/` を編集して `python3 src/build.py`（出力先は `../dist`）。
