# 鍵のない部屋

「FBI＆警察庁」の世界を舞台にした、16:9の本格推理アドベンチャー。総監・翼の事件簿、全100事件。

物を調べ、事実をつなぎ、証言を崩し、最後に報告書を書く。10の章を通して、1つの部屋にたどり着く。

## 遊び方

`index.html` をブラウザで開く。`voice-011.mp3`、`c/`、`v/` を同じフォルダに置く。横長の画面向け。

- **事件を選ぶ**　題の画面から、事件簿を開く。10章、100事件。どの事件からでも始められる。
- **現場検証**　気になる所を直接押す。印は出ない。
- **証拠**　ホイールか＋で拡大。つかんで動かす。裏返す。細かい字や数字を押すと「事実カード」になる。
- **推理ボード**　カードを2枚押すと糸が張られる。筋が通ると「仮説」が生まれる。時系列と相関図は自動で増える。
- **尋問**　証言の中の言葉を選び、証拠か事実か仮説を突きつける。まちがえると信頼が減る。0になると出直し。
- **推理レポート**　欄を埋め、根拠を添える。SからCの評価が出る。最初の欄をまちがえると、差し戻しになる。
- **最終話**　報告書に、正しい答えのない欄が2つある。選んだとおりの結末になる。
- **ヒント**　初期設定は切。設定で入にできる。使うたびに評価が下がる。
- **動き**　設定で「自動」「なめらか」「軽い」を選べる。音が途切れる時や重い時は「軽い」にする。タッチ端末は最初から軽い表示になる。

## 保存

進み具合は、事件ごとに自動で保存される。

- claude.ai のアーティファクトとして開いた時は、アカウントに保存する。別の端末でも続きから遊べる。
- ファイルとして開いた時は、ブラウザに保存する。
- 設定の「いま保存する」で、その場で保存できる。
- 設定の「合言葉」で、記録を文字にして持ち出し、別の端末で戻せる。

## 事件の文の書き方

`src/cases/NNN.txt` は、頭に設定、あとに台本を書く。

```
# NNN 題
@when 日付   @where 場所   @lead 一行
@who id 名前 役 m45        人物（この事件だけの人）
@loc id 名前 bg=背景       場所。flag=us|jp|both|none で旗を決められる
@p 人 話題 -> 台本の名前   話せる相手
@h 背景の中の物 -> 台本の名前
@ev id 名前 | 字 | 説明    証拠。次の行から %table %form %memo %text %chat %graph %cctv
*事実のid 行               押すと事実カードになる行
@fact id 題 | 説明 | 分類
@hyp id 題 | 説明 | a+b | ヒント | 翼の台詞
@intr 相手 at=場所 title=…
@st id 句/句               証言。p（ゆさぶる）a（正解）n（惜しい）o（突きつけたあと）h（ヒント）
@rep 質問 | 副題 | 選択 | *正解 | 選択 ^ 根拠     *のない欄は、正しい答えのない欄
## op / 各台本 / ## end / ## fin / ## bad
```

`python3 src/build.py` で組み立てる。`node src/check3.js` で調べる。
