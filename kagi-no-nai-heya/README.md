# 鍵のない部屋

「FBI＆警察庁」の世界を舞台にした、16:9の本格推理アドベンチャー。総監・翼の事件簿 FILE 011。

亡命した記者が、鍵のかかった部屋で死んだ。FBIも、警備局も、捜査一課も「うちの事件だ」と言う。
物を調べ、事実をつなぎ、3人の証言を崩し、最後に報告書を書く。

## 遊び方

`index.html` をブラウザで開く。`voice-011.mp3` を同じフォルダに置く。横長の画面向け。

- **現場検証**　気になる所を直接押す。印は出ない。台所のように、近づいてから調べる場所もある。
- **証拠**　ホイールか＋で拡大。つかんで動かす。裏返す。細かい字や数字を押すと「事実カード」になる。
- **推理ボード**　カードを2枚押すと糸が張られる。筋が通ると「仮説」が生まれる。時系列と相関図は自動で増える。
- **尋問**　証言の中の言葉を選び、証拠か事実か仮説を突きつける。まちがえると信頼が減る。0になると出直し。
- **推理レポート**　実行犯、内通者、指示役、手口、動機を選び、根拠を添える。結論で結末が分かれ、SからCの評価が出る。
- **ヒント**　初期設定は切。設定で入にできる。使うたびに評価が下がる。
- **動き**　設定で「自動」「なめらか」「軽い」を選べる。音が途切れる時や重い時は「軽い」にする。タッチ端末は最初から軽い表示になる。

進み具合は、ブラウザに自動で保存される。
