# 三十三年目の雨

1960年、1993年、2026年。33年ごとに9日だけ開く穴と、4つの家をめぐる、本格SF推理アドベンチャー。

雨の森の洞窟の前で、宿の主人が死んでいた。着ている作業着のタグは昭和35年。ポケットには、平成5年の整理券と、60年前の百円札。刑事の三雲朔は、車で町を回り、遺体を検分し、穴を通って過去へ行く。そこで会うのは、まだ生まれていないはずの人と、33年前に消えた弟だ。

人物、町、物語は、全てこのゲームのために作った物。実在の人物、団体、土地とは関係がない。

## 大きさ

- 時代は3つ。場所は10。森、洞窟、町、警察、医院、宿、発電所、屋敷、排水坑、墓地。
- 検分は3回。遺体、33年前に掘り出された白骨、66年前に拾われた子どもの持ち物。
- 事実は101個。台詞は552行で、全部に声がある。
- 推理ボードでつなぐ人物は10組。「この時代のこの人は、別の時代のあの人だ」を、裏づけ2つで確かめる。
- 論破は9回、30問。全部、自分の言葉で書く。
- 結末は3つ。

## 遊び方

`index.html` をブラウザで開く。`v/` を同じフォルダに置く。横長の画面向け。

1本の指で、全部できる。急ぐ場面は1つもない。時間で負ける事もない。

- **車**　「進む」を1度押すと走り、もう1度押すと止まる。分かれ道では車が止まって待つ。「左折」「直進」「右折」「引き返す」を選ぶと、ハンドルが回って、その道へ曲がる。「地図で、行き先を選ぶ」を使えば、おまかせで着く。道から出る事も、ぶつかる事もない。
- **ハンドルの補助**　初期設定は入。設定で切にすると、カーブで車が外へふくらむ。「左へ切る」「右へ切る」で戻す。はみ出しても、ゆっくりになるだけ。
- **歩く**　矢印を1度押すと歩き、もう1度押すと止まる。行きたい所や、人や物を、じかに押してもいい。近くに何かあると、まん中に大きなボタンが出る。
- **検分**　気になる所をじかに押す。拡大図が出て、分かった事が「事実」になる。動かすには1本指で引く。大きさは「＋」「−」で変える。
- **手帳**　手に入れた証拠を開いて、行を押すと、事実として書きとめる。メモも書ける。
- **推理ボード**　4つの家を、3つの時代に並べた図。2人を順に押して、「同じ人物か」を確かめる。裏づけの事実を2つ選ぶ。年表は自動で増える。
- **論破**　突きつける物を1つ選び、自分の言葉で書く。キーボードで打っても、下の言葉のボタンを押して入れてもいい。ひらがな、言いかえ、少しの打ちまちがいは通る。言葉を並べすぎると、通らない。
- **ヒント**　初期設定は切。設定で入にできる。使うと評価が下がる。

## まちがえて押した時のために

- 大事な決定（突きつける、答える、人物をつなぐ、時代を渡る、おまかせ運転、泊まる、当主と向き合う）の前に、かならず「これで決定しますか？」と聞く。
- 押したあと0.3秒は、次の押しを受けつけない。設定で、なし、0.3秒、0.6秒、1秒に変えられる。
- 「1つ戻る」で、1つ前の場所へ戻れる。論破の文は「1つ消す」で戻せる。
- 進み具合は、いつも自動で保存される。claude.ai のアーティファクトとして開いた時はアカウントに、ファイルとして開いた時はブラウザに保存する。

## iPad で

- 音は、画面を1度押すと出る。題の画面の右下に、「音：出ます」と出る。
- 鳴らない時は、設定の「音のテスト」を開く。音の出口が開いているか、声がどこまで読みこめたかが分かる。「ピッ」「声」「雨」「エンジン」を1つずつ鳴らせる。
- 論破で入力欄を押すと、入力欄と「これで答える」と確認のボタンが、画面の上の方に集まる。キーボードの下に隠れない。「言葉のボタンに戻る」で、もとの並びに戻る。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（1ファイル） |
| `v/a.mp3`〜`v/d.mp3` | 声。2026年、1993年、1960年、最後の夜 |
| `src/story.txt` `src/story2.txt` | 台本。あとの物が、同じ名前の場面を上書きする |
| `src/data.js` | 時代、道、場所、調べる物、人、証拠、事実、人物のつながり、論破の判定、言葉の辞書 |
| `src/chars.js` `src/cast.js` | 人物の絵。骨格（頭、あご、首、鎖骨、肩）から組む。年齢で顔が変わる。表情は11通り |
| `src/scenes_a.js` `src/scenes_b.js` `src/scenes_c.js` | 背景。時代で変わる。`scenes_c.js` は墓地と、部屋の小物・光・床の描き込み |
| `src/art2.js` `src/art3.js` | 歩く主人公、立っている人、検分の図と拡大図 |
| `src/drive.js` | フロントガラスごしの道。曲がり角、傾く景色、ワイパー、流れる雨つぶ、時代ごとの運転席 |
| `src/audio.js` | 声、雨、洞窟、車、足音、音楽。最初の1押しで音を開く処理と、音のテスト |
| `src/engine.js` `src/style.css` `src/page.html` | エンジンと画面 |
| `build.py` | `index.html` を組み立てる |
| `voices.py` | VOICEVOX で声を作る。読みの辞書は `../cyber-game/src` の物を使う |
| `test/run.js` | 最初から3つの結末まで、実際の画面を通して遊ぶテスト |
| `test/check.js` | データのつじつまを調べる。名前のある物が全部あるか、全部の事実が手に入るか |
| `test/judge.js` | 文字入力の判定のテスト。言いかえと打ちまちがいが通り、まちがいと総当たりが通らない事を見る |
| `test/touch.js` `test/ui.js` | タブレットをまねた画面で、1本指の操作を確かめるテスト |
| `test/drive.js` | 分かれ道の選択、ハンドルの回り方、補助を切った時のふくらみを確かめるテスト |
| `test/ipad.js` | 音が最初の1押しで開く事、音のテスト、キーボードを出した時の並びを確かめるテスト |
| `test/voice.js` | 全部の台詞に声がある事を数えるテスト |

`python3 build.py` で組み立てる。テストは、フォルダを `python3 -m http.server 8770` で開いてから `node test/run.js` など。
